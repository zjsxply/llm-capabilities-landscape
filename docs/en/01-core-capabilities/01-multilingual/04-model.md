# 1.1.4 Model

- [XLM-R](https://arxiv.org/abs/1911.02116): A field-defining multilingual pretraining method that scales masked-language-model training over CommonCrawl data across 100 languages for cross-lingual transfer without task-specific translation supervision.
- [mT5](https://arxiv.org/abs/2010.11934): A multilingual text-to-text pretraining recipe that trains a T5-style encoder-decoder on mC4 so understanding and generation share one sequence-to-sequence objective across languages.
- [BLOOMZ and mT0](https://arxiv.org/abs/2211.01786): A multilingual instruction-tuning line that uses prompted multitask mixtures to transfer instruction following to unseen tasks and languages.
- [Aya Expanse](https://arxiv.org/abs/2412.04261): A multilingual open-model recipe combining broader language coverage, annotation, preference tuning, and safety iteration to improve multilingual frontier behavior.
- [Zero-Shot Prompting for LLM-Based Machine Translation Using In-Domain Target Sentences](https://doi.org/10.1109/taslp.2024.3519814): Uses in-domain target-language sentences as zero-shot demonstrations for LLM machine translation, directly testing prompt-side adaptation without parallel examples.
- [When natural language is not enough: The limits of in-context learning demonstrations in multilingual reasoning](https://doi.org/10.18653/v1/2025.findings-naacl.412): Shows where in-context demonstrations fail for multilingual reasoning, identifying limits of few-shot transfer across languages.
- [Multilingual Reasoning via Self-training](https://doi.org/10.18653/v1/2025.naacl-long.577): Improves multilingual reasoning through self-training, using model-generated reasoning data to strengthen transfer beyond supervised multilingual resources.
- [Language-Specific Latent Process Hinders Cross-Lingual Performance](https://arxiv.org/abs/2505.13141): Analyzes language-specific latent processes that hinder cross-lingual transfer, giving a model-side account of multilingual performance gaps.
- [MPO](https://arxiv.org/abs/2505.16869): Introduces Multilingual Safety Alignment via Reward Gap Optimization, a model-side contribution for Multilingual.
- [CulFiT](https://arxiv.org/abs/2505.19484): Introduces Fine-grained Cultural-aware LLM Training Paradigm via Multilingual Critique Data Synthesis, a model-side contribution for Multilingual.
- [When Language Shapes Thought: Cross-Lingual Transfer of Factual Knowledge in Question Answering](https://arxiv.org/abs/2505.24409): Studies how language choice changes transfer of factual knowledge in question answering, separating knowledge storage from cross-lingual expression.
- [R2-MultiOmnia](https://doi.org/10.18653/v1/2025.acl-long.402): Introduces Leading Multilingual Multimodal Reasoning via Self-Training, a model-side contribution for Multilingual.
- [Overcoming language barriers via machine translation with sparse Mixture-of-Experts fusion of large language models](https://doi.org/10.1016/j.ipm.2025.104078): Introduces sparse mixture-of-experts fusion for LLM-based machine translation, making multilingual generation a model-side composition problem rather than a single-model prompt.
- [Grounding Multilingual Multimodal LLMs With Cultural Knowledge](https://arxiv.org/abs/2508.07414): Grounds multilingual multimodal LLMs with cultural knowledge so image-language reasoning is not reduced to translated surface text.
- [A Shared Geometry of Difficulty in Multilingual Language Models](https://arxiv.org/abs/2601.12731): Finds shared difficulty geometry across multilingual models, helping compare language-specific and model-specific failure patterns.
- [Multilingual Large Language Models do not comprehend all natural languages to equal degrees](https://arxiv.org/abs/2602.20065): Measures unequal language comprehension in multilingual LLMs, treating language coverage as a graded model capability rather than a binary support flag.
- [Tiny Aya](https://arxiv.org/abs/2603.11510): Studies compact multilingual model training and scaling choices for maintaining language coverage at small parameter counts.
- [ShapleyLaw: A Game-Theoretic Approach to Multilingual Scaling Laws](https://arxiv.org/abs/2603.17945): Formulates multilingual scaling laws with Shapley-style attribution to estimate language contributions during multilingual training.
- [Neither Here Nor There: Cross-Lingual Representation Dynamics of Code-Mixed Text in Multilingual Encoders](https://arxiv.org/abs/2603.19771): Analyzes code-mixed text representations in multilingual encoders, clarifying how cross-lingual dynamics change when languages are mixed.
- [Multiple-Debias: A Full-process Debiasing Method for Multilingual Pre-trained Language Models](https://arxiv.org/abs/2604.02772): Proposes a full-process debiasing method for multilingual pretrained language models, covering data, training, and inference stages.
- [English is Not All You Need](https://arxiv.org/abs/2604.13286): Studies multilingual post-training data composition, testing how language diversity affects downstream multilingual and reasoning behavior.
- [Resolving Linguistic Asymmetry: Forging Symmetric Multilingual Embeddings Through Asymmetric Contrastive and Curriculum Learning](https://doi.org/10.3390/sym17091386): Uses asymmetric contrastive learning and curriculum learning to reduce directional asymmetry in multilingual embeddings.
