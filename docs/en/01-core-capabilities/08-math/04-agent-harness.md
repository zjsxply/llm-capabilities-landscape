# 1.8.4 Agent Harness

- [Draft, Sketch, and Prove](https://arxiv.org/abs/2210.12283) ([code](https://github.com/albertqjiang/draft_sketch_prove)): A two-stage formal proving harness that first generates proof sketches, then calls provers/hammers to complete formal proofs.
- [PAL](https://arxiv.org/abs/2211.10435) ([code](https://github.com/reasoning-machines/pal)): Rewrites mathematical reasoning as executable programs and then fills in the answer, a classic starting point for programmatic math agents.
- [Program of Thoughts](https://arxiv.org/abs/2211.12588) ([code](https://github.com/TIGER-AI-Lab/Program-of-Thoughts)): Explicitly converts intermediate reasoning into program execution traces, reducing arithmetic errors in pure-text reasoning.
- [Tree of Thoughts](https://arxiv.org/abs/2305.10601) ([code](https://github.com/princeton-nlp/tree-of-thought-llm)): Tree-structures reasoning trajectories and supports branch expansion, backtracking, and self-evaluation; a representative harness for mathematical test-time search.
- [LeanDojo](https://arxiv.org/abs/2306.15626) ([code](https://github.com/lean-dojo/LeanDojo)): Integrates premise retrieval, proof-state interaction, and verifier feedback into a reproducible proof-assistant-in-the-loop runtime.
- [ToRA](https://arxiv.org/abs/2309.17452) ([code](https://github.com/microsoft/ToRA)): Orchestrates natural-language reasoning, code execution, and symbolic tool calls into a unified math agent loop.
- [COPRA](https://arxiv.org/abs/2310.04353) ([code](https://github.com/trishullab/copra)): A collaborative proof agent for Lean, emphasizing planning, retrieval, and a proof-state-driven execution loop.
- [DeepSeek-Prover-V1.5](https://arxiv.org/abs/2408.08152) ([code](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5)): A specialized agent implementation for Lean formal proof, emphasizing verifiable proof trajectories.
- [Newclid](https://arxiv.org/abs/2411.11938) ([code](https://github.com/Newclid/Newclid)): A neuro-symbolic agent framework for geometry proving, emphasizing a verifiable search process.
- [AlphaGeometry 2](https://arxiv.org/abs/2502.03544) ([code](https://github.com/google-deepmind/alphageometry2)): A follow-up AlphaGeometry system that strengthens collaboration between geometry reasoning and symbolic search.
- [Goedel-Prover](https://arxiv.org/abs/2502.07640) ([code](https://github.com/Goedel-LM/Goedel-Prover)): An agent system for formal mathematical proof, highlighting automated proof search and verifiable output.
- [StepMathAgent](https://arxiv.org/abs/2503.10105): A process-evaluation agent for mathematical solutions; the core idea is to segment, score, aggregate, and organize step errors through a Tree-of-Error representation instead of only judging final answers.
- [DeepSeek-Prover-V2](https://arxiv.org/abs/2504.21801) ([code](https://github.com/deepseek-ai/DeepSeek-Prover-V2)): A recursive subgoal-decomposition formal proving harness for Lean 4; the core idea is to first have a strong model generate proof plans and subgoals, then use a prover to search for subgoal proofs and use Lean-verifiable feedback for cold start and reinforcement learning.
- [Prover Agent](https://arxiv.org/abs/2506.19923) ([code](https://github.com/kAIto47802/Prover-Agent)): Improves Lean proof-solving capability through agentic search and tool interaction.
- [Seed-Prover](https://arxiv.org/abs/2507.23726) ([code](https://github.com/ByteDance-Seed/Seed-Prover)): A lemma-style whole-proof proving system for IMO-level problems; the core idea is to iteratively revise proofs using Lean feedback, proven lemmas, and self-summarization, while combining depth and breadth search strategies at test time.
- [Goedel-Prover-V2](https://arxiv.org/abs/2508.03613) ([code](https://github.com/Goedel-LM/Goedel-Prover-V2)): A self-correcting formal proof harness; the core idea is to improve proof-search stability and verification rate with difficulty-progressive data scaffolding, self-correction driven by Lean compiler feedback, and checkpoint averaging.
- [Code2Math](https://arxiv.org/abs/2603.03202): A multi-agent harness for evolving mathematical problems with code agents. Core idea: use code execution and validation loops to transform existing problems into harder solvable variants, turning problem generation into an exploratory agent workflow.
- [QED](https://arxiv.org/abs/2604.24021): A multi-agent proof-generation system for open mathematical problems; the core idea is to distribute proof search, critique, verification focus, and revision across specialized agents to address research-level proving failure modes.
- [OProver](https://arxiv.org/abs/2605.17283): An agentic formal proving framework for Lean 4; the core idea is to iteratively feed failed proof attempts, compiler feedback, and verified proofs back into the training and repair loop.
- [STAR-PólyaMath](https://arxiv.org/abs/2605.19338) ([code](https://github.com/Julius-Woo/STAR-PolyaMath)): A multi-agent mathematical reasoning harness for leaderboards such as MathArena Apex, AIME, Putnam, IMO, HMMT, and USAMO; the core idea is to use a Meta-Strategist, Reasoner-Verifier, and challenge-step-replan state machine to maintain long-horizon strategies, backtrack failed branches, and limit hallucination accumulation.
- [AlphaGeometry](https://www.nature.com/articles/s41586-023-06747-5) ([code](https://github.com/google-deepmind/alphageometry)): A neuro-symbolic geometry proving system that constrains proof correctness with verifiable symbolic deduction.
