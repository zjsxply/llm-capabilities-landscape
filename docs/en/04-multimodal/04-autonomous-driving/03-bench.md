# 4.4.3 Bench

- [From Words to Collisions](https://arxiv.org/abs/2502.02145): Evaluates and generates safety-critical driving scenarios with LLM guidance. Core idea: turn natural-language risk descriptions into adversarial traffic situations so autonomous-driving systems can be stress-tested on rare but dangerous scenarios.
- [A Comprehensive LLM-powered Framework for Driving Intelligence Evaluation](https://arxiv.org/abs/2503.05164): Evaluates driving behavior intelligence in complex traffic environments. Core idea: use natural-language evaluation data from professional drivers and passengers to score autonomous-driving behavior beyond low-level perception metrics.
- [SCD-Bench](https://arxiv.org/abs/2503.06497): Evaluates safety cognition in vision-language models for autonomous driving. Core idea: pair interactive driving scenarios with semi-automated expert-refined annotations and automated assessment so safety-critical reasoning is measured beyond ordinary perception accuracy.
- [DriveLMM-o1](https://arxiv.org/abs/2503.10621): Benchmarks step-by-step visual reasoning for autonomous driving. Core idea: pair perception, prediction, and planning VQA with explicit reasoning traces so driving models are judged on the reasoning process as well as final answers.
- [Capability-Driven Scenario Understanding Evaluation](https://arxiv.org/abs/2503.11400): Evaluates multimodal large language models on autonomous-driving scenario understanding. Core idea: organize driving-scene comprehension by capabilities so failures in perception, context reasoning, and decision-relevant understanding can be separated.
- [AutoDrive-QA](https://arxiv.org/abs/2503.15778): Evaluates vision-language models in urban autonomous-driving scenes through multiple-choice QA. Core idea: convert open driving QA sources into standardized questions with distractors tied to driving misconceptions, sensor misreadings, logic errors, computational oversights, and ambiguity.
- [UniOcc](https://arxiv.org/abs/2503.24381): Benchmarks occupancy forecasting and prediction in autonomous driving. Core idea: unify real and simulated datasets with 2D/3D occupancy labels, per-voxel flows, and metrics for assessing occupancy quality beyond pseudo-label evaluation.
- [RealEngine](https://arxiv.org/abs/2505.16902): Provides a realistic simulation framework for evaluating autonomous-driving agents. Core idea: combine multimodal sensing, realistic scene rendering, closed-loop trajectories, diverse traffic scenarios, multi-agent interaction, and scalable execution to make driving-agent assessment more controlled and realistic.
- [Drive4C](https://doi.org/10.1109/CVPRW67362.2025.00371): A closed-loop benchmark for language-guided autonomous driving, aimed at testing which foundation-model capabilities matter when instructions must translate into driving behavior.
- [Pseudo-Simulation](https://arxiv.org/abs/2506.04218): Benchmarks autonomous-driving policies with synthetic future observations over real data. Core idea: approximate closed-loop recovery and causal-confusion effects without full interactive simulation, with a public leaderboard for pseudo-simulation evaluation.
- [DriveAction](https://arxiv.org/abs/2506.05667): Evaluates human-like driving decisions in VLA models. Core idea: use action-driven QA over diverse real-world driving scenarios with discrete action labels from driver behavior, making decision preference and scenario coverage explicit.
- [STSBench](https://arxiv.org/abs/2506.06218): Evaluates spatio-temporal scenario understanding for multimodal large language models in autonomous driving. Core idea: test whether models reason over dynamic driving scenes and temporal relations rather than only classify static road images.
- [AD^2-Bench](https://arxiv.org/abs/2506.09557): Evaluates multimodal large language models for autonomous driving under adverse conditions. Core idea: use hierarchical chain-of-thought style tasks to test whether models can reason about degraded driving scenes rather than only handle clean visual inputs.
- [Drama-X](https://arxiv.org/abs/2506.17590): Benchmarks fine-grained intent prediction and risk reasoning for driving. Core idea: use traffic scenarios where participant intent and risk evolve over time so driving systems are tested on anticipation, not only object detection.
- [AirV2X](https://arxiv.org/abs/2506.19283): Benchmarks unified air-ground vehicle-to-everything collaboration. Core idea: combine aerial, roadside, and vehicle viewpoints so cooperative perception and planning systems can be tested under cross-platform sensing and communication constraints.
- [StyleDrive](https://arxiv.org/abs/2506.23982): Benchmarks driving-style awareness in end-to-end autonomous driving. Core idea: evaluate whether driving policies preserve task success while adapting to style-sensitive behaviors such as cautious, normal, or aggressive driving.
- [PDB-Eval](https://arxiv.org/abs/2507.18447): Evaluates multimodal models on personalized driving-behavior description and explanation. Core idea: test temporal driver-behavior understanding with explanation and QA components, complementing general driving-scene perception benchmarks.
- [End-to-End Autonomous Driving through V2X Cooperation Challenge](https://arxiv.org/abs/2507.21610): Benchmarks cooperative autonomous driving through V2X. Core idea: evaluate cooperative temporal perception and end-to-end planning under communication, fusion, and multi-agent planning constraints instead of isolated ego-vehicle perception.
- [Bench2ADVLM](https://arxiv.org/abs/2508.02028): A closed-loop benchmark for vision-language models in autonomous driving. Core idea: evaluate driving-relevant perception, reasoning, and decision behavior in a loop rather than only scoring static scene understanding.
- [DriveQA](https://arxiv.org/abs/2508.21824): Evaluates driving knowledge in LLMs and MLLMs through text and vision questions. Core idea: exhaustively cover traffic rules, signage, right-of-way, numerical reasoning, and spatial layouts so driving agents are tested on edge cases that ordinary scene-understanding datasets underrepresent.
- [DriveE2E](https://arxiv.org/abs/2509.23922): A closed-loop autonomous-driving benchmark built through real-to-simulation scenario transfer. Core idea: replay real intersection traffic in CARLA-style evaluation so end-to-end driving agents face realistic dynamic scenes rather than hand-scripted scenarios.
- [ODVBench](https://arxiv.org/abs/2509.24871): Evaluates online video understanding in autonomous-driving scenarios as part of the StreamForest work. Core idea: test generalization under driving videos where temporal state, scene changes, and persistent event memory matter.
- [DriveCritic](https://arxiv.org/abs/2510.13108): Evaluates autonomous-driving trajectories with context-aware human preferences. Core idea: pair challenging driving scenarios with trajectory-pair judgments so VLM-based evaluators can be measured against human-aligned context reasoning rather than only geometric metrics.
- [Evaluating Video Models as Simulators of Multi-Person Pedestrian Trajectories](https://arxiv.org/abs/2510.20182): Evaluates whether video models can simulate multi-person pedestrian trajectories. Core idea: test social-motion and trajectory consistency so video generation is judged as a usable simulator rather than only by visual plausibility.
- [VehicleWorld](https://aclanthology.org/2025.findings-emnlp.23/): What it evaluates: API agents for intelligent vehicle-cockpit interaction. Core idea: provide executable vehicle modules, APIs, properties, and real-time state so agents must build environment awareness and recover from tool-call errors across tightly coupled subsystems.
- [Driving Safety Bench / DSBench](https://arxiv.org/abs/2511.14592): Evaluates both external road-environment risks and in-cabin behavior risks for autonomous-driving VLM safety readiness.
- [AIGV-Bench](https://arxiv.org/abs/2512.06376): Evaluates whether AI-generated driving videos are usable for autonomous-driving training and evaluation. Core idea: diagnose artifacts, implausible motion, and traffic-semantic violations, then measure their downstream impact on perception tasks.
- [Intention-Drive](https://arxiv.org/abs/2512.12302): Evaluates end-to-end autonomous driving from high-level human intentions. Core idea: pair complex natural-language intents with sensor data and use Imagined Future Alignment to judge semantic goal fulfillment beyond geometric trajectory accuracy.
- [SAVeD](https://arxiv.org/abs/2512.17724): A first-person ADAS near-miss and crash video benchmark. Core idea: curate social-media videos of ADAS-equipped vehicles with frame-level event annotations and VLLM baselines so driving-video models can be tested on rare, safety-critical edge cases.
- [DrivingGen](https://arxiv.org/abs/2601.01528): Evaluates generative video world models for autonomous driving. Core idea: use driving-specific scene dynamics and controllability requirements to test whether generated futures are useful for embodied planning rather than only visually plausible.
- [HazardForge / MovSafeBench](https://arxiv.org/abs/2601.08470): Evaluates VLM safety in generated hazardous mobile scenarios. Core idea: synthesize moving, intrusive, and distant hazards with validation modules, then test models on normal and anomalous scenario QA that stresses motion-aware safety reasoning.
- [AutoDriDM](https://arxiv.org/abs/2601.14702): An explainable benchmark for VLM decision-making in autonomous driving. Core idea: evaluate whether vision-language models produce grounded, interpretable driving decisions rather than only perception labels.
- [AgentDrive](https://arxiv.org/abs/2601.16964): Evaluates agentic reasoning in autonomous systems with LLM-generated driving scenarios. Core idea: use open scenario data to test whether agents can reason about autonomous-system situations rather than only classify static driving scenes.
- [ScenePilot-4K](https://arxiv.org/abs/2601.19582): evaluates vision-language models in first-person autonomous-driving scenes. Core idea: use large-scale egocentric driving data and benchmark tasks to test whether models understand driving-relevant scene evidence from the vehicle viewpoint.
- [DriveCombo](https://arxiv.org/abs/2603.01637): Benchmarks compositional traffic-rule reasoning in autonomous driving. Core idea: use a five-level cognitive ladder to test progression from single-rule understanding to multi-rule integration and conflict resolution in text and vision driving scenarios.
- [CounterScene](https://arxiv.org/abs/2603.21104): A counterfactual closed-loop evaluation framework for safety-critical driving world models. Core idea: identify causally critical agents, model interaction dependencies, and generate minimally perturbed adversarial scenarios that preserve trajectory realism while exposing long-horizon collision risk.
- [VehicleMemBench](https://arxiv.org/abs/2603.23840): What it evaluates: long-term multi-user memory in in-vehicle agents. Core idea: make memory affect executable tool-state outcomes in a simulated vehicle assistant, exposing preference conflict and user-specific recall failures.
