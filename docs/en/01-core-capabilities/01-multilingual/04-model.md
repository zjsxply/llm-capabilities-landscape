# 1.1.4 Model

- [XLM-R](https://arxiv.org/abs/1911.02116): A field-defining multilingual pretraining method that scales masked-language-model training over CommonCrawl data across 100 languages for cross-lingual transfer without task-specific translation supervision.
- [mT5](https://arxiv.org/abs/2010.11934): A multilingual text-to-text pretraining recipe that trains a T5-style encoder-decoder on mC4 so understanding and generation share one sequence-to-sequence objective across languages.
- [BLOOMZ and mT0](https://arxiv.org/abs/2211.01786): A multilingual instruction-tuning line that uses prompted multitask mixtures to transfer instruction following to unseen tasks and languages.
- [LLaMA Beyond English: An Empirical Study on Language Capability Transfer](https://arxiv.org/abs/2401.01055): Empirically studies language capability transfer beyond English in LLaMA-style models.
- [Multilingual Instruction Tuning With Just a Pinch of Multilinguality](https://arxiv.org/abs/2401.01854): Tests how a small amount of multilingual instruction data can transfer instruction following across languages without fully multilingual tuning mixtures.
- [MPN: Leveraging Multilingual Patch Neuron for Cross-lingual Model Editing](https://arxiv.org/abs/2401.03190): Uses multilingual patch neurons as localized edit targets so a factual model edit can propagate across languages.
- [Translate-Distill: Learning Cross-Language Dense Retrieval by Translation and Distillation](https://arxiv.org/abs/2401.04810): Trains cross-language dense retrievers by translating queries or passages and distilling retrieval behavior across languages.
- [Whose wife is it anyway? Assessing bias against same-gender relationships in machine translation](https://arxiv.org/abs/2401.04972): Probes machine-translation systems for gendered relationship bias when translating references to same-gender spouses.
- [Discovering Low-rank Subspaces for Language-agnostic Multilingual Representations](https://arxiv.org/abs/2401.05792): Identifies low-rank representation subspaces that preserve language-agnostic signals in multilingual encoders.
- [Towards Boosting Many-to-Many Multilingual Machine Translation with Large Language Models](https://arxiv.org/abs/2401.05861): Adapts large language models for many-to-many machine translation rather than only English-centric translation directions.
- [Adapting Large Language Models for Document-Level Machine Translation](https://arxiv.org/abs/2401.06468): Fine-tunes or prompts LLMs for document-level translation where sentence outputs must preserve discourse context.
- [Kun: Answer Polishment for Chinese Self-Alignment with Instruction Back-Translation](https://arxiv.org/abs/2401.06477): Uses instruction back-translation and answer polishing to self-align Chinese instruction responses.
- [TransliCo: A Contrastive Learning Framework to Address the Script Barrier in Multilingual Pretrained Language Models](https://arxiv.org/abs/2401.06620): Uses contrastive learning to align transliterated and original-script representations, targeting the script barrier in multilingual pretrained language models rather than an external agent loop.
- [MAPO: Advancing Multilingual Reasoning through Multilingual Alignment-as-Preference Optimization](https://arxiv.org/abs/2401.06838): Applies multilingual preference optimization to align reasoning behavior across languages.
- [xCoT: Cross-lingual Instruction Tuning for Cross-lingual Chain-of-Thought Reasoning](https://arxiv.org/abs/2401.07037): Builds cross-lingual chain-of-thought instruction data so reasoning traces learned in one language transfer to others.
- [Question Translation Training for Better Multilingual Reasoning](https://arxiv.org/abs/2401.07817): Uses translated questions as training signals to improve multilingual reasoning without requiring fully parallel rationales.
- [Enhancing Document-level Translation of Large Language Model via Translation Mixed-instructions](https://arxiv.org/abs/2401.08088): Mixes translation instructions during LLM tuning to improve document-level machine translation behavior.
- [Breaking the Curse of Multilinguality with Cross-lingual Expert Language Models](https://arxiv.org/abs/2401.10440): Introduces cross-lingual expert language models to reduce interference between languages in multilingual training.
- [Cross-lingual Editing in Multilingual Language Models](https://arxiv.org/abs/2401.10521): Studies whether knowledge edits made in one language transfer to other languages inside multilingual language models.
- [LangBridge: Multilingual Reasoning Without Multilingual Supervision](https://arxiv.org/abs/2401.10695): Connects language-specific encoders to reasoning LLMs so multilingual reasoning can work without multilingual supervision.
- [Text Embedding Inversion Security for Multilingual Language Models](https://arxiv.org/abs/2401.12192): Tests whether multilingual text embeddings can be inverted back into sensitive source-language text.
- [How Far Can 100 Samples Go? Unlocking Overall Zero-Shot Multilingual Translation via Tiny Multi-Parallel Data](https://arxiv.org/abs/2401.12413): Shows how tiny multi-parallel seed data can unlock broader zero-shot multilingual translation.
- [Improving Machine Translation with Human Feedback: An Exploration of Quality Estimation as a Reward Model](https://arxiv.org/abs/2401.12873): Uses quality-estimation models as reward signals for human-feedback-style machine-translation optimization.
- [MaLA-500: Massive Language Adaptation of Large Language Models](https://arxiv.org/abs/2401.13303): Adapts large language models across 500 languages for broad multilingual coverage.
- [RomanSetu: Efficiently unlocking multilingual capabilities of Large Language Models via Romanization](https://arxiv.org/abs/2401.14280): Romanizes non-Latin inputs to expose multilingual ability in LLMs without changing the model vocabulary.
- [Modular Adaptation of Multilingual Encoders to Written Swiss German Dialect](https://arxiv.org/abs/2401.14400): Applies modular adaptation to multilingual encoders for written Swiss German dialects with scarce standard resources.
- [Multilingual Text-to-Image Generation Magnifies Gender Stereotypes and Prompt Engineering May Not Help You](https://arxiv.org/abs/2401.16092): Evaluates how multilingual prompts in text-to-image models amplify gender stereotypes and where prompt engineering fails to mitigate them.
- [TeenyTinyLlama: open-source tiny language models trained in Brazilian Portuguese](https://arxiv.org/abs/2401.16640): Releases tiny LLaMA-style language models trained specifically on Brazilian Portuguese corpora.
- [Cross-Lingual Transfer from Related Languages: Treating Low-Resource Maltese as Multilingual Code-Switching](https://arxiv.org/abs/2401.16895): Treats low-resource Maltese as multilingual code-switching to improve cross-lingual transfer.
- [Paramanu: Compact and Competitive Monolingual Language Models for Low-Resource Morphologically Rich Indian Languages](https://arxiv.org/abs/2401.18034): Trains compact monolingual language models for morphologically rich low-resource Indian languages.
- [CroissantLLM: A Truly Bilingual French-English Language Model](https://arxiv.org/abs/2402.00786): Builds a balanced French-English bilingual LLM rather than adapting an English-dominant base model.
- [Predicting Machine Translation Performance on Low-Resource Languages: The Role of Domain Similarity](https://arxiv.org/abs/2402.02633): Models low-resource translation performance as a function of domain similarity between available data and target use cases.
- [KS-Lottery: Finding Certified Lottery Tickets for Multilingual Language Models](https://arxiv.org/abs/2402.02801): Searches for certified lottery-ticket subnetworks inside multilingual language models.
- [Soft Prompt Tuning for Cross-Lingual Transfer: When Less is More](https://arxiv.org/abs/2402.03782): Studies soft prompt tuning for cross-lingual transfer.
- [UltraLink: An Open-Source Knowledge-Enhanced Multilingual Supervised Fine-tuning Dataset](https://arxiv.org/abs/2402.04588): Provides a knowledge-enhanced multilingual supervised fine-tuning dataset for training instruction models.
- [Multilingual E5 Text Embeddings: A Technical Report](https://arxiv.org/abs/2402.05672): Reports multilingual E5 text embeddings, relevant to multilingual retrieval and representation models.
- [A Prompt Response to the Demand for Automatic Gender-Neutral Translation](https://arxiv.org/abs/2402.06041): Studies prompting strategies for automatic gender-neutral translation.
- [FaBERT: Pre-training BERT on Persian Blogs](https://arxiv.org/abs/2402.06617): Pretrains a Persian BERT variant on blog text to improve informal-domain Persian language modeling.
- [Aya Dataset: An Open-Access Collection for Multilingual Instruction Tuning](https://arxiv.org/abs/2402.06619): Releases an open-access multilingual instruction-tuning dataset.
- [GenTranslate: Large Language Models are Generative Multilingual Speech and Machine Translators](https://arxiv.org/abs/2402.06894): Frames LLMs as generative translators across speech and text translation settings.
- [Aya Model: An Instruction Finetuned Open-Access Multilingual Language Model](https://arxiv.org/abs/2402.07827): Releases an open-access multilingual instruction-tuned model.
- [Massively Multi-Cultural Knowledge Acquisition & LM Benchmarking](https://arxiv.org/abs/2402.09369): Collects multicultural knowledge and uses it to benchmark how language models represent culture-specific facts.
- [Do Llamas Work in English? On the Latent Language of Multilingual Transformers](https://arxiv.org/abs/2402.10588): Analyzes the latent language used by multilingual transformers when processing non-English inputs.
- [Python is Not Always the Best Choice: Embracing Multilingual Program of Thoughts](https://arxiv.org/abs/2402.10691): Replaces English-only Python program-of-thought reasoning with programs written in languages better matched to each task.
- [An Empirical Study on Cross-lingual Vocabulary Adaptation for Efficient Language Model Inference](https://arxiv.org/abs/2402.10712): Studies cross-lingual vocabulary adaptation for efficient language-model inference.

- [I Learn Better If You Speak My Language: Understanding the Superior Performance of Fine-Tuning Large Language Models with LLM-Generated Responses](https://arxiv.org/abs/2402.11192): Compares fine-tuning with LLM-generated responses in the target language against English-centric response data.
- [LEIA: Facilitating Cross-Lingual Knowledge Transfer in Language Models with Entity-based Data Augmentation](https://arxiv.org/abs/2402.11485): Uses entity-based data augmentation to transfer factual knowledge across languages in language models.
- [Advancing Translation Preference Modeling with RLHF: A Step Towards Cost-Effective Solution](https://arxiv.org/abs/2402.11525): Builds preference models for translation quality so RLHF-style optimization can be applied more cheaply to MT.
- [Zero-Shot Video Translation via Token Warping](https://arxiv.org/abs/2402.12099): Uses token warping to perform video translation without paired video-translation supervision.
- [Enhancing Multilingual Capabilities of Large Language Models through Self-Distillation from Resource-Rich Languages](https://arxiv.org/abs/2402.12204): Distills behavior from resource-rich languages into lower-resource languages to improve multilingual LLM capability.
- [GlórIA: A Generative and Open Large Language Model for Portuguese](https://arxiv.org/abs/2402.12969): Releases an open generative LLM trained for Portuguese.
- [Investigating Cultural Alignment of Large Language Models](https://arxiv.org/abs/2402.13231): Measures how well LLM behavior aligns with culture-specific norms across languages and regions.
- [Investigating Multilingual Instruction-Tuning: Do Polyglot Models Demand for Multilingual Instructions?](https://arxiv.org/abs/2402.13703): Tests whether already multilingual base models need multilingual instruction data or can transfer from monolingual instructions.
- [LexC-Gen: Generating Data for Extremely Low-Resource Languages with Large Language Models and Bilingual Lexicons](https://arxiv.org/abs/2402.14086): Generates training data for extremely low-resource languages by combining LLM generation with bilingual lexicons.
- [Unveiling Linguistic Regions in Large Language Models](https://arxiv.org/abs/2402.14700): Maps language-related regions in LLM representations to explain where multilingual behavior is encoded.
- [Efficient and Effective Vocabulary Expansion Towards Multilingual Large Language Models](https://arxiv.org/abs/2402.14714): Expands LLM vocabularies for multilingual use while controlling retraining cost.
- [Zero-shot cross-lingual transfer in instruction tuning of large language models](https://arxiv.org/abs/2402.14778): Studies when instruction tuning transfers zero-shot from one language to another.

- [Fine-Tuned Machine Translation Metrics Struggle in Unseen Domains](https://arxiv.org/abs/2402.18747): Shows that fine-tuned machine-translation metrics lose reliability when evaluated outside their training domains.
- [AdaMergeX: Cross-Lingual Transfer with Large Language Models via Adaptive Adapter Merging](https://arxiv.org/abs/2402.18913): Merges adapters from a reference task and source or target languages to estimate target-language task adapters, improving cross-lingual transfer without directly fine-tuning every task-language pair.
- [What Is Missing in Multilingual Visual Reasoning and How to Fix It](https://arxiv.org/abs/2403.01404): Tests multilingual visual reasoning failures and improves open VLMs with translate-test, visual-programming, and caption-based interventions for multilinguality, reasoning, and multimodality.
- [Analyzing and Adapting Large Language Models for Few-Shot Multilingual NLU: Are We There Yet?](https://arxiv.org/abs/2403.01929): Compares supervised fine-tuning, instruction tuning, and in-context learning across six languages and three NLU tasks, finding instruction tuning the best performance-cost tradeoff while target-language adaptation does not fix low-resource ICL understanding.
- [IRCoder: Intermediate Representations Make Language Models Robust Multilingual Code Generators](https://arxiv.org/abs/2403.03894): Continues causal-language-model training on the SLTrans corpus of roughly four million source-code files paired with compiler intermediate representations, aligning programming languages through a shared IR.
- [Did Translation Models Get More Robust Without Anyone Even Noticing?](https://arxiv.org/abs/2403.03923): Re-evaluates multilingual MT and LLM translators under spelling, abbreviation, and formatting noise, showing recent open systems are much more robust than older MT models without explicit robustness training.
- [Breaking the Language Barrier: Can Direct Inference Outperform Pre-Translation in Multilingual LLM Applications?](https://arxiv.org/abs/2403.04792): Benchmarks PaLM2 direct inference versus pre-translation across 108 languages and six tasks, finding direct non-English inference usually beats translating inputs into English first.
- [Tracing the Roots of Facts in Multilingual Language Models: Independent, Shared, and Transferred Knowledge](https://arxiv.org/abs/2403.05189): Uses mLAMA probes and Wikipedia source tracing to separate language-independent, cross-lingual shared, and transferred factual knowledge patterns in multilingual BERT.
- [Cost-Performance Optimization for Processing Low-Resource Language Tasks Using Commercial LLMs](https://arxiv.org/abs/2403.05434): Measures tokenization cost and quality for low-resource languages in GPT-4, then compares code-mixing, translation, and transliteration policies that can reduce LLM service cost while preserving task quality.
- [Revealing the Parallel Multilingual Learning within Large Language Models](https://arxiv.org/abs/2403.09073): Introduces Parallel Input in Multiple Languages, where translated copies of the same prompt improve in-context comprehension and produce more selective neuron activation across multilingual LLMs.
- [Komodo: A Linguistic Expedition into Indonesia's Regional Languages](https://arxiv.org/abs/2403.09362): Releases Komodo-7B base and instruction models for Indonesian, English, and 11 Indonesian regional languages, with evaluations against GPT-3.5, Aya-101, Llama-2-Chat, Mixtral, and Gemma.
- [Is Translation All You Need? A Study on Solving Multilingual Tasks with Large Language Models](https://arxiv.org/abs/2403.10258): Shows English translation helps English-centric LLMs on some NLP tasks but native-language prompting is stronger for culture-sensitive queries that require local linguistic nuance.
- [MYTE: Morphology-Driven Byte Encoding for Better and Fairer Multilingual Language Modeling](https://arxiv.org/abs/2403.10691): Replaces byte or character segmentation with morpheme-based encoding to shorten sequences across 99 languages and reduce multilingual language-model perplexity gaps, especially for non-European and non-Latin languages.
- [Optimizing Language Augmentation for Multilingual Large Language Models: A Case Study on Korean](https://arxiv.org/abs/2403.10882): Builds the Korean-focused Bllossom model by expanding the vocabulary, continuing bilingual pretraining, and instruction-tuning on a small high-quality Korean dataset.
- [RakutenAI-7B: Extending Large Language Models for Japanese](https://arxiv.org/abs/2403.15484): Releases Japanese-oriented 7B foundation, instruction, and chat models under Apache 2.0, reporting top Japanese LM Harness performance among open 7B models.

- [Poro 34B and the Blessing of Multilinguality](https://arxiv.org/abs/2404.01856): Trains a 34B open decoder model on Finnish, English, and programming-language data, using balanced multilingual pretraining to improve Finnish without isolating it from higher-resource text.
- [Backdoor Attacks on Multilingual Machine Translation](https://arxiv.org/abs/2404.02393): Shows that poisoning less than 0.01 percent of a low-resource translation pair can transfer malicious behavior into high-resource directions in multilingual NMT.
- [On the Multilingual Ability of Decoder-based Pre-trained Language Models: Finding and Controlling Language-Specific Neurons](https://arxiv.org/abs/2404.02431): Identifies language-specific neurons in decoder-only multilingual PLMs and shows that manipulating under 1 percent of neurons can steer the generated language.
- [Sailor: Open Language Models for South-East Asia](https://arxiv.org/abs/2404.03608): Continues pretraining open LLMs with Southeast Asian language corpora and tokenizer adaptation, releasing models aimed at Indonesian, Thai, Vietnamese, Malay, and related regional languages.
- [Chinese Tiny LLM: Pretraining a Chinese-Centric Large Language Model](https://arxiv.org/abs/2404.04167): Documents a small Chinese-centric LLM pretraining stack, including Chinese-heavy data construction and tokenizer choices for resource-efficient local-language modeling.
- [Multilingual Pretraining and Instruction Tuning Improve Cross-Lingual Knowledge Alignment, But Only Shallowly](https://arxiv.org/abs/2404.04659): Proposes CLiKA to measure performance, consistency, and conductivity of cross-lingual knowledge alignment, finding that pretraining and instruction tuning help but do not deeply align knowledge transfer.
- [Low-Resource Machine Translation through Retrieval-Augmented LLM Prompting: A Study on the Mambai Language](https://arxiv.org/abs/2404.04809): Uses retrieved bilingual examples and lexical resources in LLM prompts for Mambai translation, illustrating a retrieval-heavy low-resource MT adaptation rather than model pretraining.
