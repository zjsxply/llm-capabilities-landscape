# 2.8.4 Model

- [Outcome-based Reinforcement Learning to Predict the Future](https://arxiv.org/abs/2505.17989): Applies RLVR to real-world event forecasting with delayed outcome rewards and proper scoring rules, improving probabilistic calibration in smaller models.
- [Aurora](https://arxiv.org/abs/2509.22295): Introduces a multimodal time-series foundation model for zero-shot cross-domain forecasting, using text and image context to guide probabilistic future-token generation.
- [OpenForecaster](https://arxiv.org/abs/2512.25070) ([code](https://github.com/OpenForecaster/scaling-forecasting-training)): Trains forecasting agents from automatically synthesized OpenForesight questions, offline retrieval, and reinforcement learning to improve accuracy, calibration, and long-term consistency.
- [Future-as-Label](https://arxiv.org/abs/2601.06336): Uses real-world event resolution as scalable supervision, training forecasting models with outcome-based RLVR and proper scoring rewards over causally masked information.
