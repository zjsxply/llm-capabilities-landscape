# 1.5.3 Bench

(The following are sorted by release time and cover OCR, document understanding, chart understanding, general VQA and diagnostics, STEM/science figure reasoning, visual agent/tool-use evaluation, and related subtasks.)

- [DocVQA](https://arxiv.org/abs/2007.00398) ([challenge page](https://www.docvqa.org/challenges)): evaluates visual question answering, table understanding, and information extraction on document images. The core idea is to put OCR, layout structure, and answer localization in real scanned/photographed documents into one challenge protocol; it is the core benchmark behind the DocVQA Challenge leaderboard.
- [FSC-147](https://arxiv.org/abs/2105.08386): evaluates few-shot counting, where the model counts in a new image after receiving a few annotated examples. The core idea is to test counting generalization in a few-shot setting, and it is often used as a classic reference for the "counting" sub-capability.
- `CountBench` (see [Teaching CLIP to Count to Ten](https://arxiv.org/abs/2302.12066); [dataset](https://huggingface.co/datasets/vikhyatk/CountBenchQA)): evaluates visual counting and the reliability of quantity concepts. The core idea is to diagnose basic visual capability and bias through "whether the count is correct", often combined with VQA/bias diagnostics.
- [HallusionBench](https://arxiv.org/abs/2310.14566) ([open-source code](https://github.com/tianyi-lab/HallusionBench); [dataset](https://huggingface.co/datasets/lmms-lab/HallusionBench)): evaluates visual hallucination and errors driven by visual illusions. The core idea is to use controlled visual illusions and image-context reasoning questions to diagnose specific types of "making things up from images."
- [MMMU](https://arxiv.org/abs/2311.16502) ([homepage/leaderboard](https://mmmu-benchmark.github.io/#leaderboard); [dataset](https://huggingface.co/datasets/MMMU/MMMU); [evaluation code](https://github.com/MMMU-Benchmark/MMMU)): evaluates multidisciplinary multimodal understanding and reasoning. The core idea is to use cross-disciplinary question types and a unified scoring protocol to measure integrated "see image + read question + reason" capability.
- [MM-SAP: A Comprehensive Benchmark for Assessing Self-Awareness of Multimodal Large Language Models in Perception](https://arxiv.org/abs/2401.07529): evaluates whether MLLMs know what they can and cannot perceive from images. The core idea is a perception knowledge-quadrant protocol that links hallucination analysis to self-awareness over visual evidence.
- [SceMQA: A Scientific College Entrance Level Multimodal Question Answering Benchmark](https://arxiv.org/abs/2402.05138): evaluates college-entrance-level science QA across mathematics, physics, chemistry, and biology. The benchmark mixes multiple-choice and free-response questions, knowledge-point labels, and explanations to test multimodal scientific reasoning.
- [ChartX and ChartVLM: A Versatile Benchmark and Foundation Model for Complicated Chart Reasoning](https://arxiv.org/abs/2402.12185): evaluates chart reasoning over 18 chart types, 7 task families, and 22 disciplinary topics. The benchmark stresses extracting visualized values and reasoning over chart content rather than ordinary image captioning.
- [MM-Soc: Benchmarking Multimodal Large Language Models in Social Media Platforms](https://arxiv.org/abs/2402.14154): evaluates multimodal social-media understanding across tasks such as misinformation, hate speech, emotion, and social-context generation, combining existing datasets with a large YouTube tagging dataset.
- [A Cognitive Evaluation Benchmark of Image Reasoning and Description for Large Vision Language Models](https://arxiv.org/abs/2402.18409): evaluates LVLM cognitive abilities with 251 semantically rich Cookie-Theft-style images, annotations for eight reasoning capabilities, and paired image-description and VQA tasks.
- [VLKEB: A Large Vision-Language Model Knowledge Editing Benchmark](https://arxiv.org/abs/2403.07350): evaluates LVLM knowledge editing with reliability, locality, generality, and portability metrics, using more reliable image collection to test whether edited knowledge transfers into relevant visual contexts.
- [B-AVIBench: Toward Evaluating the Robustness of Large Vision-Language Model on Black-Box Adversarial Visual-Instructions](https://arxiv.org/abs/2403.09346): evaluates LVLM robustness to black-box adversarial visual instructions, covering image attacks, text attacks, and bias-triggering content over 316K adversarial visual-instruction samples.
- [EXAMS-V: A Multi-Discipline Multilingual Multimodal Exam Benchmark for Evaluating Vision Language Models](https://arxiv.org/abs/2403.10378): evaluates VLMs on 20,932 multilingual exam questions across 20 school disciplines, with images, tables, maps, diagrams, scientific symbols, and equations from 11 languages and varied education systems.
- [IllusionVQA: A Challenging Optical Illusion Dataset for Vision Language Models](https://arxiv.org/abs/2403.15952): evaluates VLMs on optical-illusion VQA, stressing whether models can answer from deceptive visual evidence rather than surface language priors.
- [MMStar](https://arxiv.org/abs/2403.20330) ([project page](https://mmstar-benchmark.github.io/); [open-source code](https://github.com/MMStar-Benchmark/MMStar); [dataset](https://huggingface.co/datasets/Lin-Chen/MMStar)): evaluates comprehensive multimodal tasks where vision is indispensable. The core idea is to use multidimensional sub-capability axes and analysis metrics such as "multimodal gain/leakage" to measure whether models truly use visual input.
- [IsoBench: Benchmarking Multimodal Foundation Models on Isomorphic Representations](https://arxiv.org/abs/2404.01266): evaluates whether foundation models preserve performance across isomorphic visual, textual, and mathematical representations of the same math, science, algorithm, and game problems.
- [What Are We Measuring When We Evaluate Large Vision-Language Models? An Analysis of Latent Factors and Biases](https://arxiv.org/abs/2404.02415): analyzes latent factors and biases in VL evaluation, including generation-length bias and transfer structure across benchmarks, making it a benchmark-quality audit rather than a new task set.
- [MathWriting: A Dataset For Handwritten Mathematical Expression Recognition](https://arxiv.org/abs/2404.10690): provides 230K human-written and 400K synthetic handwritten mathematical-expression samples, supporting both online stroke recognition and rendered offline formula OCR.
- [SEED-Bench-2-Plus: Benchmarking Multimodal Large Language Models with Text-Rich Visual Comprehension](https://arxiv.org/abs/2404.16790): evaluates text-rich visual comprehension with 2.3K human-annotated multiple-choice questions, targeting images where embedded text must be read and used for reasoning.
- [Exploring the Capability of LLMs in Performing Low-Level Visual Analytic Tasks on SVG Data Visualizations](https://arxiv.org/abs/2404.19097): evaluates LLMs on low-level analytic tasks over SVG visualizations, testing whether text-form chart encodings can support value lookup, comparison, and visual-analysis reasoning.
- [Vibe-Eval](https://arxiv.org/abs/2405.02287) ([open-source code](https://github.com/reka-ai/reka-vibe-eval)): evaluates multimodal models across multidimensional tasks. The core idea is to provide a broad comprehensive evaluation suite with annotations and scoring protocols closer to human subjective preferences.
- [MTVQA](https://arxiv.org/abs/2405.11985) ([project page](https://bytedance.github.io/MTVQA/); [open-source code](https://github.com/bytedance/MTVQA)): evaluates multilingual text-centric visual QA, where models read and understand text in images. The core idea is to cover multilingual and low-resource languages and emphasize integrated text perception and cross-lingual understanding.
- [LOVA3: Learning to Visual Question Answering, Asking and Assessment](https://arxiv.org/abs/2405.14974): evaluates multimodal question answering, question generation, and answer assessment as a linked learning loop, broadening VQA evaluation beyond answer-only accuracy.
- [VLind-Bench: Measuring Language Priors in Large Vision-Language Models](https://arxiv.org/abs/2406.08702): measures language-prior reliance in LVLMs by constructing image-question cases where text patterns can conflict with visual evidence, exposing hallucination risk from ignoring the image.
- [MuirBench](https://arxiv.org/abs/2406.09411) ([project page](https://muirbench.github.io/); [open-source code](https://github.com/muirbench/MuirBench); [dataset](https://huggingface.co/datasets/muirbench/MuirBench)): evaluates robust multi-image understanding under multi-image input. The core idea is to decompose multi-image tasks into robustness/consistency subtasks that specifically test cross-image alignment and resistance to interference.
- [SUGARCREPE++ Dataset: Vision-Language Model Sensitivity to Semantic and Lexical Alterations](https://arxiv.org/abs/2406.11171): evaluates VLM sensitivity to semantic and lexical perturbations, using controlled text alterations to test whether image-text matching models preserve precise meaning.
- [DocGenome: An Open Large-scale Scientific Document Benchmark for Training and Testing Multi-modal Large Language Models](https://arxiv.org/abs/2406.11633): builds a scientific-document benchmark from 500K arXiv documents across 153 disciplines with an auto-labeling pipeline, covering multi-page extraction and within-document formats such as charts and equations.
- [VRSBench: A Versatile Vision-Language Benchmark Dataset for Remote Sensing Image Understanding](https://arxiv.org/abs/2406.12384): evaluates remote-sensing image understanding with higher-quality object information and multi-task vision-language annotations, addressing single-task and weak-control limits in prior RS datasets.
- [Benchmarking Multi-Image Understanding in Vision and Language Models: Perception, Knowledge, Reasoning, and Multi-Hop Reasoning](https://arxiv.org/abs/2406.12742): introduces MIRB for multi-image relational understanding across perception, visual world knowledge, reasoning, and multi-hop reasoning, contrasting with single-image VLM benchmarks.
- [PIN: A Knowledge-Intensive Dataset for Paired and Interleaved Multimodal Documents](https://arxiv.org/abs/2406.13923): releases paired and interleaved multimodal-document data that combines structured Markdown with full-page layout images, supporting knowledge-intensive document understanding and cross-modal relation reasoning.
- [Measuring the Measurers: Quality Evaluation of Hallucination Benchmarks for Large Vision-Language Models](https://arxiv.org/abs/2406.17115): audits hallucination benchmarks for LVLMs, evaluating benchmark quality and failure coverage rather than only ranking models on another VQA set.
- [CharXiv](https://arxiv.org/abs/2406.18521) ([project page](https://princeton-nlp.github.io/CharXiv/); [dataset](https://huggingface.co/datasets/princeton-nlp/CharXiv); [leaderboard](https://charxiv.github.io/#leaderboard)): evaluates chart/figure and image-text alignment understanding in scientific-paper settings. The core idea is to make "figure-text evidence alignment" into quantifiable QA.
- [MindBench: A Comprehensive Benchmark for Mind Map Structure Recognition and Analysis](https://arxiv.org/abs/2407.02842): evaluates bilingual mind-map and structured-diagram recognition, with annotations for text, layout, hierarchy, and element interactions that ordinary document OCR benchmarks often omit.
- [FlowLearn: Evaluating Large Vision-Language Models on Flowchart Understanding](https://arxiv.org/abs/2407.05183): Releases 3,858 scientific and 10,000 simulated flowcharts with component, OCR, Mermaid, and VQA annotations; GPT-4V leads node counting at 58% while Claude leads OCR at 83%, with no model best on every task.
- [VLMs are Blind](https://arxiv.org/abs/2407.06581) ([project page](https://vlmsareblind.github.io/)): evaluates VLM reliability on extremely simple visual-primitive tasks. The core idea is to use geometry/spatial/counting mini-tests that are nearly effortless for humans to diagnose whether models really "see" the key evidence.
- [NTSEBENCH: Cognitive Reasoning Benchmark for Vision Language Models](https://arxiv.org/abs/2407.10380): evaluates multimodal cognitive reasoning over puzzles, series, and analogies, stressing spatial and textual pattern reasoning beyond commonsense VQA.
- [MM-Vet v2: A Challenging Benchmark to Evaluate Large Multimodal Models for Integrated Capabilities](https://arxiv.org/abs/2408.00765): extends MM-Vet with image-text sequence understanding while retaining integrated capability coverage over recognition, knowledge, spatial awareness, language generation, OCR, and math.
- [GlyphPattern: An Abstract Pattern Recognition for Vision-Language Models](https://arxiv.org/abs/2408.05894): Evaluates abstract pattern recognition in vision-language models. Core idea: pair visual glyph patterns with human-written descriptions to test abstraction rather than familiar object recognition.
- [Multimodal Causal Reasoning Benchmark: Challenging Multimodal Large Language Models to Discern Causal Links Across Modalities](https://arxiv.org/abs/2408.08105): evaluates whether MLLMs can infer causal links across visual and textual modalities rather than answer from correlation or object recognition alone.
- [TWLV-I: Analysis and Insights from Holistic Evaluation on Video Foundation Models](https://arxiv.org/abs/2408.11318): provides a holistic evaluation signal for video foundation models, useful here as a temporal extension of image understanding rather than an OCR-specific test.
- [MMR: Evaluating Reading Ability of Large Multimodal Models](https://arxiv.org/abs/2408.14594): evaluates complex reading, reasoning, and spatial understanding over text-rich images, targeting cases where extraction-only OCR questions no longer separate model capability.
- [EvoChart: A Benchmark and a Self-Training Approach Towards Real-World Chart Understanding](https://arxiv.org/abs/2409.01577): evaluates real-world chart understanding and pairs the benchmark with synthetic chart self-training data, stressing visual comprehension over chart values and relations.
- [MMMU-Pro](https://arxiv.org/abs/2409.02813) ([homepage/leaderboard](https://mmmu-benchmark.github.io/#leaderboard); [dataset](https://huggingface.co/datasets/MMMU/MMMU_Pro); [evaluation code](https://github.com/MMMU-Benchmark/MMMU)): evaluates harder multimodal STEM where the model "must look at the image." The core idea is to embed question text into images, filter out text-only-answerable questions, and strengthen distractor options so evaluation depends more on visual input and reasoning chains.
- [CDM: A Reliable Metric for Fair and Accurate Formula Recognition Evaluation](https://arxiv.org/abs/2409.03643): proposes Character Detection Matching for formula recognition, comparing rendered character-level matches to reduce unfairness from equivalent LaTeX strings and notation variants.
- [READoc: A Unified Benchmark for Realistic Document Structured Extraction](https://arxiv.org/abs/2409.05137): evaluates document structured extraction as a unified task, addressing fragmented benchmarks by covering realistic raw documents and structured-output requirements.
- [Dynamic Multimodal Evaluation with Flexible Complexity by Vision-Language Bootstrapping](https://arxiv.org/abs/2410.08695): builds dynamic multimodal evaluation via vision-language bootstrapping, targeting static benchmark contamination and fixed-complexity limits.
- [MCTBench: Multimodal Cognition towards Text-Rich Visual Scenes Benchmark](https://arxiv.org/abs/2410.11538): evaluates cognitive abilities in text-rich visual scenes through visual reasoning and content-creation tasks, complementing benchmarks that focus only on text perception.
- [MC-Bench: A Benchmark for Multi-Context Visual Grounding in the Era of MLLMs](https://arxiv.org/abs/2410.12332): evaluates multi-context visual grounding with 2K manually annotated image-pair samples and open-ended prompts that require localizing target instances across images.
- [HumanEval-V: Evaluating Visual Understanding and Reasoning Abilities of Large Multimodal Models Through Coding Tasks](https://arxiv.org/abs/2410.12381): evaluates diagram interpretation for coding, with human-annotated tasks across six visual reasoning types where the model must understand a diagram before generating code.
- [MultiChartQA: Benchmarking Vision-Language Models on Multi-Chart Problems](https://arxiv.org/abs/2410.14179): evaluates multi-hop QA over multiple charts, requiring models to extract and integrate information across charts rather than solve isolated single-chart questions.
- [Advancements in Visual Language Models for Remote Sensing: Datasets, Capabilities, and Enhancement Techniques](https://arxiv.org/abs/2410.17283): surveys remote-sensing VLM datasets and capability axes, serving as evidence for how image-language benchmarks in this page extend beyond natural images.
- [AutoBench-V: Can Large Vision-Language Models Benchmark Themselves?](https://arxiv.org/abs/2410.21259): studies automatic construction of visual benchmarks by LVLMs, addressing human-cost, static-data, and contamination problems in multimodal evaluation.
- [Image2Struct: Benchmarking Structure Extraction for Vision-Language Models](https://arxiv.org/abs/2410.22456): evaluates structure extraction from images by asking VLMs to output renderable structures such as LaTeX or HTML, then comparing the rendered result with the source image.
- [M-Longdoc: A Benchmark For Multimodal Super-Long Document Understanding And A Retrieval-Aware Tuning Framework](https://arxiv.org/abs/2411.06176): evaluates open-ended QA over hundreds-page multimodal documents containing text, figures, and tables, with 851 samples and a retrieval-aware reading setup.
- [Large Vision-Language Models for Remote Sensing Visual Question Answering](https://arxiv.org/abs/2411.10857): evaluates generative LVLMs for remote-sensing VQA, focusing on open-ended answers over satellite imagery rather than traditional discriminative RS pipelines.
- [CHOICE: Benchmarking the Remote Sensing Capabilities of Large Vision-Language Models](https://arxiv.org/abs/2411.18145): evaluates hierarchical remote-sensing capabilities of general and domain-specific VLMs for Earth-observation perception and reasoning.
- [TQA-Bench: Evaluating LLMs for Multi-Table Question Answering with Scalable Context and Symbolic Extension](https://arxiv.org/abs/2411.19504): evaluates QA over heterogeneous multi-table relational data, stressing scalable context serialization, symbolic extensions, and cross-table reasoning absent from single-table QA.
- [Assessing GPT model uncertainty in mathematical OCR tasks via entropy analysis](https://arxiv.org/abs/2412.01221): analyzes uncertainty in equation-image-to-LaTeX OCR with entropy and mutual information over output token sequences and image-resolution variants.
- [CC-OCR: A Comprehensive and Challenging OCR Benchmark for Evaluating Large Multimodal Models in Literacy](https://arxiv.org/abs/2412.02210): evaluates OCR literacy across multi-scene text reading, multilingual text reading, document parsing, and key-information extraction, with 39 subsets and 7,058 fully annotated images.
- [BigDocs: An Open and Permissively-Licensed Dataset for Training Multimodal Models on Document and Code Tasks](https://arxiv.org/abs/2412.04626): releases BigDocs-7.5M, a license-permissive multimodal document dataset spanning 30 document and code tasks with documented filtering and quality controls.
- [OmniDocBench 1.5](https://arxiv.org/abs/2412.07626) ([open-source code](https://github.com/opendatalab/OmniDocBench); [dataset](https://huggingface.co/datasets/opendatalab/OmniDocBench); [leaderboard](https://github.com/opendatalab/OmniDocBench#leaderboard)): evaluates modular document-parsing capabilities such as layout, paragraphs, tables, and structure. The core idea is to decompose "document parsing capability" into measurable parts with modular metrics and engineering runtimes such as hybrid matching, CDM, and Dockerization.
- [CoMT: A Novel Benchmark for Chain of Multi-modal Thought on Large Vision-Language Models](https://arxiv.org/abs/2412.12932): evaluates multimodal chain-of-thought where intermediate reasoning can include visual operations, addressing text-only output limits in prior multimodal reasoning benchmarks.
- [Multi-modal, Multi-task, Multi-criteria Automatic Evaluation with Vision Language Models](https://arxiv.org/abs/2412.14613): proposes a multi-task, multi-criteria VLM-based evaluation setup for generated text quality, adapting criteria beyond single-task image-captioning metrics.
- [FiVL: A Framework for Improved Vision-Language Alignment through the Lens of Training, Evaluation and Explainability](https://arxiv.org/abs/2412.14672): Provides a dataset, benchmark, metric, or evaluation protocol for measuring Image and OCR capabilities.
- [REFINESUMM: Self-Refining MLLM for Generating a Multimodal Summarization Dataset](https://doi.org/10.18653/v1/2024.acl-long.743): uses a self-refining MLLM pipeline to generate a multimodal summarization dataset, making visual-document summarization a reusable evaluation and data-construction setting.
- [OCRBench v2](https://arxiv.org/abs/2501.00321) ([evaluation implementation collection](https://github.com/Yuliang-Liu/MultimodalOCR); [Codesota leaderboard](https://www.codesota.com/ocr/benchmark/ocrbench-v2)): evaluates multimodal OCR, where models read text in images and then perform understanding/reasoning. The core idea is to couple OCR with downstream reasoning and distinguish "cannot read it" from "read it but cannot use it."
- [IllusionBench+: A Large-scale and Comprehensive Benchmark for Visual Illusion Understanding in Vision-Language Models](https://arxiv.org/abs/2501.00848): IllusionBench+ evaluates vision-language models on large-scale visual illusion understanding and visual hallucination failure modes.
- [Acknowledging Focus Ambiguity in Visual Questions](https://arxiv.org/abs/2501.02201): Bench candidate for image, document, chart, and general multimodal understanding. Core idea: Acknowledging Focus Ambiguity in Visual Questions.
- [EMMA](https://arxiv.org/abs/2501.05444) ([homepage](https://emma-benchmark.github.io/); [leaderboard](https://emma-benchmark.github.io/#leaderboard); [dataset](https://huggingface.co/datasets/luckychao/EMMA-mini); [open-source code](https://github.com/EMMA-Bench/EMMA)): evaluates "organic multimodal reasoning" across math, physics, chemistry, and coding. The core idea is to construct tasks that require chaining evidence across modalities and provide generation/evaluation scripts for reproducible comparison.
- [CHIRP: A Fine-Grained Benchmark for Open-Ended Response Evaluation in Vision-Language Models](https://arxiv.org/abs/2501.09672): evaluates long-form open-ended VLM responses with fine-grained criteria, introduced after analyzing weaknesses in automated, AI-based, and human evaluation across Robin model scales.
- [MM-IQ: Benchmarking Human-Like Abstraction and Reasoning in Multimodal Models](https://arxiv.org/abs/2502.00698): Benchmarks human-like abstraction and reasoning in multimodal models.
- [SARChat-Bench-2M: A Multi-Task Vision-Language Benchmark for SAR Image Interpretation](https://arxiv.org/abs/2502.08168): evaluates vision-language interpretation of synthetic-aperture-radar imagery across multiple SAR tasks, extending image understanding benchmarks beyond optical images.
- [EventSTR: A Benchmark Dataset and Baselines for Event Stream based Scene Text Recognition](https://arxiv.org/abs/2502.09020): provides 9,928 high-definition event-camera samples with Chinese and English text annotations for scene text recognition under low light, motion blur, and clutter.
- [REAL-MM-RAG: A Real-World Multi-Modal Retrieval Benchmark](https://arxiv.org/abs/2502.12342): A real-world multimodal retrieval benchmark; core idea: compare retrieval and generation when evidence may be textual, visual, or cross-modal.
- [SimpleVQA](https://arxiv.org/abs/2502.13059) ([open-source code](https://github.com/SimpleVQA/SimpleVQA)): evaluates multimodal factuality and "whether the image is truly used." The core idea is to use a simple but strict VQA protocol to identify whether models rely on language priors instead of visual evidence.
- [GroundCap: A Visually Grounded Image Captioning Dataset](https://arxiv.org/abs/2502.13898): provides grounded image captions for 52,016 movie frames, linking object identities and actions through tags so caption text can be verified against specific visual elements.
- [What Is a Good Caption? A Comprehensive Visual Caption Benchmark for Evaluating Both Correctness and Coverage of MLLMs](https://arxiv.org/abs/2502.14914): Evaluates visual captions for correctness and coverage. Core idea: separate whether captions are factually correct from whether they cover the important visual evidence.
- [KITAB-Bench: A Comprehensive Multi-Domain Benchmark for Arabic OCR and Document Understanding](https://arxiv.org/abs/2502.14949): Benchmarks Arabic OCR and document understanding across diverse layouts and text-rich domains.
- [PairBench: Are Vision-Language Models Reliable at Comparing What They See?](https://arxiv.org/abs/2502.15210): Systematic VLM benchmark for pairwise visual comparison reliability.
- [VisFactor](https://arxiv.org/abs/2502.16435) ([open-source code](https://github.com/CUHK-ARISE/VisFactor)): evaluates basic visual cognition in multimodal models, leaning toward "visual primitives." The core idea is to systematically split basic visual sub-capabilities into controlled subtests and reduce room for language gaming.
- [MCiteBench: A Benchmark for Multimodal Citation Text Generation in MLLMs](https://arxiv.org/abs/2503.02589): evaluates multimodal citation text generation, testing whether MLLMs can generate citation statements grounded in visual and textual scholarly context.
- [Vision-Language Models Struggle to Align Entities across Modalities](https://arxiv.org/abs/2503.03854): Provides a reusable evaluation target, leaderboard, or measurement protocol for image and vision-language understanding.
- [Chart-HQA: A Benchmark for Hypothetical Question Answering in Charts](https://arxiv.org/abs/2503.04095): evaluates counterfactual chart QA by imposing hypothetical assumptions on chart questions, forcing models to reason from chart content rather than parametric memory.
- [A Benchmark for Multi-Lingual Vision-Language Learning in Remote Sensing Image Captioning](https://arxiv.org/abs/2503.04592): Provides a dataset, benchmark, metric, or evaluation protocol for measuring Image and OCR capabilities.
- [VLForgery Face Triad: Detection, Localization and Attribution via Multimodal Large Language Models](https://arxiv.org/abs/2503.06142): Provides a benchmark, dataset, or evaluation protocol for measuring Images and OCR capabilities.

- [OWLViz: An Open-World Benchmark for Visual Question Answering](https://arxiv.org/abs/2503.07631): Adds a benchmark or evaluation suite for image ocr, centered on OWLViz: An Open-World Benchmark for Visual Question Answering.

- [Towards Understanding Graphical Perception in Large Multimodal Models](https://arxiv.org/abs/2503.10857): Graphical-perception evaluation: fine-grained perception limits in infographic-style inputs. Core idea: diagnose visual perception failures before downstream reasoning.
- [OmniDiff: A Comprehensive Benchmark for Fine-Grained Image Difference Captioning](https://arxiv.org/abs/2503.11093): Benchmarks fine-grained image difference captioning with diverse real and synthetic scenarios, stressing visual-change localization and semantic description.

- [OpenLEAF: A Novel Benchmark for Open-Domain Interleaved Image-Text Generation](https://doi.org/10.1145/3664647.3685511): evaluates open-domain interleaved image-text generation, testing whether models can produce coherent multimodal sequences rather than isolated captions.

- [mSOP-765k: A Benchmark For Multi-Modal Structured Output Predictions](https://openreview.net/forum?id=OBaCMeVx13): evaluates multimodal structured output prediction with schema-like targets, connecting visual understanding to reliable structured generation.
- [Before the First Token: Benchmarking Data Preprocessing in Vision-Language Models](https://doi.org/10.1145/3805621.3807641): benchmarks VLM data preprocessing before inference, measuring how image preprocessing choices affect downstream vision-language evaluation.
- [MRBench](https://doi.org/10.1145/3746027.3755442): What it evaluates: knowledge-based multi-image reasoning across visually similar, same-entity, attribute-associated, and independent image relations. Core idea: combine multi-image inputs with adaptive retrieval to test whether MLLMs can integrate external knowledge and reason across images.
- [Making Multimodal LLMs Reliable Chart Data Extractors: A Benchmark and Training Framework](https://doi.org/10.1145/3772318.3790721): Evaluates image, OCR, document, chart, or diagram understanding with a defined task, protocol, or dataset.
- [SciTableQA: A Question-Answering Benchmark for Complex Scientific Tables](https://doi.org/10.1007/978-3-032-05409-8_7): Benchmarks question answering over complex scientific tables. Core idea: test whether models can parse table structure and scientific context together rather than only reading plain text.
- [TaiwanVQA: A Benchmark for Visual Question Answering for Taiwanese Daily Life](https://www.semanticscholar.org/paper/9c898b589af81686d7892eb0c3f40e4c7a4f680a): Benchmarks visual question answering for Taiwanese daily life.
