# 2.3.2 Survey

- [From Matching to Generation: A Survey on Generative Information Retrieval](https://arxiv.org/abs/2404.14851): Explains retrieval moving from document ranking to generated results and answers.
- [Large Language Models, Knowledge Graphs and Search Engines](https://arxiv.org/abs/2501.06699): Builds a taxonomy of user information needs and compares how LLMs, knowledge graphs, and search engines can be combined for answer seeking.
- [Agentic Retrieval-Augmented Generation: A Survey on Agentic RAG](https://arxiv.org/abs/2501.09136): Reviews agents that plan retrieval, select tools, and iteratively consume evidence.
- [A Survey of Large Language Model Empowered Agents for Recommendation and Search: Towards Next-Generation Information Retrieval](https://arxiv.org/abs/2503.05659): Connects user intent, interactive search, retrieval planning, and feedback adaptation.
- [A Survey of WebAgents: Towards Next-Generation AI Agents for Web Automation with Large Foundation Models](https://arxiv.org/abs/2503.23350): Covers web environments, perception, planning, action execution, evaluation, and safety.
- [An Illusion of Progress? Assessing the Current State of Web Agents](https://openreview.net/forum?id=6jZi4HSs6o): A COLM 2025 assessment that questions whether web-agent progress is robust across realistic tasks, making it useful as a survey-style calibration point for this page.
- [A Survey of LLM-based Deep Search Agents: Paradigm, Optimization, Evaluation, and Challenges](https://arxiv.org/abs/2508.05668): Frames complex search as iterative query planning, evidence acquisition, evaluation, and synthesis.
- [Integrating Graphs, Large Language Models, and Agents](https://arxiv.org/abs/2604.15951): Surveys how graph structures, large language models, and agent workflows can be integrated for reasoning and retrieval.
- [A Survey of Reasoning-Intensive Retrieval](https://arxiv.org/abs/2605.00063): Surveys retrieval settings where relevance depends on latent inference, covering benchmarks, retrievers, rerankers, and LLM-enabled reasoning across the retrieval pipeline.
- [Knowledge intensive agents](https://doi.org/10.1016/j.aiopen.2026.02.002): Surveys agents for knowledge-intensive tasks, connecting retrieval, knowledge integration, and reasoning as a broader frame for search-augmented agents.
