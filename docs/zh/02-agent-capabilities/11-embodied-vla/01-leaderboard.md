# 2.11.1 Leaderboard

- [BEHAVIOR Challenge Leaderboard](https://behavior.stanford.edu/challenge/index.html)：BEHAVIOR 官方挑战页，用于具身家庭活动基准提交与结果跟踪。
- [HA-VLN Leaderboard](https://ha-vln-project.vercel.app/)：官方 human-aware vision-language navigation 榜单，面向动态多人导航场景。
- [RoboTwin Leaderboard](https://robotwin-platform.github.io/leaderboard)：官方双臂机器人操作榜单，围绕生成式数字孪生任务评测模型。
- [Orak Leaderboard](https://krafton-ai.github.io/orak-leaderboard/)：官方视频游戏 agent 榜单，覆盖多种游戏类型、battle arenas 和 agent-module 设置。
- [RoboArena Leaderboard](https://robo-arena.github.io/)：官方分布式真实世界评测榜单，用于比较通用机器人策略。
- [EmbodiedBench Leaderboard](https://embodiedbench.github.io/)：官方榜单，评测多模态大语言模型作为视觉驱动具身 agent 的表现。
- [VLA Evaluation Harness Leaderboard](https://allenai.github.io/vla-evaluation-harness/leaderboard/)：广泛使用的统一 VLA 榜单，覆盖 LIBERO、CALVIN、RoboCasa、RoboTwin、VLABench、RLBench、BEHAVIOR-1K 等 policy stacks。
- [PokeAgent Challenge Leaderboard](https://pokeagent.github.io/leaderboard.html)：官方挑战榜单，评测 Pokemon 对战和 RPG 速通任务中的具身决策能力。
- [VideoGameBench Leaderboard](https://vgbench.com/#leaderboard)：视频游戏环境中的具身 agent 感知、导航、操作与规划持续榜单；适合跟踪能在可执行视觉世界中行动的模型与 scaffold，而不是只看静态截图。
