# 3.1.5 Agent Harness

- [Installamatic](https://arxiv.org/abs/2412.06294) ([open-source code](https://github.com/coinse/installamatic)) is the most typical agent for installation-step synthesis and failure recovery.
- [ExecutionAgent](https://arxiv.org/abs/2412.10133) ([open-source code](https://github.com/sola-st/ExecutionAgent)) represents "fixing environment commands based on execution feedback."
- [Enabling Autonomic Microservice Management through Self-Learning Agents](https://arxiv.org/abs/2501.19056): An agent harness or runtime for environment setup and operational automation. Core idea: externalize enabling autonomic microservice management through self-learning agents into reusable orchestration, tool-use, memory, or protocol logic.
- [Repo2Run](https://arxiv.org/abs/2502.13681) ([open-source code](https://github.com/bytedance/Repo2Run)) explicitly casts environment construction as Dockerfile synthesis plus a testing loop.
- [SetUpAgent](https://arxiv.org/abs/2503.07701) (open-source code: not released) focuses on self-reflective Dockerfile synthesis and environment patching, representative of explicitly agentizing "trial-and-error environment setup."
- [SWE-smith](https://arxiv.org/abs/2504.21798) ([open-source code](https://github.com/SWE-bench/SWE-smith)) connects executable environment construction, task synthesis, and verification pipelines, closer to a "data factory driven by environment-setup ability."
- [CompileAgent](https://arxiv.org/abs/2505.04254) ([open-source code](https://github.com/Ch3nYe/AutoCompiler)) targets compile-failure repair, emphasizing localization of missing dependencies, API incompatibilities, and build-script issues from compiler logs.
- [Deployability-Centric Infrastructure-as-Code Generation: Fail, Learn, Refine, and Succeed through LLM-Empowered DevOps Simulation](https://arxiv.org/abs/2506.05623): Infrastructure-as-Code (IaC) generation holds significant promise for automating cloud infrastructure provisioning.
- [SWE-Builder (SWE-Factory)](https://arxiv.org/abs/2506.10954) ([open-source code](https://github.com/DeepSoftwareAnalytics/swe-factory)) modularizes environment construction into reusable components for large-scale generation of executable SWE training and evaluation instances.
- [A Fast, Reliable, and Secure Programming Language for LLM Agents with Code Actions](https://arxiv.org/abs/2506.12202): A programming language for secure and reliable code actions by LLM agents. Core idea: constrain executable agent actions through a language layer designed for reliability, security, and inspectability.
- [Type-Compliant Adaptation Cascades: Adapting Programmatic LM Workflows to Data](https://arxiv.org/abs/2508.18244): Adapts programmatic language-model workflows to new data through type-compliant cascades.
- [KubeIntellect: A Modular LLM-Orchestrated Agent Framework for End-to-End Kubernetes Management](https://arxiv.org/abs/2509.02449): An agent harness or runtime for environment setup and operational automation. Core idea: externalize a modular llm-orchestrated agent framework for end-to-end kubernetes management into reusable orchestration, tool-use, memory, or protocol logic.
- [OSS-BUILD-AGENT](https://arxiv.org/abs/2509.25248) (open-source code: no stable public repository found) focuses on recovering build failures in real open-source software, repeatedly modifying dependencies, configuration, and scripts based on build logs until compilation succeeds.
- [Multi-Agent Code-Orchestrated Generation for Reliable Infrastructure-as-Code](https://arxiv.org/abs/2510.03902): An agent harness or runtime for environment setup and operational automation. Core idea: externalize multi-agent code-orchestrated generation for reliable infrastructure-as-code into reusable orchestration, tool-use, memory, or protocol logic.
- [GradleFixer (Automating Android Build Repair)](https://arxiv.org/abs/2510.08640) (open-source code: not released) is boundary-related: it focuses on Android/Gradle build-failure repair, with tasks strongly dependent on build and dependency-environment operations; its ideas are relevant to "environment setup + build repair" tasks, but it is not a general Repo2Run/EnvBench-style benchmark.
- [Automated Cloud Infrastructure-as-Code Reconciliation with AI Agents](https://arxiv.org/abs/2510.20211): Cloud infrastructure is managed through a mix of interfaces -- traditionally, cloud consoles, command-line interfaces (CLI), and SDKs are the tools of choice.
- [Aragog: Just-in-Time Model Routing for Scalable Serving of Agentic Workflows](https://arxiv.org/abs/2511.20975): Routes models just in time inside agentic workflows to reduce serving cost under workflow constraints.
- [SWE-Bench++](https://arxiv.org/abs/2512.17419) ([open-source code](https://github.com/TuringEnterprises/SWE-Bench-plus-plus)) explicitly introduces environment synthesis into an automatic SWE benchmark generation pipeline and compares against setup agents.
- [Deploy-Ready IaC Generation Using Multi-Agent Systems for Cloud Deployments](https://doi.org/10.1109/icbats66542.2025.11258273): Uses multiple agents to produce deployment-ready Infrastructure-as-Code artifacts for cloud deployments, fitting this page when the generated output is directly usable infrastructure configuration rather than prose planning.
- [LLM - Driven Autonomous Cloud Automation Agent](https://doi.org/10.1109/csitss67709.2025.11295499): A reusable agent harness, runtime, protocol, or workflow scaffold for environment setup and executable infrastructure. Core idea: Published in 2025 9th International Conference on Computational System and Information Technology for Sustainable Solutions (CSITSS); metadata title: LLM - Driven Autonomous Cloud Automation Agent.
- [ContextCache: Task-Aware Lifecycle Management for Memory-Efficient LLM Agent Deployment](https://doi.org/10.1109/iros60139.2025.11247595): Contributes an agent workflow, runtime, protocol, tool-use pattern, or multi-agent orchestration approach for agent runtime and deployment infrastructure.
- [LEAF: A Lightweight Edge Agent Framework with Expert SLMs for the Industrial Internet of Things](https://doi.org/10.32604/cmc.2025.074384): Contributes an agent workflow, runtime, protocol, tool-use pattern, or multi-agent orchestration approach for agent runtime and deployment infrastructure.
- [MEnvAgent](https://arxiv.org/abs/2601.22859) ([open-source code](https://github.com/ernie-research/MEnvAgent)) turns "polyglot environment construction" into a multi-agent Planning-Execution-Verification loop and introduces environment reuse.
- [SWE-Universe](https://arxiv.org/abs/2602.02361) (open-source code: not released) advocates large-scale automatic construction of verifiable SWE environments and task data, with environment ability evaluated on the authors' own multilingual task set.
- [HerAgent](https://arxiv.org/abs/2602.07871) ([open-source code](https://github.com/EuniAI/HerAgent)) focuses on automatic environment deployment and performs unified comparative evaluation on multiple setup-related sub-benchmarks; see the paper.
- [ScaleSWE](https://arxiv.org/abs/2602.09892) ([open-source code](https://github.com/AweAI-Team/ScaleSWE)) constructs large-scale verified SWE instances through a multi-agent pipeline of setup agent, test creation agent, and problem synthesis agent.
- [SWE-rebench V2](https://arxiv.org/abs/2602.23866) ([open-source code](https://github.com/SWE-rebench/SWE-rebench-V2)) releases an interactive setup synthesis agent and image build flow for complex repository setup automation.
- [SWE-Hub](https://arxiv.org/abs/2603.00575) ([open-source code](https://github.com/zhenglw02/SWE-Hub)) introduces Env Agent as the execution substrate for a data factory, emphasizing environment setup as infrastructure in large-scale SWE pipelines.
- [stratum: A System Infrastructure for Massive Agent-Centric ML Workloads](https://arxiv.org/abs/2603.03589): System infrastructure for massive agent-centric ML workloads; the core idea is to support thousands of exploratory agent pipeline runs with reproducible execution.
- [RepoLaunch](https://arxiv.org/abs/2603.05026) ([open-source code](https://github.com/microsoft/RepoLaunch)) abstracts cross-language repository build-test execution into a general pipeline.
- [daVinci-Env (OpenSWE)](https://arxiv.org/abs/2603.13023) ([open-source code](https://github.com/GAIR-NLP/OpenSWE)) uses a multi-agent pipeline to synthesize executable Docker environments and evaluation scripts at scale, leaning toward "reproducible infrastructure + environment synthesis."
- [MEMRES](https://arxiv.org/abs/2604.16941): A memory-augmented Python dependency resolver that combines reusable resolution memories, curated import-to-package mappings, semantic import analysis, and a confidence cascade before falling back to an LLM.
- [RAT / RunAnyThing](https://arxiv.org/abs/2604.23190): A language-agnostic automated environment-configuration framework for arbitrary repositories; it combines semantic initialization, planning, specialized setup tools, and sandboxed repair, and introduces RATBench for heterogeneous setup evaluation.
- [Crab: A Semantics-Aware Checkpoint/Restore Runtime for Agent Sandboxes](https://arxiv.org/abs/2604.28138): A semantics-aware checkpoint and restore runtime for agent sandboxes. Core idea: checkpoint only recovery-relevant OS state by bridging agent turn semantics with filesystem, process, and runtime effects.
- [BootstrapAgent](https://arxiv.org/abs/2605.15815) ([open-source code](https://github.com/Vossera/BootstrapAgent)) distills repository-startup experience into a reusable `.bootstrap` contract; its core flow includes evidence extraction, structured planning, Docker verification, trace-driven repair, and clean replay, aiming to reduce repeated trial and error for later coding agents.
- [Self-Healing Infrastructure: Autonomous LLM Agents for Real-Time Remediation of Configuration Drift and Security Misconfigurations in IaC Deployments](https://doi.org/10.35940/ijitee.d4757.15040326): Proposes a closed-loop IaC remediation pipeline with drift detectors, security reasoners, root-cause analyzers, remediation generators, and post-remediation validators, evaluated on simulated Terraform drift scenarios.
