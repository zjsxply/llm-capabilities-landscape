# 1.5.4 Model

- [LLaVA](https://arxiv.org/abs/2304.08485): A high-impact visual instruction-tuning method that connects a vision encoder to an LLM and trains on synthetic image-instruction data.
- [Qwen2.5-VL](https://arxiv.org/abs/2502.13923): A vision-language model recipe with improved visual tokenization, training data, and post-training for OCR, documents, charts, grounding, and visual reasoning.
- [Table-R1](https://arxiv.org/abs/2505.12415): Introduces Region-based Reinforcement Learning for Table Understanding, a model-side contribution for Image Ocr.
- [Effective Training Data Synthesis for Improving MLLM Chart Understanding](https://arxiv.org/abs/2508.06492): Introduces Effective Training Data Synthesis for Improving MLLM Chart Understanding, a model-side contribution for Image Ocr.
- [SERVAL: Surprisingly Effective Zero-Shot Visual Document Retrieval Powered by Large Vision and Language Models](https://arxiv.org/abs/2509.15432): Uses large vision-language models for zero-shot visual document retrieval, directly matching document understanding and OCR retrieval needs.
- [GRPO for Multimodal Table Understanding](https://arxiv.org/abs/2509.16889): Applies GRPO-style reinforcement learning to improve complex table understanding in multimodal models.
- [Infinity Parser](https://arxiv.org/abs/2510.15349): Introduces Layout Aware Reinforcement Learning for Scanned Document Parsing, a model-side contribution for Image Ocr.
- [DeepSeek-OCR](https://arxiv.org/abs/2510.18234): Introduces Contexts Optical Compression, a model-side contribution for Image Ocr.
- [PaddleOCR-VL-1.5](https://arxiv.org/abs/2601.21957): A compact OCR and document VLM trained for recognition, layout, tables, forms, and document QA under noisy real-world inputs.
- [HopChain](https://arxiv.org/abs/2603.17024): A synthetic data method that generates chained visual-question data so VLMs combine multiple pieces of visual evidence.
- [Vero](https://arxiv.org/abs/2604.04917): An open reinforcement-learning recipe for visual reasoning that combines visual data, reward design, and RL optimization.
- [Spatial Priming Outperforms Semantic Prompting: A Grid-Based Approach to Improving LLM Accuracy on Chart Data Extraction](https://arxiv.org/abs/2605.08220): Uses grid-based spatial priming to improve chart data extraction accuracy, a concrete image-OCR and structured-visual-reading task.
