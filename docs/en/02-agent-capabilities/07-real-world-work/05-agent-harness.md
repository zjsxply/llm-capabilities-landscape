# 2.7.5 Agent Harness

- [BrowserGym Ecosystem](https://arxiv.org/abs/2412.05467) ([open-source code](https://github.com/ServiceNow/BrowserGym)): Unifies web/enterprise work environments such as WebArena, VisualWebArena, and WorkArena, with the AgentLab experiment framework; suitable for reproducible comparison of real web and workplace agents.
- [Autono](https://arxiv.org/abs/2504.04650): A ReAct-style autonomous-agent framework with adaptive action generation, timely-abandonment control, and multi-agent memory transfer. Core idea: improve robustness when fixed planner workflows fail by letting execution paths adapt while retaining termination safeguards.
- [Alita](https://arxiv.org/abs/2505.20286) ([open-source code](https://github.com/CharlesQ9/Alita)): A production-oriented general solver agent emphasizing cross-tool orchestration and complex workflow execution, transferable to multi-step execution in real business tasks.
- [MaRGen](https://arxiv.org/abs/2508.01370): A multi-agent harness for self-directed market research and analysis. Core idea: coordinate researcher, retriever, reviewer, and writer agents to query data, generate insights and visualizations, draft market reports, and iteratively improve report quality with automated review.
- [AgenticData](https://arxiv.org/abs/2508.05002): An agentic data-analytics system for heterogeneous structured and unstructured data. Core idea: turn natural-language questions into semantic plans, then coordinate profiling, cross-validation, semantic optimization, and memory agents to execute and refine data-analysis workflows.
- [HomerAgent](https://arxiv.org/abs/2508.09124) ([open-source code](https://github.com/microsoft/OdysseyBench)): The office-productivity agent/harness paired with OdysseyBench, using explicit memory to organize stage results in long-horizon workflows; useful for analyzing context forgetting and erroneous reuse in office workflows.
- [AgentArch Reference Harness](https://arxiv.org/abs/2509.10769) ([open-source code](https://github.com/ServiceNow/AgentArch)): Compares multiple agent architectures in a unified enterprise task environment, suitable for ablating harness design variables such as planner-executor, multi-agent, memory, and tool routing.
- [ARE](https://arxiv.org/abs/2509.17158) ([open-source code](https://github.com/facebookresearch/meta-agents-research-environments)): Turns real task environments into asynchronous runtimes supporting notifications, external systems, state evolution, and execution logs, suitable for evaluating sustained plan updates in dynamic workflows.
- [BrowserAgent](https://arxiv.org/abs/2510.10666) ([open-source code](https://github.com/TIGER-AI-Lab/BrowserAgent)): A solver agent that executes multi-step tasks in real browser action spaces, suitable for realistic constraint-driven web tasks such as WorldTravel.
- [HAL Harness](https://openreview.net/pdf?id=vUaY1t64ZZ) ([open-source code](https://github.com/princeton-pli/hal-harness)): A standardized and cost-visible agent evaluation harness providing a unified CLI, parallel runs, log/cost tracking, and leaderboard submission workflow; useful for moving reproducible real-work agent experiments from single-paper scripts to continuous evaluation.
- [Enterprise Deep Research](https://arxiv.org/abs/2510.17797) ([open-source code](https://github.com/SalesforceAIResearch/enterprise-deep-research)): A multi-agent deep-research system implementation for enterprise research scenarios. Core idea: connect enterprise private knowledge, public web, messages, and file retrieval to a planner/retriever/writer/checker process, suitable for research and reporting workflows inside real organizations.
- [DataSage](https://arxiv.org/abs/2511.14299): A multi-agent insight-discovery harness for data analysis. Core idea: combine external knowledge retrieval, role-based debate, and multi-path reasoning so business analytics agents can validate and refine discovered insights.
- [Agent Discovery in Internet of Agents](https://arxiv.org/abs/2511.19113): Defines how agents advertise, search, match, and verify capabilities under dynamic tasks for large-scale collaboration.
- [AgentNet++](https://arxiv.org/abs/2512.00614): Adds hierarchical coordination, privacy-preserving knowledge sharing, and resource allocation to decentralized LLM-agent networks.
- [Multi-Objective Agentic Rewrites](https://arxiv.org/abs/2512.02289): An agentic rewrite harness for DocETL-style unstructured data pipelines. Core idea: optimize semantic-operator rewrites across accuracy, cost, and latency rather than treating LLM data processing as a fixed prompt pipeline.
- [Trust-Aware Decentralized Multi-Agent System](https://arxiv.org/abs/2512.02410): Extends AgentNet-style dynamic agent graphs with trust-aware communication, privacy-preserving knowledge sharing, and resource-aware coordination for larger agent societies.
- [EvoEnv](https://arxiv.org/abs/2601.08173) ([open-source code](https://github.com/KnowledgeXLab/EvoEnv)): The unified environment/harness framework behind TraineeBench, providing a workspace manager, virtual clock, tool gateway, trajectory/evaluation pipeline, and visual trace viewer; suitable for studying dynamic task scheduling and continuously learning workplace agents.
- [UXCascade](https://arxiv.org/abs/2601.15777): Uses persona-conditioned simulated user agents, action logs, and think-aloud traces to aggregate scalable design feedback.
- [MultiVis-Agent](https://arxiv.org/abs/2601.18320): A multi-agent framework for cross-modal data visualization, using logic rules to coordinate reliable and comprehensive visualization workflows.
- [A2H](https://arxiv.org/abs/2602.15831): Standardizes how agents discover, address, notify, and involve humans as protocol participants rather than out-of-band observers.
- [Reliable Database Question Answering with Collaborative Agents](https://doi.org/10.1109/icassp55912.2026.11463606): A collaborative-agent approach for database question answering, relevant as a data-work harness where multiple roles coordinate query planning and answer verification.
- [SimAB](https://arxiv.org/abs/2603.01024): Converts design screenshots and conversion goals into persona-conditioned simulated user sessions for rapid A/B-style design evaluation.
- [kRAIG](https://arxiv.org/abs/2603.20311): A natural-language-driven agent for automated DataOps pipeline generation, relevant to real-work agents that turn requirements into executable data operations.
- [DAB DataAgent](https://arxiv.org/abs/2603.20576) ([open-source code](https://github.com/ucbepic/DataAgentBench)): The execution framework bundled with Data Agent Benchmark, organized around multi-database connections, Python execution, query logs, tool-call traces, and Pass@1 aggregation; useful as a harness reference for enterprise data QA/analytics tasks.
- [EnterpriseLab](https://arxiv.org/abs/2603.21630) (open-source code: no stable public repository found): A full-stack development and deployment platform for enterprise agents; it connects MCP-style enterprise application environments, automatic trajectory synthesis, training pipelines, and continuous evaluation, validated on an EnterpriseArena instance with 15 applications and 140+ tools. It belongs to the "private enterprise agent harness + data generation + training/evaluation loop" line.
- [DeepEye](https://arxiv.org/abs/2603.28889): A steerable self-driving data-agent system. Core idea: expose controllable data-analysis workflows so users can guide autonomous exploration, visualization, and insight generation instead of accepting a black-box analytics run.
- [Claw-Eval Harness](https://arxiv.org/abs/2604.06132) ([open-source code](https://github.com/claw-eval/claw-eval)): Runs multiple classes of real tasks around OpenClaw-style agents, emphasizing three-channel evidence recording, fine-grained rubrics, Pass^k stability, and safety/robustness checks; suitable as a regression evaluation framework for deployable agents.
- [AV-SQL](https://arxiv.org/abs/2604.07041): Decomposes complex Text-to-SQL with agentic views, making intermediate query views part of the agent workflow rather than relying on one-shot SQL generation.
- [ClawBench Browser Harness](https://arxiv.org/abs/2604.08523) ([open-source code](https://github.com/reacher-z/ClawBench)): Builds a pipeline for task recording, HTTP interception, trajectory replay, and payload judgment around real browser sessions; suitable for evaluating browser agents that modify remote state while minimizing actual destructive submissions.
- [Agentic Jackal](https://arxiv.org/abs/2604.09470): A live-execution and semantic-grounding harness for Text-to-JQL, relevant to data and workflow agents that must validate generated queries against tool-side values.
- [OccuBench LWM Harness](https://arxiv.org/abs/2604.10866) ([open-source code](https://github.com/GregxmHu/OccuBench)): Outsources professional-scenario tool responses to a Language World Model and provides a reference agent loop, fault injection, 3-vote rubric verifier, and OpenAI-compatible API interface; its value is enabling interactive agent evaluation for professional tasks without real backend systems.
- [PExA](https://arxiv.org/abs/2604.22934): A parallel exploration agent for complex Text-to-SQL, relevant as a data-agent harness that searches multiple query hypotheses before committing to an answer.
- [Agentic Harness Engineering](https://arxiv.org/abs/2604.25850): Treats the harness as an observable and iterative object. Core idea: use component visibility, experience visibility, and decision visibility to make automatic evolution of coding-agent harnesses a verifiable loop.
- [Claw-Eval-Live Harness](https://arxiv.org/abs/2604.28139) ([open-source code](https://github.com/Claw-Eval-Live/Claw-Eval-Live)): Connects marketplace signals to task snapshots, mock services, workspace fixtures, graders, and leaderboard aggregation; suitable for building workflow benchmarks that refresh periodically while preserving reproducible snapshots.
- [DataEvolver](https://arxiv.org/abs/2605.01789): A goal-driven loop-agent harness for autonomous data construction and improvement. Core idea: make dataset building an iterative workflow with goals, feedback, and revision rather than a one-shot generation step.
- [WildClawBench Native Runtime Harness](https://arxiv.org/abs/2605.10912) ([open-source code](https://github.com/internlm/WildClawBench)): Hosts long-horizon tasks with Docker and real CLI agent harnesses, emphasizing joint evaluation of the agent system, tool runtime, and model; a realistic complement to evaluating only raw models or lightweight wrappers.
- [LLM-Based Multi-agent Systems](https://doi.org/10.1007/978-3-032-15632-7_9): Surveys LLM-based multi-agent frameworks, evaluation practices, open challenges, and research frontiers, useful for distinguishing multi-agent orchestration patterns from isolated model capability.
- [Internet of Agentic AI](https://doi.org/10.1109/mcom.001.2500309): Frames large-scale agent interoperability, communication, discovery, and governance as infrastructure problems.
