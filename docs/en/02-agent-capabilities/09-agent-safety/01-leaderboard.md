# 2.9.1 Leaderboard

- [CAIS AI Dashboard](https://dashboard.safe.ai/): Includes Risk Index, capability index, and automation views, and is currently the most suitable public safety overview for observing the joint evolution of capabilities and risks across models.
- [MLCommons AILuminate official results](https://ailuminate.mlcommons.org/benchmarks/security/0.5-en_us-official-ensemble): Publishes MLCommons AI safety and reliability benchmark results under a standardized benchmark protocol, making it one of the most credible public safety result surfaces.
- [Libra-Leaderboard](https://leaderboard.librai.tech/): Balances helpfulness and safety scores in a public ranking interface, useful when a safety-only rank would hide large capability regressions.
- [TrustLLM benchmark site](https://trustllmbenchmark.github.io/TrustLLM-Website/): Provides public model result tables across truthfulness, safety, fairness, robustness, privacy, machine ethics, and related trustworthiness dimensions.
- [HarmBench](https://www.harmbench.org/): Official benchmark page for automated red teaming and robust refusal, with public results for attacks, classifiers, and target models.
- [JailbreakBench](https://jailbreakbench.github.io/): Official open robustness benchmark site for jailbreak attacks and defenses, with public challenge-style result tables for model refusal robustness.
- [AgentDojo results](https://agentdojo.spylab.ai/results): Official result page for prompt-injection robustness in tool-using agents, separating utility from attack success and defense behavior.
- [SafeArena leaderboard](https://huggingface.co/spaces/McGill-NLP/safearena-leaderboard): Hugging Face leaderboard for autonomous web-agent safety, tied to the official SafeArena project page.
- [SafePro](https://safeprobench.github.io/safepro/): A project page for professional-grade agent safety, providing benchmark descriptions and result signals such as unsafe rate; useful for tracking "can complete but unsafe" failure modes in real professional work.
- [SORRY-Bench](https://sorry-bench.github.io/): Official safety-refusal benchmark site with public model results for refusal and over-refusal behavior.
- [Agent Security Bench / ASB](https://luckfort.github.io/ASBench/): Official result page for agent-security attacks and defenses, covering prompt injection, memory poisoning, backdoors, and tool-stage vulnerabilities.
- [SafeBench for MLLMs](https://safebench-mm.github.io/): Official project page and result table for multimodal large-language-model safety evaluation.
- [SafeAgentBench](https://safeagentbench.github.io/): Official project page with embodied-agent safety-planning results and benchmark examples.
- [AgentHarm evaluation](https://ukgovernmentbeis.github.io/inspect_evals/evals/safeguards/agentharm/): UK AISI Inspect Evals page for the AgentHarm benchmark, documenting the public evaluation implementation and result interpretation.
- [ML Safety SafeBench winners](https://www.mlsafety.org/safebench/winners): Competition results page for the SafeBench challenge, useful for locating benchmark-winning safety submissions such as AgentDojo and BackdoorLLM.
- [Gray Swan Agent Red-Teaming Challenge results](https://www.grayswan.ai/news/uk-aisi-x-gray-swan-agent-red-teaming-challenge-results-snapshot): Public challenge-results snapshot for indirect prompt-injection red teaming of agents, connected to ART-style agent red-team evaluations.

Note: Agent safety does not yet have a mature, unified, continuously submitted public leaderboard comparable to SWE-bench or Terminal-Bench. Project pages, dashboards, and result tables inside papers are currently more common.
