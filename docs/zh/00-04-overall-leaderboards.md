# 0.4 偏总体验的总榜

> 上级章节：0. Harness 与 Skill Creator


- [LMSYS Chatbot Arena](https://lmarena.ai/leaderboard/text) 更像文本场景下的最终用户体验总榜。
- [Vision Arena](https://lmarena.ai/leaderboard/vision) 更像视觉场景下的最终用户体验总榜。
- [LLM Stats](https://llm-stats.com/) 是持续聚合型模型总榜，把公开 benchmark、API 速度和价格等信号合成统一比较入口；适合快速查看通用模型在多项主流任务上的总体走势。
- [Artificial Analysis Intelligence Index](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index) 是公开的综合模型排名，把多个高难评测聚合成总体能力指数；适合作为模型厂商和用户常看的总体比较点，而不是某个单一任务族的专项 benchmark。
- [CAIS AI Dashboard](https://dashboard.safe.ai/) 是能力与安全并列的前沿模型总览，覆盖文本能力、视觉能力、风险指数和自动化进展；适合把 capability leaderboard 与 safety dashboard 放到同一视图中观察。
这些榜单都不是某个专项能力的专用 benchmark，因此不放进后面的能力章，而作为总体体验指标单独保留。
- [BenchmarkCards](https://arxiv.org/abs/2410.12974)（[开源代码](https://github.com/SokolAnn/BenchmarkCards)）：标准化 benchmark 文档化框架；读新 benchmark 时可用它检查任务目标、数据来源、指标、限制、风险和适用边界是否被说明清楚。
