# 2.1.4 Model

- [AlphaCode](https://arxiv.org/abs/2203.07814): A field-defining contest-code model system using large-scale code pretraining, massive sampling, filtering, clustering, and ranking for Codeforces-style problems.
- [Whodunit: Classifying Code as Human Authored or GPT-4 generated- A case study on CodeChef problems](https://arxiv.org/abs/2403.04013): Adds a model-side contribution for competitive programming, such as training, architecture, post-training, synthetic data, reward/verifier, or world-model machinery.
- [ACECODER](https://arxiv.org/abs/2502.01718): Trains coder models with reinforcement learning by synthesizing automated test cases that provide reliable executable rewards.
- [rStar-Coder](https://arxiv.org/abs/2505.21297): Scales competitive-code reasoning with a large verified dataset and training pipeline for high-difficulty problems with executable tests.
- [ReVeal](https://arxiv.org/abs/2506.11442): Optimizes reliable self-verification behavior for code agents instead of relying only on final outcome rewards.
- [Teaching LLM to Reason: Reinforcement Learning from Algorithmic Problems without Code](https://arxiv.org/abs/2507.07498): The method trains LLM reasoning from algorithmic problems without relying on code execution.
- [CodeRL+](https://arxiv.org/abs/2510.18471): Aligns reinforcement learning for code generation with execution semantics to reduce the gap between text likelihood and functional correctness.
- [AlphaCode 2 Technical Report](https://storage.googleapis.com/deepmind-media/AlphaCode2/AlphaCode2_Tech_Report.pdf): Upgrades competitive-programming model pipelines around Gemini-era reasoning, large-scale generation, search, filtering, and scoring.
- [DRIVE: Data Curation Best Practices for Reinforcement Learning with Verifiable Reward in Competitive Code Generation](https://arxiv.org/abs/2511.06307): Gives data-curation practices for reinforcement learning with verifiable rewards in competitive code generation.
- [Scaling Reasoning Tokens via RL and Parallel Thinking: Evidence From Competitive Programming](https://arxiv.org/abs/2604.01302): Scales reasoning-token budgets through RL training and parallel thinking for competitive programming.
- [GrandCode](https://arxiv.org/abs/2604.02721): Uses agentic reinforcement learning and Agentic GRPO to improve contest-programming modules such as hypothesis proposal, solving, test generation, and summarization.
- [When Independent Sampling Outperforms Agentic Reasoning](https://arxiv.org/abs/2605.08478): Shows that repeated independent sampling can beat agentic reasoning on Codeforces under fixed cost, giving contest-code agents a strong compute-allocation baseline.
- [Solvita: Enhancing Large Language Models for Competitive Programming via Agentic Evolution](https://arxiv.org/abs/2605.15301): A stateless-to-evolutionary contest-solving harness. Core idea: split work across Planner, Solver, Oracle, and Hacker agents, attach a trainable graph-structured knowledge network to each role, and update routing from pass/fail verdicts, certified tests, and adversarially discovered vulnerabilities.
