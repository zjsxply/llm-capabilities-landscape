# 1.5.1 Leaderboard

- [DocVQA Challenge](https://www.docvqa.org/challenges)：持续榜单：文档视觉问答的经典公开挑战；适合跟踪 OCR、版面理解与答案抽取在真实文档问答上的长期进展。
- [Vision Arena](https://huggingface.co/spaces/WildVision/vision-arena)：持续榜单：开放式图像对话模型的 pairwise battle；适合补充传统准确率榜单之外的人类偏好/开放问答比较。
- [MMMU Leaderboard](https://mmmu-benchmark.github.io/#leaderboard)：官方榜单：多学科多模态理解与 MMMU-Pro；适合跟踪闭源和开源模型在 STEM、人文与专家级图文推理题上的表现。
- [MMStar Leaderboard](https://mmstar-benchmark.github.io/)：官方榜单：vision-indispensable 多模态任务；适合比较模型在感知、推理和 leakage-aware 子能力上的表现。
- [MTVQA Leaderboard](https://bytedance.github.io/MTVQA/)：官方榜单：多语言文本中心视觉问答；适合跟踪跨语言与低资源文字场景中的 OCR-grounded VQA。
- [CharXiv Leaderboard](https://charxiv.github.io/#leaderboard)：官方榜单：科研论文场景中的图表、插图和图文证据对齐理解；适合比较普通 OCR 之外的 evidence alignment 能力。
- [OCRBench v2 Leaderboard](https://www.codesota.com/ocr/benchmark/ocrbench-v2)：持续榜单：围绕 OCRBench v2 聚合 text-rich image、文档、图表和 OCR-to-reasoning 结果；适合快速追踪新 VLM 在“读文字并推理”链路上的位置。
- [EMMA Leaderboard](https://emma-benchmark.github.io/#leaderboard)：官方榜单：跨数学、物理、化学和编码的有机多模态推理；适合跟踪模型能否跨模态串联证据，而不是只回答孤立文本题。
- [PhyX Leaderboard](https://phyx-bench.github.io/)：官方榜单：高保真视觉场景中的物理推理；适合比较模型在文本去冗余和视觉 grounding 物理题协议下的表现。
- [PointArena](https://pointarena.github.io/)：官方 arena 与排名页：pointing 和定位模型；适合用直接空间输出指标比较视觉 grounding 系统。
- [OmniDocBench Leaderboard](https://github.com/opendatalab/OmniDocBench#leaderboard)：持续榜单：文档解析 pipeline 的版面、表格、段落和结构化指标；适合比较 OCR-free/OCR-based parser 与端到端文档模型。
- [IDP Leaderboard](https://idp-leaderboard.org/)：持续榜单：企业文档 AI 模型的 OCR、表格抽取、KIE、VQA、分类与长文档处理；适合作为“文档智能”工程侧综合榜单。
- [OCR Arena](https://www.ocrarena.ai/)：持续榜单：OCR/文档模型的竞技场式比较；适合发现可复用的文档解析、表格抽取和视觉问答模型配置。
- [OpenCompass Open VLM Leaderboard](https://huggingface.co/spaces/opencompass/open_vlm_leaderboard)：广泛使用的 Hugging Face 聚合榜单：覆盖 MMMU、MMStar、OCRBench 等开放 VLM 多模态评测；适合作为需要横向模型排名时的跨 benchmark 入口。
