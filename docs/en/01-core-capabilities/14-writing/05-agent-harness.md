# 1.14.5 Agent Harness

- [Self-Refine](https://arxiv.org/abs/2303.17651) ([code](https://github.com/madaan/self-refine)): A general `generate -> feedback -> revise` loop for writing revision; useful for turning one-shot writing into a reviewable, iterative long-form generation process.
- [Fine-Grained Modeling of Narrative Context: A Coherence Perspective via Retrospective Questions](https://arxiv.org/abs/2402.13551): Builds NarCo, an LLM-instantiated graph of retrospective questions between narrative snippets, so downstream writing and story-QA workflows can retrieve coherence dependencies rather than relying on flat context.
- [Metamorpheus: Interactive, Affective, and Creative Dream Narration Through Metaphorical Visual Storytelling](https://arxiv.org/abs/2403.00632): An affective dream-storytelling interface that orders a dream narrative by emotional arc, suggests metaphors, and generates metaphorical images and text descriptions for user-guided reflection.
- [Towards Full Authorship with AI: Supporting Revision with AI-Generated Views](https://arxiv.org/abs/2403.01055): Supports writing revision through AI-generated views.
- [SARD: A Human-AI Collaborative Story Generation](https://arxiv.org/abs/2403.01575): A drag-and-drop visual interface for multi-chapter story generation, using node-based narrative visualization to help writers steer LLM-generated story structure while exposing usability tradeoffs in mental overhead.
- [LLM-based agents for automating the enhancement of user story quality: An early report](https://arxiv.org/abs/2403.09442): Implements an autonomous LLM-agent reference model inside Austrian Post Group IT to revise agile user stories, then evaluates story-quality improvement with 11 participants across six teams.
- [StoryVerse: Towards Co-authoring Dynamic Plot with LLM-based Character Simulation via Narrative Planning](https://arxiv.org/abs/2405.13042): Supports dynamic plot co-authoring with LLM-based character simulation and narrative planning.
- [HoLLMwood: Unleashing the Creativity of Large Language Models in Screenwriting via Role Playing](https://arxiv.org/abs/2406.11683): Uses role playing to support large-language-model screenwriting workflows.
- [CollabStory: Multi-LLM Collaborative Story Generation and Authorship Analysis](https://arxiv.org/abs/2406.12665): A multi-LLM co-authoring setup and dataset of more than 32,000 stories, extending authorship-analysis tasks to cases where up to five instruction-tuned LLMs jointly write one story.
- [IBSEN: Director-Actor Agent Collaboration for Controllable and Interactive Drama Script Generation](https://arxiv.org/abs/2407.01093): Uses director-actor agent collaboration to support controllable and interactive drama script generation.
- [LLM-based multi-agent poetry generation in non-cooperative environments](https://arxiv.org/abs/2409.03659): A social-learning poetry-generation harness where cooperative and non-cooperative LLM agents interact over many rounds, increasing lexical diversity and novelty in generated poems.
- [ScriptViz: A Visualization Tool to Aid Scriptwriting based on a Large Movie Database](https://arxiv.org/abs/2410.03224): Retrieves reference visuals from a large movie database as writers type scripts, with controls for fixed and uncertain visual elements that were tested with 15 scriptwriters.
- [Usefulness of LLMs as an Author Checklist Assistant for Scientific Papers: NeurIPS'24 Experiment](https://arxiv.org/abs/2411.03417): Deploys an LLM checklist assistant for 234 voluntary NeurIPS 2024 submissions, giving authors standards-compliance feedback while surfacing risks such as excessive strictness and score gaming.
- [Amuse: Human-AI Collaborative Songwriting with Multimodal Inspirations](https://arxiv.org/abs/2412.18940): A songwriting assistant that turns image, text, or audio inspirations into chord suggestions by routing noisy multimodal-LLM outputs through a unimodal chord filter.
- [StoryChat: An Interactive Storytelling System for Engaging with Agent Characters in a Story](https://doi.org/10.1109/iscid63852.2024.00055): An interactive storytelling system where users converse with agent characters inside a story world, turning narrative consumption into character-mediated dialogue.
- [Let storytelling tell vivid stories: A multi-modal-agent-based unified storytelling framework](https://doi.org/10.1016/j.neucom.2024.129316): A multimodal-agent storytelling framework that coordinates narrative text with visual and other modality generation so stories can be produced as richer cross-modal artifacts.
- [OmniThink](https://arxiv.org/abs/2501.09751): A slow-thinking machine-writing framework. Core idea: iteratively expand and reflect on retrieved knowledge so generated long-form articles gain information density without losing coherence.
- [Fuzzy Linkography: Automatic Graphical Summarization of Creative Activity Traces](https://arxiv.org/abs/2502.04599): Automates linkography by building semantic-similarity graphs over recorded design moves, enabling graphical summaries of LLM-supported ideation sessions and other creative traces.
- [MarkerGen](https://arxiv.org/abs/2502.13544): A length-control harness for long-form generation. Core idea: decompose length-controllable generation into sub-abilities, insert dynamic markers for explicit length modeling, and use a three-stage generation scheme to better satisfy length constraints.
- [RAPID](https://arxiv.org/abs/2503.00751): A retrieval-augmented long-text generation harness. Core idea: generate a preliminary outline, use attribute-constrained information discovery, and then write plan-guided articles to improve factual coverage and coherence for knowledge-intensive long texts.
- [Heterogeneous Recursive Planning](https://arxiv.org/abs/2503.08275) (code: no stable public repository found): An adaptive planning harness for long-form writing; core idea: instead of generating a one-shot outline, recursively decompose writing units at different granularities and adjust planning depth during generation as the content requires.
- [LLM MapReduce V2](https://arxiv.org/abs/2504.05732): A test-time scaling harness for long-form article generation from extremely long resources. Core idea: stack MapReduce-style integration layers so local evidence is progressively composed into global article structure before generation.
- [Co-Writing with AI, on Human Terms: Aligning Research with User Demands Across the Writing Process](https://arxiv.org/abs/2504.12488): Synthesizes 109 HCI papers and interviews 15 writers to map AI writing support strategies onto planning, translating, reviewing, and monitoring while preserving agency and ownership.
- [BookWorld](https://arxiv.org/abs/2504.14538): Builds interactive agent societies from novels for creative story generation. Core idea: use character agents, social simulation, and story-world state to extend narrative generation beyond single-pass drafting.
- [EvalAgent: Discovering Implicit Evaluation Criteria from the Web](https://arxiv.org/abs/2504.15219): discovers task-specific implicit evaluation criteria from expert web guidance, improving rubric construction for structured writing evaluation.
- [CAFES: A Collaborative Multi-Agent Framework for Multi-Granular Multimodal Essay Scoring](https://arxiv.org/abs/2505.13965): Agent-harness candidate for writing and text generation: Uses collaborative agents for multi-granular multimodal essay scoring.
- [HiCaM](https://arxiv.org/abs/2505.24319): A hierarchical-causal framework for long-form text modification; core idea: combine a hierarchical summary tree with a causal graph so revisions avoid unrelated passages while still updating implicitly dependent content.
- [NexusSum: Hierarchical LLM Agents for Long-Form Narrative Summarization](https://arxiv.org/abs/2505.24575): Uses hierarchical LLM agents for long-form narrative summarization, separating planning and synthesis across a structured writing workflow.
- [CO-OPERA: A Human-AI Collaborative Playwriting Tool to Support Creative Storytelling for Interdisciplinary Drama Education](https://arxiv.org/abs/2506.00791): A drama-education playwriting tool where users discuss ideas with a tutor, operate agents to generate script elements, and iteratively modify generated plays.
- [STORYTELLER](https://arxiv.org/abs/2506.02347): A plot-planning harness for long story generation. Core idea: represent plot nodes with subject-verb-object triplets and coordinate a dynamic storyline module with a narrative entity knowledge graph to preserve coherence and consistency.
- [A Hybrid Multi-Agent Prompting Approach for Simplifying Complex Sentences](https://arxiv.org/abs/2506.11681): Uses a hybrid multi-agent prompting workflow for sentence simplification and revision.
- [StoryWriter](https://arxiv.org/abs/2506.16445) (code: no stable public repository found): A multi-agent framework for long story generation; core idea: assign character setting, plot planning, chapter writing, and consistency checking to different agents to reduce character drift and plot breaks in long stories.
- [MOG](https://arxiv.org/abs/2506.23393): A hierarchical-memory harness for Wikipedia-style generation; core idea: extract fine-grained memory units, recursively organize them into an article outline, and attach sentence-level citations to improve informativeness and verifiability.
- [PIC](https://doi.org/10.18653/v1/2025.acl-long.347): A plug-in method for longer coherent generation. Core idea: compress position IDs in the context, with NTK-aware and dynamic variants, to extend output length without proportionally degrading long-form generation quality.
- [Constrained Text Revision Agent](https://doi.org/10.18653/v1/2025.findings-acl.1377): An iterative planning-and-search harness for constrained text revision. Core idea: treat revision as a controlled search process so an agent can repair text while preserving explicit content and form constraints.
- [Constella: Supporting Storywriters’ Interconnected Character Creation through LLM-based Multi-Agents](https://arxiv.org/abs/2507.05820): Uses LLM-based multi-agents to help storywriters create interconnected characters through related-character discovery, parallel journals, and inter-character comments.
- [DiaryPlay: AI-Assisted Creation of Interactive Story Vignettes for Everyday Storytelling](https://arxiv.org/abs/2507.11628): Converts a natural-language everyday story into environment, character, and event elements, then uses an LLM narrative planner to create branch-and-bottleneck interactive vignettes.
- [Multi-Agent Synergy-Driven Iterative Visual Narrative Synthesis](https://arxiv.org/abs/2507.13285): Uses structured narrative planning, adaptive layout generation, iterative optimization, and preference evaluation for multi-agent visual presentation synthesis.
- [WiNELL](https://arxiv.org/abs/2508.03728): A multi-agent harness for never-ending Wikipedia updating. Core idea: aggregate online information, select important new knowledge for an entity, and generate human-reviewable edit suggestions for existing articles.
- [Auto-Slides](https://arxiv.org/abs/2509.11062): An interactive multi-agent harness for research presentation creation and customization. Core idea: split slide generation, editing, and user-guided refinement across agent roles so presentation writing becomes an iterative artifact workflow rather than one-shot text generation.
- [Collaborative Document Editing with Multiple Users and AI Agents](https://arxiv.org/abs/2509.11826): Embeds AI agents into shared document editing through visible agent profiles, tasks, and comment-thread responses, then studies 14 teams over one week.
- [ConvergeWriter](https://arxiv.org/abs/2509.12811): A bottom-up harness for grounded long-form article construction; core idea: retrieve exhaustively first, cluster the evidence into knowledge boundaries, and only then generate an outline and article so the final document remains constrained by available sources.
- [AgentCTG: Harnessing Multi-Agent Collaboration for Fine-Grained Precise Control in Text Generation](https://arxiv.org/abs/2509.13677): Contributes an agent workflow, runtime, protocol, tool-use pattern, or multi-agent orchestration approach for writing and summarization.
- [LLM Agents at the Roundtable: A Multi-Perspective and Dialectical Reasoning Framework for Essay Scoring](https://arxiv.org/abs/2509.14834): Introduces Roundtable Essay Scoring, where prompt- and topic-specific evaluator agents draft trait rubrics, score essays, and reach a holistic score through dialectical discussion.
- [Where Do I 'Add the Egg'?: Exploring Agency and Ownership in AI Creative Co-Writing Systems](https://arxiv.org/abs/2509.15440): Compares agentic, tool-like, and magical interface metaphors in three co-writing systems, using writer interviews to derive agency and ownership subtypes for creative writing tools.
- [OPEN-THEATRE: An Open-Source Toolkit for LLM-based Interactive Drama](https://arxiv.org/abs/2509.16713): An open-source toolkit for LLM interactive drama with a configurable pipeline, efficient multi-agent architecture, and hierarchical retrieval-based memory for coherent character behavior.
- [SummQ](https://arxiv.org/abs/2509.20900): A multi-agent long-document summarization harness. Core idea: couple summary generators and reviewers with quiz generators, quiz reviewers, and an examinee agent so summaries are iteratively revised against comprehension questions rather than judged only by one-shot similarity metrics.
- [DraftMarks: Enhancing Transparency in Human-AI Co-Writing Through Interactive Skeuomorphic Process Traces](https://arxiv.org/abs/2509.23505): An augmented reading tool that computes process traces from writer-AI interaction logs and displays them with skeuomorphic marks such as eraser crumbs, tape, and smudges.
- [MemAGent: A Cognitive-Hierarchical Multi-Agent System for Long-Form Story Generation](https://doi.org/10.1109/ICCVIT67848.2025.11391379): A cognitive-hierarchical multi-agent system for long-form story generation, coordinating memory, planning, and drafting roles to reduce plot and character inconsistency.
- [Multi-Agent Based Character Simulation for Story Writing](https://doi.org/10.18653/v1/2025.in2writing-1.9): Uses multi-agent character simulation to support story-writing workflows.
- [Co-DIRECT: A knowledge-augmented multi-agent framework for interactive drama script generation](https://doi.org/10.1016/j.eswa.2025.130571): A Director-in-the-Loop drama-script framework where Writer, Actor, and Critic agents use an ontology-driven knowledge graph of narratological principles to improve coherence, emotional expressiveness, and diversity.
- [SlideCraft: Context-aware Slides Generation Agent](https://doi.org/10.1109/picom68402.2025.00028): A context-aware slide-generation agent that infers the communication setting, selects a template, synthesizes input documents with external knowledge and internal assets, and supports iterative updates through natural-language channels.
- AgRefine ([paper](https://doi.org/10.1109/ICA67499.2025.00023)): A review-guided multi-agent academic-refinement harness with planner, language-expert, and reviewer roles for iterative sentence-level revision.
- [CtrlNews](https://doi.org/10.18653/v1/2025.findings-emnlp.461): A multi-agent workflow for controllable news writing. Core idea: coordinate writing agents with a knowledge-gravitational-field mechanism so topic control and content grounding are managed during generation.
- [RAG-AgentWrite](https://doi.org/10.1109/ISCIPT67144.2025.11265096): A retrieval-grounded extension of AgentWrite for ultra-long generation; core idea: add RAG to each planning and writing step so outputs above 20,000 words have stronger factual grounding, coherence, and depth.
- [SlideBot: A Multi-Agent Framework for Generating Informative, Reliable, Multi-Modal Presentations](https://arxiv.org/abs/2511.09804): A reusable agent harness, runtime, protocol, or workflow scaffold for writing and long-form generation. Core idea: Large Language Models (LLMs) have shown immense potential in education, automating tasks like quiz generation and content summarization.
- [DramaGAT: A Hierarchical Multi-Agent Collaborative Framework for Long-Form Script Generation](https://doi.org/10.1109/icbase66587.2025.11181381): Contributes an agent workflow, runtime, protocol, tool-use pattern, or multi-agent orchestration approach for writing and summarization.
- [Progressive Ideation using an Agentic AI Framework for Human-AI Co-Creation](https://arxiv.org/abs/2601.00475): Presents MIDAS, a distributed team of specialized ideation agents that progressively refine design ideas and score both global and local novelty.
- [MUSE](https://arxiv.org/abs/2602.03028): a multi-agent harness for unconstrained story envisioning. Core idea: use closed-loop cognitive orchestration so planning, generation, and revision roles can coordinate open-ended narrative development.
- [From Crafting Text to Crafting Thought: Grounding AI Writing Support to Writing Center Pedagogy](https://arxiv.org/abs/2602.04047): Grounds an AI feedback prototype, Writor, in writing-center pedagogy so it sets revision goals, gives balanced feedback, and avoids generating replacement prose verbatim.
- [iRULER](https://arxiv.org/abs/2602.12779): A rubric-based revision-evaluation harness. Core idea: turn user-defined criteria into intelligible feedback that can guide writing revision.
- [Multi-Agent Comedy Club: Investigating Community Discussion Effects on LLM Humor Generation](https://arxiv.org/abs/2602.14770): Tests a stand-up-comedy sandbox where critic and audience discussions are filtered into social memory and retrieved for later monologue generation.
- [Meflex: A Multi-agent Scaffolding System for Entrepreneurial Ideation Iteration via Nonlinear Business Plan Writing](https://arxiv.org/abs/2602.15631): Integrates business-plan writing scaffolds with a nonlinear idea canvas, using LLM-supported reflection and meta-reflection to help novice entrepreneurs iterate ideas.
- [StoryComposerAI: Supporting Human-AI Story Co-Creation Through Decomposition and Linking](https://arxiv.org/abs/2602.21486): Implements creative decomposition and linking so writers can edit storylines, personas, locations, and scenes separately while keeping generated visuals coherent.
- [CoLyricist: Enhancing Lyric Writing with AI through Workflow-Aligned Support](https://arxiv.org/abs/2602.22606): Aligns AI lyric-writing assistance with theme setting, ideation, drafting, and melody fitting, based on interviews with 10 experienced lyricists and a 16-person user study.
- [APRES](https://arxiv.org/abs/2603.03142): An agentic paper revision and evaluation system for scientific writing. Core idea: discover citation-predictive rubrics and use them to revise manuscripts while preserving core scientific content, making paper improvement a reviewable workflow.
- [Reactive Writers: How Co-Writing with AI Changes How We Engage with Ideas](https://arxiv.org/abs/2603.10374): Characterizes "reactive writing" from 19 interviews and 1,291 co-writing sessions, showing how evaluation of AI suggestions can replace independent ideation and shape opinions.
- [PaperOrchestra](https://arxiv.org/abs/2604.05018) (code: no stable public repository found): A multi-agent framework for automated AI research paper writing; core idea: decompose paper writing into topic/context analysis, section drafting, cross-review, and overall revision, corresponding to the academic writing tasks in PaperWritingBench.
- [CoAuthorAI: A Human in the Loop System For Scientific Book Writing](https://arxiv.org/abs/2604.19772): A human-in-the-loop scientific book-writing system combining retrieval-augmented generation, expert hierarchical outlines, reference linking, and sentence-level expert refinement.
- [Semantic Prompting: Agentic Incremental Narrative Refinement through Spatial Semantic Interaction](https://arxiv.org/abs/2604.19971): Introduces S-PRISM, which interprets spatial semantic interactions, infers refinement intent, and performs targeted positional revisions for incrementally steered narratives.
- [AeSlides: Incentivizing Aesthetic Layout in LLM-Based Slide Generation via Verifiable Rewards](https://arxiv.org/abs/2604.22840): A harness for verifiable-reward optimization of aesthetic layout in LLM-based slide generation. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [LLM-ReSum](https://arxiv.org/abs/2604.25665): A reflective summarization harness based on self-evaluation. Core idea: identify summary weaknesses through self-assessment and feed them into revision across long-document summarization tasks.
- [Making AI Drafts Count: A Quality Threshold in Audio Description Workflows](https://arxiv.org/abs/2605.05348): Studies GenAD and RefineAD for audio-description writing, showing that guideline- and context-aware drafts reduce time and cognitive load only when draft quality clears a content-dependent threshold.
- [WriteGuard-X: Constraint-Governed LLM Assistance for Ethical Scientific Writing](https://doi.org/10.1109/wccst67302.2026.11496178): Adds a constraint-governed LLM writing-assistance workflow for ethical scientific writing.
- [SYNthia: An Interface Concept for Writing With Large Language Models](https://doi.org/10.1145/3698061.3734401): An interface concept for LLM-assisted writing that emphasizes controllable writer interaction rather than treating generation as a one-shot prompt-response task.
- [Steering Narrative Agents Through a Dynamic Cognitive Framework for Guided Emergent Storytelling](https://doi.org/10.1609/aiide.v21i1.36841): Uses a dynamic cognitive framework to steer narrative agents during emergent storytelling, giving the author a control layer over agent-driven plot development.
- [Intelligent Support Engages Writers Through Relevant Cognitive Processes](https://doi.org/10.1145/3613904.3642549): Studies writing support that prompts relevant cognitive processes instead of only correcting text, making the tool behavior align with how writers plan, monitor, and revise.
- [“Helping Me Versus Doing It for Me”: Designing for Agency in LLM-Infused Writing Tools for Science Journalism](https://doi.org/10.1145/3772318.3790372): Derives agency-centered design guidance for science-journalism writing tools, distinguishing assistance that helps writers reason from automation that takes over authorship.
- [Exploring Creator-Centric Methods for LLM-Assisted Interactive Storytelling](https://doi.org/10.1145/3772318.3791362): Investigates creator-centered methods for LLM-assisted interactive storytelling, focusing on how authors can guide story structure and interaction rather than surrendering control to generation.
- [Generative AI and linguistic diversity in academic writing and publishing](https://doi.org/10.1075/jerpp.00035.ugw): Examines how generative-AI writing assistance intersects with linguistic diversity in academic publishing, a deployment boundary for scholarly writing workflows rather than a new generation model.
- [Story-Driven: Exploring the Impact of Providing Real-time Context Information on Automated Storytelling](https://doi.org/10.1145/3654777.3676372): Tests real-time context information as a control signal for automated storytelling, studying whether live contextual cues improve generated story relevance and continuity.
- [Friction: Deciphering Writing Feedback into Writing Revisions through LLM-Assisted Reflection](https://doi.org/10.1145/3706598.3714316): Turns writing capability into an executable or orchestrated workflow rather than a single prompt.
- [CASTCurate: An Agentic System to Accelerate the Collection and Annotation of Data-Driven Stories](https://doi.org/10.1145/3770761.3777345): Uses an agentic system to collect and annotate data-driven stories.
