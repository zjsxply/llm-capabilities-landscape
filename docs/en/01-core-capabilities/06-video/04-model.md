# 1.6.4 Model

- [CoVR: Learning Composed Video Retrieval from Web Video Captions](https://arxiv.org/abs/2308.14746): Trains composed video retrieval from noisy web captions so queries can modify a reference video with language rather than retrieve by text alone.
- [Retrieval-Augmented Egocentric Video Captioning](https://arxiv.org/abs/2401.00789): Augments egocentric captioning with retrieved visual-language context so first-person video descriptions can use similar past clips and captions.
- [DeepStream: Video Streaming Enhancements Using Compressed Deep Neural Networks](https://doi.org/10.1109/tcsvt.2022.3229079): Compresses deep video-streaming networks so enhancement models can run with lower bandwidth and compute while preserving visual quality.
- [Glance and Focus: Memory Prompting for Multi-Event Video Question Answering](https://arxiv.org/abs/2401.01529): Uses a coarse-to-fine memory prompting strategy that first surveys long videos and then focuses on event-specific evidence for multi-event question answering.
- [VSS-Net: Visual Semantic Self-Mining Network for Video Summarization](https://doi.org/10.1109/tcsvt.2023.3312325): Mines visual semantics inside videos to select summary frames that preserve high-level events instead of relying only on low-level saliency.
- [FMA-Net: Flow-Guided Dynamic Filtering and Iterative Feature Refinement with Multi-Attention for Joint Video Super-Resolution and Deblurring](https://arxiv.org/abs/2401.03707): Combines optical-flow guidance, dynamic filtering, and iterative multi-attention refinement to jointly super-resolve and deblur degraded video frames.
- [Diffusion Priors for Dynamic View Synthesis from Monocular Videos](https://arxiv.org/abs/2401.05583): Uses diffusion priors to regularize monocular dynamic-view synthesis, improving temporal and geometric plausibility when only a single video is available.
- [Cross-Modality and Within-Modality Regularization for Audio-Visual Deepfake Detection](https://arxiv.org/abs/2401.05746): Regularizes both audio-visual consistency and within-modality representations to detect deepfakes whose artifacts may appear in only one stream.
- [Distilling Vision-Language Models on Millions of Videos](https://arxiv.org/abs/2401.06129): Distills large vision-language supervision over millions of videos to make compact video-language models inherit broad temporal and semantic knowledge.
- [Collaboratively Self-Supervised Video Representation Learning for Action Recognition](https://arxiv.org/abs/2401.07584): Learns action-recognition representations through collaborative self-supervision that coordinates complementary temporal cues without dense labels.
- [SRL-CLIP: Efficient CLIP Video Adaptation via Structured Semantic Role Labels](https://arxiv.org/abs/2401.07669): Adapts CLIP to video with structured semantic role labels, injecting actor-action-object structure for efficient video-language recognition.
- [GPT4Ego: Unleashing the Potential of Pre-Trained Models for Zero-Shot Egocentric Action Recognition](https://arxiv.org/abs/2401.10039): Prompts and adapts pretrained multimodal models for zero-shot egocentric action recognition, reducing dependence on first-person action annotations.
- [Towards Language-Driven Video Inpainting via Multimodal Large Language Models](https://arxiv.org/abs/2401.10226): Uses a multimodal LLM to interpret language editing requests and guide video inpainting over the intended objects, regions, and temporal spans.
- [M2-CLIP: A Multimodal, Multi-task Adapting Framework for Video Action Recognition](https://arxiv.org/abs/2401.11649): Adapts CLIP with multimodal and multi-task signals so a shared representation can handle video action recognition across varied settings.
- [Diffusion Facial Forgery Detection](https://arxiv.org/abs/2401.15859): Trains a detector for diffusion-generated facial forgeries by targeting artifacts introduced by diffusion-based synthesis pipelines.
- [MoE-LLaVA: Mixture of Experts for Large Vision-Language Models](https://arxiv.org/abs/2401.15947): Adds mixture-of-experts routing to LLaVA-style vision-language models so specialized experts can cover different multimodal inputs more efficiently.
- [Synchformer: Efficient Synchronization From Sparse Cues](https://arxiv.org/abs/2401.16423): Learns audio-visual synchronization from sparse temporal cues, enabling efficient alignment of events across video and sound.
- [SNP-S3: Shared Network Pre-Training and Significant Semantic Strengthening for Various Video-Text Tasks](https://arxiv.org/abs/2401.17773): Pretrains a shared video-text network and strengthens semantic alignment so one backbone transfers across retrieval, captioning, and related tasks.
- [M2-RAAP: A Multi-Modal Recipe for Advancing Adaptation-based Pre-training towards Effective and Efficient Zero-shot Video-text Retrieval](https://arxiv.org/abs/2401.17797): Combines multimodal adaptation and pretraining recipes to make zero-shot video-text retrieval more effective without full task-specific retraining.
- [Taylor Videos for Action Recognition](https://arxiv.org/abs/2402.03019): Represents video dynamics with Taylor-style temporal approximations to improve action recognition from motion evolution rather than isolated frames.
- [Video-LaVIT: Unified Video-Language Pre-training with Decoupled Visual-Motional Tokenization](https://arxiv.org/abs/2402.03161): Separates visual appearance tokens from motional tokens in unified video-language pretraining, giving the model explicit access to temporal change.
- [Tuning Large Multimodal Models for Videos using Reinforcement Learning from AI Feedback](https://arxiv.org/abs/2402.03746): Applies reinforcement learning from AI feedback to tune multimodal models for video, aligning answers with temporal evidence and preference signals.
- [Memory Consolidation Enables Long-Context Video Understanding](https://arxiv.org/abs/2402.05861): Consolidates video memories across context windows so models can retain salient events for long-context video understanding.
- [World Model on Million-Length Video And Language With Blockwise RingAttention](https://arxiv.org/abs/2402.08268): Uses blockwise RingAttention to train a video-language world model over million-token sequences, targeting extremely long temporal dependencies.
- [Momentor: Advancing Video Large Language Model with Fine-Grained Temporal Reasoning](https://arxiv.org/abs/2402.11435): Improves Video LLM temporal reasoning by modeling fine-grained moments and their relations instead of summarizing videos into coarse global features.
- [OLViT: Multi-Modal State Tracking via Attention-Based Embeddings for Video-Grounded Dialog](https://arxiv.org/abs/2402.13146): Tracks multimodal dialogue state with attention-based video embeddings so grounded responses can follow changing objects and events over time.
- [LLMs Meet Long Video: Advancing Long Video Comprehension with An Interactive Visual Adapter in LLMs](https://arxiv.org/abs/2402.13546): Inserts an interactive visual adapter into an LLM so long-video evidence can be queried and compressed during comprehension.
- [Place Anything into Any Video](https://arxiv.org/abs/2402.14316): Enables object insertion into arbitrary videos by matching placement, appearance, and temporal consistency across edited frames.
- [Learning an Actionable Discrete Diffusion Policy via Large-Scale Actionless Video Pre-Training](https://arxiv.org/abs/2402.14407): Pretrains a discrete diffusion policy from actionless videos so robot-like action predictions can emerge from observed visual dynamics.
- [Sora Generates Videos with Stunning Geometrical Consistency](https://arxiv.org/abs/2402.17403): Analyzes Sora outputs as evidence that large video generators can learn persistent geometry, camera motion, and object consistency from scale.
- [VideoMAC: Video Masked Autoencoders Meet ConvNets](https://arxiv.org/abs/2402.19082): Combines masked autoencoding with convolutional video backbones to learn temporally aware representations for video understanding.
- [OVEL: Large Language Model as Memory Manager for Online Video Entity Linking](https://arxiv.org/abs/2403.01411): Uses an LLM as an online memory manager that maintains entity hypotheses and context while linking entities across streaming video.
- [DreamFrame: Enhancing Video Understanding via Automatically Generated QA and Style-Consistent Keyframes](https://arxiv.org/abs/2403.01422): Generates question-answer supervision and style-consistent keyframes to strengthen video understanding models without manual dense annotation.
- [Exposing the Deception: Uncovering More Forgery Clues for Deepfake Detection](https://arxiv.org/abs/2403.01786): Expands deepfake detection beyond obvious artifacts by mining additional forgery cues across facial appearance and temporal behavior.
- [Exploiting Style Latent Flows for Generalizing Deepfake Video Detection](https://arxiv.org/abs/2403.06592): Models flows in style latent space to improve deepfake video detection when test manipulations differ from training forgeries.
- [WorldGPT: A Sora-Inspired Video AI Agent as Rich World Models from Text and Image Inputs](https://arxiv.org/abs/2403.07944): Builds a text-and-image-conditioned video world model that generates rich simulated scenes in the style of large video generators.
- [Dam: Dynamic Adapter Merging for Continual Video QA Learning](https://arxiv.org/abs/2403.08755): Merges adapters dynamically during continual Video QA learning so new tasks can be absorbed while limiting forgetting of earlier skills.
- [MIM4D: Masked Modeling with Multi-View Video for Autonomous Driving Representation Learning](https://arxiv.org/abs/2403.08760): Uses masked modeling over multi-view driving videos to learn 4D spatiotemporal representations for autonomous-driving perception.
- [MM1: Methods, Analysis & Insights from Multimodal LLM Pre-training](https://arxiv.org/abs/2403.09611): Studies multimodal LLM pretraining choices across data mixture, architecture, and resolution, including how video-like visual signals affect model capability.

- [VideoAgent: Long-form Video Understanding with Large Language Model as Agent](https://arxiv.org/abs/2403.10517): Uses an LLM-driven agent to decompose long-form video understanding into searchable temporal evidence and reasoning steps.
- [Towards Neuro-Symbolic Video Understanding](https://arxiv.org/abs/2403.11021): Combines neural video perception with symbolic structure so video understanding can reason over events, relations, and compositional semantics.
- [LocalStyleFool: Regional Video Style Transfer Attack Using Segment Anything Model](https://arxiv.org/abs/2403.11656): Attacks video models by applying SAM-guided regional style transfer, exposing sensitivity to localized style shifts across frames.
- [Contextual AD Narration with Interleaved Multimodal Sequence](https://arxiv.org/abs/2403.12922): Generates contextual audio-description narration from interleaved multimodal sequences so video accessibility descriptions reflect both visual content and temporal context.
- [HyperLLaVA: Dynamic Visual and Language Expert Tuning for Multimodal Large Language Models](https://arxiv.org/abs/2403.13447): Tunes dynamic visual and language experts inside a LLaVA-style model so inference can specialize to each multimodal input.
- [Language Repository for Long Video Understanding](https://arxiv.org/abs/2403.14622): Builds a language-based memory repository for long videos, letting models retrieve event descriptions instead of reprocessing all frames.
- [StreamingT2V: Consistent, Dynamic, and Extendable Long Video Generation from Text](https://arxiv.org/abs/2403.14773): Generates long text-to-video outputs in a streaming manner, extending scenes while preserving motion continuity and content consistency.

- [AVicuna: Audio-Visual LLM with Interleaver and Context-Boundary Alignment for Temporal Referential Dialogue](https://arxiv.org/abs/2403.16276): Adds audio-visual interleaving and context-boundary alignment so an LLM can resolve temporal references in video-grounded dialogue.
- [AI-Generated Video Detection via Spatio-Temporal Anomaly Learning](https://arxiv.org/abs/2403.16638): Detects AI-generated videos by learning spatiotemporal anomalies that distinguish synthesized motion and appearance from real footage.
- [Understanding Long Videos with Multimodal Language Models](https://arxiv.org/abs/2403.16998): Studies how multimodal language models process long videos and adapts temporal sampling and context handling for long-form comprehension.
- [OmniViD: A Generative Framework for Universal Video Understanding](https://arxiv.org/abs/2403.17935): Unifies video recognition, captioning, QA, dense captioning, temporal localization, and tracking as video-grounded token generation with language labels plus time and box tokens in one encoder-decoder model.
- [An Image Grid Can Be Worth a Video: Zero-Shot Video Question Answering Using a VLM](https://arxiv.org/abs/2403.18406): Converts sampled video frames into an image grid so image-based VLMs can answer video questions in a zero-shot setting.

- [Collaborative Learning of Anomalies with Privacy (CLAP) for Unsupervised Video Anomaly Detection: A New Baseline](https://arxiv.org/abs/2404.00847): Introduces privacy-aware collaborative learning for unsupervised video anomaly detection, sharing anomaly knowledge without centralizing sensitive footage.
