# 1.16.3 Bench

- [Matching-Based Capture-the-Flag Games for Multiagent Systems](https://doi.org/10.1109/tcds.2023.3323572): Uses capture-the-flag games with matching-based agent assignment to study how multiagent teams allocate attackers and defenders under competitive pressure.
- [TimeArena: Shaping Efficient Multitasking Language Agents in a Time-Aware Simulation](https://arxiv.org/abs/2402.05733): Uses a time-aware simulation to test whether language agents can schedule concurrent tasks, trade off deadlines and rewards, and improve multitasking policies through time-pressure feedback.
- [LLMArena: Assessing Capabilities of Large Language Models in Dynamic Multi-Agent Environments](https://arxiv.org/abs/2402.16499): Places LLM agents in dynamic multi-agent environments so decision quality is measured against changing peers, opponents, and interaction state.
- [Towards Personalized Evaluation of Large Language Models with An Anonymous Crowd-Sourcing Platform](https://arxiv.org/abs/2403.08305): Appears off-axis for Agent Swarm because its main artifact is anonymous crowd-sourced personalization evaluation for LLMs, not multi-agent coordination; kept for now pending a safe move.
- [How Far Are We on the Decision-Making of LLMs? Evaluating LLMs' Gaming Ability in Multi-Agent Environments](https://arxiv.org/abs/2403.11807) ([leaderboard: GAMA-Bench](https://cuhk-arise.github.io/GAMABench/)): Introduces GAMA-Bench, a suite of multi-agent games that measure LLM decision making under interactive competition, cooperation, and changing opponent behavior.
- [SocialBench: Sociality Evaluation of Role-Playing Conversational Agents](https://arxiv.org/abs/2403.13679): Evaluates role-playing conversational agents on sociality, including whether persona behavior supports believable multi-turn social interaction rather than only factual role imitation.
- [Seal-Tools: Self-Instruct Tool Learning Dataset for Agent Tuning and Detailed Benchmark](https://arxiv.org/abs/2405.08355): Is primarily a tool-learning dataset and benchmark for agent tuning; its fit is tool use rather than agent swarms, so it is retained only as a move candidate.
- [Evaluating the Performance of Large Language Models via Debates](https://arxiv.org/abs/2406.11044): Measures whether debate-style exchanges between LLM instances improve answer quality, making inter-agent argumentation the evaluated protocol.
- [Evaluating Visual and Cultural Interpretation: The K-Viscuit Benchmark with Human-VLM Collaboration](https://arxiv.org/abs/2406.16469): Appears closer to multimodal cultural interpretation and human-VLM collaboration than to swarm coordination; kept as an off-axis candidate until a safe paired move is made.
- [POGEMA: A Benchmark Platform for Cooperative Multi-Agent Navigation](https://arxiv.org/abs/2407.14931): Provides a grid-based cooperative navigation platform for multi-agent pathfinding, with scenario generation and evaluation support for coordination policies.
- [MMAU: A Holistic Benchmark of Agent Capabilities Across Diverse Domains](https://arxiv.org/abs/2407.18961): Evaluates agent capabilities across diverse domains with a holistic protocol, making cross-domain planning, tool use, and interaction skills comparable in one benchmark.
- [The Fellowship of the LLMs: Multi-Agent Workflows for Synthetic Preference Optimization Dataset Generation](https://arxiv.org/abs/2408.08688): Uses multi-agent LLM workflows to generate synthetic preference-optimization data, making it a harness or data-generation candidate rather than a pure benchmark.
- [MuMA-ToM: Multi-modal Multi-Agent Theory of Mind](https://arxiv.org/abs/2408.12574) ([leaderboard](https://scai.cs.jhu.edu/projects/MuMA-ToM/leaderboard.html)): Tests whether models can infer other agents' beliefs, goals, and perspectives from multimodal scenes rather than only answer from their own viewpoint.
- [Collaboration Dynamics and Reliability Challenges of Multi-Agent LLM Systems in Finite Element Analysis](https://arxiv.org/abs/2408.13406): Empirically studies role-based LLM teams on finite-element-analysis work, tracking collaboration dynamics, reliability failures, and error propagation across agents.
- [BattleAgentBench: A Benchmark for Evaluating Cooperation and Competition Capabilities of Language Models in Multi-Agent Systems](https://arxiv.org/abs/2408.15971): Evaluates LLM agents in battle-style multi-agent scenarios where cooperation, competition, communication, and strategic adaptation are all observable.
- [PersoBench: Benchmarking Personalized Response Generation in Large Language Models](https://arxiv.org/abs/2410.03198): Benchmarks personalized response generation from user profiles and histories; it is likely better placed under personalization or memory than Agent Swarm.
- [COMMA: A Communicative Multimodal Multi-Agent Benchmark](https://arxiv.org/abs/2410.07553): Tests multimodal multi-agent communication, requiring agents to exchange visual and language information rather than solve tasks from isolated observations.
- [AgentSense: Benchmarking Social Intelligence of Language Agents through Interactive Scenarios](https://arxiv.org/abs/2410.19346): Uses interactive social scenarios to test whether language agents infer social context, choose appropriate actions, and explain behavior in agent-like settings.
- [BENCHAGENTS: Automated Benchmark Creation with Agent Interaction](https://arxiv.org/abs/2410.22584): Automates benchmark construction through agent interaction, using LLM agents to generate, refine, and validate task instances instead of relying on a static human-written test set.
- [Towards Effective GenAI Multi-Agent Collaboration: Design and Evaluation for Enterprise Applications](https://arxiv.org/abs/2412.05449): Designs and evaluates enterprise multi-agent collaboration patterns, with role assignment, task handoff, and workflow effectiveness as the main organizational variables.
- [LegalAgentBench: Evaluating LLM Agents in Legal Domain](https://arxiv.org/abs/2412.17259): Evaluates legal-domain LLM agents on tasks that require retrieval, reasoning, and action planning over legal materials, making it more domain-agent than swarm-specific.
- [BaiJia: A Large Scale Role-Playing Agent Corpus of Chinese Historical Charcaters](https://arxiv.org/abs/2412.20024): Releases a large Chinese historical-character role-playing corpus, making persona knowledge, character style, and social dialogue consistency measurable for role-playing agents.
- [Efficient Multi-Agent Collaboration with Tool Use for Online Planning in Complex Table Question Answering](https://arxiv.org/abs/2412.20145): Tests a tool-using multi-agent planner for complex table question answering, where agents coordinate decomposition and online tool calls over structured data.
- [From Clicks to Conversations: Evaluating the Effectiveness of Conversational Agents in Statistical Analysis](https://arxiv.org/abs/2502.08114): Evaluates conversational agents for statistical analysis workflows, comparing dialogue-based assistance with conventional click-driven analysis interfaces.
- [YRC-Bench: A Benchmark for Learning to Coordinate with Experts](https://arxiv.org/abs/2502.09583): Measures whether an agent can coordinate with expert collaborators by learning when to ask, defer, or act across tasks with specialized partner knowledge.
- [MultiMind: Enhancing Werewolf Agents with Multimodal Reasoning and Theory of Mind](https://arxiv.org/abs/2504.18039): Extends Werewolf agents with multimodal reasoning and theory-of-mind signals, using the social-deduction game to expose deception, belief tracking, and team inference.
- [Evaluating Contrastive Feedback for Effective User Simulations](https://arxiv.org/abs/2505.02560): Studies contrastive feedback for user simulators, making simulated user behavior and correction signals the evaluated artifact rather than swarm coordination itself.
- [Interactional Fairness in LLM Multi-Agent Systems: An Evaluation Framework](https://arxiv.org/abs/2505.12001): Defines metrics for fairness across turns and participants in LLM multi-agent interactions, separating interactional treatment from final task success.
- [Exploring the Potential of LLMs as Personalized Assistants: Dataset, Evaluation, and Analysis](https://arxiv.org/abs/2506.01262): Provides data and evaluation for personalized assistant behavior; it appears adjacent to memory or personalization rather than multi-agent swarm evaluation.
- [MultiAgentBench](https://aclanthology.org/2025.acl-long.421/): Evaluates collaboration and competition among LLM agents. Core idea: measure agent teams rather than isolated single agents, making interaction protocol, role design, and outcome trade-offs explicit benchmark variables.
- [CORE: Measuring Multi-Agent LLM Interaction Quality under Game-Theoretic Pressures](https://arxiv.org/abs/2508.11915): Measures interaction quality under game-theoretic pressure, using cooperation and conflict incentives to expose how multi-agent LLM conversations coordinate or break down.
- [Benchmarking Agentic Systems in Automated Scientific Information Extraction with ChemX](https://arxiv.org/abs/2510.00795): Uses ChemX to evaluate agentic scientific information extraction, where systems must coordinate document parsing, evidence retrieval, and structured chemistry extraction.
- [Emergent Coordination in Multi-Agent Language Models](https://arxiv.org/abs/2510.05174): Provides information-theoretic criteria for detecting higher-order structure and synergy in multi-agent LLM systems.
- [ProMediate: A Socio-cognitive framework for evaluating proactive agents in multi-party negotiation](https://arxiv.org/abs/2510.25224): Evaluates proactive AI mediator agents in multi-topic, multi-party negotiation. Core idea: combine theory-grounded negotiation simulations with metrics for consensus change, intervention timing, and mediator effectiveness so social coordination is evaluated beyond final agreement.
- [The Limits of Obliviate: Evaluating Unlearning in LLMs via Stimulus-Knowledge Entanglement-Behavior Framework](https://arxiv.org/abs/2510.25732): Is off-axis for Agent Swarm because it evaluates LLM unlearning through stimulus, knowledge, and behavior entanglement rather than multi-agent interaction.
- [Multi-Agent Craftax: Benchmarking Open-Ended Multi-Agent Reinforcement Learning at the Hyperscale](https://arxiv.org/abs/2511.04904): Extends Craftax into a hyperscale open-ended multi-agent reinforcement-learning benchmark for coordination, exploration, and emergent team behavior.
- [Task-Specific Trust Evaluation for Multi-Hop Collaborator Selection via GNN-Aided Distributed Agentic AI](https://arxiv.org/abs/2512.05788): Evaluates collaborator selection by estimating task-specific trust over multi-hop agent networks with GNN support, making routing quality depend on collaborator reliability rather than static agent labels.
- [MLLMs Construction Company: Investigating Multimodal LLMs' Communicative Skills in a Collaborative Building Task](https://aclanthology.org/2025.clicit-1.97/): Evaluates multimodal LLM communication in a collaborative building task, where agents must exchange spatial and visual information to construct a shared artifact.
- [When Identity Overrides Incentives: Representational Choices as Governance Decisions in Multi-Agent LLM Systems](https://arxiv.org/abs/2601.10102): Tests how role personas and payoff visibility change equilibrium behavior in four-agent LLM strategic games.
- [More at Stake: How Payoff and Language Shape LLM Agent Strategies in Cooperation Dilemmas](https://arxiv.org/abs/2601.19082): Tests how payoff size and prompt language change LLM-agent strategies in cooperation dilemmas, making incentive framing a measurable social-behavior variable.
- [Auditing Multi-Agent Reasoning Trees](https://arxiv.org/abs/2602.09341): Audits evidential structure in multi-agent reasoning traces. Core idea: replace majority vote or generic LLM-as-judge aggregation with localized verification over agreements and divergences inside an agent swarm.
- [This human study did not involve human subjects: Validating LLM simulations as behavioral evidence](https://arxiv.org/abs/2602.15785): Validates when LLM-based simulations can stand in for behavioral evidence, an adjacent methodology item for agent-society experiments rather than a swarm benchmark.
- [Guiding LLM-Based Human Mobility Simulation with Mobility Measures from Shared Data](https://arxiv.org/abs/2602.16726): Guides LLM-based mobility simulations with aggregate mobility measures from shared data, evaluating whether simulated agents reproduce population movement patterns.
- [A Benchmark and Knowledge-Grounded Framework for Advanced Multimodal Personalization Study](https://arxiv.org/abs/2602.19001): Builds a knowledge-grounded benchmark for multimodal personalization, making it a personalization or memory candidate rather than an agent-swarm benchmark.
- [@GrokSet: multi-party Human-LLM Interactions in Social Media](https://arxiv.org/abs/2602.21236): Curates multi-party Human-LLM social-media interactions so researchers can study conversational roles, reply chains, and group dynamics around LLM participants.
- [Framing Effects in Independent-Agent Large Language Models: A Cross-Family Behavioral Analysis](https://arxiv.org/abs/2603.19282): Compares how framing changes behavior across independent LLM agent families, exposing sensitivity of agent-society simulations to prompt representation.
- [Deception and Communication in Autonomous Multi-Agent Systems: An Experimental Study with Among Us](https://arxiv.org/abs/2603.26635): Uses Among Us as an experimental environment for autonomous agents, measuring deception, communication, and suspicion management in hidden-role play.
- [Communicate-Predict-Act: Evaluating Social Intelligence of Agents](https://arxiv.org/abs/2604.08727): Evaluates social intelligence through a communicate, predict, and act loop where agents must exchange messages, anticipate others, and choose coordinated actions.
- [Imperfectly Cooperative Human-AI Interactions: Comparing the Impacts of Human and AI Attributes in Simulated and User Studies](https://arxiv.org/abs/2604.15607): Compares simulated and user-study evidence for imperfect cooperation, varying human and AI attributes to see how mixed teams coordinate.
- [Cooperate to Compete / C2C](https://arxiv.org/abs/2604.25088): Provides a mixed-motive multi-agent negotiation game with private deals, asymmetric objectives, and human-versus-agent studies, making alliance formation and betrayal measurable beyond final win rate.
- [Talk is Cheap, Communication is Hard](https://arxiv.org/abs/2605.01750): Studies dynamic grounding failures and repair in multi-agent negotiation. Core idea: make communication breakdown and recovery observable as swarm-level evaluation signals rather than only final deal outcomes.
- [Agent Island](https://arxiv.org/abs/2605.04312): A dynamic multi-agent game benchmark designed to resist saturation and contamination. Core idea: rank agents through adaptive multiplayer cooperation, conflict, and persuasion with Bayesian Plackett-Luce skill estimates rather than a fixed static task set.
- [TeamBench: Evaluating Agent Coordination under Enforced Role Separation](https://arxiv.org/abs/2605.07073): Evaluates agent coordination under enforced role separation so team success cannot hide one role doing another role's work.
- [Unsolvability Ceiling in Multi-LLM Routing: An Empirical Study of Evaluation Artifacts](https://arxiv.org/abs/2605.07395): Audits multi-LLM routing evaluations for unsolvable cases and artifacts, showing when router scores reflect benchmark construction rather than collaborator selection quality.
- [DESBench](https://arxiv.org/abs/2605.13172): Evaluates hierarchical multi-agent coordination in event-driven industrial scheduling. Core idea: use a shared discrete-event environment with partial observability, coupled constraints, and multi-timescale decisions to test when hierarchical swarm coordination helps or hurts.
- [SAGE / Social Agent Group Evolution](https://arxiv.org/abs/2606.03544): Evaluates whether shared peer experience improves self-evolving agents beyond isolated self-improvement. Core idea: compare compute-matched SocialEvo and SelfEvo conditions across ML research, economic planning, and multiplayer play to reveal when group history helps plateaued agents.
- [Mosaic](https://doi.org/10.1145/3772363.3798830): Provides a multi-level framework for observing and evaluating multi-agent system performance. Core idea: structure evaluation across system, agent, and interaction levels so swarm behavior is not reduced to a single final outcome score.
- [Werewolf Communication-Game Evaluation](https://doi.org/10.1145/3723498.3723702): Evaluates LLMs through a Werewolf-style communication game in Unity, testing multi-agent social reasoning and deception handling.
- [Solving Multi-agent Path Finding as an LLM Benchmark: How, How Good and Why](https://openreview.net/forum?id=gyFT8TQLy1) ([task leaderboard: MAPF Arena](https://mapf.dev/leaderboard)): Frames multi-agent path finding as an LLM benchmark, using MAPF instances to test route planning, conflict avoidance, and coordination explanations.
- [RoleAgent: Building, Interacting, and Benchmarking High-quality Role-Playing Agents from Scripts](https://doi.org/10.52202/079017-1563): Builds role-playing agents from scripts and evaluates them with RoleAgentBench, covering character knowledge, style consistency, and interactive persona behavior.
- [LEMSS: LLM-Based Platform for Multi-Agent Competitive Search Simulation](https://doi.org/10.1145/3726302.3730312): Provides an LLM-based competitive search simulation platform where multiple agents search, compete, and adapt strategies in a shared environment.
- [Exploring the Effects of Third-Party Explanations in Multi-Agent Settings After an AI Refusal](https://doi.org/10.1145/3772363.3798502): Evaluates third-party explanations after AI refusals in multi-agent settings.
- [alem](https://arxiv.org/abs/2606.08340): Benchmarks open-ended multi-agent coordination in procedurally generated JAX worlds where communication, specialization, and long-horizon survival replace fixed scripted collaboration tasks.
- [PerspectiveGap](https://arxiv.org/abs/2606.08878): Evaluates multi-agent orchestration prompting with 110 scenarios, role-fragment assignment and free-form prompt-writing formats, and ten topology patterns for composing agent teams.
- [CoffeeBench](https://arxiv.org/abs/2606.16613): Simulates 90 days of heterogeneous firm economies to evaluate LLM agents on communication, negotiation, trading, and long-term profit management across multi-agent market interactions.
