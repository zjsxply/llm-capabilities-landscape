# 1.13.6 Skill

- [Skill Discovery for Software Scripting Automation via Offline Simulations with LLMs](https://arxiv.org/abs/2504.20406): Skill candidate for skill use. Core idea: Skill Discovery for Software Scripting Automation via Offline Simulations with LLMs.
- [Capability-Driven Skill Generation with LLMs: A RAG-Based Approach for Reusing Existing Libraries and Interfaces](https://arxiv.org/abs/2505.03295): Proposes generating agent skills by retrieving relevant libraries and interfaces from a capability description, then turning them into reusable skill wrappers rather than hand-writing every tool recipe.
- [ToolLibGen: Scalable Automatic Tool Creation and Aggregation for LLM Reasoning](https://arxiv.org/abs/2510.07768): Automatically creates and aggregates tool libraries for LLM reasoning.
- [SkillWrapper](https://arxiv.org/abs/2511.18203): A skill-abstraction mechanism for task-level planning. Core idea: wrap individual skill executions into invented predicates so long-horizon planners can reason over reusable capability units.
- [SkillFortify](https://arxiv.org/abs/2603.00195): A formal-analysis framework for agentic skill supply chains. Core idea: model malicious skills across the skill lifecycle, combine static analysis with capability sandboxing and audit evidence, and give skill ecosystems stronger guarantees than heuristic scanning alone.
- [SkillNet](http://skillnet.openkg.cn) (paper: [SkillNet](https://arxiv.org/abs/2603.04448); [code](https://github.com/zjunlp/SkillNet)) is closer to skill registry / ontology / marketplace infrastructure, covering skill creation, evaluation, connection, and retrieval.
- [Knowledge Activation](https://arxiv.org/abs/2603.14805): A skill design framework for institutional knowledge in agentic software development. Core idea: package procedures, policies, deployment playbooks, and decisions as governance-aware agent-consumable skill units.
- [EffiSkill: Agent Skill Based Automated Code Efficiency Optimization](https://arxiv.org/abs/2603.27850): Skill candidate for skill use. Core idea: Agent Skill Based Automated Code Efficiency Optimization.
- [Skill Supply-Chain Poisoning](https://arxiv.org/abs/2604.03081): Studies poisoning attacks against coding-agent skill ecosystems. Core idea: treat third-party skills as supply-chain dependencies whose trusted reuse can silently alter agent behavior.
- [SkillAttack](https://arxiv.org/abs/2604.04989): An automated red-teaming framework for agent skills. Core idea: iteratively refine attack paths against skill packages so audits cover multi-step misuse rather than isolated prompt strings.
- [SkillSieve](https://arxiv.org/abs/2604.06550): A hierarchical triage framework for detecting malicious AI-agent skills. Core idea: combine fast static checks, focused LLM sub-analyses, and deeper review only for suspicious skill packages so skill marketplaces can screen both code and natural-language `SKILL.md` attack surfaces.

This thread is currently more mature around `benchmark + retrieval/orchestration/runtime + registry` than around a single skill dedicated to skill use.
For engineering practice, it is more useful to revisit the creator / validator / reviewer paths in `0.3 Skill Creator`; they determine whether skills are discoverable, installable, and composable.
- [BadSkill](https://arxiv.org/abs/2604.09378): Studies model-in-skill poisoning as a backdoor threat to agent skills. Core idea: hide malicious behavior inside a bundled model artifact so a skill appears benign until semantic triggers activate it.
- [Reasoning Skills](https://arxiv.org/abs/2604.21764): A reusable reasoning-skill layer for token-efficient inference. Core idea: distill long deliberation traces into retrievable skills that guide future coding and math reasoning without restarting from scratch.
- [KG-First, LLM-Fallback: A Hybrid Microservice for Grounded Skill Search and Explanation](https://arxiv.org/abs/2605.01582): Adds reusable skill-search, skill-explanation, or skill-runtime infrastructure for skill use, skill search, and reusable skill infrastructure.
- [Experience-RAG Skill](https://arxiv.org/abs/2605.03989): A pluggable skill for experience-driven retrieval orchestration. Core idea: choose retrieval strategies from prior experience for factoid, multi-hop, and scientific verification tasks.
- [Proteus](https://arxiv.org/abs/2605.11891): A self-evolving red team for agent skill ecosystems. Core idea: measure adaptive leakage by repeatedly rewriting skills through an audit-sandbox-oracle loop until harmful runtime behavior is found or blocked.
- [HarnessAPI](https://arxiv.org/abs/2605.22733): A skill-first runtime framework for unifying streaming APIs and MCP tools. Core idea: treat a typed skill folder as the single source of truth, then derive SSE HTTP endpoints, OpenAPI UI, and MCP tools from that artifact.
- [SkillDAG: Self-Evolving Typed Skill Graphs for LLM Skill Selection at Scale](https://arxiv.org/abs/2606.03056): Models skill libraries as typed directed graphs where skills can depend on, conflict with, specialize, or duplicate one another, then exposes graph-neighbor retrieval and propose-then-commit updates as an agent-callable skill-selection interface.
- [SkillAxe](https://arxiv.org/abs/2606.10546): Refines LLM-authored agent skills through evaluation-guided self-refinement. Core idea: diagnose quality impact, trigger precision, instruction compliance, and solution-path coverage without supervision, then improve pass rates on SkillsBench and SpreadsheetBench.
