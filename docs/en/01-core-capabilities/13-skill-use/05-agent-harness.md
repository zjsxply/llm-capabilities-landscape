# 1.13.5 Agent Harness

- [On the (In)Security of LLM App Stores](https://arxiv.org/abs/2407.08422): Adds reusable orchestration, prompting, planning, tool-use, memory, or environment-management logic for skill use.
- [Agent Skill Acquisition for Large Language Models via CycleQD](https://arxiv.org/abs/2410.14735): Adds a agent-harness entry for skill, centered on agent skill acquisition or skill-use contribution.
- [LLM Agents Making Agent Tools](https://arxiv.org/abs/2502.11705): Studies agents that create tools for later agent use; core idea: move from one-off tool calls toward reusable tool artifacts that can be selected, invoked, and improved across tasks.
- [SkillFlow](https://arxiv.org/abs/2504.06188): A multi-stage agent skill retrieval pipeline; core idea: model skill acquisition as information retrieval by chaining dense retrieval, cross-encoder reranking, and LLM selection over about 36K community `SKILL.md` definitions.
- [SkillWeaver: Web Agents can Self-Improve by Discovering and Honing Skills](https://arxiv.org/abs/2504.07079): A harness for web-agent self-improvement through discovered and honed skills. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [Rethinking Agent Design: From Top-Down Workflows to Bottom-Up Skill Evolution](https://arxiv.org/abs/2505.17673): Skill-evolution harness: bottom-up skill evolution for agent design. Core idea: shift agent design from hand-written workflows to learned reusable skills.
- [COALESCE](https://arxiv.org/abs/2506.01900): Studies economic and security dynamics of skill-based task outsourcing among teams of autonomous LLM agents. Core idea: model skill delegation as a market-like coordination problem where agents choose whether to outsource capabilities while managing cost, trust, and adversarial risk.
- [Automated Skill Discovery for Language Agents through Exploration and Iterative Feedback](https://arxiv.org/abs/2506.04287): Discovers agent skills through environment exploration and iterative feedback rather than manual trajectory collection.
- [MetaAgent: Toward Self-Evolving Agent via Tool Meta-Learning](https://arxiv.org/abs/2508.00271): Generates help requests and learns new tool-like expertise when the agent encounters capability gaps.
- [HERAKLES: Hierarchical Skill Compilation for Open-ended LLM Agents](https://arxiv.org/abs/2508.14751): Compiles hierarchical skills for open-ended LLM agents. Core idea: organize reusable skills into higher-level structures so agents can compose capabilities for open-ended tasks.
- [Empowering LLMs with Parameterized Skills for Adversarial Long-Horizon Planning](https://arxiv.org/abs/2509.13127): A skill-use harness for adversarial environments. Core idea: represent reusable high-level behaviors as parameterized skills, then ground them into long-horizon plans under hostile or changing conditions.
- [Metacognitive Reuse: Turning Recurring LLM Reasoning Into Concise Behaviors](https://arxiv.org/abs/2509.13237): Adds an external orchestration or execution framework for agent skill use and reusable behaviors.
- [ARM: Discovering Agentic Reasoning Modules for Generalizable Multi-Agent Systems](https://arxiv.org/abs/2510.05746): Reasoning-module discovery harness: agentic reasoning modules for generalizable multi-agent systems. Core idea: discover reusable modules that can be composed across tasks.
- [ALLOY: Generating Reusable Agent Workflows from User Demonstration](https://arxiv.org/abs/2510.10049): Generates reusable agent workflows from user demonstrations. Core idea: distill demonstrated procedures into workflow artifacts that agents can replay, adapt, and reuse.
- [PolySkill: Learning Generalizable Skills Through Polymorphic Abstraction](https://arxiv.org/abs/2510.15863): learns generalizable and compositional agent skills by separating a skill abstract goal from its concrete implementations, improving reuse across web environments.
- [Alita-G: Self-Evolving Generative Agent for Agent Generation](https://arxiv.org/abs/2510.23601): Evolves a generalist agent into a domain specialist by generating, abstracting, and curating MCP tools from trajectories.
- [Procedural Knowledge Improves Agentic LLM Workflows](https://arxiv.org/abs/2511.07568): Large language models (LLMs) often struggle when performing agentic tasks without substantial tool support, prom-pt engineering, or fine tuning.
- [Audited Skill-Graph Self-Improvement for Agentic LLMs via Verifiable Rewards, Experience Synthesis, and Continual Memory](https://arxiv.org/abs/2512.23760): Promotes replay-verified skills with explicit interfaces, contracts, and provenance into an auditable skill graph.
- [CASCADE: Cumulative Agentic Skill Creation through Autonomous Development and Evolution](https://arxiv.org/abs/2512.23880): introduces a self-evolving agent framework for cumulative skill creation, using meta-skills, memory consolidation, and SciSkillBench science tasks.
- [Deploy-Master: Automating the Deployment of 50,000+ Agent-Ready Scientific Tools in One Day](https://arxiv.org/abs/2601.03513): Automates large-scale deployment of agent-ready scientific tools. Core idea: turn thousands of scientific tools into deployable agent capabilities with less manual packaging.
- [Yunjue Agent](https://arxiv.org/abs/2601.18226): A zero-start in-situ self-evolving agent system for open-ended tasks. Core idea: distill short-term execution feedback into reusable long-term capabilities, with tool evolution as the main route for expanding an agent's effective skill boundary.
- [CUA-Skill](https://arxiv.org/abs/2601.21123) ([project page](https://microsoft.github.io/cua_skill/)): A structured skill base and CUA-Skill Agent for computer-use agents; core idea: package GUI operation knowledge as skills with parameterized execution and composition graphs, then call them through retrieval, parameter instantiation, and memorized failure recovery.
- [AutoRefine](https://arxiv.org/abs/2601.22758): A trajectory-to-expertise harness for continual agents. Core idea: distill successful and failed trajectories into reusable procedural expertise repositories that future runs can retrieve and refine.
- [MemSkill](https://arxiv.org/abs/2602.02474): A harness for learning and evolving memory skills in self-evolving agents. Core idea: turn recurring memory operations into reusable skills that can be selected, updated, and carried across tasks.
- [Agentic Proposing](https://arxiv.org/abs/2602.03279): A compositional skill-synthesis harness for agentic reasoning. Core idea: propose reusable skills from subproblems so later reasoning tasks can compose them instead of starting from scratch.
- [Evolutionary Context Search](https://arxiv.org/abs/2602.16113): An automated skill-acquisition harness based on context search. Core idea: evolve candidate context resources and keep those that actually improve task execution, rather than selecting only semantically similar material.
- [Agent Skill Framework: Perspectives on the Potential of Small Language Models in Industrial Environments](https://arxiv.org/abs/2602.16653): Frames reusable agent skills for small language models in industrial environments. Core idea: package industrial operations as skill-level capabilities rather than relying on one monolithic model call.
- [SkillOrchestra](https://arxiv.org/abs/2602.19672): A skill-aware agent-routing harness. Core idea: route agents through skill transfer, making the transferability of skills an explicit orchestration signal.
- [TARSE](https://arxiv.org/abs/2603.01241): A test-time adaptation harness that retrieves skills and experience for reasoning agents.
  Core idea: select reusable procedural knowledge and prior experience at each reasoning step so skill reuse becomes part of online adaptation.
- [AgentSkillOS](https://arxiv.org/abs/2603.02176) ([code](https://github.com/ynulihao/AgentSkillOS)): An OS-style route for skill retrieval and orchestration; it decomposes skill use into `capability tree retrieval -> DAG orchestration -> artifact-rich output evaluation`.
  Core idea: compare "flat direct invocation" with "structured retrieval + DAG composition" at ecosystem scales from 200 to 200K skills; the paper also provides 30 artifact-rich tasks across five categories, showing that skill use is not only about finding a skill, but about organizing multiple skills into an executable pipeline.
- [EvoSkill](https://arxiv.org/abs/2603.02766): An automated skill-discovery harness for multi-agent systems. Core idea: evolve reusable workflows and code-level skills from experience so agents can expand their capability library over time.
- [ToolRosella](https://arxiv.org/abs/2603.09290): A repository-to-tool translation harness for scientific agents. Core idea: convert existing code repositories into standardized callable tools so agents do not need to rediscover interfaces at runtime.
- [XSkill](https://arxiv.org/abs/2603.12056): A continual multimodal-agent skill harness. Core idea: jointly retain visual experiences and structured reusable skills so later tasks can draw on both episodic evidence and procedural abstractions.
- [Memento-Skills](https://arxiv.org/abs/2603.18743) ([code](https://github.com/Memento-Teams/Memento-Skills)): A generalist agent system that treats reusable skills as persistent, evolvable memory.
  Core idea: use read-write reflective learning to select, update, and extend Markdown skill files, allowing agents to continually reshape task-specific agents without updating model parameters.
- [Semantic Tool Discovery for Large Language Models: A Vector-Based Approach to MCP Tool Selection](https://arxiv.org/abs/2603.20313): Uses vector-based semantic discovery to select MCP tools, fitting the skill-selection layer between raw tools and reusable skills.
- [ContractSkill](https://arxiv.org/abs/2603.20340): A repairable contract-based skill harness for multimodal web agents. Core idea: bind skills to explicit contracts so invocation, failure diagnosis, and repair are part of the skill lifecycle.
- [SkillClone: Multi-Modal Clone Detection and Clone Propagation Analysis in the Agent Skill Ecosystem](https://arxiv.org/abs/2603.22447): Studies multimodal clone detection and clone propagation in the agent-skill ecosystem. Core idea: detect copied or propagated skills so skill libraries can be governed and audited.
- [SkillRouter](https://arxiv.org/abs/2603.22455): A large-scale skill-routing harness for LLM agents. Core idea: route requests to relevant skills at ecosystem scale so agents can use broad skill libraries without stuffing all descriptions into context.
- [D2Skill](https://arxiv.org/abs/2603.28716): A dynamic dual-granularity skill bank for agentic reinforcement learning. Core idea: maintain task-level and step-level skills from experience, retrieve and prune them by hindsight utility, and inject them into later rollouts for reusable agent behavior.
- [SkillReducer](https://arxiv.org/abs/2603.29919): A token-efficiency harness for LLM-agent skills. Core idea: compress skill descriptions while preserving executability, selection quality, and useful guidance.
- [AdaSkill](https://arxiv.org/abs/2604.01608): A skill-distillation harness for deciding when a single skill-augmented agent can replace a multi-agent system.
  Core idea: extract tools, knowledge, and structure from multi-agent traces only when metric-free diagnostics indicate the distillation is beneficial.
- [CoEvoSkills](https://arxiv.org/abs/2604.01687): A co-evolutionary verification harness for self-evolving agent skills. Core idea: let agents construct multi-file reusable skills and verify them through paired evolution of tasks and skill implementations.
- [SkVM](https://arxiv.org/abs/2604.03088) ([code](https://github.com/SJTU-IPADS/SkVM)): Skill compilation and runtime; core idea: treat skills as compilable artifacts for capability binding, concurrent extraction, and JIT hardening, improving portability across harnesses.
- [SkillFoundry](https://arxiv.org/abs/2604.03964) ([code](https://github.com/ma-compbio-lab/SkillFoundry)): Builds self-evolving skill libraries from heterogeneous scientific and engineering resources.
  Core idea: extract procedural knowledge from documents, repositories, scripts, notebooks, databases, and papers into skill packages with inputs, outputs, execution steps, environment assumptions, provenance, and tests, then close the loop through expansion, repair, merge, and pruning.
  Core idea: distill trajectories into a three-level structure of strategic plans, functional skills, and atomic skills, then iteratively correct and actively expand skill coverage through execution feedback.
- [Graph of Skills](https://arxiv.org/abs/2604.05333) ([code](https://github.com/davidliuk/graph-of-skills)): Dependency-aware structured retrieval for skills; core idea: replace flat skill lists with structured context containing prerequisite relations, reducing blind selection.
- [SkillClaw](https://arxiv.org/abs/2604.08377): A collective skill-evolution harness for OpenClaw-style agents. Core idea: update shared deployed skills from cross-user workflow successes and failures.
- [SkillForge](https://arxiv.org/abs/2604.08618): A domain-specific self-evolving skill-forging harness for cloud technical support. Core idea: generate, test, and revise support skills from domain traces so skills improve with operational feedback.
- [SkillMOO](https://arxiv.org/abs/2604.09297): A multi-objective optimization harness for software-engineering agent skills. Core idea: tune skill bundles while balancing task success, token cost, and misleading-guidance risk.
- [Skill-SD: Skill-Conditioned Self-Distillation for Multi-turn LLM Agents](https://arxiv.org/abs/2604.10674): Skill-conditioned self-distillation for multi-turn LLM agents; core idea: condition distillation on task-relevant skills so long-horizon agents receive denser reusable supervision.
- [WebXSkill](https://arxiv.org/abs/2604.13318) ([code](https://github.com/aiming-lab/WebXSkill)): A web-agent skill-learning harness. Core idea: mine reusable web action subsequences into executable parameterized skills with natural-language guidance, index them by URL context, and deploy them in grounded or guided modes.
- [Corpus2Skill](https://arxiv.org/abs/2604.14572): A navigable-skill harness for enterprise QA and RAG. Core idea: distill corpora into hierarchical skill directories that agents traverse from summaries to documents instead of consuming one-shot retrieval results.
- [From Procedural Skills to Strategy Genes: Towards Experience-Driven Test-Time Evolution](https://arxiv.org/abs/2604.15097): Experience-driven test-time evolution from procedural skills to strategy representations.
- [Bilevel Skill Optimization](https://arxiv.org/abs/2604.15709): A Monte-Carlo-tree-search harness for optimizing agent skills. Core idea: search over skill-level choices and lower-level execution behavior jointly so reusable skills are improved by task feedback.
- [AgentClick](https://arxiv.org/abs/2604.16520): A skill-based human-in-the-loop review layer for terminal agents. Core idea: route risky terminal actions through review skills so human approval becomes part of the execution workflow.
- [GraSP](https://arxiv.org/abs/2604.17870): A graph-structured skill-composition harness for LLM agents. Core idea: compose focused skills through graph structure so agents use coherent skill sets rather than overloaded flat prompts.
- [EvoAgent](https://arxiv.org/abs/2604.20133): An evolvable agent framework for skill learning and multi-agent delegation.
  Core idea: treat skills as learned reusable units and delegate work among agents according to the evolving skill state.
- [Co-Evolving LLM Decision and Skill Bank Agents](https://arxiv.org/abs/2604.20987): A long-horizon skill-bank harness.
  Core idea: co-evolve a decision agent with a skill-bank agent so task experience reshapes both planning and reusable skill inventory.
- [From Skills to Talent](https://arxiv.org/abs/2604.22446): Organizes heterogeneous agents as portable Talents. Core idea: package skills, tools, and runtime configuration into recruitable agent identities, then use an Explore-Execute-Review tree search and a Talent Market to assemble, execute, and improve multi-agent organizations dynamically.
- [RouteGuard: Internal-Signal Detection of Skill Poisoning in LLM Agents](https://arxiv.org/abs/2604.22888): Detects skill poisoning before execution. Core idea: use response-conditioned attention and hidden-state alignment signals to identify malicious spans inside otherwise legitimate skills.
- [ClawTrace: Cost-Aware Tracing for LLM Agent Skill Distillation](https://arxiv.org/abs/2604.23853): Adds a agent harness for skill use, centered on ClawTrace: Cost-Aware Tracing for LLM Agent Skill Distillation.
- [From Skill Text to Skill Structure: The Scheduling-Structural-Logical Representation for Agent Skills](https://arxiv.org/abs/2604.24026): Candidate 1.13.3 Agent Harness entry; the title indicates a reusable benchmark or agent-harness contribution that should be checked before formal insertion.
- [Skill Retrieval Augmentation for Agentic AI](https://arxiv.org/abs/2604.24594): A skill-retrieval augmentation framework for agentic AI. Core idea: retrieve relevant skills at runtime so agents can adapt their capability set to the current task.
- [Structured Security Auditing and Robustness Enhancement for Untrusted Agent Skills](https://arxiv.org/abs/2604.25109): A security-auditing harness for untrusted agent skills. Core idea: inspect and harden third-party skills before agents execute them.
- [Skills-Coach: A Self-Evolving Skill Optimizer via Training-Free GRPO](https://arxiv.org/abs/2604.27488): Optimizes reusable agent skills without changing the task model, targeting broader and more reliable skill coverage.
- [Ctx2Skill](https://arxiv.org/abs/2604.27660): Builds context-specific skills without manual annotations by running a Challenger, Reasoner, and Judge in self-play; failures become targeted skill updates, so long technical contexts are converted into reusable procedures through internal feedback rather than external labels.
- [Semia: Auditing Agent Skills via Constraint-Guided Representation Synthesis](https://arxiv.org/abs/2605.00314): Audits agent skills through constraint-guided representation synthesis. Core idea: inspect whether skill behavior satisfies stated constraints before agents reuse it.
- [Neuro-Symbolic Skill Induction](https://arxiv.org/abs/2605.01293): A programmatic skill-induction harness for long-horizon agents. Core idea: lift interaction traces into logic-grounded programs with explicit control flow, variable binding, and activation conditions.
- [HeavySkill: Heavy Thinking as the Inner Skill in Agentic Harness](https://arxiv.org/abs/2605.02396): Treats heavy thinking as an internal skill in an agentic harness. Core idea: package deeper reasoning routines as reusable skills that a harness can invoke when needed.
- [FitText: Evolving Agent Tool Ecologies via Memetic Retrieval](https://arxiv.org/abs/2605.02411): Adds a agent harness for skill use, centered on FitText: Evolving Agent Tool Ecologies via Memetic Retrieval.
- [SkCC](https://arxiv.org/abs/2605.03353): Cross-framework skill compilation and security hardening; core idea: use the strongly typed intermediate representation SkIR to decouple the semantics of Markdown skills from the prompt formats of different agent frameworks, while incorporating permissions, safety checks, and portability into the compilation process.
- [Sealing the Audit-Runtime Gap for LLM Skills](https://arxiv.org/abs/2605.05274): Seals the audit-runtime gap for LLM skills. Core idea: bind audited skill artifacts to a tamper-evident registry and verifiable hosting path so runtime skill content matches what was approved.
- [From History to State: Constant-Context Skill Learning for LLM Agents](https://arxiv.org/abs/2605.05413): Agent Harness entry; core idea: constant-context skill learning from interaction history; core idea: convert long agent trajectories into reusable state and skills without growing the prompt.
- [SkillScope](https://arxiv.org/abs/2605.05868): A least-privilege enforcement layer for agent skills. Core idea: scope each skill's permissions at fine granularity and enforce them during execution so reusable skills do not silently expand an agent's authority.
- [SkillOS](https://arxiv.org/abs/2605.06614): A skill-curation harness for self-evolving agents. Core idea: pair a frozen executor that retrieves and applies skills with a trainable curator that updates an external SkillRepo from accumulated experience, using delayed task-stream rewards to learn long-term skill maintenance policies.
- [Group of Skills: Group-Structured Skill Retrieval for Agent Skill Libraries](https://arxiv.org/abs/2605.06978): Adds a agent harness for skill use, centered on Group of Skills: Group-Structured Skill Retrieval for Agent Skill Libraries.
- [SkillLens](https://arxiv.org/abs/2605.08386): A hierarchical skill-reuse and evolution framework; core idea: organize skills into policy, strategy, procedure, and primitive layers, retrieve at mixed granularity, and rewrite only locally mismatched subskills to reduce context and adaptation cost.
- [CoCoDA: Co-evolving Compositional DAG for Tool-Augmented Agents](https://arxiv.org/abs/2605.08399): Adds a agent harness for skill use, centered on CoCoDA: Co-evolving Compositional DAG for Tool-Augmented Agents.
- [Skill-CMIB: Multimodal Agent Skill for Consistent Action via Conditional Multimodal Information Bottleneck](https://arxiv.org/abs/2605.08526): Multimodal skill harness: consistent action through reusable multimodal skills. - [MIND-Skill: Quality-Guaranteed Skill Generation via Multi-Agent Induction and Deduction](https://arxiv.org/abs/2605.08670): Skill-generation harness: quality-guaranteed skill generation via multi-agent induction and deduction. Core idea: use multiple agents to induce and verify reusable procedural skills.
- [SkillMaster](https://arxiv.org/abs/2605.08693): An autonomous skill mastery framework.
  Core idea: close the loop across skill creation, refinement, and selection so an LLM agent can maintain reusable capabilities rather than only consume a fixed skill list.
- [AgentPSO](https://arxiv.org/abs/2605.08704) ([code](https://github.com/HYUNMIN-HWANG/AgentPSO/)): A multi-agent particle-swarm framework for evolving reasoning skills. - [Ace-Skill: Bootstrapping Multimodal Agents with Prioritized and Clustered Evolution](https://arxiv.org/abs/2605.08887): A harness for prioritized and clustered skill evolution for multimodal agents. - [SearchSkill: Teaching LLMs to Use Search Tools with Evolving Skill Banks](https://arxiv.org/abs/2605.09038): Teaches LLMs to use search tools with evolving skill banks; the core idea is to accumulate reusable search skills rather than rely on one-off prompts.
- [SPARK](https://arxiv.org/abs/2605.09192) ([code](https://github.com/EtaYang10th/spark-skills)): Structured pipelines for autonomous runnable tasks; core idea: compress post-task experience into runnable skill flows, emphasizing posterior skill formation and later reuse.
- [SkillMAS](https://arxiv.org/abs/2605.09341): A post-deployment skill-evolution harness for multi-agent systems; core idea: assign credit from verified traces, update reusable procedures under bounded growth, and restructure the agent organization when failures reveal role-skill mismatch.
- [SkillRAE](https://arxiv.org/abs/2605.10114): Skill-based context compilation for retrieval-augmented execution; core idea: compile retrieved skills into compact, grounded, executable context instead of directly stuffing a set of raw Markdown skills into the agent.

- [SkillHone](https://arxiv.org/abs/2606.08671): Continually refines agent skills through persistent decision history. Core idea: combine practice probes, role-separated subagents, and structured revision evidence so skill updates carry across sessions instead of being local prompt edits.
