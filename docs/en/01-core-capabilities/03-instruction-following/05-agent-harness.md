# 1.3.5 Agent Harness

- [HELM](https://arxiv.org/abs/2211.09110) ([open-source code](https://github.com/stanford-crfm/helm)): a general evaluation harness. For instruction-following tasks, it can reuse IFEval scenarios and strict-accuracy metrics, standardizing rule checks, model calls, and result aggregation.
- [Reflexion](https://arxiv.org/abs/2303.11366) ([open-source code](https://github.com/noahshinn/reflexion)): stores failure experience as textual memory for the next execution round, making it suitable for continuous improvement on multi-turn constraint tasks.
- [Self-Refine](https://arxiv.org/abs/2303.17651) ([open-source code](https://github.com/madaan/self-refine)): a `generate first -> self-evaluate -> self-revise` repair loop that can serve as a general self-repair skeleton for complex instruction execution.
- [Connecting Large Language Models with Evolutionary Algorithms Yields Powerful Prompt Optimizers](https://arxiv.org/abs/2309.08532): Connecting Large Language Models with Evolutionary Algorithms Yields adds an instruction-following agent-harness for prompt optimization, instruction control, or task-directed prompting.
- [Efficient Prompt Optimization Through the Lens of Best Arm Identification](https://arxiv.org/abs/2402.09723): Contributes an external workflow, tool, memory, retrieval, orchestration, or agent loop for instruction following capabilities.
- [Unleashing the Potential of Large Language Models as Prompt Optimizers: An Analogical Analysis with Gradient-based Model Optimizers](https://arxiv.org/abs/2402.17564): Contributes an external workflow, tool, memory, retrieval, orchestration, or agent loop for instruction following capabilities.
- [CoGenesis: A Framework Collaborating Large and Small Language Models for Secure Context-Aware Instruction Following](https://arxiv.org/abs/2403.03129): Contributes an external workflow, tool, memory, retrieval, orchestration, or agent loop for instruction following capabilities.
- [Prompt Optimization with EASE? Efficient Ordering-aware Automated Selection of Exemplars](https://arxiv.org/abs/2405.16122): Contributes an external workflow, tool, memory, retrieval, orchestration, or agent loop for instruction following capabilities.
- [AutoManual: Constructing Instruction Manuals by LLM Agents via Interactive Environmental Learning](https://arxiv.org/abs/2405.16247): builds manuals through interactive environment learning, with Planner, Builder, and Formulator agents that turn online rule updates and case-conditioned prompting into human-readable instructions for downstream planning.
- [TS-Align: A Teacher-Student Collaborative Framework for Scalable Iterative Finetuning of Large Language Models](https://arxiv.org/abs/2405.20215): Adds an agent workflow, orchestration pattern, tool loop, memory mechanism, or multi-agent harness for Instruction Following coverage.
- [Learning to Ask: When LLM Agents Meet Unclear Instruction](https://arxiv.org/abs/2409.00557): adds a clarification loop for tool-using agents, using NoisyToolBench and Ask-when-Needed so agents ask users for missing arguments instead of hallucinating tool calls under unclear instructions.
- [Moral Alignment for LLM Agents](https://arxiv.org/abs/2410.01639): studies an agent decision-making setup where explicit deontological and utilitarian intrinsic rewards shape behavior in Iterated Prisoner's Dilemma, including unlearning selfish policies and transfer to other matrix games.
- [BT-ACTION: A Test-Driven Approach for Modular Understanding of User Instruction Leveraging Behaviour Trees and LLMs](https://arxiv.org/abs/2504.02779): Contributes an agent workflow, orchestration pattern, prompting loop, or tool-mediated harness for instruction-following capability.
- [ADL: A Declarative Language for Agent-Based Chatbots](https://arxiv.org/abs/2504.14787): defines customer-service chatbot agents and their interactions in a declarative language, supporting natural-language programming, four agent types, custom functions, tool use, third-party agents, and execution through MICA.
- [SI-Agent: An Agentic Framework for Feedback-Driven Generation and Tuning of Human-Readable System Instructions for Large Language Models](https://arxiv.org/abs/2507.03223): Contributes an agent workflow, runtime, protocol, tool-use pattern, or multi-agent orchestration approach for instruction following.
- [Re5](https://arxiv.org/abs/2507.05598): a self-review/revision harness for instruction following. The core idea is to first extract the task and constraints, then perform structural evaluation, constraint-level content evaluation, and selective revision, reducing the quality degradation caused by blind multi-turn self-editing.
- [COCORELI: Enforcing Execution Preconditions for Reliable Collaborative Instruction Following](https://arxiv.org/abs/2509.04470): Enforces execution preconditions for collaborative instruction following; the core idea is to prevent agents from acting when instructions are underspecified.
- [MAC: A Multi-Agent Framework for Interactive User Clarification in Multi-turn Conversations](https://arxiv.org/abs/2512.13154): Contributes an agent workflow, runtime, protocol, tool-use pattern, or multi-agent orchestration approach for instruction following.
- [Evaluation-Driven Prompt Instruction Optimization](https://arxiv.org/abs/2601.03359): A multi-agent workflow for improving prompt instructions. Core idea: use evaluator feedback to iteratively repair instructions that produce correct content but violate formal constraints.
- [NSVIF](https://arxiv.org/abs/2601.17789): a neurosymbolic instruction-following verification framework. The core idea is to model natural-language instructions as logical and semantic constraints and generate interpretable feedback through a unified solver, making it usable as an independent compliance-check layer before agent output.
- [Error Taxonomy-Guided Prompt Optimization](https://arxiv.org/abs/2602.00997): A harness for prompt optimization guided by execution-log error taxonomies. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [LLMON: An LLM-native Markup Language to Leverage Structure and Semantics at the LLM Interface](https://arxiv.org/abs/2603.22519): A harness for LLMON, a structured markup interface that separates instructions, data, and semantics for LLM calls. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [Hierarchical Alignment: Enforcing Hierarchical Instruction-Following in LLMs through Logical Consistency](https://arxiv.org/abs/2604.09075): Adds a agent harness for instruction following, centered on Hierarchical Alignment: Enforcing Hierarchical Instruction-Following in LLMs through Logical Consistency.
- [Automated Instruction Revision (AIR): A Structured Comparison of Task Adaptation Strategies for LLM](https://arxiv.org/abs/2604.09418): A harness for automated instruction revision as a rule-induction approach for task adaptation. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [CASPER](https://doi.org/10.18653/v1/2026.eacl-industry.32): A feedback-guided prompt-optimization framework for LLM workflow automation. Core idea: bridge discrete and continuous prompt search so agent prompts can be improved without manual prompt engineering alone.
- lm-evaluation-harness ([open-source code](https://github.com/EleutherAI/lm-evaluation-harness)): a general language-model evaluation execution framework. Its value is that it already includes an `ifeval` task implementation, making it suitable for integrating instruction-following rule checks into reproducible experiment pipelines.
- [Offscript](https://doi.org/10.1145/3786304.3787891): An agentic auditing framework for instruction adherence. Core idea: automatically probe whether LLMs and generative search systems obey custom behavioral and sourcing instructions.
