# 2.7.3 Bench

- [GAIA](https://arxiv.org/abs/2311.12983) ([dataset](https://huggingface.co/datasets/gaia-benchmark/GAIA); [leaderboard](https://huggingface.co/spaces/gaia-benchmark/leaderboard)): Evaluates reasoning, multimodality, web browsing, and tool use by general AI assistants on real-world questions. Core idea: combine "can search, calculate, use tools, and integrate evidence" into an early anchor for general agent evaluation using problems easy for humans but hard for models.
- [TravelPlanner: A Benchmark for Real-World Planning with Language Agents](https://arxiv.org/abs/2402.01622): Benchmarks real-world travel planning by language agents, making long-horizon practical planning measurable.
- [Evaluating Large Language Models in Process Mining: Capabilities, Benchmarks, Evaluation Strategies, and Future Challenges](https://arxiv.org/abs/2403.06749): Adds a bench reference for real-world work, with a reusable contribution signaled by the title rather than a narrow application-only result.
- [WorkArena](https://arxiv.org/abs/2403.07718) ([open-source code](https://github.com/ServiceNow/WorkArena), [BrowserGym leaderboard](https://huggingface.co/spaces/ServiceNow/browsergym-leaderboard)): Evaluates common knowledge-work web tasks in ServiceNow enterprise software. Core idea: use a realistic enterprise-software-style platform and BrowserGym environment to evaluate web operation, form handling, retrieval, and process execution.
- [WorkBench](https://arxiv.org/abs/2405.00823) ([open-source code](https://github.com/olly-styles/WorkBench)): Evaluates tool use and state-changing tasks in realistic office/business activities. Core idea: provide a sandbox with 5 databases, 26 tools, and 690 tasks, using outcome-centric evaluation to check whether the final database state is uniquely correct, emphasizing executable common workflows such as email, meetings, and record updates as well as the risk of misoperation.
- [The Dawn of Natural Language to SQL: Are We Fully Ready?](https://arxiv.org/abs/2406.01265): Introduces NL2SQL360, a multi-angle evaluation framework for production-style natural-language database querying. Core idea: compare NL2SQL methods across domains and SQL characteristics, then use the same framework to search the design space for a task-suitable solution.
- [tau-bench](https://arxiv.org/abs/2406.12045) ([open-source code](https://github.com/sierra-research/tau-bench), [Leaderboard](https://taubench.com/)): Evaluates multi-turn tool-agent-user interaction in realistic domains such as retail and airlines. Core idea: constrain agents jointly with simulated users, domain APIs, and policy guidelines, then evaluate true user-goal completion through final database state.
- [WONDERBREAD](https://arxiv.org/abs/2406.13264): Evaluates multimodal foundation models on business-process-management work beyond end-to-end automation. Core idea: use 2,928 documented workflow demonstrations, 6 BPM tasks, and an automated harness to test workflow documentation, knowledge transfer, and process-improvement reasoning.
- [SpreadsheetBench](https://arxiv.org/abs/2406.14991): Evaluates spreadsheet manipulation on real Excel-forum scenarios. Core idea: pair 912 real user questions with messy spreadsheets containing multiple tables, non-standard relations, and non-textual elements, then use online-judge-style generated test spreadsheets to check robust formula or operation solutions.
- [WorkArena++](https://arxiv.org/abs/2407.05291) ([open-source code](https://github.com/ServiceNow/WorkArena), [BrowserGym leaderboard](https://huggingface.co/spaces/ServiceNow/browsergym-leaderboard)): Evaluates more compositional enterprise knowledge workflows. Core idea: extend WorkArena to 682 tasks requiring compositional planning, logical/arithmetic reasoning, retrieval, and context understanding, specifically amplifying planning failures in multi-step enterprise processes.
- [InsightBench](https://arxiv.org/abs/2407.06423) ([open-source code](https://github.com/ServiceNow/insight-bench)): Evaluates business analytics agents. Core idea: require multi-step insight generation over realistic datasets, connecting data understanding, analysis planning, and business-facing explanation.
- [IDAT](https://arxiv.org/abs/2407.08898): Provides data and evaluation tooling for interactive grounded task-solving agents. Core idea: collect about 9,000 utterances and 1,000+ clarification questions in a Minecraft-like environment, and pair the dataset with a human-in-the-loop platform for multi-turn agent evaluation.
- [Spider2-V](https://arxiv.org/abs/2407.10956): Evaluates multimodal agents on professional data-science and data-engineering workflows. Core idea: run 494 tasks inside authentic enterprise software environments such as BigQuery, dbt, and Airbyte, requiring code, SQL, and GUI actions rather than final-answer text only.
- [AssistantBench](https://arxiv.org/abs/2407.15711) ([project page](https://assistantbench.github.io/), [Leaderboard](https://huggingface.co/spaces/AssistantBench/leaderboard)): Evaluates realistic and time-consuming web assistant tasks. Core idea: turn web work such as monitoring, filtering, locating, and information integration into automatically evaluated tasks, linking GAIA-style general assistant ability with WebArena-style executable web environments.
- [OfficeBench](https://arxiv.org/abs/2407.19056) ([open-source code](https://github.com/zlwang-cs/OfficeBench)): Evaluates office automation across Word, Excel, PDF, calendars, email, and other applications. Core idea: use 300 multi-application tasks to test long-horizon planning, application switching, and large-action-space grounding, highlighting redundant operations, hallucination, and cross-application failures in daily office workflows.
- [TableBench: A Comprehensive and Complex Benchmark for Table Question Answering](https://arxiv.org/abs/2408.09174): Benchmarks real world work capabilities with a task, evaluation protocol, or diagnostic setting.
- [BPM Task Benchmark](https://arxiv.org/abs/2410.03255): Benchmarks LLMs on business-process-management tasks where generic NLP scores do not directly transfer. Core idea: compare open-source and commercial models across four BPM tasks to expose task-specific variation and model-size tradeoffs for process-management deployment.
- [Enterprise Benchmarks for Large Language Model Evaluation](https://arxiv.org/abs/2410.12857): Evaluates LLMs across enterprise NLP domains. Core idea: assemble 25 public datasets from finance, legal, cybersecurity, climate, and sustainability domains and compare 13 models, making enterprise domain and task choice explicit in model selection.
- [Social Science Meets LLMs: How Reliable Are Large Language Models in Social Simulations?](https://arxiv.org/abs/2410.23426): Benchmarks or evaluates real-world work capabilities with a reusable task, dataset, protocol, or metric.
- [CRMArena](https://arxiv.org/abs/2411.02305): Evaluates professional customer service, analysis, and management tasks in CRM systems. Core idea: introduce industrial objects, hidden variables, and business rules to test function calling, rule following, and business-process reliability in realistic CRM work environments.
- [Spider 2.0](https://arxiv.org/abs/2411.07763) ([project page and leaderboard](https://spider2-sql.github.io/)): Evaluates real enterprise text-to-SQL workflows. Core idea: require metadata search, dialect handling, codebase context, and multi-query SQL generation, making database work closer to real analytics tasks than classic single-query Spider.
- [LLM User-Agents for Task-Oriented Dialogue Evaluation](https://arxiv.org/abs/2411.09972): Uses LLMs as context-aware user simulators for evaluating task-oriented dialogue systems. Core idea: prompt user-agents with in-context examples, track user-goal state, and evaluate TOD systems dynamically rather than relying only on static offline dialogue datasets.
- [ChinaTravel](https://arxiv.org/abs/2412.13682): Evaluates open-ended Chinese travel planning under compositional constraints. Core idea: combine a multi-day, multi-POI sandbox, a domain-specific language for feasibility and preference validation, and human-written implicit requirements to test whether language agents can satisfy real travel constraints.
- [TheAgentCompany](https://arxiv.org/abs/2412.14161) ([leaderboard](https://the-agent-company.com/#/leaderboard); [open-source code](https://github.com/TheAgentCompany/TheAgentCompany)): Evaluates real digital-employee tasks in a simulated software company. Core idea: build a self-contained company environment, internal websites, and coworker communication, requiring agents to complete work through web browsing, coding, program execution, and collaboration rather than operating in a single tool.
- [Collaborative Gym](https://arxiv.org/abs/2412.15701): Evaluates human-agent collaboration with bidirectional communication and task-environment interaction. Core idea: support simulated and real-user conditions across travel planning, related-work writing, and tabular analysis, measuring both outcomes and collaboration-process failures such as poor communication or situational awareness.
