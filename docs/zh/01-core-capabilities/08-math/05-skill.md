# 1.8.5 Skill

- [sympy](https://github.com/davila7/claude-code-templates/tree/main/cli-tool/components/skills/scientific/sympy) 是最实用的 executable math skill，适合 `PAL / PoT / ToRA` 路线。
- [math-reasoning](https://skills.sh/lingzhi227/agent-research-skills/math-reasoning) 适合把数学解答组织成可检验、可 LaTeX 化的结构。
- [lean4](https://github.com/cameronfreer/lean4-skills/tree/main/plugins/lean4/skills/lean4) 适合 Lean 4 证明工作流。
- [lean4-theorem-proving](https://github.com/benchflow-ai/skillsbench/tree/main/tasks/lean4-proof/environment/skills/lean4-theorem-proving) 适合长时程形式化证明任务。
- [lean4-memories](https://github.com/benchflow-ai/skillsbench/tree/main/tasks/lean4-proof/environment/skills/lean4-memories) 适合沉淀证明失败轨迹与可复用策略记忆。
- [benchflow-ai/skillsbench/sympy](https://github.com/benchflow-ai/skillsbench/tree/main/tasks/crystallographic-wyckoff-position-analysis/environment/skills/sympy)（符号数学 skill；覆盖代数、微积分、矩阵、数论与代码生成）也适合作为可执行工具层补充。
