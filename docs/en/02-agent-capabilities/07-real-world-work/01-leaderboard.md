# 2.7.1 Leaderboard

- [GAIA Leaderboard](https://huggingface.co/spaces/gaia-benchmark/leaderboard): A long-running public leaderboard for general real-world assistant tasks, covering reasoning, web browsing, multimodality, and tool use; it remains an important entry point for comparing whether agents can solve real problems rather than isolated tool skills.
- [TheAgentCompany Leaderboard](https://the-agent-company.com/#/leaderboard): A public leaderboard for digital-employee tasks in a simulated software company; useful for observing end-to-end completion rates on mixed real-work tasks involving web, code, files, and coworker communication.
- [HAL / Holistic Agent Leaderboard](https://hal.cs.princeton.edu/) ([open-source harness](https://github.com/princeton-pli/hal-harness)): Reports accuracy, cost, runtime, and traces across GAIA, AssistantBench, tau-bench, Online Mind2Web, SWE-bench Verified, and other tasks; its value is that models, agent scaffolds, and evaluation cost are compared together in public.
- [GDPval Leaderboard](https://evals.openai.com/gdpval/leaderboard): A public leaderboard for economically valuable task deliverables; it focuses on rubric-driven professional output quality and puts model capability, context, and scaffolding benefits for real work into one entry point.
- [Remote Labor Index Leaderboard](https://labs.scale.com/leaderboard/rli): Continuously compares agents on automation rate and delivery quality for real remote-labor projects; it complements GDPval by emphasizing outsourced projects, economic signals, and end-to-end delivery.
- [APEX-Agents Leaderboard](https://www.mercor.com/apex/apex-agents-leaderboard/): A public leaderboard covering professional-service tasks such as investment banking, consulting, and corporate law; it treats files, tools, rubrics, and gold outputs as deliverables for real white-collar work.
- [ClawBench Leaderboard](https://claw-bench.com/): A leaderboard for write-operation tasks on real live websites, recording model, harness, trace, HTTP interception, and reward; its main value is making agent behavior auditable in real web workflows.
- [ClawMark Leaderboard](https://claw-mark.com/leaderboard): A multi-calendar-time coworker-agent workflow leaderboard, useful for tracking real-work agents that can wait, remember, and collaborate across days rather than only complete single-session tasks.
- [BrowserGym Leaderboard](https://huggingface.co/spaces/ServiceNow/browsergym-leaderboard): ServiceNow's public Hugging Face leaderboard for BrowserGym web-agent environments, including WorkArena-style enterprise tasks; useful for comparing agents under a shared browser-operation harness.
- [tau-bench Leaderboard](https://taubench.com/): The official public tau-bench results site for tool-using conversational agents in retail, airline, and related customer-service domains, with task-fix and trajectory updates alongside scores.
- [AssistantBench Leaderboard](https://huggingface.co/spaces/AssistantBench/leaderboard): The official Hugging Face leaderboard for time-consuming web-assistant tasks, complementing GAIA with automatically evaluated monitoring, filtering, and information-integration workflows.
- [Spider 2.0 Leaderboard](https://spider2-sql.github.io/): The official Spider 2.0 challenge leaderboard for real enterprise text-to-SQL workflows, including Snowflake, DBT, and Lite settings.
- [WebChoreArena Leaderboard](https://webchorearena.github.io/): The official WebChoreArena project page links to the public challenge leaderboard for reproducible, tedious web-work tasks built on WebArena-style environments.
- [FieldWorkArena AgentBeats Leaderboard](https://agentbeats.dev/agentbeater/fieldworkarena): A public AgentBeats challenge leaderboard for FieldWorkArena, tracking multimodal field-work agents on factory, warehouse, and retail tasks.
- [Data Agent Benchmark Leaderboard](https://ucbepic.github.io/DataAgentBench/): UC Berkeley EPIC's official DAB leaderboard for enterprise data agents that answer natural-language queries across heterogeneous databases and unstructured text.
- [Claw-Eval Leaderboard](https://claw-eval.github.io/): A public leaderboard for transparent real-world agent tasks, reporting Pass^3, completion, robustness, and safety over human-verified workflow tasks.
- [Claw-Eval-Live Leaderboard](https://claw-eval-live.github.io/): A live Claw-Eval family leaderboard that refreshes workflow tasks from marketplace demand signals and reports pass rate plus completion score.
- [PinchBench Leaderboard](https://pinchbench.com/) ([benchmark tasks](https://github.com/pinchbench/skill)): An OpenClaw-oriented real-task leaderboard for comparing model brains inside the same agent runtime; it reports success rate, speed, and cost over messy work such as scheduling, email triage, research, coding, file management, analysis, memory, and skill discovery.
- [QwenClawBench Leaderboard](https://skylenage-ai.github.io/QwenClawBench-Leaderboard/) ([open-source code](https://github.com/SKYLENAGE-AI/QwenClawBench); [dataset](https://huggingface.co/datasets/skylenage-ai/QwenClawBench)): A Qwen and Alibaba Data leaderboard for OpenClaw agents over 100 real-user-distribution tasks, useful for comparing models inside the same OpenClaw runtime while keeping infrastructure anomalies and repeated-run reliability visible.
- [PawBench Leaderboard](https://agentscope-ai.github.io/PawBench/) ([open-source code](https://github.com/agentscope-ai/PawBench)): A public model-harness matrix for real-work agent tasks; it reports overall and slice scores over 150 tasks, so readers can compare the same model under QwenPaw, OpenClaw, and Hermes rather than treating the harness as invisible.
- [AlphaEval Leaderboard](https://alphaeval.ai/): A production-oriented real-work agent leaderboard over business tasks from deployed-agent settings, comparing complete agent products and scaffolds rather than only model APIs.
- [GDPval-AA Leaderboard](https://artificialanalysis.ai/evaluations/gdpval-aa): Artificial Analysis' independent GDPval evaluation with web and shell access through the Stirrup harness, ranking agentic model performance on professional deliverables by Elo.
