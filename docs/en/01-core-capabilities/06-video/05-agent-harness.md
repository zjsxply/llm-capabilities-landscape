# 1.6.5 Agent Harness

- [VideoAgent: A Memory-augmented Multimodal Agent for Video Understanding](https://arxiv.org/abs/2403.11481): Maintains structured memory for temporal events and object tracking states, then calls segment-localization and object-memory tools so an LLM can answer long-horizon video questions from targeted evidence.
- [VURF: A General-purpose Reasoning and Self-refinement Framework for Video Understanding](https://arxiv.org/abs/2403.14743): Prompts an LLM with instruction-program examples to generate executable visual programs for video tasks, then uses GPT-3.5 error feedback and iterative example refinement to repair unsupported functions.
- [VDMA: Video Question Answering with Dynamically Generated Multi-Agents](https://arxiv.org/abs/2407.03610): Generates task-specific expert agents for EgoSchema-style video QA, coordinating staged tool use and response selection rather than relying on a single answer generator.
- [LMMs-Eval](https://arxiv.org/abs/2407.12772) ([code](https://github.com/EvolvingLMMs-Lab/lmms-eval)): A multimodal evaluation harness covering video tasks such as Video-MME, LongVideoBench, and Video-MMMU; suitable as a unified entry point for reproducible experiments and batch leaderboard submissions.
- [Propose, Assess, Search: Harnessing LLMs for Goal-Oriented Planning in Instructional Videos](https://arxiv.org/abs/2409.20557): Uses propose-assess-search LLM orchestration for goal-oriented planning in instructional videos.
- [Adaptive Video Understanding Agent: Enhancing efficiency with dynamic frame sampling and feedback-driven reasoning](https://arxiv.org/abs/2410.20252): Lets an LLM choose query-relevant frames at inference time and uses self-reflective verbal feedback to improve answers while reducing the number of sampled frames.
- [VideoChat-Online](https://arxiv.org/abs/2501.00584) ([code](https://github.com/MCG-NJU/VideoChat-Online)): A reference implementation for online/streaming video understanding, tightly coupled to the OVBench benchmark-specific runtime.
- [ENTER: Event Based Interpretable Reasoning for VideoQA](https://arxiv.org/abs/2501.14194): A harness for event-graph reasoning for interpretable VideoQA. Core idea: expose workflow logic outside the base model so planning, tool use, memory, verification, recovery, or orchestration can be studied and reused.
- [VideoRAG](https://arxiv.org/abs/2502.01549) ([code](https://github.com/HKUDS/VideoRAG)): A retrieval-augmented generation workflow for ultra-long videos that delegates "finding segment evidence" to video retrieval and indexing structures.
- [PreMind: Multi-Agent Video Understanding for Advanced Indexing of Presentation-style Videos](https://arxiv.org/abs/2503.00162): A multi-agent video-understanding framework for presentation-style video indexing. Core idea: coordinate agents over visual, textual, and temporal cues to produce richer indexes for long presentation videos.
- [LVAgent](https://arxiv.org/abs/2503.10200) ([code](https://github.com/64327069/LVAgent)): A dynamic agent for long-video QA; it adaptively selects retrieval and analysis paths for different questions through task planning, iterative tool use, and real-time progress management.
- [Logic-in-Frames: Dynamic Keyframe Search via Visual Semantic-Logical Verification for Long Video Understanding](https://arxiv.org/abs/2503.13139): A dynamic keyframe-search harness for long-video understanding. Core idea: select evidence frames through semantic-logical verification so video reasoning focuses on relevant temporal evidence.
- [VideoMind](https://arxiv.org/abs/2503.13444) ([code](https://github.com/yeliudev/VideoMind)): Decomposes long-video understanding into an agentic pipeline of planning, grounding, retrieval, and reasoning, and adapts to long-video tasks with Chain-of-LoRA.
- [AssistPDA](https://arxiv.org/abs/2503.21904): Builds an online video surveillance assistant that unifies anomaly prediction, detection, and analysis with interactive VLM reasoning.
- [TimeSearch: Hierarchical Video Search with Spotlight and Reflection for Human-like Long Video Understanding](https://arxiv.org/abs/2504.01407): A hierarchical video-search framework with spotlight and reflection; core idea: search long videos at multiple temporal granularities and reflect on missing evidence before answering.
- [VideoAgent2: Enhancing the LLM-Based Agent System for Long-Form Video Understanding by Uncertainty-Aware CoT](https://arxiv.org/abs/2504.04471): Enhances long-form video agents with uncertainty-aware chain-of-thought and tool-supported fine-grained inspection.
- [RAVEN: An Agentic Framework for Multimodal Entity Discovery from Large-Scale Video Collections](https://arxiv.org/abs/2504.06272): Infers collection themes, dynamically generates entity schemas, and uses schema-guided multimodal extraction so large video libraries become searchable by domain-specific entities and attributes.
- [ViSMaP: Unsupervised Hour-long Video Summarisation by Meta-Prompting](https://arxiv.org/abs/2504.15921): Uses a three-LLM meta-prompting loop to generate, judge, and improve pseudo-summaries from short-clip descriptions, enabling hour-long video summarization without long-video annotations.
- [LiveCC](https://arxiv.org/abs/2504.16030) ([code](https://github.com/showlab/LiveCC)): An understanding and caption/commentary generation pipeline for time-sensitive scenarios such as live sports.
- [MR.Video](https://arxiv.org/abs/2504.16082) ([code](https://github.com/ziqipang/MR-Video)): Organizes long-video understanding as MapReduce-style evidence aggregation, first extracting local evidence by segment and then aggregating globally for reasoning.
- [TimeChat-Online](https://arxiv.org/abs/2504.17343) ([code](https://github.com/yaolinli/TimeChat-Online)): Online interactive video understanding for time-sensitive scenarios, emphasizing online state updates and temporal alignment.
- [VideoMultiAgents: A Multi-Agent Framework for Video Question Answering](https://arxiv.org/abs/2504.20091): A multi-agent framework for video question answering. Core idea: decompose video QA into specialized agents for visual, temporal, and linguistic reasoning before answer synthesis.
- [AVA: Towards Agentic Video Analytics with Vision Language Models](https://arxiv.org/abs/2505.00254): An agentic video-analytics framework with vision-language models. Core idea: turn open-ended video analysis into an adaptable agent workflow rather than a fixed video-understanding task.
- [ViQAgent: Zero-Shot Video Question Answering via Agent with Open-Vocabulary Grounding Validation](https://arxiv.org/abs/2505.15928): A zero-shot VideoQA agent with open-vocabulary grounding validation. Core idea: combine video question answering with grounded evidence checks so the agent can validate visual entities and reduce unsupported answers.
- [Deep Video Discovery](https://arxiv.org/abs/2505.18079) ([code](https://github.com/microsoft/DeepVideoDiscovery)): An agentic search harness for long-video understanding; with multi-granularity video databases and search-centric tools, it lets agents adaptively plan, retrieve segments, and summarize evidence by question.
- [ReAgent-V: A Reward-Driven Multi-Agent Framework for Video Understanding](https://arxiv.org/abs/2506.01300): Video multi-agent harness: reward-driven multi-agent video understanding. Core idea: add feedback and self-correction loops to video reasoning.
- [APVR: Hour-Level Long Video Understanding with Adaptive Pivot Visual Information Retrieval](https://arxiv.org/abs/2506.04953): A retrieval harness for hour-level long-video understanding. Core idea: select adaptive visual pivots so models can reason over long videos without uniform dense sampling.
- [VideoChat-A1](https://arxiv.org/abs/2506.06097): A chain-of-shot reasoning harness for long-video understanding. Core idea: progressively select question-relevant shots and inspect them with coarse-to-fine multimodal reasoning instead of feeding redundant temporal context to the model.
- [MAGNET: A Multi-agent Framework for Finding Audio-Visual Needles by Reasoning over Multi-Video Haystacks](https://arxiv.org/abs/2506.07016): Audio-visual multi-agent harness: multi-agent search over multi-video haystacks. Core idea: coordinate agents to retrieve and reason over many videos.
- [CyberV: Cybernetics for Test-time Scaling in Video Understanding](https://arxiv.org/abs/2506.07971): Agent Harness candidate for video understanding. Core idea: Cybernetics for Test-time Scaling in Video Understanding.
- [VideoDeepResearch](https://arxiv.org/abs/2506.10821) ([code](https://github.com/yhy-2000/VideoDeepResearch)): Organizes "watch video -> retrieve external materials -> generate report" into a reusable long-chain pipeline.
- [AdaVideoRAG](https://arxiv.org/abs/2506.13589) ([code](https://github.com/xzc-zju/AdaVideoRAG)): A long-video RAG harness that adaptively selects hierarchical indexes and retrieval depth by task, reducing waste from fixed frame sampling or fixed chunking strategies.
- [Ego-R1: Chain-of-Tool-Thought for Ultra-Long Egocentric Video Reasoning](https://arxiv.org/abs/2506.13654): A harness for chain-of-tool-thought for ultra-long egocentric video reasoning. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [AViLA: Asynchronous Vision-Language Agent for Streaming Multimodal Data Interaction](https://arxiv.org/abs/2506.18472): Agent Harness candidate for video understanding. Core idea: Asynchronous Vision-Language Agent for Streaming Multimodal Data Interaction.
- [DIVE: Deep-search Iterative Video Exploration A Technical Report for the CVRR Challenge at CVPR 2025](https://arxiv.org/abs/2506.21891): A deep-search iterative video-exploration harness for long-video challenge tasks. Core idea: repeatedly search, inspect, and refine video evidence instead of answering from a fixed frame sample.
- [Flash-VStream](https://arxiv.org/abs/2506.23825) ([code](https://github.com/IVGSZ/Flash-VStream)): A memory-budget harness for streaming long-video understanding, emphasizing memory updates and information fidelity under real-time constraints.
- [Temporal Chain of Thought: Long-Video Understanding by Thinking in Frames](https://arxiv.org/abs/2507.02001): A harness for frame-wise temporal chain-of-thought for long-video reasoning. Core idea: expose workflow logic outside the base model so planning, tool use, memory, verification, recovery, or orchestration can be studied and reused.
- [Interactive Text-to-Video Retrieval via Uncertainty Minimization](https://arxiv.org/abs/2507.15504): turns video retrieval into an interactive uncertainty-reduction workflow.
- [Lava: Language Driven Scalable and Versatile Traffic Video Analytics](https://arxiv.org/abs/2507.19821): Maps flexible natural-language questions over large traffic-camera archives into scalable video analytics, replacing fixed SQL-style semantic categories with language-driven query interpretation.
- [StreamAgent](https://arxiv.org/abs/2508.01875): A streaming-video agent that anticipates future task-relevant intervals and regions; the core idea is to maintain task-driven temporal expectations so the agent can respond proactively instead of only reacting to sampled frames.
- [ROVER: Recursive Reasoning Over Videos with Vision-Language Models for Embodied Tasks](https://arxiv.org/abs/2508.01943): A recursive video-reasoning harness for embodied VLM tasks. Core idea: structure extended camera-frame streams into iterative reasoning steps so an agent can maintain task progress across long visual sequences.
- [VideoForest: Person-Anchored Hierarchical Reasoning for Cross-Video Question Answering](https://arxiv.org/abs/2508.03039): Uses person-anchored hierarchical reasoning for cross-video question answering.
- [Think Before You Segment: An Object-aware Reasoning Agent for Referring Audio-Visual Segmentation](https://arxiv.org/abs/2508.04418): Adds object-aware reasoning to an agent for referring audio-visual segmentation.
- [VSI: Visual Subtitle Integration for Keyframe Selection to enhance Long Video Understanding](https://arxiv.org/abs/2508.06869): Integrates visual subtitles for keyframe selection in long-video understanding.
- [M3-Agent](https://arxiv.org/abs/2508.09736) (code: no stable public official repository found yet): A long-term memory agent for long videos; it decomposes "watch, listen, remember, reason" into interactive modules and pairs with M3-Bench to test memory retention and cross-modal evidence use.
- [Towards Agentic AI for Multimodal-Guided Video Object Segmentation](https://arxiv.org/abs/2508.10572): Uses an LLM to assemble dynamic per-input workflows over specialized low-level multimodal segmentation tools, making referring VOS and audio-visual segmentation training-free and adaptive.
- [NoteIt: A System Converting Instructional Videos to Interactable Notes Through Multimodal Video Understanding](https://arxiv.org/abs/2508.14395): Converts instructional videos into editable interactive notes by extracting hierarchical structure and multimodal key information, then exposing controls for users to customize content and presentation.
- [See What You Need: Query-Aware Visual Intelligence through Reasoning-Perception Loops](https://arxiv.org/abs/2508.17932): A query-aware video reasoning harness built around reasoning-perception loops. Core idea: let the system decide what visual evidence to inspect for the current question instead of processing video uniformly.
- [ChainReaction](https://arxiv.org/abs/2508.21010) ([project page](https://paritoshparmar.github.io/chainreaction/)): A modular causal-reasoning harness for causal-why VideoQA. Core idea: first extract natural-language causal chains from video-question pairs, then answer from those chains, making causal video reasoning more interpretable and easier to evaluate with causality-oriented metrics such as CauCo.
- [CAViAR: Critic-Augmented Video Agentic Reasoning](https://arxiv.org/abs/2509.07680): Adds critic-augmented reasoning to video agents. Core idea: combine video perception with critique and revision to improve complex long-video reasoning.
- [NeuS-QA: Grounding Long-Form Video Understanding in Temporal Logic and Neuro-Symbolic Reasoning](https://arxiv.org/abs/2509.18041): A neuro-symbolic workflow for long-form video QA. Core idea: ground video understanding in temporal logic and structured reasoning instead of uniform frame sampling alone.
- [VideoJudge: Bootstrapping Enables Scalable Supervision of MLLM-as-a-Judge for Video Understanding](https://arxiv.org/abs/2509.21451): A scalable MLLM-as-a-judge harness for video understanding evaluation. Core idea: bootstrap supervision so open-ended video answers can be judged more finely than with text-overlap metrics.
- [FrameThinker](https://arxiv.org/abs/2509.24304): A long-video reasoning harness that lets a model iteratively select salient frames and update its reasoning state; the core idea is to train a frame-spotlighting action policy so long-video QA uses targeted evidence rather than uniform sampling.
- [Perceive, Verify and Understand Long Video: Multi-Granular Perception and Active Verification via Interactive Agents](https://arxiv.org/abs/2509.24943): A long-video agent harness with multi-granular perception and active verification. Core idea: let the agent adaptively inspect, verify, and refine evidence instead of using a fixed frame-sampling pipeline.
- [PANDA](https://arxiv.org/abs/2509.26386): Builds an agentic AI engineer for generalist video anomaly detection with scene-aware strategy planning, optimization, and verification loops.
- [TAMA: Tool-Augmented Multimodal Agent for Procedural Activity Understanding](https://arxiv.org/abs/2510.00161): A tool-augmented multimodal agent for procedural activity understanding. Core idea: combine multimodal perception with external tools so procedural assistants can reason over activities such as cooking, assembly, or laboratory work.
- [VideoLucy: Deep Memory Backtracking for Long Video Understanding](https://arxiv.org/abs/2510.12422): A deep-memory backtracking framework for long-video understanding; core idea: let agents revisit and verify relevant video evidence instead of relying on one-pass summaries.
- [DASR: Distributed Adaptive Scene Recognition - A Multi-Agent Cloud-Edge Framework for Language-Guided Scene Detection](https://doi.org/10.18653/v1/2025.emnlp-industry.57): Contributes an agent workflow, runtime, protocol, tool-use pattern, or multi-agent orchestration approach for video understanding.

Core idea: go beyond frame-level anomaly scores by producing spatial, semantic, and explanatory reasoning about abnormal events.
- [UniVA: Universal Video Agent towards Open-Source Next-Generation Video Generalist](https://arxiv.org/abs/2511.08521): A universal video agent toward an open-source video generalist.
- [GCAgent](https://arxiv.org/abs/2511.08909) (code: no stable public official repository found yet): A graph-compression agent for long videos; it uses graph structures to compress long-video events and entity relations, then locally expands and reasons around the question.
- [Agentic Video Intelligence: A Flexible Framework for Advanced Video Exploration and Understanding](https://arxiv.org/abs/2511.14446): Provides a flexible framework for advanced video exploration and understanding, adding a video-agent harness for interactive evidence search rather than one-pass video QA.

- [LongVT](https://arxiv.org/abs/2511.20785) ([code](https://github.com/EvolvingLMMs-Lab/LongVT)): A native tool-calling and "thinking with long videos" workflow for long videos, often used as an agentic runtime reference for long-video scenarios.

- [VideoSeek](https://arxiv.org/abs/2603.20185): A long-horizon video-agent harness. Core idea: use video logic flow and a multi-granular observation toolkit so the agent actively seeks answer-critical evidence while reading far fewer frames than exhaustive parsing.
- [VideoDetective](https://arxiv.org/abs/2603.22285): A clue-hunting harness for long-video QA; the core idea is to combine query relevance with intrinsic segment affinity and iteratively verify which sparse segments should support the final answer.
- [LensWalk](https://arxiv.org/abs/2603.24558): An agentic video-understanding harness. Core idea: let the reasoner actively choose temporal scope and sampling density through video tools, creating a reason-plan-observe loop that gathers evidence on demand instead of relying on fixed frame preprocessing.
- [VideoTIR: Accurate Understanding for Long Videos with Efficient Tool-Integrated Reasoning](https://arxiv.org/abs/2603.25021): Adds a agent harness for video, centered on VideoTIR: Accurate Understanding for Long Videos with Efficient Tool-Integrated Reasoning.
- [Progressive Video Condensation with MLLM Agent for Long-form Video Understanding](https://arxiv.org/abs/2604.02891): Uses an MLLM agent to progressively condense long videos, supporting long-form video understanding under context limits.
- [QVAD](https://arxiv.org/abs/2604.03040): uses a question-centric agentic workflow for efficient training-free video anomaly detection.
- [AURA: Always-On Understanding and Real-Time Assistance via Video Streams](https://arxiv.org/abs/2604.04184): Adds a agent harness for video, centered on AURA: Always-On Understanding and Real-Time Assistance via Video Streams.
- [G2F-RAG](https://arxiv.org/abs/2604.04372): A training-free video RAG harness that renders retrieved graph evidence back into visual space; the core idea is to use agents to build and retrieve a video knowledge graph, then fuse the selected evidence as an inspectable reasoning frame.
- [SVAgent](https://arxiv.org/abs/2604.05079) (code: not confirmed public): A storyline-guided long-video QA agent; the core idea is to let a storyline agent build narrative state from selected frames, have cross-modal decision agents answer from visual and textual evidence, and use a meta-agent to align conflicting predictions.
- [LOLGORITHM: Funny Comment Generation Agent For Short Videos](https://arxiv.org/abs/2604.09729): Uses a modular short-video comment workflow that summarizes video content, classifies style, retrieves semantic examples and current meme signals, then generates platform-tailored humorous comments.
- [Video-ToC: Video Tree-of-Cue Reasoning](https://arxiv.org/abs/2604.20473): Video reasoning harness: tree-of-cue reasoning over video evidence. Core idea: organize video clues hierarchically during reasoning.
- [UpstreamQA: A Modular Framework for Explicit Reasoning on Video Question Answering Tasks](https://arxiv.org/abs/2604.23145): Contributes a reusable agent workflow or execution harness for video understanding and temporal reasoning.
- [MarkIt: Training-Free Visual Markers for Precise Video Temporal Grounding](https://arxiv.org/abs/2604.25886): A harness for training-free visual markers for precise video temporal grounding. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [ReFineVQA](https://doi.org/10.1109/WACV61042.2026.00738): Iteratively refines video descriptions for video question answering. Core idea: generate feedback over intermediate descriptions so the final answer is grounded in a corrected video narrative.
- [VRAgent](https://doi.org/10.1109/WACV61042.2026.00787): A self-refining agent for zero-shot multimodal video retrieval. Core idea: iteratively improve retrieval queries and evidence checks so video search is not a single-pass embedding match.
- [MACF](https://arxiv.org/abs/2605.00444): A compact latent multi-agent collaboration framework for scalable long-video understanding; the core idea is to split video perception across local agents and let a coordinator combine task-sufficient latent evidence without collapsing the video into text.
- [Video Active Perception: Effective Inference-Time Long-Form Video Understanding with Vision-Language Models](https://arxiv.org/abs/2605.01662): A harness for active frame acquisition for effective inference-time long-form video understanding. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [Response-G1](https://arxiv.org/abs/2605.07575): Uses online query-guided scene graphs, historical graph retrieval, and trigger prompting to decide when a proactive streaming VideoLLM should remain silent or respond.
- [VideoSEAL](https://arxiv.org/abs/2605.12571) (code: no stable public official repository found yet): An evidence-calibration framework for agentic long video understanding; the core idea is to decouple answer generation from evidence alignment/verification, mitigating mismatch between retrieved segments and final answers in long-video agents.
- [ReTool-Video](https://arxiv.org/abs/2605.13228) (code: not confirmed public): A recursive tool-using video agent; the core idea is to ground high-level video intents into executable tool chains over a fine-grained MetaAug-Video Tool Library, repairing or decomposing unmatched actions at runtime.
- [VideoSeeker](https://arxiv.org/abs/2605.16079) (code: the paper says it will be released, but no stable public repository has been confirmed yet): Native agentic tool invocation for video understanding; it emphasizes instance-level tool selection and brings search, grounding, and verification into the model decision process.
- [RAG4VAD](https://doi.org/10.1016/j.ins.2026.123589): uses a training-free retrieval-augmented generation workflow for explainable video anomaly detection.
- [MACD Video Anomaly Detection](https://doi.org/10.1049/sfw2/6947479): uses multi-agent counterfactual dialectics for online video anomaly detection.
- [Accelerating Long Video Understanding via Compressed Scene Graph-Enabled Chain-of-Thought](https://doi.org/10.1145/3746027.3754765): Compresses long videos into scene-graph evidence and feeds that structure into chain-of-thought reasoning, reducing the amount of raw temporal context the downstream VideoQA model must inspect.
- [Towards An Improved Video RAG Workflow With Orchestration Support in A Visual Data Management System](https://doi.org/10.1145/3735654.3735945): Embeds video-RAG orchestration inside a visual data-management system, focusing on how indexing, retrieval, and workflow coordination can be managed as first-class video data operations.
- [VidCog: Empowering LLM with Long Video Understanding via Human-like Temporal Cognitive Loop](https://doi.org/10.1145/3743093.3771043): Uses a human-like temporal cognitive loop for long-video understanding. Core idea: replace fragmented multi-step video reasoning with an iterative loop that controls information gathering and temporal integration.
- [GraphVideoAgent: Enhancing Long-form Video Understanding with Entity Relation Graphs](https://doi.org/10.1145/3746027.3755537): Uses entity-relation graphs to organize long-form video evidence, adding a structured agent workflow for video understanding.
