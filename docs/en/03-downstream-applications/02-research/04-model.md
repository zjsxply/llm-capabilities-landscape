# 3.2.4 Model

- [AlphaSAGE: Structure-Aware Alpha Mining via GFlowNets for Robust Exploration](https://arxiv.org/abs/2509.25055): AlphaSAGE uses a structure-aware relational graph encoder, Generative Flow Networks, and dense multi-faceted rewards to explore formulaic alpha expressions. It aims to mine a diverse, novel, and predictive portfolio of signals, automating quantitative research-side factor discovery rather than operational order execution.
- [PPSGen: Learning to Generate Presentation Slides for Academic Papers](https://www.ijcai.org/Proceedings/13/Abstracts/310.html): PPSGen learns sentence importance with regression and uses integer linear programming to select and align phrases and sentences into slides; the reported evaluation uses 200 paper-slide pairs, providing a concrete pre-LLM extraction-and-optimization approach to paper-to-slide generation.
- [Learning to Generate Posters of Scientific Papers](https://arxiv.org/abs/1604.01219): Learns poster panel structure and attributes from paper-poster pairs with graphical models, then synthesizes each panel composition; the released Poster-Paper dataset makes scientific poster generation measurable.
- [Learning to Generate Posters of Scientific Papers by Probabilistic Graphical Models](https://arxiv.org/abs/1702.06228): Introduces the NJU-Fudan Paper-Poster dataset with exhaustive panel and attribute labels, and combines MAP layout inference with recursive page splitting to test whether generated posters obey design constraints.
- [AI Feynman: a Physics-Inspired Method for Symbolic Regression](https://arxiv.org/abs/1905.11481): AI Feynman recursively exploits symmetry, separability, compositionality, and dimensional structure before neural fitting, recovering all 100 Feynman equations and raising the harder-set success rate from 15% to 90%.
- [DOC2PPT: Automatic Presentation Slides Generation from Scientific Documents](https://arxiv.org/abs/2101.11796): Decomposes document-to-slide generation into hierarchical content selection, paraphrasing, image retrieval, and layout prediction in a sequence-to-sequence model, backed by about 6K document-slide pairs.
- [Towards Topic-Aware Slide Generation for Academic Papers with Unsupervised Mutual Learning](https://doi.org/10.1609/aaai.v35i15.17564): The method mines recurring topics from academic slides, uses a log-linear model to construct pseudo-target distributions, and collaboratively trains two sentence extractors without labeled training targets; labeled test data and human judgments evaluate the resulting paper-to-slide content.
- [AI Descartes: Combining Data and Theory for Derivable Scientific Discovery](https://arxiv.org/abs/2109.01634): AI Descartes combines symbolic regression with logical axioms such as conservation laws, allowing sparse data to distinguish formulas that fit similarly but only one is theoretically derivable.
- [Neural Content Extraction for Poster Generation of Scientific Papers](https://arxiv.org/abs/2112.08550): Isolate the content selection problem of poster generation. First decide which texts, figures and tables should be extracted for each panel, and then hand it over to the subsequent layout and visual organization steps.
- [AI Research Associate for Early-Stage Scientific Discovery](https://arxiv.org/abs/2202.03199): The AI Research Associate searches a minimally biased, invariant-aware ontology for parsimonious hypotheses and compiles them into interpretable tensor graphs that can be trained and tested on sparse noisy observations.
- [Interpretable Machine Learning for Science with PySR and SymbolicRegression.jl](https://arxiv.org/abs/2305.01582): PySR contributes a distributed multi-population evolve--simplify--optimize loop with runtime operator fusion and automatic differentiation, and introduces EmpiricalBench for recovering historical scientific equations.
- [AutomaTikZ](https://arxiv.org/abs/2310.00367): Represent scientific vector graphics as a TikZ program, construct DaTikZ with 120K caption-TikZ drawing pairs, and fine-tune LLaMA and CLiMA that introduce CLIP embedding on DaTikZ.
- [Research about the Ability of LLM in the Tamper-Detection Area](https://arxiv.org/abs/2401.13504): Evaluates how general LLMs handle tamper-detection prompts, distinguishing basic manipulation recognition from harder domain-specific evidence checks for research-integrity use.
- [Reviewer2](https://arxiv.org/abs/2402.10886): Train two models: one generates aspect questions that reviewers may pay attention to, and the other generates corresponding reviews under the conditions of papers and aspect questions, thereby explicitly modeling the distribution of reviewer opinions.
- [MMSR: Symbolic regression is a multi-modal information fusion task](https://arxiv.org/abs/2402.18603):MMSR treats data-to-expression discovery as multimodal fusion, jointly training contrastive alignment with the regression objectives and improving results across mainstream symbolic-regression datasets including SRBench; code is released.
- [Monitoring AI-Modified Content at Scale](https://arxiv.org/abs/2403.07183): Using large-scale corpus and vocabulary signals to monitor the distribution drift of AI rewritten content into scientific writing and peer review.
- [Generalizing the SINDy approach with nested neural networks](https://arxiv.org/abs/2404.15742):Nested SINDy places additional neural layers before and after the SINDy core, expanding equation-discovery expressivity for compositional and multiplicative dynamics while exposing optimization limitations.
- [The Inefficiency of Genetic Programming for Symbolic Regression - Extended Version](https://arxiv.org/abs/2404.17292): Equality saturation collapses expressions into semantically unique structures; exhaustive comparisons on two real datasets show genetic programming explores only a small fraction of them and repeatedly evaluates congruent formulas.
- [OptPDE: Discovering Novel Integrable Systems via AI-Human Collaboration](https://arxiv.org/abs/2405.04484): OptPDE optimizes PDE coefficients to maximize the number of conserved quantities and reports four integrable-PDE families, three new to the authors' knowledge. It analyzes one new family in depth and proposes an AI-human workflow in which machine learning generates interpretable candidates for human verification and analysis.
- [Classifying Scientific Peer Reviews: Distinguishing Authentic, Generic, and AI-Generated Feedback](https://doi.org/10.1109/fmlds67896.2025.00068): Frames peer-review authenticity as a three-way classification task over authentic, generic, and AI-generated feedback, giving academic-integrity systems a peer-review-specific detection problem.
- [Automated novelty evaluation of academic paper: A collaborative approach integrating human and large language model knowledge](https://doi.org/10.1002/asi.70005): Combines human and LLM knowledge for automated academic-paper novelty evaluation, giving research-idea and paper-review systems a scholarly novelty signal.
- [Causality Pursuit from Heterogeneous Environments via Neural Adversarial Invariance Learning](https://arxiv.org/abs/2405.04715): FAIR-NN searches for predictors whose conditional behavior remains invariant across environments by adversarially testing regression solutions; its Gumbel relaxation and stochastic gradient descent-ascent recover quasi-causal variables under stated heterogeneity conditions and are demonstrated on simulated and real data.
- [Multi-objective SINDy for parameterized model discovery from single transient trajectory data](https://arxiv.org/abs/2405.08771):Extends SINDy with soft constraints from fixed points, cycles, quasiperiodic orbits, and chaotic attractors, jointly balancing transient fit, attractor fit, and sparsity to identify parameterized dynamics from fewer transient trajectories.
- [Symmetry-Informed Governing Equation Discovery](https://arxiv.org/abs/2405.16756):Derives equivariance constraints from ODE symmetries and injects them into sparse-regression and genetic-programming discovery, shrinking the equation search space while improving noise robustness and recovery probability across dynamical systems; code is public.
- [Scalable and Flexible Causal Discovery with an Efficient Test for Adjacency](https://arxiv.org/abs/2406.09177): Introduces the Differentiable Adjacency Test, which replaces exponentially many conditional-independence tests for graph adjacency with a provably equivalent relaxed problem solved by two neural networks; DAT-Graph handles observational and interventional data, learns 1,000-variable graphs with state-of-the-art accuracy, and supports more accurate intervention-effect prediction on large-scale RNA-sequencing data.
- [A hybrid method for structural-parametric identification of dynamic systems](https://doi.org/10.17212/2782-2001-2025-2-111-122): GP-SINDy first uses genetic programming to determine differential-equation structure from observations and then applies sparse identification to estimate parameters; tests on three dynamic systems report models with high accuracy and low complexity.
- [ARGUABLY @ AI Debater-NLPCC 2021 Task 3: Argument Pair Extraction from Peer Review and Rebuttals](https://doi.org/10.1007/978-3-030-88483-3_48): Improves argument-pair extraction between peer-review criticisms and author rebuttals by combining ERNIE 2.0 token representations with double attention for long-range dependencies, reporting an 8.81% relative F1 gain over the NLPCC shared-task multi-task baseline.
- [NeurReview: A Neural Architecture Based Conformity Prediction of Peer Reviews](https://doi.org/10.1109/access.2022.3224019): Models review structure and reviewer-author interactions to predict whether an individual review conforms to its meta-review, using two ICLR-derived datasets and features such as cross-review divergence and sentiment-score consistency to flag misaligned reviews.
- [The Quality Assist: A Technology-Assisted Peer Review Based on Citation Functions to Predict the Paper Quality](https://doi.org/10.1109/access.2022.3225871): Predicts acceptance, paper quality, and review scores from citation-function labels, non-citation sentence features, and reference sources without using reviewer comments; on ICLR 2017-2020 data it reaches 0.75 quality-classification accuracy and 0.99 recall for good papers.
- [ElicitationGPT: Text Elicitation Mechanisms via Language Models](https://arxiv.org/abs/2406.09363): ElicitationGPT scores free-form textual reports by querying a black-box ChatGPT to turn text information into forecast scores, obtaining a theoretically proper mechanism and testing human-preference alignment on peer reviews rather than relying on domain-specific manual rubrics.
- [Automated Peer Reviewing in Paper SEA](https://arxiv.org/abs/2407.12857): First standardize multiple review formats, then use standardized data to fine-tune the model to generate constructive reviews, and use mismatch scores to support self-correction; it is different from the focus prompts of Reviewer2, and the focus is to organize the chaotic real review text into a unified supervision format.
- [Simplifying Scholarly Abstracts for Accessible Digital Libraries Using Language Models](https://arxiv.org/abs/2408.03899): Uses language models to rewrite scholarly abstracts for accessible digital libraries, treating abstract simplification as a document-transformation step in scholarly communication workflows.
- [Active Symbolic Discovery of Ordinary Differential Equations via Phase Portrait Sketching](https://arxiv.org/abs/2409.01416):APPS sketches an informative phase-space region before sampling a batch of initial conditions, reducing the data burden caused by chaotic trajectory divergence. Extensive experiments show that this active acquisition strategy discovers more accurate ODE expressions than baselines trained on passively collected datasets.
- [Constraining genetic symbolic regression via semantic backpropagation](https://arxiv.org/abs/2409.07369):Adds semantic backpropagation to gene-expression programming so domain constraints can propagate as corrective feedback through expression trees, improving physically consistent equation recovery and noise robustness on Feynman-style discovery tasks.
- [Extracting Affect Aggregates from Longitudinal Social Media Data with Temporal Adapters for Large Language Models](https://arxiv.org/abs/2409.17990): Fine-tunes Temporal Adapters for Llama 3 8B on full timelines from a panel of British Twitter users and applies established questionnaires to extract longitudinal emotion and attitude aggregates. For the early COVID-19 period, several collective-emotion estimates show strong positive, significant correlations with representative British surveys, remain robust across training seeds and prompt formulations, and align with a labeled-data classifier.
- [Causal Inference with Generative Artificial Intelligence: Application to Texts as Treatments*](https://arxiv.org/abs/2410.00903): GenAI-Powered Inference uses an LLM's internal representation of text treatments instead of learning a causal representation from scratch, proves identification and double-machine-learning properties, avoids a key overlap failure, and improves estimates in simulations and Llama 3 text experiments.
- [Text2Chart31: Instruction Tuning for Chart Generation with Automatic Feedback](https://arxiv.org/abs/2410.04064): Text2Chart31 provides 11.1K description-code-table-plot tuples across 31 Matplotlib chart types and uses automatic-feedback reinforcement-learning instruction tuning to improve complex chart generation without human feedback.
- [‘Quis custodiet ipsos custodes?’ Who will watch the watchmen? On Detecting AI-generated peer-reviews](https://arxiv.org/abs/2410.09770):The paper proposes a token-frequency detector and a review-regeneration detector for identifying ChatGPT-written peer reviews, then stress-tests them against token attacks and paraphrasing. A defensive strategy reduces paraphrase effects; RR is more robust, while TF is stronger without attacks, and the code, dataset, and model are released.
- [Symmetry Discovery for Different Data Types](https://arxiv.org/abs/2410.09841): LieSD discovers continuous symmetries from a trained input-output map by solving the Lie-algebra space from inputs, outputs, and gradients; it extends to multichannel and tensor data and identifies the correct basis count across four symmetry-bearing task families without group sampling.
- [Almost-Linear RNNs Yield Highly Interpretable Symbolic Codes in Dynamical Systems Reconstruction](https://arxiv.org/abs/2410.14240):AL-RNNs learn parsimonious piecewise-linear dynamical representations from time series and yield symbolic encodings that preserve topological properties, recovering minimal forms for Lorenz and Rossler systems and interpretable codes on empirical data.
- [On uniqueness in structured model learning](https://arxiv.org/abs/2410.22009): With full noiseless measurements, the proposed regularization identifies a unique missing model component as the PDE's regularization-minimizing solution; with incomplete noisy data, parameterized neural components converge to that solution under stated network conditions.
- [CycleResearcher: Improving Automated Research via Automated Review](https://arxiv.org/abs/2411.00816): Post-trains open-source LLMs for the full research-and-review cycle; CycleResearcher drafts and revises papers, CycleReviewer simulates peer review, and Review-5k plus Research-14k turn reviewer feedback into iterative reinforcement-learning signals.
- [Rethinking Scale: The Efficacy of Fine-Tuned Open-Source LLMs in Large-Scale Reproducible Social Science Research](https://arxiv.org/abs/2411.00890): Fine-tuned small open LLMs match or exceed ChatGPT-4 on large-scale social-science text classification; the study also measures how training-set size changes gains and uses those results to motivate a privacy-preserving hybrid workflow.
- [Symbolic regression via MDLformer-guided search: from minimizing prediction error to minimizing description length](https://arxiv.org/abs/2411.03753):SR4MDL trains MDLformer to estimate description length and uses it as a monotonic search objective, recovering about 50 formulas across 133 benchmark problems and generalizing to 122 unseen black-box problems.
- [Learning interpretable network dynamics via universal neural symbolic regression](https://arxiv.org/abs/2411.06833):Combines neural fitting with pretrained symbolic regression to infer interpretable network-dynamics equations, testing the tool across more than ten physics, biochemistry, ecology, and epidemiology scenarios rather than a single domain case.
- [TRENDy: Temporal Regression of Effective Non-linear Dynamics](https://arxiv.org/abs/2412.03496):TRENDy cascades multiscale filters before fitting a neural ODE whose parameter space matches the unknown input PDE, making low-dimensional effective dynamics robust to noisy data. It automatically locates Turing and Hopf bifurcations on synthetic and real datasets and uses ocellated-lizard patterning as a real scientific analysis case, showing a reusable route from observations to interpretable dynamical hypotheses.
- [OpenReviewer: A Specialized Large Language Model for Generating Critical Scientific Paper Reviews](https://arxiv.org/abs/2412.11948): Fine-tunes Llama-OpenReviewer-8B on 79,000 expert reviews and wraps it in a PDF-to-review pipeline that extracts full paper content before producing template-constrained critical reviews.
- [Learning to Generate Research Idea with Dynamic Control](https://arxiv.org/abs/2412.14626): Trains controllable research-idea generation rather than leaving ideation to static prompting. Core idea: use dynamic control signals during generation so novelty, feasibility, and topical constraints can be adjusted as the idea is formed.
- [Tests for model misspecification in simulation-based inference: from local distortions to global model checks](https://arxiv.org/abs/2412.15100): Model misspecification is reframed as many hypothesis tests over controlled simulator distortions, linking anomaly detection, validation, and residual goodness-of-fit; a self-calibrating training algorithm is demonstrated on synthetic scenarios and gravitational-wave event GW150914.
- [Noise-Resilient Symbolic Regression with Dynamic Gating Reinforcement Learning](https://arxiv.org/abs/2501.01085): NRSR learns symbolic-selection policies with a dynamic gating module that filters high-noise signals and a mixed-path-entropy bonus that improves exploration, outperforming popular symbolic-regression baselines on noisy and clean benchmarks.
- [SpaceTime: Causal Discovery from Non-Stationary Time Series](https://arxiv.org/abs/2501.10235): SPACETIME combines MDL scoring, nonparametric functional models, and kernel discrepancy tests to jointly infer causal graphs, mechanism changepoints, and invariant context groups from nonstationary multi-context time series.
- [Citation recommendation based on argumentative zoning of user queries](https://arxiv.org/abs/2501.18292): Builds a multi-task model that jointly recommends citations and classifies argumentative zones in the user's citing sentence; a new PubMed Central corpus annotated under an argumentative-zoning schema shows that modeling rhetorical intent improves citation recommendation over ignoring the sentence's role.
- [SyMANTIC: An Efficient Symbolic Regression Method for Interpretable and Parsimonious Model Discovery in Science and Beyond](https://arxiv.org/abs/2502.03367): SyMANTIC is a broadly reusable symbolic-regression method for interpretable model discovery in science and beyond.
- [Was Tournament Selection All We Ever Needed? A Critical Reflection on Lexicase Selection](https://arxiv.org/abs/2502.18093): Across noisy synthetic and real symbolic-regression problems, down-sampling improves generalization and reduces code growth; tournament selection with down-sampling performs similarly to epsilon-lexicase but runs significantly faster.
- [DeepReview](https://arxiv.org/abs/2503.08569): Use DeepReview-13K to train DeepReviewer-14B, so that the review process explicitly includes structured analysis, literature retrieval and evidence-based argumentation; it is similar to ReviewAgents in learning human-style in-depth review, but puts more emphasis on organizing the review reasoning process into a long chain that can be supervised.
- [GraphEval](https://arxiv.org/abs/2503.12600): Split complex research ideas into opinion graphs, and then propagate evaluation signals on nodes and edges; the label propagation version turns idea review into a quality propagation problem on the graph structure.
- [Neural-Guided Equation Discovery](https://arxiv.org/abs/2503.16953): Reviews neural-guided equation-discovery methods through MGMT, a modular grammar-guided Monte Carlo tree-search system. Experiments compare seven tabular-data encoders, find supervised learning usually stronger than reinforcement learning, and show that grammar-rule actions plus risk-seeking or AmEx search improve on token-level actions.
- [OmniScience: A Domain-Specialized LLM for Scientific Reasoning and Discovery](https://arxiv.org/abs/2503.17604): Builds a scientific reasoning model through literature-adaptive pretraining, science-task instruction tuning, and reasoning distillation, then evaluates it on general-science and battery-discovery tasks.
- [Structuring Scientific Innovation: A Framework for Modeling and Discovering Impactful Knowledge Combinations](https://arxiv.org/abs/2503.18865): The framework learns which method combinations distinguish historically disruptive work and uses reasoning-guided Monte Carlo search to propose promising recombinations for a new research problem.
- [ScholarCopilot: Training Large Language Models for Academic Writing with Accurate Citations](https://arxiv.org/abs/2504.00824): ScholarCopilot jointly trains academic generation and citation retrieval on 500K arXiv papers: a generated [RET] token decides when to query a scholarly database, letting a 7B model write with contextually matched references instead of relying on fixed RAG prompting.
- [DUE: A Deep Learning Framework and Library for Modeling Unknown Equations](https://arxiv.org/abs/2504.10373):DUE packages a deep-learning framework and open-source library for learning unknown ODEs, PDEs, DAEs, IDEs, SDEs, and partially observed dynamics, while also supporting surrogate modeling of costly known equations; its cross-domain examples make equation discovery reusable research software.
- [Physics Informed Constrained Learning of Dynamics from Static Data](https://arxiv.org/abs/2504.12675): Balances governing-equation constraints against observed data through message-passing optimization, allowing first-order dynamics to be inferred from static or partially observed samples; experiments recover nonlinear physical dependencies and outperform existing estimators on metabolic flux analysis.
- [HypoGen](https://arxiv.org/abs/2504.12976): Evaluates scientific hypothesis generation from structured paper data. Core idea: convert paper-derived problems, conventional assumptions, conceptual flips, and hypotheses into a conditional generation task with explicit reasoning traces.
- [OpenReviewer](https://aclanthology.org/2025.naacl-demo.44): Fine-tuning Llama-3.1-8B-Instruct with ~79K high-confidence expert reviews to make the model learn structured, critical, and meeting templates to follow.
- [REMOR](https://arxiv.org/abs/2505.11718): Uses reasoning LLMs and multi-objective reinforcement learning to generate peer reviews aligned with multiple review-quality dimensions.
- [CALM: Co-evolution of Algorithms and Language Model for Automatic Heuristic Design](https://arxiv.org/abs/2505.12285): A co-evolution harness for automatic heuristic design. Core idea: evolve algorithms and language-model proposals together so heuristic search becomes an agentic discovery loop.
- [TruthHypo / Toward Reliable Scientific Hypothesis Generation](https://arxiv.org/abs/2505.14599): Training hypothesis truth and hallucination detectors to enable generative systems to filter weakly supported alternatives with learnable reliability signals.
- [CHIMERA](https://arxiv.org/abs/2505.20779): Builds a knowledge base of scientific idea recombinations by defining a recombination-extraction task, fine-tuning an LLM extractor, and using the mined structure to train hypothesis-generation models that propose cross-disciplinary directions.
- [Leveraging GANs for citation intent classification and its impact on citation network analysis](https://arxiv.org/abs/2505.21162): A compact GAN-based citation-intent classifier is evaluated as a scholarly-impact analysis model, and the study shows that filtering citation types can materially change citation-network centrality rankings.
- [A VLM-Based Method for Visual Anomaly Detection in Robotic Scientific Laboratories](https://arxiv.org/abs/2506.05405): Uses vision-language models to monitor robotic laboratory scenes for abnormal states, making visual anomaly detection a model-side safety signal for automated experimental facilities.
- [Sparse Interpretable Deep Learning with LIES Networks for Symbolic Regression](https://arxiv.org/abs/2506.08267):LIES combines interpretable primitive activations, oversampling, a sparsity-oriented loss, and post-training pruning to extract compact formulas, outperforming baselines on symbolic-regression benchmarks.
- [HypER](https://arxiv.org/abs/2506.12937): Train small models to distinguish between valid and invalid literature-grounded inference chains, and improve hypothesis generation with sourced inference supervision. Although it is oriented towards hypothesis generation, it is also suitable for scientific research QA: the model needs to learn which type of natural language evidence chain actually supports the answer, rather than just learning the citation format.
- [Model Specification Search in Correlated Factor Models Using Bee Swarm Optimization](https://doi.org/10.1080/10705511.2025.2612170): Uses bee swarm optimization to search correlated-factor measurement models by jointly selecting factor dimensionality and items; simulations vary correlations, cross-loadings, noise items, and structural complexity to test recovery and derive hyperparameter recommendations.
- [LazyReview](https://aclanthology.org/2025.acl-long.165): Build lazy-thinking data through expert annotation and silver annotation, and use instruction fine-tuning to improve the model's ability to identify fine-grained lazy thinking.
- [PAP2PAT](https://aclanthology.org/2025.findings-acl.496): Use outline-guided chunk-based generation to solve the problem of over-long generation from papers to patent descriptions.
- [DeepReview](https://aclanthology.org/2025.acl-long.1420): Build DeepReview-13K to capture intermediate steps such as structured analysis, literature retrieval, and evidence-based argumentation, and then train DeepReviewer.
- [Leveraging Generative Artificial Intelligence for Causal Inference with Unstructured Data](https://arxiv.org/abs/2507.03897): GenAI-Powered Inference uses open-source language and diffusion models without fine-tuning to generate text or images and extract guaranteed structure-capturing low-dimensional representations; downstream machine learning estimates causal effects with uncertainty and supports prediction across censorship, image-feature, and political-rhetoric applications.
- [GUIDE](https://arxiv.org/abs/2507.08870): Use research idea evaluation samples to supervise and fine-tune the suggestion model, and then select high-quality suggestions based on manual scoring distribution similarity and text similarity to continue training; it is different from the work of directly predicting paper scores, and the real scores are mainly used to train "how to provide modification suggestions for ideas".
- [Automated Novelty Evaluation of Academic Paper](https://arxiv.org/abs/2507.11330): Use human knowledge and large language model knowledge to assist the model in predicting the method novelty of academic papers; it is different from CHIMERA's recombination extraction, and the training goal is to determine whether the paper method forms a new technical combination.
- [Trustworthy scientific inference with generative models](https://arxiv.org/abs/2508.02602): Frequentist-Bayes reshapes AI-generated posteriors into locally valid confidence regions, providing interpretable coverage diagnostics and minimum-size guarantees under train-target alignment; demonstrations span shifted-source identification, competing theories, and biased observations.
- [ReviewRL: Towards Automated Scientific Review with RL](https://arxiv.org/abs/2508.10308): A retrieval-augmented harness for automated scientific review. Core idea: combine ArXiv-MCP context generation with review optimization for factual and analytical feedback.
- [Improving the Accuracy of Amortized Model Comparison with Self-Consistency](https://arxiv.org/abs/2508.20614): Adds a self-consistency loss on unlabeled real data to four amortized Bayesian model-comparison estimators, then compares closed-world and misspecified open-world behavior on one artificial and two real case studies against analytic or bridge-sampling references.
- [Table2LaTeX-RL](https://arxiv.org/abs/2509.17589): Convert table images to LaTeX code as a multimodal generation task, trained with GRPO and dual rewards: one reward evaluates the LaTeX structure, and the other reward evaluates the visual fidelity of the rendered results.
- [Adaptive L1 Regularization for Neural Network-Based Symbolic Regression](https://doi.org/10.1109/cec65147.2025.11042914): Replaces Equation Learner's abrupt two-stage sparsification schedule with L1adapt, which continuously adjusts the L1 penalty from the model's current prediction accuracy as training proceeds. The gradual constraint avoids a discrete switch from accuracy fitting to pruning and lets the differentiable symbolic-regression network trade equation fidelity against structural simplicity throughout training.
- [Probabilistic Symbolic Regression for Equation Discovery via Operator-induced and Regularized Symbolic Forests](https://arxiv.org/abs/2509.19710): Represents expressions as ensembles of symbolic trees, controls topology with a complexity prior, and summarizes model uncertainty with Occam's window. It proves posterior concentration for arbitrarily good symbolic approximations, a near-parametric rate for exact finite formulas, and oracle concentration under misspecification; experiments report predictive accuracy, complexity control, structural recovery, and materials descriptor formulas.
- [AI-Noether](https://arxiv.org/abs/2509.23004): Introduces an abductive-inference system that proposes axiom-system corrections to align AI-derived scientific laws with canonical theory.
- [Scaling Generalist Data-Analytic Agents](https://arxiv.org/abs/2509.25084): Introduces DataMind for training open-source generalist data-analysis agents. Core idea: synthesize diverse data-analysis tasks with an easy-to-hard taxonomy, knowledge-augmented generation, and stable code-based multi-turn rollouts so agents can handle large heterogeneous files and long workflows.
- [Expert Credibility Prediction Model Based on Fuzzy C-Means Clustering and Similarity Association](https://doi.org/10.1109/tfuzz.2025.3574947): Predicts reviewer credibility for scientific and technological evaluation by clustering expert attributes with fuzzy C-means, selecting features through recursive elimination, deriving expert-association features with Gower distance, and training a feedforward network on a real-world expert-credibility dataset.
- [NAIPv2](https://arxiv.org/abs/2509.25179): Trains a debiased pairwise paper-quality estimator from domain-year comparison groups and reviewer-tendency signals.
- [Presenting a Paper is an Art: Self-Improvement Aesthetic Agents for Academic Presentations](https://arxiv.org/abs/2510.05571): EvoPresent uses PresAesth, a multi-task RL aesthetic model for scoring, defect adjustment, and comparison, and evaluates self-improvement on a 650-paper presentation set plus 2,000 aesthetic slide pairs.
- [Foundation Inference Models for Equation Discovery](https://arxiv.org/abs/2510.12618): Targets fast coarse-graining and equation discovery with foundation inference models, adding a scientific-modeling route for automated research.
- [ReviewGuard: Enhancing Deficient Peer Review Detection via LLM-Driven Data Augmentation](https://arxiv.org/abs/2510.16549): ReviewGuard combines human-validated GPT-4.1 labels, synthetic review augmentation, and fine-tuning to detect deficient peer reviews; mixed real and synthetic data raises Qwen3-8B recall from 0.5499 to 0.6653 and F1 from 0.5606 to 0.7073.
- [AutoSciDACT: Automated Scientific Discovery through Contrastive Embedding and Hypothesis Testing](https://arxiv.org/abs/2510.21935): AutoSciDACT combines contrastive representations learned from simulated science data with the New Physics Learning Machine two-sample test, turning novelty detection into a pipeline that can attach statistical claims to anomalies.
- [Practical Author Name Disambiguation under Metadata Constraints: A Contrastive Learning Approach for Astronomy Literature](https://arxiv.org/abs/2511.10722): NAND reframes author-name disambiguation as Siamese similarity learning using only author names, titles, and abstracts, avoiding the email, venue, and affiliation metadata that many prior systems require. Its ORCID-linked physics dataset supports realistic evaluation, reaching up to 94% pairwise accuracy and over 95% clustering F1, directly automating scholarly-record curation.
- [SemanticCite](https://arxiv.org/abs/2511.16198): Model citation verification as full-text evidence support classification, train or fine-tune the lightweight Qwen3 model to complete claim extraction/refinement and support checking, and output Supported, Partially Supported, Unsupported, Uncertain.
- [SciPostGen: Bridging the Gap between Scientific Papers and Poster Layouts](https://arxiv.org/abs/2511.22490): SciPostGen links paper structure to poster element counts and releases a large paired corpus; its retrieval-augmented layout generator retrieves structurally compatible posters before applying creator constraints.
- [Semantic Reconstruction of Adversarial Plagiarism: A Context-Aware Framework for Detecting and Restoring "Tortured Phrases" in Scientific Literature](https://arxiv.org/abs/2512.10435): Detects and reconstructs adversarially paraphrased "tortured phrases" by using local scientific context to restore likely original terminology.
- [LLM as a Neural Architect: Controlled Generation of Image Captioning Models Under Strict API Contracts](https://arxiv.org/abs/2512.14706): Builds an LLM-guided neural-architecture generation pipeline that composes CNN encoders and sequence decoders under strict API contracts to produce runnable image-captioning models.
- [Training AI Co-Scientists Using Rubric Rewards](https://arxiv.org/abs/2512.23707): Trains AI co-scientist models with rubric rewards, making scientific research assistance a domain-specific model-training target.
- [From Memorization to Creativity: LLM as a Designer of Novel Neural-Architectures](https://arxiv.org/abs/2601.02997): Uses an LLM to design novel neural architectures, treating model-design creativity as a scientific generation problem rather than ordinary architecture search.
