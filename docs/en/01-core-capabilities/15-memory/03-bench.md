# 1.15.3 Bench

- [TREC iKAT 2023: The Interactive Knowledge Assistance Track Overview](https://arxiv.org/abs/2401.01330): Evaluates interactive knowledge assistants that must maintain user context, reformulate information needs, retrieve evidence, and answer across conversational turns.
- [LOCOMO](https://arxiv.org/abs/2402.17753) ([code](https://github.com/snap-research/locomo)): What it evaluates: very long-term dialogue memory. Core idea: treat facts, preferences, and events in multi-session dialogue as retrieval targets, evaluating whether agents can use historical information consistently over long periods.
- [TAXI: Evaluating Categorical Knowledge Editing for Language Models](https://arxiv.org/abs/2404.15004): Evaluates categorical knowledge editing, testing whether edits propagate across class-level relations while preserving unrelated model knowledge.
- [UnSeenTimeQA: Time-Sensitive Question-Answering Beyond LLMs' Memorization](https://arxiv.org/abs/2407.03525): Tests time-sensitive QA on facts that change after model pretraining, separating live temporal reasoning from memorized parametric knowledge.
- [MemSim](https://arxiv.org/abs/2409.20163) ([code](https://github.com/nuster1128/MemSim)): What it evaluates: memory behavior in LLM-based personal assistants. Core idea: use a Bayesian simulator to make memory updates, retrieval, and personalized assistant behavior measurable under controlled interaction histories.
- [Assessing Episodic Memory in LLMs with Sequence Order Recall Tasks](https://arxiv.org/abs/2410.08133): Uses sequence-order recall tasks to diagnose whether LLMs preserve episodic order, not just item-level content, under controlled prompt histories.
- [LongMemEval](https://arxiv.org/abs/2410.10813): What it evaluates: memory question answering in long dialogue and personal assistant scenarios. Core idea: split long histories into local facts, global preferences, and cross-time reasoning questions to test whether models or memory systems can locate and combine relevant memories from lengthy interactions.
- [FAME: Towards Factual Multi-Task Model Editing](https://arxiv.org/abs/2410.10859): Benchmarks factual model editing across multiple task formats, measuring whether edited knowledge remains accurate, consistent, and localized.
- [SHARE: Shared Memory-Aware Open-Domain Long-Term Dialogue Dataset Constructed from Movie Script](https://arxiv.org/abs/2410.20682): Builds a long-term dialogue dataset from movie scripts where shared character memories must be tracked and reused in open-domain conversation.
- [Unraveling the Complexity of Memory in RL Agents: an Approach for Classification and Evaluation](https://arxiv.org/abs/2412.06531): Classifies memory demands in RL settings and evaluates agents by the type of temporal information they must retain for later decisions.
- [MemHunter: Automated and Verifiable Memorization Detection at Dataset-scale in LLMs](https://arxiv.org/abs/2412.07261): Detects training-data memorization at dataset scale with automated, verifiable probes rather than relying on hand-picked extraction examples.
- [Episodic Memories Generation and Evaluation Benchmark](https://arxiv.org/abs/2501.13121): Evaluates LLM episodic-memory generation, making memory construction itself a measurable benchmark target.
- [Minerva: A Programmable Memory Test Benchmark for Language Models](https://arxiv.org/abs/2502.03358): automatically generates interpretable tests for how language models use context memory, covering search, recall, editing, matching, comparison, and state maintenance.
- [REALTALK: A 21-Day Real-World Dataset for Long-Term Conversation](https://arxiv.org/abs/2502.13270): A 21-day real-world long-term conversation dataset; core idea: evaluate whether memory systems retain and reuse facts, preferences, and events across realistic multi-day interaction rather than a single packed context.
- [Quantifying Memorization and Parametric Response Rates in Retrieval-Augmented Vision-Language Models](https://arxiv.org/abs/2502.13836): Measures when retrieval-augmented vision-language models answer from parametric memory instead of retrieved visual evidence.
- [PersonaBench: Evaluating AI Models on Understanding Personal Information through Accessing (Synthetic) Private User Data](https://arxiv.org/abs/2502.20616): Evaluates use of synthetic private user data for personal-information understanding.
- [Investigating Memory in RL with POPGym Arcade](https://arxiv.org/abs/2503.01450): Uses POPGym Arcade partially observable games to stress RL agents' observation memory, state tracking, and delayed-dependency handling.
- [Interpersonal Memory Matters: A New Task for Proactive Dialogue Utilizing Conversational History](https://arxiv.org/abs/2503.05150): Evaluates proactive dialogue with long-term conversational memory. Core idea: make agents use implicit user attributes and preferences from history instead of steering only toward fixed keywords.
- [Toward Multi-Session Personalized Conversation: A Large-Scale Dataset and Hierarchical Tree Framework for Implicit Reasoning](https://arxiv.org/abs/2503.07018): A dataset and hierarchical framework for multi-session personalized conversation; core idea: evaluate whether agents infer and reuse implicit user state across sessions.
- [Can Memory-Augmented Language Models Generalize on Reasoning-in-a-Haystack Tasks?](https://arxiv.org/abs/2503.07903): Evaluates agent and model memory. Core idea: use the paper's task, dataset, or protocol around can memory-augmented language models generalize on reasoning-in-a-haystack tasks? to make this capability more comparable.
- [Leaking LoRa: An Evaluation of Password Leaks and Knowledge Storage in Large Language Models](https://arxiv.org/abs/2504.00031): Evaluates whether LoRA adaptation stores and leaks password-like secrets, treating memorized credentials as a measurable safety failure.
- [Strong Memory, Weak Control: An Empirical Study of Executive Functioning in LLMs](https://arxiv.org/abs/2504.02789): Tests executive-control failures in LLMs by contrasting strong recall with inhibition, updating, and control tasks.
- [Know Me, Respond to Me: Benchmarking LLMs for Dynamic User Profiling and Personalized Responses at Scale](https://arxiv.org/abs/2504.14225): Evaluates dynamic user profiling and personalized responses from interaction history. Core idea: make this capability comparable through a defined task set, protocol, or scoring interface.
- [On the Feasibility of In-Context Probing for Data Attribution](https://doi.org/10.18653/v1/2025.findings-naacl.286): Evaluates whether in-context probes can attribute outputs to training data, using attribution behavior as an indirect memorization signal.
- [Latent State Persistence](https://arxiv.org/abs/2505.10571): What it evaluates: whether LLMs can maintain hidden internal state across independent queries. Core idea: use controlled games and sequence tasks to expose failures in persistent working memory that are not visible in single-prompt reasoning tests.
- [EdgeWisePersona: A Dataset for On-Device User Profiling from Natural Language Interactions](https://arxiv.org/abs/2505.11417): Supplies natural-language interaction data for on-device user profiling, testing how local systems infer and preserve persona attributes.
- [Real-world Knowledge Injection Benchmark](https://arxiv.org/abs/2505.12306): Evaluates how language models memorize and incorporate newly injected real-world knowledge.
- [UniEdit: A Unified Knowledge Editing Benchmark for Large Language Models](https://arxiv.org/abs/2505.12345): Provides a unified benchmark for LLM knowledge editing, evaluating whether model updates are correct, localized, and reusable.
- [DIAMONDs: A Dataset for Dynamic Information And Mental modeling Of Numeric Discussions](https://arxiv.org/abs/2505.12651): A benchmark for dynamic information and mental-state tracking in numeric multiparty discussions. Core idea: test whether models can maintain who knows what, when values change, and which facts are relevant across extended conversation.
- [How Memory Management Impacts LLM Agents: An Empirical Study of Experience-Following Behavior](https://arxiv.org/abs/2505.16067): An empirical study of experience-following behavior under different memory-management choices; core idea: measure when stored experience stabilizes later actions and when it causes brittle reuse.
- [Benchmarking and Rethinking Knowledge Editing for Large Language Models](https://arxiv.org/abs/2505.18690): Benchmarks LLM knowledge editing across fact-level and event-level settings. Core idea: evaluate whether model knowledge can be updated consistently rather than only patched on isolated facts.
- [How much do language models memorize?](https://arxiv.org/abs/2505.24832): Provides a reusable evaluation target, leaderboard, or measurement protocol for memory.
- [LaMP-QA: A Benchmark for Personalized Long-form Question Answering](https://arxiv.org/abs/2506.00137): A benchmark for personalized long-form question answering; core idea: require answers to use user-specific history and preferences, making persistent memory part of answer quality.
- [ThinkEval: Practical Evaluation of Knowledge Preservation and Consistency in LLM Editing with Thought-based Knowledge Graphs](https://arxiv.org/abs/2506.01386): Evaluates knowledge preservation and consistency in LLM editing with thought-based knowledge graphs.
- [FictionalQA: A Dataset for Studying Memorization and Knowledge Acquisition](https://arxiv.org/abs/2506.05639): Uses fictional facts and QA pairs to separate genuine knowledge acquisition from prior memorization of real-world entities.
- [PersonaFeedback: A Large-scale Human-annotated Benchmark For Personalization](https://arxiv.org/abs/2506.12915): A human-annotated personalization benchmark. Core idea: evaluate whether systems tailor responses to user personas and preferences, connecting response quality with persistent user modeling.
- [StoryBench: A Dynamic Benchmark for Evaluating Long-Term Memory with Multi Turns](https://arxiv.org/abs/2506.13356): Adds a benchmark or evaluation suite for memory, centered on StoryBench: A Dynamic Benchmark for Evaluating Long-Term Memory with Multi Turns.
- [MemBench](https://arxiv.org/abs/2506.21605) ([code](https://github.com/import-myself/Membench)): What it evaluates: episodic, semantic, and procedural memory in LLM-based agents. Core idea: separately model "participatory memory" and "observational memory", and introduce large-scale noisy conversations to test long-term memory retrieval.
- [Evaluating the Long-Term Memory of Large Language Models](https://doi.org/10.18653/v1/2025.findings-acl.1014): Evaluates long-term memory in large language models.
- [MemoryAgentBench](https://arxiv.org/abs/2507.05257) ([code](https://github.com/HUST-AI-HYZ/MemoryAgentBench)): What it evaluates: memory writing, updating, and recall in multi-turn incremental interaction. Core idea: do not put all history into the prompt at once; instead, provide information gradually as an interaction stream and test whether the memory module can evolve with state.

Core idea: evaluate whether agents can gather user-relevant evidence and adapt responses through feedback rather than static preference prompts.
- [MEMTRACK](https://arxiv.org/abs/2510.01353): What it evaluates: long-term memory and state tracking in multi-platform agent environments. Core idea: interleave events across Slack, Linear, Git, files, and code contexts to test memory acquisition, selection, conflict resolution, efficiency, and redundancy.

- [MemEye](https://arxiv.org/abs/2605.15128): Evaluates visual-centric multimodal agent memory. Core idea: stratify tasks by decisive visual-evidence granularity from scene level to pixel level and by evidence-use pattern from single evidence to evolutionary synthesis, then use validation gates for answerability, shortcut resistance, visual necessity, and reasoning structure across eight life-scenario tasks.
- [Is One Score Enough? Rethinking the Evaluation of Sequentially Evolving LLM Memory](https://arxiv.org/abs/2605.15384): Adds a benchmark or evaluation suite for memory, centered on Is One Score Enough? Rethinking the Evaluation of Sequentially Evolving LLM Memory.
- [SMMBench](https://arxiv.org/abs/2605.15710): Evaluates source-distributed multimodal agent memory. Core idea: require agents to retrieve, align, resolve conflicts, and act on evidence scattered across conversations, profiles, screenshots, tables, images, and documents.
- [EvoMemBench](https://arxiv.org/abs/2605.18421) ([code](https://github.com/DSAIL-Memory/EvoMemBench)): What it evaluates: self-evolution capability of agent memory. Core idea: divide memory tasks by `in-episode / cross-episode` x `knowledge / execution` to evaluate memory strategies more systematically.
- [MINTEval](https://arxiv.org/abs/2605.18565): What it evaluates: memory for long-horizon, frequently updated, mutually interfering information. Core idea: use multi-objective interference to upgrade static recall pressure into dynamic memory and aggregation reasoning.
- [MemGym](https://arxiv.org/abs/2605.20833): What it evaluates: long-horizon agent memory environments. Core idea: use Memory-Isolated Tasks to isolate memory writing, retention, and later use from ordinary task capability, and connect scenarios such as MEMGYM-DR and MEMGYM-SWE to deep research and software tasks.
- [Same Ranking, Different Winner](https://arxiv.org/abs/2605.24060): Audits memory-benchmark reliability with TIAP fixed-output scoring. Core idea: show that Raw, Source, and Canonical scoring targets can change LoCoMo and LongMemEval-S rankings, making the scoring target itself part of the memory evaluation protocol.
- [StreamProfileBench](https://arxiv.org/abs/2605.25758): Benchmarks streaming user profiling as continuous state maintenance. Core idea: use 120K user-generated posts with annotation-free temporal evaluation to test whether a memory system updates fine-grained user profiles as evidence arrives.
- [EnterpriseMem-Bench](https://arxiv.org/abs/2605.26394): Evaluates memory architectures for multi-turn Text-to-SQL. Core idea: provide 300 sessions, 1,400 turns, multiple memory conditions, and a Memory Benefit Score so improvements from conversational memory can be separated from base SQL ability.
- [EGOSTREAM](https://arxiv.org/abs/2605.31557): Diagnoses streaming episodic memory in egocentric vision. Core idea: use an Answer Validity Window and 8,528 recall-conditioned evaluations so agents must remember events while the evidence stream moves forward.
- [SuperMemory-VQA](https://arxiv.org/abs/2606.00825): Evaluates long-horizon memory for AI-glasses-style egocentric video question answering. Core idea: ask object, location, intent, timeline, and conversational memory questions with an unanswerable option to discourage hallucinated recall.
- [MemoryDocDataSet](https://arxiv.org/abs/2606.04442): Tests joint conversational memory and long-document reasoning. Core idea: use 50 micro-worlds, 1,000 QA pairs, real long documents, multi-session conversations, and Hybrid source tags so agents must first locate a document through memory and then read it to answer.
- [SubtleMemory](https://arxiv.org/abs/2606.05761): Evaluates fine-grained relational memory discrimination in long-running agents. Core idea: embed complementary, nuanced, and contradictory memory variants into realistic histories, then test whether agents recover distributed relation structures rather than isolated facts.
- [M^3Exam](https://arxiv.org/abs/2606.07402): Benchmarks query-centric multimodal conversational memory in realistic user-agent file interactions. Core idea: require cross-modal grounding and implicit-information inference so memory is tested over files and modalities, not only text chat facts.
- [H2HMem](https://arxiv.org/abs/2606.09461): Evaluates multimodal memory for agents assisting human-human interactions such as meetings. Core idea: include multi-party references, anaphora, deixis, and conflicting information, filling the gap between single-user text memory and shared-interaction memory.
- [StreamMemBench](https://arxiv.org/abs/2606.14571): Evaluates streaming personal-agent memory for future-oriented assistance. Core idea: build two-step task sequences around EgoLife evidence anchors and score evidence recall, initial use, feedback incorporation, and follow-up reuse.
- [Bench'd AI memory scoreboard](https://benchd.ai/): What it evaluates: practical memory-system performance across multiple long-term-memory protocols such as LoCoMo and LongMemEval. Core idea: aggregate memory-system results into an independent ranking surface, making cross-benchmark memory comparisons easier than reading each benchmark repository separately.
- [GLM-EER: Global-Local Memory and Emotion Evaluation Refinement For Emotional Video Description](https://doi.org/10.1016/j.eswa.2026.132042): Evaluates emotional video description with global-local memory and emotion refinement, treating remembered temporal context as part of the scoring setup.
- [From Clusters to Characters: USERPRINT for Cross-Dataset Transfer in LLM Personalization](https://doi.org/10.1016/j.procs.2026.01.050): Tests cross-dataset transfer for LLM personalization by turning user clusters into character-style profiles that can be reused across datasets.
- [Scalability Limitations of Processing-in-Memory using Real System Evaluations](https://doi.org/10.1145/3639046): Uses real-system measurements to benchmark processing-in-memory scalability limits, marking a hardware-memory evaluation boundary rather than agent recall.
