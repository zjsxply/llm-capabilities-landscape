# 1.10.5 Agent Harness

Note: In the public ecosystem, there are not many solver agents named only for a specific long-context benchmark. More common are reusable long-horizon agent practices such as segmented loading, state summaries, failed-branch logging, and pluggable compression/retrieval components.

- [LLMLingua](https://arxiv.org/abs/2310.05736) ([code](https://github.com/microsoft/LLMLingua)): A pluggable context-compression component, often used in long-context agents to reduce irrelevant token interference and improve effective information density.
- [LongLLMLingua](https://arxiv.org/abs/2310.06839) ([code](https://github.com/microsoft/LLMLingua)): Compression and reordering strategies for longer inputs, emphasizing retention of key reasoning evidence under high compression ratios.
- [RAPTOR](https://arxiv.org/abs/2401.18059) ([code](https://github.com/parthsarthi03/raptor)): Organizes document memory with recursive summary trees, allowing agents to retrieve and aggregate evidence across context chunks at different granularities.
- [A Human-Inspired Reading Agent with Gist Memory of Very Long Contexts](https://arxiv.org/abs/2402.09727): Introduces ReadAgent, a prompting system that groups document spans into memory episodes, compresses them into gist memories, and looks up original passages when details are needed, extending effective context on QuALITY, NarrativeQA, and QMSum.
- [LongAgent](https://arxiv.org/abs/2402.11550) ([evaluation code/data](https://github.com/zuucan/needleinahaystack-plus)): A multi-agent collaborative long-context harness; the core idea is to assign ultra-long texts to multiple member agents and have a leader agent aggregate local evidence, making it suitable as an alternative to stuffing the entire input into one prompt.
- [(Perhaps) Beyond Human Translation: Harnessing Multi-Agent Collaboration for Translating Ultra-Long Literary Texts](https://arxiv.org/abs/2405.11804): Introduces TransAgents, a translation-company-style workflow with CEO, editors, translator, localization specialist, and proofreader roles that first draft guidelines and then translate, localize, proofread, and quality-check ultra-long literary texts.
- [HippoRAG](https://arxiv.org/abs/2405.14831) ([code](https://github.com/OSU-NLP-Group/HippoRAG)): Adds knowledge-graph-like association and hippocampus-inspired retrieval mechanisms to RAG, suitable for long-range factual association and multi-hop evidence organization.
- [Toward Conversational Agents with Context and Time Sensitive Long-term Memory](https://arxiv.org/abs/2406.00057): Builds a conversational-memory RAG setting for ambiguous and time/event-based queries, combining chain-of-table search, vector retrieval, and prompt-based query disambiguation over long-form simulated conversations.
- [Chain-of-Agents](https://arxiv.org/abs/2406.02818) ([unofficial implementation](https://github.com/rudrankriyam/Chain-of-Agents)): Splits long input into worker agents that process segments serially and pass intermediate messages, then has a manager agent summarize the final answer; suitable for long-document QA and summarization tasks.
- [GraphReader: Building Graph-based Agent to Enhance Long-Context Abilities of Large Language Models](https://arxiv.org/abs/2406.14550): Structures long texts as graphs and lets an agent plan, call functions to read node contents and neighbors, record insights, and reflect during coarse-to-fine exploration before answering.
- [HopRAG: Multi-Hop Reasoning for Logic-Aware Retrieval-Augmented Generation](https://arxiv.org/abs/2502.12442): Adds logic-aware multi-hop retrieval and reasoning workflow for retrieval-augmented generation.
- [Self-Taught Agentic Long Context Understanding](https://arxiv.org/abs/2502.15920): An agentic framework for long-context understanding. Core idea: combine question clarification and context retrieval so long-document QA is handled as an interactive agent process.
- [XpandA](https://arxiv.org/abs/2505.20625): A question-driven multi-agent long-context harness. Core idea: dynamically partition long texts, keep shared question-information state in centralized memory, and selectively replay relevant partitions to reduce information loss and latency when processing very long inputs.
- [TracLLM: A Generic Framework for Attributing Long Context LLMs](https://arxiv.org/abs/2506.04202): A generic attribution framework for long-context LLM outputs. Core idea: trace which context segments support generated claims in RAG and agent applications.
- [Parallelism Meets Adaptiveness: Scalable Documents Understanding in Multi-Agent LLM Systems](https://arxiv.org/abs/2507.17061): An adaptive multi-agent framework for scalable document understanding. Core idea: route long-document subtasks dynamically and coordinate agents instead of using fixed chunk-processing roles.
- [Sculptor](https://arxiv.org/abs/2508.04664): Gives LLMs active context-management tools such as fragmentation, summarization, hide-and-restore, and precise search to control working memory during long-context reasoning.
- [PiKV: KV Cache Management System for Mixture of Experts](https://arxiv.org/abs/2508.06526): Provides a distributed MoE KV-cache serving framework with expert-sharded storage, PiKV routing, adaptive scheduling of query-relevant entries, and compression modules for long-context inference.
- [OnGoal: Tracking and Visualizing Conversational Goals in Multi-Turn Dialogue with Large Language Models](https://arxiv.org/abs/2508.21061): Implements a chat interface that tracks user goals in real time, explains goal-alignment scores with examples, and visualizes goal progression across long multi-turn writing dialogues.
- [Graph of Agents](https://arxiv.org/abs/2509.06644) ([code](https://github.com/tjoo512/graph-of-agents)): A graph-style multi-agent collaboration harness for long context; the core idea is to organize text chunks, local agent outputs, and aggregation nodes into a scalable graph structure, replacing a single long prompt with local processing and cross-node aggregation.
- [Graph of Agents: Principled Long Context Modeling by Emergent Multi-Agent Collaboration](https://arxiv.org/abs/2509.21848): Formalizes Graph of Agents as an emergent multi-agent long-context architecture, arranging chunk-level workers and aggregation nodes into graph topologies so local analyses can be composed without one monolithic prompt.
- [ReMemR1](https://arxiv.org/abs/2509.23040): A long-context reasoning harness with revisitable memory. Core idea: let the model call back earlier memory states during a document scan so dispersed evidence is not lost through linear overwriting.
- [ToM](https://arxiv.org/abs/2511.00489): A tree-oriented MapReduce harness for long-context reasoning. Core idea: parse long documents into a hierarchical DocTree, perform local reasoning over nodes, and aggregate upward to preserve document structure better than flat chunk ranking.
- [DocLens : A Tool-Augmented Multi-Agent Framework for Long Visual Document Understanding](https://arxiv.org/abs/2511.11552): A tool-augmented multi-agent harness for long visual documents. Core idea: localize evidence pages and fine-grained visual details before answering.
- [Two-Faced Social Agents: Context Collapse in Role-Conditioned Large Language Models](https://arxiv.org/abs/2511.15573): Evaluates role-conditioned social-agent simulations under SAT math and affective-preference tasks, measuring when long role context collapses into a single optimized identity instead of preserving socioeconomic persona variation.
- [Principled Context Engineering for RAG](https://arxiv.org/abs/2511.17908): a conformal-prediction context-filtering harness for retrieval-augmented generation. Core idea: remove irrelevant retrieved snippets while preserving a target coverage level for supporting evidence, making context reduction statistically controlled rather than heuristic-only.
- [Solving Context Window Overflow in AI Agents](https://arxiv.org/abs/2511.22729): Replaces oversized tool outputs with memory pointers so agents can access arbitrary-length results without stuffing raw data into the context window, demonstrated in a materials-science workflow with lower token use.
- [Resolving Evidence Sparsity: Agentic Context Engineering for Long-Document Understanding](https://arxiv.org/abs/2511.22850): proposes SLEUTH, a multi-agent context-engineering workflow for long-document VLM understanding that retrieves, filters textual and visual evidence, plans reasoning, and synthesizes answers.
- [From Context to EDUs: Faithful and Structured Context Compression via Elementary Discourse Unit Decomposition](https://arxiv.org/abs/2512.14244): Managing extensive context remains a critical bottleneck for Large Language Models (LLMs), particularly in applications like long-document question answering and autonomous agents where lengthy inputs incur high computational costs and introduce noise.
- [Disk-Based Shared KV Cache Management for Fast Inference in Multi-Instance LLM RAG Systems](https://doi.org/10.1109/cloud67622.2025.00029): Introduces Shared RAG-DCache, which precomputes disk-resident KV caches for retrieved document chunks, uses query waiting time for prefetching, and shares cached contexts across multiple RAG inference instances to reduce TTFT.
- [To Retrieve or To Think? An Agentic Approach for Context Evolution](https://arxiv.org/abs/2601.08747): Proposes Agentic Context Evolution, where an orchestrator uses majority voting to decide whether to invoke a retriever for new evidence or a reasoner for internal refinement, keeping multi-hop QA context concise.
- [Entropic Context Shaping](https://arxiv.org/abs/2601.11585): An information-theoretic context-filtering harness for LLM agents. Core idea: measure whether a passage shifts the model toward the correct answer, separating useful context from distractors better than lexical similarity.
- [LSTM-MAS](https://arxiv.org/abs/2601.11913): A multi-agent harness for long-context understanding inspired by long short-term memory. Core idea: split long inputs across agents and coordinate memory-like state updates so long-context processing is not reduced to a single ever-growing prompt.
- [Structured Context Engineering for File-Native Agentic Systems: Evaluating Schema Accuracy, Format Effectiveness, and Multi-File Navigation at Scale](https://arxiv.org/abs/2602.05447): Contributes an agent workflow, orchestration pattern, prompting loop, or tool-mediated harness for long-context processing, compression, or file-native context capability.
- [Structured Prompt Language](https://arxiv.org/abs/2602.21257): A declarative context-management language for LLMs. Core idea: expose token budgets, retrieval, memory, and query optimization as programmable context operations rather than hand-written prompt stuffing.
- [The Missing Memory Hierarchy](https://arxiv.org/abs/2603.09023): Introduces demand paging for LLM context windows. Core idea: manage context as a memory hierarchy so long-running agents can page relevant state in and out instead of keeping all tool and prompt state in context.
- [Chow-Liu Ordering for Chain-of-Agents](https://arxiv.org/abs/2603.09835): a long-context harness refinement for CoA-style systems. Core idea: learn chunk dependency structure with Chow-Liu trees and traverse it to reduce information loss in bounded shared memory.
- [Recursive Language Models Meet Uncertainty: The Surprising Effectiveness of Self-Reflective Program Search for Long Context](https://arxiv.org/abs/2603.15653): Long-context handling remains a core challenge for language models: even with extended context windows, models often fail to reliably extract, reason over, and use the information across long contexts.
- [Conversation Tree Architecture](https://arxiv.org/abs/2603.21278): A structured framework for multi-branch LLM conversations. Core idea: organize conversations as context-isolated tree nodes with explicit context-flow rules to reduce topic bleed and logical context poisoning.
- [Reasoner-Executor-Synthesizer: Scalable Agentic Architecture with Static O(1) Context Window](https://arxiv.org/abs/2603.22367): Adds a agent harness for long context, centered on Reasoner-Executor-Synthesizer: Scalable Agentic Architecture with Static O(1) Context Window.
- [ContextCurator](https://arxiv.org/abs/2604.11462): An active context-curation harness for long-horizon agents. Core idea: pair a lightweight policy model with a frozen task executor so working memory keeps sparse reasoning anchors while pruning noisy environment history.
- [Context Kubernetes](https://arxiv.org/abs/2604.11623): Defines declarative orchestration for enterprise knowledge contexts used by agentic AI systems.
- [SLIDERS](https://arxiv.org/abs/2604.22294): a structured-reasoning harness for QA over very large document sets. Core idea: extract salient evidence into a relational database, reconcile duplicate or inconsistent records with provenance, and answer through SQL-backed persistent state rather than ever-larger prompts.
- [PolyKV: A Shared Asymmetrically-Compressed KV Cache Pool for Multi-Agent LLM Inference](https://arxiv.org/abs/2604.24971): Shares one asymmetrically compressed KV-cache pool across concurrent agents by writing compressed keys and values once and injecting them into independent HuggingFace DynamicCache contexts.
