# 1.2.4 Model

- [Galactica](https://arxiv.org/abs/2211.09085): A scientific-language-model pretraining effort over papers, textbooks, code, and knowledge artifacts, making scientific notation, citation style, and technical reasoning a model-side capability target.
- [Toward Scientific Reasoning in LLMs](https://arxiv.org/abs/2505.19501): Introduces Training from Expert Discussions via Reinforcement Learning, a model-side contribution for Scientific Knowledge.
- [Sequential Causal Discovery with Noisy Language Model Priors](https://arxiv.org/abs/2506.16234): Uses language-model priors in sequential causal discovery, directly connecting LLM knowledge with scientific hypothesis search.
- [Training a Scientific Reasoning Model for Chemistry](https://arxiv.org/abs/2506.17238): A chemistry-focused scientific-reasoning training recipe that combines domain data and staged training so models improve on reasoning tasks rather than only chemical fact recall.
- [ChemDFM-R](https://arxiv.org/abs/2507.21990): A chemistry reasoning LLM that injects atomized chemical knowledge into training for molecule, reaction, and domain-reasoning questions.
- [CoT-Evo](https://arxiv.org/abs/2510.13166): Introduces Evolutionary Distillation of Chain-of-Thought for Scientific Reasoning, a model-side contribution for Scientific Knowledge.
- [Addressing Logical Fallacies In Scientific Reasoning From Large Language Models: Towards a Dual-Inference Training Framework](https://arxiv.org/abs/2512.04228): Trains a dual-inference framework to address logical fallacies in LLM scientific reasoning.
- [Data Darwinism Part I](https://arxiv.org/abs/2602.07824): A scientific-data curation method that studies how scientific data quality and selection affect pretraining value for scientific foundation models.
- [DataEvolve](https://arxiv.org/abs/2603.14420): An automated pretraining-data evolution method that uses model feedback and autonomous data-improvement loops to refine scientific corpus mixtures.
- [Intern-S1-Pro](https://arxiv.org/abs/2603.25040): A trillion-scale scientific multimodal foundation model that scales scientific text, image, chart, document, and domain data training.
- [Do We Need Bigger Models for Science?](https://arxiv.org/abs/2604.01965): Proposes a task-aware retrieval framework with small language models for scientific applications, showing how specialized retrieval can compensate for reduced model scale.
