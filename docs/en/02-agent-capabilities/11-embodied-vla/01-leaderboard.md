# 2.11.1 Leaderboard

- [BEHAVIOR Challenge Leaderboard](https://behavior.stanford.edu/challenge/index.html): Official BEHAVIOR challenge page for embodied household activities and benchmark submissions.
- [HA-VLN Leaderboard](https://ha-vln-project.vercel.app/): Official human-aware vision-language navigation leaderboard for dynamic multi-human navigation settings.
- [RoboTwin Leaderboard](https://robotwin-platform.github.io/leaderboard): Official leaderboard for dual-arm robot manipulation tasks built around generative digital twins.
- [Orak Leaderboard](https://krafton-ai.github.io/orak-leaderboard/): Official video-game agent leaderboard spanning multiple genres, battle arenas, and agent-module settings.
- [RoboArena Leaderboard](https://robo-arena.github.io/): Official distributed real-world evaluation leaderboard for generalist robot policies.
- [EmbodiedBench Leaderboard](https://embodiedbench.github.io/): Official leaderboard for multimodal large language models operating as vision-driven embodied agents.
- [VLA Evaluation Harness Leaderboard](https://allenai.github.io/vla-evaluation-harness/leaderboard/): A widely used unified VLA leaderboard covering LIBERO, CALVIN, RoboCasa, RoboTwin, VLABench, RLBench, BEHAVIOR-1K, and related policy stacks.
- [PokeAgent Challenge Leaderboard](https://pokeagent.github.io/leaderboard.html): Official challenge leaderboard for embodied decision making in Pokemon battles and RPG speedrunning tasks.
- [VideoGameBench Leaderboard](https://vgbench.com/#leaderboard): A continuous leaderboard for embodied agent perception, navigation, manipulation, and planning in video-game environments; useful for tracking models and scaffolds that operate in executable visual worlds rather than static screenshots.
