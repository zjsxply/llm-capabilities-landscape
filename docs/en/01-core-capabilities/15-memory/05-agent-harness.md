# 1.15.5 Agent Harness

- [Reflexion](https://arxiv.org/abs/2303.11366) ([code](https://github.com/noahshinn/reflexion)): Converts failure trajectories into language feedback and episodic memory for use in the next attempt; an early representative of using experience memory to improve repeated agent attempts.
- [Generative Agents](https://arxiv.org/abs/2304.03442) ([code](https://github.com/joonspk-research/generative_agents)): Combines memory streams, reflection, and planning loops into long-term behavioral agents, and is a common starting point for later agent-memory papers.
- [MemoryBank](https://arxiv.org/abs/2305.10250) ([code](https://github.com/zhongwanjun/MemoryBank-SiliconFriend)): Builds long-term memory writing, retrieval, and personality/preference updates as dialogue-agent components, useful for tracking cross-turn consistency.
- [Voyager](https://arxiv.org/abs/2305.16291) ([code](https://github.com/MineDojo/Voyager)): Distills exploration experience into a callable skill library and long-term memory; although the task is Minecraft, it established the classic harness form of `experience writing -> retrieval reuse -> capability accumulation`.
- [MemGPT](https://arxiv.org/abs/2310.08560) ([code](https://github.com/cpacker/MemGPT)): Reframes the long-context problem as explicit memory tiers and scheduling policies, forming a reusable long-horizon agent runtime.
- [Compress to Impress: Unleashing the Potential of Compressive Memory in Real-World Long-Term Conversations](https://arxiv.org/abs/2402.11975): Builds a compressive memory workflow for long-term conversations, using memory generation and compression so dialogue agents can preserve salient history without replaying the full transcript.
- ["My agent understands me better": Integrating Dynamic Human-like Memory Recall and Consolidation in LLM-Based Agents](https://arxiv.org/abs/2404.00573): Integrates human-like recall and consolidation into LLM agents, separating dynamic retrieval from longer-term memory updating for personalized interaction.
- [RAM: Towards an Ever-Improving Memory System by Learning from Communications](https://arxiv.org/abs/2404.12045): Learns memory updates from communication traces so the memory store can improve over repeated interactions rather than remaining a static retrieval archive.
- [HiAgent: Hierarchical Working Memory Management for Solving Long-Horizon Agent Tasks with Large Language Model](https://arxiv.org/abs/2408.09559): Manages long-horizon tasks with hierarchical working memory, splitting task state into levels so agents can retrieve compact context for subgoals.
- [X-TURING: Towards an Enhanced and Efficient Turing Test for Long-Term Dialogue Agents](https://arxiv.org/abs/2408.09853): Proposes a long-term dialogue-agent test harness that stresses persistent memory, user simulation, and efficient multi-session evaluation.
- [Agent Workflow Memory](https://arxiv.org/abs/2409.07429) (code: no stable public repository found): A memory mechanism for multi-step agent workflows; core idea: have agents explicitly record key states, tool results, and decision rationales during task execution, then retrieve them as needed in later steps instead of feeding back the full history.
- [OmniQuery: Contextually Augmenting Captured Multimodal Memories to Enable Personal Question Answering](https://arxiv.org/abs/2409.08250): Augments captured multimodal memories with context so personal QA systems can retrieve and reason over images, events, and dialogue-grounded evidence.
- [A Compressive Memory-based Retrieval Approach for Event Argument Extraction](https://arxiv.org/abs/2409.09322): Uses compressive memory retrieval for event argument extraction, preserving salient historical evidence while reducing retrieval context size.
- [Stable Hadamard Memory: Revitalizing Memory-Augmented Agents for Reinforcement Learning](https://arxiv.org/abs/2410.10132): Uses a Stable Hadamard Memory module for RL agents, applying structured memory augmentation to stabilize long-horizon policy learning.
- [TiMePReSt: Time and Memory Efficient Pipeline Parallel DNN Training with Removed Staleness](https://arxiv.org/abs/2410.14312): Optimizes pipeline-parallel DNN training for time and memory efficiency by removing staleness, a systems-memory boundary rather than an agent-recall harness.
- [Zep](https://arxiv.org/abs/2501.13956) ([code](https://github.com/getzep/graphiti)): A temporal knowledge-graph architecture for agent memory; core idea: organize events, entities, relations, and temporal evolution into a queryable graph for long-term personalization and cross-session recall.
- [MINDSTORES: Memory-Informed Neural Decision Synthesis for Task-Oriented Reinforcement in Embodied Systems](https://arxiv.org/abs/2501.19318): Combines memory-informed decision synthesis with task-oriented reinforcement in embodied systems.

Core idea: expose workflow logic outside the base model so planning, tool use, memory, verification, recovery, or orchestration can be studied and reused.
