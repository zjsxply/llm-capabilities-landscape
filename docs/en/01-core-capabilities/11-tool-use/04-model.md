# 1.11.4 Model

- [Toolformer](https://arxiv.org/abs/2302.04761): A self-supervised tool-use training method where language models teach themselves when to call APIs, pass arguments, and condition on tool results.
- [ToolkenGPT](https://arxiv.org/abs/2305.11554): Learns tool embeddings as special tokens so a frozen language model can decide when to invoke tools through a trainable model interface.
- [Gorilla](https://arxiv.org/abs/2305.15334): A fine-tuned LLaMA-based API-call model and APIBench training setup for generating accurate calls over large API collections.
- [GPT4Tools](https://arxiv.org/abs/2305.18752): Uses self-instruction to teach open models to invoke multimodal tools, showing that synthetic tool-use instructions can transfer to unseen tools.
- [ToolAlpaca](https://arxiv.org/abs/2306.05301): Builds a multi-agent simulation environment to generate thousands of tool-use cases over hundreds of real APIs, then fine-tunes compact models for generalized tool use.
- [ToolLLM](https://arxiv.org/abs/2307.16789): Builds ToolBench-style trajectories and trains ToolLLaMA to retrieve APIs, fill arguments, and execute multi-step tool calls.
- [FireAct](https://arxiv.org/abs/2310.05915): Fine-tunes backbone language models on agent trajectories from search and other tool-using tasks, making trajectory data a model-side route to stronger agents.
- [AgentTuning](https://arxiv.org/abs/2310.12823): Constructs AgentInstruct interaction trajectories and trains AgentLM models so planning, memory, and tool utilization improve without sacrificing general instruction ability.
- [Chain of Evidences and Evidence to Generate](https://arxiv.org/abs/2401.05787): Uses evidence-chain prompting to ground retrieval-augmented reasoning in cited context before answer generation.
- [MLLM-Tool](https://arxiv.org/abs/2401.10727): Trains multimodal tool-agent behavior by aligning a multimodal LLM with tool descriptions, visual inputs, and executable tool outputs.
- [The Power of Noise](https://arxiv.org/abs/2401.14887): Stress-tests RAG retrievers with noisy passages to show when retrieval quality, ranking, and filtering matter more than adding more context.
- [ReSLLM](https://arxiv.org/abs/2401.17645): Uses LLMs as resource selectors for federated search, choosing which vertical search engines or corpora should answer a query.
- [G-Retriever](https://arxiv.org/abs/2402.07630): Combines graph neural retrieval with LLM generation so question answering can use textual graph structure rather than flat passages alone.
- [API Pack](https://arxiv.org/abs/2402.09615): Releases a large multilingual API-call generation corpus for training models to map natural-language requests into executable API invocations.
- [BlendFilter](https://arxiv.org/abs/2402.11129): Blends generated retrieval queries with knowledge filtering so RAG models retrieve cleaner evidence before generation.
- [Offline Training of Language Model Agents with Functions as Learnable Weights](https://arxiv.org/abs/2402.11359): Treats functions as learnable weights during offline agent training, letting a model internalize reusable function behavior rather than only calling external tools.
- [TOOLVERIFIER](https://arxiv.org/abs/2402.14158): Trains models to self-verify tool selection and parameter generation with synthetic contrastive questions, improving transfer to unseen tools.
- [Tug-of-War between Knowledge](https://arxiv.org/abs/2402.14409): Studies internal-versus-retrieved knowledge conflicts in RAG and proposes conflict-aware strategies for deciding when retrieved evidence should override model memory.
- [Self-Retrieval](https://arxiv.org/abs/2403.00801): Collapses indexing, retrieval, ranking, and generation into one LLM-driven retrieval architecture instead of a separate retriever-generator stack.
- [ToolNet](https://arxiv.org/abs/2403.00839): Builds a tool graph so LLMs can retrieve and connect large numbers of tools through learned dependencies among tool descriptions.
- [LLMs in the Imaginarium](https://arxiv.org/abs/2403.04746): Uses simulated trial and error with imagined tool-use scenarios, execution feedback, memory, and replay to improve tool learning.
- [RA-ISF](https://arxiv.org/abs/2403.06840): Applies iterative self-feedback to decompose questions, inspect retrieved evidence, and revise RAG answers when retrieval is noisy.
- [RAFT](https://arxiv.org/abs/2403.10131): Fine-tunes domain RAG models on question, document, and chain-of-thought triples so they learn to cite relevant retrieved documents and ignore distractors.
- [Agent-FLAN](https://arxiv.org/abs/2403.12881): Redesigns agent-tuning data and negative samples so open LLMs learn tool use and agent reasoning while reducing hallucinated actions.
- [Octopus](https://arxiv.org/abs/2404.01549): Fine-tunes small on-device models on software API documentation and function-call data, pairing API-call learning with conditional output masking.
- [FT2Ra](https://arxiv.org/abs/2404.01554): Adapts retrieval-augmented code completion with a fine-tuning-inspired retriever-generator setup for repository context.
- [CONFLARE](https://arxiv.org/abs/2404.04287): Adds conformal retrieval to RAG so the model can calibrate which retrieved passages are reliable enough to use.
- [Blended RAG](https://arxiv.org/abs/2404.07220): Combines semantic search with hybrid query-based retrieval to improve evidence selection before RAG generation.
- [Dubo-SQL](https://arxiv.org/abs/2404.12560): Couples diverse retrieval augmentation with fine-tuning for text-to-SQL, targeting structured database tool use.
- [RETTA](https://arxiv.org/abs/2405.07046): Uses retrieval-enhanced test-time adaptation to bridge retrieved video-text evidence into a zero-shot captioning generator.
- [Fine-Tuning Large Vision-Language Models as Decision-Making Agents via Reinforcement Learning](https://arxiv.org/abs/2405.10292): Fine-tunes vision-language models with reinforcement learning so they act as decision-making agents in interactive visual environments.
- [xRAG](https://arxiv.org/abs/2405.13792): Compresses retrieved documents into a single retrieval token, reducing RAG context cost while preserving document-grounded generation.
- [Towards Completeness-Oriented Tool Retrieval for Large Language Models](https://arxiv.org/abs/2405.16089): Optimizes tool retrieval for coverage of all tools needed by a task, rather than only top-ranked semantic similarity.
- [GRAG](https://arxiv.org/abs/2405.16506): Uses graph retrieval augmentation so generation can exploit relationships among retrieved entities and passages.
- [Tool Learning in the Wild](https://arxiv.org/abs/2405.16533): Collects real-world tool-use supervision and trains LLMs to act as automatic tool agents across heterogeneous APIs.
- [Advancing Tool-Augmented Large Language Models](https://arxiv.org/abs/2406.07115): Learns from errors in tool-use inference trees to improve model decisions about when and how to call tools.
- [Few-Shot Recognition via Stage-Wise Retrieval-Augmented Finetuning](https://arxiv.org/abs/2406.11148): Uses stage-wise retrieval-augmented fine-tuning to improve few-shot recognition with retrieved support examples.
- [AvaTaR](https://arxiv.org/abs/2406.11200): Optimizes LLM tool use with contrastive reasoning, training models to distinguish successful tool-use trajectories from flawed alternatives.
- [PlanRAG](https://arxiv.org/abs/2406.12430): Adds a plan-then-retrieve stage so decision-making LLMs retrieve evidence according to an explicit plan before answering.
- [Generate-then-Ground](https://arxiv.org/abs/2406.14891): Generates candidate reasoning paths and then grounds them with retrieval for multi-hop question answering.
- [CogMG](https://arxiv.org/abs/2406.17231): Coordinates LLMs and knowledge graphs so generation can query structured knowledge while also helping update incomplete graph evidence.
- [Enhancing Tool Retrieval with Iterative Feedback from Large Language Models](https://arxiv.org/abs/2406.17465): Uses LLM feedback loops to iteratively refine tool retrieval results before final tool selection.
- [APIGen](https://arxiv.org/abs/2406.18518): Synthesizes verifiable function-calling datasets over thousands of executable APIs, using format checks, real execution, and semantic verification before training xLAM-style models.
- [From Artificial Needles to Real Haystacks: Improving Retrieval Capabilities in LLMs by Finetuning on Synthetic Data](https://arxiv.org/abs/2406.19292): Fine-tunes LLMs on synthetic long-context retrieval data to improve retrieval from realistic haystack-style documents.
- [Granite-Function Calling](https://arxiv.org/abs/2407.00121): Trains an open Granite model on granular function-calling tasks such as nested calls, function chaining, parallel calls, and next-function prediction.
- [ColPali: Efficient Document Retrieval with Vision Language Models](https://arxiv.org/abs/2407.01449): Encodes document pages as visual patches with a PaliGemma-style VLM and late interaction, making retrieval work over screenshots rather than OCR text chunks.
- [MixGR: Enhancing Retriever Generalization for Scientific Domain through Complementary Granularity](https://arxiv.org/abs/2407.10691): Trains scientific-domain retrievers with complementary granularities so evidence can be matched across terms, sentences, and document-level context.
- [NV-Retriever: Improving text embedding models with effective hard-negative mining](https://arxiv.org/abs/2407.15831): Improves embedding retrievers through a hard-negative mining recipe that selects difficult non-matches for contrastive training.
- [SAKR: Enhancing Retrieval-Augmented Generation via Streaming Algorithm and K-Means Clustering](https://arxiv.org/abs/2407.21300): Uses streaming selection and k-means clustering to keep representative retrieved chunks before RAG generation.
- [Breaking the Hourglass Phenomenon of Residual Quantization: Enhancing the Upper Bound of Generative Retrieval](https://arxiv.org/abs/2407.21488): Analyzes residual-quantization bottlenecks in generative retrieval and modifies the quantization setup to raise retrieval-code capacity.
- [Re-Invoke: Tool Invocation Rewriting for Zero-Shot Tool Retrieval](https://arxiv.org/abs/2408.01875): Rewrites tool invocations to improve zero-shot tool retrieval for language-model tool use.
- [HybridRAG: Integrating Knowledge Graphs and Vector Retrieval Augmented Generation for Efficient Information Extraction](https://arxiv.org/abs/2408.04948): Combines knowledge-graph lookup with vector retrieval so RAG information extraction can use both entity relations and dense text matches.
- [TinyAgent](https://arxiv.org/abs/2409.00608): Trains small function-calling models for edge deployment with curated function-call data, tool retrieval, and quantized local execution.
- [ToolACE](https://arxiv.org/abs/2409.00920): A tool-learning data and training line for improving function-calling behavior across diverse tool-use instructions.
- [xLAM](https://arxiv.org/abs/2409.03215): Releases large action models trained with a scalable pipeline that unifies, augments, and synthesizes agent datasets for function calling and tool-use tasks.
- [Training-free Zero-shot Composed Image Retrieval via Weighted Modality Fusion and Similarity](https://arxiv.org/abs/2409.04918): Adjacent retrieval work that fuses image and text similarities for composed image search, without adding tool-call or API-use training.
- [Towards Fair RAG: On the Impact of Fair Ranking in Retrieval-Augmented Generation](https://arxiv.org/abs/2409.11598): Studies how fair-ranking objectives change RAG answer quality and group exposure, making it a retrieval-policy diagnostic rather than a tool-calling trainer.
- [Harnessing LLMs for API Interactions: A Framework for Classification and Synthetic Data Generation](https://arxiv.org/abs/2409.11703): Classifies natural-language API requests and uses LLMs to synthesize API-interaction data for software-function invocation.
- [M2R-Whisper: Multi-stage and Multi-scale Retrieval Augmentation for Enhancing Whisper](https://arxiv.org/abs/2409.11889): Adds multi-stage and multi-scale retrieval around Whisper so speech recognition can consult external context at different granularities.
- [You Only Read Once (YORO): Learning to Internalize Database Knowledge for Text-to-SQL](https://arxiv.org/abs/2409.12172): Fine-tunes text-to-SQL models to internalize database knowledge and reduce repeated schema retrieval at inference time.
- [KAG: Boosting LLMs in Professional Domains via Knowledge Augmented Generation](https://arxiv.org/abs/2409.13731): Builds domain RAG around knowledge graphs and logical-form reasoning so professional QA can retrieve and reason over structured knowledge.
- [RAMBO: Enhancing RAG-based Repository-Level Method Body Completion](https://arxiv.org/abs/2409.15204): Uses repository-level retrieval to supply relevant code context for method-body completion rather than relying on local file context alone.
- [Disentangling Questions from Query Generation for Task-Adaptive Retrieval](https://arxiv.org/abs/2409.16570): Separates user-question understanding from retrieval-query generation, training query generators that adapt retrieval behavior to the task.
- [Unified Multimodal Interleaved Document Representation for Retrieval](https://arxiv.org/abs/2410.02729): Learns a unified representation for documents interleaving text, tables, and images so retrieval can operate over mixed-modality evidence.
- [ToolGen](https://arxiv.org/abs/2410.03439): Treats tool retrieval and tool calling as generation by representing tools as special tokens, letting model parameters internalize large tool libraries.
- [Hammer](https://arxiv.org/abs/2410.04587): Builds on-device function-calling models with augmented irrelevance data and function masking to improve robustness against misleading tool names.
- [ReFIR: Grounding Large Restoration Models with Retrieval Augmentation](https://arxiv.org/abs/2410.05601): Retrieves similar restored examples to condition large image-restoration models, grounding restoration decisions in external visual references.
- [TurboRAG: Accelerating Retrieval-Augmented Generation with Precomputed KV Caches for Chunked Text](https://arxiv.org/abs/2410.07590): Precomputes key-value caches for retrieval chunks so RAG can reuse encoded context and reduce generation latency.
- [StepTool: Enhancing Multi-Step Tool Usage in LLMs via Step-Grained Reinforcement Learning](https://arxiv.org/abs/2410.07745): Models tool learning as a multi-step decision process, giving each tool interaction a shaped reward for invocation success and task contribution before optimizing the policy across tool-use steps.
- [From Exploration to Mastery: Enabling LLMs to Master Tools via Self-Driven Interactions](https://arxiv.org/abs/2410.08197): Introduces DRAFT, where an LLM probes tools through trial-and-error, mines interaction feedback, and rewrites tool documentation so later tool calls become easier for multiple models.
- [BUTTON](https://arxiv.org/abs/2410.12952): Generates compositional multi-turn function-calling data with bottom-up task construction and top-down simulated human-assistant-tool trajectories.
- [How Does Knowledge Selection Help Retrieval Augmented Generation?](https://arxiv.org/abs/2410.13258): Analyzes which selected knowledge snippets actually affect RAG generation, separating helpful retrieval from distractor context.
- [Improve Dense Passage Retrieval with Entailment Tuning](https://arxiv.org/abs/2410.15801): Tunes dense passage retrievers with entailment-style supervision so retrieved passages better support downstream answers.
- [BIG5-CHAT: Shaping LLM Personalities Through Training on Human-Grounded Data](https://arxiv.org/abs/2410.16491): Off-axis for tool use; it trains persona-conditioned chat behavior from Big Five personality data rather than tool-call behavior.
- [SmartRAG: Jointly Learn RAG-Related Tasks From the Environment Feedback](https://arxiv.org/abs/2410.18141): Jointly optimizes RAG components from environment feedback instead of training retrieval and generation modules separately.
- [EcoAct: Economic Agent Determines When to Register What Action](https://arxiv.org/abs/2411.01643): Models action registration as an economic decision so an agent can decide when an external action is worth taking.
- [WebRL: Training LLM Web Agents via Self-Evolving Online Curriculum Reinforcement Learning](https://arxiv.org/abs/2411.02337): Trains open web agents with self-evolving online curriculum reinforcement learning for interactive browser tasks.
- [From Novice to Expert: LLM Agent Policy Optimization via Step-wise Reinforcement Learning](https://arxiv.org/abs/2411.03817): Optimizes LLM agent policies step by step with reinforcement learning, turning intermediate tool-use decisions into trainable feedback.
- [Meta-Reasoning Improves Tool Use in Large Language Models](https://arxiv.org/abs/2411.04535): Introduces TECTON, a two-phase tool selector that first proposes candidate tools with a fine-tuned head and then meta-reasons over that choice.
- [MIRe: Enhancing Multimodal Queries Representation via Fusion-Free Modality Interaction for Multimodal Retrieval](https://arxiv.org/abs/2411.08334): Improves multimodal retrieval by modeling cross-modal query interaction without fusing modalities into a single representation.
- [Video-RAG: Visually-aligned Retrieval-Augmented Long Video Comprehension](https://arxiv.org/abs/2411.13093): Retrieves visually aligned evidence for long-video question answering so generation is grounded in relevant frames and captions.
- [TL-Training: A Task-Feature-Based Framework for Training Large Language Models in Tool Use](https://arxiv.org/abs/2412.15495): Reweights key tool-use tokens during SFT and adds PPO rewards tied to tool-call error categories, reaching strong results from 1,217 training examples.
- [APEX2: Adaptive and Extreme Summarization for Personalized Knowledge Graphs](https://arxiv.org/abs/2412.17336): Off-axis personalization work that summarizes user knowledge graphs adaptively rather than training API or tool invocation.
- [Geospatial large language model trained with a simulated environment for generating tool-use chains autonomously](https://doi.org/10.1016/j.jag.2024.104312): Trains geospatial tool-use chains in a simulated environment so an LLM can autonomously compose GIS operations.
- [Keyword-Enhanced Semantic Retrieval and Multi-Dimensional Relevance Ranking in RAG](https://doi.org/10.1109/iccc62609.2024.10941711): Combines keyword-expanded semantic retrieval with multi-dimensional relevance ranking for RAG evidence selection; it is adjacent retrieval-ranking work rather than function-call training.
- [Exploring the Application of Retrieval-Augmented Generation Technology in Defense Technology Intelligence](https://doi.org/10.1109/csis-iac63491.2024.10919351): Applies RAG to defense-technology intelligence retrieval and answer grounding, making it a domain RAG case rather than API-planning supervision.
- [Advancing Large Language Model Agent via Iterative Contrastive Trajectory Optimization](https://doi.org/10.2478/ijanmc-2024-0033): Optimizes successful and failed agent trajectories with ICTO, using POMDP-framed step guidance to improve open-source LLM task solving.
- [A Comparative Analysis of Large Language Models with Retrieval-Augmented Generation based Question Answering System](https://doi.org/10.1109/i-smac61858.2024.10714814): Compares RAG-based question-answering systems across LLM choices, so the contribution is evaluation-oriented retrieval augmentation rather than tool-use training.
- [OpenRAG: Open-source Retrieval-Augmented Generation Architecture for Personalized Learning](https://doi.org/10.1109/icairc64177.2024.10900069): Implements an open-source RAG architecture for personalized learning advisors, wiring retrieval into course-aware generation without new tool-call supervision.
- [The enhanced context for AI-generated learning advisors with Advanced RAG](https://doi.org/10.1109/acompa64883.2024.00021): Uses an Advanced RAG pipeline to enrich context for generated learning-advisor feedback, an educational RAG application rather than a tool-calling model recipe.
- [GeoTool-GPT: a trainable method for facilitating Large Language Models to master GIS tools](https://doi.org/10.1080/13658816.2024.2438937): Curates GeoTool instructions, GeoSolution tool-use solutions, and GeoTask evaluations, then instruction-tunes LLaMA-2-7B to compose professional GIS tool chains.
- [Transferable dual multi-granularity semantic excavating for partially relevant video retrieval](https://doi.org/10.1016/j.imavis.2024.105168): Learns dual multi-granularity semantics for partially relevant video retrieval, making it adjacent vision retrieval rather than API or tool-call learning.
- [MC-indexing: Effective Long Document Retrieval via Multi-view Content-aware Indexing](https://doi.org/10.18653/v1/2024.findings-emnlp.150): Builds multi-view, content-aware indexes for long-document retrieval so evidence can be matched across complementary document perspectives.
- [Improving Retrieval-Augmented Generation through Multi-Agent Reinforcement Learning](https://arxiv.org/abs/2501.15228): Treats query rewriting, retrieval, filtering, and answer generation as cooperative RL agents in MMOA-RAG, optimizing the whole RAG pipeline against final-answer rewards instead of tuning each module separately.
- [Self-Training LLMs for Tool-Use Without Demonstrations](https://arxiv.org/abs/2502.05867): Lets models synthesize their own tool-use traces and then compares supervised and preference fine-tuning without gold demonstrations.
- [Graph RAG-Tool Fusion](https://arxiv.org/abs/2502.07223): Models structured dependencies among tools during RAG-based tool retrieval, so agents can retrieve prerequisite and related APIs instead of treating every tool description independently.
- [CoALM](https://arxiv.org/abs/2502.08820): Trains collaborative agentic language models on a multi-task dataset that interleaves multi-turn ReAct reasoning and complex API use.
- [QuOTE: Question-Oriented Text Embeddings](https://arxiv.org/abs/2502.10976): Trains embeddings around question-oriented supervision so retrieval representations are shaped by the queries they must answer.
- [How Expressive are Knowledge Graph Foundation Models?](https://arxiv.org/abs/2502.13339): Off-axis analysis of knowledge-graph foundation-model expressivity, useful for structured retrieval context but not a tool-calling method.
- [The KnowWhereGraph: A Large‐Scale Geo‐Knowledge Graph for Interdisciplinary Knowledge Discovery and Geo‐Enrichment](https://arxiv.org/abs/2502.13874): Publishes a large geo-knowledge graph for interdisciplinary discovery and enrichment, acting as structured retrieval infrastructure rather than tool-use training.
- [Text-to-SQL Domain Adaptation via Human-LLM Collaborative Data Annotation](https://arxiv.org/abs/2502.15980): Uses human and LLM collaboration to annotate text-to-SQL data for domain adaptation of database-query models.
- [CommGPT: A Graph and Retrieval-Augmented Multimodal Communication Foundation Model](https://arxiv.org/abs/2502.18763): Combines graph retrieval with multimodal communication data to build a communication-domain foundation model.
- [PEToolLLM: Towards Personalized Tool Learning in Large Language Models](https://arxiv.org/abs/2502.18980): Formulates personalized tool learning from user interaction history, introduces PEToolBench, and adapts PEToolLLaMA so implicit user preferences can influence tool choice.
- [GenTool: Enhancing Tool Generalization in Language Models through Zero-to-One and Weak-to-Strong Simulation](https://arxiv.org/abs/2502.18990): Synthesizes tool-use experience from zero-to-one and weak-to-strong simulation to improve tool generalization.
- [Do Retrieval-Augmented Language Models Adapt to Varying User Needs?](https://arxiv.org/abs/2502.19779): Evaluates whether RAG systems adjust retrieval and generation to different user needs, exposing personalization limits rather than a new tool-use trainer.
- [RANGE: Retrieval Augmented Neural Fields for Multi-Resolution Geo-Embeddings](https://arxiv.org/abs/2502.19781): Uses retrieval-augmented neural fields to produce multi-resolution geo-embeddings for spatial retrieval.
- [Online Pseudo-average Shifting Attention(PASA) for Robust Low-precision LLM Inference: Algorithms and Numerical Analysis](https://arxiv.org/abs/2503.01873): Off-axis inference-robustness work for low-precision LLMs, not a retrieval or function-calling model.
- [START](https://arxiv.org/abs/2503.04625): Builds a self-taught reasoner with tools by filtering and fine-tuning hint-triggered code-execution trajectories.
- [Aligning Extraction and Generation for Robust Retrieval-Augmented Generation](https://arxiv.org/abs/2503.04789): Aligns the extraction stage and the generation stage so RAG answers remain robust when retrieved evidence is noisy.
- [ROGRAG: A Robustly Optimized GraphRAG Framework](https://arxiv.org/abs/2503.06474): Optimizes a GraphRAG pipeline for robustness, using graph-structured retrieval rather than plain passage retrieval.
- [Alignment for Efficient Tool Calling of Large Language Models](https://arxiv.org/abs/2503.06708): Aligns LLMs for efficient tool calling, targeting reliable tool selection and call generation with less overhead.
- [MAGNET](https://arxiv.org/abs/2503.07826): Synthesizes multi-turn tool-use trajectories by translating function-signature graphs into conversations with executable calls, then trains models with positive and negative trajectories.
- [Beyond Single Pass, Looping Through Time: KG-IRAG with Iterative Knowledge Retrieval](https://arxiv.org/abs/2503.14234): Runs iterative knowledge-graph retrieval across multiple passes so RAG can refine evidence instead of answering from one retrieval batch.
- [Don't lie to your friends: Learning what you know from collaborative self-play](https://arxiv.org/abs/2503.14481): Uses collaborative self-play to teach agents when to answer, use tools, trust tools, or abstain.
- [Good4cir: Generating Detailed Synthetic Captions for Composed Image Retrieval](https://arxiv.org/abs/2503.17871): Off-axis composed-image-retrieval data work that generates detailed synthetic captions rather than tool-use or API-call data.
- [ToRL](https://arxiv.org/abs/2503.23383): Scales tool-integrated reinforcement learning so models learn when to invoke computational tools through reward-driven exploration rather than imitation alone.
- [ToolACE-R](https://arxiv.org/abs/2504.01400): A model-aware iterative training and refinement method for tool learning rather than only a new evaluation set.
- [LLM-VPRF: Large Language Model Based Vector Pseudo Relevance Feedback](https://arxiv.org/abs/2504.01448): Uses an LLM to produce vector pseudo-relevance feedback, expanding retrieval signals without manual relevance labels.
- [DiaTool-DPO: Multi-Turn Direct Preference Optimization for Tool-Augmented Large Language Models](https://arxiv.org/abs/2504.02882): Models tool-augmented dialogue as state transitions, builds paired correct and incorrect trajectories, and uses DPO to improve information gathering and out-of-scope rejection in multi-turn tool use.
- [APIGen-MT](https://arxiv.org/abs/2504.03601): Generates verifiable multi-turn API-use trajectories through simulated interaction and trains xLAM function-calling models from the data.
- [SWiRL](https://arxiv.org/abs/2504.04736): Combines synthetic data generation with step-wise reinforcement learning over multi-step reasoning and tool-use trajectories.
- [VectorLiteRAG: Latency-Aware and Fine-Grained Resource Partitioning for Efficient RAG](https://arxiv.org/abs/2504.08930): Partitions vector-search resources at fine granularity to reduce RAG latency under constrained serving budgets.
- [UP-Person: Unified Parameter-Efficient Transfer Learning for Text-Based Person Retrieval](https://arxiv.org/abs/2504.10084): Off-axis person-retrieval work that uses parameter-efficient transfer for text-based identity search, not tool-use training.
- [Efficient Distributed Retrieval-Augmented Generation for Enhancing Language Model Performance](https://arxiv.org/abs/2504.11197): Distributes RAG retrieval and generation work to improve serving efficiency for language-model augmentation.
- [ReTool](https://arxiv.org/abs/2504.11536): Trains models to interleave reasoning with real-time code execution through supervised warmup and outcome-reward reinforcement learning.
- [Estimating Optimal Context Length for Hybrid Retrieval-augmented Multi-document Summarization](https://arxiv.org/abs/2504.12972): Estimates how much retrieved context a hybrid multi-document summarizer should include before extra evidence hurts or wastes budget.
- [ToolRL](https://arxiv.org/abs/2504.13958): Uses reinforcement learning as the central signal for tool learning, emphasizing reward design over static function-calling imitation.
- [OTC](https://doi.org/10.48550/arXiv.2504.14870): Uses reinforcement learning to optimize when a language model should issue tool calls instead of relying only on imitation traces.
- [Privacy-Preserving Federated Embedding Learning for Localized Retrieval-Augmented Generation](https://arxiv.org/abs/2504.19101): Proposes FedE4RAG, where clients collaboratively train private RAG retrievers through federated parameter aggregation, server-client knowledge distillation, and homomorphic-encryption mechanisms without sharing raw local data.
- [MICE for CATs: Model-Internal Confidence Estimation for Calibrating Agents with Tools](https://arxiv.org/abs/2504.20168): Estimates tool-call confidence from intermediate-layer logitLens decodes and similarity-to-final-output features, then uses the calibrated score to decide when tool use is worth the risk.
- [Nemotron-Research-Tool-N1](https://arxiv.org/abs/2505.00024): Trains tool-calling reasoning models with binary rule rewards for call-format validity and functional correctness, avoiding supervised intermediate traces.
- [EnronQA: Towards Personalized RAG over Private Documents](https://arxiv.org/abs/2505.00263): Builds a private-document QA setting from Enron email to study personalized RAG over user-owned corpora.
- [Agentic Reasoning and Tool Integration for LLMs via Reinforcement Learning](https://arxiv.org/abs/2505.01441): Uses outcome-based RL so models learn when, how, and which tools to invoke inside multi-turn reasoning chains without step-level labels.
- [OpenThinkIMG: Learning to Think with Images via Visual Tool Reinforcement Learning](https://arxiv.org/abs/2505.08617): Learns interactive visual-tool use through reinforcement learning for thinking with images.
- [The Accountability Paradox: How Platform API Restrictions Undermine AI Transparency Mandates](https://arxiv.org/abs/2505.11577): Off-axis policy analysis showing how platform API restrictions can block AI transparency mandates, not a model-training method.
- [LLM-based Query Expansion Fails for Unfamiliar and Ambiguous Queries](https://arxiv.org/abs/2505.12694): Shows that LLM query expansion can degrade retrieval for unfamiliar or ambiguous queries, a failure mode for RAG front ends.
- [Tool-Star](https://arxiv.org/abs/2505.16410): Synthesizes tool-integrated reasoning traces with hint-based sampling, filters them by quality and difficulty, then applies multi-tool self-critic RL.
- [VTool-R1](https://arxiv.org/abs/2505.19255): Injects Python visual-editing tools into reinforcement fine-tuning so VLMs learn to interleave text reasoning with intermediate visual steps.
