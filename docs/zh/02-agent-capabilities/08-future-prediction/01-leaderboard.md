# 2.8.1 Leaderboard

- [TS-Arena](https://arxiv.org/abs/2512.20761)： 提供时间序列预测的实时预注册平台，用于在结果揭晓前评测预测。
- [CT Open](https://arxiv.org/abs/2604.16742)：开放的 clinical-trial outcome live prediction 平台，可作为垂直领域 future-prediction leaderboard。
- [ForecastBench Leaderboard](http://www.forecastbench.org/)：持续动态生成并定期更新的真实未来事件预测榜单；适合比较模型在未兑现问题上的概率预测、校准和专家/人群对照。
- [Metaculus FutureEval](https://www.metaculus.com/futureeval/)：Metaculus 持续 AI forecasting leaderboard；按统一 log-score 每日更新，并把 AI 模型、Metaculus 社群和专业预测者放在同一视图中比较。
- [FutureSearch Evaluations](https://evals.futuresearch.ai/)：FutureSearch 官方评测入口，汇总 DRB 与 BTF-2；适合把 deep research agent 与 forecasting agent 的“研究-判断”能力放到同一可复现框架下追踪。
- [Prophet Arena](https://www.prophetarena.co/)：面向 LLM-as-a-Prophet 的实时预测竞技场；适合诊断事件回忆、数据源理解、近兑现信息聚合和概率校准等预测 pipeline 环节。
- [TemporalBench Leaderboard](https://huggingface.co/spaces/Melady/TemporalBench_Leaderboard)：TemporalBench 官方 Hugging Face 榜单；适合比较上下文驱动、事件驱动与时间序列式预测能力。
- [Echo](https://echo.unipat.ai/)：UniPat 的动态未来预测 leaderboard 与训练系统；适合观察多点对齐 Elo、Train-on-Future 与 AI-native prediction API 组合后的持续预测表现。
- [Impermanent Dashboard](https://impermanent.timecopilot.dev/)：TimeCopilot 的 live temporal generalization dashboard；适合跟踪时间序列预测模型在滚动数据流上的真实时间外推表现。
- [FutureX Leaderboard](https://futurex-ai.github.io/)：FutureX 官方每周榜单，用于 live future-event prediction，跟踪动态收集的未兑现事件与 FutureX-Pro 垂直领域任务上的模型表现。
- [CryptoBench Leaderboard](https://cryptobench.space/)：面向加密货币领域的 live benchmark 榜单，围绕专家编写的检索与预测任务持续更新，覆盖链上情报、市场数据、DeFi、衍生品和 MEV 信号。
- [OpenFinArena FinDeepForecast Leaderboard](https://openfinarena.com/fin-deep-forecast)：OpenFinArena 的金融深度预测 live 榜单，用市场 foresight 任务比较 deep-research 和 search-enabled 系统。
- [Prediction Arena](https://www.predictionarena.ai/)：公开 AI forecaster live arena，面向 Kalshi 与 Polymarket 风格问题交易，报告 account value、PnL、return、Sharpe 和 trade history。
- [QuantSightBench Leaderboard](https://quantsightbench.com/)：QuantSightBench 官方区间预测榜单，用 1,000 个真实数值预测问题比较 90% prediction interval 的校准能力。
- [KellyBench Leaderboard](https://www.gr.inc/releases/introducing-kellybench)：General Reasoning 发布的 KellyBench 公开结果表，评测赛季级体育博彩决策 agent，并报告 ROI、ruin avoidance、bankroll 和相对市场的 log loss。
- [Foresight Arena](https://foresightarena.xyz/)：公开链上 AI 预测竞技场，通过概率提交与事后兑现补充 future-event forecasting leaderboard。
