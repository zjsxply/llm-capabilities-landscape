# 3.2 Research

> Parent section: 3. Downstream Applications

## 3.2.1 Leaderboard

- [MLE-bench Leaderboard / Official Results](https://github.com/openai/mle-bench): The official OpenAI MLE-bench repository maintains public results and submission instructions; useful for tracking reproducible performance of ML engineering agents such as AIDE, MLE-STAR, MLEvolve, Famou-Agent, and MARS+ on Kaggle-derived tasks.
- [PaperBench Leaderboard / Official Results](https://github.com/openai/frontier-evals/blob/main/project/paperbench/README.md): The official PaperBench entry in OpenAI Frontier Evals; useful for comparing long-horizon research-coding agents under paper reproduction, code development, and rubric grading.
- [MLRC-Bench Leaderboard](https://huggingface.co/spaces/launch/MLRC_Bench): The official Hugging Face leaderboard for MLRC-Bench; useful for observing agents' ability to advance more open ML research challenges.
- [ResearchCodeBench Leaderboard](https://researchcodebench.github.io/leaderboard/index.html): The official ResearchCodeBench leaderboard; useful for comparing whether models and coding agents can implement unseen research code from recent ML papers.
- [SciArena](https://sciarena.allen.ai/): An open evaluation platform for AI2 scientific-literature tasks; useful for tracking scientific literature understanding, cross-paper synthesis, citation-backed answers, and user-preference evaluation.
- [AstaBench Leaderboard](https://huggingface.co/spaces/allenai/asta-bench-leaderboard): The AI2 AstaBench leaderboard; useful for unifying literature understanding, tool use, and science-research tasks into one science-agent evaluation view.
- [CORE-Bench / CORE-Bench Hard](https://hal.cs.princeton.edu/corebench_hard): HAL's CORE-Bench Hard leaderboard; useful for tracking agents' performance on real paper reproducibility tasks.

## 3.2.2 Survey

- [LLM4SR: A Survey on Large Language Models for Scientific Research](https://arxiv.org/abs/2501.04306): Surveys scientific literature, hypothesis generation, experimentation, data analysis, and writing.
- [Transforming Science with Large Language Models: A Survey on AI-assisted Scientific Discovery, Experimentation, Content Generation, and Evaluation](https://arxiv.org/abs/2502.05151): Reviews AI-assisted scientific discovery from experimentation through content generation and evaluation.
- [Agentic AI for Scientific Discovery: A Survey of Progress, Challenges, and Future Directions](https://arxiv.org/abs/2503.08979): Focuses on autonomous scientific workflows, tool use, and reliability challenges.

- [Deep Research: A Survey of Autonomous Research Agents](https://arxiv.org/abs/2508.12752): Reviews search, synthesis, reasoning, citation, and long-horizon research-agent workflows.

## 3.2.3 Bench

- [MLAgentBench](https://arxiv.org/abs/2310.03302) ([open-source code](https://github.com/snap-stanford/MLAgentBench)): Evaluates end-to-end automation of machine-learning research tasks. Core idea: package research tasks, execution environments, and scoring protocols into a reproducible platform, measuring whether agents can actually produce runnable experiments and effective improvements.
- [ResearchArena](https://arxiv.org/abs/2406.10291) ([open-source code](https://github.com/cxcscmu/ResearchArena)): Evaluates academic research and survey generation. Core idea: use an offline paper environment and survey-writing protocol to test whether agents can retrieve relevant literature, compare methods, and organize field-level research narratives.
- [DiscoveryBench](https://arxiv.org/abs/2407.01725) ([open-source code](https://github.com/allenai/discoverybench)): Evaluates data-driven scientific discovery. Core idea: use real scientific data and hypothesis generation/verification workflows to evaluate whether agents can propose and test meaningful scientific conclusions.
- [SciCode](https://arxiv.org/abs/2407.13168) ([open-source code](https://github.com/scicode-bench/SciCode)): Evaluates scientific coding for real research problems. Core idea: problems are scientist-curated, provide gold solutions/tests, and decompose research problems into subproblems requiring knowledge recall, reasoning, and code synthesis.
- [Can LLMs Generate Novel Research Ideas?](https://arxiv.org/abs/2409.04109): Evaluates research-idea generation through a large human study with NLP researchers. Core idea: compare expert-written and LLM-generated ideas under blind review, finding stronger perceived novelty but weaker feasibility while exposing self-evaluation and diversity gaps in ideation agents.
- [CORE-Bench / CORE-Bench Hard](https://arxiv.org/abs/2409.11363): Evaluates computational reproducibility of published research. Core idea: convert papers, code, data, and execution environments into reproduction tasks operated by agents, serving as an important baseline for the "research reproduction" line before PaperBench; HAL separately maintains CORE-Bench Hard as an entry for a harder reproducibility subset.
- [MLE-bench](https://arxiv.org/abs/2410.07095) ([open-source code](https://github.com/openai/mle-bench)): Evaluates machine-learning engineering and data-science competition modeling across 75 Kaggle competitions, scored by competition metrics after generating `submission.csv` and aggregated with `Any Medal`. Core idea: put data loading, EDA, feature engineering, model selection, tuning, training, validation, submission-format repair, and long experiment iteration from real ML engineering into one executable benchmark; the official release also provides a 22-task Low/Lite split to reduce the 3.3TB data and 24-hour run cost of full evaluation.
- [OpenScholar / ScholarQABench](https://arxiv.org/abs/2411.14199) ([open-source code](https://github.com/AkariAsai/OpenScholar); [demo](https://open-scholar.allen.ai/)): Evaluates large-scale scientific literature search and citation-backed synthesis. Core idea: pair a retrieval-augmented literature model with expert-written multi-domain scientific queries, long-form reference answers, and citation-accuracy checks, directly supporting ARIS-style multi-source literature search.
- [RE-Bench](https://arxiv.org/abs/2411.15114) ([open-source code](https://github.com/METR/RE-Bench)): Evaluates real research-engineering tasks in AI R&D automation, covering open-ended R&D work such as algorithm design, experiment execution, and result analysis. Core idea: complement MLE-bench's Kaggle competition protocol by emphasizing research-engineer-style problem solving, code experiments, and research judgment.
- [MLGym](https://arxiv.org/abs/2502.14499) ([open-source code](https://github.com/facebookresearch/MLGym)): Evaluates interactive ML research environments and benchmarks for AI research agents. Core idea: turn open-ended machine-learning research tasks into Gym-style environments so agents can repeatedly experiment, observe results, and improve research plans.
- [Mind the Blind Spots](https://arxiv.org/abs/2502.17086): Evaluates LLM-generated peer reviews at the focus/facet level. Core idea: compare attention distributions over review facets against human-review priorities so review quality is judged beyond surface overlap or generic helpfulness.
- [Is Your Paper Being Reviewed by an LLM?](https://arxiv.org/abs/2502.19614): Benchmarks AI-text detection in peer review. Core idea: build peer-review-specific detection resources so academic-integrity evaluation covers whether LLM-written reviews can be distinguished in the domain where the harm occurs.
- [BixBench](https://arxiv.org/abs/2503.00096) ([open-source code](https://github.com/Future-House/BixBench), [dataset](https://huggingface.co/datasets/futurehouse/BixBench)): Evaluates agents on real bioinformatics data-analysis tasks. Core idea: derive multi-step open-ended questions from Code Ocean capsules, requiring agents to explore data, run analysis, and explain results, emphasizing scientific data analysis rather than paper QA alone.
- [Relative Neighbor Density](https://arxiv.org/abs/2503.01508): Provides a domain-agnostic novelty-assessment metric for AI scientist idea evaluation. Core idea: compare an idea's local density against neighboring densities and create scalable test sets without expert labels, giving research-ideation systems a reusable novelty signal.
- [No Evidence for LLMs Being Useful in Problem Reframing](https://arxiv.org/abs/2503.01631): Evaluates LLM-assisted problem reframing in a controlled design study. Core idea: compare free-form, direct-generation, and theory-structured GPT-4o use against manual reframing, finding no quality gain and warning that current LLM assistance can reduce agency or widen expertise gaps.
- [Automatic Evaluation Metrics for Artificially Generated Scientific Research](https://arxiv.org/abs/2503.05712): Studies reusable metrics for evaluating AI-generated research. Core idea: compare citation-count prediction and review-score prediction over OpenReview-derived paper metadata and hypotheses, exposing where proxy-review metrics can and cannot replace expert review.
- [CLAIMCHECK](https://arxiv.org/abs/2503.21717): Evaluates whether LLM critiques of scientific papers are grounded in the claims they challenge. Core idea: map review weaknesses to disputed paper claims, fine-grained labels, rewrites, and grounded verification so claim-level critique can be judged beyond generic review fluency.
- [SciReplicate-Bench](https://arxiv.org/abs/2504.00255) ([open-source code](https://github.com/xyzCS/SciReplicate-Bench)): Evaluates algorithm reproduction from recent research papers. Core idea: require agents to understand algorithm descriptions in papers, retrieve dependencies, and write executable code, jointly measuring research reproduction ability with reasoning graph accuracy and execution accuracy.
- [PaperBench](https://arxiv.org/abs/2504.01848): Evaluates reading papers and reproducing experiments/implementations in a fresh sandbox, followed by rubric grading. Core idea: treat "can actually reproduce/run it" as the core acceptance criterion, emphasizing sandbox reruns and rubric judges rather than superficial similarity of generated code.
- [MLRC-Bench](https://arxiv.org/abs/2504.09702) ([Leaderboard](https://huggingface.co/spaces/launch/MLRC_Bench)): Evaluates agent performance on machine-learning research challenges from more open ML research-challenge scenarios. Core idea: push "can complete competition modeling" further toward "can advance research challenges," making it a transitional evaluation between MLE-bench and MLR-Bench.
- [arXiv2Table](https://arxiv.org/abs/2504.10284): Evaluates literature-review table generation from pools of papers. Core idea: move beyond oracle schemas by adding realistic user demands, retrieval distractors, and utilization-oriented scoring for research-synthesis tables.
- [ArXivBench](https://arxiv.org/abs/2504.10496): Evaluates academic-writing assistance through accurate arXiv reference generation. Core idea: test whether models can produce relevant real papers and valid arXiv links across major subject categories and computer-science subfields, exposing hallucinated citations in research workflows.
- [MASSW](https://aclanthology.org/2025.findings-naacl.127/) ([dataset](https://osf.io/7ygrq/?view_only=3d8261a0ea09489fa67ece2c68235afa)): Evaluates AI-assisted scientific workflows. Core idea: turn multi-step scientific work practices into benchmark tasks, covering workflow planning and execution rather than only paper QA.
- [CSR-Bench](https://aclanthology.org/2025.naacl-long.633/): Evaluates LLM agents deploying computer-science research repositories. Core idea: connect paper/repository understanding with environment setup, execution, and debugging, making research-repo deployment a concrete benchmark task.
- [MLE-Dojo](https://arxiv.org/abs/2505.07782) ([open-source code](https://github.com/MLE-Dojo/MLE-Dojo)): Evaluates interactive machine-learning engineering agents in Gym-style executable environments. Core idea: build feedback-loop tasks from 200+ Kaggle challenges so agents can iteratively experiment, debug, verify outcomes, and be trained or evaluated under realistic long-horizon ML workflows.
- [Re2](https://arxiv.org/abs/2505.07920): Provides a consistency-ensured dataset for full-stage peer review and multi-turn rebuttal discussion. Core idea: pair initial submissions, reviews, rebuttals, and discussion signals so review and rebuttal agents can be trained or evaluated on a more complete publication workflow.
- [BAISBench](https://arxiv.org/abs/2505.08341) (artifacts: no accessible public repository or dataset endpoint found during URL check): Evaluates biology AI scientists driven by omics data. Core idea: use real single-cell transcriptomics data to construct cell-type annotation and scientific discovery QA, assessing whether agents can derive meaningful biological conclusions from experimental data.
- [Research Impact Summarization](https://arxiv.org/abs/2505.14838): Evaluates time-aware summaries of a paper's scientific impact. Core idea: use fine-grained temporal citation-intent analysis to capture confirmation, critique, and evolution of influence, then score whether generated summaries are nuanced and useful to researchers.
- [SciArena](https://sciarena.allen.ai/SciArena_An_Open_Evaluation_Platform_for_Foundation_Models_in_Scientific_Literature_Tasks.pdf) ([platform](https://sciarena.allen.ai/)): Evaluates scientific literature understanding, synthesis, and citation-backed answers. Core idea: use an open evaluation platform to collect model performance on literature tasks, connecting literature-level understanding and user-preference evaluation to research-agent assessment.
- [Scientist-Bench / AI-Researcher](https://arxiv.org/abs/2505.18705) ([open-source code](https://github.com/HKUDS/AI-Researcher)): Evaluates autonomous scientific innovation across literature review, hypothesis generation, algorithm implementation, and manuscript preparation. Core idea: combine guided innovation and open-ended exploration tasks to test whether a research agent can convert scientific context into implemented and written research contributions.
- [MLR-Bench](https://arxiv.org/abs/2505.19955) ([open-source code](https://github.com/chchenhui/mlrbench)): Evaluates open-ended machine-learning research, from idea to proposal to experimentation to paper writing, with both end-to-end and staged evaluation. Core idea: provide `MLR-Judge` and `MLR-Agent` scaffolds to make the research process reproducible and reviewable, explicitly exposing reliability failure modes such as experiment fabrication or invalid results.
- [Reviewing Scientific Papers for Critical Problems With Reasoning LLMs](https://arxiv.org/abs/2505.23824): Evaluates LLMs as manuscript quality checkers. Core idea: define baseline approaches and an automatic evaluation framework for finding critical problems in scientific papers without treating full review generation as the only target.
- [Scientific Novelty Detection](https://arxiv.org/abs/2505.24615): Evaluates whether LLMs can judge research-idea novelty with datasets in marketing and NLP. Core idea: compare idea-level novelty against closure sets of related papers, separating conceptual novelty from surface text similarity.
- [EXP-Bench](https://arxiv.org/abs/2505.24785) ([open-source code](https://github.com/Just-Curieous/Curie/tree/main/benchmark/exp_bench)): Evaluates whether AI agents can complete full AI research experiments. Core idea: given a research question and incomplete starter code, require agents to propose hypotheses, design experiments, implement, execute, and analyze results, directly evaluating end-to-end experimental ability.
- [MIR](https://arxiv.org/abs/2506.00249): Evaluates methodology-inspiration retrieval for scientific research problems. Core idea: define retrieval of prior work that can inspire a given problem, then provide a dataset, baselines, and a Methodology Adjacency Graph to test whether retrievers find conceptually useful methodological analogues.
- [ResearchCodeBench](https://arxiv.org/abs/2506.02314) ([project page](https://researchcodebench.github.io/); [open-source code](https://github.com/PatrickHua/ResearchCodeBench)): Evaluates implementation of unseen research code from the latest machine-learning papers. Core idea: construct 212 executable coding challenges from 2024-2025 top-conference papers, specifically testing whether models can translate new research contributions into code.
- [KRAMABENCH](https://arxiv.org/abs/2506.06541) ([project page](https://kramabench.org/); [open-source code](https://github.com/mitdbg/KramaBench), [dataset](https://huggingface.co/datasets/eugenie-y/KramaBench)): Evaluates data-to-insight pipelines over data lakes. Core idea: require agents to perform data discovery, cleaning, integration, statistical inference, and Python pipeline orchestration, covering open data-science research workflows beyond MLE-bench.
- [CLAIM-BENCH](https://arxiv.org/abs/2506.08235): Evaluates scientific claim-evidence extraction and validation in full-length AI papers. Core idea: use expert-annotated claim-evidence pairs to test whether models can identify claims, retrieve dispersed support, and validate the logical links underlying scientific argumentation.
- [Breaking the Reviewer](https://arxiv.org/abs/2506.11113): Evaluates automated peer review under textual adversarial attacks. Core idea: test whether LLM-generated reviews remain useful and reliable when manuscripts contain adversarial perturbations, exposing robustness risks in AI-assisted reviewing.
- [LLM Speedrunner](https://arxiv.org/abs/2506.22419) ([open-source code](https://github.com/facebookresearch/llm-speedrunner)): Evaluates agents reproducing NanoGPT speedrun improvements. Core idea: turn a living ML systems competition into executable reproduction tasks, requiring agents to understand a previous training script, implement a published speedup, and verify gains under the benchmark harness.
- [RExBench](https://arxiv.org/abs/2506.22598) ([project page](https://rexbench.com/)): Evaluates whether coding agents can implement AI research extensions. Core idea: give agents published papers and original codebases as context, ask them to implement expert-authored new experiments/extensions, and evaluate research-extension ability through automatic execution and metric checks.
- [AbGen](https://aclanthology.org/2025.acl-long.611/): Evaluates ablation-study design and evaluation for scientific research. Core idea: test whether models can decide what to ablate, predict what evidence matters, and judge experimental conclusions rather than only summarize papers.
- [LimitGen](https://arxiv.org/abs/2507.02694): Evaluates whether LLMs can identify critical limitations in AI research papers. Core idea: combine a limitation-type taxonomy with synthetic perturbation and human-written limitation subsets so review-assistance models are judged on substantive weakness discovery.
- [AblationBench](https://arxiv.org/abs/2507.08038) ([project page](https://ablation-bench.github.io/); [open-source code](https://github.com/ai-scientist-bench/ablation-bench)): Evaluates automated ablation planning for empirical AI research. Core idea: split the task into author-side ablation proposal from method sections and reviewer-side missing-ablation detection from full papers, matching ARIS-style reviewer-perspective ablation planning after preliminary results.
- [AirQA](https://arxiv.org/abs/2509.16952): Evaluates AI-research paper question answering with 13,956 papers, multimodal and multi-task questions, and instance-level scoring. Core idea: pair paper-QA evaluation with ExTrActor-generated interaction trajectories for training and testing tool-using research agents.
- [Sci2Pol-Bench](https://arxiv.org/abs/2509.21493) ([open-source code](https://github.com/WeiminWu2000/Sci2Pol), [dataset](https://huggingface.co/datasets/Northwestern-CSSI/Sci2Pol-Bench)): Evaluates research translation from scientific papers to policy briefs. Core idea: split completion, understanding, summarization, generation, and verification into five-stage writing tasks, measuring whether models can turn scientific evidence into usable material for policy readers.
- [ReviewScore](https://arxiv.org/abs/2509.21679): Evaluates detection of misinformed peer-review points. Core idea: reconstruct explicit and implicit premises behind review weaknesses or questions, then score whether those premises are contradicted or answered by the paper so review factuality can be measured beyond fluency.
- [EvidenceBench](https://openreview.net/forum?id=lEQnUI5lEA): Evaluates evidence extraction from biomedical papers. Core idea: require models to locate and extract claim-supporting evidence in scientific texts, a key subtask for literature-grounded research agents.
- [MoSciBench](https://openreview.net/forum?id=kZHSvETWdi) ([open-source code](https://github.com/usail-hkust/MoSciBench)): Evaluates multimodal data-driven scientific discovery. Core idea: require agents to align heterogeneous data, model, explain, and complete hypothesis verification in end-to-end scientific tasks, linking multimodal understanding with scientific analysis workflows.
- [FML-bench](https://arxiv.org/abs/2510.10472) ([open-source code](https://github.com/qrzou/FML-bench)): Evaluates agents' iterative improvement ability on foundational machine-learning research problems. Core idea: provide baseline code, an evaluation harness, and a research-task description, requiring agents to iterate like researchers rather than only optimize application metrics.
- [PaperArena](https://arxiv.org/abs/2510.10909) ([project page](https://paperarena-ai.github.io/); [open-source code](https://github.com/Melmaphother/PaperArena)): Evaluates multi-paper, tool-assisted scientific literature reasoning. Core idea: require agents to call parsing, retrieval, computation, and other tools to integrate multi-format evidence from multiple papers into grounded answers.
- [BadScientist](https://arxiv.org/abs/2510.18003): Evaluates whether fabricated research-agent papers can fool LLM reviewers. Core idea: pair a fabrication-oriented paper-generation agent with calibrated review evaluation to measure vulnerabilities in automated publication and review loops.
- [AstaBench](https://arxiv.org/abs/2510.21652) ([open-source code](https://github.com/allenai/asta-bench); [Leaderboard](https://huggingface.co/spaces/allenai/asta-bench-leaderboard)): Evaluates comprehensive research-agent abilities. Core idea: unify literature retrieval, code execution, data analysis, scientific discovery, and other tasks in the Asta science-agent suite, with standardized tool environments and a public leaderboard for comparing agents.
- [ReplicationBench](https://arxiv.org/abs/2510.24591): Evaluates whether agents can reproduce the core contributions of experimental astrophysics papers. Core idea: split full papers into key tasks co-designed by original authors and evaluate faithfulness and correctness separately, closer to real research reproduction.
- [LMR-BENCH](https://aclanthology.org/2025.emnlp-main.314/): Evaluates LLM agents reproducing language-modeling research. Core idea: test paper understanding, experimental setup, code execution, and result reproduction within the language-modeling subfield.
- [Paper2SysArch](https://arxiv.org/abs/2511.18036): Evaluates system-architecture diagram generation from scientific papers. Core idea: pair papers with ground-truth architecture diagrams and score semantic accuracy, layout coherence, and visual quality so research-communication artifacts are evaluated beyond plain text or slide decks.
- [FLAWS](https://arxiv.org/abs/2511.21843): Evaluates error identification and localization in scientific papers. Core idea: provide automated Fault Localization Across Writing in Science tasks so LLM reviewers are judged on whether they can pinpoint concrete paper errors rather than only produce plausible review prose.
- [SGI-Bench](https://arxiv.org/abs/2512.16969) (paper: Probing Scientific General Intelligence of LLMs with Scientist-Aligned Workflows): Evaluates scientific general intelligence aligned with research workflows. Core idea: use scientist-aligned workflows as a unified protocol to assess end-to-end performance in retrieval, reasoning, experiment planning, and result organization.
- [AInsteinBench](https://arxiv.org/abs/2512.21373) ([open-source code](https://github.com/ByteDance-Seed/AInsteinBench)): Evaluates repository-level development ability in scientific computing/research software ecosystems, based on real scientific codebases and maintainer PR-derived tasks. Core idea: place scientific research software development back into the realistic context of executable environments, test verification, and science-semantic failure modes, measuring whether agents have research-grade engineering ability.
- [HeurekaBench](https://arxiv.org/abs/2601.01678) ([open-source code](https://github.com/mlbio-epfl/HeurekaBench), [project page](https://brbiclab.epfl.ch/projects/heurekabench/)): Evaluates AI co-scientists on real experimental-data-driven research problems. Core idea: use open-ended single-cell analysis tasks such as sc-HeurekaBench to evaluate whether co-scientist agents can propose testable hypotheses, execute analyses, and improve scientific conclusions with a critic module.
- [APEX / APEX-Bench](https://arxiv.org/abs/2601.04794): Evaluates academic poster editing by agents. Core idea: expose multi-level poster-editing APIs and a review-adjust loop so agents can revise dense scientific visual-text artifacts under fine-grained user instructions.
- [RebuttalBench / Paper2Rebuttal](https://arxiv.org/abs/2601.14171) ([project page](https://mqleet.github.io/Paper2Rebuttal_ProjectPage/); [open-source code](https://github.com/AutoLab-SAI-SJTU/Paper2Rebuttal)): Evaluates AI assistance for academic author responses. Core idea: turn reviewer comments, manuscript evidence, literature search, strategy generation, and human feedback into a transparent rebuttal workflow, so response quality is scored beyond generic writing fluency.
- [FIRE-Bench / Full-cycle Insight Rediscovery Evaluation](https://arxiv.org/abs/2602.02905) ([project page](https://firebench.github.io/); [open-source code](https://github.com/maitrix-org/FIRE-Bench)): Evaluates whether agents can rediscover experimentally grounded insights from influential machine-learning papers. Core idea: start from high-level research questions and require agents to explore ideas, design experiments, implement code, execute plans, and support rediscovered insights with experimental evidence.
- [BABE](https://arxiv.org/abs/2602.05857): Evaluates "experimental reasoning" in biology over scientific materials where textual and visual evidence are intertwined. Core idea: emphasize integrating experimental results with contextual knowledge, testing causal reasoning and cross-scale inference rather than rote biological-knowledge QA.
- [AIRS-Bench](https://arxiv.org/abs/2602.06855) ([open-source code](https://github.com/facebookresearch/airs-bench)): Evaluates end-to-end research workflows for frontier AI research agents. Core idea: put idea generation, experiment analysis, and iterative revision into one task set, specifically observing whether agents can advance real AI research workflows.
- [SciClaimEval](https://arxiv.org/abs/2602.07621) ([project page](https://sciclaimeval.github.io/)): Evaluates cross-modal scientific claim verification in papers. Core idea: pair authentic paper claims, including refuted variants, with textual, figure, and table evidence, making claim-to-evidence checking closer to ARIS paper-claim audits than generic fact verification.
- [SciAgentGym / SciAgentBench](https://arxiv.org/abs/2602.12984) ([project page](https://www.huayusha.org/publication/SciAgentGym/)): Evaluates multi-step tool use by scientific agents. Core idea: provide 1,780 tasks across natural-science tools and hierarchical evaluation sets, specifically stress-testing tool orchestration from single-step calls to long-horizon workflows.
- [DECKBench](https://arxiv.org/abs/2602.13318): Evaluates multi-agent systems for academic slide generation and iterative editing. Core idea: use paper-to-slide pairs plus realistic editing instructions to score content fidelity, deck coherence, layout quality, and multi-turn compliance in research presentation production.
- [ResearchGym](https://arxiv.org/abs/2602.15112) ([project page](https://anikethh.github.io/ResearchGym/); [open-source code](https://github.com/Anikethh/ResearchGym)): Evaluates language-model agents on real-world AI research. Core idea: retain datasets, baselines, and executable evaluation harnesses from real conference-paper repositories while hiding the original method, requiring agents to formulate hypotheses, run experiments, and exceed the available baseline.
- [QEDBench](https://arxiv.org/abs/2602.20629) ([open-source code](https://github.com/qqliu/Yale-QEDBench)): Evaluates alignment gaps in automated evaluation of university-level mathematical proofs. Core idea: compare AI judges against course-specific and expert rubrics, giving proof-checking agents a benchmark for judging natural-language proof quality rather than only generating proofs.
- [PostTrainBench](https://arxiv.org/abs/2603.08640) ([project page](https://posttrainbench.com/); [open-source code](https://github.com/aisa-group/PostTrainBench)): Evaluates whether LLM agents can automate LLM post-training under bounded compute. Core idea: require agents to retrieve methods, prepare data, run training experiments, and optimize target evaluations under a single-H100 budget, exposing research-loop failures such as reward hacking.
- [HindSight](https://arxiv.org/abs/2603.15164): A time-split evaluation framework for LLM-generated research ideas. Core idea: constrain idea generators to pre-cutoff literature, match outputs to future publications, and score them by venue and citation impact rather than only LLM or human preference judgments.
- [CNPE](https://arxiv.org/abs/2603.17588): A comparison-native framework for LLM-based paper evaluation. Core idea: construct informative paper pairs and aggregate relative judgments so scholarly evaluation is less tied to unstable absolute score scales.
- [DiscoGen / DiscoBench](https://arxiv.org/abs/2603.17863) ([project page](https://disco-gen.github.io/); [open-source code](https://github.com/AlexGoldie/discogen)): Evaluates algorithm-discovery agents with procedurally generated machine-learning tasks. Core idea: generate many optimizer, loss-function, and related ML algorithm-discovery tasks, then use a fixed benchmark subset to compare discovery agents under less saturated and less contaminated conditions.
- [PRBench](https://arxiv.org/abs/2603.27646) ([open-source code](https://github.com/HET-AGI/PRBench-Eval-Handson)): Evaluates end-to-end paper reproduction in physics research. Core idea: ask agents to read papers, implement algorithms from scratch in sandboxes, and reproduce quantitative results, broadening executable scientific reproduction beyond machine-learning-only settings.
- [PaperOrchestra / PaperWritingBench](https://arxiv.org/abs/2604.05018) ([open-source code](https://github.com/google-research/paper-orchestra); dataset not included in the code repository at URL-check time): Evaluates automated AI research-paper writing from raw research materials. Core idea: reverse-engineer pre-writing materials from top AI conference papers and score whether agents can produce submission-ready LaTeX manuscripts with literature synthesis, section structure, figures, and content refinement.
- [Can Large Language Models Reinvent Foundational Algorithms?](https://arxiv.org/abs/2604.05716): Evaluates whether LLMs can rediscover foundational computer-science algorithms after targeted unlearning. Core idea: remove knowledge of algorithms such as Dijkstra or Euclid, vary hint levels, and measure reinvention as a controlled proxy for foundational research innovation.
- [SciPredict](https://arxiv.org/abs/2604.10718): Evaluates natural-science experiment outcome prediction. Core idea: isolate "can the result be judged before the experiment is run" as a scientific prediction task, testing whether LLMs/agents can move beyond knowledge QA to form verifiable experimental forecasts.
- [ArcBench / ArcDeck](https://arxiv.org/abs/2604.11969) ([project page](https://arcdeck.org/); [open-source code](https://github.com/RehgLab/ArcDeck), [dataset](https://huggingface.co/datasets/ArcDeck/ArcBench)): Evaluates narrative-driven paper-to-slide generation. Core idea: use academic paper-slide pairs to score whether agents preserve logical flow, narrative commitments, figures, and visual presentation quality when converting papers into research talks.
- [AI-Assisted Peer Review at Scale / AAAI-26 AI Review Pilot](https://arxiv.org/abs/2604.13940): Evaluates AI assistance in real conference peer review. Core idea: use an AAAI-26 pilot to study whether AI reviewers can surface scientific weaknesses at scale while preserving human oversight, reviewer usefulness, and process transparency.
- [REVIEWBENCH / ReviewGrounder](https://arxiv.org/abs/2604.14261): Evaluates and improves substantive AI peer review. Core idea: derive paper-specific rubrics from guidelines, manuscript content, and human reviews, then use a rubric-guided tool-integrated agent to ground shallow review drafts in evidence.
- [What Makes a Good AI Review?](https://arxiv.org/abs/2604.19998): Evaluates AI peer review at the concern level. Core idea: align official and AI-generated review concerns with severity and post-rebuttal treatment, exposing whether automated reviewers identify and prioritize the right scientific issues rather than merely matching final accept/reject tendencies.
- [ResearchClawBench](https://github.com/InternScience/ResearchClawBench) ([dataset mirror](https://huggingface.co/datasets/InternScience/ResearchClawBench)): Evaluates end-to-end automated research from re-discovery to new-discovery in the OpenClaw/InternScience ecosystem. Core idea: organize tasks with real data files, database queries, and multi-step inference, testing whether agents can form verifiable conclusions from complex life-science evidence.
- [Multimodal Conference Dataset / MCD](https://arxiv.org/abs/2605.05831): Evaluates fine-grained correspondence across papers, slides, presentation videos, and explanatory videos. - [InciteResearch / TF-Bench](https://arxiv.org/abs/2605.06345): Evaluates pre-question scientific ideation. Core idea: start from vague or domain-distant research friction, elicit a structured researcher profile, violate hidden assumptions, and judge whether agents can turn tacit insight into explicit, feasible, and novel research proposals.
- [PDEAgent-Bench](https://arxiv.org/abs/2605.09636): Evaluates executable numerical solver generation from PDE specifications. Core idea: use professional FEM libraries such as DOLFINx, Firedrake, and deal.II, evaluating scientific coding agents on runnability, numerical accuracy, and efficiency.
- [Ambig-DS](https://arxiv.org/abs/2605.09698): Evaluates whether data-science agents proactively clarify under task-framing ambiguity. Core idea: construct ambiguous target-variable/evaluation-goal tasks based on DSBench and MLE-bench, exposing hidden failures where artifacts run but the task was misunderstood.
- [SciIntegrity-Bench](https://arxiv.org/abs/2605.10246) ([open-source code](https://github.com/liuxingtong/Sci-Integrity-Bench)): Evaluates academic integrity of AI scientists. Core idea: construct dilemmatic scenarios where agents can only honestly admit failure and cannot complete by fabricating data/results, assessing whether agents commit academic misconduct under completion pressure.
- [Collider-Bench](https://arxiv.org/abs/2605.13950) (open-source code and task corpus are described in the paper): Evaluates reproduction of particle-physics experimental analyses. Core idea: require agents to reproduce simulation-and-selection pipelines from LHC papers and public software, scoring with continuous histogram metrics and trajectory audits, complementing real scientific reproducibility tasks.
- [1GC-7RC](https://arxiv.org/abs/2605.17046) (code: paper reports a GitHub release, but no accessible public repository was found during URL check): Evaluates coding agents on seven machine-learning research challenges under a one-GPU budget. Core idea: stress from-scratch model training, experiment design, and result verification in a controlled compute setting that complements Kaggle-style MLE-bench tasks.
- [FML-Bench Search Dynamics Study](https://arxiv.org/abs/2605.17373) ([open-source code](https://github.com/qrzou/FML-bench)): Re-examines FML-Bench from the perspective of research-agent search strategy. - [ResearchArena / True Auto Research](https://youarespecialtome.github.io/ResearchArena/index.html) ([open-source code](https://github.com/YouAreSpecialToMe/ResearchArena)): Evaluates frontier CLI agents conducting end-to-end research across 117 generated papers and 13 domains. Core idea: combine Stanford Agentic Reviewer, multi-agent peer review, code-aware artifact review, and manual integrity checks to expose gaps in experimental rigor, result faithfulness, and reference integrity.
- [REFLECT](https://arxiv.org/abs/2605.19196): Evaluates LLM evaluators of evidence-based deep research agents through controlled interventions. Core idea: perturb evidence, claims, and review conditions so evaluator reliability can be measured rather than assumed from final scores alone.
