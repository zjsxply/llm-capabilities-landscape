# 4.4.4 Agent Harness

- [Drive Like A Human](https://arxiv.org/abs/2307.07162) ([open-source code](https://github.com/PJLab-ADG/DriveLikeAHuman)): An early closed-loop LLM driving harness in HighwayEnv, useful as a precursor for later memory/reflection-based autonomous-driving agents.
- [DiLu](https://arxiv.org/abs/2309.16292) ([open-source code](https://github.com/PJLab-ADG/DiLu)): A closed-loop self-evolving driving framework with environment, reasoning, reflection, and memory modules, making driving decisions through an explicit agent loop rather than a single perception model.
- [Agent-Driver](https://arxiv.org/abs/2311.10813) ([open-source code](https://github.com/physical-superintelligence-lab/Agent-Driver); [project page](https://usc-gvl.github.io/Agent-Driver/)): An LLM cognitive agent for autonomous driving with function-call tools, cognitive memory, reasoning, task planning, motion planning, and self-reflection.
- [Parallel Actor-Reasoner Framework](https://arxiv.org/abs/2503.00502): An LLM-driven harness for autonomous-vehicle interaction. Core idea: separate a slow reasoning module from an interaction-memory Actor so vehicles can communicate intentions and improve interaction decisions without relying on real-time LLM inference for every action.
- [AgentThink](https://arxiv.org/abs/2505.15298): A tool-augmented reasoning harness for autonomous-driving VLMs. Core idea: build a driving tool library and structured self-verified reasoning data so agents can invoke tools during chain-of-thought style driving perception and decision tasks.
- [AGENTS-LLM](https://arxiv.org/abs/2507.13729): An agentic LLM framework for generating challenging traffic scenarios. Core idea: use LLM-driven scenario augmentation to stress autonomous-driving agents with harder, more diverse traffic situations than fixed scenario libraries provide.
- [MTRDrive](https://arxiv.org/abs/2509.20843): An autonomous-driving reasoning harness that combines procedural memory retrieval with dynamic tools for corner cases. Core idea: close the loop among driving experience memory, tool calls, and proactive decisions so out-of-distribution driving scenarios are handled as agent trajectories rather than static perception.
- [SafeCoop](https://arxiv.org/abs/2510.18123): An agentic defense harness for natural-language collaborative driving. Core idea: combine a semantic firewall, language-perception consistency checks, multi-source consensus, and spatial-frame transformation to detect and mitigate attacks on V2X language communication.
- [Dream2Drive](https://doi.org/10.1109/IJCNN64981.2025.11228910): An LLM-based vehicle motion-planning agent for multi-task driving. Core idea: combine observation, short-term memory, long-term experience, planning, and rethinking modules so driving decisions can reuse prior experience across real-world planning tasks.
- [Agentic Fast-Slow Planning](https://arxiv.org/abs/2604.01681): An autonomous-driving agent harness that separates slow large-model reasoning from fast control. Core idea: compress scenes into ego-centric topology, map them to symbolic driving directives, and bridge those directives to real-time MPC-style control so language reasoning does not directly drive brittle trajectories.
