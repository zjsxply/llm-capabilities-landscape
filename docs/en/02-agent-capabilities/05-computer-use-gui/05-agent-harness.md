# 2.5.5 Agent Harness

- [AppAgent](https://arxiv.org/abs/2312.13771) ([open-source code](https://github.com/mnotgod96/AppAgent); [project page](https://appagent-official.github.io/)): An early smartphone GUI agent harness that learns app operation through autonomous exploration or human demonstrations, then reuses the generated operation documents for later tasks.
- [SeeAct](https://arxiv.org/abs/2401.01614) ([open-source code](https://github.com/OSU-NLP-Group/SeeAct); an early web GUI agent paradigm combining visual grounding with structural information, later absorbed by many CUA variants)
- [SeeClick: Harnessing GUI Grounding for Advanced Visual GUI Agents](https://arxiv.org/abs/2401.10935): A GUI grounding agent built around screen-only action prediction; it converts screenshots into clickable coordinates and uses GUI-specific pretraining to support visual operation across web, desktop, and mobile interfaces.
- [Mobile-Agent: Autonomous Multi-Modal Mobile Device Agent with Visual Perception](https://arxiv.org/abs/2401.16158): A smartphone GUI control loop that reads screenshots, detects icons and text with visual perception modules, plans the next operation, executes taps or swipes, and iterates with self-reflection when the phone state changes.
- [UFO: A UI-Focused Agent for Windows OS Interaction](https://arxiv.org/abs/2402.07939): A Windows desktop harness with AppAgent and ActAgent roles; it selects the active application, inspects GUI controls and screenshots, grounds actions to Windows UI operations, and keeps task state across multi-app workflows.
- [ScreenAgent: A Vision Language Model-driven Computer Control Agent](https://arxiv.org/abs/2402.07945): A computer-control loop that lets a VLM observe screenshots, reason about the current screen, emit mouse and keyboard operations, and receive updated screen feedback for multi-step desktop tasks.
- [CoCo-Agent: A Comprehensive Cognitive MLLM Agent for Smartphone GUI Automation](https://arxiv.org/abs/2402.11941): A smartphone automation framework that couples perception, memory, reasoning, decision, and reflection modules so the agent can localize screen elements, plan action chains, and revise failed mobile operations.
- [On the Multi-turn Instruction Following for Conversational Web Agents](https://arxiv.org/abs/2402.15057): Studies conversational web agents where user goals arrive over multiple turns, requiring the harness to preserve dialogue context while executing web navigation actions and adapting plans after each page transition.
- [Android in the Zoo: Chain-of-Action-Thought for GUI Agents](https://arxiv.org/abs/2403.02713): Introduces a Chain-of-Action-Thought prompting loop for Android agents, explicitly tracking previous observations and actions before choosing the next GUI API action on smartphone screens.
- [Cradle: Empowering Foundation Agents towards General Computer Control](https://arxiv.org/abs/2403.03186): A general computer-control harness that standardizes screenshots, keyboard and mouse actions, self-reflection, and skill or memory reuse so foundation agents can operate games and desktop software without task-specific APIs.
- [SheetAgent: A Generalist Agent for Spreadsheet Reasoning and Manipulation via Large Language Models](https://arxiv.org/abs/2403.03636): A spreadsheet GUI harness that decomposes workbook tasks, grounds operations in sheet structure, executes cell, formula, and formatting actions, and verifies intermediate spreadsheet state across multi-step manipulations.
- [Mobile-Agent-v2 / Mobile-Agent-E](https://arxiv.org/abs/2406.01014) ([Mobile-Agent-E](https://arxiv.org/abs/2501.11733); [open-source code](https://github.com/X-PLUG/MobileAgent)): A mobile GUI-agent lineage with explicit planning, reflection, multi-agent collaboration, and later self-evolution, bridging AndroidWorld-style tasks and general mobile operation.
- [GUICourse: From General Vision Language Models to Versatile GUI Agents](https://arxiv.org/abs/2406.11317): A curriculum for turning general VLMs into GUI agents, combining screen grounding, action prediction, and staged GUI tasks so models learn reusable observation-action behavior rather than isolated captioning.
- [WebCanvas: Benchmarking Web Agents in Online Environments](https://arxiv.org/abs/2406.12373): Primarily a live-web benchmark, but relevant here because it supplies an online browser interaction harness with evolving pages, action execution, and feedback loops for testing adaptive web agents.
- [Agent-E: From Autonomous Web Navigation to Foundational Design Principles in Agentic Systems](https://arxiv.org/abs/2407.13032): A web-navigation agent architecture distilled into design principles, emphasizing perception, planning, action execution, reflection, and recovery patterns for autonomous browser workflows.
- [WebPilot: A Versatile and Autonomous Multi-Agent System for Web Task Execution with Strategic Exploration](https://arxiv.org/abs/2408.15978): A multi-agent web harness that separates strategic exploration, state assessment, and browser action execution so agents can handle uncertain dynamic sites instead of following rigid hand-coded policies.
- [Navigating the Digital World as Humans Do: Universal Visual Grounding for GUI Agents](https://arxiv.org/abs/2410.05243): A GUI grounding method for agents that predicts actionable screen coordinates from visual input, giving browser, desktop, and mobile agents a human-like click target interface.
- [Agent S](https://arxiv.org/abs/2410.08164) ([open-source code](https://github.com/simular-ai/Agent-S); an integrated computer-use workflow with ACI, hierarchical planning, external knowledge retrieval, and experience memory)
- [TinyClick: Single-Turn Agent for Empowering GUI Automation](https://arxiv.org/abs/2410.11871): A lightweight single-turn GUI agent specialized for localizing the UI element named by a user command, making it useful as a fast click-grounding component inside larger automation loops.
- [AgentStore](https://arxiv.org/abs/2410.18603) ([open-source code](https://github.com/chengyou-jia/AgentStore); an App Store-like platform for dynamic selection and composition of heterogeneous agents)
- [OpenWebVoyager](https://arxiv.org/abs/2410.19609) ([open-source code](https://github.com/MinorJerry/OpenWebVoyager); builds multimodal web agents through real-web exploration, feedback, and optimization, connecting WebArena/VisualWebArena with open-web operation)
- [Is Your LLM Secretly a World Model of the Internet? Model-Based Planning for Web Agents](https://arxiv.org/abs/2411.06559): Adds model-based planning to web agents by predicting webpage transition dynamics, enabling tree-search style evaluation of candidate browser actions before committing to the live page.
- [Aguvis: Unified Pure Vision Agents for Autonomous GUI Interaction](https://arxiv.org/abs/2412.04454): A pure-vision GUI agent route that treats screenshots as the main observation, grounds actions directly on visual interface elements, and targets cross-platform autonomous GUI interaction without relying on DOM text.
