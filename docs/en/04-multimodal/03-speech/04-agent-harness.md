# 4.3.4 Agent Harness

- [AudioGPT](https://arxiv.org/abs/2304.12995) ([open-source code](https://github.com/AIGC-Audio/AudioGPT)): An early audio agent harness that uses ChatGPT/LangChain-style planning to call speech, singing, audio, and talking-head foundation models as tools.
- [WavJourney](https://arxiv.org/abs/2307.14335) ([open-source code](https://github.com/Audio-AGI/WavJourney); [demo](https://audio-agi.github.io/WavJourney_demopage/)): A compositional audio-creation harness that decomposes text intent into story, speech, music, and sound-effect generation workflows.
- [ReelWave](https://arxiv.org/abs/2503.07217): A multi-agent harness for movie sound generation. Core idea: use a Sound Director agent to coordinate on-screen and off-screen sound agents through multimodal conversation, aligning speech, effects, ambience, and music across multi-scene video narratives.
- [Dopamine Audiobook](https://arxiv.org/abs/2504.11002): A training-free multi-agent harness for emotional audiobook generation. Core idea: split speech and audio design roles around multimodal inputs, align speech, sound effects, and music temporally and semantically, and include automated preference-aligned evaluation for immersive audio outputs.
- [AudioGenie](https://arxiv.org/abs/2505.22053): A training-free multi-agent harness for multimodality-to-multiaudio generation. Core idea: coordinate specialized agents for fine-grained multimodal understanding, audio-type planning, and generation so speech, music, songs, and sound effects can be synthesized from mixed inputs.
- [AudioToolAgent](https://arxiv.org/abs/2510.02995) ([open-source code](https://github.com/GLJS/AudioToolAgent)): An agentic harness for audio-language models. Core idea: route audio understanding and generation tasks through external tools so auditory agents can decompose workflows instead of relying only on one end-to-end model call.
- [LVAS-Agent / LVAS-Bench](https://aclanthology.org/2025.emnlp-main.1133/): A multi-agent harness for long-video audio synthesis. Core idea: decompose long-form video-to-audio work into scene segmentation, script generation, audio design, and audio synthesis, with LVAS-Bench providing professionally curated long videos for systematic evaluation.
- [Open Full-duplex Voice Agent](https://doi.org/10.1109/ASRU65441.2025.11434669): An open-source framework for full-duplex speech-to-speech voice agents. Core idea: convert standard text LLMs into spoken agents that can listen and speak with interruption-aware full-duplex interaction rather than turn-isolated text exchange.
- Pipecat ([open-source code](https://github.com/pipecat-ai/pipecat); [docs](https://docs.pipecat.ai/)): An open-source Python framework for real-time voice and multimodal conversational agents, covering STT, LLM, TTS, WebRTC/WebSocket transports, pipeline composition, and subagents.
- LiveKit Agents ([open-source code](https://github.com/livekit/agents); [docs](https://docs.livekit.io/agents/)): A real-time programmable-participant framework for conversational multimodal voice agents, including tool calls, telephony, MCP integrations, job scheduling, and testing support.
- TEN Framework ([open-source code](https://github.com/TEN-framework/ten-framework)): A real-time multimodal conversational-AI framework with voice assistant examples, VAD, turn detection, memory, RTC/WebSocket integrations, and agent orchestration components.
- [AudioFab](https://arxiv.org/abs/2512.24645): An open-source audio-agent framework for tool learning. Core idea: package fragmented audio-processing tools behind a natural-language interface, simplify dependency management, and improve tool selection and collaboration for complex audio tasks.
- [MIST](https://arxiv.org/abs/2605.06897): A multimodal speech-based tool-calling assistant framework for smart homes. Core idea: connect spoken interaction, multimodal context, and executable device tools so tool-use agents can be evaluated and engineered beyond text-only API calls.
