# 2.10.5 Agent Harness

- [HackingBuddyGPT](https://arxiv.org/abs/2308.00121) ([open-source code](https://github.com/ipa-lab/hackingBuddyGPT); [docs](https://docs.hackingbuddy.ai/)): A security-researcher assistant harness for authorized hacking workflows, useful as an early open-source reference for tool-mediated reconnaissance, exploitation attempts, and auditability.
- [PentestGPT](https://arxiv.org/abs/2308.06782) ([open-source code](https://github.com/GreyDGL/PentestGPT); [project page](https://pentestgpt.com/)): An early LLM penetration-testing agent that organizes reasoning, task status, and tool interaction around authorized assessment workflows.
- [HPTSA](https://arxiv.org/abs/2406.01637) ([open-source code](https://github.com/uiuc-kang-lab/HPTSA)): A hierarchical planning and task-specific agent framework for web penetration testing, useful for decomposing exploitation attempts into scoped subagents.
- [EnIGMA](https://arxiv.org/abs/2409.16165) ([open-source code](https://github.com/SWE-agent/SWE-agent); [project page](https://enigma-agent.com/)): A SWE-agent-based cyber harness for CTF and vulnerability tasks, relevant as a reusable scaffold for executable security challenges.
- [AutoPT](https://arxiv.org/abs/2411.01236) ([open-source code](https://github.com/Dizzy-K/AutoPT)): A web penetration-testing automation harness that coordinates reconnaissance, vulnerability analysis, exploitation, and reporting in authorized environments.
- [HackSynth](https://arxiv.org/abs/2412.01778) ([open-source code](https://github.com/aielte-research/HackSynth)): A CTF and penetration-testing harness with planning, tool execution, and benchmark-runner components for reproducible cyber-agent experiments.
- [VulnBot](https://arxiv.org/abs/2501.13411) ([open-source code](https://github.com/KHenryAegis/VulnBot)): An autonomous multi-agent penetration-testing framework. Core idea: use a penetration task graph plus specialized reconnaissance, scanning, and exploitation agents to coordinate end-to-end testing.
- [Rule-ATT&CK Mapper (RAM)](https://arxiv.org/abs/2502.02337): Maps structured SIEM rules to MITRE ATT&CK techniques through a multi-stage LLM pipeline with external contextual knowledge.
- [Autonomous Assumed Breach Penetration Testing](https://arxiv.org/abs/2502.04227): An Active Directory penetration-testing harness for LLM-driven agents. Core idea: run autonomous assumed-breach workflows in a GOAD-style Microsoft Active Directory testbed and analyze account-compromise behavior across reasoning and non-reasoning models.
- [ARACNE](https://arxiv.org/abs/2502.18528): An autonomous shell pentesting agent for SSH and Linux shell environments. Core idea: use a multi-LLM architecture for command execution and exploitation attempts, providing a focused baseline for terminal-mediated pentesting agents.
- [CRAKEN](https://arxiv.org/abs/2505.17107) ([open-source code](https://github.com/NYU-LLM-CTF/nyuctf_agents_craken)): A knowledge-based cybersecurity LLM-agent harness. Core idea: combine task-critical decomposition, iterative retrieval, and knowledge-hint injection for CTF and MITRE-style attack execution.
- [VulBinLLM](https://arxiv.org/abs/2505.22010): An LLM-powered workflow for vulnerability detection in stripped binaries. Core idea: organize binary-analysis evidence, code metrics, and language-model reasoning into a security-analysis loop for cases where source-level context is unavailable.
- [ELFuzz](https://arxiv.org/abs/2506.10323): An LLM-driven fuzzing harness for automated input-generator synthesis. Core idea: evolve seed fuzzers with coverage feedback so agents can construct system-specific fuzzers instead of relying on manually written grammars and constraints.
- [Perry](https://arxiv.org/abs/2506.20770): A high-level experimentation harness for cyber deception. Core idea: let operators specify attackers, defenders, and deception strategies abstractly, then translate them into realistic emulated-network experiments.
- [Locus](https://arxiv.org/abs/2508.21302): An agentic predicate-synthesis harness for directed fuzzing. Core idea: use agents to synthesize predicates that guide fuzzers toward security-relevant program states, connecting reasoning, program analysis, and executable testing feedback.
- [PentestMCP](https://arxiv.org/abs/2510.03610) ([open-source code](https://github.com/Craftzman7/pentest-mcp)): A toolkit of MCP servers for agentic penetration testing. Core idea: expose scanning, enumeration, exploitation, and post-exploitation functions as composable tools for security-agent workflows.
- [Automated Threat Emulation Framework with LLMs for Cyber Physical Systems](https://doi.org/10.1109/CogMI67134.2025.00059): A threat-emulation harness for cyber-physical systems. Core idea: use LLM-driven automation to structure adversary emulation workflows over CPS evidence and operations, making threat testing more repeatable than ad hoc manual exercises.
- [Agentic RAG for Command Generation in Automated Penetration Testing](https://doi.org/10.1109/SPCNC68200.2025.11406223): A retrieval-driven command-generation harness for penetration-testing agents. Core idea: extend PentestGPT-style workflows with multi-step retrieval over a structured knowledge base so generated commands can close reasoning-time knowledge gaps.
- [Retrieval-Augmented Reasoning for Offensive Security](https://doi.org/10.1109/FLLM67465.2025.11391064): A retrieval-first CTF automation harness for offensive-security agents. Core idea: couple a benchmark-clean domain corpus with a lightweight tool-agnostic RAG pipeline so multi-step CTF reasoning is grounded in relevant exploitation knowledge.
- [Agentic Penetration Testing using Secure Shell](https://doi.org/10.1109/Cyber-AI66431.2025.11233438): An SSH-centered feedback-loop harness for penetration-testing agents. Core idea: use open-source LLMs to generate context-aware Linux commands, analyze command output, and recommend next vulnerability-assessment steps.
- [LIMA](https://doi.org/10.1109/FMLDS67896.2025.00135): A penetration-testing harness that pairs LLMs with MCP servers for initial machine access. Core idea: expose authorized foothold-discovery steps through structured MCP tools so LLM agents can coordinate reconnaissance, access attempts, and evidence collection.
- [Automated Penetration Test Framework for ICS](https://doi.org/10.1109/ICBDSE65491.2025.11220032): A multi-agent collaboration harness for penetration testing in industrial control systems. Core idea: coordinate specialized agents around ICS reconnaissance, vulnerability analysis, and attack-path reasoning to support authorized cyber assessment workflows.
- [LLM-Driven Automated Penetration Testing](https://doi.org/10.1109/ICSSS66939.2025.11346427): A penetration-testing architecture and benchmark-oriented framework for LLM agents. Core idea: organize reconnaissance, exploitation planning, execution feedback, and safety controls into a reusable automated pentest workflow.
- [Cybersecurity AI](https://arxiv.org/abs/2512.02654) ([open-source code](https://github.com/aliasrobotics/cai); [project page](https://aliasrobotics.com/cybersecurityai.php)): A security CTF agent system. Core idea: organize cyber challenge solving around agentic planning, tool use, and iterative verification, making it relevant as a harness reference for executable CTF-style evaluation.
- [Automated Penetration Testing with LLM Agents and Classical Planning](https://arxiv.org/abs/2512.11143): A penetration-testing harness that combines LLM agents with symbolic planning. Core idea: use classical planning to structure reconnaissance and exploitation steps while LLM agents handle interpretation and tool interaction.
- [Agentic AI for Autonomous Defense in Software Supply Chain Security](https://arxiv.org/abs/2512.23480): Uses agents to detect, reason about, and mitigate software-supply-chain vulnerabilities during development and delivery workflows.
- [DeepAttacker](https://doi.org/10.1109/isaics66888.2025.11350066): Coordinates attacker roles and security-test steps so breach simulation can be automated as an agent workflow.
- [Multi-Step LLM Pipeline for Enhancing TTP Extraction in Cyber Threat Intelligence](https://doi.org/10.1109/ACCESS.2025.3622350): Uses an LLM extractor, retrieval-based ATT&CK candidate generator, and LLM validator to convert raw CTI reports into ranked TTP predictions.
- [KryptoPilot](https://arxiv.org/abs/2601.09129): an open-world knowledge-augmented agent for cryptographic CTF exploitation. Core idea: combine deep research, persistent workspace memory, behavioral governance, and cost-aware model routing so agents can acquire fine-grained cryptanalytic knowledge and apply it across long-horizon exploit workflows.
- [VulnResolver](https://arxiv.org/abs/2601.13933): A hybrid agent framework for automated vulnerability issue resolution. Core idea: combine vulnerability analysis, repair planning, and validation feedback in one LLM-based issue-resolution loop.
- [PatchIsland](https://arxiv.org/abs/2601.17471): Orchestrates LLM agents for continuous vulnerability repair. Core idea: organize detection, patching, validation, and iteration into a repair loop for security defects.
- [Co-RedTeam](https://arxiv.org/abs/2602.02164): A coordinated security discovery and exploitation harness. Core idea: combine discovery, exploitation, execution feedback, validation, and memory reuse across cooperating red-team agents.
- [Hallucination-Resistant Security Planning](https://arxiv.org/abs/2602.05279): Places LLM security planning in an iterative loop with checks that reduce hallucinated recommendations before incident-response use.
- [Dual-Loop Vulnerability Reproduction](https://arxiv.org/abs/2602.05721): A dual-loop agent framework for automated vulnerability reproduction. Core idea: coordinate exploit hypothesis generation and validation feedback so agents can reproduce CVE evidence rather than only report likely flaws.
- [PenAgent](https://doi.org/10.1109/ISCAIT69154.2026.11477307): A retrieval-augmented multi-agent penetration-testing framework. Core idea: combine retrieval with coordinated security agents so reconnaissance and exploitation decisions can use external pentest knowledge instead of relying only on model memory.
- [Task-Driven SOC Analysis](https://doi.org/10.1049/cit2.70138): A task-driven framework for LLM-powered security operations analysis. Core idea: convert ambiguous SOC queries into verifiable analysis steps and evidence-backed conclusions.
- [AWE](https://arxiv.org/abs/2603.00960): A memory-augmented multi-agent harness for dynamic web penetration testing. Core idea: combine vulnerability-specific analysis pipelines, context-aware payload mutation, persistent memory, and browser-backed verification so exploitation attempts are more deterministic and reproducible.
- [VulnAgent-X](https://arxiv.org/abs/2603.13384): A layered agentic framework for repository-level vulnerability detection. Core idea: combine repository context, staged analysis, and validation to support realistic vulnerability detection.
- [Automated Membership Inference Attacks](https://arxiv.org/abs/2603.19375): Uses LLM agents to discover signal computations for membership inference attacks. Core idea: automate the exploratory attack-design loop for model-privacy testing.
- [AuditGPT](https://doi.org/10.1109/icassp55912.2026.11463116): A multi-agent framework for enhancing static analysis. Core idea: coordinate agents around code-audit evidence, suspected findings, and validation to reduce static-analysis triage friction.
- [STRIATUM-CTF](https://arxiv.org/abs/2603.22577): A protocol-driven agentic framework for general-purpose CTF solving. Core idea: structure challenge analysis, tool execution, feedback, and solution submission as a reusable CTF-solving workflow.
- [Environment-Grounded Multi-Agent Workflow for Autonomous Penetration Testing](https://arxiv.org/abs/2603.24221): A multi-agent penetration-testing harness for robotic cyber-physical environments. Core idea: maintain a shared graph memory of topology, channels, vulnerabilities, and exploit attempts so reconnaissance and exploitation remain grounded in observed environment state.
- [Knowdit](https://arxiv.org/abs/2603.26270): A knowledge-driven smart-contract vulnerability-detection harness. Core idea: summarize historical audit reports into a DeFi semantics graph, then coordinate agents for specification generation, harness synthesis, fuzz execution, and finding reflection through shared working memory.
- [Red-MIRROR](https://arxiv.org/abs/2603.27127): An autonomous penetration-testing harness with reflective verification and knowledge-augmented interaction. Core idea: close the loop between attack attempts, evidence checking, and memory-backed strategy refinement.
- [GONDAR](https://arxiv.org/abs/2604.01645): A sink-centric Java vulnerability-discovery harness. Core idea: combine CWE-specific sink scanning, LLM-assisted static filtering, exploration and exploitation agents, and coverage-guided fuzzing so agents can target reachable sink calls and synthesize proof-of-concept exploits.
- [ClearAgent](https://doi.org/10.1145/3759425.3763397): An agentic binary-analysis harness for vulnerability detection. Core idea: organize binary inspection, evidence extraction, reasoning, and vulnerability judgment into a tool-using analysis workflow.
- [RAVEN](https://arxiv.org/abs/2604.17948): A retrieval-augmented vulnerability exploration network for memory-corruption analysis in source code and binaries. Core idea: combine retrieval, program evidence, and exploit-oriented analysis loops for security-agent workflows.
- [APIOT](https://arxiv.org/abs/2605.02346): An autonomous purple-teaming harness for bare-metal industrial OT networks. Core idea: design protocol-level action spaces and runtime controls so LLM agents can complete discovery, exploitation, patching, and verification on Modbus/TCP and CoAP devices without shell or filesystem assumptions.
- [SLYP](https://arxiv.org/abs/2605.05000): An agentic binary-analysis harness for Windows COM vulnerability reasoning. Core idea: expose binary exploration, COM metadata, and debugger feedback as tools so agents can move from race-condition discovery to verified PoC generation.
- [Patch2Vuln](https://arxiv.org/abs/2605.06601): An agentic vulnerability-reconstruction harness for Linux distribution binary patches. Core idea: diff old and new ELF packages, rank changed functions, build evidence dossiers, and have a local agent produce bounded audit and validation plans from binary-derived evidence.
- [ALUSKORT](https://doi.org/10.12732/ijam.v38i5s.328): A hierarchical multi-agent cognitive architecture for autonomous security operations. Core idea: combine deterministic guardrails with staged LLM reasoning agents to automate SOC incident investigation and produce evidence-oriented investigative artifacts.
- [Agentic Fuzzing](https://arxiv.org/abs/2605.10074): Frames fuzzing as an agentic reasoning workflow for logic-bug discovery where conventional coverage feedback and pattern matching are weak.
- [Veritas](https://arxiv.org/abs/2605.15097): A semantically grounded agentic framework for memory-corruption vulnerability detection in binaries. Core idea: combine static slicing, dual-view LLM reasoning over decompiled and IR evidence, and multi-agent debugger validation to check exploit-relevant hypotheses.
- CyberGym's execution stack, SEC-bench's vulnerable-repository harnesses, and ExploitBench's staged task environments are the most relevant benchmark-side harness references here. The reusable harness pattern is `reconnaissance -> hypothesis -> exploit or patch attempt -> verifier-owned evidence -> retry`, with strict sandboxing and audit logs.
- [CurriculumPT](https://doi.org/10.3390/app15169096): A multi-agent autonomous penetration-testing harness with curriculum-guided task scheduling. Core idea: structure reconnaissance, exploitation, and follow-up work through staged task selection so security agents can progress through authorized pentest workflows more systematically.
- [Four-Layer AI Agent Architecture for Web Application Security Testing](https://doi.org/10.48084/etasr.16879): A web-security testing harness combining LLM reasoning, a detection engine, ReAct-style autonomous testing, and human validation. Core idea: structure routine web vulnerability assessment as layered agent automation over OWASP WebGoat, DVWA, and custom test environments.
- [Autosecagent](https://doi.org/10.1007/s11227-026-08439-z): Combines recursive memory, real-time retrieval, and tool-mediated security reasoning for iterative authorized penetration testing.
