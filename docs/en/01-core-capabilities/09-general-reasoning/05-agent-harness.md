# 1.9.5 Agent Harness

- [ReAct](https://arxiv.org/abs/2210.03629) ([code](https://github.com/ysymyth/ReAct)) alternates reasoning traces with tool/environment actions, an early strong baseline for general reasoning agents.
- [Reflexion](https://arxiv.org/abs/2303.11366) ([code](https://github.com/noahshinn/reflexion)) converts failed trajectories into language feedback and episodic memory for the next attempt.
- [Tree of Thoughts](https://arxiv.org/abs/2305.10601) ([code](https://github.com/princeton-nlp/tree-of-thought-llm)) is a representative search-style test-time harness that tree-structures the reasoning process.
- [RAP](https://arxiv.org/abs/2305.14992) ([code](https://github.com/Ber666/RAP)) places stronger emphasis on reasoning as a planning problem.
- [Graph of Thoughts](https://arxiv.org/abs/2308.09687) ([code](https://github.com/spcl/graph-of-thoughts)) generalizes ToT's tree structure into graph-style intermediate states, supporting merging, aggregation, and more complex reasoning topologies.
- [LATS](https://arxiv.org/abs/2310.04406) ([code](https://github.com/lapisrocks/LanguageAgentTreeSearch)) incorporates planning, evaluation, and search more systematically into the agent loop.
- [Generalized Planning for the Abstraction and Reasoning Corpus](https://arxiv.org/abs/2401.07426): Treats ARC as a generalized-planning problem, synthesizing reusable action abstractions that solve families of grid tasks rather than single instances.
- [An Enhanced Prompt-Based LLM Reasoning Scheme via Knowledge Graph-Integrated Collaboration](https://arxiv.org/abs/2402.04978): Couples prompt-based reasoning with knowledge-graph collaboration so an LLM can retrieve structured entities and relations while forming answers.
- [Simulating Multi-Stakeholder Decision-Making with Generative Agents in Urban Planning](https://arxiv.org/abs/2402.11314): Uses role-conditioned generative agents to simulate urban-planning stakeholders, making collective preference formation and negotiation an explicit multi-agent workflow.
- [Benchmark Self-Evolving: A Multi-Agent Framework for Dynamic LLM Evaluation](https://arxiv.org/abs/2402.11443): Uses multiple agents to generate, judge, and refresh benchmark items so evaluation sets can evolve as model capabilities improve.
- [PROC2PDDL: Open-Domain Planning Representations from Texts](https://arxiv.org/abs/2403.00092): Converts procedural natural-language text into PDDL-style planning representations, linking language understanding to symbolic planners.
- [KnowAgent: Knowledge-Augmented Planning for LLM-Based Agents](https://arxiv.org/abs/2403.03101): Adds explicit knowledge acquisition and use to the agent-planning loop so LLM agents can ground plans in relevant external facts.
- [AgentStudio: A Toolkit for Building General Virtual Agents](https://arxiv.org/abs/2403.17918): Provides a toolkit for assembling virtual agents with configurable perception, memory, planning, and action modules.
- [Prompting Techniques for Reducing Social Bias in LLMs through System 1 and System 2 Cognitive Processes](https://arxiv.org/abs/2404.17218): Uses dual-process prompting to separate fast intuitive responses from slower deliberation when trying to reduce biased outputs.
- [COAST: COnstraints And STreams for Task and Motion Planning](https://arxiv.org/abs/2405.08572): Represents task-and-motion planning as constraint and stream composition, allowing symbolic planners to call continuous generators during search.
- [Agent Planning with World Knowledge Model](https://arxiv.org/abs/2405.14205): Incorporates a world-knowledge model into agent planning so candidate actions can be checked against background commonsense and task constraints.
- [Tool-Planner: Dynamic Solution Tree Planning for Large Language Model with Tool Clustering](https://arxiv.org/abs/2406.03807): Builds a dynamic solution tree over clustered tools, letting an LLM plan which tools to call and how to branch across intermediate results.
- [Buffer of Thoughts: Thought-Augmented Reasoning with Large Language Models](https://arxiv.org/abs/2406.04271): Stores reusable thought templates in a buffer and retrieves them during inference to guide similar reasoning problems.
- [Retrieve-Plan-Generation: An Iterative Planning and Answering Framework for Knowledge-Intensive LLM Generation](https://arxiv.org/abs/2406.14979): Alternates retrieval, planning, and generation so knowledge-intensive answers can revise their plan as new evidence is found.
- [RASTeR: Robust, Agentic, and Structured Temporal Reasoning](https://arxiv.org/abs/2406.19538): Structures temporal reasoning as an agentic pipeline that extracts events, orders them, and checks time relations before answering.
- [Tree Search for Language Model Agents](https://arxiv.org/abs/2407.01476): Applies tree-search control to language-model agents, expanding, evaluating, and backtracking over candidate action trajectories.
- [An Empirical Study of Retrieval Augmented Generation with Chain-of-Thought](https://arxiv.org/abs/2407.15569): Compares how retrieval-augmented generation interacts with chain-of-thought prompting, clarifying when retrieved evidence helps or distracts multi-step reasoning.
- [A Logical Fallacy-Informed Framework for Argument Generation](https://arxiv.org/abs/2408.03618): Guides argument generation with explicit fallacy categories so generated claims can be checked against common reasoning errors.
- [Causal Agent based on Large Language Model](https://arxiv.org/abs/2408.06849): Frames causal reasoning as an LLM-agent loop that identifies causal variables, queries supporting knowledge, and revises causal conclusions.
- [Abstract Operations Research Modeling Using Natural Language Inputs](https://arxiv.org/abs/2408.07272): Turns natural-language problem descriptions into abstract operations-research models, connecting LLM parsing with optimization formulation.
- [IDEA: Enhancing the Rule Learning Ability of Large Language Model Agent through Induction, Deduction, and Abduction](https://arxiv.org/abs/2408.10455): Organizes rule learning around induction, deduction, and abduction steps so an agent can infer and test latent task rules.
- [From Grounding to Planning: Benchmarking Bottlenecks in Web Agents](https://arxiv.org/abs/2409.01927): Diagnoses web-agent failures by separating grounding, state tracking, and planning bottlenecks across browser tasks.
- [PARCO: Parallel AutoRegressive Models for Multi-Agent Combinatorial Optimization](https://arxiv.org/abs/2409.03811): Uses parallel autoregressive agents to construct combinatorial-optimization solutions, coordinating multiple partial decisions instead of one serial decoder.
- [TART: An Open-Source Tool-Augmented Framework for Explainable Table-based Reasoning](https://arxiv.org/abs/2409.11724): Combines table operations, tool calls, and explanation generation so table-based reasoning can expose intermediate computations.
- [The Ability of Large Language Models to Evaluate Constraint-satisfaction in Agent Responses to Open-ended Requests](https://arxiv.org/abs/2409.14371): Studies LLMs as constraint checkers for open-ended agent responses, separating generation quality from constraint-satisfaction evaluation.
- [Self-Correction is More than Refinement: A Learning Framework for Visual and Language Reasoning Tasks](https://arxiv.org/abs/2410.04055): Treats self-correction as a learned loop over critique, error localization, and revised solving for both visual and language reasoning.

- [Agent-Driven Topology Assembly: Trustworthy LLM Dispatch Reasoning in Distribution Networks](https://doi.org/10.1109/acpee69242.2026.11525045): Uses LLM agents to assemble distribution-network topology and support dispatch reasoning under power-grid constraints.
- [LogiCue: Targeted Prompting for Improved Modal and Conditional Reasoning in Large Language Models](https://doi.org/10.1016/j.procs.2026.01.057): Uses targeted cues in prompts to steer LLMs through modal and conditional reasoning cases that require explicit logical distinctions.
- ARC-AGI-solution ([code](https://github.com/aviad12g/ARC-AGI-solution); no standalone paper): An engineering-oriented ARC solving agent guided by LLM-based DSL search.
- [CoAgt: unleashing the reasoning capabilities of large language models on tabular data with a chain of agents](https://doi.org/10.7717/peerj-cs.3423): Chains specialized agents for table understanding, operation selection, and answer synthesis over tabular data.
- [SyLeR: A Framework for Explicit Syllogistic Legal Reasoning in Large Language Models](https://doi.org/10.1145/3746252.3761120): Encodes legal reasoning as explicit syllogistic steps so LLM outputs can expose rule, fact, and conclusion structure.
- [Moving Experiences - Towards a Conceptual Framework for Performative Artefacts in Museums](https://doi.org/10.1145/3719236.3719249): Develops a conceptual framework for performative museum artifacts; it is not clearly a general LLM reasoning harness.
- [Generative High‐Resolution Ensemble Weather Forecast Supports Renewable Energy Planning and Operation](https://doi.org/10.1029/2025gl119044): Uses generative high-resolution ensemble weather forecasts to support renewable-energy planning and operation decisions.
- [BayBE: a Bayesian Back End for experimental planning in the low-to-no-data regime](https://doi.org/10.1039/d5dd00050e): Provides a Bayesian optimization backend for experimental planning when little or no prior data is available.
- [LLM-Collab: a framework for enhancing task planning via chain-of-thought and multi-agent collaboration](https://doi.org/10.3934/aci.2024019): Combines chain-of-thought planning with multi-agent collaboration so task plans can be proposed, critiqued, and refined by separate agents.
- [Cognitive Agents in Urban Mobility: Integrating LLM Reasoning into Multi-Agent Simulations](https://doi.org/10.3390/s25185688): Embeds LLM reasoning inside urban-mobility simulations so cognitive agents can explain and adapt their travel decisions.
- [SPARK_AI: A Prompt-Orchestrated Architecture for Stateful, Process-Oriented Reasoning with Large Language Models](https://doi.org/10.3390/informatics13040063): Defines a prompt-orchestrated architecture that maintains state across process-oriented reasoning steps.
- [SwarmPrompt: Swarm Intelligence-Driven Prompt Optimization Using Large Language Models](https://doi.org/10.5220/0013090300003890): Applies swarm-intelligence search to prompt optimization, treating candidate prompts as a population that can be iteratively improved.
