# 1.14.5 Agent Harness

- [Self-Refine](https://arxiv.org/abs/2303.17651) ([code](https://github.com/madaan/self-refine)): A general `generate -> feedback -> revise` loop for writing revision; useful for turning one-shot writing into a reviewable, iterative long-form generation process.
- [STORM](https://arxiv.org/abs/2402.14207) ([code](https://github.com/stanford-oval/storm)): A `retrieval -> multi-perspective questioning -> outline -> draft` harness for long encyclopedic writing; closer to report or survey generation than single-turn composition.
- [Heterogeneous Recursive Planning](https://arxiv.org/abs/2503.08275) (code: no stable public repository found): An adaptive planning harness for long-form writing; core idea: instead of generating a one-shot outline, recursively decompose writing units at different granularities and adjust planning depth during generation as the content requires.
- [BookWorld](https://arxiv.org/abs/2504.14538): Builds interactive agent societies from novels for creative story generation. Core idea: use character agents, social simulation, and story-world state to extend narrative generation beyond single-pass drafting.
- [A Hybrid Multi-Agent Prompting Approach for Simplifying Complex Sentences](https://arxiv.org/abs/2506.11681): Uses a hybrid multi-agent prompting workflow for sentence simplification and revision.
- [StoryWriter](https://arxiv.org/abs/2506.16445) (code: no stable public repository found): A multi-agent framework for long story generation; core idea: assign character setting, plot planning, chapter writing, and consistency checking to different agents to reduce character drift and plot breaks in long stories.
- [Auto-Slides](https://arxiv.org/abs/2509.11062): An interactive multi-agent harness for research presentation creation and customization. Core idea: split slide generation, editing, and user-guided refinement across agent roles so presentation writing becomes an iterative artifact workflow rather than one-shot text generation.
- [MUSE](https://arxiv.org/abs/2602.03028): a multi-agent harness for unconstrained story envisioning. Core idea: use closed-loop cognitive orchestration so planning, generation, and revision roles can coordinate open-ended narrative development.
- [PaperOrchestra](https://arxiv.org/abs/2604.05018) (code: no stable public repository found): A multi-agent framework for automated AI research paper writing; core idea: decompose paper writing into topic/context analysis, section drafting, cross-review, and overall revision, corresponding to the academic writing tasks in PaperWritingBench.
