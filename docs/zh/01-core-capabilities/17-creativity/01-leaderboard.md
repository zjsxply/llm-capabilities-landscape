# 1.17.1 Leaderboard

- [AesBench](https://aesbench.github.io/)：官方基准页面按 aesthetic perception、empathy、assessment 和 interpretation 等维度排列多模态模型的专家审美感知表现。
- [NoveltyBench](https://novelty-bench.github.io/)：官方榜单跟踪模型在开放式 prompt 和真实用户问题中生成多个不同且高质量答案的能力。
- [AidanBench](https://aidanbench.com/)：官方开放式 novel-idea 基准页面报告 creativity、reliability、contextual attention 和 instruction following 结果；[AI Stats 镜像](https://ai-stats.phaseo.app/benchmarks/aidanbench) 提供可读的公开快照。
- [EQ-Bench Creative Writing v3](https://eqbench.com/creative_writing.html)：广泛使用的创意写作榜单，关注主观质量、风格、叙事控制和文学表达。
- [EQ-Bench Longform Creative Writing](https://eqbench.com/creative_writing_longform.html)：广泛使用的长篇创意写作榜单，强调持续风格、叙事节奏和长程连贯性。
- [LLM Creative Story-Writing Benchmark](https://github.com/lechmazur/writing)：公开的约束短故事写作基准与榜单，用带显式要求的创意写作 prompt 比较模型。
- [HumorRank: A Tournament-Based Leaderboard for Evaluating Humor Generation in Large Language Models](https://arxiv.org/abs/2604.19786)：构建基于锦标赛的 HumorRank 榜单，用成对幽默判断评测 LLM 笑话生成，而不是只看单个 prompt 示例。
- [Creative AI Index](https://schapiro.ai/creative-ai-index/)（[论文](https://arxiv.org/abs/2605.13450)）：公开的 LLM 创造力测验与创造性成就预测榜，覆盖 DAT、Conditional DAT、DRAT、创意写作、发散思维和科研构思，而不是只给单一故事写作分数。
