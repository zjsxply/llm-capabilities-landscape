# 2.5.5 Agent Harness

- [AppAgent](https://arxiv.org/abs/2312.13771) ([open-source code](https://github.com/mnotgod96/AppAgent); [project page](https://appagent-official.github.io/)): An early smartphone GUI agent harness that learns app operation through autonomous exploration or human demonstrations, then reuses the generated operation documents for later tasks.
- [SeeAct](https://arxiv.org/abs/2401.01614) ([open-source code](https://github.com/OSU-NLP-Group/SeeAct); an early web GUI agent paradigm combining visual grounding with structural information, later absorbed by many CUA variants)
- [Mobile-Agent-v2 / Mobile-Agent-E](https://arxiv.org/abs/2406.01014) ([Mobile-Agent-E](https://arxiv.org/abs/2501.11733); [open-source code](https://github.com/X-PLUG/MobileAgent)): A mobile GUI-agent lineage with explicit planning, reflection, multi-agent collaboration, and later self-evolution, bridging AndroidWorld-style tasks and general mobile operation.
- [Agent S](https://arxiv.org/abs/2410.08164) ([open-source code](https://github.com/simular-ai/Agent-S); an integrated computer-use workflow with ACI, hierarchical planning, external knowledge retrieval, and experience memory)
- [AgentStore](https://arxiv.org/abs/2410.18603) ([open-source code](https://github.com/chengyou-jia/AgentStore); an App Store-like platform for dynamic selection and composition of heterogeneous agents)
- [OpenWebVoyager](https://arxiv.org/abs/2410.19609) ([open-source code](https://github.com/MinorJerry/OpenWebVoyager); builds multimodal web agents through real-web exploration, feedback, and optimization, connecting WebArena/VisualWebArena with open-web operation)
- [BrowserGym Ecosystem](https://arxiv.org/abs/2412.05467) ([open-source code](https://github.com/ServiceNow/BrowserGym); unifies web GUI environments such as WebArena, VisualWebArena, and WorkArena, and provides reproducible evaluation interfaces)
- [R2D2](https://arxiv.org/abs/2501.12485): A web-agent harness built around remembering, reflecting, and dynamic decision making. Core idea: maintain and revise task memory during web interaction so agents can adapt plans instead of relying only on a fixed prompt and recent browser context.
- [PC-Agent](https://arxiv.org/abs/2502.14282) ([open-source code](https://github.com/X-PLUG/MobileAgent/tree/main/PC-Agent); uses hierarchical multi-agent collaboration with `Manager / Progress / Decision / Reflection` roles for complex cross-application PC tasks)
- [Agent S2](https://arxiv.org/abs/2504.00906) ([open-source code](https://github.com/simular-ai/Agent-S); a multi-role workflow combining generalists and specialists)
- [UXAgent](https://arxiv.org/abs/2504.09407): Simulates usability testing of web designs with LLM agents. Core idea: coordinate persona-like user agents and web interaction to generate usability evidence before human testing.
- Browser-Use ([open-source code](https://github.com/browser-use/browser-use); a common browser-agent scaffold on leaderboards such as HAL, AssistantBench, and Online Mind2Web, packaging Playwright browser state, action execution, persistent browsers, and tool extensions into a reusable web automation harness)
- Stagehand ([open-source code](https://github.com/browserbase/stagehand); [docs](https://docs.stagehand.dev/)): A production-oriented browser automation harness that combines deterministic Playwright code with natural-language actions and extraction, useful as a Browserbase-line alternative to browser-only agent loops.
- Skyvern ([open-source code](https://github.com/Skyvern-AI/skyvern); [homepage](https://www.skyvern.com/)): A production web-workflow automation harness that uses LLM and vision components for browser navigation, form filling, workflow execution, and stateful web tasks.
- [LiteCUA](https://arxiv.org/abs/2505.18829) (open-source code: not released; abstracts the "computer" as an MCP server environment semantic layer to reduce action-space complexity)
- [AgentPbD](https://doi.org/10.1109/vl-hcc65237.2025.00064): A browser-agent workflow-generation harness from user demonstrations. Core idea: convert programming-by-demonstration traces into interactive agentic workflows that can guide web automation beyond hand-written task scripts.
- [UI-Evol](https://arxiv.org/abs/2505.21964) ([open-source code](https://github.com/microsoft/FIVE-UI-Evol); a pluggable knowledge evolution module that improves success rate and reduces behavior variance on OSWorld based on Agent S2)
- [CoAct-1](https://arxiv.org/abs/2508.03923) ([open-source code](https://github.com/SalesforceAIResearch/CoAct); explicit multi-agent collaboration with `Orchestrator / GUI Operator / Programmer`)
- [Autonomous Agents for Accessibility](https://doi.org/10.1109/ASE63991.2025.00349): A web-accessibility evaluation harness that simulates visually impaired users with autonomous agents. Core idea: run GUI-grounded user journeys over web interfaces to expose accessibility failures through interaction traces rather than static page inspection alone.
- [MobileRAG](https://arxiv.org/abs/2509.03891): A retrieval-augmented mobile-agent harness. Core idea: add retrieval, memory, and external-environment interaction to mobile GUI agents so they can recover from missing app capabilities, learn from prior failures, and reduce repeated interface rediscovery.
- [Agentic Lybic](https://arxiv.org/abs/2509.11067) ([open-source code](https://github.com/xlang-ai/OSWorld/tree/main/mm_agents/maestro); FSM-driven `Controller / Manager / Worker / Evaluator` division of labor and quality control)
- [AgentProg](https://arxiv.org/abs/2512.10371) ([open-source code](https://github.com/MobileLLM/AgentProg); rewrites long-horizon GUI interaction history into programmatic context with variables and control flow, and maintains partially observable mobile GUI task state through a global belief state)
- [OS-Symphony](https://arxiv.org/abs/2601.07779) ([open-source code](https://github.com/OS-Copilot/OS-Symphony); a cross-platform computer-use framework with Orchestrator, Reflection-Memory, and tutorial retrieval)
- [CUA-Skill Agent](https://arxiv.org/abs/2601.21123) ([open-source code](https://github.com/microsoft/cua_skill); structured GUI skill library, parameterized composition graph, dynamic skill retrieval/instantiation, and memory-aware recovery)
- [BEAP-Agent](https://arxiv.org/abs/2601.21352) (open-source code: not released; explicitly models GUI execution as DFS, supporting multi-level backtracking and dynamic task tracking)
- [Minitap mobile-use](https://arxiv.org/abs/2602.07787) ([open-source code](https://github.com/minitap-ai/mobile-use); an AndroidWorld-centered task-decomposition multi-agent mobile harness that splits mobile GUI tasks into verifiable subgoals through supervisor, visual grounding, and action-execution roles)
- [Secure Intent-Centric Mobile Agent OS](https://arxiv.org/abs/2602.10915): Proposes a mobile runtime layer that mediates agent intent, app economics, permissions, and security boundaries beyond screen-only control.
- [OSExpert](https://arxiv.org/abs/2603.07978) (code: no stable public repository found; a GUI-based depth-first exploration harness for learning professional computer-use skills; core idea: combine exploratory search, skill abstraction, and transfer to unseen interfaces)
- [Natural-Language Agent Harnesses](https://arxiv.org/abs/2603.25723) ([open-source code](https://github.com/curated-skills/LinguaClaw); externalizes harness logic into editable natural-language documents, executed by a shared runtime with state and artifacts written back)
- [Avenir-UX](https://arxiv.org/abs/2604.09581): A GUI-grounded web-interaction harness for automated UX evaluation. Core idea: simulate user journeys on real websites, combine action traces with SUS, SEQ, and think-aloud style protocols, and generate structured usability reports.
- [EE-MCP](https://arxiv.org/abs/2604.09815) (code: no stable public repository found; a self-evolving MCP-GUI agent framework; core idea: automatically generate environments, collect trajectories, and learn an experience bank for balancing GUI actions with MCP tool calls)
- [SkillDroid](https://arxiv.org/abs/2604.14872): A skill-compilation harness for mobile GUI agents. Core idea: compile successful LLM-guided phone trajectories into parameterized UI-action templates with locators, slots, retrieval, replay, and failure-triggered recompilation so repeated tasks no longer require fresh LLM reasoning at every step.
- [AgentLens](https://arxiv.org/abs/2604.20279): A mobile GUI-agent interaction harness for adaptive visual feedback. Core idea: add Full UI, Partial UI, and generated-UI communication modes plus a virtual display so background mobile agents can expose the right amount of execution state to users.
- [ToolCUA](https://arxiv.org/abs/2605.12481) ([open-source code](https://github.com/X-PLUG/ToolCUA)): A GUI-plus-tool computer-use harness that coordinates screen interaction with tool execution, making it relevant to OSWorld-MCP and MobileWorld-style tasks where visual actions and structured tools must be chosen together.
