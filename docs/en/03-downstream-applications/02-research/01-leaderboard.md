# 3.2.1 Leaderboard

- [SciArena: An Open Evaluation Platform for Non-Verifiable Scientific Literature-Grounded Tasks](https://arxiv.org/abs/2507.01001) ([platform](https://sciarena.allen.ai/)): An open arena for scientific literature-grounded tasks. Its ranked evaluations combine community model comparisons with researcher votes on long-form scientific responses, measuring literature understanding and cross-paper synthesis rather than generic question answering.
- [MLE-bench Leaderboard / Official Results](https://github.com/openai/mle-bench) ([paper](https://arxiv.org/abs/2410.07095); [open-source code](https://github.com/openai/mle-bench)): Ranks agents on 75 Kaggle competitions using competition metrics after they produce `submission.csv`, aggregated with `Any Medal`. The workload covers data loading, EDA, feature engineering, model selection, tuning, training, validation, submission repair, and long experiment iteration, making data-science automation observable at scale.
- [PaperBench Leaderboard / Official Results](https://github.com/openai/frontier-evals/blob/main/project/paperbench/README.md) ([paper](https://arxiv.org/abs/2504.01848)): Reports PaperBench results for agents that read a published paper, implement or reproduce its experiments in a fresh sandbox, and undergo author-designed rubric grading. The central measurement is whether an agent can produce a working, evidence-backed reproduction rather than merely plausible code.
- [MLRC-Bench Leaderboard](https://huggingface.co/spaces/launch/MLRC_Bench) ([paper](https://arxiv.org/abs/2504.09702)): Scores agents on more open machine-learning research challenges. It moves beyond competition modeling by asking whether an agent can make progress on research challenges, bridging MLE-bench-style data science and open-ended ML experimentation.
- [HypoBench Leaderboards](https://chicagohai.github.io/HypoBench/leaderboard_real) ([paper](https://arxiv.org/abs/2504.11524); [project page](https://chicagohai.github.io/HypoBench/); [open-source code](https://github.com/ChicagoHAI/HypoBench-code); [synthetic leaderboard](https://chicagohai.github.io/HypoBench/leaderboard_synth)): Ranks model-generated scientific hypotheses on real and synthetic datasets. It scores whether natural-language explanations are useful for downstream prediction through accuracy and F1, and separately measures novelty, plausibility, and clarity on real data.
- [SciCode Leaderboard](https://scicode-bench.github.io/leaderboard/) ([paper](https://arxiv.org/abs/2407.13168); [open-source code](https://github.com/scicode-bench/SciCode)): Reports performance on scientist-curated coding problems drawn from real research. Each problem supplies decomposed subproblems, gold solutions, and tests, exposing whether a model can combine scientific knowledge, reasoning, and executable code synthesis.
- [LiveIdeaBench Leaderboard](https://liveideabench.com/) ([paper](https://arxiv.org/abs/2412.17596)): Ranks scientific ideas generated from minimal single-keyword prompts across 1,180 keywords and 22 domains. Its originality, feasibility, fluency, flexibility, and clarity metrics directly evaluate scientific divergent thinking rather than general creative writing.
- [MLE-Dojo Leaderboard](https://huggingface.co/spaces/MLE-Dojo/Leaderboard) ([paper](https://arxiv.org/abs/2505.07782); [open-source code](https://github.com/MLE-Dojo/MLE-Dojo)): Ranks interactive ML-engineering agents in executable Gym-style environments built from more than 200 Kaggle challenges. Feedback from iterative data processing, architecture search, tuning, debugging, and verification turns routine competition work into a long-horizon experimental-control evaluation.
- [Scientist-Bench / AI-Researcher Leaderboard](https://autoresearcher.github.io/leaderboard.html) ([paper](https://arxiv.org/abs/2505.18705); [open-source code](https://github.com/HKUDS/AI-Researcher)): Compares agents on guided and open-ended scientific-innovation tasks spanning literature review, hypothesis generation, algorithm implementation, and manuscript preparation. The board tests whether a system can turn scientific context into an implemented and written contribution across multiple research stages.
- [ResearchCodeBench Leaderboard](https://researchcodebench.github.io/leaderboard/index.html) ([paper](https://arxiv.org/abs/2506.02314); [project page](https://researchcodebench.github.io/); [open-source code](https://github.com/PatrickHua/ResearchCodeBench)): Evaluates faithful implementation of previously unseen contributions from recent ML papers. Its 212 executable challenges from 2024--2025 top-conference papers isolate the research step of translating a new method into working code.
- [KRAMABENCH Rankings](https://kramabench.org/) ([paper](https://arxiv.org/abs/2506.06541); [open-source code](https://github.com/mitdbg/KramaBench); [dataset](https://huggingface.co/datasets/eugenie-y/KramaBench)): Ranks data-to-insight agents over data lakes. Tasks require data discovery, cleaning, integration, statistical inference, and Python pipeline orchestration, so the board measures whether an agent can carry an open-ended data-science analysis from raw sources to an interpretable result.
- [RExBench Leaderboard](https://rexbench.com/) ([paper](https://arxiv.org/abs/2506.22598); [project page](https://rexbench.com/)): Tests whether coding agents can extend published AI research. Agents receive papers and original codebases, implement expert-authored new experiments or hypotheses, and are scored through automatic execution and metric checks.
- [AstaBench Leaderboard](https://huggingface.co/spaces/allenai/asta-bench-leaderboard) ([paper](https://arxiv.org/abs/2510.21652); [open-source code](https://github.com/allenai/asta-bench)): Unifies literature retrieval, code execution, data analysis, and scientific-discovery tasks in a standardized science-agent suite. The public rankings therefore compare several concrete research-workflow stages under shared tool environments.
- [InnovatorBench Leaderboard](https://ai-innovator.opensii.ai/leaderboard/) ([paper](https://arxiv.org/abs/2510.27598); [project page](https://ai-innovator.opensii.ai/); [open-source code](https://github.com/GAIR-NLP/InnovatorBench)): Ranks agents on 20 executable LLM-research tasks built on ResearchGym. Systems must produce runnable artifacts, and the evaluation combines task performance with uncertainty-aware checks to distinguish research-grade improvements from lucky or irreproducible results.
- [FIRE-Bench Leaderboard](https://firebench.github.io/#leaderboard) ([paper](https://arxiv.org/abs/2602.02905); [project page](https://firebench.github.io/); [open-source code](https://github.com/maitrix-org/FIRE-Bench)): Measures full-cycle insight rediscovery from influential ML papers. Agents start with high-level research questions, explore ideas, design and implement experiments, execute them, and support the rediscovered claim with evidence; the board reports precision, recall, and F1 over repeated trials.
- [CORE-Bench / CORE-Bench Hard](https://hal.cs.princeton.edu/corebench_hard) ([paper](https://arxiv.org/abs/2409.11363)): Tracks agent performance on computational reproduction of published research, with HAL providing the harder CORE-Bench Hard subset. The task packages papers, code, data, and execution environments so success requires actually rerunning a scientific result.
- [SGI-Bench Leaderboard](https://huggingface.co/spaces/InternScience/SGI-Bench-Leaderboard) ([paper](https://arxiv.org/abs/2512.16969)): Evaluates scientist-aligned workflows covering retrieval, reasoning, experiment planning, and result organization. Its leaderboard treats these connected abilities as a protocol for probing scientific general intelligence rather than as isolated language tasks.
- [ResearchGym Leaderboard](https://anikethh.github.io/ResearchGym/#leaderboard) ([paper](https://arxiv.org/abs/2602.15112); [project page](https://anikethh.github.io/ResearchGym/); [open-source code](https://github.com/Anikethh/ResearchGym)): Evaluates closed-loop AI research in real conference-paper codebases. The original method is hidden while agents formulate hypotheses, run experiments, and try to exceed an available baseline under a fixed budget, making empirical research progress the score target.
- [AIRS-Bench Leaderboard](https://github.com/facebookresearch/airs-bench#leaderboard) ([paper](https://arxiv.org/abs/2602.06855); [open-source code](https://github.com/facebookresearch/airs-bench)): Compares frontier AI-research agents on tasks that combine idea generation, experiment analysis, and iterative revision. It focuses the leaderboard on whether an agent can advance a real AI research workflow, not just generate a polished answer.
- [PostTrainBench Leaderboard](https://posttrainbench.com/#leaderboard) ([paper](https://arxiv.org/abs/2603.08640); [project page](https://posttrainbench.com/); [open-source code](https://github.com/aisa-group/PostTrainBench)): Tests autonomous LLM post-training as a bounded research loop. Agents retrieve methods, prepare data, run training experiments, and optimize target evaluations under a single-H100 budget, exposing failures such as reward hacking and weak experiment control.
- [ResearchArena / True Auto Research Results](https://youarespecialtome.github.io/ResearchArena/) ([paper](https://arxiv.org/abs/2605.19156); [project page](https://youarespecialtome.github.io/ResearchArena/); [open-source code](https://github.com/YouAreSpecialToMe/ResearchArena)): Evaluates frontier CLI agents over 117 generated papers and 13 CS domains, including CPU, GPU, and H100-scaling conditions. Stanford Agentic Reviewer, code-aware multi-agent review, and manual artifact inspection expose gaps in experimental rigor, result faithfulness, and reference integrity across the full research loop.
- [AutoLab Leaderboard](https://autolab.moe/leaderboard) ([paper](https://arxiv.org/abs/2606.05080); [project page](https://autolab.moe/); [open-source code](https://github.com/autolabhq/autolab)): Ranks agents on long-horizon closed-loop optimization, including model-development and ML-experiment tasks alongside systems, puzzles, and CUDA kernels. Starting from correct but deliberately suboptimal baselines, it measures whether agents repeatedly benchmark, edit, and use empirical feedback over a strict wall-clock budget.
- [ResearchClawBench Leaderboard](https://huggingface.co/datasets/InternScience/ResearchClawBench) ([paper](https://arxiv.org/abs/2606.07591); [open-source code](https://github.com/InternScience/ResearchClawBench)): Evaluates end-to-end autonomous research from relevant literature and raw data through experiments and peer-reviewed reporting, using hidden target papers. Its released package supplies target-paper context, data, figures, and multimodal checklist judging to distinguish reproduction from open discovery.
- [ResearcherBench Leaderboard](https://researcherbench.github.io/) ([paper](https://arxiv.org/abs/2507.16280); [open-source code](https://github.com/GAIR-NLP/ResearcherBench)): Evaluates agentic research judgment on 65 expert-selected frontier-AI questions from laboratory discussions and interviews. Technical-detail, literature-review, and open-consulting tasks are scored with expert insight rubrics plus citation faithfulness and coverage checks.
- [DEEPSYNTH Leaderboard](https://huggingface.co/spaces/DeepSynthesisTeam/deepsynth-leaderboard) ([paper](https://arxiv.org/abs/2602.21143); [open-source code](https://github.com/agentdeepsynthesis/deepsynth-bench)): Ranks agents on 120 time-consuming multi-source synthesis tasks across seven domains and 67 countries. The benchmark's task-construction pipeline collects official data, forms hypotheses, performs manual analysis, and defines verifiable answers, allowing the leaderboard to measure an agent's ability to gather evidence, analyze it, and extract structured insights.
