## 1.6.1 Leaderboard

- [Video-MME Leaderboard](https://video-mme.github.io/home_page.html#leaderboard): Continuous leaderboard for multitask understanding of short, medium, and long videos; a useful baseline reference for broad video VLM capability.
- [LongVideoBench Leaderboard](https://longvideobench.github.io/index.html#leaderboard): Continuous leaderboard for long-context interleaved video-language understanding; suitable for comparing different frame budgets, subtitle inputs, and long-range retrieval strategies.
- [VideoAutoArena](https://videoautoarena.github.io/): Continuous leaderboard that compares open-ended video analysis models through user simulation, model battles, and automatic judging; useful for covering real user video tasks that multiple-choice benchmarks miss.
- [Video-MMMU Leaderboard](https://videommmu.github.io/#Leaderboard): Continuous leaderboard for knowledge acquisition and QA in professional videos across disciplines; useful for tracking whether video models can learn from tutorial or lecture-style videos.
- [MMVU Leaderboard](https://mmvu-benchmark.github.io/#leaderboard): Continuous leaderboard for general video understanding and QA; useful for cross-screening strong video agent runtimes alongside Video-MME and Video-MMMU.
- [V-STaR Leaderboard](https://v-star-bench.github.io/#leaderboard): Continuous leaderboard for video spatial-temporal reasoning; useful for specifically observing object motion, event ordering, and cross-segment grounding.

## 1.6.2 Bench

(The following items are ordered by release time and cover subtasks such as video knowledge, video reasoning, motion/perception, long-video, multi-video, streaming, and agentic/web-video.)

- [ContPhy](https://arxiv.org/abs/2402.06119): Evaluates continuous physical processes and dynamic understanding; the core idea is physical consistency and state prediction under continuously changing conditions.
- [TempCompass](https://arxiv.org/abs/2403.00476): Evaluates temporal localization and event-order understanding; the core idea is fine-grained temporal alignment and timestamp retrieval.
- [Video-MME](https://arxiv.org/abs/2405.21075) ([project page](https://mme-benchmark.github.io/); [code](https://github.com/MME-Benchmarks/Video-MME)): Evaluates the full spectrum of video analysis capabilities; the core idea is to decompose "video understanding" into comparable dimensions through more systematic task coverage and evaluation protocols, with one-click evaluation scripts.
- [LVBench](https://arxiv.org/abs/2406.08035): Evaluates long-video understanding; the core idea is to distinguish long-video capability through longer time spans and stronger information-retrieval requirements.
- [LongVideoBench](https://arxiv.org/abs/2407.15754): Evaluates long-video understanding; the core idea is to interleave `frames + subtitles + question` as input and explicitly parameterize the frame budget, such as `max_num_frames`, for reproducible comparison. ([project page](https://longvideobench.github.io/); [dataset](https://huggingface.co/datasets/longvideobench/LongVideoBench); [code](https://github.com/longvideobench/LongVideoBench))
- [VideoAutoArena](https://videoautoarena.github.io/): Evaluates open-ended video analysis models through an automatic arena-style comparison; the core idea is to use user simulation, model battles, and automatic judging to cover real user tasks that fixed multiple-choice benchmarks miss.
- [TVBench](https://arxiv.org/abs/2410.07752): Evaluates temporal understanding and motion-related perception; the core idea is to use change and motion as the main signal rather than static single-frame recognition.
Video reasoning (temporal/causal/multi-hop reasoning):
- [VideoWebArena](https://arxiv.org/abs/2410.19100) ([project page](https://videowebarena.github.io/); [code](https://github.com/ljang0/videowebarena)): Evaluates video understanding by long-context multimodal agents in web tasks; the core idea is to put tutorial/video evidence, web state, and executable actions in the same environment and measure whether an agent can operate after watching a video by task success rate.
- [TOMATO](https://arxiv.org/abs/2410.23266): Evaluates temporal reasoning and action understanding; the core idea is to construct questions around event boundaries and state transitions.
- [CG-Bench](https://arxiv.org/abs/2412.12075): Evaluates long-chain video understanding and complex reasoning/generation; the core idea is to strengthen compositional reasoning and output constraints to reduce shortcuts.
- [OVBench](https://arxiv.org/abs/2501.00584) ([code](https://github.com/MCG-NJU/VideoChat-Online)): Evaluates online/streaming video understanding and interaction; the core idea is to make "updating state and answering while receiving video" part of the input protocol, with reproducible online-video runtime and evaluation scripts.
- [MotionBench](https://arxiv.org/abs/2501.02955): Evaluates motion understanding and fine-grained action perception; the core idea is to cover multiple motion patterns under a unified evaluation protocol.
- [OVOBench](https://arxiv.org/abs/2501.05510): Evaluates online video and online interactive understanding; the core idea is real-time constraints and continuous state updates for online settings.
- [MMVU](https://arxiv.org/abs/2501.12380): Evaluates general video understanding and QA; the core idea is to diagnose the capability spectrum from factual recall to comprehension and reasoning through more systematic task decomposition and question-type coverage.
- [Video-MMMU (VideoMMMU)](https://arxiv.org/abs/2501.13826): Evaluates QA ability for "learning knowledge from video"; the core idea is to introduce incremental metrics such as `delta accuracy` in addition to absolute accuracy, and to standardize input organization, for example appending question images to the final video frame, for unified evaluation. ([project page](https://videommmu.github.io/); [dataset](https://huggingface.co/datasets/lmms-lab/VideoMMMU); [code](https://github.com/EvolvingLMMs-Lab/VideoMMMU))
- [Video-OCR Benchmark](https://arxiv.org/abs/2502.06445) ([code](https://github.com/video-db/ocr-benchmark)): Evaluates differences between VLMs and traditional OCR on text recognition in video frames; the core idea is to separate video text recognition from single-image OCR and explicitly compare the benefits of frame sampling, temporal redundancy, and end-to-end vision-language models.
- [ViSpeak](https://arxiv.org/abs/2503.12769): Evaluates real-time or semi-real-time video-to-language expression; the core idea is to emphasize temporal consistency, information coverage, and output fluency.
- [EgoTempo](https://arxiv.org/abs/2503.13646): Evaluates temporal and action understanding in egocentric video; the core idea is to use occlusion, fast motion, and interactivity in egocentric views to increase difficulty.
- [FAVOR-Bench](https://arxiv.org/abs/2503.14935) ([project page](https://favor-bench.github.io/); [code](https://github.com/FAVOR-Bench/FAVOR-Bench); [dataset](https://huggingface.co/datasets/zl2048/FAVOR)): Evaluates fine-grained video motion understanding; the core idea is to cover first-person and third-person videos, closed-set QA, and open descriptions to diagnose whether models truly understand action details, trajectories, and temporal dynamics.
- [VideoSimpleQA](https://arxiv.org/abs/2503.18923): Evaluates basic video factual QA; the core idea is to quickly distinguish "whether the model saw it" and "whether the model remembered it" through a low-ambiguity QA protocol.


- [IV-Bench](https://arxiv.org/abs/2504.15415) ([code](https://github.com/multimodal-art-projection/IV-Bench)): Evaluates image-grounded video perception and reasoning; the core idea is to input reference images, video, and text questions together, checking whether a model can incorporate external visual context into video understanding instead of relying only on current video frames.
- [LiveSports3K](https://arxiv.org/abs/2504.16030): Evaluates understanding and caption/commentary-related capabilities in live sports scenarios; the core idea is to challenge models with live-stream distributions and time-sensitive information.
- [Minerva](https://arxiv.org/abs/2505.00681): Evaluates complex video reasoning and knowledge integration; the core idea is longer-chain reasoning and cross-modal information fusion.
- [VideoEval-Pro](https://arxiv.org/abs/2505.14640): Evaluates more professional long-video understanding and the robustness of evaluation protocols; the core idea is stricter evaluation settings and more realistic long-video task organization.
- [MME-VideoOCR](https://arxiv.org/abs/2505.21333): Evaluates dynamic text perception, recognition, and reasoning in video; the core idea is to treat text-in-video as a key dimension of video understanding, covering multilingual, multi-scene, and OCR-to-reasoning questions.
- [Video-Holmes](https://arxiv.org/abs/2505.21374): Evaluates "detective-style" video reasoning and evidence-chain alignment; the core idea is to constrain reasoning with explainable clue chains and reduce unsupported conclusions.
- [VideoReasonBench](https://arxiv.org/abs/2505.23359): Evaluates temporal, causal, and multi-step reasoning; the core idea is to explicitly require integrating cross-segment clues rather than recognizing a single frame.
- [ScaleLong](https://arxiv.org/abs/2505.23922) ([code](https://github.com/multimodal-art-projection/ScaleLong)): Evaluates long-video understanding across multiple time scales; the core idea is to place second-, minute-, and hour-level context in a unified evaluation protocol and diagnose degradation in retrieval, memory, and cross-segment reasoning as video length grows.
- [V-STaR](https://v-star-bench.github.io/#leaderboard): Evaluates video spatial-temporal reasoning; the core idea is to use object motion, event ordering, and cross-segment grounding as independent stress points, complementing the finer-grained diagnosis of spatiotemporal reasoning dimensions not fully covered by Video-MME and LongVideoBench.
- [VideoMathQA](https://arxiv.org/abs/2506.05349) ([project page](https://mbzuai-oryx.github.io/VideoMathQA); [code](https://github.com/mbzuai-oryx/VideoMathQA)): Evaluates mathematical reasoning in video; the core idea is to make models understand teaching or problem-solving processes across visual, audio, text, and long-temporal clues, connecting video understanding with mathematical reasoning.
- [Morse-500](https://arxiv.org/abs/2506.05523): Evaluates more fine-grained video reasoning and clue tracking; the core idea is diagnosis through denser reasoning points and stricter answer constraints.
- [EASG-Bench](https://arxiv.org/abs/2506.05787) ([code](https://github.com/fpv-iplab/EASG-bench)): Evaluates video QA based on egocentric action scene graphs; the core idea is to generate QA from dynamic graphs with spatiotemporal grounding, focusing on actor, action, object relations, and temporal order.
- [CausalVQA](https://arxiv.org/abs/2506.09943): Evaluates physical causal reasoning in real videos; the core idea is to use counterfactual, hypothetical, anticipation, and planning question types, requiring models to predict event outcomes from visual evidence rather than language priors.
- [HiVU](https://arxiv.org/abs/2506.13589) ([code](https://github.com/xzc-zju/AdaVideoRAG)): Evaluates hierarchical indexing and evidence retrieval in long-video QA; the core idea is to split video into multi-granularity index levels and diagnose whether models can locate useful segments in ultra-long videos instead of uniformly sampling frames.
- [CausalStep](https://arxiv.org/abs/2507.16878): Evaluates explicit step-by-step causal reasoning; the core idea is to cut video into causally related units and use a sequential answering protocol to prevent models from taking global-context shortcuts to guess the final answer.
- [M3-Bench](https://arxiv.org/abs/2508.09736): Evaluates cross-modal long-term memory in long-video agents; the core idea is to include visual, audio, and text memory signals at the same time, requiring models to maintain, retrieve, and combine historical evidence in long-term context.
- [ODVBench](https://arxiv.org/abs/2509.24871): Evaluates online video understanding in autonomous-driving scenarios as part of the StreamForest work. Core idea: test generalization under driving videos where temporal state, scene changes, and persistent event memory matter.
- [OmniVideoBench](https://arxiv.org/abs/2510.10689) ([project page](https://omnivideobench.github.io/omnivideobench_home/); [code](https://github.com/NJU-LINK/OmniVideoBench)): Evaluates omni-modal long-video understanding; the core idea is to put visual, audio, OCR, and ASR evidence into the same evaluation protocol and check whether models can integrate cross-modal information in long videos.
- [CrossVid](https://arxiv.org/abs/2511.12263): Evaluates comparison, retrieval, and aggregate reasoning across multiple videos; the core idea is multi-video evidence organization and consistency reasoning rather than single-video QA.
- [LongShOTBench](https://arxiv.org/abs/2512.16978) ([project page](https://mbzuai-oryx.github.io/LongShOT/); [dataset](https://huggingface.co/datasets/MBZUAI/longshot-bench); [code](https://github.com/mbzuai-oryx/longshot)): Evaluates omni-modal reasoning and agentic tool use in long videos; the core idea is to place visual, speech, and ambient-audio evidence, open-ended QA, multi-turn dialogue, and explainable scoring rubrics in the same evaluation protocol.
- [VideoZeroBench](https://arxiv.org/abs/2604.01569): Evaluates long-video QA with spatio-temporal evidence verification. Core idea: score not only answer correctness but also temporal intervals and spatial bounding boxes of supporting evidence, exposing the gap between plausible answers and genuinely grounded video reasoning.
- [ZeroVideo](https://github.com/ByteDance-Seed/Seed2.0): A challenging real-world video evaluation reported in the Seed2.0 model card; no standalone public release has been confirmed. Core idea: keep track of vendor-reported video reasoning sets that stress very long, realistic videos even when only aggregate model-card results are currently public.
- [SYNCR](https://arxiv.org/abs/2605.08412): Evaluates cross-video reasoning with synthetic grounding; the core idea is to use controllable synthetic clues to check whether models can establish correspondences across multiple videos, locate evidence, and complete compositional inference.
- [EgoMemReason](https://arxiv.org/abs/2605.09874) ([project page](https://egomemreason.github.io/); [dataset](https://huggingface.co/datasets/Ted412/EgoMemReason); [code](https://github.com/Ziyang412/EgoMemReason)): Evaluates memory-driven reasoning over long egocentric videos; the core idea is to extend the LongVideoBench citation line to lifelog-style egocentric video, requiring models to retain, retrieve, and combine long-term personal visual evidence.
- [TOC-Bench](https://arxiv.org/abs/2605.09904): Evaluates temporal object consistency in video foundation models; the core idea is to track identity, attributes, and state consistency for the same object across time segments, avoiding static recognition based only on local frames.


## 1.6.3 Agent Harness

- [LMMs-Eval](https://arxiv.org/abs/2407.12772) ([code](https://github.com/EvolvingLMMs-Lab/lmms-eval)): A multimodal evaluation harness covering video tasks such as Video-MME, LongVideoBench, and Video-MMMU; suitable as a unified entry point for reproducible experiments and batch leaderboard submissions.
- [VideoChat-Online](https://arxiv.org/abs/2501.00584) ([code](https://github.com/MCG-NJU/VideoChat-Online)): A reference implementation for online/streaming video understanding, tightly coupled to the OVBench benchmark-specific runtime.
- [VideoRAG](https://arxiv.org/abs/2502.01549) ([code](https://github.com/HKUDS/VideoRAG)): A retrieval-augmented generation workflow for ultra-long videos that delegates "finding segment evidence" to video retrieval and indexing structures.
- [LVAgent](https://arxiv.org/abs/2503.10200) ([code](https://github.com/64327069/LVAgent)): A dynamic agent for long-video QA; it adaptively selects retrieval and analysis paths for different questions through task planning, iterative tool use, and real-time progress management.
- [VideoMind](https://arxiv.org/abs/2503.13444) ([code](https://github.com/yeliudev/VideoMind)): Decomposes long-video understanding into an agentic pipeline of planning, grounding, retrieval, and reasoning, and adapts to long-video tasks with Chain-of-LoRA.
- [LiveCC](https://arxiv.org/abs/2504.16030) ([code](https://github.com/showlab/LiveCC)): An understanding and caption/commentary generation pipeline for time-sensitive scenarios such as live sports.
- [MR.Video](https://arxiv.org/abs/2504.16082) ([code](https://github.com/ziqipang/MR-Video)): Organizes long-video understanding as MapReduce-style evidence aggregation, first extracting local evidence by segment and then aggregating globally for reasoning.
- [TimeChat-Online](https://arxiv.org/abs/2504.17343) ([code](https://github.com/yaolinli/TimeChat-Online)): Online interactive video understanding for time-sensitive scenarios, emphasizing online state updates and temporal alignment.
- [Deep Video Discovery](https://arxiv.org/abs/2505.18079) ([code](https://github.com/microsoft/DeepVideoDiscovery)): An agentic search harness for long-video understanding; with multi-granularity video databases and search-centric tools, it lets agents adaptively plan, retrieve segments, and summarize evidence by question.
- [VideoDeepResearch](https://arxiv.org/abs/2506.10821) ([code](https://github.com/yhy-2000/VideoDeepResearch)): Organizes "watch video -> retrieve external materials -> generate report" into a reusable long-chain pipeline.
- [AdaVideoRAG](https://arxiv.org/abs/2506.13589) ([code](https://github.com/xzc-zju/AdaVideoRAG)): A long-video RAG harness that adaptively selects hierarchical indexes and retrieval depth by task, reducing waste from fixed frame sampling or fixed chunking strategies.
- [Flash-VStream](https://arxiv.org/abs/2506.23825) ([code](https://github.com/IVGSZ/Flash-VStream)): A memory-budget harness for streaming long-video understanding, emphasizing memory updates and information fidelity under real-time constraints.
- [M3-Agent](https://arxiv.org/abs/2508.09736) (code: no stable public official repository found yet): A long-term memory agent for long videos; it decomposes "watch, listen, remember, reason" into interactive modules and pairs with M3-Bench to test memory retention and cross-modal evidence use.
- [GCAgent](https://arxiv.org/abs/2511.08909) (code: no stable public official repository found yet): A graph-compression agent for long videos; it uses graph structures to compress long-video events and entity relations, then locally expands and reasons around the question.
- [LongVT](https://arxiv.org/abs/2511.20785) ([code](https://github.com/EvolvingLMMs-Lab/LongVT)): A native tool-calling and "thinking with long videos" workflow for long videos, often used as an agentic runtime reference for long-video scenarios.
- [SAGE](https://arxiv.org/abs/2512.13874) ([code](https://github.com/allenai/SAGE)): An any-horizon long-video reasoning agent that learns the policy of when to answer in one turn and when to search for evidence across multiple turns.
- [LongShOTAgent](https://arxiv.org/abs/2512.16978) ([code](https://github.com/mbzuai-oryx/longshot)): A long-video agentic system built around LongShOTBench; it handles visual, speech, and ambient-audio evidence through preprocessing, cross-modal retrieval, tool use, and iterative refinement.
- [EGAgent](https://arxiv.org/abs/2601.18157) (code: no stable public official repository found yet): An agentic workflow for very long egocentric video; the core is to actively retrieve, compress, and reorganize evidence from first-person lifelog records by query.
- [SVAgent](https://arxiv.org/abs/2604.05079) (code: not confirmed public): A storyline-guided long-video QA agent; the core idea is to let a storyline agent build narrative state from selected frames, have cross-modal decision agents answer from visual and textual evidence, and use a meta-agent to align conflicting predictions.
- [VideoSEAL](https://arxiv.org/abs/2605.12571) (code: no stable public official repository found yet): An evidence-calibration framework for agentic long video understanding; the core idea is to decouple answer generation from evidence alignment/verification, mitigating mismatch between retrieved segments and final answers in long-video agents.
- [ReTool-Video](https://arxiv.org/abs/2605.13228) (code: not confirmed public): A recursive tool-using video agent; the core idea is to ground high-level video intents into executable tool chains over a fine-grained MetaAug-Video Tool Library, repairing or decomposing unmatched actions at runtime.
- [VideoSeeker](https://arxiv.org/abs/2605.16079) (code: the paper says it will be released, but no stable public repository has been confirmed yet): Native agentic tool invocation for video understanding; it emphasizes instance-level tool selection and brings search, grounding, and verification into the model decision process.

## 1.6.4 Skill

- [ffmpeg](https://skills.sh/digitalsamba/claude-code-video-toolkit/ffmpeg) is suitable for clipping, frame extraction, and transcoding.
- [ffmpeg-video-editor](https://skills.sh/sundial-org/awesome-openclaw-skills/ffmpeg-video-editor) is suitable for local video editing and segment export.
- [whisper](https://skills.sh/davila7/claude-code-templates/whisper) is suitable for speech transcription from video.
- [faster-whisper](https://skills.sh/theplasmak/faster-whisper/faster-whisper) is suitable for low-latency speech transcription.
- [ffmpeg-analyse-video](https://skills.sh/fabriqaai/ffmpeg-analyse-video-skill/ffmpeg-analyse-video) is suitable for structured analysis of video content.
- [video-understand](https://github.com/heygen-com/skills/tree/master/skills/video-understand) is a local `ffmpeg + whisper` video-understanding workflow skill; it is closer to a reusable video-processing pipeline than to something named after a specific benchmark.
