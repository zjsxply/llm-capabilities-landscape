- [From Automation to Augmentation: Large Language Models Elevating Essay Scoring Landscape](https://arxiv.org/abs/2401.06431): Builds an open-source dual-process LLM essay-scoring system that pairs automatic grading, feedback, confidence-aware misgrading mitigation, and human-AI co-grading studies.

- [Surface Reconstruction from Gaussian Splatting via Novel Stereo Views](https://arxiv.org/abs/2404.01810): Presents GS2Mesh, a 3D Gaussian-splatting surface-reconstruction method using stereo-rendered views; it is off-axis for Writing / Model.

- [Analyzing the Performance of Large Language Models on Code Summarization](https://arxiv.org/abs/2404.08018): Shows code-summarization scores are strongly driven by token overlap between function names and reference docstrings, limiting metric insight.

- [Navigating the Path of Writing: Outline-guided Text Generation with Large Language Models](https://arxiv.org/abs/2404.13919): Proposes WritingPath, which guides LLM generation with explicit outlines and evaluates both outline quality and generated blog-style text with professional writers.

- [RST-LoRA: A Discourse-Aware Low-Rank Adaptation for Long Document Abstractive Summarization](https://arxiv.org/abs/2405.00657): Injects rhetorical-structure discourse signals into LoRA adaptation for long-document abstractive summarization.

- [Enhancing Creativity in Large Language Models through Associative Thinking Strategies](https://arxiv.org/abs/2405.06715): Uses associative-thinking prompts to push LLMs to connect distant concepts, framing creativity improvement as controlled concept association rather than generic temperature sampling.
- [Design Opportunities for Explainable AI Paraphrasing Tools: A User Study with Non-native English Speakers](https://arxiv.org/abs/2405.07475): Builds ParaScope and studies how non-native English speakers use back-translation, explanations, and usage examples when choosing AI paraphrases.
- [Shotluck Holmes: A Family of Efficient Small-Scale Large Language Vision Models For Video Captioning and Summarization](https://arxiv.org/abs/2405.20648): Extends small vision-language models from image understanding to shot-sequence understanding with improved pretraining and data collection for video captioning and summarization.
- [Prompt Chaining or Stepwise Prompt? Refinement in Text Summarization](https://arxiv.org/abs/2406.00507): Compares three-prompt draft-critique-refine chaining with a single stepwise prompt and finds chaining produces stronger iterative summarization refinements.
- [Enhancing Text Authenticity: A Novel Hybrid Approach for AI-Generated Text Detection](https://arxiv.org/abs/2406.06558): Combines TF-IDF features, classical classifiers, CatBoost, and multiple DeBERTa-v3-large detectors for AI-generated text authenticity classification.
- [Wild-GS: Real-Time Novel View Synthesis from Unconstrained Photo Collections](https://arxiv.org/abs/2406.10373): Adapts 3D Gaussian Splatting for real-time novel-view synthesis from tourist photo collections; it is off-axis for Writing / Model.
