# 2.9.2 Survey

- [Episodic Memory in AI Agents Poses Risks that Should be Studied and Mitigated](https://arxiv.org/abs/2501.11739): Analyzes safety risks from agent episodic memory and proposes mitigation principles for monitoring, control, privacy, and trustworthy deployment.
- [A Survey on Trustworthy LLM Agents: Threats and Countermeasures](https://arxiv.org/abs/2503.09648): Organizes threats and defenses across planning, tools, memory, collaboration, and deployment.
- [A Survey of Direct Preference Optimization](https://arxiv.org/abs/2503.11701): Maps DPO variants, assumptions, and failure modes that matter when aligning agent policies without online reinforcement learning.
- [Aligning Multimodal LLM with Human Preference](https://arxiv.org/abs/2503.14504): Extends preference alignment to multimodal systems, covering preference data, reward models, and optimization recipes for vision-language behavior.
- [A Survey on Personalized Alignment - The Missing Piece for Large Language Models in Real-World Applications](https://arxiv.org/abs/2503.17003): Treats alignment targets as user- and context-dependent, surfacing deployment trade-offs beyond one-size-fits-all preferences.
- [Building Trustworthy Multimodal AI](https://arxiv.org/abs/2504.13199): Reviews fairness, transparency, and ethics issues in vision-language tasks, extending safety coverage beyond text-only agents.
- [A Survey of Attacks on Large Language Models](https://arxiv.org/abs/2505.12567): Systematizes adversarial attacks against LLMs and LLM-based agents, including misuse, privacy leakage, service disruption, and defense directions.
- [A Red Teaming Roadmap Towards System-Level Safety](https://arxiv.org/abs/2506.05376): Moves red teaming from isolated model probing toward system-level safety across components, workflows, and deployment contexts.
- [A Systematic Review of Poisoning Attacks Against Large Language Models](https://arxiv.org/abs/2506.06518): Organizes LLM poisoning threat models, attack specifications, metrics, and recurring attack classes for safety analysis.
- [From LLMs to MLLMs to Agents](https://arxiv.org/abs/2506.15170): Surveys jailbreak attacks and defenses as the LLM ecosystem expands from text-only models to multimodal systems and agents.
- [A Technical Survey of Reinforcement Learning Techniques for Large Language Models](https://arxiv.org/abs/2507.04136): Organizes reinforcement-learning methods that shape LLM behavior, giving agent safety a technical map of reward, policy, and feedback mechanisms.
- [LLM in the Middle](https://arxiv.org/abs/2509.10682): Systematically reviews threats and mitigations for real-world LLM systems across software and model life cycles.
- [SoK: Taxonomy and Evaluation of Prompt Security in Large Language Models](https://arxiv.org/abs/2510.15476): Systematizes jailbreak and prompt-security attacks, defenses, threat models, evaluation profiles, and standardized resources.
- [Security Issues in the Model Context Protocol Ecosystem](https://arxiv.org/abs/2510.16558): Empirically studies security issues in the MCP ecosystem. Core idea: inspect how MCP servers, clients, and tool descriptions create new attack surfaces so protocol-level defenses can be grounded in real ecosystem failures.
- [Safety and Security Framework for Real-World Agentic Systems](https://arxiv.org/abs/2511.21990): Organizes safety and security controls for deployed agentic systems. Core idea: connect threat modeling, runtime monitoring, governance, and evaluation so agent risk management is treated as an operational lifecycle rather than a one-time benchmark score.
- [Lessons from External Review of DeepMind's Scheming Inability Safety Case](https://arxiv.org/abs/2604.21964): Extracts review methodology and evidence requirements from an external audit of a frontier-AI scheming safety case.
- [Indirect Prompt Injection in the Wild](https://arxiv.org/abs/2604.27202): Studies real-world indirect prompt injection, mapping prevalence, techniques, and attacker objectives.
- [Toward Securing AI Agents Like Operating Systems](https://arxiv.org/abs/2605.14932): Frames LLM-agent security through operating-system concepts such as resource isolation, privilege separation, mediation, and auditability.
- [Securing LLM Agents](https://doi.org/10.1016/j.iotcps.2026.03.001): Connects prompt sanitization, guardrails, and autonomous red-teaming into a defense stack for LLM agents rather than treating attacks one at a time.
- [Data leakage and privacy failures in agentic AI](https://doi.org/10.3389/fcomp.2026.1802727): Surveys privacy risks introduced by autonomous agents with memory, tools, and multi-agent collaboration. Core idea: trace how sensitive information can be retained, propagated, and amplified across tasks and execution cycles.
- [LLM in the middle](https://doi.org/10.1016/j.cosrev.2026.100916): Reviews threats and mitigations for real-world LLM-based systems, connecting prompt injection, deployment surfaces, and defense patterns for agent safety.
- [Mind the Agent: A Comprehensive Survey on Large Language Model-Based Agent Safety](https://openreview.net/forum?id=DHe0UXipKU): Distinguishes agent safety through tool execution, memory poisoning, interaction, and multi-agent failures.
- [A Survey on the Safety and Security Threats of Computer-Using Agents: JARVIS or Ultron?](https://arxiv.org/abs/2505.10924): Focuses on action-taking risks across graphical environments and applications.
- [A Survey on Autonomy-Induced Security Risks in Large Model-Based Agents](https://arxiv.org/abs/2506.23844): Explains risks introduced by planning, delegation, persistence, tools, and feedback.
- [The Attack and Defense Landscape of Agentic AI: A Comprehensive Survey](https://arxiv.org/abs/2603.11088): Maps attack surfaces and mitigations in tool-using workflow systems.
- [Prompt Injection Attacks in Large Language Models and AI Agent Systems](https://doi.org/10.3390/info17010054): Surveys prompt-injection risks and defenses across LLM and agent systems. Core idea: connect direct and indirect injection, RAG poisoning, MCP/tool poisoning, real incidents, and defense-in-depth mitigations into one threat map.
- [AI Agents Meet Blockchain](https://doi.org/10.3390/fi17020057): Surveys blockchain-backed collaboration for multi-agent systems, focusing on security, scalability, identity, and coordination trade-offs.
- [AI Alignment](https://doi.org/10.1145/3770749): Provides a broad alignment map spanning problem definitions, human oversight, scalable supervision, preference learning, and governance risks.
- [From threat to trust](https://doi.org/10.1007/s10207-025-01185-y): Assesses security risks in agentic AI systems, adding a broad risk-assessment entry beyond single attack benchmarks.
