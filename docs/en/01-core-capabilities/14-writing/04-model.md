# 1.14.4 Model

- [Weaver](https://arxiv.org/abs/2401.17268): A creative-writing foundation model and training reference for controllable setting, plot, and narrative-style generation.
- [LongWriter](https://arxiv.org/abs/2408.07055) ([code](https://github.com/THUDM/LongWriter)): Trains long-output capability with LongWrite-Ruler and long-form supervised data, separating output-length scaling from merely reading long context.
- [Progressive Document-level Text Simplification via Large Language Models](https://arxiv.org/abs/2501.03857): Uses progressive document-level simplification to preserve structure while rewriting long text.
- [Modifying Large Language Model Post-Training for Diverse Creative Writing](https://arxiv.org/abs/2503.17126): Introduces Modifying Large Language Model Post-Training for Diverse Creative Writing, a model-side contribution for Writing.
- [SCORE: Story Coherence and Retrieval Enhancement for AI Narratives](https://arxiv.org/abs/2503.23512): Improves AI narrative coherence with retrieval-enhanced story modeling.
- [ScholarCopilot](https://arxiv.org/abs/2504.00824): Trains LLMs for academic writing with citation-aware supervision and accuracy-oriented generation.
- [Writing-Zero](https://arxiv.org/abs/2506.00103) ([code](https://github.com/damoonsh/writing-zero)): Converts open-ended writing into an optimizable reward process through procedural feedback and checkable constraints.
- [LongWriter-Zero](https://arxiv.org/abs/2506.18841) ([dataset](https://huggingface.co/datasets/THU-KEG/Arena-Write)): Uses reinforcement learning with length, quality, and structure rewards to induce ultra-long writing and think-before-writing planning.
- [ACE-RL](https://arxiv.org/abs/2509.04903): Decomposes writing instructions into fine-grained constraints and uses constraint satisfaction as an RL reward for long-form generation.
- [OUTLINEFORGE](https://arxiv.org/abs/2601.09858): Uses hierarchical reinforcement learning with explicit states for scientific-writing outline generation.
- [HiFlow](https://arxiv.org/abs/2603.04996): A hierarchical feedback optimization method for constrained long-form generation across global structure, paragraph quality, and local constraints.
- [UniCreative](https://arxiv.org/abs/2604.05517): Uses reference-free reinforcement learning to unify long-form logic and short-form creative quality for writing-centric generation.
