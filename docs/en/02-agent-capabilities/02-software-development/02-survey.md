# 2.2.2 Survey

- [Large Language Models for Software Engineering: A Systematic Literature Review](https://arxiv.org/abs/2308.10620): A foundational review spanning requirements, coding, testing, debugging, and maintenance.
- [LLM-Based Multi-Agent Systems for Software Engineering: Literature Review, Vision, and the Road Ahead](https://arxiv.org/abs/2404.04834): Reviews multi-agent coding, testing, review, management, and collaboration workflows.
- [Large Language Model-Based Agents for Software Engineering: A Survey](https://arxiv.org/abs/2409.02977): Connects repository understanding, localization, patching, testing, and tool feedback.
- [Software Development Life Cycle Perspective: A Survey of Benchmarks for Code Large Language Models and Agents](https://arxiv.org/abs/2505.05283): Maps code-model and agent evaluation coverage across the development lifecycle.
- [Agentic Software Engineering: Foundational Pillars and a Research Roadmap](https://arxiv.org/abs/2509.06216): Frames autonomous software engineering through interaction, verification, collaboration, and lifecycle integration.
