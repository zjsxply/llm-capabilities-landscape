# 4.1 Image Generation and Editing Models

> Parent chapter: 4. Multimodal

Note: This page collects benchmarks and harnesses whose primary target is image creation, text-to-image generation, image editing, visual-generation evaluation, or generated-image safety. Image/OCR understanding benchmarks remain in [1.5 Images](01-05-image-ocr.md).

## 4.1.1 Leaderboard

- [Artificial Analysis Text to Image Leaderboard](https://artificialanalysis.ai/text-to-image): A public arena-style comparison of text-to-image systems based on blind human preferences.
- [Arena Image Edit Leaderboard](https://arena.ai/en/leaderboard/image-edit): A public arena leaderboard focused on instruction-based image editing systems.

## 4.1.2 Survey

- [Text-to-image Diffusion Models in Generative AI: A Survey](https://arxiv.org/abs/2303.07909): A foundational survey of text-to-image diffusion systems and evaluation.
- [Diffusion Model-Based Image Editing: A Survey](https://arxiv.org/abs/2402.17525): Surveys instruction-guided and text-driven image editing methods and evaluation.
- [A Survey of Multimodal-Guided Image Editing with Text-to-Image Diffusion Models](https://arxiv.org/abs/2406.14555): Reviews editing guided by text, masks, layouts, references, and other controls.
- [Trustworthy Text-to-Image Diffusion Models: A Timely and Focused Survey](https://arxiv.org/abs/2409.18214): Covers safety, fairness, privacy, robustness, and trustworthiness.
- [Personalized Image Generation with Deep Generative Models: A Decade Survey](https://arxiv.org/abs/2502.13081): Reviews subject-preserving, reference-conditioned, and personalized generation.

## 4.1.3 Bench

- [HarmonyIQA](https://arxiv.org/abs/2501.01116): Evaluates image harmonization quality assessment. Core idea: collect harmonized images from multiple harmonization algorithms with human preference scores, testing whether image-quality models detect foreground-background lighting and color inconsistencies that generic IQA often misses.
- [MEt3R](https://arxiv.org/abs/2501.06336): Evaluates multi-view consistency in generated images. Core idea: measure whether generated views preserve shared 3D structure, making spatial consistency failures visible beyond single-image quality.
- [IE-Bench](https://arxiv.org/abs/2501.09927): Evaluates text-driven image editing with source-aware human opinion scores. Core idea: judge edited images against both the prompt and the source image so editing quality reflects human perception rather than only text-image alignment.
- [T2ISafety](https://arxiv.org/abs/2501.12612): Evaluates fairness, toxicity, and privacy risks in text-to-image generation. Core idea: organize safety prompts and judgments so image generators are tested for harmful, biased, or private-content outputs rather than only visual fidelity and prompt alignment.
- [Q-Eval-100K](https://arxiv.org/abs/2503.02357): Evaluates visual quality and alignment for text-to-vision content. Core idea: scale human annotations over generated visual outputs so quality and prompt-following can be assessed across text-to-image and text-to-video style generation rather than by small preference sets.
- [WISE](https://arxiv.org/abs/2503.07265): Evaluates world-knowledge-informed semantic consistency in text-to-image generation. Core idea: test whether generated images preserve commonsense object relations, spatial layouts, and real-world constraints rather than only matching prompt keywords.
- [ICE-Bench](https://arxiv.org/abs/2503.14482): Evaluates image creation and editing in a unified benchmark. Core idea: compare generation and editing systems under shared tasks and metrics so image-creation and image-modification capabilities can be diagnosed together.
- [LeX-Bench](https://arxiv.org/abs/2503.21749): Evaluates visual text generation in text-to-image systems. Core idea: use high-quality prompt and image synthesis around text rendering to test whether generators can produce legible, instruction-aligned text rather than only plausible surrounding imagery.
- [GPT-ImgEval](https://arxiv.org/abs/2504.02782): Diagnoses image generation quality for GPT-4o-style multimodal generators. Core idea: organize generation prompts and evaluation dimensions to expose where image generators fail in instruction following, visual fidelity, and semantic consistency.
- [Envisioning Beyond the Pixels](https://arxiv.org/abs/2504.02826): Evaluates reasoning-informed visual editing. Core idea: test whether editing systems follow semantic and logical constraints rather than only matching low-level visual instructions.
- [LMM4LMM](https://arxiv.org/abs/2504.08358): Benchmarks large-multimodal image generation using LMM-based evaluation. Core idea: use multimodal judges to assess generated-image quality and alignment, making image-generation comparison more structured than ad hoc preference checks.
- [ScienceT2I](https://arxiv.org/abs/2504.13129): evaluates scientific plausibility in text-to-image generation. Core idea: use expert-annotated scientific prompts, adversarial image pairs, and an isolated test set to expose when visually plausible images violate scientific concepts or physical realism.
- [Complex-Edit](https://arxiv.org/abs/2504.13143): Evaluates complexity-controllable image editing. Core idea: generate CoT-like editing instructions with controlled difficulty so editing models can be tested on compositional and multi-step intent rather than only simple local edits.
- [Scalable Human-aligned Benchmark for Text-guided Image Editing](https://arxiv.org/abs/2505.00502): Evaluates text-guided image editing with human-aligned judgments. Core idea: scale evaluation around whether edits satisfy user instructions and human quality preferences rather than only low-level visual metrics.
- [WorldGenBench](https://arxiv.org/abs/2505.01490): Evaluates reasoning-driven text-to-image generation with world knowledge. Core idea: test whether image generators preserve commonsense and factual world constraints rather than only matching local prompt tokens.
- [UniEval](https://arxiv.org/abs/2505.10483): provides unified holistic evaluation for multimodal understanding and generation models. Core idea: reduce fragmented task-specific testing by comparing unified models under one evaluation framework that covers both comprehension and generation behavior.
- [GIE-Bench](https://arxiv.org/abs/2505.11493): Evaluates grounded text-guided image editing. Core idea: check whether edits follow text instructions while remaining grounded in the source image rather than only producing visually plausible changes.
- [CompBench](https://arxiv.org/abs/2505.12200): Benchmarks complex instruction-guided image editing. Core idea: stress compositional edit instructions and measure whether editing models preserve both target modifications and surrounding visual consistency.
- [KRIS-Bench](https://arxiv.org/abs/2505.16707): Benchmarks intelligent image editing models. Core idea: evaluate whether image editors preserve semantic intent, spatial consistency, and edit fidelity under richer editing instructions.
- [OmniGenBench](https://arxiv.org/abs/2505.18775): Evaluates omnipotent multimodal generation across more than 50 tasks. Core idea: place heterogeneous generation tasks under one benchmark protocol so text, image, audio, video, and cross-modal generators can be compared beyond isolated task-specific metrics.
- [MMIG-Bench](https://arxiv.org/abs/2505.19415): Evaluates multimodal image generation with text prompts and multi-view reference images. Core idea: unify text-to-image, image-conditioned generation, editing, and concept-consistency checks with annotated subjects and explainable dimensions such as compositional semantics and common knowledge.
- [TIIF-Bench](https://arxiv.org/abs/2506.02161): evaluates instruction following in text-to-image models. Core idea: turn prompt compliance into a targeted benchmark so models can be compared on whether generated images satisfy specified constraints.
- [ByteMorph](https://arxiv.org/abs/2506.03107): Benchmarks instruction-guided image editing with non-rigid motions. Core idea: test whether editing systems can handle deformation, pose change, and motion-like transformations while preserving object identity and scene coherence.
- [RefEdit-Bench](https://arxiv.org/abs/2506.03448): Evaluates instruction-based image editing with referring expressions in complex scenes. Core idea: root edits in real RefCOCO-style object references so models must identify the intended entity and preserve the rest of the source image.
- [ComplexBench-Edit](https://arxiv.org/abs/2506.12830) ([code](https://github.com/llllly26/ComplexBench-Edit)): Evaluates complex instruction-driven image editing. Core idea: stress multi-instruction and chain-dependent edits, while measuring preservation of unmodified regions so editing models are not rewarded for satisfying one operation while damaging the rest of the image.
- [AIGODI Quality Assessment](https://arxiv.org/abs/2506.21925): Evaluates quality and saliency for AI-generated omnidirectional images. Core idea: target VR/AR-style 360-degree generated images with distortion-aware quality assessment and saliency prediction, separating panoramic artifacts from ordinary single-view image-generation failures.
- [MVGBench](https://arxiv.org/abs/2507.00006): Evaluates multi-view generation models. Core idea: compare whether generators preserve object, scene, and viewpoint consistency across multiple generated views rather than only scoring single-image fidelity.
- [LMM4Edit / EBench-18K](https://arxiv.org/abs/2507.16193) ([code](https://github.com/IntMeGroup/LMM4Edit)): Evaluates text-guided image editing with human preference annotations and LMM-based scoring. Core idea: cover perceptual quality, editing alignment, attribute preservation, and task-specific QA so image-editing evaluation better matches human judgments.
- [7Bench](https://arxiv.org/abs/2508.12919): Evaluates layout-guided text-to-image generation. Core idea: stress whether image generators can follow explicit spatial layouts and text prompts together, complementing broader multimodal-generation benchmarks with a layout-control axis.
- [EdiVal-Agent](https://arxiv.org/abs/2509.13399): An object-centric evaluation framework for multi-turn image editing. Core idea: make editing trajectories auditable with scalable, fine-grained checks rather than judging only final-image appearance.
- [Text-to-Image Models Leave Identifiable Signatures](https://arxiv.org/abs/2510.06525): Studies leaderboard security for generative image models. Core idea: show that generated images can deanonymize hidden model identities with high accuracy, making rank manipulation and prompt-selection attacks a concrete reliability risk for anonymous arenas.
- [DREAM](https://arxiv.org/abs/2510.10053): Benchmarks deepfake photorealism assessment. Core idea: evaluate whether models or judges can distinguish and rate the realism of synthetic face imagery, complementing broader image-generation quality and safety checks.
- [GIR-Bench](https://arxiv.org/abs/2510.11026): Evaluates image generation with reasoning in unified multimodal models. Core idea: test understanding-generation consistency, reasoning-conditioned visual synthesis, and generalization across complex visual tasks.
- [ViVerBench](https://arxiv.org/abs/2510.13804) ([project page](https://omniverifier.github.io/); [dataset](https://huggingface.co/datasets/comin/ViVerBench)): evaluates verification capability for visual results. The core idea is to convert key judgments in visual understanding/generation into verifiable subtasks and emphasize "whether the model can prove itself right or wrong."
- [UniGenBench++](https://arxiv.org/abs/2510.18701): Evaluates semantic alignment in text-to-image generation. Core idea: use a unified semantic evaluation protocol to test whether generated images satisfy prompt meaning rather than only achieving high visual quality.
- [UniREditBench](https://arxiv.org/abs/2511.01295): Evaluates reasoning-based image editing for multimodal generative models. Core idea: test whether editors handle multi-object interactions, rule-governed scenes, and implicit reasoning demands rather than only simple attribute changes.
- [Q-REAL](https://arxiv.org/abs/2511.16908): Evaluates realism and plausibility in AI-generated content. Core idea: judge whether generated outputs are not only visually or perceptually polished but also plausible under real-world constraints.
- [Beyond Words and Pixels](https://arxiv.org/abs/2511.18271): evaluates implicit world-knowledge reasoning in generative models. Core idea: test whether generated outputs reflect unstated real-world constraints rather than only surface prompt tokens.
- [SPQR](https://arxiv.org/abs/2511.19558): A standardized benchmark for safety alignment methods in text-to-image diffusion models. Core idea: compare modern safety mechanisms under a common T2I protocol instead of relying on isolated red-team examples.
- [UnicEdit-10M](https://arxiv.org/abs/2512.02790): Evaluates reasoning-enriched image editing at scale. Core idea: pair a large edit dataset with unified verification so instruction following, reasoning constraints, and edit quality can be checked together.
- [I2I-Bench](https://arxiv.org/abs/2512.04660): evaluates image-to-image editing models. Core idea: organize image editing tasks into a benchmark suite so instruction adherence, preservation, and edit quality can be compared across systems.
- [LongT2IBench](https://arxiv.org/abs/2512.09271): Evaluates long text-to-image generation with graph-structured annotations. Core idea: test whether image generators preserve entities, attributes, relations, and constraints from long prompts rather than only matching a short caption.
- [TextEditBench](https://arxiv.org/abs/2512.16270): Evaluates reasoning-aware text editing beyond simple rendering. Core idea: test whether image editors can modify text in context while preserving semantic intent, layout, and visual consistency.
- [GenEval 2](https://arxiv.org/abs/2512.16853): Studies benchmark drift in text-to-image evaluation. Core idea: update and diagnose image-generation evaluation so model comparisons remain meaningful as systems adapt to older benchmark distributions.
- [VIBE](https://arxiv.org/abs/2602.01851): Evaluates visual instruction following in image editing. Core idea: use systematic visual-editing tasks to test whether models preserve semantic and logical constraints in the edited image rather than only applying superficial visual changes.
- [GenArena](https://arxiv.org/abs/2602.06013): Evaluates visual generation tasks with human-aligned comparison protocols. Core idea: use arena-style or preference-aligned evaluation to better match human judgments across image and visual-generation outputs.
- [WorldEdit](https://arxiv.org/abs/2602.07095): Evaluates open-world image editing with knowledge-informed prompts and checks. Core idea: test whether editing models use world knowledge and instruction semantics rather than only performing local visual transformations.
- [MICON-Bench](https://arxiv.org/abs/2602.19497): evaluates multi-image-context image generation in unified multimodal models. Core idea: test whether generators can condition on several images coherently instead of treating each visual context independently.
- [InEdit-Bench](https://arxiv.org/abs/2603.03657): evaluates intermediate logical pathways in intelligent image editing. Core idea: require models to generate coherent multi-step visual transitions across state changes, dynamic processes, temporal sequences, and scientific simulations, exposing reasoning failures hidden by final-frame evaluation.
- [DSH-Bench](https://arxiv.org/abs/2603.08090): Evaluates subject-driven text-to-image generation with difficulty- and scenario-aware hierarchical taxonomy. Core idea: separate subject preservation failures by scenario and difficulty instead of reporting only generic prompt-image alignment.
- [WeEdit](https://arxiv.org/abs/2603.11593): evaluates text-centric image editing across bilingual and multilingual operations. Core idea: pair a large HTML-generated editing corpus with standardized benchmarks so models are judged on instruction adherence, text clarity, and preservation of non-target image regions.
- [Omni IIE Bench](https://arxiv.org/abs/2603.16944): evaluates practical instruction-based image editing capability. Core idea: use dual-track diagnostics for single-turn consistency and multi-turn editing behavior so models are tested on semantic-scale stability rather than only mixed task averages.
- [TIEdit](https://arxiv.org/abs/2603.19775): Evaluates text-guided image editing across representative edit tasks. Core idea: pair source images with prompts and edited outputs from multiple systems, then assess perceptual quality, instruction alignment, and content preservation while probing why automatic LLM-based judgments diverge from human perception.
- [MultiBind](https://arxiv.org/abs/2603.21937): Evaluates attribute misbinding in multi-subject image generation. Core idea: use multiple subject references, background references, and entity-indexed prompts to test whether generated images preserve and edit attributes on the intended subject rather than swapping them across people.
- [BizGenEval](https://arxiv.org/abs/2603.25732): evaluates commercial visual content generation. Core idea: use business-facing visual creation tasks to compare whether generators satisfy layout, branding, instruction, and content-quality requirements.
- [CREval](https://arxiv.org/abs/2603.26174): Evaluates creative image manipulation under complex instructions. Core idea: make image-editing assessment more interpretable by decomposing complex user intent into automated checks rather than relying only on coarse visual preference.
- [ImagenWorld](https://arxiv.org/abs/2603.27862): stress-tests image generation models on open-ended real-world tasks with explainable human evaluation. Core idea: evaluate whether generated images satisfy realistic task constraints and make human judgments auditable.
- [KITTEN](https://www.semanticscholar.org/paper/6ccd8fbaa9578bb6a3f7835329515353477d6ad3): Evaluates image generation on visual entities with knowledge-integrated checks. Core idea: test whether generators preserve entity-specific visual facts and knowledge rather than only producing plausible generic images.
- [SCALE / ZoneMaestro](https://arxiv.org/abs/2605.02537): Evaluates intricate spatial orchestration in irregular indoor scene generation. Core idea: stress dense spatial relations, functional zones, and non-convex layouts so spatial reasoning is tested beyond simple object placement.
- [DynT2I-Eval](https://arxiv.org/abs/2605.06170): Evaluates text-to-image models with dynamically generated prompts. Core idea: construct a structured visual-semantic space and continuously sample fresh prompts across subject, logic, environment, and composition dimensions to reduce benchmark contamination and diagnose alignment, perceptual quality, and aesthetics.

## 4.1.4 Agent Harness

- [ComfyBench / ComfyAgent](https://arxiv.org/abs/2409.01392) ([open-source code](https://github.com/xxyQwQ/ComfyBench); [project page](https://xxyqwq.github.io/ComfyBench)): A ComfyUI workflow-generation and evaluation harness in which an LLM agent learns documentation, generates executable workflows, runs them, and is scored by pass/resolve-style metrics.
- [ComfyGPT](https://arxiv.org/abs/2503.17671) ([open-source code](https://github.com/comfygpt/comfygpt); [project page](https://comfygpt.github.io/)): A self-optimizing multi-agent system for ComfyUI workflow generation, with flow generation, refinement, and execution agents.
- [CIGEval](https://arxiv.org/abs/2504.07046): An agentic evaluation harness for conditional image generation. Core idea: let an LMM select tools and produce fine-grained judgments across conditional generation tasks, making image-generation evaluation a tool-mediated workflow rather than a single scalar metric.
- [ComfyMind](https://arxiv.org/abs/2505.17908) ([open-source code](https://github.com/EnVision-Research/ComfyMind)): a planning-and-feedback harness for general-purpose generation on ComfyUI. Core idea: use tree-based workflow planning and reactive execution feedback so complex multimodal generation tasks can be decomposed, executed, and repaired rather than handled as one-shot prompts.
- [ComfyUI-Copilot](https://arxiv.org/abs/2506.05010) ([open-source code](https://github.com/AIDC-AI/ComfyUI-Copilot)): A ComfyUI workflow-lifecycle assistant for generation, debugging, rewriting, parameter tuning, and agentic workflow operation inside the ComfyUI ecosystem; its public repository currently notes that the official API service is paused, so practical deployment needs a user-supplied LLM API key and base URL.
- [Maestro](https://arxiv.org/abs/2509.10704): An agent-orchestration harness for self-improving text-to-image generation. Core idea: coordinate generation, critique, and refinement agents so image outputs improve through an explicit workflow rather than a single model call.
- [PromptSculptor](https://arxiv.org/abs/2509.12446): A multi-agent text-to-image prompt-optimization harness. Core idea: separate prompt analysis, refinement, and quality feedback into cooperating agents so image-generation prompts can be iteratively improved outside the base generator.
- [OmniVerifier](https://arxiv.org/abs/2510.13804) ([open-source code](https://github.com/Cominclip/OmniVerifier)): a generative verifier for visual-result verification. It can turn "visual judgment" into an explicit verification and self-correction loop and compare evaluations on ViVerBench and related benchmarks.
- [ComfySearch](https://arxiv.org/abs/2601.04060): An autonomous exploration harness for ComfyUI workflows. Core idea: search the component graph under strict workflow constraints and use validation-guided construction so agents can generate executable, higher-quality ComfyUI pipelines.
- [coDrawAgents](https://arxiv.org/abs/2603.12829): a multi-agent dialogue harness for compositional image generation. Core idea: split interpretation, planning, checking, and painting roles so complex object layouts and attributes can be iteratively grounded before image synthesis.
- [EditRefiner](https://arxiv.org/abs/2605.07457): a human-aligned agentic framework for image-editing refinement. Core idea: wrap image editing in an iterative refinement loop so feedback, alignment checks, and edit revision are handled outside the base generator.
