# 1.11.6 Skill

- [mcp-builder](https://skills.sh/anthropics/skills/mcp-builder) is suitable for quickly building MCP servers.
- [mcp-cli](https://skills.sh/github/awesome-copilot/mcp-cli) gives agents command-line operations for inspecting, invoking, and managing MCP runtimes instead of treating tools as opaque endpoints.
- [mcp-deploy-manage-agents](https://skills.sh/github/awesome-copilot/mcp-deploy-manage-agents) covers deployment and lifecycle operations for MCP services and agent processes, including start, stop, update, and monitoring routines.
- [mcporter](https://github.com/openclaw/openclaw/tree/main/skills/mcporter) is suitable for listing, configuring, authenticating, calling, and inspecting MCP servers and tools from an agent-readable command-line workflow.
- [langchain4j-tool-function-calling-patterns](https://skills.sh/giuseppe-trisciuoglio/developer-kit/langchain4j-tool-function-calling-patterns) is suitable for integrating function calling into engineering frameworks.
- [skill-validator](https://skills.sh/daffy0208/ai-dev-standards/skill-validator) can serve as an additional validation layer in tool-call chains.
- [Design and Implementation of MCP-Web-Curl: A Model Context Protocol Server for Web and API Access in Agentic Coding Assistants](https://doi.org/10.15408/jti.v19i1.49625): Reusable skill/tooling candidate for tool use and retrieval-augmented execution: Provides an MCP server for web and API access in coding-assistant workflows.
