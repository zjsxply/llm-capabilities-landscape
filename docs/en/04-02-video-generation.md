# 4.2 Video Generation Models

> Parent chapter: 4. Multimodal

Note: This page collects video, audio-video, animation, 3D scene, editing, and dynamic world-model generation evaluations and orchestration harnesses. Passive video understanding stays in [1.6 Video](01-06-video.md).

## 4.2.1 Bench

- [VBench++](https://doi.org/10.1109/TPAMI.2025.3633890): A comprehensive benchmark suite for video generative models. Core idea: organize versatile metrics for generated-video quality, consistency, motion, and prompt alignment so video generation systems can be compared beyond isolated preference tests.
- [T2VEval](https://arxiv.org/abs/2501.08545): Evaluates text-to-video generation with a benchmark dataset and objective evaluation method. Core idea: provide structured prompts, generated-video samples, and automatic metrics so T2V quality can be compared beyond ad hoc preference judgments.
- [VE-Bench](https://doi.org/10.1609/aaai.v39i7.32763): Evaluates text-driven video editing quality with subjective-aligned criteria. Core idea: benchmark edited videos against human preference dimensions so editing systems are judged on perceptual quality and instruction alignment rather than only low-level metrics.
- [Physical Coherence Benchmark](https://arxiv.org/abs/2502.05503): Evaluates physical coherence in generated videos through optical-flow-guided frame prediction. Core idea: use motion-consistency signals to expose physically implausible generated dynamics rather than judging only frame-level appearance.
- [VidCapBench](https://arxiv.org/abs/2502.12782): Evaluates video captioning for controllable text-to-video generation. Core idea: test whether captioning captures controllable generation attributes that matter for prompt construction and evaluation.
- [WorldModelBench](https://arxiv.org/abs/2502.20694): Evaluates whether video generation models behave as usable world models. Core idea: test instruction following and physics adherence with human-labeled violations and a learned evaluator for application-driven domains such as robotics and autonomous driving.
- [GRADEO](https://arxiv.org/abs/2503.02341): evaluates text-to-video generation with multi-step reasoning. Core idea: make video-quality judgments more human-like by decomposing evaluation into reasoning steps rather than using only surface-level automatic metrics.
- [VideoPhy-2](https://arxiv.org/abs/2503.06800): Evaluates action-centric physical commonsense in generated videos. Core idea: use diverse real-world actions, human judgments, and automatic evaluation to test whether video generation models preserve physically plausible dynamics rather than only visual appearance.
- [AIGVE-Tool](https://arxiv.org/abs/2503.14064): evaluates AI-generated video with a multifaceted benchmark toolkit. Core idea: combine several video-quality and prompt-alignment criteria so generated-video evaluation is more systematic than single-metric scoring.
- [SceneEval](https://arxiv.org/abs/2503.14756): Evaluates semantic coherence in text-conditioned 3D indoor scene synthesis. Core idea: test whether generated scenes satisfy spatial, object-relation, and layout semantics implied by text prompts.
- [ETVA](https://arxiv.org/abs/2503.16867): Evaluates text-to-video alignment through fine-grained question generation and answering. Core idea: decompose prompts into atomic checks so semantic alignment failures are localized rather than collapsed into one coarse score.
- [3DGen-Bench](https://arxiv.org/abs/2503.21745): Evaluates 3D generative models through a comprehensive benchmark suite. Core idea: compare generated 3D content across visual, geometric, and semantic criteria so 3D generation quality is not reduced to isolated perceptual scores.
- [WorldScore](https://arxiv.org/abs/2504.00983): Provides a unified evaluation benchmark for world generation. Core idea: compare generated worlds through task-relevant consistency and dynamics, making world-generation quality measurable for downstream embodied use.
- [Video-Bench](https://arxiv.org/abs/2504.04907): Evaluates human alignment in video generation. Core idea: compare generated videos against human preferences and quality judgments rather than relying only on automatic surface metrics.
- [FingER](https://arxiv.org/abs/2504.10358): Evaluates AI-generated videos with content-aware fine-grained reasoning. Core idea: inspect generated-video quality through interpretable reasoning over visual content rather than only aggregate perceptual scores.
- [Eval3D](https://arxiv.org/abs/2504.18509): Evaluates generated 3D assets with fine-grained, interpretable visual, geometric, and semantic criteria, complementing spatial consistency benchmarks for 3D generation.
- [T2VPhysBench](https://arxiv.org/abs/2505.00337): Evaluates physical consistency in text-to-video generation from first-principles constraints. Core idea: turn violations of physical laws and dynamics into explicit diagnostics for generated videos.
- [T2VTextBench](https://arxiv.org/abs/2505.04946): Evaluates textual control in text-to-video generation. Core idea: use human evaluation of on-screen text fidelity and temporal consistency to expose failures that broad video-quality metrics miss.
- [EWMBench](https://arxiv.org/abs/2505.09694): Evaluates embodied world models across scene consistency, motion correctness, and semantic alignment. Core idea: use a curated dataset and evaluation toolkit to test whether generated dynamics are physically grounded and action-consistent for embodied tasks.
- [LOVE](https://arxiv.org/abs/2505.12098): Evaluates text-to-video generation and video-to-text interpretation. Core idea: compare both directions of video-language alignment so generation quality and interpretability are assessed under a shared protocol.
- [CineTechBench](https://arxiv.org/abs/2505.15145) ([code](https://github.com/PRIS-CV/CineTechBench), [dataset](https://huggingface.co/datasets/Xinran0906/CineTechBench)): Evaluates cinematographic technique understanding and generation. Core idea: use expert annotations for camera movement, shot composition, lighting, and related film techniques, testing whether video and generation models can reason about craft-level visual language rather than only events.
- [TDVE-Assessor](https://arxiv.org/abs/2505.19535): Benchmarks text-driven video editing quality with LMM-based assessment. Core idea: use TDVE-DB, human ratings, and dimensions such as edited-video quality, editing alignment, and structural consistency to judge editing results.
- [OpenS2V-Nexus](https://arxiv.org/abs/2505.20292): Evaluates subject-to-video generation with a detailed benchmark and million-scale dataset. Core idea: test whether generators preserve the referenced subject while producing temporally coherent videos.
- [AIGC-LipSync Benchmark / OmniSync](https://arxiv.org/abs/2505.21448): Evaluates lip synchronization in diverse AI-generated videos. Core idea: test whether audio-driven editing preserves identity, visual quality, and accurate mouth-audio alignment across real, stylized, and AI-generated video scenarios.
- [RealVideoQuest](https://arxiv.org/abs/2506.01689): Evaluates video generation as a response to realistic user intents. Core idea: derive video-response queries from real user interactions and score whether generated videos answer the underlying information need rather than merely matching prompt keywords.
- [3D Arena](https://arxiv.org/abs/2506.18787): evaluates generative 3D systems through an open comparison platform. Core idea: make 3D generation quality comparable across visual, geometric, and semantic dimensions rather than relying on isolated qualitative examples.
- [TC-Bench](https://doi.org/10.18653/v1/2025.findings-acl.241): Evaluates temporal compositionality in conditional video generation; core idea: test whether generated videos preserve ordered events, temporal relations, and condition-dependent motion rather than only visual fidelity.
- [NarrLV](https://arxiv.org/abs/2507.11245): Evaluates narrative coherence in long-video generation. Core idea: make story structure, event continuity, and long-range consistency first-class evaluation targets for generated videos.
- [PhyWorldBench](https://arxiv.org/abs/2507.13428): Evaluates physical realism in text-to-video models. Core idea: make violations of object dynamics, interactions, and physical consistency the primary scoring target for generated videos.
- [T2VWorldBench](https://arxiv.org/abs/2507.18107): Evaluates world knowledge in text-to-video generation. Core idea: test whether generated videos respect commonsense, object behavior, and real-world constraints rather than only matching prompt keywords.
- [World Consistency Score](https://arxiv.org/abs/2508.00144): Evaluates video generation quality through world consistency; core idea: unify checks for temporal, physical, and semantic consistency so generated videos are scored beyond frame-level appearance.
- [UI2V-Bench](https://arxiv.org/abs/2509.24427): Evaluates understanding-based image-to-video generation. Core idea: test whether models infer scene structure, intent, and plausible motion from an input image before generating video.
- [FiVE-Bench](https://doi.org/10.1109/ICCV51701.2025.01548): Evaluates video editing by diffusion and rectified-flow models. Core idea: use fine-grained edit categories and metrics to separate editing fidelity, temporal consistency, and prompt alignment.
- [DynamicEval](https://arxiv.org/abs/2510.07441): Evaluates dynamic text-to-video synthesis under camera motion. Core idea: use prompts emphasizing dynamic shots plus large-scale pairwise human annotations to judge video-level quality instead of only aggregate model rankings.
- [VideoVerse](https://doi.org/10.48550/arXiv.2510.08398): Evaluates how far text-to-video generators are from usable world models. Core idea: test whether generated videos preserve physical, temporal, and action-conditioned dynamics rather than only visual plausibility.
- [LikePhys](https://arxiv.org/abs/2510.11512): Evaluates intuitive physics understanding in video diffusion models through likelihood preference. Core idea: compare physically plausible and implausible alternatives so video-generation evaluation can expose dynamics failures rather than only visual quality.
- [IVEBench](https://arxiv.org/abs/2510.11647): Evaluates instruction-guided video editing models. Core idea: use a modern editing benchmark suite to separate instruction following, edit fidelity, temporal consistency, and perceptual quality in generated or edited videos.
- [SeqBench](https://arxiv.org/abs/2510.13042): Evaluates sequential narrative coherence in text-to-video generation. Core idea: use multi-event prompts, human-annotated model outputs, and Dynamic Temporal Graph metrics to test whether generated videos preserve logical event order over longer sequences.
- [Identity Leakage in Talking Face Generation](https://arxiv.org/abs/2511.08613): Evaluates identity leakage in talking-face generation with silent-input, mismatched audio-video, and matched synthesis setups. Core idea: detect whether generated lip motion leaks from the identity reference rather than the driving audio, adding a reliability check beyond ordinary lip-sync scores.
- [Target-Bench](https://arxiv.org/abs/2511.17792): Evaluates whether video world models can support mapless path planning with semantic targets. Core idea: test navigation-relevant foresight by asking models to reason about target-directed movement without an explicit map.
- [4DWorldBench](https://arxiv.org/abs/2511.19836): Evaluates 3D and 4D world generation models. Core idea: judge generated worlds over spatial structure and temporal evolution, extending spatial evaluation from static scenes to dynamic world-generation outputs.
- [CVBench](https://doi.org/10.1109/VCIP67698.2025.11396889): Benchmarks and compares video generation with large multimodal models. Core idea: use an LMM-based evaluation protocol to judge generated-video quality and prompt alignment more systematically than ad hoc visual inspection.
- [RULER-Bench](https://arxiv.org/abs/2512.02622): Evaluates rule-based reasoning in video generation models. Core idea: test whether generated videos obey explicit rules and structured constraints rather than only matching prompt-level appearance.
- [VideoScience-Bench](https://arxiv.org/abs/2512.02942): Evaluates scientific understanding and reasoning for video generation. Core idea: use science-oriented prompts and judgments to test whether generated videos preserve scientific concepts and causal structure rather than only surface realism.
- [EgoEditBench](https://arxiv.org/abs/2512.06065): Evaluates instruction-guided egocentric video editing. Core idea: test instruction faithfulness, hand and interaction preservation, and temporal stability under rapid egomotion and streaming constraints.
- [RVE-Bench / ReViSE](https://arxiv.org/abs/2512.09924): Evaluates reason-informed video editing. Core idea: test whether editing models preserve physical plausibility and causal dynamics through reasoning-aware editing and in-context video-to-video generation tasks.
- [T2AV-Compass](https://arxiv.org/abs/2512.21094): Evaluates text-to-audio-video generation under a unified protocol. Core idea: jointly assess visual quality, audio quality, prompt alignment, and cross-modal synchronization.
- [SVBench](https://arxiv.org/abs/2512.21507): Evaluates social reasoning in video generation. Core idea: test whether generated videos preserve interactions, intentions, and social relations rather than only visual plausibility.
- [PhyAVBench](https://arxiv.org/abs/2512.23994): Evaluates audio physics sensitivity in text-to-audio-video generation; core idea: test whether generated visual and audio events obey physically grounded cross-modal cues.
- [Wow, wo, val!](https://arxiv.org/abs/2601.04137): Evaluates embodied world models through a Turing-test-style protocol. Core idea: compare generated dynamics against interactive world behavior to judge perceptual fidelity and action consistency.
- [NRVBench](https://arxiv.org/abs/2601.18340): Evaluates non-rigid video editing. Core idea: combine physics-based motion categories, fine-grained edit instructions, multiple-choice checks, and NRVE-Acc to test physical compliance, temporal consistency, and instruction alignment.
- [GEOATTRACTION-500 / GAP](https://arxiv.org/abs/2601.18698): evaluates geographically grounded visual knowledge in text-to-video generation. Core idea: use tourist-attraction prompts and complementary structural, keypoint, and vision-language judgments to separate global video quality from attraction-specific geographic fidelity.
- [VC-Bench](https://arxiv.org/abs/2601.19236): evaluates video connecting, where a model generates smooth intermediate content between start and end clips. Core idea: score video quality, start-end consistency, and transition smoothness so clip-connection systems are not judged only by generic generation quality.
- [Artifact-Aware Evaluation](https://arxiv.org/abs/2601.20297): Evaluates high-quality video generation through appearance, motion, and camera artifact categories. Core idea: localize and classify generated-video failures instead of reporting only coarse quality scores.
- [WorldBench](https://arxiv.org/abs/2601.21282): Diagnoses physical fidelity in world models. Core idea: disentangle physics factors to localize failures in dynamics, causality, and object interactions relevant to embodied planning.
- [MTAVG-Bench](https://arxiv.org/abs/2602.00607): evaluates multi-talker dialogue-centric audio-video generation. Core idea: test whether generated videos preserve speaker interaction, audiovisual synchronization, and dialogue-centered temporal consistency.
- [Omni-Judge](https://arxiv.org/abs/2602.01623): Evaluates whether omni-modal LLMs can serve as human-aligned judges for text-conditioned audio-video generation. Core idea: replace isolated audio, video, and text metrics with interpretable multimodal judging over visual quality, audio quality, prompt alignment, and audio-video synchronization.
- [RISE-Video](https://arxiv.org/abs/2602.05986): Evaluates whether video generators capture implicit world rules. Core idea: test rule-consistent dynamics rather than surface realism, complementing physical-plausibility benchmarks for generated video.
- [MIND](https://arxiv.org/abs/2602.08025): Benchmarks memory consistency and action control in world models. Core idea: test whether interactive world models preserve state over time and respond reliably to action-conditioned control.
- [UniVBench](https://arxiv.org/abs/2602.21835): Evaluates video foundation models under a unified protocol; core idea: consolidate multiple video understanding and generation dimensions so model comparisons are less fragmented across task-specific suites.
- [MSVBench](https://arxiv.org/abs/2602.23969): Evaluates multi-shot video generation. Core idea: move evaluation toward human-level judgment of continuity, identity, scene consistency, and narrative coherence across multiple shots.
- [Actor-Bench / WildActor](https://arxiv.org/abs/2603.00586): Evaluates identity-preserving human video generation across viewpoints, environments, and motions. Core idea: test full-body identity consistency rather than only face similarity or single-reference prompt following.
- [OSCBench](https://arxiv.org/abs/2603.11698): evaluates object state change in text-to-video generation. Core idea: use action-object prompts from regular, novel, and compositional scenarios to test whether generated videos show temporally consistent state transformations rather than only broad semantic alignment.
- [Out of Sight, Out of Mind?](https://arxiv.org/abs/2603.13215): Evaluates state evolution in video world models. Core idea: diagnose whether a world model maintains hidden or temporarily occluded state over time, a key requirement for embodied planning.
- [SGC](https://arxiv.org/abs/2603.19048): Evaluates 3D spatial geometric consistency in dynamically generated videos. Core idea: estimate local camera-pose divergence over static background regions so geometric failures are detected separately from foreground motion.
- [Physion-Eval](https://arxiv.org/abs/2603.19607): Evaluates physical realism in generated videos through expert human reasoning. Core idea: annotate temporally localized physical glitches and fine-grained violation categories against real reference videos, making failures explainable rather than only preference-based.
- [Omni-WorldBench](https://arxiv.org/abs/2603.22212): Evaluates interaction-centric 4D world models. Core idea: combine an interaction prompt suite with agent-based metrics that measure how actions causally affect final outcomes and intermediate state trajectories.
- [World Reasoning Arena](https://arxiv.org/abs/2603.25887): Evaluates world models as simulators for agents. Core idea: test action simulation fidelity, long-horizon forecasting, and simulative reasoning/planning rather than only next-frame realism.
- [PVIR](https://arxiv.org/abs/2604.05898): Evaluates physics-aware video instance removal. Core idea: test whether object removal preserves shadows, reflections, illumination, background integrity, and spatial consistency rather than only visual plausibility.
- [AVGen-Bench](https://arxiv.org/abs/2604.08540): Evaluates text-to-audio-video generation. Core idea: assess perceptual quality, semantic controllability, audio-video alignment, speech, music, text rendering, and physical reasoning under a single multi-granular protocol.
- [VidAudio-Bench](https://arxiv.org/abs/2604.10542): evaluates video-to-audio and video-text-to-audio generation across sound effects, music, speech, and singing. Core idea: combine category-specific metrics with human-alignment checks so audio quality, video-audio consistency, and text-audio consistency are diagnosed separately.
- [HOIVG-Bench / OmniShow](https://arxiv.org/abs/2604.11804): Evaluates human-object interaction video generation under text, reference image, audio, and pose conditions. Core idea: make multimodal controllability and audio-visual interaction fidelity explicit targets for generated-video evaluation.
- [AnimationBench](https://arxiv.org/abs/2604.15299): Evaluates character-centric animation generation. Core idea: operationalize animation principles, IP preservation, motion rationality, camera consistency, and semantic consistency for both closed-set and open-set image-to-video evaluation.
- [VEFX-Bench](https://arxiv.org/abs/2604.16272): Evaluates generic video editing and visual effects generation. Core idea: use a holistic protocol to test editing fidelity, effect quality, and prompt-conditioned controllability rather than only passive video generation.
- [OmniHuman / OHBench](https://arxiv.org/abs/2604.18326): evaluates human-centric video generation in complex real-world scenes. Core idea: use hierarchical annotations and a three-level benchmark to diagnose scene diversity, person-person and person-object interactions, and individual attribute alignment in generated audio-video content.
- [RoboWM-Bench](https://arxiv.org/abs/2604.19092): Evaluates world models in robotic manipulation. Core idea: test whether predicted dynamics and state changes are useful for manipulation planning, not just visually plausible video continuation.
- [CLVG-Bench](https://arxiv.org/abs/2604.19193): Evaluates multimodal reasoning in video generation through context learning. Core idea: use complex physical, logical, and interactive video-context tasks plus adaptive evaluation feedback to expose reasoning and grounding failures in video generators.
- [WorldMark](https://arxiv.org/abs/2604.21686): Evaluates interactive image-to-video world models under standardized controls. Core idea: map a shared WASD-style action vocabulary into each model's native interface, then compare visual quality, control alignment, and world consistency on identical scenes and trajectories.
- [MuSS](https://arxiv.org/abs/2604.23789): evaluates multi-shot subject-to-video generation through a cinematic narrative benchmark. Core idea: test continuous storytelling, cross-shot subject consistency, and resistance to copy-paste shortcuts in long-form or montage-like generated videos.
- [HuM-Eval / HuM-Bench](https://arxiv.org/abs/2604.25361): Evaluates human-centric generated videos. Core idea: combine VLM-based global assessment with pose and 3D human-motion checks so anatomical correctness and motion stability are scored explicitly.
- [BRITE](https://arxiv.org/abs/2605.00873): Evaluates text-to-video generation on implausible scenarios. Core idea: combine implausible prompts, audio-visual consistency checks, and QA-based interpretable assessment so off-manifold failures can be localized rather than only scored holistically.
- [iWorld-Bench](https://arxiv.org/abs/2605.03941): Evaluates interactive world models with a unified action-generation framework. Core idea: test whether world models support action-conditioned interaction rather than only passive video prediction.
- [AV-Phys Bench](https://arxiv.org/abs/2605.07061): Evaluates physical commonsense in joint audio-video generation. Core idea: test visual, audio, and cross-modal physical consistency across steady-state and transition scenarios, including deliberately inconsistent Anti-AV-Physics prompts.
- [ACWM-Phys](https://arxiv.org/abs/2605.08567): Evaluates action-conditioned video world models under diverse physical interactions. Core idea: use controllable simulation data across rigid-body, kinematic, deformable-object, and particle dynamics with in-distribution and out-of-distribution protocols.
- [MechVerse](https://arxiv.org/abs/2605.14843): Evaluates mechanical motion consistency in image-to-video generation. Core idea: use articulated mechanical assemblies with rigid-link, contact, coupling, and kinematic-chain constraints to expose physically inadmissible generated motion.
- [PDI-Bench](https://arxiv.org/abs/2605.15185): Evaluates geometric consistency in generated videos. Core idea: lift tracked object-centric observations into 3D and compute projective-geometry residuals for scale-depth alignment, motion consistency, and structural rigidity.
- [EntityBench](https://arxiv.org/abs/2605.15199): Evaluates entity consistency in long-range multi-shot video generation. Core idea: use narrative episodes with explicit character, object, and location schedules to separate intra-shot quality, prompt following, and cross-shot consistency.

## 4.2.2 Agent Harness

- [FilmAgent](https://arxiv.org/abs/2501.12909): A multi-agent film-automation harness in virtual 3D spaces. Core idea: decompose film creation into coordinated agent roles and executable scene-production steps rather than treating video generation as a single prompt-to-video call.
- [MM-StoryAgent](https://arxiv.org/abs/2503.05242) ([open-source code](https://github.com/X-PLUG/MM_StoryAgent)): A multi-agent harness for narrated storybook video generation. Core idea: coordinate writing, visual generation, narration, sound effects, and music modules so a story can be planned and rendered across text, image, and audio tools rather than generated by one monolithic model.
- [MovieAgent](https://arxiv.org/abs/2503.07314): A multi-agent planning harness for automated long-form video generation. Core idea: assign LLM agents roles such as director, screenwriter, storyboard artist, and location manager so scripts can be decomposed into scenes, shots, camera choices, subtitles, audio, and character-consistent generation steps.
- [V-Stylist](https://arxiv.org/abs/2503.12077): A multi-agent video-stylization harness. Core idea: coordinate video parsing, style-model search, and reflection so MLLM agents can decompose multi-shot videos and iteratively refine stylized outputs.
- [AniMaker](https://arxiv.org/abs/2506.10540): a multi-agent harness for animated storytelling. Core idea: combine role-based story planning with MCTS-driven clip generation so long animation can be decomposed, searched, and revised across agents.
- [AniME](https://arxiv.org/abs/2508.18781): a multi-agent planning harness for long animation generation. Core idea: adaptively coordinate planning roles so long animations preserve plot, character, and scene consistency across generated segments.
- [EditDuet](https://arxiv.org/abs/2509.10761): A multi-agent harness for non-linear video editing. Core idea: split editing into an Editor agent that uses video-editing tools and a Critic agent that gives feedback or approves renders, turning instruction-driven editing into an iterative tool-mediated workflow.
- [MagicWand](https://arxiv.org/abs/2511.18352): A user-preference-aligned generation and evaluation agent for image and video AIGC. Core idea: keep preference descriptions in the loop across prompt enhancement, generation, evaluation, and refinement, with UniPreferBench used to assess preference alignment.
- [The Script is All You Need](https://arxiv.org/abs/2601.17737): An agentic framework for long-horizon dialogue-to-cinematic video generation, treating scripts as planning artifacts for multi-stage video creation.
- [SAGE: Scalable Agentic 3D Scene Generation](https://arxiv.org/abs/2602.10116): Provides scalable 3D scene generation for embodied-agent evaluation. Core idea: synthesize agentic scenes so robots or simulated agents can be tested across diverse actionable environments rather than a small fixed map set.
- [SPIRAL](https://arxiv.org/abs/2603.08403): A reflective planning harness for long-horizon action-conditioned video generation. Core idea: decompose goals with a PlanAgent, generate segments with memory context, and use a CriticAgent to reflect and repair action execution over time.
- [Mind-of-Director](https://arxiv.org/abs/2603.14790): A multimodal agent-driven film previsualization framework, using collaborative decision-making to organize cinematic planning before generation.
- [CutClaw](https://arxiv.org/abs/2603.29664) ([open-source code](https://github.com/GVCLab/CutClaw)): An agentic harness for hours-long video editing through music synchronization. Core idea: coordinate long-range editing decisions around audio structure so video-editing agents can handle extended timelines.
- [DIRECT](https://arxiv.org/abs/2604.04875): A video mashup creation framework using hierarchical multi-agent planning and intent-guided editing, relevant to agentic orchestration for video composition.
- [Camera Artist](https://arxiv.org/abs/2604.09195): A multi-agent framework for cinematic language storytelling video generation, relevant to video-generation harnesses that coordinate narrative, camera, and shot decisions.
