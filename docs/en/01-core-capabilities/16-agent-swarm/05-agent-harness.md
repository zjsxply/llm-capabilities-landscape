# 1.16.5 Agent Harness

- [LLM Harmony: Multi-Agent Communication for Problem Solving](https://arxiv.org/abs/2401.01312): Uses CAMEL-style role-playing personas so multiple LLM agents exchange problem-solving messages autonomously instead of relying on a human-specified chain-of-thought script.
- [Why Solving Multi-agent Path Finding with Large Language Model has not Succeeded Yet](https://arxiv.org/abs/2401.03630): Stress-tests LLM planning on multi-agent path finding, showing why route coordination is hard for plain LLM prompting and where external planners or constraint tools are still needed.
- [Bootstrapping LLM-based Task-Oriented Dialogue Agents via Self-Talk](https://arxiv.org/abs/2401.05033): Uses self-talk conversations to synthesize task-oriented dialogue trajectories, giving dialogue agents a bootstrap loop for generating goals, user turns, and agent responses before downstream evaluation or tuning.
- [S-Agents: Self-organizing Agents in Open-ended Environments](https://arxiv.org/abs/2402.04578): Builds a self-organizing swarm with a tree-of-agents workflow, hourglass agent architecture, and non-obstructive collaboration protocol for open-ended tasks.
- [LLM Agents can Autonomously Hack Websites](https://arxiv.org/abs/2402.06664): Demonstrates a web-security agent loop in which LLM agents inspect sites, plan exploits, and execute browser or web actions autonomously against realistic targets.
- [Simulating Strategic Reasoning: Comparing the Ability of Single LLMs and Multi-Agent Systems to Replicate Human Behavior](https://arxiv.org/abs/2402.08189): Compares single-agent and two-agent LLM simulations of ultimatum-game bargaining to test whether agent interaction better reproduces human punishment and norm-enforcement behavior.
- [TDAG](https://arxiv.org/abs/2402.10178): Builds multi-agent workflows through dynamic task decomposition and agent generation. Core idea: decompose a task graph on demand, instantiate agents for subtasks, and let the generated team execute the evolving graph instead of relying on a fixed role roster.
- [AgentScope](https://arxiv.org/abs/2402.14034) ([code](https://github.com/agentscope-ai/agentscope); [docs](https://doc.agentscope.io/)): A general open-source multi-agent framework with agents, tools, skills, memory, planning, MCP/A2A support, human-in-the-loop components, and evaluation utilities; useful as a practical substrate for swarm-style orchestration experiments.
- [AgentLite: A Lightweight Library for Building and Advancing Task-Oriented LLM Agent System](https://arxiv.org/abs/2402.15538): Provides a lightweight task-oriented agent library with modular reasoning, memory, tool-use, and environment interfaces, making it a reusable harness for prototyping and comparing LLM agent systems.
- [Language Agents as Optimizable Graphs](https://arxiv.org/abs/2402.16823): Represents language-agent pipelines as optimizable computation graphs, so prompts, modules, and inter-agent edges can be searched or tuned instead of being fixed by hand.
- [Rethinking the Bounds of LLM Reasoning: Are Multi-Agent Discussions the Key?](https://arxiv.org/abs/2402.18272): Evaluates discussion-style collaboration among LLM agents, treating inter-agent deliberation as the external reasoning scaffold being tested rather than adding a new base model.
- [Transforming Competition into Collaboration: The Revolutionary Role of Multi-Agent Systems and Language Models in Modern Organizations](https://arxiv.org/abs/2403.07769): Frames organization-scale LLM multi-agent systems around role specialization, cooperative decision routines, and incentive-aware coordination rather than treating agents as isolated productivity tools.
- [Agent Group Chat: An Interactive Group Chat Simulacra For Better Eliciting Collective Emergent Behavior](https://arxiv.org/abs/2403.13433): Simulates interactive group debates with character agents and a verbal-strategist agent, using group chat dynamics to elicit collective emergent behavior.
- [Agentic AI: The Era of Semantic Decoding](https://arxiv.org/abs/2403.14562): Frames humans, LLMs, search engines, code executors, and other tools as semantic processors that can be orchestrated as an optimization procedure in semantic space.
- [AgentFL: Scaling LLM-based Fault Localization to Project-Level Context](https://arxiv.org/abs/2403.16362): Decomposes project-level fault localization across LLM agents so large codebases can be inspected beyond a single method or class context window.
- [TwoStep: Multi-agent Task Planning using Classical Planners and Large Language Models](https://arxiv.org/abs/2403.17246): Lets an LLM decompose multi-agent goals into subgoals, then delegates each subgoal to classical PDDL planners to exploit simultaneous single-agent action plans.
- [ITCMA: A Generative Agent Based on a Computational Consciousness Structure](https://arxiv.org/abs/2403.20097): Adds an internal time-consciousness structure to agent reasoning so the agent can maintain longer-term consistency while acting in open-world settings.
- [Self-Organized Agents: A LLM Multi-Agent Framework toward Ultra Large-Scale Code Generation and Optimization](https://arxiv.org/abs/2404.02183): Organizes autonomous code agents that independently generate or modify components while coordinating through a self-organized framework for large codebases.
- [360∘REA: Towards A Reusable Experience Accumulation with 360∘ Assessment for Multi-Agent System](https://arxiv.org/abs/2404.05569): Accumulates reusable multi-agent experience and evaluates it with a 360-degree assessment loop so agents can reuse interaction knowledge across tasks.
- [Apollonion: Profile-centric Dialog Agent](https://arxiv.org/abs/2404.08692): Centers the dialogue harness on user profiles, combining retrieval, character personalization, and short- or long-term memory to vary responses across users.
- [Confidence Calibration and Rationalization for LLMs via Multi-Agent Deliberation](https://arxiv.org/abs/2404.09127): Uses collaborative calibration among multiple LLM agents so collective deliberation adjusts both answers and confidence estimates.
- [mABC: multi-Agent Blockchain-Inspired Collaboration for root cause analysis in micro-services architecture](https://arxiv.org/abs/2404.12135): Assigns RCA specialists to microservice faults and uses blockchain-inspired voting plus bounded task steps to reduce hallucinated root-cause loops.
- [Elicitron: An LLM Agent-Based Simulation Framework for Design Requirements Elicitation](https://arxiv.org/abs/2404.16045): Generates simulated user agents that act through product-experience scenarios, exposing needs, observations, and edge cases for requirements elicitation.
- [Cooperate or Collapse: Emergence of Sustainable Cooperation in a Society of LLM Agents](https://arxiv.org/abs/2404.16698): Studies cooperation and collapse in a society of LLM agents, making repeated social interaction the mechanism for testing sustainable group behavior.
- [PLAYER*: Enhancing LLM-based Multi-Agent Communication and Interaction in Murder Mystery Games](https://arxiv.org/abs/2404.17662): Builds murder-mystery-game agents that reason through natural-language interaction under undefined state spaces and no intermediate rewards.
- [ComposerX: Multi-Agent Symbolic Music Composition with LLMs](https://arxiv.org/abs/2404.18081): Splits symbolic music composition across LLM agents for music-theory reasoning, long-range structure, and harmony-constrained generation.
- [MARE: Multi-Agents Collaboration Framework for Requirements Engineering](https://arxiv.org/abs/2405.03256): Divides requirements engineering into elicitation, modeling, verification, and specification agents that collaborate over the full RE workflow.
- [Large language models (LLMs) as agents for augmented democracy](https://arxiv.org/abs/2405.03452): Uses LLM agents to augment citizen-preference data over election policy proposals, testing whether agent simulations can predict individual and aggregate choices.
- [LLM Discussion: Enhancing the Creativity of Large Language Models via Discussion Framework and Role-Play](https://arxiv.org/abs/2405.06373): Improves creative generation through role-play discussions in which multiple LLM agents propose, critique, and refine ideas.
- [Human-Centered LLM-Agent User Interface: A Position Paper](https://arxiv.org/abs/2405.13050): Defines interface design requirements for supervising LLM agents, emphasizing visibility into plans, controllable delegation, intervention points, and user feedback loops for agentic workflows.
- [From Role-Play to Drama-Interaction: An LLM Solution](https://arxiv.org/abs/2405.14231): Defines an interactive-drama pipeline where a drama LLM coordinates plot, character, thought, diction, spectacle, and user interaction during live role-play.
- [Towards Efficient LLM Grounding for Embodied Multi-Agent Collaboration](https://arxiv.org/abs/2405.14314): Grounds embodied collaboration by connecting LLM communication with task-state representations and action plans, targeting lower-cost coordination among agents in shared physical or simulated environments.
- [SMART: Scalable Multi-agent Real-time Simulation via Next-token Prediction](https://arxiv.org/abs/2405.15677): Treats multi-agent simulation as next-token prediction, offering a scalable real-time simulator for agent populations rather than hand-stepped interaction rules.
- [LLM-Based Cooperative Agents using Information Relevance and Plan Validation](https://arxiv.org/abs/2405.16751): Proposes REVECA, where cooperative language agents filter information by relevance and proximity, then validate trajectories against collaborator-induced environment changes.
- [LLM experiments with simulation: Large Language Model Multi-Agent System for Simulation Model Parametrization in Digital Twins](https://arxiv.org/abs/2405.18092): Uses observing, reasoning, decision-making, and summarizing LLM agents to interact with digital-twin simulations and search feasible parameter settings.
- [Adaptive In-conversation Team Building for Language Model Agents](https://arxiv.org/abs/2405.19425): Introduces a Captain Agent that forms teams during a conversation, using nested group chats and reflection to select expertise step by step.
- [CharacterGPT: A Persona Reconstruction Framework for Role-Playing Agents](https://arxiv.org/abs/2405.19778): Reconstructs personas for role-playing agents.
- [Towards Hierarchical Multi-Agent Workflows for Zero-Shot Prompt Optimization](https://arxiv.org/abs/2405.20252): Uses a hierarchy of agents to generate, critique, and refine prompts for unseen tasks, making prompt optimization a reusable multi-agent workflow.
- [Scaling Large-Language-Model-based Multi-Agent Collaboration](https://arxiv.org/abs/2406.07155): Organizes agents as a directed acyclic collaboration network, testing whether adding more topologically orchestrated agents scales collective reasoning.
- [Multi-Agent Collaboration via Cross-Team Orchestration](https://arxiv.org/abs/2406.08979): Coordinates multiple agent teams rather than a single flat team, making cross-team task routing and handoff the core orchestration mechanism.
- [Improving Multi-Agent Debate with Sparse Communication Topology](https://arxiv.org/abs/2406.11776): Replaces all-to-all debate with sparse communication graphs, reducing token overhead while preserving or improving multi-agent debate quality.
- [Leveraging Large Language Model for Heterogeneous Ad Hoc Teamwork Collaboration](https://arxiv.org/abs/2406.12224): Uses an LLM to help an ad hoc robot infer teammate capabilities and choose cooperation policies when joining an unknown heterogeneous team.
- [EvoAgent: Towards Automatic Multi-Agent Generation via Evolutionary Algorithms](https://arxiv.org/abs/2406.14228): Evolves agent teams automatically, searching over agent roles and collaboration structures instead of hand-designing a fixed multi-agent roster.
- [MultiAgent Collaboration Attack: Investigating Adversarial Attacks in Large Language Model Collaborations via Debate](https://arxiv.org/abs/2406.14711): Studies collaboration attacks in debate-style LLM teams, where adversarial participants can steer shared reasoning and final decisions.
- [Crafting Customisable Characters with LLMs: A Persona-Driven Role-Playing Agent Framework](https://arxiv.org/abs/2406.17962): Injects personalized character features into role-playing agents and evaluates multi-turn persona dialogue through the SimsConv dataset.
- [BMW Agents - A Framework For Task Automation Through Multi-Agent Collaboration](https://arxiv.org/abs/2406.20041): Organizes task automation through business, management, and worker agents, separating high-level planning, coordination, and execution roles inside a collaborative multi-agent workflow.

- [Craftium: Bridging Flexibility and Efficiency for Rich 3D Single- and Multi-Agent Environments](https://arxiv.org/abs/2407.03969): Provides a customizable 3D environment platform with single-agent and multi-agent support, useful as a simulation substrate for spatial swarm experiments.
- [Controllable and Reliable Knowledge-Intensive Task-Oriented Conversational Agents with Declarative Genie Worksheets](https://arxiv.org/abs/2407.05674): Uses declarative Genie worksheets to program knowledge-intensive task dialogues, exposing conditional logic and data-source integration as controllable agent workflow components.
- [FinCon: A Synthesized LLM Multi-Agent System with Conceptual Verbal Reinforcement for Enhanced Financial Decision Making](https://arxiv.org/abs/2407.06567): Synthesizes financial decision agents and reinforces them with verbalized concepts, structuring market analysis as a multi-agent reasoning process.
