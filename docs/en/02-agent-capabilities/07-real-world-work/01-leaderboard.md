# 2.7.1 Leaderboard

- [GAIA Leaderboard](https://huggingface.co/spaces/gaia-benchmark/leaderboard): A long-running public leaderboard for general real-world assistant tasks, covering reasoning, web browsing, multimodality, and tool use; it remains an important entry point for comparing whether agents can solve real problems rather than isolated tool skills.
- [TheAgentCompany Leaderboard](https://the-agent-company.com/#/leaderboard): A public leaderboard for digital-employee tasks in a simulated software company; useful for observing end-to-end completion rates on mixed real-work tasks involving web, code, files, and coworker communication.
- [HAL / Holistic Agent Leaderboard](https://hal.cs.princeton.edu/) ([open-source harness](https://github.com/princeton-pli/hal-harness)): Reports accuracy, cost, runtime, and traces across GAIA, AssistantBench, tau-bench, Online Mind2Web, SWE-bench Verified, and other tasks; its value is that models, agent scaffolds, and evaluation cost are compared together in public.
- [GDPval Leaderboard](https://evals.openai.com/gdpval/leaderboard): A public leaderboard for economically valuable task deliverables; it focuses on rubric-driven professional output quality and puts model capability, context, and scaffolding benefits for real work into one entry point.
- [Remote Labor Index Leaderboard](https://labs.scale.com/leaderboard/rli): Continuously compares agents on automation rate and delivery quality for real remote-labor projects; it complements GDPval by emphasizing outsourced projects, economic signals, and end-to-end delivery.
- [APEX-Agents Leaderboard](https://www.mercor.com/apex/apex-agents-leaderboard/): A public leaderboard covering professional-service tasks such as investment banking, consulting, and corporate law; it treats files, tools, rubrics, and gold outputs as deliverables for real white-collar work.
- [ClawBench Leaderboard](https://claw-bench.com/): A leaderboard for write-operation tasks on real live websites, recording model, harness, trace, HTTP interception, and reward; its main value is making agent behavior auditable in real web workflows.
- [ClawMark Leaderboard](https://claw-mark.com/leaderboard): A multi-calendar-time coworker-agent workflow leaderboard, useful for tracking real-work agents that can wait, remember, and collaborate across days rather than only complete single-session tasks.
