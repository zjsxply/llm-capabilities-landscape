# 2.2.6 Skill

- [bugfix](https://skills.sh/doodledood/codex-workflow/bugfix) is suitable for focusing coding tasks on the most common defect-repair workflow, in a SWE-bench-like style.
- [OpenClaw coding-agent](https://github.com/openclaw/openclaw/tree/main/skills/coding-agent) is an integration skill for delegating larger coding work to background Codex, Claude Code, OpenCode, or Pi workers with explicit notification and monitoring rules.
- [pytest](https://skills.sh/bobmatnyc/claude-mpm-skills/pytest) is suitable for grounding "is the fix correct" in executable regression tests, and is also commonly useful in real projects beyond SWE-Bench.
- [SWE-Skills-Bench skills](https://github.com/GeniusHTX/SWE-Skills-Bench/tree/main/skills) provide a concrete library for skill-injected software-engineering evaluation, including `tdd-workflow`, `fix`, `analyze-ci`, `github-actions-templates`, `python-packaging`, `python-resilience`, `mcp-builder`, and security-review skills.
