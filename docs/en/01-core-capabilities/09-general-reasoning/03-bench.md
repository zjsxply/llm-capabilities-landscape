# 1.9.3 Bench

- [GPT-4 passes the bar exam](https://doi.org/10.1098/rsta.2023.0254): Evaluates GPT-4 on Uniform Bar Exam components and Multistate Bar Examination-style multiple choice, using human bar-score percentiles to show legal-reasoning performance rather than a new open benchmark.
- [The 2023 International Planning Competition](https://doi.org/10.1002/aaai.12169): Reports the IPC 2023 planning competition tracks and results, benchmarking automated planners on standardized planning domains, instances, and competition scoring protocols.
- [ARC (ARC-AGI-1)](https://github.com/fchollet/ARC): What it evaluates: abstract reasoning and induction through small-grid transformations and rule induction; core idea: place tiny data and strong out-of-distribution generalization at the center, forcing methods to rely on program induction/rule extraction rather than language templates.
- [BIG-Bench Hard](https://arxiv.org/abs/2210.09261) ([code](https://github.com/suzgunmirac/BIG-Bench-Hard)): What it evaluates: manually selected hard reasoning subtasks from BIG-Bench; core idea: a common chain-of-thought baseline set covering symbolic, commonsense, algorithmic, and language inference.
- [AGIEval](https://arxiv.org/abs/2304.06364) ([code](https://github.com/ruixiangcui/AGIEval)): What it evaluates: general reasoning from standardized tests and human ability tests; core idea: supplement synthetic tasks with problem types closer to human exams, covering language, mathematics, logic, and professional knowledge.
- [MuSR](https://arxiv.org/abs/2310.16049) ([code](https://github.com/Zayne-sprague/MuSR)): What it evaluates: multi-step soft reasoning, including murder mystery, object placement, and team allocation tasks; core idea: require models to maintain constraints in long prompts and progressively eliminate candidates.
- [GPQA](https://arxiv.org/abs/2311.12022) ([code](https://github.com/idavidrein/gpqa)): What it evaluates: graduate-level, search-resistant scientific QA; core idea: emphasize expert-level reasoning and resistance to data leakage, often used as a hard-problem baseline for general reasoning models.
- [LogicAsker: Evaluating and Improving the Logical Reasoning Ability of Large Language Models](https://arxiv.org/abs/2401.00757): Generates logical-reasoning questions from formal rules and asks models to answer and explain them, so failures can be tied to specific logical forms rather than broad QA accuracy.
- [Advancing Spatial Reasoning in Large Language Models: An In-Depth Evaluation and Enhancement Using the StepGame Benchmark](https://arxiv.org/abs/2401.03991): Uses StepGame's synthetic spatial-relation stories to test whether LLMs infer relative object positions across multi-hop relations, with task variants that separate spatial reasoning from prompt-format effects.
- [Prometheus-Vision: Vision-Language Model as a Judge for Fine-Grained Evaluation](https://arxiv.org/abs/2401.06591): Evaluates vision-language models as fine-grained judges, using rubric-style multimodal scoring to check whether automatic evaluators can assess image-conditioned outputs beyond coarse preference labels.
- [PUB: A Pragmatics Understanding Benchmark for Assessing LLMs’ Pragmatics Capabilities](https://arxiv.org/abs/2401.07078): Introduces a pragmatics benchmark for implicature, presupposition, reference, and discourse-context understanding, measuring whether LLMs draw conversational inferences that are not explicit in the utterance.
- [MMToM-QA: Multimodal Theory of Mind Question Answering](https://arxiv.org/abs/2401.08743): Builds multimodal Theory-of-Mind QA cases where models infer beliefs, intentions, and perspectives from both image evidence and text, making mental-state reasoning depend on cross-modal context.
- [Code Prompting Elicits Conditional Reasoning Abilities in Text+Code LLMs](https://arxiv.org/abs/2401.10065): Tests whether code-form prompts elicit conditional reasoning in text and code LLMs, comparing natural-language and code-style representations on controlled if-then reasoning problems.
- [CivRealm: A Learning and Reasoning Odyssey in Civilization for Decision-Making Agents](https://arxiv.org/abs/2401.10568): Evaluates decision-making agents in Civilization-style gameplay, where learning, planning, diplomacy, and long-horizon resource choices are measured through a turn-based simulation environment.
- [Benchmarking LLMs via Uncertainty Quantification](https://arxiv.org/abs/2401.12794): Assesses LLM answers with uncertainty-quantification scores, comparing correctness with confidence, calibration, and abstention behavior rather than only raw accuracy.
- [CMMU: A Benchmark for Chinese Multi-modal Multi-type Question Understanding and Reasoning](https://arxiv.org/abs/2401.14011): Provides Chinese multimodal questions spanning multiple task types, testing whether models can combine image understanding, Chinese language comprehension, and reasoning rather than solve translated English-style items.
- [Evaluating Gender Bias in Large Language Models via Chain-of-Thought Prompting](https://arxiv.org/abs/2401.15585): Measures gender bias in chain-of-thought outputs by comparing prompt conditions and reasoning traces, making demographic stereotype leakage visible in step-by-step explanations.
- [Can Large Language Models be Trusted for Evaluation? Scalable Meta-Evaluation of LLMs as Evaluators via Agent Debate](https://arxiv.org/abs/2401.16788): Tests whether large language models can be trusted as evaluators by using agent debate for scalable meta-evaluation.
- [Conditional and Modal Reasoning in Large Language Models](https://arxiv.org/abs/2401.17169): Probes LLM handling of conditionals and modal operators, using controlled logical forms to distinguish valid necessity, possibility, and implication judgments from surface plausibility.
- [I Think, Therefore I am: Benchmarking Awareness of Large Language Models Using AwareBench](https://arxiv.org/abs/2401.17882): Introduces AwareBench to test model self-awareness and situation awareness through questions about identity, capability, context, and interaction state instead of ordinary knowledge recall.
- [A Chain-of-Thought Is as Strong as Its Weakest Link: A Benchmark for Verifiers of Reasoning Chains](https://arxiv.org/abs/2402.00559): Benchmarks verifiers on reasoning chains by localizing weak steps in chain-of-thought traces, so evaluation targets process checking rather than final-answer agreement alone.
- [How Well Can LLMs Negotiate? NegotiationArena Platform and Analysis](https://arxiv.org/abs/2402.05863): Introduces NegotiationArena for multi-turn bargaining, measuring whether LLM agents make offers, infer opponents, and reach favorable deals under controlled negotiation settings.
- [OpenToM: A Comprehensive Benchmark for Evaluating Theory-of-Mind Reasoning Capabilities of Large Language Models](https://arxiv.org/abs/2402.06044): Evaluates Theory-of-Mind with OpenToM scenarios that vary belief states, observations, and agents, separating mental-state tracking from ordinary commonsense QA.
- [Can Graph Descriptive Order Affect Solving Graph Problems with LLMs?](https://arxiv.org/abs/2402.07140): Tests graph-problem sensitivity to textual serialization by changing node and edge description order, measuring whether LLM graph reasoning is invariant to equivalent graph presentations.
- [AQA-Bench: An Interactive Benchmark for Evaluating LLMs' Sequential Reasoning Ability](https://arxiv.org/abs/2402.09404): Uses interactive answer-query steps to evaluate sequential reasoning, scoring whether a model can request, integrate, and act on intermediate information across a multi-step problem.
- [STEER: Assessing the Economic Rationality of Large Language Models](https://arxiv.org/abs/2402.09552): Measures economic rationality with decision problems involving risk, time, social preference, and strategic choice, comparing LLM behavior against normative and behavioral-economics expectations.
- [When LLMs Meet Cunning Texts: A Fallacy Understanding Benchmark for Large Language Models](https://arxiv.org/abs/2402.11100): Introduces fallacy-understanding tasks built from deceptive or rhetorically tricky texts, evaluating whether models identify flawed reasoning rather than merely classify topic or sentiment.
- [Direct Evaluation of Chain-of-Thought in Multi-hop Reasoning with Knowledge Graphs](https://arxiv.org/abs/2402.11199): Directly scores chain-of-thought steps for multi-hop knowledge-graph reasoning, checking whether intermediate entities and relations support the final answer.
- [CofCA: A STEP-WISE Counterfactual Multi-hop QA benchmark](https://arxiv.org/abs/2402.11924): Provides step-wise counterfactual multi-hop QA, requiring models to update intermediate reasoning under changed facts instead of answering from the original context.
- [Are LLM-based Evaluators Confusing NLG Quality Criteria?](https://arxiv.org/abs/2402.12055): Evaluates whether LLM-based evaluators confuse natural-language generation quality criteria.
- [GTBench: Uncovering the Strategic Reasoning Limitations of LLMs via Game-Theoretic Evaluations](https://arxiv.org/abs/2402.12348): Uses game-theoretic settings to test strategic reasoning, including whether models anticipate other players, reason about payoffs, and choose equilibrium-consistent actions.
- [Archer: A Human-Labeled Text-to-SQL Dataset with Arithmetic, Commonsense and Hypothetical Reasoning](https://arxiv.org/abs/2402.12554): Supplies human-labeled Text-to-SQL questions requiring arithmetic, commonsense, and hypothetical reasoning, so SQL generation is evaluated on reasoning-heavy query construction rather than schema matching alone.
- [TreeEval: Benchmark-Free Evaluation of Large Language Models through Tree Planning](https://arxiv.org/abs/2402.13125): Evaluates LLMs by having them plan over generated trees, making correctness checkable through tree search while avoiding dependence on a fixed static benchmark set.
- [Making Reasoning Matter: Measuring and Improving Faithfulness of Chain-of-Thought Reasoning](https://arxiv.org/abs/2402.13950): Measures and improves chain-of-thought faithfulness, linking reasoning quality to verifiable explanations.
- [CriticBench: Benchmarking LLMs for Critique-Correct Reasoning](https://arxiv.org/abs/2402.14809): Tests critique-correct reasoning by asking models to find and repair flawed answers, measuring whether critique improves the reasoning path rather than only producing a new final answer.
- [ToMBench: Benchmarking Theory of Mind in Large Language Models](https://arxiv.org/abs/2402.15052): Evaluates Theory-of-Mind through ToMBench tasks spanning belief, intention, emotion, knowledge, and social reasoning, with controlled prompts for mental-state inference.
- [Measuring Bargaining Abilities of LLMs: A Benchmark and A Buyer-Enhancement Method](https://arxiv.org/abs/2402.15813): Evaluates bargaining ability through buyer-seller negotiation tasks, tracking deal success, surplus, concession behavior, and whether targeted buyer prompts improve negotiation outcomes.
- [Are LLMs Capable of Data-based Statistical and Causal Reasoning? Benchmarking Advanced Quantitative Reasoning with Data](https://arxiv.org/abs/2402.17644): Benchmarks quantitative reasoning over data tables and study descriptions, requiring statistical comparison, causal interpretation, and evidence-grounded conclusions rather than text-only commonsense.
- [CogBench: a large language model walks into a psychology lab](https://arxiv.org/abs/2402.18225): Adapts psychology-lab cognitive tasks for LLMs, probing memory, decision biases, learning, and social cognition with experimental-style protocols rather than single-shot QA.
- [Functional Benchmarks for Robust Evaluation of Reasoning Performance, and the Reasoning Gap](https://arxiv.org/abs/2402.19450): Proposes functional reasoning benchmarks that generate many controlled variants, exposing the reasoning gap between task templates and robust out-of-distribution performance.
- [CR-LT-KGQA: A Knowledge Graph Question Answering Dataset Requiring Commonsense Reasoning and Long-Tail Knowledge](https://arxiv.org/abs/2403.01395): Builds KGQA examples that combine long-tail entities with commonsense links, testing whether models can reason over sparse graph knowledge instead of relying on popular facts.
- [NPHardEval4V: A Dynamic Reasoning Benchmark of Multimodal Large Language Models](https://arxiv.org/abs/2403.01777): Generates multimodal tasks from NP-hard problem families, making visual reasoning difficulty controllable and reducing memorization through dynamic instance creation.
- [Can large language models reason and plan?](https://arxiv.org/abs/2403.04121): Evaluates LLM reasoning and planning on controlled planning tasks, contrasting apparent plan text with validity under formal preconditions, goals, and action effects.
- [Rethinking Generative Large Language Model Evaluation for Semantic Comprehension](https://arxiv.org/abs/2403.07872): Recasts semantic-comprehension evaluation for generative LLMs, emphasizing open-ended answer assessment and meaning preservation rather than narrow classification accuracy.
- [PuzzleVQA: Diagnosing Multimodal Reasoning Challenges of Language Models with Abstract Visual Patterns](https://arxiv.org/abs/2403.13315): Uses abstract visual-pattern puzzles for VQA, diagnosing whether models infer shape, relation, and rule patterns from images instead of depending on natural-image priors.
- [Benchmarking Chinese Commonsense Reasoning of LLMs: From Chinese-Specifics to Reasoning-Memorization Correlations](https://arxiv.org/abs/2403.14112): Evaluates Chinese commonsense reasoning with Chinese-specific items and memorization checks, separating culturally grounded reasoning from dataset recall.
- [Towards Human-AI Deliberation: Design and Evaluation of LLM-Empowered Deliberative AI for AI-Assisted Decision-Making](https://arxiv.org/abs/2403.16812): Evaluates an LLM-empowered deliberation system for AI-assisted decision making, measuring discussion quality, participant support, and decision outcomes in human-AI deliberative workflows.
- [Can Multiple-choice Questions Really Be Useful in Detecting the Abilities of LLMs?](https://arxiv.org/abs/2403.17752): Tests whether multiple-choice formats diagnose LLM ability by comparing answer-option effects, free-form alternatives, and distractor sensitivity across benchmark questions.
- [CheckEval: A reliable LLM-as-a-Judge framework for evaluating text generation using checklists](https://arxiv.org/abs/2403.18771): Introduces CheckEval, an LLM-as-judge framework that decomposes text-generation criteria into checklists so evaluation scores depend on explicit item-level checks.
- [Can Language Models Recognize Convincing Arguments?](https://arxiv.org/abs/2404.00750): Tests argument-quality recognition by asking models to judge persuasive or convincing arguments, probing rhetorical and evidential reasoning rather than factual QA.
- [Auxiliary task demands mask the capabilities of smaller language models](https://arxiv.org/abs/2404.02418): Shows that auxiliary task demands can hide smaller models' underlying competence, using simplified task variants to separate reasoning ability from formatting and instruction burdens.
- [Length-Controlled AlpacaEval: A Simple Way to Debias Automatic Evaluators](https://arxiv.org/abs/2404.04475): Adds length-controlled AlpacaEval scoring to reduce automatic evaluator preference for verbose responses, making pairwise instruction-following judgments less confounded by output length.
- [Evaluation of an LLM in Identifying Logical Fallacies: A Call for Rigor When Adopting LLMs in HCI Research](https://arxiv.org/abs/2404.05213): Studies LLM identification of logical fallacies in HCI research contexts, emphasizing rigorous validation before using model judgments as research instruments.
- [RAR-b: Reasoning as Retrieval Benchmark](https://arxiv.org/abs/2404.06347): Frames reasoning as retrieval by testing whether models can recover relevant premises and facts needed for an answer, separating retrieval failures from downstream inference failures.
- [CausalBench: A Comprehensive Benchmark for Causal Learning Capability of LLMs](https://arxiv.org/abs/2404.06349): Benchmarks causal learning in LLMs across causal discovery, effect estimation, and counterfactual reasoning tasks, emphasizing structured causal variables and graph-level judgments.
- [When Hindsight is Not 20/20: Testing Limits on Reflective Thinking in Large Language Models](https://arxiv.org/abs/2404.09129): Probes reflective thinking by giving models opportunities to reconsider earlier judgments, measuring when hindsight-style prompts correct errors or merely rationalize wrong answers.
- [Eyes Can Deceive: Benchmarking Counterfactual Reasoning Abilities of Multi-modal Large Language Models](https://arxiv.org/abs/2404.12966): Benchmarks multimodal counterfactual reasoning with image-text situations whose visual evidence conflicts with default assumptions, testing whether models update conclusions under altered conditions.
- [Evidence from counterfactual tasks supports emergent analogical reasoning in large language models](https://arxiv.org/abs/2404.13070): Uses counterfactual task variants to test analogical transfer, checking whether models map relational structure across cases rather than copy surface content.
- [A Closer Look at Classification Evaluation Metrics and a Critical Reflection of Common Evaluation Practice](https://arxiv.org/abs/2404.16958): Audits classification metrics and common evaluation practice, clarifying how accuracy, F-scores, class imbalance, and averaging choices can distort model comparisons.
- [Holmes: A Benchmark to Assess the Linguistic Competence of Language Models](https://arxiv.org/abs/2404.18923): Uses Holmes to assess linguistic competence through controlled grammatical and semantic contrasts, probing whether language models generalize beyond surface fluency.
- [Do Large Language Models Understand Conversational Implicature- A case study with a Chinese sitcom](https://arxiv.org/abs/2404.19509): Uses Chinese sitcom dialogue to test conversational implicature, requiring models to infer unstated meanings from speaker intent, context, and cultural-pragmatic cues.
- [ACORN: Aspect-wise Commonsense Reasoning Explanation Evaluation](https://arxiv.org/abs/2405.04818): Evaluates commonsense reasoning explanations aspect by aspect, scoring whether generated rationales cover the relevant commonsense relation instead of only matching the answer.
- [Initialization is Critical to Whether Transformers Fit Composite Functions by Reasoning or Memorizing](https://arxiv.org/abs/2405.05409): Uses composite-function learning experiments to distinguish transformer reasoning from memorization, showing how initialization changes whether models learn compositional rules.
- [MM-InstructEval: Zero-Shot Evaluation of (Multimodal) Large Language Models on Multimodal Reasoning Tasks](https://arxiv.org/abs/2405.07229): Evaluates zero-shot multimodal instruction following on reasoning tasks, combining image-conditioned prompts with task-specific scoring to compare MLLM reasoning behavior.
- [Elements of World Knowledge (EWOK): A cognition-inspired framework for evaluating basic world knowledge in language models](https://arxiv.org/abs/2405.09605): Evaluates basic world knowledge with EWOK, a cognition-inspired suite of minimal-pair physical and social scenarios designed to reveal commonsense reasoning failures.
- [SOK-Bench: A Situated Video Reasoning Benchmark with Aligned Open-World Knowledge](https://arxiv.org/abs/2405.09713): Couples videos with aligned open-world knowledge for situated reasoning, requiring models to combine temporal visual evidence with external commonsense facts.
- [M3CoT: A Novel Benchmark for Multi-Domain Multi-step Multi-modal Chain-of-Thought](https://arxiv.org/abs/2405.16473): Benchmarks multimodal chain-of-thought across multiple domains and reasoning steps, pairing image-text questions with rationales to test intermediate multimodal inference.
- [Efficient multi-prompt evaluation of LLMs](https://arxiv.org/abs/2405.17202): Studies efficient multi-prompt evaluation by estimating model performance from prompt samples, targeting prompt variance and evaluation cost rather than a new task domain.
- [Thai Winograd Schemas: A Benchmark for Thai Commonsense Reasoning](https://arxiv.org/abs/2405.18375): Provides Thai Winograd-style pronoun-resolution schemas, testing Thai commonsense reasoning with language-specific ambiguity rather than translated English items alone.
- [LLMs achieve adult human performance on higher-order theory of mind tasks](https://arxiv.org/abs/2405.18870): Compares LLMs with adult humans on higher-order false-belief and perspective-taking tasks, using psychology-style Theory-of-Mind protocols as the evaluation target.
- [Easy Problems That LLMs Get Wrong](https://arxiv.org/abs/2405.19616): Collects simple-looking problems where LLMs fail, using them as diagnostic probes for brittle reasoning, instruction parsing, and shortcut reliance.
- [PertEval: Unveiling Real Knowledge Capacity of LLMs with Knowledge-Invariant Perturbations](https://arxiv.org/abs/2405.19740): Applies knowledge-invariant perturbations to benchmark questions so the correct answer should remain unchanged, measuring whether model performance reflects knowledge or prompt sensitivity.
- [MARS: Benchmarking the Metaphysical Reasoning Abilities of Language Models with a Multi-task Evaluation Dataset](https://arxiv.org/abs/2406.02106): Introduces a multitask dataset for metaphysical reasoning, asking models to reason about identity, persistence, causation, and modality beyond ordinary factual knowledge.
- [The CLRS-Text Algorithmic Reasoning Language Benchmark](https://arxiv.org/abs/2406.04229): Adapts CLRS algorithmic tasks into text-form graph and program-trace questions, testing out-of-distribution and compositional algorithmic reasoning rather than recall of known puzzles.
- [OCDB: Revisiting Causal Discovery with a Comprehensive Benchmark and Evaluation Framework](https://arxiv.org/abs/2406.04598): Revisits causal discovery on real datasets with CPDAG/DAG structure metrics, causal-effect checks, and interpretability-oriented comparisons of generated causal graphs.
- [Towards a Benchmark for Causal Business Process Reasoning with LLMs](https://arxiv.org/abs/2406.05506): Defines causal business-process reasoning tasks where models infer causes and effects in process traces, bringing causal reasoning into workflow and process-mining settings.
- [Decision-Making Behavior Evaluation Framework for LLMs under Uncertain Context](https://arxiv.org/abs/2406.05972): Measures uncertain-decision behavior along risk preference, probability weighting, and loss aversion, comparing LLM choices with normative and behavioral decision-theory expectations.
- [Open-LLM-Leaderboard: From Multi-choice to Open-style Questions for LLMs Evaluation, Benchmark, and Arena](https://arxiv.org/abs/2406.07545) ([leaderboard](https://huggingface.co/spaces/open-llm-leaderboard/open_llm_leaderboard)): Documents Open LLM Leaderboard changes from multiple-choice to open-style evaluation.
- [Judging the Judges: A Systematic Investigation of Position Bias in Pairwise Comparative Assessments by LLMs](https://arxiv.org/abs/2406.07791): Systematically measures position bias in pairwise LLM-as-judge comparisons by swapping response order and quantifying preference flips across judges and tasks.
- [ConMe: Rethinking Evaluation of Compositional Reasoning for Modern VLMs](https://arxiv.org/abs/2406.08164): Tests VLM compositionality with controlled attributes, relations, and word order, probing whether models reason over visual compositions rather than exploit dataset priors.
- [A Better LLM Evaluator for Text Generation: The Impact of Prompt Output Sequencing and Optimization](https://arxiv.org/abs/2406.09972): Tests LLM-as-evaluator prompt formats by changing the order of score, reason, and instruction outputs, measuring how sequencing affects text-generation scoring consistency.
- [TEG-DB: A Comprehensive Dataset and Benchmark of Textual-Edge Graphs](https://arxiv.org/abs/2406.10310): Introduces TEG-DB, a textual-edge graph dataset collection where both nodes and edges carry natural-language descriptions for benchmarking graph analysis methods.
- [StrucText-Eval: Evaluating Large Language Model's Reasoning Ability in Structure-Rich Text](https://arxiv.org/abs/2406.10621): Evaluates reasoning over structure-rich text by asking LLMs to parse and use tables, lists, layouts, and nested document structure rather than flat passages only.
- [Exposing the Achilles' Heel: Evaluating LLMs Ability to Handle Mistakes in Mathematical Reasoning](https://arxiv.org/abs/2406.10834): Evaluates whether LLMs can identify and recover from erroneous steps in math solutions, showing that final-answer scoring can hide failures on faulty reasoning chains.
- [MDCR: A Dataset for Multi-Document Conditional Reasoning](https://arxiv.org/abs/2406.11784): Creates questions whose answers depend on combining eligibility conditions scattered across multiple documents with the query user's situation, such as scholarship rules.
- [Exploring and Benchmarking the Planning Capabilities of Large Language Models](https://arxiv.org/abs/2406.13094): Combines classical planning and natural-language planning tasks with generated difficulty levels, then probes many-shot in-context learning, fine-tuning, CoT, and out-of-distribution planning.
- [MoreHopQA: More Than Multi-hop Reasoning](https://arxiv.org/abs/2406.13397): Extends multi-hop QA evaluation to require more-than-standard-hop reasoning.
- [LLMs as models for analogical reasoning](https://arxiv.org/abs/2406.13803): Uses semantic-word, letter, and abstract-symbol analogies to test flexible relation mapping and re-representation, with distractors exposing surface-association shortcuts.
- [MR-BEN: A Comprehensive Meta-Reasoning Benchmark for Large Language Models](https://arxiv.org/abs/2406.13975): Introduces MR-BEN for meta-reasoning, testing whether models know when to reason, what strategy to use, and how to monitor reasoning rather than only solve object-level tasks.
- [African or European Swallow? Benchmarking Large Vision-Language Models for Fine-Grained Object Classification](https://arxiv.org/abs/2406.14496): Benchmarks VLM fine-grained object classification with visually similar categories, testing whether models distinguish subtle species or object attributes rather than broad labels.
- [MMLU-SR: A Benchmark for Stress-Testing Reasoning Capability of Large Language Models](https://arxiv.org/abs/2406.15468): Replaces key MMLU terms with locally defined dummy terms so models must apply the supplied definitions instead of relying on familiar lexical cues.
- [CaT-Bench: Benchmarking Language Model Understanding of Causal and Temporal Dependencies in Plans](https://arxiv.org/abs/2406.15823): Introduces CaT-Bench step-order prediction over recipe plans, scoring whether models infer necessary before-or-after relations from causal and temporal dependencies.
- [Can LLM Graph Reasoning Generalize beyond Pattern Memorization?](https://arxiv.org/abs/2406.15992): Tests graph-reasoning generalization beyond memorized patterns by varying graph structures and problem instances, checking whether LLMs solve graph tasks compositionally.
- [Chain-of-Probe: Examing the Necessity and Accuracy of CoT Step-by-Step](https://arxiv.org/abs/2406.16144): Probes each chain-of-thought step for necessity and correctness, targeting early-answering behavior where the model may know the answer before generating its rationale.
- [Evaluating the Ability of Large Language Models to Reason about Cardinal Directions](https://arxiv.org/abs/2406.16528): Separates cardinal-direction world-knowledge recall from templated spatial reasoning, varying maps, locomotion, and persons to reveal when models compute directions.
- [Multi-LogiEval: Towards Evaluating Multi-Step Logical Reasoning Ability of Large Language Models](https://arxiv.org/abs/2406.17169): Evaluates multi-step logical reasoning with Multi-LogiEval, using structured logical problems that require chaining premises across several inference steps.
- [LLMs instead of Human Judges? A Large Scale Empirical Study across 20 NLP Evaluation Tasks](https://arxiv.org/abs/2406.18403): Runs LLM-as-judge experiments across 20 NLP evaluation tasks, measuring agreement, consistency, and task sensitivity when LLM judges replace human annotators.
- [LiveBench](https://arxiv.org/abs/2406.19314) ([leaderboard](https://livebench.ai/); [code](https://github.com/LiveBench/LiveBench)): What it evaluates: continuously updated tasks including reasoning, mathematics, coding, language, and data analysis; core idea: reduce contamination through temporal updates and automatic grading, making it suitable for recent capability tracking.
- [GraphArena: Benchmarking Large Language Models on Graph Computational Problems](https://arxiv.org/abs/2407.00379): Benchmarks LLMs on graph computational problems.
- [FRoG: Evaluating Fuzzy Reasoning of Generalized Quantifiers in Large Language Models](https://arxiv.org/abs/2407.01046): Evaluates fuzzy reasoning over generalized quantifiers, testing whether LLMs handle vague quantity terms and graded truth conditions rather than crisp logical operators only.
- [Compare without Despair: Reliable Preference Evaluation with Generation Separability](https://arxiv.org/abs/2407.01878): Proposes generation separability for reliable preference evaluation, measuring whether systems can distinguish genuinely better outputs from hard-to-separate comparisons.
- [Is Your Large Language Model Knowledgeable or a Choices-Only Cheater?](https://arxiv.org/abs/2407.01992): Builds an 820-question contrast set from UnifiedQA commonsense datasets to test whether MCQA performance comes from answer-choice shortcuts or question knowledge.
- [GraCoRe: Benchmarking Graph Comprehension and Complex Reasoning in Large Language Models](https://arxiv.org/abs/2407.02936): Benchmarks graph comprehension and complex reasoning across graph types and task families, separating basic graph reading from multi-step structural inference.
- [Planetarium: A Rigorous Benchmark for Translating Text to Structured Planning Languages](https://arxiv.org/abs/2407.03321): Asks models to translate natural-language planning problems into formal planning languages, using planner-based checks to make semantic planning correctness verifiable.
- [LogicVista](https://arxiv.org/abs/2407.04973) ([code](https://github.com/Yijia-Xiao/LogicVista)): What it evaluates: visual logical reasoning, closer to "solving logic problems/puzzles from images"; core idea: ground logical constraints in visible structures through visual puzzles, reducing shortcuts in pure-text reasoning.

- [Visual Riddles: a Commonsense and World Knowledge Challenge for Large Vision and Language Models](https://arxiv.org/abs/2407.19474): Uses images to disambiguate commonsense riddles that are underspecified in text, testing whether LVLMs integrate visual context with world knowledge.
- [CLR-Fact: Evaluating the Complex Logical Reasoning Capability of Large Language Models over Factual Knowledge](https://arxiv.org/abs/2407.20564): Evaluates complex logical reasoning over factual knowledge with CLR-Fact, requiring models to combine facts and logical constraints instead of retrieving isolated statements.
- [DebateQA: Evaluating Question Answering on Debatable Knowledge](https://arxiv.org/abs/2408.01419): Builds QA over debatable knowledge where several defensible answers may exist, stressing evidence-sensitive responses rather than fixed single-label factual QA.
- [Exploring Reasoning Biases in Large Language Models Through Syllogism: Insights from the NeuBAROCO Dataset](https://arxiv.org/abs/2408.04403): Uses English and Japanese syllogisms to compare logical accuracy with human-like belief-bias patterns under congruent and incongruent premises.
- [SPARK: Multi-Vision Sensor Perception and Reasoning Benchmark for Large-scale Vision-Language Models](https://arxiv.org/abs/2408.12114): Benchmarks large VLMs on multi-sensor perception and reasoning, combining visual evidence from different sensor types to test spatial and scene-level inference.
- [Zero-Shot Visual Reasoning by Vision-Language Models: Benchmarking and Analysis](https://arxiv.org/abs/2409.00106): Analyzes zero-shot visual reasoning in VLMs through visual task families that require relation, attribute, and rule inference without task-specific training.
- [MMLU-Pro+: Evaluating Higher-Order Reasoning and Shortcut Learning in LLMs](https://arxiv.org/abs/2409.02257): Extends MMLU-Pro with multi-correct-answer questions and metrics such as shortcut selection ratio and correct pair identification ratio to expose shortcut learning.
