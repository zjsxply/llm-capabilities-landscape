# 3.2.5 Agent Harness

- [AutoQuant: An Auditable Expert-System Framework for Execution-Constrained Auto-Tuning in Cryptocurrency Perpetual Futures](https://arxiv.org/abs/2512.22476): AutoQuant combines explicit execution and cost rules with Bayesian search, two-stage screening, deterministic audit artifacts, and replay checks for configuration selection in perpetual-futures backtests. Its experiments show that fee-only or zero-cost runs inflate apparent performance and that the auditable pipeline more often exposes lower-drawdown alternatives under strict semantics, making it a reusable validation harness for quantitative research.
- [CiteScreener: A Pipeline for Citation Verification in Digital Libraries with Datasets](https://doi.org/10.1109/jcdl67857.2025.00027): CiteScreener turns citation checking into a runnable pipeline: extract the citation context, retrieve the cited work, compare text overlap, and combine language-model judgments to flag irrelevant citations. The paper releases two evaluation datasets, benchmarks the component methods, and validates the pipeline on real papers, making citation integrity checking an executable research workflow.
- [Prompt-guided LLM agent for end-to-end ontology learning](https://doi.org/10.31649/vitce/2.2025.35): This agent turns raw text into RDF/OWL through schema discovery, instance extraction, constraint-based self-repair, and ontology alignment, looping over schema and instance fixes whenever domain-range validation fails. On MINE it reaches 67.5% fact recall with LLaMA-3.3-70B versus 66.07% for KGGen, and it populates bilingual scholarly corpora with hundreds of entities, showing an end-to-end, verifiable research-knowledge curation loop.
- [BACON.5: The Discovery of Conservation Laws](https://www.ijcai.org/Proceedings/81-1/Papers/025.pdf): Given variables and admissible values, BACON.5 varies one factor while holding others fixed, collects observations, detects trends and constants, forms reusable hypotheses, and uses analogy to redirect later experiments; the same loop rediscovers laws in optics, mechanics, thermodynamics, electricity, and planetary motion.
- [ReviewRobot: Explainable Paper Review Generation based on Knowledge Synthesis](https://arxiv.org/abs/2010.06119): ReviewRobot builds an explainable paper-review pipeline by extracting knowledge graphs from the target paper, its cited work, and a background corpus, then comparing them to predict review scores and evidence. Templates turn that structured evidence into comments; experiments report 71.4%–100% score accuracy and 41.7%–70.5% valid, constructive comments judged by domain experts.
- [D2S: Document-to-Slide Generation Via Query-Based Text Summarization](https://arxiv.org/abs/2105.03664): D2S retrieves text, figures, and tables using slide titles, then turns the retrieved context into bullets with long-form question answering; SciDuet supplies paper-slide pairs for this two-stage task.
- [Bursting Scientific Filter Bubbles: Boosting Innovation via Novel Author Discovery](https://arxiv.org/abs/2108.05669): Bridger represents researchers with paper-derived facets and inferred personas, then balances author similarity against contrast so a discovery tool can surface unfamiliar scholars who may open new research directions.
- [PosterBot: A System for Generating Posters of Scientific Papers with Neural Models](https://doi.org/10.1609/aaai.v36i11.21738): PosterBot is a three-stage paper-to-poster system: it selects important paper sections, uses neural models to turn selected text and graphics into panels, and composes the panels into a complete poster with templates.
- [The 'Problematic Paper Screener' automatically selects suspect publications for post-publication (re)assessment](https://arxiv.org/abs/2210.04895): Implements an online post-publication screening loop that combines automatic detection with human assessment to flag suspect published papers and curate the scholarly record.
- [Supporting Qualitative Analysis with Large Language Models: Combining Codebook with GPT-3 for Deductive Coding](https://arxiv.org/abs/2304.10548): Combines expert-authored codebooks with prompted GPT-3 to perform deductive qualitative coding without task-specific training, achieving fair-to-substantial agreement with expert labels in a curiosity-question case study.
- [SciMON](https://arxiv.org/abs/2305.14259) ([open-source code and resources](https://github.com/EagleW/CLBD)): A literature-grounded scientific-idea generation framework that retrieves inspiration papers and iteratively revises proposed ideas against prior work to optimize novelty, making research ideation an explicit search-and-comparison loop rather than one-shot brainstorming.
- [LLM-Assisted Content Analysis: Using Large Language Models to Support Deductive Coding](https://arxiv.org/abs/2306.14924): LACA structures deductive content analysis around LLM coding, prompt refinement, code-level guessing diagnostics, and explicit decisions about when to retain human coders; across four public datasets, GPT-3.5 often reached inter-coder agreement comparable to people.
- [Large Language Models for Automated Open-domain Scientific Hypotheses Discovery](https://arxiv.org/abs/2309.02726): Inducing social science hypotheses from open-domain raw corpus observations is different from hypothesis generation given labeled samples. It extends data insights to unstructured, open-domain observations.
- [CoQuest](https://arxiv.org/abs/2310.06155) ([open-source code](https://github.com/yiren-liu/coquest)) is an LLM-based research-question co-creation system; it compares breadth-first and depth-first interaction designs for helping researchers frame candidate questions while keeping human control over ideation.
- [Can Large Language Models Serve as Data Analysts? A Multi-Agent Assisted Approach for Qualitative Data Analysis](https://arxiv.org/abs/2402.01386): Uses multiple agents to support qualitative data analysis, focusing on how LLMs help code, compare, and interpret qualitative evidence under analyst oversight.
- [Large Language Model Agent for Hyper-Parameter Optimization](https://arxiv.org/abs/2402.01881): Turns hyper-parameter optimization into an LLM-agent loop that proposes configurations, reads optimization feedback, and steers subsequent search.
- [ReviewFlow](https://arxiv.org/abs/2402.03530): Scaffolds novice academic reviewers with structured review stages and guidance, turning peer review into an interactive workflow rather than a one-shot review-generation prompt.
- [Large Language Models to Enhance Bayesian Optimization](https://arxiv.org/abs/2402.03921): Uses LLMs to enhance Bayesian optimization loops, a reusable research-automation harness pattern.
- [DataDreamer: A Tool for Synthetic Data Generation and Reproducible LLM Workflows](https://arxiv.org/abs/2402.10379): DataDreamer is a Python library that makes LLM-in-the-loop research pipelines reproducible across synthetic-data generation, evaluation, fine-tuning, and distillation by standardizing workflow steps and recording their artifacts.
- [MatPlotAgent: Method and Evaluation for LLM-Based Agentic Scientific Data Visualization](https://arxiv.org/abs/2402.11453): Automates scientific plotting with an agent that interprets visualization intents, writes code, and iteratively repairs plots against evaluation feedback.
- [DS-Agent: Automated Data Science by Empowering Large Language Models with Case-Based Reasoning](https://arxiv.org/abs/2402.17453): Uses case-based reasoning to guide data-science agents through analysis planning, code generation, execution, and iterative correction.
- [A Sentiment Consolidation Framework for Meta-Review Generation](https://arxiv.org/abs/2402.18005):The framework models meta-review writing as three layers of sentiment consolidation and turns them into prompting strategies and evaluation metrics; structured prompts produce better meta-reviews than simple instructions.
- [Data Interpreter: An LLM Agent For Data Science](https://arxiv.org/abs/2402.18679): Builds a data-science LLM agent for interpreting and executing analysis workflows.
- [Acceleron](https://arxiv.org/abs/2403.04382): Let colleagues and mentor agents interactively help researchers form comprehensive proposals, verify motivations, identify gaps in the literature, and suggest feasible methods through aspect-based retrieval.
- [OverleafCopilot: Empowering Academic Writing in Overleaf with Large Language Models](https://arxiv.org/abs/2403.09733):OverleafCopilot integrates LLM assistance into Overleaf through a browser extension, while PromptGenius supports prompt sharing and an agent command system lets researchers assemble customized writing agents.
- [Using Generative Text Models to Create Qualitative Codebooks for Student Evaluations of Teaching](https://arxiv.org/abs/2403.11984): On 5,000 student evaluations, the method combines extraction, embeddings, clustering, and LLM summarization to induce a qualitative codebook without a hand-written scheme upfront.
- [InsightLens](https://arxiv.org/abs/2404.01644): Adds interactive insight management and navigation to LLM-powered data analysis, helping analysts inspect, organize, and refine generated findings.
- [Hypothesis Generation with Large Language Models](https://arxiv.org/abs/2404.04326): Formalizes data-conditioned scientific hypothesis generation, asking LLMs to infer plausible explanatory hypotheses from labeled examples and evaluating whether generated hypotheses are novel and useful.
- [ResearchAgent](https://arxiv.org/abs/2404.07738): Iteratively generates research ideas over scientific literature, using retrieved papers and feedback loops to refine candidate directions rather than producing one-shot suggestions.
- [Automated Social Science: Language Models as Scientist and Subjects](https://arxiv.org/abs/2404.11794): Treats language models as both simulated social scientists and experimental subjects, using automated study design, participant simulation, and analysis loops to test whether social-science workflows can be delegated to LLM agents.
- [Cocoon: Semantic Table Profiling Using Large Language Models](https://arxiv.org/abs/2404.12552): Adds Semantic Context, Semantic Profile, and Semantic Review stages to statistical table profiling, using LLM reasoning to judge whether missing, extreme, or unusual values are errors or semantically valid variations; user studies validate the distinction on real datasets.
- [In-Context Symbolic Regression: Leveraging Large Language Models for Function Discovery](https://arxiv.org/abs/2404.19094): In-Context Symbolic Regression uses an LLM to propose and iteratively repair equation forms while an external optimizer fits coefficients, separating semantic hypothesis generation from numerical calibration.
- [ChatGPTest: Opportunities and Cautionary Tales of Utilizing AI for Questionnaire Pretesting](https://arxiv.org/abs/2405.06329): Uses two applications to illustrate GPT feedback as an additional early questionnaire-pretesting stage before human pretesting, potentially reducing later iterations; researchers must interpret and decide whether to implement the model's suggestions.
- [LLM and Simulation as Bilevel Optimizers: A New Paradigm to Advance Physical Scientific Discovery](https://arxiv.org/abs/2405.09783): Scientific Generative Agent uses an LLM to propose discrete structures such as equations or molecules while differentiable simulations optimise continuous parameters and return observations for the next hypothesis revision.
- [Eliciting Informative Text Evaluations with Large Language Models](https://arxiv.org/abs/2405.15077):GPPM and GSPPM extend peer prediction from scalar reports to textual feedback by using an LLM to predict a peer’s report; theory gives approximate truth-telling guarantees, while Yelp and ICLR experiments show quality discrimination and stronger penalties for generated reviews with GSPPM.
- [Interesting Scientific Idea Generation using Knowledge Graphs and LLMs: Evaluations with 100 Research Group Leaders](https://arxiv.org/abs/2405.17044): Introduces SciMuse, which combines a 58-million-paper knowledge graph with LLM generation and evaluates the resulting cross-disciplinary ideas with 100 research group leaders.
- [Peer Review as A Multi-Turn and Long-Context Dialogue with Role-Based Interactions](https://arxiv.org/abs/2406.05688): Models peer review as a long-context dialogue among explicit roles, making review, response, and discussion turns inspectable workflow state rather than a single generated verdict.
- [AgentReview: Exploring Peer Review Dynamics with LLM Agents](https://arxiv.org/abs/2406.12708): AgentReview simulates peer review with LLM agents while varying otherwise latent reviewer factors, enabling privacy-preserving causal analysis of review dynamics and attributing a 37.1% decision variation to reviewer bias.
- [Step-Back Profiling: Distilling User History for Personalized Scientific Writing](https://arxiv.org/abs/2406.14275): Step-Back Profiling compresses a scientific-writing team's interaction history into preference and trait profiles; its PSW dataset tests personalised multi-author paper writing and shows gains on this and general personalization tasks.
- [Improving Steering and Verification in AI-Assisted Data Analysis with Interactive Task Decomposition](https://arxiv.org/abs/2407.02651): Compares Stepwise editable subgoals against Phasewise assumption-plan-code phases, showing in an 18-person study that decomposition improves control, correction, and verification in AI-assisted data analysis.
- [A Deixis-Centered Approach for Documenting Remote Synchronous Communication Around Data Visualizations](https://arxiv.org/abs/2408.04041): Captures cursor gestures together with meeting audio, uses an LLM to align spoken references with deictic actions, and compiles both into interactive documents; a user study finds the automated record preferable to video, transcripts, and manual notes.
- [The AI Scientist](https://arxiv.org/abs/2408.06292) ([open-source code](https://github.com/SakanaAI/AI-Scientist)) is the earlier open-source milestone for automated ML research, covering idea generation, code, experiments, visualization, paper writing, and automated review; keep it distinct from AI Scientist v2.
- [MLR-Copilot: Autonomous Machine Learning Research based on Large Language Models Agents](https://arxiv.org/abs/2408.14033): Organizes autonomous machine-learning research around agent-driven idea proposal, experiment implementation, result analysis, and iterative improvement.
- [Employing artificial intelligence to steer exascale workflows with colmena](https://arxiv.org/abs/2408.14434): Colmena lets cooperative agents react to task events while steering exascale science workflows, combining adaptive scheduling, a data fabric, and expensive-operation caching across chemistry, biophysics, and materials science.
- [Using Large Language Models to Create AI Personas for Replication and Prediction of Media Effects: An Empirical Test of 133 Published Experimental Research Findings](https://arxiv.org/abs/2408.16073): The study prompts 19,447 LLM personas using each experiment's measures, stimuli, and sampling specification, then regenerates datasets and analyses for 133 published findings to quantify both replication and changes under new samples or stimuli.
- [SciAgents: Automating scientific discovery through multi-agent intelligent graph reasoning](https://arxiv.org/abs/2409.05556): Uses multiple agents over scientific knowledge graphs to reason about literature and graph structure, connecting and evaluating discovery leads rather than only retrieving papers.
- [PersonaFlow: Designing LLM-Simulated Expert Perspectives for Enhanced Research Ideation](https://arxiv.org/abs/2409.12538): PersonaFlow supplies configurable LLM-simulated domain experts during interdisciplinary ideation; user studies report more relevant and creative directions, greater critical thinking and agency, without added cognitive load.
- [Scideator](https://arxiv.org/abs/2409.14634) is a human-LLM scientific ideation system grounded in research-paper facet recombination; it extracts and recombines purpose, mechanism, and evaluation facets so researchers can explore and screen candidate ideas with literature context.
- [PeerArg: Argumentative Peer Review with LLMs](https://arxiv.org/abs/2409.16813):PeerArg converts a set of paper reviews into an acceptance prediction through an LLM-plus-knowledge-representation pipeline intended to expose review arguments and decision structure. On three datasets, its best variant outperforms a few-shot end-to-end LLM, directly addressing interpretability and trust in scholarly review assistance.
- [SciDoc2Diagrammer-MAF: Towards Generation of Scientific Diagrams from Documents guided by Multi-Aspect Feedback Refinement](https://arxiv.org/abs/2409.19242): Generates scientific diagrams from documents and iteratively refines content, structure, and readability with multi-aspect feedback.
- [Thematic analysis with open-source generative AI and machine learning: a new method for inductive qualitative codebook development](https://arxiv.org/abs/2410.03721):GATOS combines open-source machine learning, NLP, and generative models to approximate stages of thematic analysis and inductively construct qualitative codebooks. Three case studies show that it recovers themes from the source datasets, while the paper reports the methodological tradeoffs for scalable social-science analysis.
- [IdeaSynth](https://arxiv.org/abs/2410.04025) is a research-idea development system that uses literature-grounded feedback to evolve and compose problem, solution, evaluation, and contribution facets, making problem framing and contribution positioning explicit in the ideation loop.
- [On the Rigour of Scientific Writing: Criteria, Analysis, and Insights](https://arxiv.org/abs/2410.04981): Derives scientific-rigour criteria bottom-up by extracting keywords, generating definitions, and selecting salient criteria; the framework adapts across fields and is tested on ICLR and ACL papers.
- [FAIR GPT: A virtual consultant for research data management in ChatGPT](https://arxiv.org/abs/2410.07108): FAIR GPT combines ChatGPT guidance with APIs for FAIRness assessment, controlled-vocabulary retrieval, and repository recommendation. It also helps create data and software management plans, README files, codebooks, and license choices, grounding its guidance to reduce hallucination.
- [HLM-Cite](https://arxiv.org/abs/2410.09112): HLM-Cite retrieves likely core references from up to 100,000 candidates with a curriculum-tuned embedder, then uses an LLM workflow to distinguish substantive scientific dependencies from superficial citations across 19 fields.
- [Many Heads Are Better Than One / VirSci](https://arxiv.org/abs/2410.09403) ([open-source code](https://github.com/open-sciencelab/Virtual-Scientists)): Builds a multi-agent scientific collaboration ecosystem where role-playing scientist agents organize teams, discuss across and within teams, and generate, evaluate, and refine research ideas against real scientific data.
- [Zero-shot Scientific Claim Verification Using LLMs and Citation Text](https://doi.org/10.18653/v1/2024.sdp-1.25):SCitance pairs citation sentences with LLM-generated negations, evidence documents, and veracity labels, enabling zero-shot scientific-claim verification and bringing GPT-4 prompting within one F1 point of prior manually supervised models.
- [ChatVis: Automating Scientific Visualization with a Large Language Model](https://arxiv.org/abs/2410.11863): Turns natural-language analysis requests into Python visualization scripts, feeding execution errors back to the LLM until the program runs; this iterative repair succeeds on five canonical scientific-visualization scenarios where one-shot scripts fail.
- [Toward Human-Aligned LLM Reviews for Scientific Papers](https://doi.org/10.1109/escience65000.2025.00072): Tests a prompting strategy for LLM paper reviewing on ICLR 2025 submissions, reporting lower score inflation and review scores closer to the human-review median than a direct ChatGPT-4 baseline.
- [Chain of Ideas / CoI](https://arxiv.org/abs/2410.13185): Organizes research ideation around literature-evolution chains. Core idea: retrieve and order related papers as a progressive idea chain so the agent can infer domain trajectories before proposing candidate ideas and experimental designs, then evaluate them with Idea Arena against human-researcher preferences.
- [Nova](https://arxiv.org/abs/2410.14255): Uses iterative planning and search to increase novelty and diversity in LLM-generated research ideas. Core idea: repeatedly plan retrieval of external knowledge, enrich the idea context, and regenerate candidates so idea quality improves through search rather than single-pass prompting.
- [Data Cleaning Using Large Language Models](https://arxiv.org/abs/2410.15547): Cocoon combines statistical error detection and correction with LLM semantic understanding, decomposing complex data cleaning into manageable steps that mimic human workflows; experiments on standard benchmarks show that it outperforms prior data-cleaning systems.
- [Literature Meets Data](https://arxiv.org/abs/2410.17309): Using literature theory and specific data sets together for hypothesis generation is different from pure data insights. It requires alternatives to both explain the data pattern and be supported by the existing theoretical context.
- [AutoKaggle](https://arxiv.org/abs/2410.20424): Coordinates specialized agents for autonomous data-science competitions, covering task understanding, feature engineering, modeling, validation, and submission repair.
- [SciPIP](https://arxiv.org/abs/2410.23166): Proposes scientific paper ideas with full-text-aware literature retrieval. Core idea: move beyond keyword search and paper metadata by retrieving semantically relevant literature and using full-paper insights to ground problem, method, and contribution generation.
- [Improving Scientific Hypothesis Generation with Knowledge Grounded Large Language Models](https://arxiv.org/abs/2411.02382): Grounds LLM hypothesis generation in retrieved scientific knowledge so proposed hypotheses are tied to prior evidence instead of unconstrained text generation.
- [Kolb-Based Experiential Learning for Generalist Agents with Human-Level Kaggle Data Science Performance](https://arxiv.org/abs/2411.03562):Agent K implements a Kolb learning cycle with Vygotsky-inspired scaffolding, separating extrinsic interaction from intrinsic reflection before open-ended generalization; on 81 Kaggle tasks it reaches 1694 Elo-MMR and reports multiple medal-level outcomes.
- [Toward better pragmatic tagging of peer review: Enhancing benchmark datasets via human-in-the-loop multi-agent collaboration](https://doi.org/10.1016/j.ipm.2026.104704): Improves peer-review pragmatic-tagging data through a human-in-the-loop multi-agent annotation workflow, targeting labels for review functions rather than generic review-quality scoring.
- [BudgetMLAgent](https://arxiv.org/abs/2411.07464) (open-source code: not released) uses multi-agent collaboration, retrieval reuse, and LLM cascades for low-cost research-task automation on MLAgentBench, subject to the paper.
- [AIGS: Generating Science from AI-Powered Automated Falsification](https://arxiv.org/abs/2411.11910): Baby-AIGS assigns research-process roles to multiple agents and adds an explicit FalsificationAgent that identifies and verifies candidate discoveries across three tasks.
- [SlideSpawn](https://arxiv.org/abs/2411.17719): Input the research paper PDF, first convert it to XML containing structural information, and then output a presentation with chapter abstracts, cluster titles, text sentences and associated charts.
- [Simulating Tabular Datasets through LLMs to Rapidly Explore Hypotheses about Real-World Entities](https://arxiv.org/abs/2411.18071):The paper uses LLMs to estimate tabular properties of concrete entities, suggest variables that operationalize qualitative hypotheses, and run standard analyses such as regression. Experiments across people, companies, books, animals, and countries show how this human-machine loop can rapidly prototype research questions, while also exposing the need to validate LLM-derived measurements.
- [Exploring Multi-Modal Data with Tool-Augmented LLM Agents for Precise Causal Discovery](https://arxiv.org/abs/2412.13667):MATMCD assigns multimodal-data retrieval and processing to a Data Augmentation agent and knowledge-driven causal reasoning to a Causal Constraint agent. Across seven datasets, the cooperating tool-augmented agents improve multimodality-enhanced causal discovery, providing a concrete multi-agent scientific-discovery workflow.
- [LLMs can realize combinatorial creativity](https://arxiv.org/abs/2412.14141): Turns scientific idea generation into a theory-grounded recombination workflow. Core idea: retrieve cross-domain knowledge at multiple abstraction levels, then structure concept recombination so generated research ideas can be novel and useful rather than only adjacent to existing papers.
- [ResearchTown](https://arxiv.org/abs/2412.17767): Simulates collaboration, writing, and review activities in a research community and generates interdisciplinary research ideas; it expands the evaluation environment to a community simulation rather than a fixed number of reviewers.
- [Dolphin](https://arxiv.org/abs/2501.03916) ([project page](https://alpha-innovator.github.io/Dolphin-project-page); open-source code: no stable public repository found) is an early closed-loop auto-research framework that connects feedback-conditioned idea generation, code-template implementation/debugging, result analysis, and the next research round.
- [Agent Laboratory](https://arxiv.org/abs/2501.04227) ([open-source code](https://github.com/SamuelSchmidgall/AgentLaboratory); [project page](https://agentlaboratory.github.io/)) is an end-to-end research-assistant workflow that starts from a human idea and coordinates literature review, experimentation, and report writing with human feedback checkpoints.
- [Language-Based Bayesian Optimization Research Assistant (BORA)](https://arxiv.org/abs/2501.16224): Blends Bayesian optimization with LLM-derived domain suggestions and progress commentary, using language context to steer high-dimensional experimental searches on synthetic and real optimization tasks.
- [PlotGen: Multi-Agent LLM-based Scientific Data Visualization via Multimodal Feedback](https://arxiv.org/abs/2502.00988): Orchestrates planning, code-generation, visual-feedback, and revision agents to produce scientific data visualizations from user requests.
- [nvAgent: Automated Data Visualization from Natural Language via Collaborative Agent Workflow](https://arxiv.org/abs/2502.05036): A collaborative-agent workflow for automated data visualization. Core idea: decompose natural-language visualization requests into analysis, chart construction, and refinement steps.
- [Accelerating Scientific Research Through a Multi-LLM Framework](https://arxiv.org/abs/2502.07960): Introduces ARIA, a four-agent multi-LLM assistant that searches, retrieves, filters, and synthesizes hundreds of papers into actionable experimental procedures, demonstrated on dropwise-condensation research with human oversight kept in the loop.
- [Automated Hypothesis Validation with Agentic Sequential Falsifications](https://arxiv.org/abs/2502.09858): An agentic sequential-falsification framework for hypothesis validation; core idea: actively design checks that could falsify a claim rather than only collecting supporting evidence.
- [SCALE: Towards Collaborative Content Analysis in Social Science with Large Language Model Agents and Human Intervention](https://arxiv.org/abs/2502.10937): Uses LLM agents and human intervention for collaborative social-science content analysis.
- [AIDE](https://arxiv.org/abs/2502.13138) ([open-source code](https://github.com/WecoAI/aideml)) represents the iterative code-experiment line for research/data-science agents and is one of the central open-source ML engineering agents in the official initial MLE-bench evaluation; its design focus is experiment-tree iteration via `propose experiment -> edit/run code -> inspect metric/log -> refine`, rather than one-shot modeling-script generation.
- [Curie](https://arxiv.org/abs/2502.16069): A rigorous automated-experimentation harness for scientific agents. Core idea: add intra-agent rigor, inter-agent control, and experiment knowledge modules so agents can run more reliable and interpretable scientific experiments.
- [IGDA: Interactive Graph Discovery through Large Language Model Agents](https://arxiv.org/abs/2502.17189): Uses LLM agents for interactive graph discovery. Core idea: combine semantic metadata, trial feedback, and agentic exploration to infer variable relationships.
- [IMPROVE: Iterative Model Pipeline Refinement and Optimization Leveraging LLM Experts](https://arxiv.org/abs/2502.18530): Uses LLM expert roles to iteratively refine ML pipelines, making model selection, preprocessing, evaluation feedback, and pipeline optimization a multi-step research workflow rather than a one-shot code generation task.
- [AI co-scientist](https://arxiv.org/abs/2502.18864) (open-source code: not released): Google Research's Gemini 2.0 multi-agent scientific hypothesis-generation system, centered on an asynchronous hypothesis tournament of `generate -> debate -> evolve`; it reports experimentally validated clues in drug repurposing, target discovery, and bacterial evolution mechanisms.
- [RevTogether: Supporting Science Story Revision with Multiple AI Agents](https://arxiv.org/abs/2503.01608): Orchestrates human-like GPT-4o agents that annotate and suggest revisions for science stories, including affective feedback and multiple user-agency levels for transparent science-communication editing.
- [LLM-Feynman: Leveraging Large Language Models for Universal Scientific Formula and Theory Discovery](https://arxiv.org/abs/2503.06512): A scientific-discovery harness for formula and theory induction. Core idea: combine LLM-guided hypothesis generation with systematic optimization to derive interpretable formulas.
- [DatawiseAgent: A Notebook-Centric LLM Agent Framework for Adaptive and Robust Data Science Automation](https://arxiv.org/abs/2503.07044): DatawiseAgent is a notebook-centric LLM agent framework for adaptive and robust data science automation.
- [Automating Psychological Hypothesis Generation with AI: When Large Language Models Meet Causal Graph](https://www.nature.com/articles/s41599-024-03407-5): Make potential relationship predictions on a causal knowledge graph and compare hypotheses generated with PhD students and only large language models; it emphasizes whether alternative hypotheses correspond to explainable causal edges on the graph, rather than just looking at whether the text is new.
- [ReviewAgents](https://arxiv.org/abs/2503.08506): Coordinates multiple reviewer roles and LLMs through the human-review stages of summary, related-work comparison, strengths, weaknesses, and recommendation; agents trained with 142,000 Review-CoT comments and relevant-paper-aware supervision narrow the gap to human reviews on ReviewBench.
- [Graph of AI Ideas / GoAI](https://arxiv.org/abs/2503.08549): Construct an idea graph along the citation graph expansion, and then let the large language model generate and evaluate research directions from the graph structure; its subtle difference is to expand the domain context as a path on the graph, rather than treating the document collection as a flat context.
- [Generative Modeling for Mathematical Discovery](https://arxiv.org/abs/2503.11061): This practical FunSearch implementation couples an interchangeable third-party LLM with a genetic search loop, lets mathematicians adapt a small Python segment for a new problem, and is benchmarked across three combinatorial and number-theoretic problems where learned principles can transfer beyond the training problem.
- [FutureGen](https://arxiv.org/abs/2503.16561): Digging out follow-up directions from the limitations of the paper and future work. Different from the evolutionary chain of CoI, it relies more on the unsolved problems left by the author himself as the boundary of novelty.
- [AgentRxiv](https://arxiv.org/abs/2503.18102) ([open-source code](https://github.com/SamuelSchmidgall/AgentLaboratory); [project page](https://agentrxiv.github.io/)) adds shared research memory to autonomous research labs by letting agents upload, retrieve, and build on prior agent-generated reports, making it a close external analogue of ARIS research-wiki memory.
- [SCI-IDEA: Context-Aware Scientific Ideation Using Token and Sentence Embeddings](https://arxiv.org/abs/2503.19257): Builds a context-aware scientific-ideation harness around paper facets and researcher profiles. Core idea: extract objective, methodology, evaluation, and future-work facets from prior papers, compress a researcher profile, and use token-level embedding novelty and surprise signals to surface "Aha" moments for iterative idea generation.
- [MC-NEST](https://arxiv.org/abs/2503.19309): A scientific hypothesis-generation harness using Monte Carlo tree search and Nash-equilibrium self-refinement. Core idea: iterate hypothesis proposal, exploration, diversity control, and self-validation so research ideation becomes a search process rather than one-shot brainstorming.
- [CodeScientist: End-to-End Semi-Automated Scientific Discovery with Code-based Experimentation](https://arxiv.org/abs/2503.22708): A semi-automated scientific discovery agent with code-based experimentation; core idea: connect hypothesis generation, executable experiments, and result analysis in one loop.
- [SPIO: Ensemble and Selective Strategies via LLM-Based Multi-Agent Planning in Automated Data Science](https://arxiv.org/abs/2503.23314): SPIO has specialist agents generate competing strategies for preprocessing, feature engineering, model selection, and tuning, then an optimisation agent cascades them into either one selected pipeline or a top-k ensemble.
- [AI-Newton](https://arxiv.org/abs/2504.01538): A concept-driven scientific-discovery system for deriving physical laws from multi-experiment data. Core idea: autonomously propose interpretable concepts and progressively generalize laws without prior physical knowledge, making law discovery an agentic research workflow.
- [AgentAda: Skill-Adaptive Data Analytics for Tailored Insight Discovery](https://arxiv.org/abs/2504.07421): AgentAda retrieves an analysis skill from a library using a hybrid matcher, generates code from that skill, and evaluates the resulting insight quality, so method selection itself becomes an agent action.

- Hugging Face ml-intern ([open-source code](https://github.com/huggingface/ml-intern); [demo](https://smolagents-ml-intern.hf.space/); no arXiv paper found) is an experimental ML-training intern agent in the Hugging Face ecosystem, useful as a practical reference for data loading, training-loop execution, and ML experiment assistance rather than a paper-backed benchmark.
- [TRACE: Transition-Aware Residual Control for Multi-Objective Materials Discovery](https://arxiv.org/abs/2608.23631): TRACE stores each LLM-agent refinement as a parent-edit-child transition with observed property deltas, then retrieves edits that are predicted to close the remaining constraint violations without damaging satisfied objectives; against the same LLEMA backbone it raises macro hit rate from 18.13% to 25.96%.
- [Autonomous Mathematical Discovery in an Open-World Multi-Agent Environment](https://arxiv.org/abs/2608.23691):The Station lets agents choose research directions, experiment, collaborate, and build shared literature without a central scripted pipeline; it reports novel results on five of 14 mathematical problems and releases dialogues, proofs, and verification code.
- [ReproAgent: Contract-Guided Paper-to-Code Reproduction](https://arxiv.org/abs/2608.24291):ReproAgent’s Prepare–Plan–Generate–Repair pipeline maintains an implementation contract that turns paper snippets into code obligations and a reference-evidence channel that retrieves structure from related repositories. Work-package and file-level contracts persist through repair, yielding the highest same-backbone PaperBench Code-Dev mean under two model configurations.
- [DeepRepro: State-Aware Subplanning for Paper-to-Code Reproduction in Evolving Repositories](https://arxiv.org/abs/2608.26557):DeepRepro continuously converts evolving repository state and execution feedback into fine-grained subplans while reproducing an ML paper, rather than relying on a static implementation plan. Repository-aware orchestration and a process-monitoring interface improve performance on PaperBench Code-Dev over scientific and commercial code-agent baselines.
- [DS-Lighting: Making Agent Harnesses Explicit for Data-Science Automation](https://arxiv.org/abs/2608.28590): DS-Lighting splits a data-science harness into data, workflow, execution, and evaluation layers and represents agents as executable operator programs; its shared sandbox and metric protocol make agent, harness, and model comparisons reproducible and reduce system failures.
- [From Question-First to Analyst-First: Domain-Expert Skills and Verified Knowledge Compilation for Proactive Enterprise Analytics](https://arxiv.org/abs/2608.28594): This analyst-first system compiles a dataset's schema knowledge offline with DuckDB, injects deterministic domain-expert skill packs into every pipeline stage, and re-verifies each published metric by rerunning evidence SQL; reports proactively seed follow-up questions instead of waiting for a user query.
- [Paper Pilot: A Human-in-the-Loop Expert System for Evidence-Traceable Scientific Manuscript Generation in Applied Sciences](https://arxiv.org/abs/2608.28596): Paper Pilot inserts eight owner-approval gates, claim classification, audit logs, no-pass criteria, and evidence-locked revision control into idea-to-claim production; in a mechanically scored citation test, ungated drafts fabricated up to 25% of citations while the gated workflow fabricated none and surfaced planted evidence gaps.
- [CrossAudit: A Git-Native, Cross-Vendor Audit Loop for Agentic Science](https://arxiv.org/abs/2608.28631): CrossAudit has a different-vendor agent audit each research increment against a human-versioned rulebook, stores reports and disputes as Git commits, runs deterministic checks first, and escalates persistent blockers to people; a seeded-defect trial records cross-vendor disagreements.
- [AutoScientist-Quant: Self-Evolving Coding Agents for Automatic Research in Quantitative Investment](https://arxiv.org/abs/2608.28632): AutoScientist-Quant makes quantitative research one budgeted search: a controller chooses improve, combine, pivot, or stop, expands nodes, retrieves shared memory, then selects a library and tunes a model; disjoint feedback and test windows repair lookahead leakage.
- [AI Scientist Mission Control (AIMC): Visual Analytics for Human Oversight of Autonomous Scientific Discovery](https://arxiv.org/abs/2608.28637): AIMC combines embeddings, automated weakness extraction, temporal analysis, and interactive views to inspect AI-generated ideas, experiments, papers, and reviews; its FARS case study surfaces recurring weaknesses, topic evolution, and papers needing deeper human review.
- [HALO: A Physics-Aware LLM Agent Framework for Nanophotonic Design](https://arxiv.org/abs/2608.28877): HALO couples an LLM planner to typed design specifications, electromagnetic simulation, diagnostics, and optional failed-trajectory retrieval; HALO-Bench compares fixed structured, autonomous structured, and coding workflows, exposing their reliability, cost, and success tradeoff.
- [PaperBanana-Interact: Scientific Diagram Refinement with Multi-Turn Human Feedback](https://arxiv.org/abs/2608.30241): PaperBanana-Interact uses an internal multi-agent critique-and-refine loop for turn-by-turn diagram requirements; MTPaperBananaBench has 292 images and 3,518 requirements, and the system counters quality drift and forgetting in ordinary multi-turn refinement.
- [FABO: Agent-Guided Discovery of Joint Breakpoint Optimization for Timing-Driven Routing Trees](https://arxiv.org/abs/2608.30268): An LLM-guided parallel-search and independent-checking loop diagnoses SALT's sink-local repair limitation and discovers FABO, which jointly optimizes shared breakpoints; on 1.29 million ICCAD15 nets it lowers normalized wirelength at every tolerance and yields FABO-FAST.
- [Using Grounded Theory for Agent Behavior Analysis at Scale](https://arxiv.org/abs/2608.30391): AutoTraceGT automates open, axial, and theoretical coding of thousands of agent trajectories until saturation, producing task-specific codebooks; across six corpora it recovers 73-91% of human-labeled failure modes, finds new patterns, and improves failure prediction over zero- and few-shot baselines.
- [Designing an Auditable LLM-Supported Workflow for Qualitative Thematic Analysis](https://arxiv.org/abs/2608.30543): The workflow constrains LLMs to interpretation while deterministic control preserves links from source excerpts to codes, justifications, themes, and descriptions; its human-comparison and expert-assessment protocol finds comparable code coverage but fewer, broader themes than manual thematic analysis.
- [Domain-Grounded Tool Orchestration for LLM-Guided Scientific Analysis](https://arxiv.org/abs/2608.30696): The architecture separates LLM intent interpretation and explanation from deterministic tool execution and constrains plans with MCP-connected ontologies; the same ParaView design transfers from CFD to topological analysis, raising interpretation accuracy from 0.41 to 0.91 with scoped retrieval.
- [Enhancing Peer Review with AI-Powered Suggestion Generation Assistance: Investigating the Design Dynamics](https://doi.org/10.1145/3640543.3645169): Studies AI suggestion interfaces for writing peer reviews, comparing inline versus list-style suggestions with 31 participants to show how interface placement changes review length, ease of use, and reviewer behavior.
- [Learning to Evaluate Before Improving: Automatic Rubric Induction for Automatic Research Agents](https://arxiv.org/abs/2608.31076): AutoSciRub decomposes an underspecified research request into atomic goals, grounds them in literature and visible data, and generates executable criteria; criterion-level verification then drives targeted revision, improving ResearchClawBench and AstaBench scores across models and harnesses.
- [ES-AHD: An Evolution Strategy Framework for Automatic Heuristic Design](https://arxiv.org/abs/2609.00023): ES-AHD replaces blind point mutations with LLM semantic recombination of high-performing heuristics and maps evolution-strategy covariance adaptation to temperature-controlled sampling, shrinking local search while retaining escapes from semantic optima; the released framework automates heuristic-program discovery.
- [Beneath the Diff: Diagnosing and Mitigating Algorithmic Mode Collapse in Code-Level Autonomous Research Loops](https://arxiv.org/abs/2609.00077): The paper identifies mechanism-level diversity collapse despite stable line-level edit diversity in autonomous ML loops, then combines category reweighting, persistent edit memory, and a validation gate in DAPS; a three-tier protocol cuts semantic-cluster decay by 69.1% and improves blind faithfulness by 83.7%.
- [Reining in an Agentic Harness for High Energy Physics](https://arxiv.org/abs/2609.00107): The paper turns reusable parts of theoretical, phenomenological, and experimental HEP agents into versioned scientific operations, then proposes common protocols, citable registries, and machine-readable scientific contracts so tools and skills can compose across models and harnesses.
- [ReDeck: Step-Level Render-Grounded Refinement for Document-to-Slide Generation](https://arxiv.org/abs/2609.00194): ReDeck changes slide revision from one-version/one-feedback to one-edit/one-observation: renderer feedback follows each atomic edit, turn-level critics handle semantics, and a submission gate handles hard layout failures; DeckQuiz separates content, spatial, and design quality.
- [ConvDeck: Conversational Paper-to-Slide Generation via Stage-Specific User Feedback](https://arxiv.org/abs/2609.00226): ConvDeck places user feedback loops at outline, content-allocation, and final-deck stages; agents either apply edits or clarify feedback, improving goal satisfaction while preserving narrative and visual quality.
- [Dr. Claw: An AI Scientist Workspace for Vibe Research](https://arxiv.org/abs/2609.00365): Dr. Claw wraps coding-agent executors with persistent state objects, reusable skills, and multi-executor coordination, joining planning, execution, and writing into a recoverable human-in-the-loop trace; with the backend fixed, the orchestration layer improves research completeness over a bare CLI agent.
- [Control-Data Flow Separation: Stable Prompt Optimization in Multi-Agent LLMs](https://arxiv.org/abs/2609.00621): The method moves routing, formatting, and termination into typed validated program objects while leaving task language optimizable; across workflows including collaborative review generation it reaches 100% eventual protocol validity while improving task performance.
- [GIDCL: A Graph-Enhanced Interpretable Data Cleaning Framework with Large Language Models](https://doi.org/10.1145/3698811): Converts relational tables to graphs for GNN-based dependency modeling, while an LLM creator-critic loop generates interpretable cleaning rules and tailored features, then iteratively refines detection and correction; experiments improve F1 by 10% on average with only 20 labeled tuples.
- [RingMoClaw: An Experience-Inspired Multi-Agent Framework for Self-Evolving Research in Remote Sensing](https://arxiv.org/abs/2609.00814): RingMoClaw closes the research loop for visual-model improvement with separate research and quality-control branches plus a dual-stream experience bus that combines external knowledge with internal experiment history; its remote-sensing evaluation reports consistent gains while cutting evolution steps by over 40%.
- [Reinforcement Learning Enhanced LLM Agents for Complex Vehicle Routing Problems](https://arxiv.org/abs/2609.00859): RLEA trains a lightweight Soft-Q planner to route LLM agents while an evolutionary memory and solver-knowledge retrieval support program generation and repair; across 48 vehicle-routing variants it raises success by 16.67% and reduces runtime errors, automating the formulation-and-test loop for complex optimization models.
- [Reliable LLM-Generated Programs for High-Energy Physics Experiments through Graph-Grounded Software Knowledge](https://arxiv.org/abs/2609.01095): The system grounds LLM program generation for HEP experiments in a heterogeneous software knowledge graph, skill-selected workflow examples, and execution-guided repair. On 275 ROOT tasks, it raises first-attempt execution from 58.5% to 76.0% under Claude Code orchestration and final success from 90.5% to 96.0%, showing that explicit software knowledge improves executable scientific coding even with agentic scaffolding.
- [Leveraging Fine-Tuned LLMs, RAG and ReAct for Enhanced Academic Document Analysis and Automated Research Proposal Generation](https://doi.org/10.1109/aidas67696.2025.11213900): Combines a fine-tuned LLM, retrieval augmentation, and ReAct tool use to analyze academic documents and draft research proposals from retrieved evidence.
- [Navigating the Alpha Jungle: An LLM-Powered MCTS Framework for Formulaic Alpha Factor Mining](https://doi.org/10.1609/aaai.v40i2.37069): The framework makes formula discovery an executable LLM-MCTS loop: the LLM proposes and refines symbolic alpha formulas, backtests provide quantitative node feedback, and frequent-subtree avoidance keeps the search diverse; real-stock experiments report better predictive and trading performance than prior mining methods while retaining interpretable formulas.
- [Expert-Inspired Multi-Agent Coordination for Multi-Objective Molecular Optimization](https://doi.org/10.1609/aaai.v40i41.40757): MAMO turns multi-objective molecular design into a coordinated expert loop: objective-specialist agents propose improvements, a central scheduler reallocates work from evaluation feedback, and the system balances conflicting goals through goal-conditioned interaction; benchmark experiments show gains in both objective quality and Pareto-front diversity, especially under strong conflicts.
- [DREAM-LLMs at LLMs4OL 2025 Task B: A Deliberation-Based Reasoning Ensemble Approach With Multiple Large Language Models for Term Typing in Low-Resource Domains](https://doi.org/10.52825/ocp.v6i.2892): DREAM-LLMs queries ChatGPT-4o, Claude Sonnet 4, DeepSeek-V3, and Gemini 2.5 Pro independently for term labels and rationales, then assigns one model to deliberate over the other three predictions. On the OBI, MatOnto, and SWEET low-resource datasets it reports F1 scores of 0.908, 0.568, and 0.593, respectively, making cross-model deliberation a concrete orchestration pattern for automated scientific knowledge curation.
- [Talk Freely, Execute Strictly: Schema-Gated Agentic AI for Flexible and Reproducible Scientific Workflows](https://arxiv.org/abs/2603.06394): The system keeps natural-language interaction flexible but compiles the resulting scientific workflow into a machine-checkable schema with dependency, governance, provenance, and human-control constraints before execution, making reproducibility checks part of the agent runtime.
- [AutoSciLab: A Self-Driving Laboratory For Interpretable Scientific Discovery](https://arxiv.org/abs/2412.12347): AutoSciLab closes an autonomous laboratory loop by generating high-dimensional experiments with a variational autoencoder, selecting informative tests through active-learning hypotheses, distilling results into low-dimensional latent variables, and learning interpretable equations; it rediscovers projectile motion and Ising transitions and finds a new nanophotonic light-emission design.
- [Jupiter: Enhancing LLM Data Analysis Capabilities via Notebook and Inference-Time Value-Guided Search](https://arxiv.org/abs/2509.09245): Jupiter extracts executable multi-step task-solution pairs from real Jupyter notebooks into NbQA, then treats data analysis as search: an MCTS value model ranks solution trajectories and node visits select short executable plans at inference time. Qwen2.5-7B and 14B reach 77.82% and 86.38% on InfiAgent-DABench, matching or surpassing GPT-4o and stronger agent scaffolds.
- [R-LAM: Reproducibility-Constrained Large Action Models for Scientific Workflow Automation](https://arxiv.org/abs/2601.09749): R-LAM constrains scientific-agent actions with structured schemas, deterministic execution policies, provenance tracking, failure-aware loops, and controlled workflow forks. Its released Python framework makes intermediate artifacts replayable and reports higher reproducibility and execution reliability than unconstrained LLM agents while retaining adaptive workflow control.
- [DataFoundry: Evolving Data Preparators via Recursive Self-Improvement](https://arxiv.org/abs/2608.29966): DataFoundry represents a data preparator as an evolvable runtime: a Controller compiles modular Skills-as-Modules, diagnoses pilot-set failures with domain criteria, and converts feedback into adapters that revise individual preparation components before production. On DataPrep-Bench, the recursive runtime produces more useful training data across four domains and multiple backbones.
- [A hybrid approach to formulaic alpha discovery with large language model assistance](https://doi.org/10.1007/s11704-025-41061-5): The paper compares LLM-only alpha generation with LLM-enhanced optimization frameworks for discovering interpretable formulaic factors. On real stock data, its hybrid method reports an average information coefficient of 0.0515, a 75% improvement over an RL baseline, and more than double the baseline cumulative excess return in backtests, demonstrating a concrete LLM-guided quantitative-research loop.
