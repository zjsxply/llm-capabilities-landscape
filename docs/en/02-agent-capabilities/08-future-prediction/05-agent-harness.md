# 2.8.5 Agent Harness

- [Reasoning and Tools for Human-Level Forecasting](https://arxiv.org/abs/2408.12036) (open-source code: not released; an early agentic forecasting scaffold whose core idea is connecting retrieval, decomposition, numerical calibration, and forecasting heuristics into one reasoning toolchain, becoming a directly cited baseline for later BTF/FutureSearch work)
- [TimeSeriesScientist](https://arxiv.org/abs/2510.01538) ([open-source code](https://github.com/Y-Research-SBU/TimeSeriesScientist); a general time-series forecasting agent whose core idea is using Curator, Planner, Forecaster, and Reporter agents to chain data diagnostics, model selection, validation integration, and report generation into a white-box forecasting workflow)
- [AIA Forecaster](https://arxiv.org/abs/2511.07678) (open-source code: not released; an agentic forecaster for real future events whose core idea is using multi-round web research, structured forecasting prompts, and calibration rules to approximate human superforecasters while exposing information-leakage risks in live/pastcasting evaluation)
- [FutureSearch Forecasting Question Generator/Resolver](https://arxiv.org/abs/2601.22444) (open-source code: not released; uses LLM-driven web research agents to automatically generate and resolve forecasting questions, serving both as a benchmark item-production harness and as a way to improve forecasting agents' probability judgments through question-decomposition strategies)
- MiroFish ([open-source code](https://github.com/666ghj/MiroFish), [official site](https://mirofish.work/); no standalone paper): Combines seed materials, knowledge graphs, multi-persona agents, and social evolution into an interactive prediction-simulation engine; suitable for turning "forecasting" from static QA into replayable scenario simulation.
- FutureSearch ReAct Agent ([open-source code](https://github.com/futuresearch/futuresearch-python); no standalone arXiv paper): The open-source FutureSearch agent implementation cited by BTF-2, providing ReAct-style system prompts, a web research toolkit, and time-management mechanisms; suitable as a reproducible experimental harness for forecasting agents.
- [Milkyway](https://arxiv.org/abs/2604.15719) (open-source code: no stable public repository found): Writes pre-resolution signals back into a continuously updated future-prediction harness. Core idea: repeatedly forecast the same unresolved question, extract pre-resolution signals, update factor tracking / evidence gathering / uncertainty handling, then perform retrospective checks using resolved outcomes; this is a more direct harness-evolution line.
- [Bayesian Linguistic Forecaster (BLF)](https://arxiv.org/abs/2604.18576) (open-source code: not released; an agentic forecaster for ForecastBench whose core idea is combining numerical probabilities and natural-language evidence summaries into a linguistic belief state, then performing sequential Bayesian updating, trial aggregation, and hierarchical calibration through iterative tool use)
