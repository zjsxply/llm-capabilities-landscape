# 1.3.4 Model

- [FLAN](https://arxiv.org/abs/2109.01652): A foundational instruction-tuning method that fine-tunes language models across many natural-language task instructions to improve zero-shot generalization.
- [InstructGPT](https://arxiv.org/abs/2203.02155): The field-defining RLHF recipe for instruction following, combining supervised demonstrations, human-preference reward modeling, and policy optimization.
- [Self-Instruct](https://arxiv.org/abs/2212.10560): A synthetic instruction-data generation method that bootstraps instructions from a language model, filters them, and fine-tunes for stronger instruction adherence.
- [DPO](https://arxiv.org/abs/2305.18290): A preference-optimization algorithm that aligns instruction-following models directly from preference pairs without separately fitting an explicit reward model.
- [Tulu 3](https://arxiv.org/abs/2411.15124): An open post-training recipe combining curated instruction data, preference learning, RL-style optimization, and evaluation-driven iteration.
- [Measuring Data Diversity for Instruction Tuning: A Systematic Analysis and A Reliable Metric](https://arxiv.org/abs/2502.17184): Defines a diversity metric for instruction-tuning data and analyzes how data diversity changes instruction-following performance.
- [HelpSteer3](https://arxiv.org/abs/2503.04378): Provides human feedback and edit data to improve open-ended instruction behavior and inference-time scaling.
- [D3: Diversity, Difficulty, and Dependability-Aware Data Selection for Sample-Efficient LLM Instruction Tuning](https://arxiv.org/abs/2503.11441): Selects instruction-tuning data by diversity, difficulty, and dependability to improve sample-efficient instruction following.
- [Adaptive Length-Bias Mitigation](https://aclanthology.org/2025.findings-naacl.169/): Mitigates excessive and deficient length preferences in reward models used for RLHF.
- [Generative RLHF-V](https://arxiv.org/abs/2505.18531): Learns multimodal alignment principles from human preference data instead of optimizing only pairwise preference scores.
- [RAIN-Merging](https://arxiv.org/abs/2602.22538): A gradient-free model-merging method for strengthening instruction compliance in large reasoning models while preserving reasoning format.
