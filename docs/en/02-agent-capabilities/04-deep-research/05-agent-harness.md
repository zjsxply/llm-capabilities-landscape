# 2.4.5 Agent Harness

- [PaperQA](https://arxiv.org/abs/2312.07559): Let the agent actively retrieve the full-text paper, evaluate the source and paragraph relevance, and then use RAG to generate answers; unlike ordinary chat models, it uses provenance as part of the answer structure.
- [STORM](https://arxiv.org/abs/2402.14207) ([code](https://github.com/stanford-oval/storm); [project page](http://storm.genie.stanford.edu)): A retrieval-grounded long-form writing harness that asks multi-perspective questions, builds an outline, and drafts cited reports; it is an important precursor to modern deep-research agents.
- [OpenResearcher](https://arxiv.org/abs/2408.06941): Provides an AI research platform for keeping up with literature and exploring new areas, combining retrieval, paper organization, and research-assistance workflows for scientific literature navigation.
- [Co-STORM](https://arxiv.org/abs/2408.15232) ([code](https://github.com/stanford-oval/storm); [project page](http://storm.genie.stanford.edu)): A collaborative exploratory-research harness with agent conversations, user steering, a dynamic mind map, and cited report output.
- [Disentangling patent quality: using a large language model for a systematic literature review](https://doi.org/10.1007/s11192-024-05206-w): Uses GPT-4 to screen 5,141 records down to 762 studies and extract 985 patent-quality indicators into economic, legal, and technological dimensions; the resulting review identifies inconsistent indicator definitions as a reproducibility problem and derives eight measurement propositions.
- [PaperQA2](https://arxiv.org/abs/2409.13740) ([open-source code](https://github.com/Future-House/paper-qa)): Retrieves scientific literature to write citation-grounded, Wikipedia-style answers and detect contradictions; in unrestricted human comparisons it matches or exceeds subject-matter experts on retrieval, summarization, and contradiction discovery, while LitQA2 exposes the underlying literature-research task.
- [Agent Laboratory](https://arxiv.org/abs/2501.04227) ([code](https://github.com/SamuelSchmidgall/AgentLaboratory)): An end-to-end research assistant workflow that starts from a human research idea and covers literature review, experimentation, and report writing.
- [Citegeist](https://arxiv.org/abs/2503.23229): Use dynamic RAG, embedding similarity, multi-stage filtering and summarization to generate citation-backed related work, suitable for quickly generating a checkable literature layout in the contribution positioning stage, rather than letting LLM freely make up sources.
- [InteractiveSurvey](https://arxiv.org/abs/2504.08762): Allow researchers to iteratively modify the intermediate output, transforming the automatic review from "one-click draft" to a workbench that can be inspected and personalized.
- [WebThinker](https://arxiv.org/abs/2504.21776) ([code](https://github.com/RUC-NLPIR/WebThinker); interleaves "reasoning-search-writing" into a single long-chain `think-search-draft` workflow)
- [ChatPD](https://arxiv.org/abs/2505.22349): An LLM-driven paper-dataset networking system that extracts dataset usage from papers, resolves dataset entities, and supports task-specific dataset discovery.
- DRBA / DRBench Baseline Agent ([code](https://github.com/ServiceNow/drbench); no independent paper; the enterprise deep research baseline agent for DRBench, built around retrieving evidence from enterprise private materials, public webpages, messages, and productivity tools, then organizing evidence and generating cited reports)
- [OWL](https://arxiv.org/abs/2505.23885) ([code](https://github.com/camel-ai/owl); explicitly decomposes deep research into a role-based `retrieval -> verification -> writing` pipeline)
- [STRUCTSENSE](https://arxiv.org/abs/2507.03674): Extracts structured records from scientific papers by combining ontology-guided symbolic knowledge, agentic self-refinement, provenance tracking, and human validation; evaluations span assessment instruments, paper metadata and resources, and biomedical named entities rather than relying on a single extraction schema.
- [Deep Cognition](https://arxiv.org/abs/2507.15759) (code: no stable public repository found; a transparent, interruptible multi-agent deep research system; core idea: expose fine-grained human steering and collaboration points during research instead of treating deep research as a sealed input-output process)
- [Compare: A Framework for Scientific Comparisons](https://arxiv.org/abs/2509.06412): Produces structured qualitative comparisons across papers and institutions, helping identify synergies, benchmark contributions, and specific research gaps.
- [WebWeaver](https://arxiv.org/abs/2509.13312) ([code](https://github.com/Alibaba-NLP/DeepResearch/tree/main/WebAgent/WebWeaver); a `planner + writer` dual-agent system that manages long-report context with dynamic outlines and an evidence memory bank)
- [InsightGUIDE: An Opinionated AI Assistant for Guided Critical Reading of Scientific Literature](https://arxiv.org/abs/2509.20493): A guided scientific-paper reading assistant. Core idea: provide structured, concise reading maps that support critical reading rather than replacing source-paper reading.
- FutureSearch ReAct Agent ([code](https://github.com/futuresearch/futuresearch-python); no independent arXiv paper; FutureSearch's open-source web research agent implementation cited in the BTF-2 paper, including tools, time management, and a ReAct-style system prompt, suitable for reproducible experimental deep research / forecasting harnesses)
- [Flash-Searcher](https://arxiv.org/abs/2509.25301) ([code](https://github.com/OPPO-PersonalAI/Flash-Searcher); turns a serial pipeline into DAG-based parallel execution and schedules dynamically by dependency)
- [FlowSearch](https://arxiv.org/abs/2510.08521) ([code](https://github.com/InternScience/InternAgent); flow-orchestration-driven integrated search and writing)
- [BrowserAgent](https://arxiv.org/abs/2510.10666) ([code](https://github.com/TIGER-AI-Lab/BrowserAgent); connects real browser action spaces to the agent and uses explicit memory to support long-horizon web tasks)
- [SQuAI](https://arxiv.org/abs/2510.15682): Use four types of collaborative agents to disassemble complex scientific problems, hybrid search, filter documents and generate reference answers with supporting sentences; compared with single-chain RAG, it makes "which evidence supports which sub-question" explicit.
- [Enterprise Deep Research](https://arxiv.org/abs/2510.17797) ([code](https://github.com/SalesforceAIResearch/enterprise-deep-research); a multi-agent deep research system implementation for enterprise research scenarios)
- [Dingtalk DeepResearch](https://arxiv.org/abs/2510.24760) (code: not public; a deep research agent for enterprise office scenarios, emphasizing workflow embedding and collaborative-office integration)
- [IterResearch](https://arxiv.org/abs/2511.07327) ([code](https://github.com/Chen-GX/IterResearch); a long-horizon deep research agent; core idea: use multi-round interaction scaling and state reconstruction to avoid noise pollution and context suffocation from a single ever-growing context)
- [AISAC: An Integrated multi-agent System for Transparent, Retrieval-Grounded Scientific Assistance](https://arxiv.org/abs/2511.14043): A transparent multi-agent runtime for retrieval-grounded scientific assistance; core idea: provide governed execution, evidence tracking, and modular roles for long-horizon scientific reasoning.
- [Cross-Disciplinary Knowledge Retrieval and Synthesis: A Compound AI Architecture for Scientific Discovery](https://arxiv.org/abs/2511.18298): Orchestrates RAG, specialized agents, and tools for cross-disciplinary knowledge retrieval and synthesis.
- [RhinoInsight](https://arxiv.org/abs/2511.18743) (code: not public; a research agent oriented toward enterprise intelligence insights)
- [MARVEL: A Multi Agent-based Research Validator and Enabler using Large Language Models](https://arxiv.org/abs/2601.03436): A locally deployable multi-agent research validator and enabler. Core idea: combine domain-aware QA, citation-precise reading, and authenticated-network operation for scientific groups that need local research assistance.
- [SciNets](https://arxiv.org/abs/2601.09727): Builds query-local concept graphs from a compact paper corpus and follows constrained multi-hop paths to synthesize mechanistic explanations; comparisons among shortest paths, diversity-constrained paths, random walks, and RAG expose a trade-off between reasoning depth and grounding stability.
- [Self-Manager](https://arxiv.org/abs/2601.17879) (code: not public; delegates multi-agent thread scheduling itself to an agent)
- [Yunque DeepResearch](https://arxiv.org/abs/2601.19578) ([code](https://github.com/Tencent-BAC/YunqueAgent); Tencent's end-to-end deep research agent)
- [FS-Researcher](https://arxiv.org/abs/2602.01566) ([code](https://github.com/Ignoramus0817/FS-Researcher); a staged retrieval and drafting research agent)
- [AgentCPM-Report](https://arxiv.org/abs/2602.06540) ([code](https://github.com/OpenBMB/AgentCPM/tree/main/AgentCPM-Report); a Chinese long-report generation specialized agent)
- [Table-as-Search](https://arxiv.org/abs/2602.06724) (code: no stable public repository found; tabularizes long-horizon information search; core idea: have the agent maintain fields to fill, evidence cells, and gaps, unifying deep search, wide search, and deep-wide search)
- Onyx ([code](https://github.com/onyx-dot-app/onyx); no arXiv paper; an open-source enterprise AI platform with built-in Deep Research, multi-step search, RAG, MCP, and Code Interpreter)
- LangChain Open Deep Research ([code](https://github.com/langchain-ai/open_deep_research); no arXiv paper; LangChain's official open-source deep research system implementation)
- AI-Q NVIDIA Research Assistant ([code](https://github.com/NVIDIA-AI-Blueprints/aiq); no arXiv paper; a fixed research loop of "plan -> parallel retrieval -> writing -> reflective supplementary retrieval -> human intervention")
- DeerFlow ([code](https://github.com/bytedance/deer-flow); no arXiv paper) separates parent planning and synthesis from independently executable subagent branches, then gives those branches sandboxed files, tools, memory, and loadable skills so one run can gather evidence and assemble cited research artifacts without conflating every branch in one context.
- Spring AI Alibaba DeepResearch ([code](https://github.com/spring-ai-alibaba/deepresearch); no arXiv paper; a Spring ecosystem integrated version of deep research)
- CellCog ([public SDK](https://github.com/CellCog/cellcog_python); no arXiv paper; a hosted multi-agent platform and Python SDK supporting agent teams and research-cog)
- [An AI Pipeline for Scientific Literacy and Discovery: a Demonstration of Perspicacité-AI integration with Knowledge Graphs](https://ceur-ws.org/Vol-4085/paper77.pdf): Demonstrates Perspicacite-AI integration with knowledge graphs, using graph-backed evidence organization as a pipeline for scientific literacy and discovery.
- [An Evidence-Centric Knowledge Management System for Humanities Research Powered by Multimodal Large Language Models](https://doi.org/10.3390/systems14050552): Builds an evidence-centric knowledge-management system for humanities research using MLLMs.
- [W&D](https://arxiv.org/abs/2602.07359) (code: no stable public repository found; Wide-and-Deep parallel tool-calling harness; core idea: horizontally call search/reading tools in parallel within a single agent step to improve source coverage and validation redundancy for BrowseComp-style tasks)
- [AnalyticsGPT: An LLM Workflow for Scientometric Question Answering](https://arxiv.org/abs/2602.09817): Decomposes scientometric questions into retrieval, metric computation, visualization, and explanation steps, so answers can be checked against concrete paper, author, venue, and citation statistics.
- [DualGraph](https://arxiv.org/abs/2602.13830) (code: no stable public repository found; separates knowledge exploration from outline planning through two co-evolving graphs, reducing the tendency to mix source discovery and report-structure decisions)
- [Feedback Is The Key for Automated Survey Generation](https://aclanthology.org/2026.findings-acl.1904): Inserts specialized feedback loops into survey drafting so outline clarity, citation support, readability, and analytical depth are checked separately before the next revision.
- [Search More, Think Less (SMTL)](https://arxiv.org/abs/2602.22675) ([code](https://github.com/OPPO-PersonalAI/SMTL); a long-horizon deep research/search agent; core idea: prioritize retrieval breadth and evidence coverage, then synthesize with lighter reasoning to reduce long-chain cost)
- [MiroFlow](https://arxiv.org/abs/2602.22808) ([code](https://github.com/MiroMindAI/MiroFlow); flowchart-style multi-stage research orchestration)
- [Hyper-Search (MM-DeepResearch)](https://arxiv.org/abs/2603.01050) ([code](https://github.com/HJYao00/MM-DeepResearch); a multimodal evidence-integration deep research agent; the link has previously been unstable)
- [ResearchPilot](https://arxiv.org/abs/2603.14629): Runs a local-first literature pipeline from a natural-language question through Semantic Scholar and arXiv retrieval, typed abstract extraction, cross-paper synthesis, and citation-aware related-work drafting, with SQLite and Qdrant persistence exposing the run history and evidence state.
- [The Knowledge-Coherence Framework for Narrative Extraction: An Empirical Study on Scientific Literature](https://doi.org/10.3390/analytics5020018): Tests narrative extraction on 3,549 IEEE visualization papers, combining embedding-based pathfinding with domain knowledge to produce coherent document sequences.
- [Adaptive Dynamic Scheduling Strategy of Multiple Large Language Models for Scientific Literature Classification Tasks](https://doi.org/10.1109/aiim67611.2025.11232910): Dynamically schedules multiple LLMs for scientific-literature classification, using model choice as part of the classification strategy rather than a fixed single-model pipeline.
- [Marco DeepResearch](https://arxiv.org/abs/2603.28376) (code: not confirmed public; a verification-centric deep research agent whose core idea is adding explicit verification to QA synthesis, trajectory construction, and test-time scaling so long-horizon search errors are caught before they propagate into the final report)
- [Rediscovering the value of academic papers in universities using a RAG system built on institutional repository papers](https://doi.org/10.1117/12.3108874): University-scale scholarly RAG can retrieve institutional publications for researcher discovery, strategic planning, and interdisciplinary theme finding, illustrating a research-facing knowledge assistant beyond public-facing question answering.
- [A Multi-Agent Human-LLM Collaborative Framework for Closed-Loop Scientific Literature Summarization](https://arxiv.org/abs/2604.01452): Uses multi-agent human-LLM collaboration for closed-loop scientific literature summarization.
- [Paper Espresso: From Paper Overload to Research Insight](https://arxiv.org/abs/2604.04562): Builds a paper-overload to research-insight workflow for literature-oriented research assistance.
- [Trustworthy Report Generation](https://arxiv.org/abs/2604.05952) (code: no stable public repository found; a deep research agent with progressive confidence estimation and calibration; core idea: continuously maintain evidence confidence during report generation to reduce unstable citations and overconfident conclusions)
- [DataSTORM](https://arxiv.org/abs/2604.06474) (code: not confirmed public; a structured-data deep research agent whose core idea is to combine exploratory data analysis, web evidence, thesis generation, and data storytelling so agents can research large databases rather than only unstructured webpages)
- [Deep-Reporter](https://arxiv.org/abs/2604.10741) (code: no stable public repository found; a grounded multimodal long-form generation harness; core idea: combine multimodal search and filtering, checklist-guided incremental synthesis, and recurrent context management)
- [Automating Categorization of Scientific Texts with In-Context Learning and Prompt-Chaining in Large Language Models](https://arxiv.org/abs/2604.23430): Combines in-context learning with prompt chaining for scientific-text categorization, targeting research-information-retrieval tasks such as classification and summarization.
- [ARIS / Auto-Research-In-Sleep](https://arxiv.org/abs/2605.03042) ([code](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep); [intro](https://wanshuiyin.github.io/Auto-claude-code-research-in-sleep/ARIS_INTRO.html)): A skill-based autonomous research harness with cross-model adversarial review, persistent research wiki, literature and experiment workflows, citation/claim audits, and Codex/OpenClaw/Claude Code portability.
- [One Prompt to Rule Them All: Automated Curve and Image Retrieval from PDFs and Websites with Agentic Multimodal RAG](https://doi.org/10.1061/9780784486184.016): Automates retrieval of curves and images from scientific PDFs and websites. Core idea: use multimodal RAG agents to locate, extract, and return visual data assets that would otherwise require manual figure and plot inspection.
- [LongSeeker](https://arxiv.org/abs/2605.05191) (code: not public; a long-horizon search/deep research agent; core idea: use Context-ReAct to dynamically compress, roll back, excerpt, and delete working memory, validating long-chain retrieval gains on BrowseComp and BrowseComp-ZH)
- [AgentDisCo](https://arxiv.org/abs/2605.11732) (code: no stable public repository found; a disentangled collaborative deep-research architecture; core idea: separate critic-driven outline/query refinement from generator-driven retrieval and outline revision, then use meta-optimization to discover reusable research-agent design strategies)
- [Argus](https://arxiv.org/abs/2605.16217): An evidence-assembly deep research agent; core idea: Searcher collects evidence while Navigator maintains an evidence graph and schedules parallel searches.
- [Building Agent Harnesses for Scientific Curation from Multimodal Sources](https://arxiv.org/abs/2606.21005): Introduces Beaver, an agent harness for scientific curation that extracts structured records from long text, tables, and figures while preserving provenance to the supporting evidence fragments.
- [GRASP: Graph-Reasoning Aided Survey Planning for High-Fidelity Related Work Generation](https://arxiv.org/abs/2607.03709): GRASP uses citation-relation graphs, argument-counterargument planning, and topology-aware pruning to plan higher-fidelity scholarly related-work sections.
- [Hallucination Detector: A hybrid LLM and Semantic Scholar tool calling for detecting hallucination in scientific literature on AtomGPT.org](https://arxiv.org/abs/2607.09774): AtomGPT's citation checker extracts bibliographic fields with an LLM, retrieves candidate records from Semantic Scholar, and scores title, author, and venue agreement to flag fabricated scientific references.
- [IllustryFlow: A Modular Framework for Automated Bibliometric Analysis Using n8n and BERT-Enhanced Topic Classification](https://doi.org/10.3390/electronics15091943): Presents IllustryFlow, an n8n-based modular workflow that automates OpenAlex corpus selection, BERT topic classification, network analysis, and reproducible bibliometric visualization.
