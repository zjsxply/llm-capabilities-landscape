# 1.15.2 Survey

- [A Survey on the Memory Mechanism of Large Language Model based Agents](https://arxiv.org/abs/2404.13501): Reviews memory types, storage, retrieval, updating, and evaluation for LLM agents.
- [From Human Memory to AI Memory: A Survey on Memory Mechanisms in the Era of LLMs](https://arxiv.org/abs/2504.15965): Connects episodic, semantic, procedural, and personalized AI memory with human-memory concepts.
- [Memory-Augmented Transformers](https://arxiv.org/abs/2508.10824): Reviews model-side memory mechanisms for Transformers, connecting neuroscience principles with context retention, reasoning, knowledge integration, and continual adaptation.
- [Towards large language models with human-like episodic memory.](https://doi.org/10.1016/j.tics.2025.06.016): Connects LLM memory design with human episodic-memory concepts, giving the memory page a cognitive reference point.
- [Graph-based Agent Memory: Taxonomy, Techniques, and Applications](https://arxiv.org/abs/2602.05665): Surveys graph construction, retrieval, temporal updates, and reasoning over agent memory.
- [Anatomy of Agentic Memory: Taxonomy and Empirical Analysis of Evaluation and System Limitations](https://arxiv.org/abs/2602.19320): Analyzes memory evaluation gaps and system limitations through an agentic taxonomy.
- [From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms](https://arxiv.org/abs/2605.06716): Tracks memory from static storage toward reusable experience and adaptation.
- [Users' Expectations and Practices with Agent Memory](https://doi.org/10.1145/3706599.3720158): Studies user expectations and practices around agent memory, grounding memory-system design in real use.
- [From Storage to Interpretation: User Perceptions, Practices, and Challenges with Long-term Memory in Agents](https://doi.org/10.1145/3765766.3765843): Analyzes user perceptions and challenges for long-term agent memory, from storage to interpretation.
- [Conversational Agents: From RAG to LTM](https://doi.org/10.1145/3767695.3769671): Reviews conversational agents from retrieval-augmented generation toward long-term memory.
