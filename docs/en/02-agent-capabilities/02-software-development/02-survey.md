# 2.2.2 Survey

- [Large Language Models for Software Engineering: A Systematic Literature Review](https://arxiv.org/abs/2308.10620): A foundational review spanning requirements, coding, testing, debugging, and maintenance.
- [LLM-Based Multi-Agent Systems for Software Engineering: Literature Review, Vision, and the Road Ahead](https://arxiv.org/abs/2404.04834): Reviews multi-agent coding, testing, review, management, and collaboration workflows.
- [Large Language Model-Based Agents for Software Engineering: A Survey](https://arxiv.org/abs/2409.02977): Connects repository understanding, localization, patching, testing, and tool feedback.
- [Software Development Life Cycle Perspective: A Survey of Benchmarks for Code Large Language Models and Agents](https://arxiv.org/abs/2505.05283): Maps code-model and agent evaluation coverage across the development lifecycle.
- [Position: Future Research and Challenges Remain Towards AI for Software Engineering](https://proceedings.mlr.press/v267/gu25e.html): An ICML 2025 position paper that organizes open challenges for AI-assisted software engineering across tasks, evaluation, reliability, human factors, and deployment.
- [Code Reasoning for Software Engineering Tasks](https://arxiv.org/abs/2506.13932): Identifies code reasoning as the common bottleneck behind debugging, repair, testing, and repository-level software tasks.
- [Navigating the growing field of research on AI for software testing](https://arxiv.org/abs/2506.14640): Builds a taxonomy and ontology-driven survey for AI-augmented software testing from manual support to full automation.
- [A Survey of LLM-based Automated Program Repair](https://doi.org/10.48550/arXiv.2506.23749): Taxonomizes LLM-based repair by fault localization, patch generation, validation, and end-to-end repair paradigms.
- [A Survey on AgentOps](https://arxiv.org/abs/2508.02121): Defines Agent System Operations around monitoring, anomaly detection, root-cause analysis, and resolution for LLM-based agent systems.
- [Agentic Software Engineering: Foundational Pillars and a Research Roadmap](https://arxiv.org/abs/2509.06216): Frames autonomous software engineering through interaction, verification, collaboration, and lifecycle integration.
- [A Research Roadmap for Augmenting Software Engineering Processes and Software Products with Generative AI](https://arxiv.org/abs/2510.26275): Provides a design-science roadmap for GenAI-augmented software processes, products, and research challenges.
- [Code to Think, Think to Code](https://aclanthology.org/2025.emnlp-main.130/): Surveys code-enhanced reasoning and reasoning-driven code intelligence, connecting coding models with broader reasoning and agentic problem-solving methods.
- [CSLLM: Code-Specific Large Language Models - A Survey](https://doi.org/10.1016/j.eswa.2025.130991): Surveys code-specialized LLMs across architectures, training data, adaptation, and evaluation, giving the software-agent page a model-side map of code intelligence.
- [LLM4Log](https://arxiv.org/abs/2604.16359): Treats log analysis as a software-engineering workflow, covering parsing, anomaly detection, root-cause analysis, and operations assistance.
- [Methods and Techniques of Agentic Software Engineering](https://doi.org/10.1109/access.2026.3652325): Systematically reviews agentic software-engineering methods, making agent workflows, techniques, and lifecycle coverage explicit rather than treating LLM coding as one-shot generation.
- [Enhancing Automated Unit Test Generation with Large Language Models](https://doi.org/10.1145/3802827): Systematically reviews LLM-based unit-test generation methods, evaluation practices, and open challenges for software-development agents and code models.
- [Generative AI solutions for software quality](https://doi.org/10.1007/s11219-026-09754-7): Assesses the industrial readiness of generative-AI approaches for software quality work, complementing lifecycle-level SE surveys.
- [Toward Responsible Autonomy](https://doi.org/10.1145/3796315.3796331): Frames autonomous software engineering around responsibility, human control, accountability, and deployment obstacles.
