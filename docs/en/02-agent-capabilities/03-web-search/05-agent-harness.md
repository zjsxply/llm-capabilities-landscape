# 2.3.5 Agent Harness

- [GMLake: Efficient and Transparent GPU Memory Defragmentation for Large-scale DNN Training with Virtual Memory Stitching](https://arxiv.org/abs/2401.08156): A GPU virtual-memory allocator that stitches non-contiguous memory blocks to reduce LLM training fragmentation; the evidence is infrastructure-side rather than a web-search or retrieval-agent harness.
- [Revolutionizing Retrieval-Augmented Generation with Enhanced PDF Structure Recognition](https://arxiv.org/abs/2401.12599): Shows a RAG document-QA pipeline where ChatDOC's panoptic and pinpoint PDF parser improves segment retrieval from professional PDFs before answer generation.
- [RAP: Retrieval-Augmented Planning with Contextual Memory for Multimodal LLM Agents](https://arxiv.org/abs/2402.03610): Uses contextual memory retrieval to pull past experiences matching the current situation, then feeds them into an agent planning loop for text and multimodal decision tasks.
- [Prompt Perturbation in Retrieval-Augmented Generation based Large Language Models](https://arxiv.org/abs/2402.07179): Stress-tests RAG with Gradient Guided Prompt Perturbation, then uses neuron-activation detectors as a verification layer against targeted wrong-answer prompt prefixes.
- [Metacognitive Retrieval-Augmented Large Language Models](https://arxiv.org/abs/2402.11626): Introduces MetaRAG, a multi-step RAG harness where the model monitors, evaluates, and replans retrieval-backed reasoning when its initial response is inadequate.
- [FeB4RAG: Evaluating Federated Search in the Context of Retrieval Augmented Generation](https://arxiv.org/abs/2402.11891): Provides a federated-search dataset and qualitative RAG comparison over 16 BEIR sub-collections, testing source selection before response generation.
- [MORE: Multi-mOdal REtrieval Augmented Generative Commonsense Reasoning](https://arxiv.org/abs/2402.13625): Extends retrieval augmentation beyond text by retrieving images and text as commonsense evidence for generative CommonGen-style reasoning.
- [RetrievalQA: Assessing Adaptive Retrieval-Augmented Generation for Short-form Open-Domain Question Answering](https://arxiv.org/abs/2402.16457): Defines an adaptive-retrieval QA testbed and TA-ARE, prompting LLMs to decide whether external retrieval is needed for new or long-tail questions.
- [REAR: A Relevance-Aware Retrieval-Augmented Framework for Open-Domain Question Answering](https://arxiv.org/abs/2402.17497): Adds a relevance-assessment module to RAG so the generator can judge retrieved-document reliability before using external evidence in open-domain QA.
- [Smart-Infinity: Fast Large Language Model Training using Near-Storage Processing on a Real System](https://arxiv.org/abs/2403.06664): Moves LLM parameter updates into near-storage accelerators and overlaps data transfer for storage-offloaded training; this is system infrastructure, not a retrieval or web-search harness.
- [Dynamic Contexts for Generating Suggestion Questions in RAG Based Conversational Systems](https://arxiv.org/abs/2403.11413): Generates clarification and suggestion questions for RAG chatbots by combining dynamic few-shot examples with dynamically retrieved context.
- [FIT-RAG: Black-Box RAG with Factual Information and Token Reduction](https://arxiv.org/abs/2403.14374): Uses a bi-label document scorer, self-knowledge recognizer, and sub-document token reducer to select factual evidence while cutting prompt tokens in black-box RAG.
- [FairRAG: Fair Human Generation via Fair Retrieval Augmentation](https://arxiv.org/abs/2403.19964): Conditions text-to-image generation on demographically diverse retrieved reference images through a lightweight projection module; this is retrieval-augmented generation for fairness, not web search.
- [Planning and Editing What You Retrieve for Enhanced Tool Learning](https://arxiv.org/abs/2404.00450): PLUTO combines an LLM query planner, neural tool retrieval, and tool-description editing so agents can decompose requests and ground them to relevant API tools.
- [PROMPT-SAW: Leveraging Relation-Aware Graphs for Textual Prompt Compression](https://arxiv.org/abs/2404.00489): Compresses long prompts by building a relation-aware graph over prompt text and extracting key information elements before LLM inference.
- [CLAPnq: Cohesive Long-form Answers from Passages in Natural Questions for RAG systems](https://arxiv.org/abs/2404.02103): Releases a grounded long-form QA dataset with gold passages and a corpus for testing retrieval, generation, and full RAG answer synthesis.
- [Dwell in the Beginning: How Language Models Embed Long Documents for Dense Retrieval](https://arxiv.org/abs/2404.04163): Audits dense-retrieval encoders for positional bias, showing MS MARCO document embeddings overemphasize early content after contrastive training.
- [Grounded Language Agent for Product Search via Intelligent Web Interactions](https://arxiv.org/abs/2404.10887): GLAINTEL trains a grounded web-interaction agent for product search, comparing unsupervised learning, demonstrations, domain adaptation, and reinforcement learning against large prompted LLM baselines.
- [AutoScraper: A Progressive Understanding Web Agent for Web Scraper Generation](https://arxiv.org/abs/2404.12753): Generates reusable web scrapers through a two-stage LLM agent that exploits HTML hierarchy, cross-page similarity, and an executability metric for changing websites.
- [LLMs Know What They Need: Leveraging a Missing Information Guided Framework to Empower Retrieval-Augmented Generation](https://arxiv.org/abs/2404.14043): MIGRES makes the RAG loop identify missing information, issue targeted follow-up retrieval queries, rerank sentences, and extract useful evidence for multi-hop QA.
- [Generate-on-Graph: Treat LLM as both Agent and KG for Incomplete Knowledge Graph Question Answering](https://arxiv.org/abs/2404.14741): GoG uses a Thinking-Searching-Generating loop that explores an incomplete knowledge graph while generating missing triples as new evidence.
- [Lifelong Knowledge Editing for LLMs with Retrieval-Augmented Continuous Prompt Learning](https://arxiv.org/abs/2405.03279): RECIPE retrieves edited knowledge, converts it into continuous prompts, and uses a Knowledge Sentinel threshold to decide when the repository should alter an LLM response.
- [ERAGent: Enhancing Retrieval-Augmented Language Models with Improved Accuracy, Efficiency, and Personalization](https://arxiv.org/abs/2405.06683): Orchestrates question rewriting, knowledge filtering, retrieval triggering, user-profile personalization, and experiential learning to avoid unnecessary re-retrieval in RAG serving.
- [TIGER: Text-Instructed 3D Gaussian Retrieval and Coherent Editing](https://arxiv.org/abs/2405.14455): Retrieves open-vocabulary objects from language-embedded 3D Gaussians and edits them with coherent score distillation; the contribution is a 3D editing pipeline rather than web search.
- [Collage is the New Writing: Exploring the Fragmentation of Text and User Interfaces in AI Tools](https://arxiv.org/abs/2405.17217): Analyzes AI writing interfaces around fragment selection, juxtaposed voices, source snippets, and editorial composition; this is design theory, not a retrieval-agent harness.
- [SPAGHETTI: Open-Domain Question Answering from Heterogeneous Data Sources with Retrieval and Semantic Parsing](https://arxiv.org/abs/2406.00562): Combines semantic parsing and generation over knowledge bases, text, tables, and infoboxes to answer heterogeneous open-domain QA queries.
- [Dual Reasoning: A GNN-LLM Collaborative Framework for Knowledge Graph Question Answering](https://arxiv.org/abs/2406.01145): Uses a GNN explicit-reasoning module to extract knowledge-graph reasoning chains, then feeds those chains into a frozen LLM for interpretable KGQA.
- [Ranking Manipulation for Conversational Search Engines](https://arxiv.org/abs/2406.03589): Formalizes conversational-search ranking as an adversarial problem and uses tree-of-attacks prompt injections to manipulate which sources LLM search engines cite.
- [VillagerAgent: A Graph-Based Multi-Agent Framework for Coordinating Complex Task Dependencies in Minecraft](https://arxiv.org/abs/2406.05720): Coordinates Minecraft agents with a DAG task decomposer, task-distribution controller, and state manager; it is a general multi-agent harness rather than web search.
- [A Tale of Trust and Accuracy: Base vs. Instruct LLMs in RAG Systems](https://arxiv.org/abs/2406.14972): Compares base and instruction-tuned LLMs inside RAG pipelines, reporting that base models outperform instructed models under the study's retrieval-generation setup.
- [Context-augmented Retrieval: A Novel Framework for Fast Information Retrieval based Response Generation using Large Language Model](https://arxiv.org/abs/2406.16383): Partitions a vector store with real-time text classification so RAG queries retrieve from a narrower, more relevant context region with lower latency.
- [The Surprising Effectiveness of Multimodal Large Language Models for Video Moment Retrieval](https://arxiv.org/abs/2406.18113): The linked arXiv record is Chrono, a temporal blueprint for MLLMs that improves video moment retrieval; it is model-side video grounding, not web-search orchestration.
- [SeaKR: Self-aware Knowledge Retrieval for Adaptive Retrieval Augmented Generation](https://arxiv.org/abs/2406.19215): Uses LLM internal-state uncertainty to decide when to retrieve, rerank snippets by uncertainty reduction, and choose reasoning strategies for multi-retrieval QA.
- [Is It Really Long Context if All You Need Is Retrieval? Towards Genuinely Difficult Long Context NLP](https://arxiv.org/abs/2407.00402): A position and taxonomy paper separating long-context difficulty into diffusion and scope, useful for deciding when retrieval should replace long prompts but not itself an agent harness.
- [Step-Controlled DPO: Leveraging Stepwise Error for Enhanced Mathematical Reasoning](https://arxiv.org/abs/2407.00782): Trains math reasoning models with step-controlled DPO over synthetic error steps; this is model post-training rather than retrieval, browser action, or web-search harness work.
- [BERGEN: A Benchmarking Library for Retrieval-Augmented Generation](https://arxiv.org/abs/2407.01102): Provides an end-to-end RAG benchmarking library standardizing datasets, corpora, retrievers, rerankers, LLMs, and metrics for reproducible pipeline comparisons.
- [An Interactive Multi-modal Query Answering System with Retrieval-Augmented Large Language Models](https://arxiv.org/abs/2407.04217): Implements an interactive multimodal QA system with preprocessing, vector representation, navigation-graph indexing, query execution, and answer generation coordinated as a pluggable RAG pipeline.
- [PersonaRAG: Enhancing Retrieval-Augmented Generation Systems with User-Centric Agents](https://arxiv.org/abs/2407.09394): Adds user-centric agents that adapt retrieval and generation from real-time user data and interactions to personalize RAG answers.
- [Evaluation of RAG Metrics for Question Answering in the Telecom Domain](https://arxiv.org/abs/2407.12873): Audits RAGAS-style faithfulness, relevance, correctness, and factuality metrics for telecom QA, including how metric behavior changes under correct versus wrong retrieval.
- [MindSearch](https://arxiv.org/abs/2407.20183) ([code](https://github.com/InternLM/MindSearch)): A multi-agent web-search harness that decomposes user questions into subquestions, searches and integrates evidence, and returns a citation-backed answer; it is a name-known search system that generic BrowseComp keyword searches can miss.
- [Adaptive Retrieval-Augmented Generation for Conversational Systems](https://arxiv.org/abs/2407.21712): Studies a conversational RAG loop that adaptively decides when dialogue turns need retrieval instead of sending every user message through a fixed retriever.
- [Optimizing RAG Techniques for Automotive Industry PDF Chatbots: A Case Study with Locally Deployed Ollama ModelsOptimizing RAG Techniques Based on Locally Deployed Ollama ModelsA Case Study with Locally Deployed Ollama Models](https://arxiv.org/abs/2408.05933): Compares local Ollama PDF-chatbot configurations for automotive documents, including chunking, embeddings, vector-store retrieval, and prompt settings rather than open-web search.
- [WeKnow-RAG: An Adaptive Approach for Retrieval-Augmented Generation Integrating Web Search and Knowledge Graphs](https://arxiv.org/abs/2408.07611): Combines multi-stage sparse and dense web-page retrieval with domain knowledge graphs and an LLM self-assessment step for CRAG-style factual answering.
- [CodeMirage: Hallucinations in Code Generated by Large Language Models](https://arxiv.org/abs/2408.08333): Audits code-generation hallucinations rather than search orchestration; it is a reliability and detection signal for code outputs, not a web-search agent loop.
- [RAGLAB: A Modular and Research-Oriented Unified Framework for Retrieval-Augmented Generation](https://arxiv.org/abs/2408.11381): Provides a transparent RAG research library that reproduces six RAG algorithms and standardizes retrievers, generators, datasets, and metrics across ten benchmarks.
- [Agentic Retrieval-Augmented Generation for Time Series Analysis](https://arxiv.org/abs/2408.14484): Uses a master agent to route time-series requests to specialized subagents that retrieve distilled prompts from a shared historical-pattern pool before prediction.
- [Knowledge Graph Modeling-Driven Large Language Model Operating System (LLM OS) for Task Automation in Process Engineering Problem-Solving](https://arxiv.org/abs/2408.14494): PEOA uses a meta-agent, action generator, expert small models, property-graph retrieval, and iterative error handling for process-engineering task automation.
- [LRP4RAG: Detecting Hallucinations in Retrieval-Augmented Generation via Layer-wise Relevance Propagation](https://arxiv.org/abs/2408.15533): Adds a verification layer for RAG outputs by using layer-wise relevance propagation features and classifiers to detect hallucinated generations.
- [MemLong: Memory-Augmented Retrieval for Long Text Modeling](https://arxiv.org/abs/2408.16967): Extends long-context generation with an external `ret-mem` retriever and controllable retrieval attention over semantic chunks, reaching far beyond the base context window.
- [RAG based Question-Answering for Contextual Response Prediction System](https://arxiv.org/abs/2409.03708): Implements a contextual-response QA pipeline around retrieval-augmented generation, using retrieved context as the grounding layer for response prediction.
- [Leveraging LLMs for Influence Path Planning in Proactive Recommendation](https://arxiv.org/abs/2409.04827): Uses LLM planning to construct influence paths for proactive recommendation, closer to recommender orchestration than general web search or RAG retrieval.

- [MRAG-Bench: Vision-Centric Evaluation for Retrieval-Augmented Multimodal Models](https://arxiv.org/abs/2410.08182): Releases a vision-centric multimodal RAG benchmark with 16,130 images and nine scenarios, showing LVLMs benefit more from retrieved images than from retrieved text.

- [Toolshed: Scale Tool-Equipped Agents with Advanced RAG-Tool Fusion and Tool Knowledge Bases](https://arxiv.org/abs/2410.14594): Stores enhanced tool descriptions in a vector knowledge base and applies pre-retrieval query planning, intra-retrieval transformation, and post-retrieval self-reflection for tool selection.

- [LLM-R: A Framework for Domain-Adaptive Maintenance Scheme Generation Combining Hierarchical Agents and RAG](https://arxiv.org/abs/2411.04476): Combines hierarchical task-based agents with instruction-level RAG to generate maintenance schemes while reducing hallucinations in equipment manuals.
