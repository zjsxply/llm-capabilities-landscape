# 1.1.1 Leaderboard

- [Evalita-LLM Leaderboard](https://huggingface.co/spaces/evalitahf/evalita_llm_leaderboard)（[论文](https://aclanthology.org/2025.clicit-1.61/)）：面向意大利语 LLM 评测的公开基准与排行榜。核心思想：使用 10 个意大利语原生任务、多种提示和 zero-shot/few-shot 设置，避免只从英文翻译测试推断意大利语能力。
- [compar:IA](https://arxiv.org/abs/2602.06669)：法国政府推出的法语 LLM 盲测成对比较 arena。核心思想：通过开放公共服务平台收集真实用户提示和偏好判断，使法语对齐与评测数据不再依赖英语 arena 的间接推断。
- [CLARIN-PT-LDB](https://arxiv.org/abs/2603.12872)：面向欧洲葡萄牙语的公开榜单与 benchmark 套件。核心思想是直接评测 PT-PT 的语言、文化与 civility 能力，而不是从英语翻译测试推断表现。
- [MTEB Leaderboard](https://huggingface.co/spaces/mteb/leaderboard)：多语文本嵌入与检索能力的公开榜单；价值在于提供可复用的 embedding/RAG 前置能力评测入口，可与 MIRAGE-Bench、AfriMTEB 等多语 RAG/检索任务衔接。
- [TyDi QA Leaderboard](https://github.com/google-research-datasets/tydiqa/blob/master/leaderboard.md)：TyDi QA 的官方公开结果列表；价值在于用类型学多样、非翻译式问答数据跟踪多语开放域问答系统。
- [Open Ko-LLM Leaderboard Results](https://huggingface.co/datasets/open-ko-llm-leaderboard/results)：Ko-H5 任务上的公开韩语 LLM benchmark 结果；价值在于用公开与私有韩语评测集比较韩语模型表现，而不是只依赖英文翻译任务。
- [Open Arabic LLM Leaderboard](https://huggingface.co/spaces/OALL/Open-Arabic-LLM-Leaderboard)：公开阿拉伯语 LLM 排行榜；价值在于围绕 ArabicMMLU 等区域语言理解基准集中记录阿拉伯语模型结果。
- [QIMMA Leaderboard](https://huggingface.co/spaces/qimma/leaderboard)：QIMMA 阿拉伯语评测套件的公开排行榜；价值在于把质量优先的阿拉伯语基准清洗与可复现排名基础设施结合起来。
- [WMT24 General MT Shared Task](https://www2.statmt.org/wmt24/translation-task.html)：WMT24 通用机器翻译共享任务官方挑战页；价值在于提供多语机器翻译的排名式提交结果与可复现任务细节。
