# 2.7.4 Model

- [WorkForceAgent-R1](https://arxiv.org/abs/2505.22942): Uses regularized R1-style reinforcement learning to train a workplace web agent for WorkArena-style enterprise navigation and action correctness.
- [ArenaRL](https://arxiv.org/abs/2601.06487): Scales reinforcement learning for open-ended agents with tournament-based relative ranking, targeting real-work tasks such as complex travel planning where scalar reward models are brittle.
- [Reasoning by Commented Code](https://arxiv.org/abs/2602.00543): Uses commented code as an intermediate reasoning form for table QA, making table operations more explicit and checkable.
- [Agent-World](https://arxiv.org/abs/2604.18292): Synthesizes real-world tool environments and verifiable tasks, then trains 8B and 14B agents with multi-environment reinforcement learning and self-evolving task generation.
- [Learning to Explore](https://arxiv.org/abs/2605.08978): Introduces exploration-aware policy optimization so LLM agents learn when environment exploration is useful before committing to task actions.
