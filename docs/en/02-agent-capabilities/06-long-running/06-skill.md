# 2.6.6 Skill

- [implementation-planner](https://skills.sh/jumppad-labs/jumppad/implementation-planner) breaks long-chain implementation into checkpointed stages with explicit acceptance criteria, so progress can be resumed or audited between runs.
- [tapestry](https://skills.sh/nicepkg/ai-workflow/tapestry) is suitable for chaining cross-system tool calls into a continuously running business-workflow skeleton.
- [error-recovery](https://skills.sh/zpankz/mcp-skillset/error-recovery) is suitable as a failure recovery/rollback prompt template for long-running execution.
- [agent-context-loader](https://skills.sh/jeremylongshore/claude-code-plugins-plus-skills/agent-context-loader) is suitable for loading task context in batches and continuously appending background material, mitigating context-organization problems in long-running work.
