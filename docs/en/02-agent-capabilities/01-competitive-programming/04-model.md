# 2.1.4 Model

- [AlphaCode](https://arxiv.org/abs/2203.07814): A field-defining contest-code model system using large-scale code pretraining, massive sampling, filtering, clustering, and ranking for Codeforces-style problems.
- [AlphaCode 2 Technical Report](https://storage.googleapis.com/deepmind-media/AlphaCode2/AlphaCode2_Tech_Report.pdf): Upgrades competitive-programming model pipelines around Gemini-era reasoning, large-scale generation, search, filtering, and scoring.
- [ACECODER](https://arxiv.org/abs/2502.01718): Trains coder models with reinforcement learning by synthesizing automated test cases that provide reliable executable rewards.
- [rStar-Coder](https://arxiv.org/abs/2505.21297): Scales competitive-code reasoning with a large verified dataset and training pipeline for high-difficulty problems with executable tests.
- [ReVeal](https://arxiv.org/abs/2506.11442): Optimizes reliable self-verification behavior for code agents instead of relying only on final outcome rewards.
- [CodeRL+](https://arxiv.org/abs/2510.18471): Aligns reinforcement learning for code generation with execution semantics to reduce the gap between text likelihood and functional correctness.
- [GrandCode](https://arxiv.org/abs/2604.02721): Uses agentic reinforcement learning and Agentic GRPO to improve contest-programming modules such as hypothesis proposal, solving, test generation, and summarization.
