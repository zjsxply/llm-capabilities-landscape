# 3.2.1 Leaderboard

- [SciArena：An Open Evaluation Platform for Non-Verifiable Scientific Literature-Grounded Tasks](https://arxiv.org/abs/2507.01001)（[平台](https://sciarena.allen.ai/)）：开放的科学文献 grounded 任务 arena。它通过社区模型对比和研究者投票对长篇科学回答进行排名，测量文献理解与跨论文综合，而不是泛化问答。
- [MLE-bench Leaderboard / Official Results](https://github.com/openai/mle-bench)（[论文](https://arxiv.org/abs/2410.07095)；[开源代码](https://github.com/openai/mle-bench)）：在 75 个 Kaggle 竞赛上评测 agent，按生成 `submission.csv` 后的竞赛指标评分，并用 `Any Medal` 聚合。任务覆盖数据读取、EDA、特征工程、模型选择、调参、训练、验证、提交修复和长时间实验迭代，使数据科学自动化能力可被系统比较。
- [PaperBench Leaderboard / Official Results](https://github.com/openai/frontier-evals/blob/main/project/paperbench/README.md)（[论文](https://arxiv.org/abs/2504.01848)）：汇报 PaperBench 中 agent 阅读已发表论文、在全新 sandbox 中实现或复现实验并接受作者设计 rubric 评分的结果。核心指标是能否产出可运行、由证据支持的复现，而不是生成表面上合理的代码。
- [MLRC-Bench Leaderboard](https://huggingface.co/spaces/launch/MLRC_Bench)（[论文](https://arxiv.org/abs/2504.09702)）：评测 agent 在更开放的机器学习研究挑战中的表现。它把问题从竞赛建模推进到能否推进研究挑战，连接 MLE-bench 式数据科学和开放式 ML 实验。
- [HypoBench Leaderboards](https://chicagohai.github.io/HypoBench/leaderboard_real)（[论文](https://arxiv.org/abs/2504.11524)；[项目页](https://chicagohai.github.io/HypoBench/)；[开源代码](https://github.com/ChicagoHAI/HypoBench-code)；[合成数据排行榜](https://chicagohai.github.io/HypoBench/leaderboard_synth)）：对真实和合成数据上的模型生成科学假设进行排名。它用下游 accuracy 和 F1 衡量自然语言解释是否有用，并在真实数据上单独评估新颖性、合理性和清晰度。
- [SciCode Leaderboard](https://scicode-bench.github.io/leaderboard/)（[论文](https://arxiv.org/abs/2407.13168)；[开源代码](https://github.com/scicode-bench/SciCode)）：汇报科学家策划的真实科研编码问题上的表现。每题提供拆解后的子问题、标准答案和测试，检验模型能否结合科学知识、推理与可执行代码合成。
- [LiveIdeaBench Leaderboard](https://liveideabench.com/)（[论文](https://arxiv.org/abs/2412.17596)）：从最少的单关键词提示出发，在 22 个领域、1,180 个关键词上对科学想法进行排名。原创性、可行性、流畅性、灵活性和清晰度指标直接测量科学发散思维，而不是一般创意写作。
- [MLE-Dojo Leaderboard](https://huggingface.co/spaces/MLE-Dojo/Leaderboard)（[论文](https://arxiv.org/abs/2505.07782)；[开源代码](https://github.com/MLE-Dojo/MLE-Dojo)）：在由 200 多个 Kaggle challenge 构成的 Gym 式可执行环境中评测交互式 ML 工程 agent。数据处理、架构搜索、调参、调试和验证形成反馈回路，把竞赛任务转化为长程实验控制能力评测。
- [Scientist-Bench / AI-Researcher Leaderboard](https://autoresearcher.github.io/leaderboard.html)（[论文](https://arxiv.org/abs/2505.18705)；[开源代码](https://github.com/HKUDS/AI-Researcher)）：比较 agent 在 guided 和 open-ended scientific innovation 任务中的表现，覆盖文献综述、假设生成、算法实现和论文准备。榜单检验系统能否跨越多个科研阶段，把科学上下文转化为已实现、可写作的研究贡献。
- [ResearchCodeBench Leaderboard](https://researchcodebench.github.io/leaderboard/index.html)（[论文](https://arxiv.org/abs/2506.02314)；[项目页](https://researchcodebench.github.io/)；[开源代码](https://github.com/PatrickHua/ResearchCodeBench)）：评测从最新 ML 论文忠实实现未见方法的能力。它从 2024--2025 顶会论文构造 212 个可执行 coding challenge，单独考察把新研究方法转换成工作代码这一科研步骤。
- [KRAMABENCH Rankings](https://kramabench.org/)（[论文](https://arxiv.org/abs/2506.06541)；[开源代码](https://github.com/mitdbg/KramaBench)；[数据集](https://huggingface.co/datasets/eugenie-y/KramaBench)）：在数据湖上对 data-to-insight agent 排名。任务要求完成数据发现、清洗、整合、统计推理和 Python pipeline 编排，衡量 agent 能否把开放式数据科学分析从原始来源推进到可解释结果。
- [RExBench Leaderboard](https://rexbench.com/)（[论文](https://arxiv.org/abs/2506.22598)；[项目页](https://rexbench.com/)）：测试 coding agent 能否扩展已发表的 AI 研究。agent 获得论文和原始代码库后实现专家撰写的新实验或假设，并通过自动执行和指标检查评分。
- [AstaBench Leaderboard](https://huggingface.co/spaces/allenai/asta-bench-leaderboard)（[论文](https://arxiv.org/abs/2510.21652)；[开源代码](https://github.com/allenai/asta-bench)）：把文献检索、代码执行、数据分析和科学发现任务统一到标准化 science-agent suite 中。公开排名因此能在共享工具环境下比较多个具体科研工作流阶段。
- [InnovatorBench Leaderboard](https://ai-innovator.opensii.ai/leaderboard/)（[论文](https://arxiv.org/abs/2510.27598)；[项目页](https://ai-innovator.opensii.ai/)；[开源代码](https://github.com/GAIR-NLP/InnovatorBench)）：在 ResearchGym 之上用 20 个可执行 LLM research 任务排名 agent。系统必须产出可运行 artifact，评价同时结合任务性能和不确定性感知检查，以区分研究级改进与偶然或不可复现的结果。
- [FIRE-Bench Leaderboard](https://firebench.github.io/#leaderboard)（[论文](https://arxiv.org/abs/2602.02905)；[项目页](https://firebench.github.io/)；[开源代码](https://github.com/maitrix-org/FIRE-Bench)）：测量从高影响 ML 论文重新发现 insight 的完整科研循环。agent 从高层研究问题出发，探索想法、设计并实现实验、执行计划，再用证据支撑重新发现的结论；榜单报告多次试验的 precision、recall 和 F1。
- [CORE-Bench / CORE-Bench Hard](https://hal.cs.princeton.edu/corebench_hard)（[论文](https://arxiv.org/abs/2409.11363)）：追踪 agent 对已发表研究进行计算复现的表现，HAL 另外提供更难的 CORE-Bench Hard 子集。任务把论文、代码、数据和执行环境打包起来，成功必须真正重跑科学结果。
- [SGI-Bench Leaderboard](https://huggingface.co/spaces/InternScience/SGI-Bench-Leaderboard)（[论文](https://arxiv.org/abs/2512.16969)）：评测与科学家工作流对齐的检索、推理、实验规划和结果组织能力。榜单把这些相互连接的能力作为探测科学通用智能的统一协议，而不是孤立的语言任务。
- [ResearchGym Leaderboard](https://anikethh.github.io/ResearchGym/#leaderboard)（[论文](https://arxiv.org/abs/2602.15112)；[项目页](https://anikethh.github.io/ResearchGym/)；[开源代码](https://github.com/Anikethh/ResearchGym)）：在真实会议论文代码库中评测闭环 AI research。系统隐藏原方法，要求 agent 提出假设、运行实验并在固定预算内超过已有 baseline，因此得分直接对应实证科研进展。
- [AIRS-Bench Leaderboard](https://github.com/facebookresearch/airs-bench#leaderboard)（[论文](https://arxiv.org/abs/2602.06855)；[开源代码](https://github.com/facebookresearch/airs-bench)）：在包含想法生成、实验分析和迭代修订的任务上比较前沿 AI research agent。它关注 agent 是否能推进真实 AI research workflow，而不只是生成一份措辞完整的答案。
- [PostTrainBench Leaderboard](https://posttrainbench.com/#leaderboard)（[论文](https://arxiv.org/abs/2603.08640)；[项目页](https://posttrainbench.com/)；[开源代码](https://github.com/aisa-group/PostTrainBench)）：把 LLM post-training 作为受限预算下的自动科研闭环进行评测。agent 需要检索方法、准备数据、运行训练实验并优化目标评测，在单张 H100 预算下暴露 reward hacking 和实验控制薄弱等问题。
- [ResearchArena / True Auto Research Results](https://youarespecialtome.github.io/ResearchArena/)（[论文](https://arxiv.org/abs/2605.19156)；[项目页](https://youarespecialtome.github.io/ResearchArena/)；[开源代码](https://github.com/YouAreSpecialToMe/ResearchArena)）：在 117 篇生成论文、13 个 CS 领域以及 CPU、GPU 和 H100 扩展设置中评测 frontier CLI agent。它结合 Stanford Agentic Reviewer、code-aware 多 agent 评审和人工 artifact 检查，揭示完整科研循环中的实验严谨性、结果忠实性和引用完整性缺口。
- [AutoLab Leaderboard](https://autolab.moe/leaderboard)（[论文](https://arxiv.org/abs/2606.05080)；[项目页](https://autolab.moe/)；[开源代码](https://github.com/autolabhq/autolab)）：在长程闭环优化任务上排名 agent，其中包含模型开发和 ML 实验任务，同时覆盖系统、谜题和 CUDA kernel。它从正确但刻意次优的 baseline 出发，在严格 wall-clock 预算内衡量 agent 是否会反复 benchmark、编辑并吸收实证反馈。
- [ResearchClawBench Leaderboard](https://huggingface.co/datasets/InternScience/ResearchClawBench)（[论文](https://arxiv.org/abs/2606.07591)；[开源代码](https://github.com/InternScience/ResearchClawBench)）：评测从相关文献和原始数据到实验、同行评审式报告的端到端自动科研，并以隐藏目标论文作为参照。公开包提供目标论文上下文、数据、图表和多模态 checklist judging，用来区分科研复现与开放发现。
- [ResearcherBench Leaderboard](https://researcherbench.github.io/)（[论文](https://arxiv.org/abs/2507.16280)；[开源代码](https://github.com/GAIR-NLP/ResearcherBench)）：在来自实验室讨论和访谈的 65 个专家选择 frontier-AI 科研问题上评测 agentic research judgment。技术细节、文献综述和开放咨询任务分别用专家 insight rubric，以及引用忠实度和覆盖度检查评分。
- [DEEPSYNTH Leaderboard](https://huggingface.co/spaces/DeepSynthesisTeam/deepsynth-leaderboard)（[论文](https://arxiv.org/abs/2602.21143)；[开源代码](https://github.com/agentdeepsynthesis/deepsynth-bench)）：在覆盖 7 个领域、67 个国家的 120 个耗时多源综合任务上排名 agent。构题流程要求收集官方数据、形成假设、执行人工分析并定义可验证答案，因此榜单可以测量 agent 收集证据、分析证据并提取结构化洞见的能力。
