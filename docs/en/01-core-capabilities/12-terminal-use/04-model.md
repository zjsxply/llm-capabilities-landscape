# 1.12.4 Model

- [BYOS: Knowledge-driven Large Language Models Bring Your Own Operating System More Excellent](https://arxiv.org/abs/2503.09663): Grounds LLM-based Linux kernel tuning in structured OS knowledge, using knowledge construction, configuration-space refinement, and continuous knowledge maintenance to reduce hallucinated kernel settings across workloads and versions.
- [TerminalTraj](https://arxiv.org/abs/2602.01244): Generates terminal-agent trajectories from Dockerized repositories, including executable tasks, validators, and verified action traces for training terminal-capable agents.
- [TermiGen](https://arxiv.org/abs/2602.07274): Synthesizes high-fidelity terminal environments and robust recovery trajectories to address execution-grounded training-data scarcity.
- [TACO](https://arxiv.org/abs/2604.19572): A self-evolving terminal-context compression method that learns reusable observation-compression rules from interaction trajectories.
- [SkillSynth](https://arxiv.org/abs/2604.25727): Uses scenario-mediated skill graphs to synthesize executable terminal tasks and minimal execution trajectories for training and evaluation.
- [Terminal-World](https://arxiv.org/abs/2605.20876): Scales terminal-agent environments through agent skills. Core idea: use skills to automatically synthesize terminal-agent tasks, environments, and teacher trajectories, producing 5,723 training environments and training Terminal-World models from those generated trajectories.
- [LiteCoder-Terminal](https://arxiv.org/abs/2605.29559) ([code and resources](https://github.com/icip-cas/LiteCoder)): Builds terminal-capable language agents through scalable SFT on 11,255 synthesized terminal trajectories, reinforcement learning in 602 verifiable environments with Decoupled Clip and Dynamic sAmpling Policy Optimization, and continued RL on standardized benchmark tasks.
- [chatHPC: Empowering HPC users with large language models](https://doi.org/10.1007/s11227-024-06637-1): Describes an HPC-scale LLM alignment pipeline for conversational question answering and script generation, including pretraining, fine-tuning, service deployment, self-instruction data generation, and evaluations for coherence, semantic accuracy, hallucination, and privacy.
