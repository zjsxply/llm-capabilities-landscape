# 4.1.5 Agent Harness

- [DiffusionAgent: Navigating Expert Models for Agentic Image Generation](https://arxiv.org/abs/2401.10061): Uses an LLM-driven tree-of-thought navigator to parse an open-domain prompt, match it against a prior-knowledge tree of diffusion experts, and update an advantage database with human feedback so model routing improves without retraining the experts.
- [Anywhere: A Multi-Agent Framework for User-Guided, Reliable, and Diverse Foreground-Conditioned Image Generation](https://arxiv.org/abs/2404.18598): Replaces a monolithic foreground inpainting model with specialized agents for foreground understanding, diversity, object integrity, prompt consistency, automated quality assessment, and regeneration when a candidate image fails checks.
- [EditScribe: Non-Visual Image Editing with Natural Language Verification Loops](https://arxiv.org/abs/2408.06632): Makes image editing accessible to blind and low-vision users by pairing natural-language edit commands with LMM-generated general descriptions, object descriptions, visual-change summaries, AI judgments, and follow-up question loops.
- [ComfyBench / ComfyAgent](https://arxiv.org/abs/2409.01392) ([open-source code](https://github.com/xxyQwQ/ComfyBench); [project page](https://xxyqwq.github.io/ComfyBench)): Evaluates ComfyUI workflow-design agents on 200 instruction-following generation tasks, then implements ComfyAgent as a code-to-workflow interpreter plus cooperating agents that learn from existing workflows and generate new node graphs.
- [MagicQuill: An Intelligent Interactive Image Editing System](https://arxiv.org/abs/2411.09703): Monitors lightweight user interactions with an MLLM to infer edit intent in real time, then sends insert, erase, and color-change requests to a diffusion prior with a learned two-branch plug-in for precise local control.
- [HILITE: Human-in-the-loop Interactive Tool for Image Editing](https://doi.org/10.1109/bigdata62323.2024.10825916): Places the user inside the editing loop, exposing an interactive review-and-correction interface so generated edits can be inspected, adjusted, and resubmitted instead of accepted as one-shot diffusion outputs.
- [Bayesian Optimization for Controlled Image Editing via LLMs](https://arxiv.org/abs/2502.18116): Uses LLM-guided Bayesian optimization to control image-editing outcomes through an iterative search loop.
- [PromptMap: An Alternative Interaction Style for AI-Based Image Generation](https://arxiv.org/abs/2503.09436): Turns image generation and editing capability into an executable or orchestrated workflow rather than a single prompt.
- [Hybrid Agents for Image Restoration](https://arxiv.org/abs/2503.10120): Splits restoration into slow MLLM agents for ambiguous degradation diagnosis, fast LLM agents for simple prompts, and feedback agents that coordinate multiple task-specific and universal restoration tools.
- [ComfyGPT](https://arxiv.org/abs/2503.17671) ([open-source code](https://github.com/comfygpt/comfygpt); [project page](https://comfygpt.github.io/)): Generates ComfyUI workflows with ReformatAgent, FlowAgent, RefineAgent, and ExecuteAgent, optimizing precise node connections and using reinforcement learning over FlowDataset and FlowBench feedback.
- [CREA](https://arxiv.org/abs/2504.05306): Treats creative image editing as a team process in which specialized agents articulate creative concepts, generate diffusion edits, critique outputs, and enhance candidates to balance originality, coherence, and artistic intent.
- [CIGEval](https://arxiv.org/abs/2504.07046): Turns conditional image-generation evaluation into an LMM tool-use loop: the agent selects from a multi-function toolbox, analyzes tool outputs with fine-grained task criteria, and can be distilled from 2.3K evaluation trajectories into smaller LMM judges.
- [Q-Agent](https://arxiv.org/abs/2504.07148): Restores degraded images by first decomposing multi-degradation perception into single-degradation chain-of-thought checks, then using IQA metrics to greedily choose the restoration algorithm sequence.
- [SPICE: A Synergistic, Precise, Iterative, and Customizable Image Editing Workflow](https://arxiv.org/abs/2504.09697): A candidate agent harness, workflow, protocol, runtime, or orchestration method for image generation and editing. Its value is making agent-side control, tool use, coordination, or verification reusable beyond one prompt.
- [Twin Co-Adaptive Dialogue for Progressive Image Generation](https://arxiv.org/abs/2504.14868): Starts from a base image and keeps the user in a synchronized dialogue loop, narrowing prompt ambiguity and adapting subsequent generations to evolving feedback instead of relying on repeated manual prompt trials.
- [ComfyMind](https://arxiv.org/abs/2505.17908) ([open-source code](https://github.com/EnVision-Research/ComfyMind)): Abstracts ComfyUI node graphs into natural-language callable modules through a Semantic Workflow Interface, then uses search-tree planning with localized execution feedback to repair workflow choices stage by stage.
- [ComfyUI-Copilot](https://arxiv.org/abs/2506.05010) ([open-source code](https://github.com/AIDC-AI/ComfyUI-Copilot)): Coordinates an assistant agent with workflow, node, and model worker agents over curated KBs of 7K nodes, 62K models, and 9K workflows, supporting one-click workflow import, node/model recommendation, prompt writing, parameter search, and canvas debugging; the public repository notes that agent functions now require a user-supplied LLM API key and base URL.
- [Retrieval Augmented Comic Image Generation](https://arxiv.org/abs/2506.12517): Uses retrieval-based character assignment to align prompt characters with references, then injects regional character features so multi-frame comic images preserve identity, costume, and expressive gestures.
- [CAL-RAG: Retrieval-Augmented Multi-Agent Generation for Content-Aware Layout Design](https://arxiv.org/abs/2506.21934): Uses retrieval-augmented multi-agent generation for content-aware layout design.
- [4KAgent](https://arxiv.org/abs/2507.07105): Profiles the input domain, has a perception agent combine VLM analysis with IQA experts to draft a restoration plan, and lets a restoration agent recursively execute and reflect with a quality-driven mixture-of-experts policy for 4K upscaling.
- [An LLM-LVLM Driven Agent for Iterative and Fine-Grained Image Editing](https://arxiv.org/abs/2508.17435): Uses an LLM-LVLM agent for iterative fine-grained image editing.
- [Narrative-to-Scene Generation: An LLM-Driven Pipeline for 2D Game Environments](https://arxiv.org/abs/2509.04481): Converts short stories into three time-framed tile scenes by extracting object-relation-object triples, retrieving GameTileNet assets with affordance-aware embeddings, generating terrain with cellular automata, and placing objects with spatial rules.
- [Maestro](https://arxiv.org/abs/2509.10704): Iteratively evolves an initial T2I prompt by having specialized MLLM critics identify image weaknesses, a verifier merge interpretable edit signals while preserving user intent, and an MLLM judge compare candidate images head to head.
- [PromptSculptor](https://arxiv.org/abs/2509.12446): Automates prompt refinement with four agents that expand vague inputs through chain-of-thought context inference, self-evaluate alignment with the original request, and incorporate user feedback for another tuning pass.
- [AgenticIQA: An Agentic Framework for Adaptive and Interpretable Image Quality Assessment](https://arxiv.org/abs/2509.26006): Agent-harness candidate for image generation and editing: Builds an agentic framework for adaptive and interpretable image-quality assessment.
- [GenPilot: A Multi-Agent System for Test-Time Prompt Optimization in Image Generation](https://arxiv.org/abs/2510.07217): A candidate agent harness, workflow, protocol, runtime, or orchestration method for image generation and editing. Its value is making agent-side control, tool use, coordination, or verification reusable beyond one prompt.
- [Bringing The Consistency Gap: Explicit Structured Memory for Interleaved Image-Text Generation](https://arxiv.org/abs/2510.10969): Adds explicit structured memory for interleaved image-text generation. Core idea: track entities, attributes, and relations in an Image Understanding Tree so long multimodal generation preserves identity, logic, and style across turns.
- [From Evidence to Verdict: An Agent-Based Forensic Framework for AI-Generated Image Detection](https://arxiv.org/abs/2511.00181): Treats AI-image detection as multi-stage forensics by combining reverse image search, metadata extraction, pretrained classifiers, VLM analysis, multi-agent debate over conflicting evidence, and optional memory over historical cases.
- [Multimodal-LLM Agent For Text-Driven Multi-Attribute Face Editing](https://doi.org/10.1109/icip55913.2025.11084332): Uses a multimodal LLM as the controller for text-driven face editing, coordinating multiple requested facial attributes rather than requiring the user to manually sequence separate edits.
- [ComfySearch](https://arxiv.org/abs/2601.04060): Formulates ComfyUI workflow generation as validation-guided graph construction, where the agent explores component choices under node-connection constraints and keeps only executable, higher-quality pipeline states.
- [M3: High-fidelity Text-to-Image Generation via Multi-Modal, Multi-Agent and Multi-Round Visual Reasoning](https://arxiv.org/abs/2602.06166): Contributes reusable orchestration, planning, memory, verification, tool use, or runtime logic for image generation and editing. Core signal: agentic steering or multi-agent reasoning around text-to-image generation.
- [GlyphBanana: Advancing Precise Text Rendering Through Agentic Workflows](https://arxiv.org/abs/2603.12155): A candidate agent harness, workflow, protocol, runtime, or orchestration method for image generation and editing. Its value is making agent-side control, tool use, coordination, or verification reusable beyond one prompt.
- [coDrawAgents](https://arxiv.org/abs/2603.12829): Coordinates Interpreter, Planner, Checker, and Painter agents so prompts are parsed into object descriptors, layouts are proposed in semantic-priority groups, spatial and attribute errors are checked, and objects are painted onto an evolving canvas.
- [Agentic Flow Steering and Parallel Rollout Search for Spatially Grounded Text-to-Image Generation](https://arxiv.org/abs/2603.18627): Contributes reusable orchestration, planning, memory, verification, tool use, or runtime logic for image generation and editing. Core signal: agentic steering or multi-agent reasoning around text-to-image generation.
- [PSDesigner: Automated Graphic Design with a Human-Like Creative Workflow](https://arxiv.org/abs/2603.25738): Automates graphic design with a human-like creative workflow.
- [GEMS](https://arxiv.org/abs/2603.28088): Combines a closed-loop multi-agent generation process with trajectory-level memory for factual states and compressed experiences, plus on-demand loading of domain skills for specialized downstream generation tasks.
- [Creo: From One-Shot Image Generation to Progressive, Co-Creative Ideation](https://arxiv.org/abs/2604.13956): Turns text-to-image generation into a staged co-creative loop, moving from editable sketches to high-resolution images while locking prior decisions so later AI-assisted edits affect only chosen regions or attributes.
- [EditRefiner](https://arxiv.org/abs/2605.07457): Uses a perception-reasoning-action-evaluation loop over EditFHF-15K feedback, localizing artifacts and editing failures, diagnosing them with textual reasoning, planning localized re-edits, and deciding whether another refinement pass is needed.
- [IEA: Amateur-Friendly Conversational Image Editing Agent via Three Stages of Multitask Alignment](https://arxiv.org/abs/2606.08016): Builds IEA, a conversational image-editing agent that operates 16 parameterized tools through interpretable action traces and trains with SFT, GRPO rewards, and synthetic multitask fine-tuning.
- [AgentStory: A Multi-Agent System for Story Visualization with Multi-Subject Consistent Text-to-Image Generation](https://doi.org/10.1145/3731715.3733271): An agent harness or runtime for image generation and editing. Core idea: externalize a multi-agent system for story visualization with multi-subject consistent text-to-image generation into reusable orchestration, tool-use, memory, or protocol logic.
- [Talk, Imagine, Evolve: A Unified Multimodal Agent for Seamless Visual Generation and Editing](https://doi.org/10.1145/3746027.3754467): A multimodal agent for visual generation and editing. Core idea: wrap image generation and editing in an agentic loop that can talk with the user, imagine candidate results, and iteratively evolve outputs.
- [AVATAR-AGENT: A Multi-Agent System for Expressive 3D Avatar Generation](https://doi.org/10.1145/3786167.3788404): Builds a multi-agent system for expressive 3D avatar generation.
