# 3.2.6 Skill

- [ResearchStudio-Reel](https://arxiv.org/abs/2607.04438)：封装五个可由 Codex/Claude 执行的 skill：共享资产提取、可编辑 PowerPoint poster/video 与双语 Word blog 生成，以及交互式 Paper2Reel 汇聚。它通过 measured-fill 与按产物划分的 release check，把论文推广变成可测试的科研交付流程。
- [Rehearse: Stepping Back from the Confidence Cliff in Self-Improving Autoresearch](https://arxiv.org/abs/2607.27687)：通过在执行前筛选候选改动并保留相似既往结果的聚焦记忆，改进自动研究循环。
- [SciVisAgentSkills](https://arxiv.org/abs/2606.05525)：提供科研数据分析与可视化的可复用 agent skills。核心思想是把 ParaView、napari、VMD 和 TTK 操作封装成技能，并用 108 个多步可视化任务评测。
- [F(AI)2R: Who Did What, and Who Checked? Verifiable AI Provenance as an Executable Skill](https://arxiv.org/abs/2607.25637)：基于 aiprov 对 PROV-O 的扩展，将 AI 参与科研的溯源封装为可执行 skill：初始化解析操作者 ORCID，搭建以溯源图一致性约束 push 的 CI，并在“主张必须有父来源”和“验证等级只能由人授予”不变量下记录活动、主张与来源，论文自身构建即为案例。
- [Scientific Data Skills: Enabling Agent-Ready Scientific Data Services at Scale](https://arxiv.org/abs/2608.19625)：将数据集语境、文件组织、操作流程、质量检查和来源追踪封装为可复用的 SciDSK 技能，同时保留权威数据仓库中的原始数据；跨六个学科的 Skill Bank 以及数据发现、解释评测表明，这种结构化封装能让科研 Agent 更准确、可执行地使用科学数据。
- [Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents](https://arxiv.org/abs/2609.00065)：该库把 16 个实践领域的 163 个程序化方法封装为按需加载目录，包含说明、参考材料和可运行脚本，具体覆盖统计检验选择、权威标识符命名空间和必要 caveat；未报告任务级评测。
- [Deli Scientific Paper Writing](https://victorchen96.github.io/auto_research/skill/paper-writing.html) 是与 Deli_AutoResearch 配套的论文生产 skill group；它把工作路由到 literature survey、paper structure and logic、experiment design、academic figures and tables、peer-review simulation 五个子技能，并显式规定 citation scoring、venue-upgrade check、质量门控和 review-driven 迭代循环。
- [ResearchStudio](https://github.com/microsoft/ResearchStudio) 是覆盖科研 first mile 与 last mile 的 Claude Code 和 Codex skill suite。`ResearchStudio-Idea` 提供可检查的 `idea-spark`、`paper-search` 与 `scoop-check` skills，用文献证据诊断 bottleneck、按模式生成想法、检查 prior-art collision 并输出可供审稿人检验的 idea card。`ResearchStudio-Reel` 现在也已公开实际的 `paper2assets`、`paper2poster`、`paper2video`、`paper2blog` 和 `paper2reel` skill 目录，覆盖 PDF 资产提取、可编辑 poster、配音 video、双语 DOCX blog 与交互式 `reel.html` viewer。
- [Paper2Web / paper-2-web](https://skills.sh/alterlab-ieu/alterlab-academic-skills/alterlab-paper-2-web)（[Paper2All 流水线](https://github.com/YuhangChen1/Paper2All)；[benchmark 论文](https://arxiv.org/abs/2510.15842)）把论文 PDF 或 LaTeX 源码转成交互式学术主页，同一 skill 家族还可生成 poster 和 video 等传播资产。核心思想是读取论文结构，抽取图表和 logo，规划响应式页面，并生成面向浏览器的 project page；它解决的是论文推广展示，而不是通用建站。
- [paper-to-storyboard](https://github.com/MaoranSun/paper-to-storyboard) 把论文 PDF 转成单页 scrollytelling 网站，带抽取出的图表、可选 AI 封面和固定的 editorial chassis。核心思想是先把论文抽成 `content.json` 和 `figures.json`，再映射成 `title → hook → problem → method → results → insight` 的叙事弧，最后渲染成适合论文讲述和推广的 scroll-snap 页面。
- [GLMV PDF to Web](https://skills.sh/zai-org/glm-skills/glmv-pdf-to-web) 是更轻量的 PDF 到项目主页 skill，面向学术论文或技术文档。核心思想是本地把 PDF 页面转成图像，生成结构化 outline JSON，再依据论文内容渲染单页 HTML project page。
- [agent-loop-skills](https://github.com/gaasher/Agent-Loop-Skills) 把 verification-gated research loops 封装成可移植 Agent Skills，而不是一次性提示词。核心思想是为任务绑定 artifact、可度量反馈信号、运行 ledger 和终止条件，再用真实指标决定每个 proposal 是保留还是回滚；Research 相关循环包括 `ml-autoresearch`、`tournament-autoresearch`、`research-question`、`hypothesis-gen`、`research-proposal`、`scientific-writer` 和 `scientific-figure`，并共享基于 Semantic Scholar 与 arXiv 的 literature-search 支持。
- [neuromechanist/research-skills](https://github.com/neuromechanist/research-skills) 是跨 agent 的 academic research workflow 插件市场。核心思想是把可复用科研工作拆成 project、grant、manuscript、OpenCite、figures、presentation 与 project-lifecycle 等可单独安装的插件，配套 figure QA 脚本、发表级图形组合技能、稿件审阅与格式化技能、基金写作/评审技能，以及 Codex、Claude、GitHub Copilot manifest；其中 neuroinformatics 组件仅作为领域插件背景，不扩展本页主覆盖。
