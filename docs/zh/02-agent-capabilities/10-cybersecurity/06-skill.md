# 2.10.6 Skill

- [setup-sandbox](https://skills.sh/recoupable/setup-sandbox) 通过 Recoup CLI 拉取组织与 artist 信息，创建 `orgs/{org}/artists/{artistSlug}` 目录并写入 `RECOUP.md` 身份标记；它是 Recoupable workspace 初始化工具，而不是 exploit 隔离控制。
- [docker-local-dev](https://skills.sh/thienanblog/awesome-ai-agent-skills/docker-local-dev) 通过技术栈检测脚本和澄清问题生成 Docker Compose 与 Dockerfile，并提供 PHP/Laravel、WordPress、Drupal、Joomla、Node.js、Python 服务模板，可用于搭建可重复的本地网络安全实验环境。
- [nmap-mcp](https://github.com/sbmilburn/nmap-mcp) 把 nmap 封装为 14 个返回结构化 JSON 的 MCP 工具，覆盖主机发现、端口扫描、服务与 OS 识别、NSE 脚本和完整侦察，同时提供 CIDR 范围约束、审计日志、scan_id 持久化和 shell 元字符过滤。
- [security-detections-mcp](https://skills.sh/aradotso/security-skills/security-detections-mcp) 通过 MCP 检索 8,200+ 条 Sigma、Splunk ESCU、Elastic、KQL、Sublime 与 CrowdStrike 检测规则，并支持 MITRE ATT&CK 映射、覆盖缺口分析、Navigator layer 导出和检测工程提示。
- [mcpsec](https://github.com/pfrederiksen/mcpsec) 按 OWASP MCP Top 10 风格检查扫描 MCP server 配置和 Claude Desktop extension manifest，并以表格或 OCSF JSON 输出 secrets、缺失认证、不安全 URI、重复工具、弱传输、schema 缺口、日志和限流问题。
