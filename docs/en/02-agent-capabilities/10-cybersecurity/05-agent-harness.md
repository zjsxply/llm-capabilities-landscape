# 2.10.5 Agent Harness

- [Accelerating Intrusion Detection Dataset Analysis- A Framework Using AutoGen Agents for CIC-IDS 2017](https://doi.org/10.52783/jisem.v10i5s.758): Contributes an agent workflow, runtime, protocol, tool-use pattern, or multi-agent orchestration approach for cybersecurity agents and security evaluation.
- [HackingBuddyGPT](https://arxiv.org/abs/2308.00121) ([open-source code](https://github.com/ipa-lab/hackingBuddyGPT); [docs](https://docs.hackingbuddy.ai/)): A security-researcher assistant harness for authorized hacking workflows, useful as an early open-source reference for tool-mediated reconnaissance, exploitation attempts, and auditability.
- [PentestGPT](https://arxiv.org/abs/2308.06782) ([open-source code](https://github.com/GreyDGL/PentestGPT); [project page](https://pentestgpt.com/)): An early LLM penetration-testing agent that organizes reasoning, task status, and tool interaction around authorized assessment workflows.
- [LLbezpeky: Leveraging Large Language Models for Vulnerability Detection](https://arxiv.org/abs/2401.01269): Uses LLM-guided code inspection to turn vulnerable-code evidence into vulnerability decisions, making the row closer to a detector workflow than an autonomous exploitation harness.
- [Enhanced Automated Code Vulnerability Repair using Large Language Models](https://arxiv.org/abs/2401.03741): Automates secure-code repair by having an LLM propose vulnerability patches and reason over code context, fitting the detect-patch review loop rather than a pure classifier.
- [A Preliminary Study on Using Large Language Models in Software Pentesting](https://arxiv.org/abs/2401.17459): Evaluates prompt-engineered LLM pentesting agents on OWASP Benchmark 1.2 source-code vulnerabilities, comparing repeated prompt improvement against unengineered agents and SonarQube.
- [SCALE: Constructing Structured Natural Language Comment Trees for Software Vulnerability Detection](https://arxiv.org/abs/2403.19096): Turns code into structured natural-language comment trees before vulnerability reasoning, using the tree as an intermediate analysis artifact for code-security decisions.
- [LLM Agents can Autonomously Exploit One-day Vulnerabilities](https://arxiv.org/abs/2404.08144): Tests whether LLM agents can exploit disclosed one-day vulnerabilities by giving agents vulnerability descriptions and letting them plan commands, execute actions, and observe results.
- [LLMPot: Dynamically Configured LLM-based Honeypot for Industrial Protocol and Physical Process Emulation](https://arxiv.org/abs/2405.05999): Uses LLMs to dynamically configure industrial-protocol honeypots and emulate physical-process behavior, making deception environments adapt to attacker interaction.
- [GenKubeSec: LLM-Based Kubernetes Misconfiguration Detection, Localization, Reasoning, and Remediation](https://arxiv.org/abs/2405.19954): Runs a Kubernetes misconfiguration workflow that detects risky settings, localizes the affected resource, explains the reasoning, and proposes remediation.
- [HPTSA](https://arxiv.org/abs/2406.01637) ([open-source code](https://github.com/uiuc-kang-lab/HPTSA)): A hierarchical planning and task-specific agent framework for web penetration testing, useful for decomposing exploitation attempts into scoped subagents.
- [DiVerify: Hardening Identity-Based Software Signing with Diverse-Context Scopes](https://arxiv.org/abs/2406.15596): Hardens identity-based software signing by checking signing scopes across diverse contextual signals, so the runtime guard limits what a compromised identity can sign.
- [A Context-Driven Approach for Co-Auditing Smart Contracts with The Support of GPT-4 code interpreter](https://arxiv.org/abs/2406.18075): Uses GPT-4 Code Interpreter as a co-auditor for smart contracts, combining contract context, executable analysis, and human review to validate vulnerability hypotheses.
- [MoRSE: Bridging the Gap in Cybersecurity Expertise with Retrieval Augmented Generation](https://arxiv.org/abs/2407.15748): Applies retrieval-augmented generation to cybersecurity assistance, grounding incident or vulnerability answers in external security knowledge instead of model memory alone.
- [CIPHER: Cybersecurity Intelligent Penetration-Testing Helper for Ethical Researcher](https://arxiv.org/abs/2408.11650): Assists ethical penetration testers by structuring reconnaissance, vulnerability reasoning, command selection, and next-step guidance in an authorized testing workflow.
- [APPATCH: Automated Adaptive Prompting Large Language Models for Real-World Software Vulnerability Patching](https://arxiv.org/abs/2408.13597): Uses adaptive prompting to repair real-world software vulnerabilities, iterating over patch candidates so the LLM can tailor fixes to code context and vulnerability type.
- [ProphetFuzz: Fully Automated Prediction and Fuzzing of High-Risk Option Combinations with Only Documentation via Large Language Model](https://arxiv.org/abs/2409.00922): Reads documentation with an LLM to predict risky option combinations, then drives fuzzing toward those configurations without hand-written option models.
- [EnIGMA](https://arxiv.org/abs/2409.16165) ([open-source code](https://github.com/SWE-agent/SWE-agent); [project page](https://enigma-agent.com/)): A SWE-agent-based cyber harness for CTF and vulnerability tasks, relevant as a reusable scaffold for executable security challenges.
- [APOLLO: A GPT-based tool to detect phishing emails and generate explanations that warn users](https://arxiv.org/abs/2410.07997): Detects phishing emails and generates user-facing warning explanations, pairing classification with an explanation step for security-awareness workflows.
- [AutoPT](https://arxiv.org/abs/2411.01236) ([open-source code](https://github.com/Dizzy-K/AutoPT)): A web penetration-testing automation harness that coordinates reconnaissance, vulnerability analysis, exploitation, and reporting in authorized environments.
- [LProtector: An LLM-driven Vulnerability Detection System](https://arxiv.org/abs/2411.06493): Runs GPT-4o with retrieval-augmented context over C and C++ codebases to detect vulnerabilities, making the external evidence-retrieval loop the reusable component.
- [Next-Generation Phishing: How LLM Agents Empower Cyber Attackers](https://arxiv.org/abs/2411.13874): Analyzes offensive phishing agents that generate and refine attack emails, exposing how autonomous writing loops can scale social-engineering campaigns.
- [HackSynth](https://arxiv.org/abs/2412.01778) ([open-source code](https://github.com/aielte-research/HackSynth)): A CTF and penetration-testing harness with planning, tool execution, and benchmark-runner components for reproducible cyber-agent experiments.
- [Large Multimodal Agents for Accurate Phishing Detection with Enhanced Token Optimization and Cost Reduction](https://arxiv.org/abs/2412.02301): Uses multimodal agents to inspect email text and visual cues for phishing while optimizing token usage and cost in the detection pipeline.
- [SpearBot: Leveraging Large Language Models in a Generative-Critique Framework for Spear-Phishing Email Generation](https://arxiv.org/abs/2412.11109): Uses a generation-and-critique loop to craft spear-phishing emails, modeling how an attacker agent can iteratively improve social-engineering content.
- [Large Language Model guided Protocol Fuzzing](https://doi.org/10.14722/ndss.2024.24556): Guides protocol fuzzing with LLM-derived message-format and state-machine hints, connecting natural-language protocol knowledge to executable fuzz inputs.
- [Generative AI Enabled Actionable Decision Support in Cyber Security Operations for Enterprise Security](https://doi.org/10.23919/ituk62727.2024.10772892): Turns enterprise-security telemetry into actionable SOC decision support, emphasizing triage, recommendation, and analyst-facing explanation rather than raw alert scoring.
- [Leveraging Multimodal Retrieval-Augmented Generation for Cyber Attack Detection in Transit Systems](https://doi.org/10.1109/tps-isa62245.2024.00046): Combines multimodal transit-system evidence with retrieval-augmented generation to detect cyberattacks against operational transportation environments.
- [LLMSmartSec: Smart Contract Security Auditing with LLM and Annotated Control Flow Graph](https://doi.org/10.1109/blockchain62396.2024.00064): Feeds annotated control-flow graphs into LLM-based smart-contract auditing so vulnerability reasoning is grounded in contract execution structure.
