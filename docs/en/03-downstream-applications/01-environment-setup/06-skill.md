# 3.1.6 Skill

- [docker-configuration-validator](https://skills.sh/rknall/claude-skills/docker-configuration-validator) is suitable for first checking Dockerfile / compose configuration.
- [docker-containerization](https://skills.sh/ailabs-393/ai-labs-claude-skills/docker-containerization) is suitable for quick containerization.
- [devcontainer-helper](https://skills.sh/gabeosx/agent-skills/devcontainer-helper) is suitable for standardizing local development environments.
- [package-managing](https://skills.sh/ingpdw/pdw-python-dev-tool/package-managing) is suitable for dependency installation and version governance.
- [error-recovery](https://skills.sh/zpankz/mcp-skillset/error-recovery) is suitable for repair loops after environment startup fails.
- [multi-stage-dockerfile](https://skills.sh/github/awesome-copilot/multi-stage-dockerfile) is suitable for generating reproducible and trim multi-stage Dockerfiles, mitigating large images, unstable dependencies, and slow builds.
- [devcontainer-setup](https://skills.sh/shipshitdev/library/devcontainer-setup) is suitable for solidifying repository environments into reusable devcontainer configuration, with emphasis on monorepo mounting and port mapping.
- [devcontainer-setup](https://skills.sh/trailofbits/skills/devcontainer-setup) is suitable for packaging multilingual toolchains together with Claude Code into a devcontainer, with emphasis on safety and engineering.
- [python-dependency-resolver](https://skills.sh/jorgealves/agent_skills/python-dependency-resolver) is suitable for locating pip version conflicts, circular dependencies, and inconsistent constraints.
- [python-uv](https://skills.sh/mindrally/skills/python-uv) is suitable for uv-first Python project setup, lockfile repair, and dependency workflow standardization, filling a gap between generic pip repair and full Docker/devcontainer setup.
- [python-packaging](https://skills.sh/wshobson/agents/python-packaging) is suitable for pyproject, build-backend, wheel, package metadata, and dependency layout fixes in repository setup tasks.
- [docker-compose-orchestration](https://skills.sh/manutej/luxor-claude-marketplace/docker-compose-orchestration) is suitable for multi-service compose environments, especially for setup benchmarks where databases, workers, and application services must start together.
- [ARIS experiment-support skills](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/tree/main/skills) such as `experiment-queue`, `run-experiment`, `vast-gpu`, `serverless-modal`, and `system-profile` cover queued experiment execution, remote GPU/cloud execution, and system profiling for research-code setup loops.
- [flonat python-env](https://github.com/flonat/claude-research/tree/main/skills/python-env) is suitable for academic Python project environments, virtual environment checks, dependency sanity checks, and run-before-experiment hygiene.
- [install-script-generator](https://skills.sh/luongnv89/skills/install-script-generator) is suitable for generating one-command cross-platform installation scripts.
- [repo-runner](https://clawhub.ai/zyl-hub/repo-runner) is suitable for starting projects according to repository documentation with risk guardrails, closer to a runbook/execution assistant.
