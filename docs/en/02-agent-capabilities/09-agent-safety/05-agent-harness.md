# 2.9.5 Agent Harness

- [ToolEmu](https://arxiv.org/abs/2309.15817): An LM-emulated sandbox for identifying risks in tool-using language-model agents. Core idea: emulate tool execution so risky behaviors can be evaluated without granting the agent real external authority.
- [Formal Agent Specs](https://arxiv.org/abs/2310.08535): A declarative specification and monitoring harness for high-level agent behavior. Core idea: describe allowed agent behavior as formal expectations and check trajectories against them during execution.
- [SPADE: Synthesizing Assertions for Large Language Model Pipelines](https://arxiv.org/abs/2401.03038): Synthesizes data-quality assertions from prompt version histories, then selects a compact assertion set for catching bad LLM pipeline outputs before deployment.
- [Combating Adversarial Attacks with Multi-Agent Debate](https://arxiv.org/abs/2401.05998): Runs multiple models in debate so a non-jailbroken or stronger model can challenge toxic outputs from a compromised model, then analyzes adversarial prompt topics with embedding clustering.
- [Formal-LLM: Integrating Formal Language and Natural Language for Controllable LLM-based Agents](https://arxiv.org/abs/2402.00798): Places a formal-language layer between natural-language goals and agent plans, using formal constraints to make multi-step LLM-agent execution more controllable.
- [TrustAgent: Towards Safe and Trustworthy LLM-based Agents](https://arxiv.org/abs/2402.01586): Enforces an Agent Constitution through pre-planning safety knowledge injection, in-planning guidance, and post-planning inspection of risky actions.
- [Secret Collusion among AI Agents: Multi-Agent Deception via Steganography](https://arxiv.org/abs/2402.07510): Formalizes secret multi-agent collusion as steganographic communication, measuring when agents can hide coordination from monitors and where paraphrasing or monitoring defenses break down.
- [Pandora: Jailbreak GPTs by Retrieval Augmented Generation Poisoning](https://arxiv.org/abs/2402.08416): Attacks custom GPT-style RAG agents by poisoning retrieved knowledge so indirect jailbreak instructions enter the agent through its retrieval channel rather than the user prompt.
- [Agent Smith: A Single Image Can Jailbreak One Million Multimodal LLM Agents Exponentially Fast](https://arxiv.org/abs/2402.08567): A multi-agent adversarial simulation harness for infectious jailbreaks. Core idea: place adversarial images into one agent's memory and measure how pairwise communication spreads unsafe behavior across very large MLLM-agent populations.
- [AuditLLM: A Tool for Auditing Large Language Models Using Multiprobe Approach](https://arxiv.org/abs/2402.09334): A multiprobe auditing harness for LLM safety. Core idea: run coordinated probes over target models and aggregate vulnerability evidence rather than relying on a single prompt or one-off manual check.
- [LLMAuditor: A Framework for Auditing Large Language Models Using Human-in-the-Loop](https://arxiv.org/abs/2402.09346): A human-in-the-loop auditing workflow for LLM safety. Core idea: combine automated probes with reviewer feedback so risk findings can be validated and refined before deployment decisions.
- [A Trembling House of Cards? Mapping Adversarial Attacks against Language Agents](https://arxiv.org/abs/2402.10196): parent-routing-needed: a taxonomy and mapping study of adversarial attacks on language agents, useful as survey coverage rather than a reusable runtime harness.
- [AutoDefense: Multi-Agent LLM Defense against Jailbreak Attacks](https://arxiv.org/abs/2403.04783): A multi-agent jailbreak-defense loop. Core idea: use defender and attacker agents to iteratively inspect, challenge, and revise risky responses so harmful outputs are blocked before release.
- [IsolateGPT: An Execution Isolation Architecture for LLM-Based Agentic Systems](https://arxiv.org/abs/2403.04960): An execution-isolation architecture for LLM app ecosystems. Core idea: isolate third-party apps, user data, and natural-language component interactions so untrusted apps cannot freely exchange authority or private state.
- [AdaShield: Safeguarding Multimodal Large Language Models from Structure-based Attack via Adaptive Shield Prompting](https://arxiv.org/abs/2403.09513): A prompt-level defense layer for MLLMs under structure-based attacks. Core idea: adapt shield prompts to attack patterns so multimodal safety checks run before unsafe visual-language outputs are accepted.
- [AEGIS: Online Adaptive AI Content Safety Moderation with Ensemble of LLM Experts](https://arxiv.org/abs/2404.05993): An online moderation harness with an ensemble of LLM safety experts. Core idea: route content through adaptive specialist judges so policy enforcement can adjust to emerging harmful-content patterns.
- [CulturalTeaming: AI-Assisted Interactive Red-Teaming for Challenging LLMs' (Lack of) Multicultural Knowledge](https://arxiv.org/abs/2404.06664): An interactive red-teaming workflow for multicultural safety gaps. Core idea: pair human testers with AI assistance to generate culture-specific probes and record failure cases beyond generic safety prompts.
- [Concept-Guided LLM Agents for Human-AI Safety Codesign](https://arxiv.org/abs/2404.15317): A concept-guided codesign harness for safety-critical human-AI workflows. Core idea: use LLM agents to organize safety concepts and scenarios so human stakeholders can review hazards and mitigation options.
- [Towards Guaranteed Safe AI: A Framework for Ensuring Robust and Reliable AI Systems](https://arxiv.org/abs/2405.06624): parent-routing-needed: a broad safe-AI framework and assurance agenda, closer to survey or methodology coverage than a concrete agent runtime harness.
- [ATM: Adversarial Tuning Multi-agent System Makes a Robust Retrieval-Augmented Generator](https://arxiv.org/abs/2405.18111): A multi-agent adversarial tuning loop for robust RAG. Core idea: coordinate attack and defense agents around retrieval-augmented generation so adversarial examples harden the generator against poisoned or misleading evidence.
- [GuardAgent](https://arxiv.org/abs/2406.09187): A guard-agent framework for knowledge-enabled safety checking. Core idea: inspect agent plans and actions before tool or API execution so unsafe operations can be caught outside the task agent's own reasoning loop.
- [TorchOpera: A Compound AI System for LLM Safety](https://arxiv.org/abs/2406.10847): A compound-system safety harness for LLM applications. Core idea: orchestrate multiple safety components around generation so detection, critique, and mitigation can be composed instead of embedded in one model call.
- [garak: A Framework for Security Probing Large Language Models](https://arxiv.org/abs/2406.11036): A model-agnostic red-teaming and assessment toolkit. Core idea: run structured probes against LLMs or dialog systems and report discovered vulnerabilities as reusable security evidence.
- [AgentDojo](https://arxiv.org/abs/2406.13352) ([open-source code](https://github.com/ethz-spylab/agentdojo); [project page](https://agentdojo.spylab.ai/)): A tool-agent security evaluation harness for indirect prompt injection, with reproducible suites, task utilities, attacks, and defense comparisons.
- [Poisoned LangChain: Jailbreak LLMs by LangChain](https://arxiv.org/abs/2406.18122): A LangChain workflow attack harness. Core idea: poison agent-chain components so jailbreak instructions propagate through tool and chain execution rather than only through the user's direct prompt.
- [RedAgent: Red Teaming Large Language Models with Context-aware Autonomous Language Agent](https://arxiv.org/abs/2407.16667): A context-aware autonomous red-teaming agent. Core idea: observe target responses, adapt attack plans, and search jailbreak strategies in a closed loop instead of replaying fixed prompt lists.
- [Fuzz-Testing Meets LLM-Based Agents: An Automated and Efficient Framework for Jailbreaking Text-to-Image Generation Models](https://arxiv.org/abs/2408.00523): A fuzz-testing red-team harness for text-to-image safety. Core idea: let an LLM-based agent mutate prompts and triage model feedback to discover jailbreaks more efficiently than manual prompt search.
- [Compromising Embodied Agents with Contextual Backdoor Attacks](https://arxiv.org/abs/2408.02882): An embodied-agent backdoor evaluation harness. Core idea: inject contextual triggers into the agent's environment or observations and test whether policy execution shifts to attacker-chosen behavior.
- [Casper: Prompt Sanitization for Protecting User Privacy in Web-Based Large Language Models](https://arxiv.org/abs/2408.07004): A browser-side prompt-sanitization privacy guard. Core idea: rewrite or mask sensitive prompt content before it reaches web-hosted LLM services, reducing personal-data exposure at runtime.
- [A Multi-LLM Debiasing Framework](https://arxiv.org/abs/2409.13884): A multi-model debiasing workflow. Core idea: use several LLMs as reviewers or generators to detect biased candidates and select safer alternatives before final output.
- [PathSeeker: Exploring LLM Security Vulnerabilities with a Reinforcement Learning-Based Jailbreak Approach](https://arxiv.org/abs/2409.14177): A reinforcement-learning jailbreak search harness. Core idea: train an attacker policy against model feedback so security testing explores vulnerability paths beyond handcrafted prompts.
- [HAICOSYSTEM](https://arxiv.org/abs/2409.16427): A sandbox ecosystem for multi-turn human-agent tool interactions. Core idea: provide configurable domains, tools, and risk settings so social, legal, operational, and safety failures in tool-equipped interactions can be reproduced.
