# 1.10.6 Skill

- [long-context](https://github.com/davila7/claude-code-templates/tree/main/cli-tool/components/skills/ai-research/emerging-techniques-long-context) directly targets long-context compression, summarization, and retrieval organization.
- [long-context](https://skills.sh/davila7/claude-code-templates/long-context) is suitable for summarization, compression, and retrieval organization under long context.
- [context-compression](https://skills.sh/sickn33/antigravity-awesome-skills/context-compression) is suitable for context pruning under high token pressure.
- [token-saver-context-compression](https://skills.sh/oimiragieo/agent-studio/token-saver-context-compression) is suitable for context compression with budget constraints as the goal.
- [ai-rag-pipeline](https://skills.sh/inferen-sh/skills/ai-rag-pipeline) turns long-document handling into an explicit retrieval pipeline with ingestion, chunking, indexing, and answer synthesis stages.
- [langchain-rag](https://skills.sh/langchain-ai/langchain-skills/langchain-rag) anchors long-context work in LangChain retrieval primitives, making document loading, vector retrieval, and grounded response generation maintainable.
- [agent-context-loader](https://skills.sh/jeremylongshore/claude-code-plugins-plus-skills/agent-context-loader) is suitable for loading repository or document context in batches.
- [gemini](https://skills.sh/zpankz/mcp-skillset/gemini) belongs to the "long-window delegation/external execution" class of skills: it delegates long-context tasks to a large-window model, leaning toward a harness-level external execution strategy.
