# 2.5.3 Bench

- [WebArena](https://arxiv.org/abs/2307.13854) ([open-source code](https://github.com/web-arena-x/webarena)): Evaluates autonomous web agents on task completion in realistic, reproducible websites. Core idea: package full web applications such as e-commerce, forums, GitLab, and maps into resettable environments, and evaluate web operations by final state rather than textual answers alone.
- [VisualWebArena](https://arxiv.org/abs/2401.13649) ([open-source code](https://github.com/web-arena-x/visualwebarena)): Evaluates multimodal web agents. Core idea: add tasks that depend on images, layouts, and visual cues to WebArena-style realistic sites, testing whether agents can combine screenshot understanding with DOM/text information.
- [OSWorld / OSWorld-Verified](https://arxiv.org/abs/2404.07972): A general benchmark for desktop computer use. Core idea: abstract real operating-system tasks into a reproducible observe-act-verify loop; the official leaderboard maintains both original tasks and verified trajectories/subsets.
- [AndroidWorld](https://arxiv.org/abs/2405.14573) ([open-source code](https://github.com/google-research/android_world)): Evaluates task completion and generalization for mobile GUI agents. Core idea: use real Android emulators and dynamically instantiated tasks to standardize phone operation as an executable benchmark.
- [WindowsAgentArena](https://arxiv.org/abs/2409.08264) ([ICML 2025 paper](https://proceedings.mlr.press/v267/bonatti25a.html), [open-source code](https://github.com/microsoft/WindowsAgentArena)): Evaluates GUI agents and skill combinations in the Windows ecosystem. Core idea: make real desktop tasks reproducible, replayable, and automatically comparable in a unified environment.
- [A3](https://arxiv.org/abs/2501.01149) ([open-source code](https://github.com/YuxiangChai/A3)): Evaluates whether mobile GUI agents reach key states in real Android tasks. Core idea: use essential-state procedural evaluation to avoid the brittleness of judging only final screenshots or static apps, and directly check state transitions that must occur during the task.
- [WorldGUI](https://arxiv.org/abs/2502.08047) ([open-source code](https://github.com/showlab/WorldGUI)): Evaluates desktop GUI agents' automation ability when starting from arbitrary intermediate states. Core idea: include common real-user "half-finished/non-default interface" states as task initial states, testing planning and recovery rather than only standard starting points.
- [MM-BrowseComp](https://arxiv.org/abs/2502.14595): Evaluates multimodal browsing and information acquisition, including GUI/web interaction. Core idea: put "look, click, read, write" into one executable and scoreable trajectory.
- [BEARCUBS](https://arxiv.org/abs/2503.07919) ([project page](https://bear-cubs.github.io/)): Evaluates computer-using web agents on information seeking, browsing, and multimodal interaction on the live web. Core idea: use continuously changing real web content, video understanding, and 3D navigation tasks to prevent pure-text retrieval from bypassing real web operation.
- [ScreenSpot-Pro](https://arxiv.org/abs/2504.07981): Evaluates GUI grounding on professional high-resolution screenshots. Core idea: require models to locate tiny UI targets from natural-language instructions, stressing high-resolution perception and precise coordinate grounding rather than only task-level success.
- [RealWebAssist](https://arxiv.org/abs/2504.10445) ([open-source code](https://github.com/SCAI-JHU/RealWebAssist)): Evaluates long-horizon web assistance for real users. Core idea: organize ambiguous, changing, and staged-confirmation user requests into sequential tasks, covering real assistance scenarios that one-shot web benchmarks miss.
- [REAL](https://arxiv.org/abs/2504.11543) ([open-source code](https://github.com/agi-inc/REAL)): Evaluates autonomous agents on deterministic simulations of real websites. Core idea: use high-fidelity replicas of common web services with practical multi-turn tasks, preserving realistic browser interaction while making reset, grading, and safety control reproducible.
- [TurkingBench](https://aclanthology.org/2025.naacl-long.188/) ([project page](https://github.com/turkingbench/turkingbench.github.io)): Evaluates web agents on crowdsourcing-style web tasks. Core idea: use human-task websites and multimodal contexts to test whether web agents can follow realistic task instructions rather than only navigate fixed demo sites.
- [OSUniverse](https://arxiv.org/abs/2505.03570) ([open-source code](https://github.com/agentsea/osuniverse)): Evaluates complex, multimodal, desktop-oriented GUI navigation tasks. Core idea: use real cross-application and cross-modal desktop tasks to add a combined stress test of visual understanding, tool choice, and long-chain navigation after OSWorld.
- [OSWorld-G](https://arxiv.org/abs/2505.13227) ([open-source code](https://github.com/xlang-ai/osworld-g), [dataset](https://huggingface.co/datasets/xlangai/Jedi)): Evaluates GUI grounding for computer-use agents. Core idea: decompose and synthesize UI interaction data so grounding requires software commonsense, layout understanding, and fine-grained manipulation rather than short referring-expression localization.
- [RedTeamCUA / RTC-Bench](https://arxiv.org/abs/2505.21936) ([project page](https://osu-nlp-group.github.io/RedTeamCUA)): Evaluates indirect prompt-injection risks for computer-use agents in hybrid Web-OS environments. Core idea: use real GUI/web action spaces and red-team examples to expose the attack surface of cross-application execution.
- [WebChoreArena](https://arxiv.org/abs/2506.01952) ([open-source code](https://github.com/WebChoreArena/WebChoreArena)): Evaluates web agents on tedious and complex web tasks. Core idea: turn web chores that humans also find repetitive, branching, and error-prone into executable benchmarks, amplifying robustness and patient execution problems.
- [VPI-Bench](https://arxiv.org/abs/2506.02456) (dataset: [VPI-Bench/vpi-bench](https://huggingface.co/datasets/VPI-Bench/vpi-bench)): Evaluates the safety of computer-use/browser-use agents under visual prompt-injection attacks. Core idea: embed malicious instructions into visual web content and test whether agents mistake on-screen text for user instructions.
- [GUI-Robust](https://arxiv.org/abs/2506.14477) ([open-source code](https://github.com/chessbean1/GUI-Robust)): Evaluates GUI-agent robustness under realistic abnormal situations. Core idea: add occlusion, accidental touches, pop-ups, and environmental anomalies to normal GUI trajectories, observing whether agents can recover from non-ideal interface states.
- [OS-Harm](https://arxiv.org/abs/2506.14866) ([open-source code](https://github.com/tml-epfl/os-harm)): Evaluates computer-use agent safety in operating-system tasks. Core idea: build on OSWorld to cover malicious user requests, prompt injection, and model misbehavior, checking whether agents perform dangerous actions in email, browsers, code editors, and other applications.
- [OSWorld-Human](https://arxiv.org/abs/2506.16042) ([OSWorld-Human Efficiency Leaderboard](https://github.com/WukLab/osworld-human); [open-source code](https://github.com/WukLab/osworld-human)): Evaluates computer-use agent efficiency against human reference trajectories. Core idea: add human-annotated trajectories to OSWorld and use metrics such as weighted excess steps to distinguish "can complete" from "completes in reasonable steps."
- [UI-Vision](https://proceedings.mlr.press/v267/nayak25a.html) ([open-source code](https://github.com/uivision/UI-Vision)): Evaluates desktop-centric GUI visual perception and interaction. Core idea: isolate GUI perception and element-understanding bottlenecks that can limit action-heavy desktop agents even when the high-level plan is correct.
- [AndroidLab](https://aclanthology.org/2025.acl-long.107/): Evaluates Android autonomous agents under a systematic multimodal framework. Core idea: unify environment, action space, training, and benchmark protocols so mobile agents can be compared beyond ad hoc app-operation tasks.
- [TransBench](https://aclanthology.org/2025.findings-acl.645/): Evaluates transferability of GUI agents in dynamic digital environments. Core idea: stress grounding and execution across changing, connected platforms rather than assuming a single frozen app state.
- [CRAB](https://aclanthology.org/2025.findings-acl.1113/): Evaluates multimodal language-model agents across websites, desktops, and mobile environments. Core idea: provide a cross-environment benchmark with graph-based fine-grained evaluation so GUI-agent progress is not tied to one interface family.
- [MMBench-GUI](https://arxiv.org/abs/2507.19478) ([open-source code](https://github.com/open-compass/MMBench-GUI)): Evaluates cross-platform GUI agents across Windows, macOS, Linux, iOS, Android, and Web. Core idea: evaluate GUI content understanding, element grounding, task automation, and task collaboration in layers, and measure execution redundancy with an efficiency-quality area metric.
- [FineState-Bench](https://arxiv.org/abs/2508.09241) ([open-source code](https://github.com/AnonymousThewarehouse/FineState-Bench), [dataset](https://huggingface.co/datasets/Willtime2006/Static-FineBench)): Evaluates fine-grained state control for GUI agents. Core idea: split perception, grounding, operation, and state achievement into multi-stage metrics to expose fine control and visual grounding bottlenecks in real GUI operation.
- [SCUBA](https://arxiv.org/abs/2509.26506) ([open-source code](https://github.com/SalesforceAIResearch/SCUBA)): Evaluates computer-use ability in Salesforce enterprise software. Core idea: place CRM-style forms, records, permissions, and business objects into real enterprise GUI tasks, emphasizing state consistency and business-rule following in professional SaaS operation.
- [UINavBench](https://openaccess.thecvf.com/content/ICCV2025/html/Agrawal_UINavBench_A_Framework_for_Comprehensive_Evaluation_of_Interactive_Digital_Agents_ICCV_2025_paper.html): Evaluates interactive digital agents on mobile-interface navigation. Core idea: provide a comprehensive framework for task execution in UI environments, making navigation and action grounding measurable beyond static screenshot pointing.
- [BrowserArena](https://arxiv.org/abs/2510.02418): Evaluates web-agent navigation on the real open web. Core idea: collect user-submitted live web tasks and use arena-style comparison plus stepwise human feedback to identify real web failure modes such as captchas, pop-ups, and direct URL navigation.
- [MLLM as a UI Judge](https://arxiv.org/abs/2510.08783): Evaluates whether multimodal LLMs can predict human perception of user interfaces. Core idea: turn UI quality and perception judgments into a benchmark signal for interface understanding beyond element grounding or task completion.
- [OSWorld-MCP](https://arxiv.org/abs/2510.24563) ([project page](https://osworld-mcp.github.io/)): Evaluates computer-use agents' ability to call MCP tools beyond GUI operation. Core idea: introduce 158 MCP tools across common applications in realistic OSWorld-style environments, while reporting task accuracy, tool invocation rate, and average completion steps.
- [MobileWorld](https://arxiv.org/abs/2512.19432) ([open-source code](https://github.com/Tongyi-MAI/MobileWorld)): Evaluates autonomous mobile agents in agent-user interaction and MCP-augmented environments. Core idea: put mobile GUI operation, user clarification, and external tool calls into one benchmark, extending AndroidWorld's static task boundary.
- [macOSWorld](https://openreview.net/forum?id=YJxGJP8feU) ([project page](https://macos-world.github.io/), [open-source code](https://github.com/showlab/macosworld)): Evaluates interactive GUI agents on macOS. Core idea: cover multilingual tasks across native applications, adding an OS family and app ecosystem not represented by Windows- or Ubuntu-centered benchmarks.
- [D-GARA](https://ojs.aaai.org/index.php/AAAI/article/view/38795): Evaluates GUI-agent robustness under dynamic real-world anomalies. Core idea: turn anomaly handling into the benchmark itself, testing whether agents recover from interface disruptions rather than only completing ideal-path tasks.
- [OS-Marathon](https://arxiv.org/abs/2601.20650) ([project page](https://os-marathon.github.io/)): Evaluates long-horizon repetitive GUI tasks for computer-use agents. Core idea: require agents to maintain pace, memory, and error recovery across long-running, repetitive desktop operations whose state accumulates over time.
- [MemGUI-Bench](https://arxiv.org/abs/2602.06075) ([open-source code](https://github.com/lgy0404/MemGUI-Bench)): Evaluates memory in mobile GUI agents. Core idea: use cross-session, cross-application, and dynamic-environment tasks to specifically test memory retention and cross-session learning.
- [AgenticShop](https://arxiv.org/abs/2602.12315): Evaluates personalized product curation on the open web. Core idea: require agents to browse noisy e-commerce information, infer user preferences, and produce verifiable shopping recommendations rather than only navigate a fixed site.
- [TimeWarp](https://arxiv.org/abs/2603.04949): Evaluates web-agent robustness to changing websites. Core idea: replay tasks across containerized historical UI, design, and layout variants so agents cannot rely on one frozen webpage version.
- [OSExpert-Eval](https://arxiv.org/abs/2603.07978): Evaluates whether computer-use agents can perform professional GUI skills efficiently. Core idea: compare agents with expert-like task decomposition and fine-grained action requirements, exposing slow transfer and inefficient exploration on unfamiliar interfaces.
- [CUA-Suite / VideoCUA](https://arxiv.org/abs/2603.24440): Provides large-scale human video demonstrations and dense annotations for computer-use agents. Core idea: evaluate and train desktop agents from continuous professional workflow videos rather than sparse screenshots alone.
- [OS-Blind](https://arxiv.org/abs/2604.10577) ([project page](https://limenlp.github.io/OS_Blind/)): Evaluates CUA safety blind spots where user instructions are harmless but the execution context may be harmful. Core idea: make harm come from environmental state or execution consequences, requiring agents to proactively identify risk before GUI actions.
- [OS-SPEAR](https://arxiv.org/abs/2604.24348): Evaluates OS agents across safety, performance, efficiency, and robustness. Core idea: provide a toolkit for analyzing OS-agent trajectories and failure types rather than only reporting final task success.
- [Odysseys](https://arxiv.org/abs/2604.24964) ([project page](https://odysseys-website.pages.dev/)): Evaluates real long-horizon GUI tasks for web agents. Core idea: use multi-stage goals and state dependencies on real websites to test navigation, information integration, error recovery, and sustained execution.
- [WindowsWorld](https://arxiv.org/abs/2604.27776): Evaluates cross-application GUI workflows on Windows. Core idea: make multi-application, multi-checkpoint professional workflows explicit, amplifying failures in cross-application coordination and staged verification.
- [SaaS-Bench](https://arxiv.org/abs/2605.15777) ([open-source code](https://github.com/UniPat-AI/SaaS-Bench)): Evaluates professional workflows in real SaaS systems. Core idea: place deployable multi-application business workflows, checkpoint validation, and long-chain state maintenance into self-hosted SaaS environments.
