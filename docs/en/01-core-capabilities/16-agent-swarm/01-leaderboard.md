# 1.16.1 Leaderboard

- [GAMA-Bench](https://cuhk-arise.github.io/GAMABench/): The official leaderboard for evaluating LLM gaming ability in multi-agent environments, focused on decision-making under interactive game dynamics.
- [MuMA-ToM](https://scai.cs.jhu.edu/projects/MuMA-ToM/leaderboard.html): The official leaderboard for multimodal multi-agent theory-of-mind evaluation.
- [MAPF Arena](https://mapf.dev/leaderboard): A widely used public leaderboard for multi-agent path finding, useful as task-level context for path-finding benchmarks even when an LLM-specific paper has no separate official board.
