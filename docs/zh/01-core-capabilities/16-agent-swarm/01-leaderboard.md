# 1.16.1 Leaderboard

- [GAMA-Bench](https://cuhk-arise.github.io/GAMABench/)：官方榜单评测 LLM 在多智能体游戏环境中的决策能力，重点关注交互式博弈动态下的决策表现。
- [MuMA-ToM](https://scai.cs.jhu.edu/projects/MuMA-ToM/leaderboard.html)：官方榜单评测多模态多智能体 theory-of-mind 能力。
- [MAPF Arena](https://mapf.dev/leaderboard)：广泛使用的多智能体路径规划公开榜单；当 LLM 专项论文没有单独官方榜单时，可作为 path-finding 任务层面的参考。
