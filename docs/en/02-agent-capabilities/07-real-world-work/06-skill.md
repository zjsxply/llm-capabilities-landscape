# 2.7.6 Skill

- [Data Product MCP](https://arxiv.org/abs/2601.08687): An MCP-style interface for chatting with enterprise data products, relevant as reusable tool infrastructure for data-analysis agents.
- [travel-planner](https://skills.sh/ailabs-393/ai-labs-claude-skills/travel-planner) is closest to `WorldTravel`.
- [implementation-planner](https://skills.sh/jumppad-labs/jumppad/implementation-planner) is suitable for decomposing real work into executable multi-stage plans.
- [ocr-document-processor](https://skills.sh/dkyazzentwatwa/chatgpt-skills/ocr-document-processor) is suitable for `information extraction / document processing`.
- [train-fasttext](https://skills.sh/letta-ai/skills/train-fasttext) exposes a small supervised-text-classification path around fastText training, evaluation, and prediction artifacts.
- [tapestry](https://skills.sh/nicepkg/ai-workflow/tapestry) stitches cross-system tool calls into business-process workflows with explicit handoffs between services and intermediate artifacts.
- [minimax-xlsx](https://github.com/MiniMax-AI/skills/tree/main/skills/minimax-xlsx) is suitable for spreadsheet-style real work: reading, cleaning, analyzing, and generating `.xlsx` artifacts.
- [minimax-docx](https://github.com/MiniMax-AI/skills/tree/main/skills/minimax-docx) is suitable for office-document real work: generating/editing `.docx` reports, contract drafts, and structured materials.
- [pptx-generator](https://github.com/MiniMax-AI/skills/tree/main/skills/pptx-generator) is suitable for turning real-work outputs into deliverable `.pptx` presentations.
- [minimax-pdf](https://github.com/MiniMax-AI/skills/tree/main/skills/minimax-pdf) adds PDF parsing, information extraction, and structured citation handling to office-style real-work pipelines.
- [shanyin-screenwriting-master](https://github.com/Shanyin-ai/shanyin-screenwriting-master) is suitable for creative real-work deliverables in film and video production, covering short films, feature-film outlines, multi-episode series, character design, scene breakdowns, and standard screenplay formatting.
- [ppt-master](https://github.com/hugohe3/ppt-master) generates editable PowerPoint deliverables from source documents, emphasizing native shapes, text boxes, charts, and animations rather than slide-image export.
