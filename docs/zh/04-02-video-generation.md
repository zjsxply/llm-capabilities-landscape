# 4.2 视频生成模型

> 上级章节：4. 多模态

说明：本页收纳视频、音视频、动画、3D 场景、编辑以及动态 world model 生成相关评测与编排 harness。被动视频理解仍保留在 [1.6 视频](01-06-video.md)。

## 4.2.1 Bench

- [VBench++](https://doi.org/10.1109/TPAMI.2025.3633890)：面向视频生成模型的综合评测套件。核心思路是系统组织生成视频的质量、一致性、运动和提示对齐等指标，使视频生成系统的比较不局限于单一偏好测试。
- [T2VEval](https://arxiv.org/abs/2501.08545)：用 benchmark dataset 与客观评价方法评估 text-to-video generation。核心思想：提供结构化 prompt、生成视频样本与自动指标，使 T2V 质量比较不只依赖临时偏好判断。
- [VE-Bench](https://doi.org/10.1609/aaai.v39i7.32763)：评测文本驱动视频编辑质量，并对齐主观评价。核心思想：用贴近人类偏好的维度衡量编辑后视频，使视频编辑系统不只依赖低层指标，而能同时比较感知质量和指令一致性。
- [Physical Coherence Benchmark](https://arxiv.org/abs/2502.05503)：通过 optical-flow-guided frame prediction 评估生成视频的物理一致性。核心思想：用运动一致性信号暴露生成动态中的物理不合理之处，而不只评价单帧外观。
- [VidCapBench](https://arxiv.org/abs/2502.12782)：评什么：面向可控文本生成视频的视频描述能力。核心思想：检验 caption 是否捕捉会影响提示构造和生成评估的可控属性。
- [WorldModelBench](https://arxiv.org/abs/2502.20694)：评测视频生成模型是否具备可用 world model 能力。核心思想：用人工标注的 violation 和学习型评判器测试指令遵循与物理一致性，面向机器人和自动驾驶等应用域。
- [GRADEO](https://arxiv.org/abs/2503.02341)：用多步推理评估文本到视频生成。核心思想：把视频质量判断拆成推理步骤，使评估更接近人类判断，而不是只依赖表层自动指标。
- [VideoPhy-2](https://arxiv.org/abs/2503.06800)：评什么：生成视频中的动作中心物理常识。核心思想：用多样真实动作、人工评审和自动评测检查视频生成模型是否保持物理上合理的动态，而不只是画面外观。
- [AIGVE-Tool](https://arxiv.org/abs/2503.14064)：用多维 benchmark 工具包评估 AI 生成视频。核心思想：结合多类视频质量与提示对齐指标，使生成视频评估不再依赖单一分数。
- [SceneEval](https://arxiv.org/abs/2503.14756)：评测文本条件 3D 室内场景合成的语义一致性。核心思想：检查生成场景是否满足提示词隐含的空间、物体关系和布局语义。
- [ETVA](https://arxiv.org/abs/2503.16867)：通过细粒度问题生成与回答评估文本到视频对齐。核心思路是把提示拆成原子检查点，从而定位语义对齐错误，而不是只给出粗粒度总分。
- [3DGen-Bench](https://arxiv.org/abs/2503.21745)：通过综合 benchmark suite 评估 3D 生成模型。核心思想：从视觉、几何与语义等维度比较生成 3D 内容，避免把 3D 生成质量压缩成单一感知分数。
- [WorldScore](https://arxiv.org/abs/2504.00983)：提供统一的世界生成评测基准。核心思路是从任务相关的一致性与动力学角度比较生成世界，使世界生成质量能够面向下游具身应用进行衡量。
- [Video-Bench](https://arxiv.org/abs/2504.04907)：评测视频生成的人类偏好对齐。核心思想：用人类偏好和质量判断补充单纯自动指标，比较生成视频是否符合真实观看标准。
- [FingER](https://arxiv.org/abs/2504.10358)：评什么：带内容感知和细粒度推理的 AI 生成视频评估。核心思想：通过围绕视频内容的可解释推理来检查生成质量，而不是只依赖整体感知分数。
- [Eval3D](https://arxiv.org/abs/2504.18509)：用细粒度、可解释的视觉、几何和语义标准评估生成式 3D 资产，补足面向 3D 生成的空间一致性评测。
- [T2VPhysBench](https://arxiv.org/abs/2505.00337)：评测文本到视频生成的物理一致性。核心思想：从第一性原理约束出发，把物理规律和动态过程的违背转成可诊断的视频生成指标。
- [T2VTextBench](https://arxiv.org/abs/2505.04946)：评什么：文本生成视频中的文字控制能力。核心思想：通过人工评估屏幕文字保真度和时间一致性，暴露通用视频质量指标容易忽略的失败。
- [EWMBench](https://arxiv.org/abs/2505.09694)：从场景一致性、运动正确性和语义对齐评测 embodied world model。核心思想：用 curated dataset 和评测工具检查生成动态是否满足具身任务所需的物理 grounding 与动作一致性。
- [LOVE](https://arxiv.org/abs/2505.12098)：评估文生视频和视频到文本解释。核心思路：在统一协议下比较视频语言对齐的两个方向，同时观察生成质量和可解释性。
- [CineTechBench](https://arxiv.org/abs/2505.15145)（[开源代码](https://github.com/PRIS-CV/CineTechBench)，[数据集](https://huggingface.co/datasets/Xinran0906/CineTechBench)）：评什么：电影摄影技术理解与生成。核心思想：用专家标注的镜头运动、构图、布光等电影技法，测试视频与生成模型是否能理解工艺级视觉语言，而不只是识别事件。
- [TDVE-Assessor](https://arxiv.org/abs/2505.19535)：用 LMM 评估文本驱动视频编辑质量的基准。核心思路是结合 TDVE-DB、人类评分以及编辑后视频质量、编辑对齐和结构一致性等维度来评价编辑结果。
- [OpenS2V-Nexus](https://arxiv.org/abs/2505.20292)：评测 subject-to-video 生成，并配套大规模数据集。核心思想：检验模型在生成连续视频时能否保持参考主体的一致性。
- [AIGC-LipSync Benchmark / OmniSync](https://arxiv.org/abs/2505.21448)：评估多样 AI 生成视频中的唇形同步。核心思路是测试音频驱动编辑在真实、风格化与 AI 生成视频场景中是否同时保持身份、视觉质量和准确的口型音频对齐。
- [RealVideoQuest](https://arxiv.org/abs/2506.01689)：评估面向真实用户意图的视频生成式回答。核心思路是从真实用户交互中提取需要视频回答的查询，并判断生成视频是否真正满足信息需求，而不只是匹配提示词。
- [3D Arena](https://arxiv.org/abs/2506.18787)：通过开放比较平台评估 3D 生成系统。核心思想：从视觉、几何和语义维度比较 3D 生成质量，而不是依赖零散定性样例。
- [TC-Bench](https://doi.org/10.18653/v1/2025.findings-acl.241)：评测条件视频生成中的时间组合性；核心思想是检查生成视频是否保持事件顺序、时间关系和条件相关运动，而不只看视觉质量。
- [NarrLV](https://arxiv.org/abs/2507.11245)：评测长视频生成的叙事一致性。核心思想：把故事结构、事件连续性和长程一致性作为生成视频的核心评价目标。
- [PhyWorldBench](https://arxiv.org/abs/2507.13428)：评测文本到视频模型的物理真实感。核心思想：把物体动态、交互和物理一致性中的违背现象作为生成视频的核心评分目标。
- [T2VWorldBench](https://arxiv.org/abs/2507.18107)：评测文本到视频生成中的世界知识。核心思想：检查生成视频是否符合常识、物体行为和现实约束，而不只是匹配提示词表面内容。
- [World Consistency Score](https://arxiv.org/abs/2508.00144)：从世界一致性角度评测视频生成质量；核心思想是统一检查时间、物理和语义一致性，使生成视频不只按单帧外观打分。
- [UI2V-Bench](https://arxiv.org/abs/2509.24427)：评测基于理解的图像到视频生成。核心思想：检查模型在生成视频前是否能从输入图像推断场景结构、意图和合理运动。
- [FiVE-Bench](https://doi.org/10.1109/ICCV51701.2025.01548)：评估扩散模型和 rectified-flow 模型的视频编辑能力。核心思路是用细粒度编辑类别和指标区分编辑保真度、时间一致性和提示对齐。
- [DynamicEval](https://arxiv.org/abs/2510.07441)：评估带有镜头运动的动态文生视频。核心思想：用强调动态镜头的提示和大规模成对人工标注评估单个视频质量，而不只汇总成模型级排名。
- [VideoVerse](https://doi.org/10.48550/arXiv.2510.08398)：评测文本到视频生成器距离可用 world model 还有多远。核心思想：检验生成视频是否保持物理、时间和动作条件下的动态一致性，而不只是视觉上看起来合理。
- [LikePhys](https://arxiv.org/abs/2510.11512)：通过似然偏好评估视频扩散模型的直觉物理理解。核心思路是比较物理合理与不合理的候选视频，使视频生成评测能暴露动力学错误，而不只关注画面质量。
- [IVEBench](https://arxiv.org/abs/2510.11647)：评测指令引导的视频编辑模型；核心思想是用现代化编辑基准区分指令遵循、编辑保真度、时间一致性和生成/编辑视频的感知质量。
- [SeqBench](https://arxiv.org/abs/2510.13042)：评估文生视频中的连续叙事一致性。核心思想：用多事件提示、人工标注的模型输出和动态时序图指标，测试生成视频能否在较长序列中保持逻辑事件顺序。
- [Identity Leakage in Talking Face Generation](https://arxiv.org/abs/2511.08613)：通过静音输入、音视频错配和匹配合成等设置评测 talking-face 生成中的身份泄漏。核心思想：检测生成唇形是否受身份参考图影响而不是由驱动音频决定，补充普通唇同步指标无法覆盖的可靠性检查。
- [Target-Bench](https://arxiv.org/abs/2511.17792)：评估视频世界模型能否支持面向语义目标的无地图路径规划。核心思路是让模型在没有显式地图的情况下推理朝目标移动所需的前瞻信息。
- [4DWorldBench](https://arxiv.org/abs/2511.19836)：评估 3D 与 4D 世界生成模型。核心思路是同时考察生成世界的空间结构与时间演化，把空间评测从静态场景扩展到动态世界生成结果。
- [CVBench](https://doi.org/10.1109/VCIP67698.2025.11396889)：用大多模态模型评测和比较视频生成结果。核心思想：通过 LMM 驱动的评测协议系统判断生成视频质量和提示对齐，而不是依赖临时性的视觉检查。
- [RULER-Bench](https://arxiv.org/abs/2512.02622)：评估视频生成模型的规则推理能力。核心思路是测试生成视频是否遵守显式规则和结构化约束，而不只是符合提示的表面外观。
- [VideoScience-Bench](https://arxiv.org/abs/2512.02942)：评估视频生成中的科学理解与推理。核心思路是用科学导向的提示和判定标准检查生成视频是否保持科学概念与因果结构，而不只是表面逼真。
- [EgoEditBench](https://arxiv.org/abs/2512.06065)：评估指令引导的第一视角视频编辑。核心思路是在快速自运动和流式约束下测试指令忠实度、手部与交互保持以及时序稳定性。
- [RVE-Bench / ReViSE](https://arxiv.org/abs/2512.09924)：评估带推理约束的视频编辑。核心思路是通过推理感知编辑和上下文视频到视频生成任务，检验编辑模型是否保持物理合理性与因果动态。
- [T2AV-Compass](https://arxiv.org/abs/2512.21094)：以统一协议评测文本到音频视频生成。核心思想：同时考察视觉质量、音频质量、提示对齐和跨模态同步。
- [SVBench](https://arxiv.org/abs/2512.21507)：评测视频生成中的社会推理。核心思想：检查生成视频能否保持互动、意图和社会关系，而不只是视觉上合理。
- [PhyAVBench](https://arxiv.org/abs/2512.23994)：评测文生音视频生成中的音频物理敏感性；核心思想是检查生成的视觉与音频事件是否遵循有物理依据的跨模态线索。
- [Wow, wo, val!](https://arxiv.org/abs/2601.04137)：用图灵测试式协议评测具身世界模型。核心思想：把生成动态与交互世界行为对比，判断感知保真度与动作一致性。
- [NRVBench](https://arxiv.org/abs/2601.18340)：评估非刚性视频编辑。核心思路是结合基于物理的运动类别、细粒度编辑指令、多选检查和 NRVE-Acc，测试物理合规性、时序一致性与指令对齐。
- [GEOATTRACTION-500 / GAP](https://arxiv.org/abs/2601.18698)：评估文本到视频生成中的地理视觉知识。核心思路是用全球旅游地标提示，并结合结构、关键点和视觉语言判断，将整体视频质量与具体地标的地理保真度区分开。
- [VC-Bench](https://arxiv.org/abs/2601.19236)：评估视频连接任务，即在起始片段和结束片段之间生成平滑的中间视频内容。核心思路是同时衡量视频质量、首尾一致性和过渡平滑性，避免只用通用生成质量评价片段连接系统。
- [Artifact-Aware Evaluation](https://arxiv.org/abs/2601.20297)：通过外观、运动和镜头伪影类别评估高质量视频生成。核心思路是定位并分类生成视频错误，而不是只报告粗粒度质量分。
- [WorldBench](https://arxiv.org/abs/2601.21282)：诊断世界模型中的物理保真度。核心思想：拆分物理因素，定位与具身规划相关的动力学、因果和物体交互失败。
- [MTAVG-Bench](https://arxiv.org/abs/2602.00607)：评估多说话人对话中心的音视频生成。核心思想：测试生成视频是否保持说话人互动、音画同步和围绕对话的时间一致性。
- [Omni-Judge](https://arxiv.org/abs/2602.01623)：评估全模态 LLM 能否作为文本条件音视频生成的人类对齐裁判。核心思路是用可解释的多模态判断覆盖视觉质量、音频质量、提示对齐和音视频同步，而不是只依赖孤立的音频、视频或文本指标。
- [RISE-Video](https://arxiv.org/abs/2602.05986)：评测视频生成器是否掌握隐含世界规则。核心思想：关注动态是否符合规则，而不只看表面真实感，可补充生成视频物理合理性评测。
- [MIND](https://arxiv.org/abs/2602.08025)：评测世界模型的记忆一致性与动作控制。核心思想：检验交互式世界模型能否长期保持状态，并对动作条件控制作出可靠响应。
- [UniVBench](https://arxiv.org/abs/2602.21835)：用统一协议评测视频基础模型；核心思想是整合多类视频理解与生成维度，减少不同任务套件之间的割裂比较。
- [MSVBench](https://arxiv.org/abs/2602.23969)：评测多镜头视频生成；核心思想是用更接近人类判断的方式检查跨镜头连续性、身份保持、场景一致性和叙事连贯性。
- [Actor-Bench / WildActor](https://arxiv.org/abs/2603.00586)：评估不同视角、环境和动作下的身份保持人物视频生成。核心思路是检验全身身份一致性，而不只看人脸相似度或单参考图像的提示跟随。
- [OSCBench](https://arxiv.org/abs/2603.11698)：评估文本到视频生成中的物体状态变化。核心思路是用常规、陌生和组合场景中的动作物体提示，测试生成视频是否真的表现出时间一致的状态转化，而不只是满足宽泛语义对齐。
- [Out of Sight, Out of Mind?](https://arxiv.org/abs/2603.13215)：评估视频世界模型中的状态演化。核心思路是诊断模型能否在时间推进中维持被遮挡或暂时不可见的状态，这是具身规划的重要要求。
- [SGC](https://arxiv.org/abs/2603.19048)：评估动态生成视频中的三维空间几何一致性。核心思路是在静态背景区域估计局部相机位姿差异，从而把几何失败与前景运动区分开来。
- [Physion-Eval](https://arxiv.org/abs/2603.19607)：用专家人类推理评测生成视频的物理真实性。核心思想：相对于真实参考视频标注时间定位的物理故障和细粒度违规类别，使失败原因可解释，而不只是偏好评分。
- [Omni-WorldBench](https://arxiv.org/abs/2603.22212)：评测以交互为中心的 4D world model。核心思想：结合交互提示套件和 agent-based 指标，衡量动作如何因果影响最终结果和中间状态轨迹。
- [World Reasoning Arena](https://arxiv.org/abs/2603.25887)：评估世界模型能否作为智能体的模拟器。核心思路是不只看下一帧真实感，而是测试动作模拟保真度、长时程预测以及基于模拟的推理和规划。
- [PVIR](https://arxiv.org/abs/2604.05898)：评估具备物理感知的视频实例移除。核心思路是检查移除物体后是否保持阴影、反射、光照、背景完整性和空间一致性，而不只看表面视觉合理性。
- [AVGen-Bench](https://arxiv.org/abs/2604.08540)：评测 text-to-audio-video 生成。核心思想：在统一的多粒度协议下同时检查感知质量、语义可控性、音视频对齐、语音、音乐、文字渲染和物理推理。
- [VidAudio-Bench](https://arxiv.org/abs/2604.10542)：评估视频到音频和视频文本到音频生成，覆盖音效、音乐、语音和歌唱四类。核心思路是将分类别指标与人工一致性验证结合，分别诊断音频质量、视听一致性和文本音频一致性。
- [HOIVG-Bench / OmniShow](https://arxiv.org/abs/2604.11804)：评估文本、参考图像、音频和姿态共同约束下的人物-物体交互视频生成。核心思路是把多模态可控性和音视频交互一致性作为生成视频评测的显式目标。
- [AnimationBench](https://arxiv.org/abs/2604.15299)：评测以角色为中心的动画视频生成。核心思想：把动画基本原则、IP 保持、运动合理性、镜头一致性和语义一致性转成可评测维度，支持闭集和开放式 image-to-video 评测。
- [VEFX-Bench](https://arxiv.org/abs/2604.16272)：评测通用视频编辑与视觉特效生成。核心思想：用整体化协议考察编辑保真度、特效质量和提示词可控性，而不只评估被动视频生成。
- [OmniHuman / OHBench](https://arxiv.org/abs/2604.18326)：评估复杂真实场景中的人物中心视频生成。核心思路是用层级标注和三级评测体系，诊断生成音视频中的场景多样性、人人互动、人物与物体互动以及个体属性对齐。
- [RoboWM-Bench](https://arxiv.org/abs/2604.19092)：评估机器人操作场景中的世界模型。核心思路是检查预测动力学和状态变化是否真正有助于操作规划，而不只是生成视觉上合理的视频延续。
- [CLVG-Bench](https://arxiv.org/abs/2604.19193)：通过视频生成中的上下文学习评测多模态推理。核心思想：用复杂物理、逻辑和交互式视频上下文任务，以及自适应评测反馈，暴露视频生成模型的推理与 grounding 缺陷。
- [WorldMark](https://arxiv.org/abs/2604.21686)：在标准化控制条件下评测交互式 image-to-video world model。核心思想：把统一的 WASD 式动作词表映射到不同模型的原生接口，再在相同场景与轨迹上比较视觉质量、控制对齐和世界一致性。
- [MuSS](https://arxiv.org/abs/2604.23789)：通过电影叙事基准评估多镜头主体到视频生成。核心思路是考察连续叙事、跨镜头主体一致性，以及生成视频中对复制粘贴式捷径的抵抗能力。
- [HuM-Eval / HuM-Bench](https://arxiv.org/abs/2604.25361)：评估以人为中心的生成视频。核心思路是结合 VLM 全局评估、二维姿态和三维人体运动检查，显式评分解剖正确性与运动稳定性。
- [BRITE](https://arxiv.org/abs/2605.00873)：评测 text-to-video 生成在不合理场景中的表现。核心思想：结合不合常理的提示、音视频一致性检查和基于 QA 的可解释评测，让离分布失败能够被定位，而不只是给整体分数。
- [iWorld-Bench](https://arxiv.org/abs/2605.03941)：用统一的动作生成框架评估交互式世界模型。核心思路是检验世界模型能否支持动作条件下的交互，而不只是被动视频预测。
- [AV-Phys Bench](https://arxiv.org/abs/2605.07061)：评测联合音视频生成中的物理常识。核心思想：在稳态、事件转变和环境转变场景下检查视觉、音频和跨模态物理一致性，并加入刻意不符合物理的 Anti-AV-Physics 提示。
- [ACWM-Phys](https://arxiv.org/abs/2605.08567)：评估动作条件视频世界模型在多类物理交互下的泛化能力。核心思想：用可控仿真数据覆盖刚体、运动学、可变形物体和粒子动力学，并设置分布内与分布外协议。
- [MechVerse](https://arxiv.org/abs/2605.14843)：评测 image-to-video 生成中的机械运动一致性。核心思想：用带刚性连杆、接触、耦合和运动链约束的机械装配体，暴露生成视频中不符合物理约束的运动。
- [PDI-Bench](https://arxiv.org/abs/2605.15185)：评测生成视频中的几何一致性。核心思想：把跟踪到的对象中心观测提升到 3D，并用投影几何残差检查尺度-深度对齐、三维运动一致性和结构刚性。
- [EntityBench](https://arxiv.org/abs/2605.15199)：评估长程多镜头视频生成中的实体一致性。核心思路是用带有角色、物体和地点日程标注的叙事片段，区分单镜头质量、提示遵循和跨镜头一致性。

## 4.2.2 Agent Harness

- [FilmAgent](https://arxiv.org/abs/2501.12909)：面向虚拟 3D 空间的多智能体电影自动化框架。核心思路：把电影创作拆成多个协作角色和可执行的场景生产步骤，而不是把视频生成简化为单次提示词调用。
- [MM-StoryAgent](https://arxiv.org/abs/2503.05242)：面向有声故事书视频生成的多智能体 harness。核心思路是协调写作、视觉生成、旁白、音效和音乐模块，使故事能够跨文本、图像与音频工具完成规划和渲染，而不是依赖单一模型一次性生成。
- [MovieAgent](https://arxiv.org/abs/2503.07314)：一个用于自动化长视频生成的多智能体规划框架。核心思路是让导演、编剧、分镜师和场景管理等 LLM 智能体分工协作，将脚本拆解为场景、镜头、机位、字幕、音频和角色一致的生成步骤。
- [V-Stylist](https://arxiv.org/abs/2503.12077)：一个多智能体视频风格化框架。核心思路是协调视频解析、风格模型搜索和反思修正，使 MLLM 智能体能够分解多镜头视频并迭代改进风格化结果。
- [AniMaker](https://arxiv.org/abs/2506.10540)：一个面向动画叙事的多智能体 harness。核心思想：结合角色化故事规划与 MCTS 驱动的片段生成，使长动画能在多个 agent 间拆解、搜索和修订。
- [AniME](https://arxiv.org/abs/2508.18781)：一个面向长动画生成的多智能体规划 harness。核心思想：自适应协调规划角色，使长动画在生成片段之间保持情节、角色和场景一致性。
- [EditDuet](https://arxiv.org/abs/2509.10761)：面向非线性视频编辑的多智能体 harness。核心思想是把编辑拆给使用视频编辑工具的 Editor agent 和给出反馈或确认渲染的 Critic agent，使指令驱动视频编辑成为迭代式工具工作流。
- [MagicWand](https://arxiv.org/abs/2511.18352)：面向图像和视频 AIGC 的用户偏好对齐生成与评估智能体。核心思路是在提示增强、生成、评估和迭代修正中持续引入偏好描述，并用 UniPreferBench 评估偏好对齐。
- [The Script is All You Need](https://arxiv.org/abs/2601.17737)：面向长程对话到电影化视频生成的智能体框架，将脚本作为多阶段视频创作的规划载体。
- [SAGE: Scalable Agentic 3D Scene Generation](https://arxiv.org/abs/2602.10116)：为具身 agent 评测提供可扩展 3D 场景生成。核心思想：合成带行动约束的场景，使机器人或模拟 agent 能在多样可行动环境中测试，而不是依赖少量固定地图。
- [SPIRAL](https://arxiv.org/abs/2603.08403)：面向长程动作条件视频生成的反思式规划 harness。核心思想：由 PlanAgent 分解目标，结合记忆上下文逐段生成视频，再由 CriticAgent 反思并修复跨时间的动作执行。
- [Mind-of-Director](https://arxiv.org/abs/2603.14790)：多模态智能体驱动的影片预演框架，通过协作决策组织生成前的电影化规划。
- [CutClaw](https://arxiv.org/abs/2603.29664)：通过音乐同步进行小时级视频剪辑的 agentic harness。核心思想：围绕音频结构协调长程剪辑决策，使视频剪辑智能体能处理更长时间线。
- [DIRECT](https://arxiv.org/abs/2604.04875)：采用层级式多智能体规划与意图引导编辑的视频混剪生成框架，适合作为视频组合创作中的智能体编排案例。
- [Camera Artist](https://arxiv.org/abs/2604.09195)：面向电影化语言叙事视频生成的多智能体框架，关注叙事、镜头与拍摄决策的协同。
