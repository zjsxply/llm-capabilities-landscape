# 2.8 Future Prediction

> Parent section: 2. Foundation Agents


Note: This line focuses on whether agents can continuously gather information before events occur, update probabilistic judgments, and maintain a traceable forecasting process over time.

## 2.8.1 Leaderboard

- [ForecastBench Leaderboard](http://www.forecastbench.org/): A real future-event forecasting leaderboard that continuously and dynamically generates and updates questions; useful for comparing probabilistic forecasts, calibration, and expert/crowd baselines on unresolved questions.
- [Metaculus FutureEval](https://www.metaculus.com/futureeval/): Metaculus's continuous AI forecasting leaderboard; updated daily with a unified log score and comparing AI models, the Metaculus community, and professional forecasters in one view.
- [FutureSearch Evaluations](https://evals.futuresearch.ai/): The official FutureSearch evaluation entry, aggregating DRB and BTF-2; useful for tracking the "research-judgment" ability of deep research agents and forecasting agents in one reproducible framework.
- [Prophet Arena](https://www.prophetarena.co/): A real-time forecasting arena for LLM-as-a-Prophet; useful for diagnosing forecasting-pipeline stages such as event recall, source understanding, near-resolution information aggregation, and probability calibration.
- [TemporalBench Leaderboard](https://huggingface.co/spaces/Melady/TemporalBench_Leaderboard): The official Hugging Face leaderboard for TemporalBench; useful for comparing context-driven, event-driven, and time-series forecasting abilities.
- [Echo](https://echo.unipat.ai/): UniPat's dynamic future-prediction leaderboard and training system; useful for observing sustained forecasting performance after combining multi-point alignment Elo, Train-on-Future, and AI-native prediction APIs.
- [Impermanent Dashboard](https://impermanent.timecopilot.dev/): TimeCopilot's live temporal-generalization dashboard; useful for tracking real-time extrapolation performance of time-series forecasting models on rolling data streams.

## 2.8.2 Survey

Note: There are not many surveys specifically on "AI forecasting the future"; the closest lines are event prediction and time-series forecasting.

- [A Survey on Event Prediction Methods from a Systems Perspective: Bringing Together Disparate Research Areas](https://arxiv.org/abs/2302.04018): Surveys future event prediction from a systems perspective. Core idea: place event-prediction methods scattered across different fields into a unified systems view, organizing requirements, taxonomies, and research gaps; this is the most direct entry point for this line.
- [Large Language Models for Time Series: A Survey](https://arxiv.org/abs/2402.01801): Surveys methods for LLMs in time-series analysis and forecasting. Core idea: summarize the main paths for encoding, aligning, and adapting time series to LLMs, suitable for an overview of "using AI for time-series prediction."
- [Large Language Models for Forecasting and Anomaly Detection: A Systematic Literature Review](https://arxiv.org/abs/2402.10350): A systematic review of LLMs in forecasting and anomaly detection. Core idea: specifically summarize applications, challenges, and future directions for LLMs in forecasting tasks, closer to "future prediction" than surveys covering all time-series tasks.
- [How do large language models bring disruptive change to time series forecasting? A survey and framework](https://ideas.repec.org/a/taf/tjmaxx/v13y2026i1p17-42.html): A survey and framework for LLM involvement in time-series forecasting. Core idea: provide a more practice-oriented pipeline view and collaboration modes, emphasizing data scenarios and workflow organization.
- [Leveraging Large Language Models for time series forecasting: A systematic literature review](https://www.sciencedirect.com/science/article/pii/S0950705126006647): A systematic review focused specifically on LLM-driven time-series forecasting. Core idea: select 78 studies with PRISMA and cover architectures, tokenization, prompting, benchmarks, and evaluation issues; currently a newer forecasting-only survey.

## 2.8.3 Bench

- [MIRAI](https://arxiv.org/abs/2407.01231): Evaluates agentic forecasting for international events. Core idea: let agents access historical structured event databases and news text, call domain APIs through code interfaces, and evaluate source integration, tool use, and cross-time reasoning; an early representative of the live future-prediction line.
- [ForecastBench](https://arxiv.org/abs/2409.19839) ([Leaderboard](http://www.forecastbench.org/)): Evaluates dynamically generated, periodically updated real future-event forecasting. Core idea: include only questions unresolved at submission time, compare experts, crowds, and LLMs together, and specifically stress-test probabilistic forecasting under minimized data leakage.
- [Context is Key (CiK)](https://arxiv.org/abs/2410.18959) ([project page](https://servicenow.github.io/context-is-key-forecasting/)): Evaluates time-series forecasting with necessary textual context. Core idea: bind numerical history with natural-language constraints/background knowledge so models must understand text to forecast, testing "forecast after reading context" rather than only curve extrapolation.
- [FOReCAst](https://arxiv.org/abs/2502.19676) ([open-source code](https://github.com/MoyYuan/FOReCAst), [dataset](https://huggingface.co/datasets/MoyYuan/FOReCAst)): Evaluates probabilistic judgment and confidence calibration on real forecasting tasks across domains. Core idea: combine Boolean, timeframe, and quantity question types while evaluating both prediction accuracy and confidence, addressing evaluations that look only at final answers and ignore calibration.
- [PROPHET](https://arxiv.org/abs/2504.01509): Evaluates future event prediction with causal interventions. Core idea: split event prediction into inferable future states and post-intervention likelihood estimation, adding an interpretable future-prediction evaluation line before FutureX/Prophet Arena.
- [Outcome-based RL Forecasting Dataset](https://arxiv.org/abs/2505.17989): Evaluates future-event probability prediction and calibration on prediction-market questions. Core idea: combine recent prediction-market questions, news clues, and delayed real outcomes, using outcome reward to train/evaluate smaller models and showing that future prediction can form an RLVR-style loop.
- [Bench to the Future (BTF)](https://arxiv.org/abs/2506.21558): Evaluates reproducible pastcasting for forecasting agents. Core idea: pair historical forecasting questions with known outcomes with frozen web corpora, letting agents research, assign probabilities, and leave reasoning traces offline as if forecasting in real time, avoiding waits for future resolution and live-web drift.
- [Evaluating LLMs on Real-World Forecasting Against Expert Forecasters](https://arxiv.org/abs/2507.04562): Evaluates LLM probability forecasts on real Metaculus forecasting questions. Core idea: compare frontier models and expert forecasters on the same real forecasting questions using Brier score and calibration, complementing evaluations that only rank models against one another.
- [FutureX](https://arxiv.org/abs/2508.11987): Evaluates live agents for future-event prediction. Core idea: use real-time updating, automatic question collection, and answer collection to reduce data contamination, requiring agents to dynamically gather information, weigh uncertainty, and continuously adapt to new trends, close to analyst/strategic-research work.
- [Prophet Arena](https://arxiv.org/abs/2510.17638) ([project page](https://www.prophetarena.co/)): Evaluates real-time forecasting intelligence for LLM-as-a-Prophet. Core idea: continuously collect live forecasting tasks and separately analyze event recall, source understanding, near-resolution information aggregation, and probability calibration, helping identify which part of the forecasting pipeline fails.
- [KalshiBench](https://arxiv.org/abs/2512.16030) (dataset: [2084Collective/kalshibench-v2](https://huggingface.co/datasets/2084Collective/kalshibench-v2)): Evaluates epistemic calibration on prediction-market questions. Core idea: use resolved Kalshi events that occurred after training cutoffs to check whether model self-reported confidence matches actual correctness.
- [FinDeepForecast](https://arxiv.org/abs/2601.05039): Evaluates deep research agents in financial forecasting scenarios. Core idea: put live multi-agent research, financial event prediction, and traceable evidence chains into one evaluation, connecting ForecastBench-style dynamic prediction with Deep Research Bench-style evidence gathering.
- [FutureX-Pro](https://arxiv.org/abs/2601.12259): Evaluates future prediction in high-value vertical domains including finance, retail, public health, natural disasters, and search. Core idea: inherit FutureX's live, contamination-free pipeline and push forecasting tasks into capital-intensive or safety-critical industries, testing whether general agents have enough domain grounding.
- [FutureOmni](https://arxiv.org/abs/2601.13836): Evaluates future prediction in multimodal context. Core idea: put text, images, video, and structured clues into the same future-event judgment task, checking whether agents can form probabilistic forecasts from cross-modal evidence.
- [Metaculus FutureEval](https://www.metaculus.com/futureeval/) ([methodology](https://www.metaculus.com/futureeval/methodology/)): Evaluates the continuous future-event forecasting leaderboard released by Metaculus in 2026-02. Core idea: continuously feed open Metaculus forecasting questions to mainstream AI models and compare them with the Metaculus community/professional forecasters on calibration, coverage, and real forecasting performance over model release times; this line can be further traced through BTF-2's references to the Metaculus AI Benchmarking Series.
- [TemporalBench](https://arxiv.org/abs/2602.13272) ([dataset](https://huggingface.co/datasets/Melady/TemporalBench); [Leaderboard](https://huggingface.co/spaces/Melady/TemporalBench_Leaderboard)): Evaluates context- and event-driven time-series forecasting for LLM agents. Core idea: split tasks into historical-structure explanation, context-free prediction, contextual reasoning, and event-conditioned prediction, diagnosing whether models truly use external events rather than only fitting curves.
- [Echo](https://echo.unipat.ai/) ([official article](https://unipat.ai/blog/Echo)): Evaluates a dynamic future-prediction leaderboard and training system across finance, politics, crypto, sports, esports, and other domains. Core idea: combine multi-point alignment Elo, Train-on-Future, and AI-native prediction APIs into a full forecasting loop, addressing misaligned prediction timestamps and delayed training signals across models.
- [Impermanent](https://arxiv.org/abs/2603.08707) ([open-source code](https://github.com/TimeCopilot/impermanent); [Dashboard](https://impermanent.timecopilot.dev/)): Evaluates live temporal generalization for time-series forecasting. Core idea: score continuously on changing data streams such as GitHub activity, testing whether models maintain forecasting stability under open-world temporal drift.
- [YC-Bench](https://arxiv.org/abs/2604.01212): What it evaluates: state memory in long-term planning and consistent execution. Core idea: make agents repeatedly use historical goals, resource states, and intermediate decisions in ongoing business-management-style tasks, observing the real benefits of context truncation, scratchpads, and memory strategies.
- [TimeSeek](https://arxiv.org/abs/2604.04220): Evaluates temporal reliability for agentic forecasters. Core idea: replay forecasts at multiple points in a question's lifecycle, comparing no-retrieval, web-retrieval, and different models on the quality of probability updates as resolution approaches.
- [TFRBench](https://arxiv.org/abs/2604.05364): Evaluates reasoning ability in forecasting systems. Core idea: decompose forecasting into a diagnosable reasoning benchmark focused on information selection, temporal causality, constraint interpretation, and forecast consistency rather than only final error.
- [Prediction Arena](https://arxiv.org/abs/2604.07355): Evaluates live model competition for prediction-market/future-event tasks. Core idea: compare model forecasts with continuously updated questions and competition rules, uniformly recording probabilities, rationales, and calibration before and after resolution.
- [PolyBench](https://arxiv.org/abs/2604.14199): Evaluates LLM forecasting and trading ability based on live prediction-market data. Core idea: connect probability judgment, trading returns, and calibration in markets such as Polymarket, assessing whether agents can turn forecasts into actionable strategies.
- [QuantSightBench](https://arxiv.org/abs/2604.15859) ([project page](https://quantsightbench.com/); [open-source code](https://github.com/aisa-group/quantsightbench)): Evaluates interval prediction and uncertainty calibration for continuous quantities. Core idea: require models to provide prediction intervals instead of point or binary answers, specifically exposing systematic overconfidence at extreme magnitudes.
- [Bench to the Future 2 (BTF-2)](https://arxiv.org/abs/2604.26106) ([FutureSearch Evaluations](https://evals.futuresearch.ai/)): Evaluates strategic reasoning and research-judgment decomposition for forecasting agents. Core idea: use 1,417 pastcasting questions, a frozen 15-million-document research corpus, and full reasoning traces to distinguish whether agents fail at information research, probabilistic judgment, or black-swan/incentive modeling.
- [FutureWorld](https://arxiv.org/abs/2604.26733): Evaluates live agentic RL environments for future prediction. Core idea: connect prediction, outcome resolution, and parameter updates into a loop, using delayed real outcomes to backfill rewards and replay trajectories, studying online improvement through "predict-resolve-learn."
- [Foresight Arena](https://arxiv.org/abs/2605.00420): Evaluates open-ended arenas for large models forecasting future events. Core idea: build continuous evaluation around dynamic questions, probability submissions, and posterior resolution, forming the main "live forecasting eval" line together with ForecastBench and FutureX.
- [OracleProto](https://arxiv.org/abs/2605.03762): Evaluates reproducible pastcasting for LLM-native forecasting. Core idea: construct repeatable forecasting protocols with knowledge cutoffs and temporal masking, specifically diagnosing hindsight leakage and retrieval-time contamination.
- [FutureSim](https://arxiv.org/abs/2605.15188): Evaluates adaptive agents by replaying real-world news and event resolutions in chronological order. Core idea: let agents forecast January-March 2026 events beyond their knowledge cutoff while receiving time-ordered news, testing long-horizon adaptation, memory, search, and calibrated uncertainty under a realistic simulated timeline.

## 2.8.4 Agent Harness

- [Reasoning and Tools for Human-Level Forecasting](https://arxiv.org/abs/2408.12036) (open-source code: not released; an early agentic forecasting scaffold whose core idea is connecting retrieval, decomposition, numerical calibration, and forecasting heuristics into one reasoning toolchain, becoming a directly cited baseline for later BTF/FutureSearch work)
- [TimeSeriesScientist](https://arxiv.org/abs/2510.01538) ([open-source code](https://github.com/Y-Research-SBU/TimeSeriesScientist); a general time-series forecasting agent whose core idea is using Curator, Planner, Forecaster, and Reporter agents to chain data diagnostics, model selection, validation integration, and report generation into a white-box forecasting workflow)
- [AIA Forecaster](https://arxiv.org/abs/2511.07678) (open-source code: not released; an agentic forecaster for real future events whose core idea is using multi-round web research, structured forecasting prompts, and calibration rules to approximate human superforecasters while exposing information-leakage risks in live/pastcasting evaluation)
- [OpenForecaster](https://arxiv.org/abs/2512.25070) ([open-source code](https://github.com/OpenForecaster/scaling-forecasting-training); a forecasting agent/model training line for open-ended future events whose core idea is automatically constructing OpenForesight forecasting questions from news, combined with offline retrieval and RL training to improve accuracy, calibration, and long-term consistency)
- [FutureSearch Forecasting Question Generator/Resolver](https://arxiv.org/abs/2601.22444) (open-source code: not released; uses LLM-driven web research agents to automatically generate and resolve forecasting questions, serving both as a benchmark item-production harness and as a way to improve forecasting agents' probability judgments through question-decomposition strategies)
- MiroFish ([open-source code](https://github.com/666ghj/MiroFish), [official site](https://mirofish.work/); no standalone paper): Combines seed materials, knowledge graphs, multi-persona agents, and social evolution into an interactive prediction-simulation engine; suitable for turning "forecasting" from static QA into replayable scenario simulation.
- FutureSearch ReAct Agent ([open-source code](https://github.com/futuresearch/futuresearch-python); no standalone arXiv paper): The open-source FutureSearch agent implementation cited by BTF-2, providing ReAct-style system prompts, a web research toolkit, and time-management mechanisms; suitable as a reproducible experimental harness for forecasting agents.
- [Milkyway](https://arxiv.org/abs/2604.15719) (open-source code: no stable public repository found): Writes pre-resolution signals back into a continuously updated future-prediction harness. Core idea: repeatedly forecast the same unresolved question, extract pre-resolution signals, update factor tracking / evidence gathering / uncertainty handling, then perform retrospective checks using resolved outcomes; this is a more direct harness-evolution line.
- [Bayesian Linguistic Forecaster (BLF)](https://arxiv.org/abs/2604.18576) (open-source code: not released; an agentic forecaster for ForecastBench whose core idea is combining numerical probabilities and natural-language evidence summaries into a linguistic belief state, then performing sequential Bayesian updating, trial aggregation, and hierarchical calibration through iterative tool use)
