# 1.17 创造力

> 上级章节：1. 基础能力

Creativity 覆盖以 novelty、originality、divergent thinking、open-ended generation、ideation、humor 或 creative diversity 为核心评测或改进对象的工作。它把创造性生成与创意构思从宽泛的 `Other` 中拆出；当某些科研创意基准同时强调科学工作流时，也可以在 Research 页交叉列出。
