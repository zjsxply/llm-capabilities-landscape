# 1.10.5 Agent Harness

Note: In the public ecosystem, there are not many solver agents named only for a specific long-context benchmark. More common are reusable long-horizon agent practices such as segmented loading, state summaries, failed-branch logging, and pluggable compression/retrieval components.

- [LLMLingua](https://arxiv.org/abs/2310.05736) ([code](https://github.com/microsoft/LLMLingua)): A pluggable context-compression component, often used in long-context agents to reduce irrelevant token interference and improve effective information density.
- [LongLLMLingua](https://arxiv.org/abs/2310.06839) ([code](https://github.com/microsoft/LLMLingua)): Compression and reordering strategies for longer inputs, emphasizing retention of key reasoning evidence under high compression ratios.
- [RAPTOR](https://arxiv.org/abs/2401.18059) ([code](https://github.com/parthsarthi03/raptor)): Organizes document memory with recursive summary trees, allowing agents to retrieve and aggregate evidence across context chunks at different granularities.
- [LongAgent](https://arxiv.org/abs/2402.11550) ([evaluation code/data](https://github.com/zuucan/needleinahaystack-plus)): A multi-agent collaborative long-context harness; the core idea is to assign ultra-long texts to multiple member agents and have a leader agent aggregate local evidence, making it suitable as an alternative to stuffing the entire input into one prompt.
- [HippoRAG](https://arxiv.org/abs/2405.14831) ([code](https://github.com/OSU-NLP-Group/HippoRAG)): Adds knowledge-graph-like association and hippocampus-inspired retrieval mechanisms to RAG, suitable for long-range factual association and multi-hop evidence organization.
- [Chain-of-Agents](https://arxiv.org/abs/2406.02818) ([unofficial implementation](https://github.com/rudrankriyam/Chain-of-Agents)): Splits long input into worker agents that process segments serially and pass intermediate messages, then has a manager agent summarize the final answer; suitable for long-document QA and summarization tasks.
- [Graph of Agents](https://arxiv.org/abs/2509.06644) ([code](https://github.com/tjoo512/graph-of-agents)): A graph-style multi-agent collaboration harness for long context; the core idea is to organize text chunks, local agent outputs, and aggregation nodes into a scalable graph structure, replacing a single long prompt with local processing and cross-node aggregation.
