# 2.11.5 Agent Harness

MineDojo, CALVIN, VIMA, and LIBERO are benchmark-side harnesses as much as datasets: they define environments, observations, action spaces, task resets, and success checks. The reusable design pattern is `observe multimodal state -> parse language goal -> plan/subgoal -> act -> verify environment state -> recover`.
- [Voyager](https://arxiv.org/abs/2305.16291) ([code](https://github.com/MineDojo/Voyager); [project page](https://voyager.minedojo.org/)): A canonical open-ended Minecraft agent with automatic curriculum, code-as-action, execution feedback, and a growing skill library, directly matching MineDojo-style long-horizon embodied-agent evaluation.
- [JARVIS-1](https://arxiv.org/abs/2311.05997) ([code](https://github.com/CraftJarvis/JARVIS-1); [project page](https://craftjarvis.github.io/JARVIS-1/)): An open-world Minecraft multi-task agent with multimodal memory and action grounding, useful as a historical game-agent harness alongside Voyager.
- [AutoRT: Embodied Foundation Models for Large Scale Orchestration of Robotic Agents](https://arxiv.org/abs/2401.12963): Orchestrates a robot fleet by using VLMs for scene grounding and LLMs to propose diverse safe instructions, collecting in-the-wild episodes through teleoperation and autonomous policies.
- [SERL: A Software Suite for Sample-Efficient Robotic Reinforcement Learning](https://arxiv.org/abs/2401.16013): Provides a reusable robot-RL software harness with off-policy learning, reward computation, environment reset tooling, and real-world training infrastructure for sample-efficient manipulation.
- [Multimodal Embodied Interactive Agent for Cafe Scene](https://arxiv.org/abs/2402.00290): Introduces MEIA, which stores visual-language scene memory and translates natural-language cafe-service goals into executable robot action plans.
- [InCoRo: In-Context Learning for Robotics Control with Feedback Loops](https://arxiv.org/abs/2402.05188): Wraps an LLM controller, scene-understanding unit, and robot feedback loop so execution commands are continually adapted as the environment changes.
- [WebLINX: Real-World Website Navigation with Multi-Turn Dialogue](https://arxiv.org/abs/2402.05930): Defines a conversational browser-control setting where agents prune HTML with retrieval, combine screenshots and action history, and execute multi-turn website navigation.
- [Introspective Planning: Aligning Robots' Uncertainty with Inherent Task Ambiguity](https://arxiv.org/abs/2402.06529): Adds a retrieval-backed uncertainty-calibration planner that selects safer robot plans by matching ambiguous instructions to introspective reasoning examples.
- [Universal Manipulation Interface: In-The-Wild Robot Teaching Without In-The-Wild Robots](https://arxiv.org/abs/2402.10329): Provides a portable robot-teaching interface that turns demonstration collection into a reusable embodied-agent harness.
- [Probabilistically Correct Language-Based Multi-Robot Planning Using Conformal Prediction](https://arxiv.org/abs/2402.15368): Builds S-ATLAS, a distributed LLM planner that uses conformal prediction to allocate uncertainty and target user-specified success rates for language-instructed robot teams.
- [Never-Ending Behavior-Cloning Agent for Robotic Manipulation](https://arxiv.org/abs/2403.00336): Uses skill-shared 3D semantic rendering and representation distillation so a language-conditioned manipulation agent can continually absorb new scene semantics and robot skills.
- [Hierarchical Diffusion Policy for Kinematics-Aware Multi-Task Robotic Manipulation](https://arxiv.org/abs/2403.03890): Splits manipulation into a high-level next-best-pose planner and a low-level kinematics-aware diffusion controller for long-horizon multi-task robot actions.
- [Learning Human-to-Humanoid Real-Time Whole-Body Teleoperation](https://arxiv.org/abs/2403.04436): Presents H2O, a real-time teleoperation framework that retargets RGB-camera human motion through sim-to-data filtering and transfers whole-body humanoid control to hardware.
- [DexCap: Scalable and Portable Mocap Data Collection System for Dexterous Manipulation](https://arxiv.org/abs/2403.07788): Provides a scalable portable mocap data-collection system for dexterous manipulation.
- [TeleMoMa: A Modular and Versatile Teleoperation System for Mobile Manipulation](https://arxiv.org/abs/2403.07869): Unifies RGB-D cameras, VR controllers, keyboards, and joysticks into a modular teleoperation interface for collecting mobile-manipulation demonstrations in simulation and real robots.
- [OPEN TEACH: A Versatile Teleoperation System for Robotic Manipulation](https://arxiv.org/abs/2403.07870): Provides a versatile teleoperation system for robotic manipulation.
- [Tina: Think, Interaction, and Action Framework for Zero-Shot Vision Language Navigation](https://arxiv.org/abs/2403.08833): Structures zero-shot VLN around thinking, environment querying, and action selection so the agent can ask for key perceptual clues before choosing navigation moves.
- [GaussNav: Gaussian Splatting for Visual Navigation](https://arxiv.org/abs/2403.11625): Uses a 3D Gaussian-splatting map as persistent visual memory, preserving geometry, semantics, and texture for instance image-goal navigation.
- [MineStudio](https://arxiv.org/abs/2403.12067) ([code](https://github.com/CraftJarvis/MineStudio)): An open-source Minecraft agent-development package covering data, training, evaluation, and trajectory tooling, bridging MineDojo and newer game-agent benchmarks.
- [Embodied LLM Agents Learn to Cooperate in Organized Teams](https://arxiv.org/abs/2403.12482): Uses prompt-imposed team roles and leadership structures to coordinate embodied LLM agents and reduce redundant or confusing inter-agent communication.
- [Yell At Your Robot: Improving On-the-Fly from Language Corrections](https://arxiv.org/abs/2403.12910): Adds a human-in-the-loop correction channel where language feedback supervises high-level policies that call low-level language-conditioned robot skills.
- [Empowering Large Language Models on Robotic Manipulation with Affordance Prompting](https://arxiv.org/abs/2404.11027): Uses affordance prompting to empower LLMs for robotic manipulation.
- [RoboHop: Segment-based Topological Map Representation for Open-World Visual Navigation](https://arxiv.org/abs/2405.05792): Represents open-world visual navigation with segment-based topological maps for more structured embodied planning.
- [Robots can feel: LLM-based Framework for Robot Ethical Reasoning](https://arxiv.org/abs/2405.05824): Wraps robot decisions with logic and simulated-emotion weighting so an LLM-based controller can reason over morally ambiguous embodied actions.
- [MC-GPT: Empowering Vision-and-Language Navigation with Memory Map and Reasoning Chains](https://arxiv.org/abs/2405.10620): Combines memory maps and reasoning chains for vision-language navigation.
- [GameVLM: A Decision-making Framework for Robotic Task Planning Based on Visual Language Models and Zero-sum Games](https://arxiv.org/abs/2405.13751): Orchestrates VLM decision agents and expert evaluator agents in a zero-sum game loop to rank and refine robotic task plans.
- [LLM-based Robot Task Planning with Exceptional Handling for General Purpose Service Robots](https://arxiv.org/abs/2405.15646): Uses LLM-based task planning with exception handling for general-purpose service robots.
- [DiPPeST: Diffusion-based Path Planner for Synthesizing Trajectories Applied on Quadruped Robots](https://arxiv.org/abs/2405.19232): Couples a goal-conditioned diffusion trajectory generator with real-time camera-reactive local path refinement and visual servoing for quadruped execution.
- [RoboCasa: Large-Scale Simulation of Everyday Tasks for Generalist Robots](https://arxiv.org/abs/2406.02523): Provides a simulation harness with realistic kitchen scenes, interactable assets, and 100 everyday manipulation tasks for training and evaluating generalist robots.
- [Trust the PRoC3S: Solving Long-Horizon Robotics Problems with LLMs and Constraint Satisfaction](https://arxiv.org/abs/2406.05572): Converts LLM-generated skill code into continuous constraint satisfaction problems so long-horizon robot plans can be checked and repaired against kinematic and physical constraints.
- [SlideSLAM: Sparse, Lightweight, Decentralized Metric-Semantic SLAM for Multirobot Navigation](https://arxiv.org/abs/2406.17249): Gives heterogeneous robot teams a decentralized metric-semantic SLAM loop with object-level maps, semantics-driven loop closure, and communication-aware map merging.
- [Manipulate-Anything: Automating Real-World Robots using Vision-Language Models](https://arxiv.org/abs/2406.18915): Automates real-world manipulation data generation by using VLMs to operate without privileged state, hand-designed skills, or fixed object instances.
- [ROS-LLM: A ROS framework for embodied AI with task feedback and structured reasoning](https://arxiv.org/abs/2406.19741): Connects chat-driven LLM agents to ROS actions and services, extracting sequence, behavior-tree, or state-machine behaviors with human and environment feedback reflection.
- [Open-TeleVision: Teleoperation with Immersive Active Visual Feedback](https://arxiv.org/abs/2407.01512): Provides an immersive teleoperation interface with stereoscopic active visual feedback and operator arm-hand mirroring for collecting humanoid demonstration data.
- [LLM-A*: Large Language Model Enhanced Incremental Heuristic Search on Path Planning](https://arxiv.org/abs/2407.02511): Combines LLM global environmental reasoning with A-star style incremental heuristic search so robot routes remain valid while benefiting from broader scene context.
- [Bunny-VisionPro: Real-Time Bimanual Dexterous Teleoperation for Imitation Learning](https://arxiv.org/abs/2407.03162): Uses a VR headset, low-cost haptic devices, and safety constraints to provide real-time bimanual dexterous teleoperation demonstrations for imitation learning.
- [Robotic Control via Embodied Chain-of-Thought Reasoning](https://arxiv.org/abs/2407.08693): Adds embodied chain-of-thought prompting before robot action selection so VLA policies can reason over task context instead of directly issuing low-level controls.

- [EPD: Long-term Memory Extraction, Context-awared Planning and Multi-iteration Decision @ EgoPlan Challenge ICML 2024](https://arxiv.org/abs/2407.19510): Chains memory extraction from egocentric progress video, context-aware next-action planning, and multi-iteration decision review for EgoPlan task execution.
- [Perceive, Reflect, and Plan: Designing LLM Agent for Goal-Directed City Navigation without Instructions](https://arxiv.org/abs/2408.04168): Builds a city-navigation loop in which an LLM agent localizes from landmarks, reflects over spatial context, and plans toward goal descriptions without turn-by-turn instructions.
- [Can LLM be a Good Path Planner based on Prompt Engineering? Mitigating the Hallucination for Path Planning](https://arxiv.org/abs/2408.13184): Mitigates LLM path-planning hallucination by transforming spatial prompts into relational chains and using curriculum Q-learning over the derived route structure.
- [VernaCopter: Disambiguated Natural-Language-Driven Robot via Formal Specifications](https://arxiv.org/abs/2409.09536): Translates natural-language robot commands into signal temporal logic specifications so an LLM motion planner can generate less ambiguous and more reliable paths.
- [PLATO: Planning with LLMs and Affordances for Tool Manipulation](https://arxiv.org/abs/2409.11580): Combines LLM planning with affordances for embodied tool manipulation.
- [OLiVia-Nav: An Online Lifelong Vision Language Approach for Mobile Robot Social Navigation](https://arxiv.org/abs/2409.13675): Integrates VLM social-context encoding with online lifelong learning so mobile robots can adapt navigation behavior in human-centered spaces.
- [ReMEmbR: Building and Reasoning Over Long-Horizon Spatio-Temporal Memory for Robot Navigation](https://arxiv.org/abs/2409.13682): Builds retrieval-augmented robot memory from long-horizon navigation video, indexing temporal, spatial, and image evidence for later embodied question answering.
- [DROP: Dexterous Reorientation via Online Planning](https://arxiv.org/abs/2409.14562): Uses online sampling-based predictive control with vision pose estimation to plan contact-rich in-hand reorientation actions at execution time.
- [KARMA: Augmenting Embodied AI Agents with Long-and-Short Term Memory Systems](https://arxiv.org/abs/2409.14908): Adds dual memory to embodied LLM planning, combining long-term 3D scene graphs with short-term object-state updates for household task execution.
- [Whole-Body Teleoperation for Mobile Manipulation at Zero Added Cost](https://arxiv.org/abs/2409.15095): Delegates mobile-base motion to a learned controller while the operator controls end-effector motion, enabling whole-body mobile-manipulator teleoperation without new hardware.
- [AIR-Embodied: An Efficient Active 3DGS-based Interaction and Reconstruction Framework with Embodied Large Language Model](https://arxiv.org/abs/2409.16019): Runs an active reconstruction loop where a multimodal LLM assesses 3DGS state, selects viewpoints and interactions, and refines actions through closed-loop reasoning.
- [Robi Butler: Remote Multimodal Interactions with Household Robot Assistant](https://arxiv.org/abs/2409.20548): Implements a remote household-robot interface where first-person video, speech or text, and pointing gestures feed an LLM behavior module that emits multistep open-vocabulary plans.

- [SPINE: Online Semantic Planning for Missions with Incomplete Natural Language Specifications in Unstructured Environments](https://arxiv.org/abs/2410.03035): Runs an online semantic-planning loop where an LLM infers missing mission details while the robot maps, selects semantic subgoals, plans, and replans without a prebuilt map.
- [MO-DDN: A Coarse-to-Fine Attribute-based Exploration Agent for Multi-object Demand-driven Navigation](https://arxiv.org/abs/2410.03488): Defines multi-object demand-driven navigation with personal preferences and a C2FAgent that performs coarse-to-fine attribute exploration across decision levels to find multiple objects.
- [GRAPPA: Generalizing and Adapting Robot Policies via Online Agentic Guidance](https://arxiv.org/abs/2410.06473): Wraps a base robot policy with role-specialized conversational agents for advising, grounding, monitoring, and robotic control, shifting actions online with object grounding and visuomotor feedback.
- [G2TR: Generalized Grounded Temporal Reasoning for Robot Instruction Following by Combining Large Pre-trained Models](https://arxiv.org/abs/2410.07494): Factors temporal instruction grounding into event-interval retrieval, interaction-frame spatial reasoning, and semantic object tracking so a robot can execute commands referring to past human actions.
- [Web Agents with World Models: Learning and Leveraging Environment Dynamics in Web Navigation](https://arxiv.org/abs/2410.13232): Computer-use move candidate; the WMA browser agent predicts next web observations and irreversible action outcomes before choosing long-horizon navigation steps.
- [Vision-Language Navigation with Energy-Based Policy](https://arxiv.org/abs/2410.14250): Learns an energy-based navigation policy that scores state-action pairs against expert occupancy measures across R2R, REVERIE, RxR, and R2R-CE.
- [MARLIN: Multi-Agent Reinforcement Learning Guided by Language-Based Inter-Robot Negotiation](https://arxiv.org/abs/2410.14383): Switches between LLM-based inter-robot negotiation and learned multi-agent policies so language plans can guide unsafe early MARL training and later hand off to trained controllers.
- [Creating and Repairing Robot Programs in Open-World Domains](https://arxiv.org/abs/2410.18893): RoboRepair traces failed LLM-generated robot programs, keeps completed world-state changes, and asks an LLM to synthesize recovery code that avoids repeating successful steps.
- [CaStL: Constraints as Specifications Through Llm Translation for Long-Horizon Task and Motion Planning](https://arxiv.org/abs/2410.22225): Uses staged LLM translation to extract goal, ordering, and blocking constraints from natural language into PDDL and Python, then solves long-horizon TAMP with a custom planner.
- [From Context to Action: Analysis of the Impact of State Representation and Context on the Generalization of Multi-Turn Web Navigation Agents](https://arxiv.org/abs/2410.23555): Analyzes LLM browser-agent context management by ablating interaction history and page representations, showing how these choices affect out-of-distribution multi-turn navigation.
- [Dynamem: Online Dynamic Spatio-Semantic Memory for Open World Mobile Manipulation](https://arxiv.org/abs/2411.04999): Maintains an online 3D point-cloud memory with open-vocabulary object localization, letting mobile manipulators update object state after human or robot changes and continue task execution.
- [Towards an Efficient Synthetic Image Data Pipeline for Training Vision-Based Robot Systems](https://arxiv.org/abs/2411.06166): Defines a componentized synthetic-image pipeline for robot-vision training, covering generation, labeling, domain-randomization, and integration stages.
- [Learning Multi-Agent Loco-Manipulation for Long-Horizon Quadrupedal Pushing](https://arxiv.org/abs/2411.07104): Uses hierarchical multi-agent reinforcement learning for quadruped pushing, combining RRT-based high-level subgoals, decentralized goal-conditioned policies, and pretrained locomotion controllers.
- [Zero-shot Object-Centric Instruction Following: Integrating Foundation Models with Traditional Navigation](https://arxiv.org/abs/2411.07848): LIFGIF grounds object-centric language instructions in a landmark factor graph while the robot builds the map, coupling foundation-model semantics with traditional navigation.

- [MindForge: Empowering Embodied Agents with Theory of Mind for Lifelong Cultural Learning](https://arxiv.org/abs/2411.12977): Adds explicit belief-desire-action representations, natural inter-agent communication, and multi-component memory to Minecraft agents for instructive and collaborative cultural learning.
