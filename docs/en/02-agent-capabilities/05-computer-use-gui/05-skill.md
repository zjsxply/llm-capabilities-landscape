# 2.5.5 Skill

- [screenshot](https://skills.sh/openai/skills/screenshot) (screenshot capability; perception-layer oriented, weakly related to OSWorld but commonly used)
- [playwright-interactive](https://skills.sh/openai/skills/playwright-interactive) (browser/Electron interaction; weakly related to OSWorld but covers some GUI interfaces)
- [browser-use](https://github.com/browser-use/browser-use/tree/main/skills/browser-use) provides a real browser-control skill for persistent browser sessions, page state inspection, clicking, typing, screenshots, tab management, and extraction.
- [OpenClaw browser-automation](https://github.com/openclaw/openclaw/tree/main/extensions/browser/skills/browser-automation) packages browser-tool operating loops, tab hygiene, stale-reference recovery, login blockers, and multi-step web interaction practices for OpenClaw-style agents.
- [computer-use-agents](https://skills.sh/sickn33/antigravity-awesome-skills/computer-use-agents) (computer-use design pattern library)
- [ubuntu-desktop-control](https://github.com/lommaj/ubuntu-desktop-control) (Ubuntu/X11 desktop control: `xdotool`, `scrot`, and related tools)
- [agent-desktop](https://skills.sh/lahfir/agent-desktop/agent-desktop) (tool-style desktop GUI automation skill; implementation is mainly macOS-oriented, with incomplete Linux/Windows support)
- [desktop-controller-skill](https://github.com/24kchengYe/desktop-controller-skill) (local Windows computer use; dual Win32 and Playwright engines)
- [guicountrol](https://clawhub.ai/dreamtraveler13/guicountrol) (Linux GUI control: `xdotool`, `wmctrl`, `dogtail`, including accessibility-tree inspection)
- [computer-use](https://clawhub.ai/Ram-Raghav-S/computer-use) (headless Linux server: `Xvfb`, `XFCE`, `xdotool`, with VNC observation support)
- [desktop-control](https://clawhub.ai/matagul/desktop-control) (general desktop automation: keyboard/mouse, screenshots, window management, and image recognition)
- [turix-cua](https://clawhub.ai/Tongyu-Yan/turix-cua) (desktop GUI automation and workflow orchestration; calls its own CUA model)
