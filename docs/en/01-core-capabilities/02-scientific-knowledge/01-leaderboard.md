# 1.2.1 Leaderboard

- [Humanity's Last Exam](https://lastexam.ai/): a public leaderboard for expert-level cross-disciplinary knowledge and reasoning. Its value is using difficult science, math, humanities, and professional questions as a stress test for the upper bound of model knowledge.
- [HLE-Rolling](https://agi.safe.ai/): the dynamic update/submission entry point for Humanity's Last Exam. Its value is reducing contamination, errors, and saturation in the public HLE through continuous revision, new questions, and live submission.
- [OlympiadBench Leaderboard](https://github.com/OpenBMB/OlympiadBench#leaderboard): official repository leaderboard tables for bilingual Olympiad-level math and science problems. Its value is separating text-only and full multimodal competition-problem performance.
- [MMLU-Pro Leaderboard](https://huggingface.co/spaces/TIGER-Lab/MMLU-Pro): TIGER-Lab's public leaderboard for harder multidisciplinary professional knowledge. Its value is tracking robust professional-domain QA after the benchmark reduces easy shortcuts and contamination.
- [CS-Bench Leaderboard](https://csbench.github.io/): official Computer Science Mastery leaderboard. Its value is comparing models on computer-science knowledge across difficulty levels and subdomains.
- [SciKnowEval Leaderboard](https://scipilots.org/sciknoweval/): official SciKnowEval leaderboard. Its value is organizing multi-level scientific-knowledge evaluation by domain and task granularity.
- [NeurIPS 2024 ML4CFD Competition](https://www.codabench.org/competitions/3282/): official Codabench page for the ML4CFD airfoil-design challenge. Its value is giving a competition-style ranking for computational-fluid-dynamics surrogate modeling.
- [PaperBench Results](https://github.com/openai/preparedness/blob/main/project/paperbench/README.md): public results for AI research agents that reproduce papers. Its value is separating rollout, reproduction, and grading, making end-to-end scientific-reproduction capability easier to compare.
- [SuperGPQA Leaderboard](https://supergpqa.github.io/): official leaderboard for long-tail professional QA. Its value is comparing models on broad, workplace-like expert knowledge rather than only standard academic exams.
- [PhyBench Leaderboard](https://www.phybench.cn/leaderboard): official PHYBench leaderboard for physics knowledge and reasoning. Its value is tracking performance on concept, law, and derivation-heavy physics tasks.
- [PhyArena](https://phyarena.github.io/): public arena and leaderboard page for the PHYSICS benchmark family. Its value is comparing physics reasoning systems under rule-based and model-based grading.
- [HealthBench Results](https://openai.com/index/healthbench/): official OpenAI results page for HealthBench. Its value is providing public model comparisons on health and clinical-knowledge reliability.
- [AstaBench Leaderboard](https://huggingface.co/spaces/allenai/asta-bench-leaderboard): a public leaderboard for a comprehensive scientific-agent suite. Its value is covering research skills such as literature retrieval, code execution, data analysis, and end-to-end scientific discovery.
- [ScienceAgentBench Leaderboard](https://hal.cs.princeton.edu/scienceagentbench): a public leaderboard for practical data-driven scientific-discovery agents. Its value is comparing systems on tasks derived from peer-reviewed papers with executable-program submissions.
- [ResearchCodeBench Leaderboard](https://researchcodebench.github.io/leaderboard/index.html): a public leaderboard for implementing research code from recent ML papers. It is suitable as a more code-implementation-oriented reference beyond PaperBench and EXP-Bench.
- [SciVisAgentBench Leaderboard](https://scivisagentbench.github.io/leaderboard.html): a leaderboard for scientific data analysis and visualization agents. Its value is bringing scientific data understanding, analysis decisions, and graphical expression into comparable evaluation.
- [MLIP Arena](https://huggingface.co/spaces/atomind/mlip-arena): an open machine-learning interatomic-potential benchmark space. Its value is giving materials-model readers a live comparison surface for MLIP accuracy, speed, and protocol transparency.
- [LABBench2 Leaderboard](https://labs.edisonscientific.com/benchmarks/labbench2): an official Edison Scientific leaderboard for realistic biology research tasks. Its value is tracking agent performance on file-handling, external-runner, and tool-switching variants of lab workflows.
- [FIRE-Bench Leaderboard](https://firebench.github.io/): official leaderboard for full-process scientific rediscovery agents. Its value is comparing agents on whether they can reconstruct paper-level claims through autonomous ideation, experimentation, and summarization.
- [AIRS-Bench Leaderboard](https://github.com/facebookresearch/airs-bench#leaderboard): official repository leaderboard for end-to-end scientific workflows. Its value is comparing agents on idea generation, experiment analysis, and iterative revision in one suite.
- [ResearchGym Leaderboard](https://anikethh.github.io/ResearchGym/): official project leaderboard for long-horizon AI research tasks. Its value is comparing agents under budgeted, codebase-backed research problems.
- [MedHELM Results](https://crfm.stanford.edu/helm/medhelm/v2.0.0/): official Stanford HELM results page for medical-task evaluation. Its value is showing broad clinical and biomedical model comparisons beyond single medical QA exams.
