# 1.17 Creativity

> Parent chapter: 1. Core Capabilities

Creativity covers evaluations and methods where novelty, originality, divergent thinking, open-ended generation, ideation, humor, or creative diversity is the central capability being measured or improved. It separates creative generation and ideation from the broad catch-all `Other` page, while still allowing research-specific creative-idea benchmarks to be cross-listed under Research when the scientific-workflow angle is central.
