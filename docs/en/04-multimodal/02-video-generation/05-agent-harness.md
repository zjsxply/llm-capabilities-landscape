# 4.2.5 Agent Harness

- [LAVE: LLM-Powered Agent Assistance and Language Augmentation for Video Editing](https://arxiv.org/abs/2402.10294): An LLM-assisted editing interface that captions user footage, lets an agent plan and execute edits from objectives, and still supports direct timeline refinement.
- [Motion-Agent: A Conversational Framework for Human Motion Generation with LLMs](https://arxiv.org/abs/2405.17013): Provides a conversational framework that uses LLMs to control human motion generation.
- [From Data to Story: Towards Automatic Animated Data Video Creation with LLM-Based Multi-Agent Systems](https://arxiv.org/abs/2408.03876): Data Director assigns agents to interpret raw data, plan narrative roles, and assemble animated data-story videos from charts, narration, and visual components.
- [Anim-Director: A Large Multimodal Model Powered Agent for Controllable Animation Video Generation](https://arxiv.org/abs/2408.09787): Uses an LMM as an animation director that expands short user inputs into storylines, character sheets, scene descriptions, generated images, and animated clips.
- [Kubrick: Multimodal Agent Collaborations for Synthetic Video Generation](https://arxiv.org/abs/2408.10453): Coordinates Director, Programmer, and Reviewer VLM agents to turn text descriptions into Blender scripts for physically grounded synthetic videos.
- [DreamFactory: Pioneering Multi-Scene Long Video Generation with a Multi-Agent Framework](https://arxiv.org/abs/2408.11788): Uses multi-agent collaboration, chain-of-thought planning, and key-frame iteration to maintain style and identity consistency across long multi-scene videos.
- [FilmAgent](https://arxiv.org/abs/2501.12909): A multi-agent film-automation harness in virtual 3D spaces. Core idea: decompose film creation into coordinated agent roles and executable scene-production steps rather than treating video generation as a single prompt-to-video call.
- [MM-StoryAgent](https://arxiv.org/abs/2503.05242) ([open-source code](https://github.com/X-PLUG/MM_StoryAgent)): A multi-agent harness for narrated storybook video generation. Core idea: coordinate writing, visual generation, narration, sound effects, and music modules so a story can be planned and rendered across text, image, and audio tools rather than generated by one monolithic model.
- [MovieAgent](https://arxiv.org/abs/2503.07314): A multi-agent planning harness for automated long-form video generation. Core idea: assign LLM agents roles such as director, screenwriter, storyboard artist, and location manager so scripts can be decomposed into scenes, shots, camera choices, subtitles, audio, and character-consistent generation steps.
- [V-Stylist](https://arxiv.org/abs/2503.12077): A multi-agent video-stylization harness. Core idea: coordinate video parsing, style-model search, and reflection so MLLM agents can decompose multi-shot videos and iteratively refine stylized outputs.
- [VideoGen-of-Thought: Step-by-step generating multi-shot video with minimal manual intervention](https://arxiv.org/abs/2503.15138): Automates multi-shot video synthesis from one sentence by expanding it into cinematic shot specifications, propagating identity tokens, and validating cross-shot continuity.
- [The Devil is in the Prompts: Retrieval-Augmented Prompt Optimization for Text-To-Video Generation](https://arxiv.org/abs/2504.11739): Adds an external orchestration or execution framework for video, 3D, and world generation.
- [Scaling Image and Video Generation via Test-Time Evolutionary Search](https://arxiv.org/abs/2505.17618): Adds an external orchestration or execution framework for video, 3D, and world generation.
- [AniMaker](https://arxiv.org/abs/2506.10540): a multi-agent harness for animated storytelling. Core idea: combine role-based story planning with MCTS-driven clip generation so long animation can be decomposed, searched, and revised across agents.
- [AniME](https://arxiv.org/abs/2508.18781): a multi-agent planning harness for long animation generation. Core idea: adaptively coordinate planning roles so long animations preserve plot, character, and scene consistency across generated segments.
- [FantasyHSI: Video-Generation-Centric 4D Human Synthesis In Any Scene through A Graph-based Multi-Agent Framework](https://arxiv.org/abs/2509.01232): Uses a graph-based multi-agent framework for long-horizon human-scene interaction video generation. Core idea: coordinate scene navigation, action planning, and critic feedback so generated human behavior remains coherent in unseen scenes.
- [EditDuet](https://arxiv.org/abs/2509.10761): A multi-agent harness for non-linear video editing. Core idea: split editing into an Editor agent that uses video-editing tools and a Critic agent that gives feedback or approves renders, turning instruction-driven editing into an iterative tool-mediated workflow.
- [Code2Video: A Code-centric Paradigm for Educational Video Generation](https://arxiv.org/abs/2510.01174): Uses planner and coder agents to generate educational videos through executable Python rendering code.
- [MagicWand](https://arxiv.org/abs/2511.18352): A user-preference-aligned generation and evaluation agent for image and video AIGC. Core idea: keep preference descriptions in the loop across prompt enhancement, generation, evaluation, and refinement, with UniPreferBench used to assess preference alignment.
- [AutoMV](https://arxiv.org/abs/2512.12196): Coordinates agents over song structure, beats, lyrics, and musical attributes to plan and render temporally consistent full-length music videos.
- [The Script is All You Need](https://arxiv.org/abs/2601.17737): An agentic framework for long-horizon dialogue-to-cinematic video generation, treating scripts as planning artifacts for multi-stage video creation.
- [StoryState: Agent-Based State Control for Consistent and Editable Storybooks](https://arxiv.org/abs/2602.01305): Adds an editable story-state layer with character sheets, global settings, and per-page scene constraints so prompt-only storybook generation can support localized edits without breaking consistency.
- [Retrieval, Refinement, and Ranking for Text-to-Video Generation via Prompt Optimization and Test-Time Scaling](https://arxiv.org/abs/2603.01509): Contributes reusable orchestration, planning, memory, verification, tool use, or runtime logic for video generation, editing, and world models. Core signal: agentic or test-time orchestration around visual generation and world-model construction.
- [ShareVerse](https://arxiv.org/abs/2603.02697): Uses a multi-agent generation workflow to maintain shared-world consistency across video scenes.
- [SPIRAL](https://arxiv.org/abs/2603.08403): A reflective planning harness for long-horizon action-conditioned video generation. Core idea: decompose goals with a PlanAgent, generate segments with memory context, and use a CriticAgent to reflect and repair action execution over time.
- [A Text-Native Interface for Generative Video Authoring](https://arxiv.org/abs/2603.09072): Doki makes freeform text the authoring surface for defining assets, structuring scenes, composing shots, refining edits, and adding audio in one generative-video document.
- [Mind-of-Director](https://arxiv.org/abs/2603.14790): A multimodal agent-driven film previsualization framework, using collaborative decision-making to organize cinematic planning before generation.
- [WorldAgents: Can Foundation Image Models be Agents for 3D World Models?](https://arxiv.org/abs/2603.19708): Contributes reusable orchestration, planning, memory, verification, tool use, or runtime logic for video generation, editing, and world models. Core signal: agentic or test-time orchestration around visual generation and world-model construction.
- [VQ-Jarvis](https://arxiv.org/abs/2603.22998): Builds a retrieval-augmented video-restoration agent with quality perception and efficient search, extending video editing/restoration beyond fixed pipelines.
- [CutClaw](https://arxiv.org/abs/2603.29664) ([open-source code](https://github.com/GVCLab/CutClaw)): An agentic harness for hours-long video editing through music synchronization. Core idea: coordinate long-range editing decisions around audio structure so video-editing agents can handle extended timelines.
- [DIRECT](https://arxiv.org/abs/2604.04875): A video mashup creation framework using hierarchical multi-agent planning and intent-guided editing, relevant to agentic orchestration for video composition.
- [SCMAPR: Self-Correcting Multi-Agent Prompt Refinement for Complex-Scenario Text-to-Video Generation](https://arxiv.org/abs/2604.05489): Uses self-correcting multi-agent prompt refinement for complex-scenario text-to-video generation, making prompt repair an orchestration layer.
- [Camera Artist](https://arxiv.org/abs/2604.09195): A multi-agent framework for cinematic language storytelling video generation, relevant to video-generation harnesses that coordinate narrative, camera, and shot decisions.
- [CANVAS: Continuity-Aware Narratives via Visual Agentic Storyboarding](https://arxiv.org/abs/2604.13452): A multi-agent storyboarding framework that explicitly tracks character continuity, background anchors, and location-aware scene transitions for long-form visual narratives.
- [A LangGraph-Orchestrated Multi-Agent Framework for Automated Multimedia Production](https://doi.org/10.1109/icmsci67830.2026.11469317): A reusable agent harness, runtime, protocol, or workflow scaffold for video, 3D, and world-model generation. Core idea: Published in 2026 Second International Conference on Multi-Agent Systems for Collaborative Intelligence (ICMSCI); metadata title: A LangGraph-Orchestrated Multi-Agent Framework for Automated Multimedia Production.
- [VideoCraft](https://doi.org/10.1145/3746059.3747606): uses mixed-reality spatial layer editing as a workflow for concept-video creation, fitting tool-mediated video-generation harnesses.
- [Boosting Text-to-Video Generative Model with MLLMs Feedback](https://doi.org/10.52202/079017-4426): Uses MLLM preference annotations to build VideoPrefer and VideoRM, turning feedback generation into an alignment loop for text-to-video models.
- [ChoreoCraft: In-situ Crafting of Choreography in Virtual Reality through Creativity Support Tool](https://doi.org/10.1145/3706598.3714220): A VR choreography authoring tool with context-aware motion suggestions and kinematic feedback to help choreographers recover, extend, and evaluate dance sequences.
