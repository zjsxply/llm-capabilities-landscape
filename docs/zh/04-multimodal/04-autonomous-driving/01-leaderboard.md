# 4.4.1 Leaderboard

- [NAVSIM Public Leaderboard](https://huggingface.co/spaces/AGC2025/e2e-driving-navhard)：面向 NAVSIM 场景的公开端到端驾驶规划榜单。
- [CARLA Autonomous Driving Leaderboard](https://leaderboard.carla.org/)：面向仿真中自动驾驶 agent 的公开闭环基准榜单。
- [nuPlan Planning Challenge Leaderboard](https://eval.ai/web/challenges/challenge-page/1856/leaderboard/4360)：nuPlan 基准闭环规划任务的官方 EvalAI 排行榜。
- [Bench2Drive Leaderboard](https://eval.ai/web/challenges/challenge-page/2098/leaderboard/4942)：面向多能力闭环端到端驾驶评测的官方 EvalAI 排行榜。
- [Waymo Open Dataset Challenges](https://waymo.com/open/challenges)：Waymo 感知、运动预测、仿真与端到端驾驶挑战的官方当前及历史排行榜入口。
- [nuScenes Detection Leaderboard](https://www.nuscenes.org/object-detection?externalData=all&mapData=all&modalities=Camera)：nuScenes 3D 目标检测任务的官方排行榜，覆盖 camera、lidar 和 open tracks。
- [OpenAD 3D Object Detection Leaderboard](https://eval.ai/web/challenges/challenge-page/2418/leaderboard)：自动驾驶开放世界 3D 目标检测的官方 EvalAI 排行榜。
