# 1.3.4 Model

- [FLAN](https://arxiv.org/abs/2109.01652): A foundational instruction-tuning method that fine-tunes language models across many natural-language task instructions to improve zero-shot generalization.
- [InstructGPT](https://arxiv.org/abs/2203.02155): The field-defining RLHF recipe for instruction following, combining supervised demonstrations, human-preference reward modeling, and policy optimization.
- [Self-Instruct](https://arxiv.org/abs/2212.10560): A synthetic instruction-data generation method that bootstraps instructions from a language model, filters them, and fine-tunes for stronger instruction adherence.
- [DPO](https://arxiv.org/abs/2305.18290): A preference-optimization algorithm that aligns instruction-following models directly from preference pairs without separately fitting an explicit reward model.
- [ChartAssisstant: A Universal Chart Multimodal Language Model via Chart-to-Table Pre-training and Multitask Instruction Tuning](https://arxiv.org/abs/2401.02384): Trains a chart-focused multimodal language model with chart-to-table pretraining and multitask instruction tuning for chart question answering and reasoning.
- [Examining Forgetting in Continual Pre-training of Aligned Large Language Models](https://arxiv.org/abs/2401.03129): Studies how continual pretraining changes aligned LLM behavior, measuring when new-domain adaptation erodes prior instruction-following and safety alignment.
- [3DMIT: 3D Multi-Modal Instruction Tuning for Scene Understanding](https://arxiv.org/abs/2401.03201): Builds a 3D multimodal instruction-tuning dataset and model recipe for scene-understanding questions grounded in point clouds and visual context.
- [Scaling Laws for Forgetting When Fine-Tuning Large Language Models](https://arxiv.org/abs/2401.05605): Fits empirical scaling laws that predict how model size, data size, and fine-tuning duration affect forgetting during task adaptation.
- [AboutMe: Using Self-Descriptions in Webpages to Document the Effects of English Pretraining Data Filters](https://arxiv.org/abs/2401.06408): Uses webpage self-descriptions to audit how English pretraining-data filters reshape the document mix that later instruction-tuned models inherit.
- [Human-Instruction-Free LLM Self-Alignment with Limited Samples](https://arxiv.org/abs/2401.06785): Aligns an LLM without human-written instructions by using a small seed set to generate and filter self-alignment data.
- [DRLC: Reinforcement Learning with Dense Rewards from LLM Critic](https://arxiv.org/abs/2401.07382): Replaces sparse task rewards with dense feedback from an LLM critic, giving reinforcement learning policies more frequent alignment signals.
- [Linear Alignment: A Closed-form Solution for Aligning Human Preferences without Tuning and Feedback](https://arxiv.org/abs/2401.11458): Proposes a closed-form linear transformation for preference alignment, avoiding iterative fine-tuning and online human feedback.
- [Tradeoffs Between Alignment and Helpfulness in Language Models](https://arxiv.org/abs/2401.16332): Analyzes how alignment interventions can reduce helpfulness, separating refusal behavior and safety gains from general assistant utility.
- [SelectLLM: Can LLMs Select Important Instructions to Annotate?](https://arxiv.org/abs/2401.16553): Uses LLMs to prioritize which instruction examples deserve human annotation, targeting cheaper construction of instruction-tuning sets.
- [Towards Efficient Exact Optimization of Language Model Alignment](https://arxiv.org/abs/2402.00856): Develops exact optimization techniques for language-model alignment objectives, reducing approximation error in preference-based training.
- [Intent-based Prompt Calibration: Enhancing prompt optimization with synthetic boundary cases](https://arxiv.org/abs/2402.03099): Calibrates prompts by generating synthetic boundary cases that expose intent mismatches before prompt optimization.
- [Rethinking the Role of Proxy Rewards in Language Model Alignment](https://arxiv.org/abs/2402.03469): Examines when proxy rewards guide or mislead alignment training, clarifying the limits of reward-model substitution for human preferences.
- [Long Is More for Alignment: A Simple but Tough-to-Beat Baseline for Instruction Fine-Tuning](https://arxiv.org/abs/2402.04833): Shows that longer responses in instruction fine-tuning form a strong baseline for perceived alignment and assistant quality.
- [Pedagogical Alignment of Large Language Models](https://arxiv.org/abs/2402.05000): Frames alignment as teaching behavior and trains LLMs to produce responses that better match pedagogical goals and learner needs.
- [A Closer Look at the Limitations of Instruction Tuning](https://arxiv.org/abs/2402.05119): Tests where instruction tuning fails to generalize, identifying limits in task transfer and robustness beyond the supervised instruction mix.
- [DeAL: Decoding-time Alignment for Large Language Models](https://arxiv.org/abs/2402.06147): Applies alignment at decoding time, steering generation without changing model weights.
- [Towards Unified Alignment Between Agents, Humans, and Environment](https://arxiv.org/abs/2402.07744): Connects human, agent, and environment preferences into a unified alignment objective for interactive systems.
- [Text-centric Alignment for Multi-Modality Learning](https://arxiv.org/abs/2402.08086): Aligns multimodal representations around text supervision so visual and other modalities better follow language instructions.
- [PRompt Optimization in Multi-Step Tasks (PROMST): Integrating Human Feedback and Preference Alignment](https://arxiv.org/abs/2402.08702): Optimizes prompts for multi-step tasks by incorporating human feedback and preference-aligned prompt search.
- [Answer is All You Need: Instruction-following Text Embedding via Answering the Question](https://arxiv.org/abs/2402.09642): Trains text embeddings through question-answering behavior so retrieval representations follow natural-language instructions.
- [Aligning Crowd Feedback via Distributional Preference Reward Modeling](https://arxiv.org/abs/2402.09764): Models crowd preferences as distributions instead of single labels, preserving disagreement when fitting reward models.
- [Reward Generalization in RLHF: A Topological Perspective](https://arxiv.org/abs/2402.10184): Uses topology to study when RLHF reward models generalize across response spaces and when they overfit local preference patterns.
- [BitDelta: Your Fine-Tune May Only Be Worth One Bit](https://arxiv.org/abs/2402.10193): Compresses fine-tuning updates into one-bit weight deltas, showing much of the adaptation signal can be retained with extreme quantization.
- [Exploration-Driven Policy Optimization in RLHF: Theoretical Insights on Efficient Data Utilization](https://arxiv.org/abs/2402.10342): Analyzes how exploration choices affect RLHF sample efficiency and policy improvement under limited preference data.
- [Relative Preference Optimization: Enhancing LLM Alignment through Contrasting Responses across Identical and Diverse Prompts](https://arxiv.org/abs/2402.10958): Optimizes preferences by contrasting responses both within the same prompt and across diverse prompts.
- [KnowTuning: Knowledge-aware Fine-tuning for Large Language Models](https://arxiv.org/abs/2402.11176): Injects knowledge-aware objectives into fine-tuning so instruction-following models retain factual and domain knowledge.
- [Dissecting Human and LLM Preferences](https://arxiv.org/abs/2402.11296): Compares human and model preference patterns to reveal where automated preference signals diverge from human judgments.
- [Chain-of-Instructions: Compositional Instruction Tuning on Large Language Models](https://arxiv.org/abs/2402.11532): Uses chained and compositional instructions during fine-tuning to improve multi-step instruction following.
- [Reformatted Alignment](https://arxiv.org/abs/2402.12219): Studies how response formatting affects alignment training and whether format changes can recover preference-aligned behavior.
- [Your Vision-Language Model Itself Is a Strong Filter: Towards High-Quality Instruction Tuning with Data Selection](https://arxiv.org/abs/2402.12501): Uses the target vision-language model as a data selector to filter higher-quality examples for visual instruction tuning.
- [Instruction-tuned Language Models are Better Knowledge Learners](https://arxiv.org/abs/2402.12847): Shows instruction tuning improves how language models absorb and use new knowledge during subsequent fine-tuning.
- [Synthetic Data (Almost) from Scratch: Generalized Instruction Tuning for Language Models](https://arxiv.org/abs/2402.13064): Generates broad synthetic instruction data with minimal human seeds to support generalized instruction tuning.
- [ELAD: Explanation-Guided Large Language Models Active Distillation](https://arxiv.org/abs/2402.13098): Selects distillation examples with explanation signals, using active learning to transfer teacher-model behavior more efficiently.
- [Bayesian Reward Models for LLM Alignment](https://arxiv.org/abs/2402.13210): Fits reward models with Bayesian uncertainty so alignment training can account for ambiguous or sparse preference labels.
- [Self-Distillation Bridges Distribution Gap in Language Model Fine-Tuning](https://arxiv.org/abs/2402.13669): Uses self-distillation to reduce the distribution gap between pretrained behavior and downstream fine-tuning data.
- [COPR: Continual Human Preference Learning via Optimal Policy Regularization](https://arxiv.org/abs/2402.14228): Regularizes policy updates so models can keep learning new human preferences without overwriting earlier alignment.
- [Q-Probe: A Lightweight Approach to Reward Maximization for Language Models](https://arxiv.org/abs/2402.14688): Adds a lightweight probe to estimate reward-improving directions for generation without full policy retraining.
- [Data-Efficient Operator Learning via Unsupervised Pretraining and In-Context Learning](https://arxiv.org/abs/2402.15734): Combines unsupervised pretraining with in-context learning to reduce labeled data needs for operator-learning models.
- [Multimodal Instruction Tuning with Conditional Mixture of LoRA](https://arxiv.org/abs/2402.15896): Routes multimodal instruction-tuning examples through conditional LoRA experts for parameter-efficient adaptation.
- [Don't Forget Your Reward Values: Language Model Alignment via Value-based Calibration](https://arxiv.org/abs/2402.16030): Calibrates language-model outputs with value estimates so reward information remains available during aligned generation.
- [InstructEdit: Instruction-based Knowledge Editing for Large Language Models](https://arxiv.org/abs/2402.16123): Edits model knowledge through explicit natural-language instructions rather than raw fact triples or gradient-only updates.
- [Set the Clock: Temporal Alignment of Pretrained Language Models](https://arxiv.org/abs/2402.16797): Adapts pretrained language models to time-sensitive knowledge and behavior so outputs better match a target temporal context.
- [RECOST: External Knowledge Guided Data-efficient Instruction Tuning](https://arxiv.org/abs/2402.17355): Uses external knowledge to select or construct fewer but more informative examples for instruction tuning.
- [SoFA: Shielded On-the-fly Alignment via Priority Rule Following](https://arxiv.org/abs/2402.17358): Enforces priority rules during generation to provide on-the-fly safety alignment without full retraining.
- [Pragmatic Instruction Following and Goal Assistance via Cooperative Language-Guided Inverse Planning](https://arxiv.org/abs/2402.17930): Uses cooperative inverse planning to infer user goals behind instructions and generate more helpful goal-directed assistance.
- [DecisionNCE: Embodied Multimodal Representations via Implicit Preference Learning](https://arxiv.org/abs/2402.18137): Learns embodied multimodal representations from implicit preference comparisons instead of explicit action labels.
- [Learning to Generate Instruction Tuning Datasets for Zero-Shot Task Adaptation](https://arxiv.org/abs/2402.18334): Trains a generator to create instruction-tuning datasets that adapt models to unseen tasks without task-specific labeled data.
- [Reward Model Learning vs. Direct Policy Optimization: A Comparative Analysis of Learning from Human Preferences](https://arxiv.org/abs/2403.01857): Compares explicit reward-model training with direct policy optimization to clarify when each preference-learning route is preferable.
- [Balancing Enhancement, Harmlessness, and General Capabilities: Enhancing Conversational LLMs with Direct RLHF](https://arxiv.org/abs/2403.02513): Uses direct RLHF to improve conversational behavior while tracking tradeoffs among helpfulness, harmlessness, and broad capability.
- [Negating Negatives: Alignment without Human Positive Samples via Distributional Dispreference Optimization](https://arxiv.org/abs/2403.03419): Aligns models from negative-only feedback by optimizing against a distribution of dispreferred responses.
- [On the Essence and Prospect: An Investigation of Alignment Approaches for Big Models](https://arxiv.org/abs/2403.04204): Reviews and analyzes major alignment approaches for large models, including supervised tuning, RLHF, constitutional methods, and preference optimization.
- [Adaptive Task Balancing for Visual Instruction Tuning via Inter-Task Contribution and Intra-Task Difficulty](https://arxiv.org/abs/2403.04343): Balances visual instruction-tuning tasks by estimating each task's contribution and example-level difficulty.
- [Provable Multi-Party Reinforcement Learning with Diverse Human Feedback](https://arxiv.org/abs/2403.05006): Gives provable reinforcement-learning methods for combining feedback from multiple humans with diverse preferences.
- [Aligning Large Language Models for Controllable Recommendations](https://arxiv.org/abs/2403.05063): Aligns recommendation-oriented LLMs so users can steer recommendation constraints and preferences through natural-language control.
- [Overcoming Reward Overoptimization via Adversarial Policy Optimization with Lightweight Uncertainty Estimation](https://arxiv.org/abs/2403.05171): Combines adversarial policy optimization with lightweight uncertainty estimates to reduce reward overoptimization in RLHF.
- [Bayesian Preference Elicitation with Language Models](https://arxiv.org/abs/2403.05534): Uses language models to ask informative preference-elicitation questions under a Bayesian model of user utilities.
- [IndicLLMSuite: A Blueprint for Creating Pre-training and Fine-Tuning Datasets for Indian Languages](https://arxiv.org/abs/2403.06350): Defines a data-building pipeline for Indian-language pretraining and instruction fine-tuning corpora.
- [ALaRM: Align Language Models via Hierarchical Rewards Modeling](https://arxiv.org/abs/2403.06754): Builds hierarchical reward models that decompose alignment feedback into multiple levels of preference signals.
- [Curry-DPO: Enhancing Alignment using Curriculum Learning & Ranked Preferences](https://arxiv.org/abs/2403.07230): Combines curriculum learning with ranked preferences to make DPO training progress from easier to harder alignment cases.
- [Improving Reinforcement Learning from Human Feedback Using Contrastive Rewards](https://arxiv.org/abs/2403.07708): Trains RLHF policies with contrastive reward signals that compare preferred and rejected responses more directly.
- [Fine-tuning Large Language Models with Sequential Instructions](https://arxiv.org/abs/2403.07794): Fine-tunes LLMs on sequences of dependent instructions to improve multi-turn and stepwise instruction following.
- [Scaling Data Diversity for Fine-Tuning Language Models in Human Alignment](https://arxiv.org/abs/2403.11124): Studies how increasing diversity in fine-tuning data affects human-aligned behavior and general instruction following.
- [A Moral Imperative: The Need for Continual Superalignment of Large Language Models](https://arxiv.org/abs/2403.14683): Argues for continual superalignment methods that repeatedly update models as capabilities, values, and deployment contexts change.
- [MetaAligner: Conditional Weak-to-Strong Correction for Generalizable Multi-Objective Alignment of Language Models](https://arxiv.org/abs/2403.17141): Trains a policy-agnostic meta-aligner that reformulates objective-labeled preference data and performs conditional weak-to-strong correction, enabling plug-and-play multi-objective alignment across policy models.
- [COIG-CQIA: Quality is All You Need for Chinese Instruction Fine-tuning](https://arxiv.org/abs/2403.18058): Releases a human-verified Chinese instruction-tuning dataset from real-world resources and evaluates data-mixing choices for models aligned to Chinese interaction patterns.
- [Understanding the Learning Dynamics of Alignment with Human Feedback](https://arxiv.org/abs/2403.18742): Theoretically analyzes how preference-dataset distributions control policy-update rates and preference distinguishability during human-feedback alignment.
- [sDPO: Don't Use Your Data All at Once](https://arxiv.org/abs/2403.19270): Splits preference data into stepwise DPO stages so later updates use a more closely aligned reference model instead of consuming all pairs at once.
- [Fine-Tuning Language Models with Reward Learning on Policy](https://arxiv.org/abs/2403.19279): Refines reward models on current policy samples with unsupervised multi-view representations and synthetic preferences to reduce off-distribution reward learning in RLHF.
- [Mixed Preference Optimization: Reinforcement Learning with Data Selection and Better Reference Model](https://arxiv.org/abs/2403.19443): Combines DPO on reward-easy response pairs with RLHF on reward-hard pairs, using the DPO policy as the reference model for online refinement.
- [ChatGLM-RLHF: Practices of Aligning Large Language Models with Human Feedback](https://arxiv.org/abs/2404.00934): Documents the ChatGLM production RLHF pipeline, including human preference collection, reward-model training, policy optimization, variance mitigation, model parallelism, and anti-forgetting regularization.
- [Regularized Best-of-N Sampling to Mitigate Reward Hacking for Language Model Alignment](https://arxiv.org/abs/2404.01054): Adds a minimum-Bayes-risk proximity regularizer to reward-model best-of-N decoding and uses the resulting samples to build stronger DPO preference data.
- [Asymptotics of Language Model Alignment](https://arxiv.org/abs/2404.01730): Derives closed-form and asymptotic links between KL-constrained reinforcement-learning alignment and best-of-N selection under simplified language and reward models.
- [Automatic Prompt Selection for Large Language Models](https://arxiv.org/abs/2404.02717): Clusters training data, generates synthetic candidate prompts, and trains a prompt evaluator to choose input-specific prompts for zero-shot math question answering.
- [An Incomplete Loop: Instruction Inference, Instruction Following, and In-context Learning in Language Models](https://arxiv.org/abs/2404.03028): Compares explicit instructions, few-shot examples, and generated task descriptions across GPT and Llama models on arithmetic and translation tasks, showing non-systematic transfer among these prompting modes.
- [CantTalkAboutThis: Aligning Language Models to Stay on Topic in Dialogues](https://arxiv.org/abs/2404.03820): Introduces a synthetic distracted-dialogue dataset for fine-tuning chat models to resist off-topic turns and maintain assigned roles in task-oriented conversations.
- [Binary Classifier Optimization for Large Language Model Alignment](https://arxiv.org/abs/2404.04656): Aligns LLMs from thumbs-up or thumbs-down feedback by training a binary classifier whose logit acts as an implicit reward approximating DPO.
- [Towards Understanding the Influence of Reward Margin on Preference Model Performance](https://arxiv.org/abs/2404.04932): Estimates preference-margin values without exhaustive labels and shows that margin-aware reward-model training improves reward prediction and downstream alignment behavior.
- [Facial Affective Behavior Analysis with Instruction Tuning](https://arxiv.org/abs/2404.05052): Builds the EmoLA multimodal instruction model with facial-prior and LoRA modules, plus a FABA instruction dataset and benchmark for emotion and action-unit reasoning.
- [Not All Contexts Are Equal: Teaching LLMs Credibility-aware Generation](https://arxiv.org/abs/2404.06809): Generates credibility-labeled RAG training data and a three-scenario benchmark so models learn to weight retrieved evidence by source reliability.
- [Self-Supervised Visual Preference Alignment](https://arxiv.org/abs/2404.10501): Creates chosen and rejected VLM responses from original versus augmented image pairs and applies DPO without GPT-4 or human preference supervision.
- [Stepwise Alignment for Constrained Language Model Policy Optimization](https://arxiv.org/abs/2404.11049): Formulates alignment as reward maximization under safety constraints and applies SACPO stepwise with DPO-style updates for helpfulness and harmlessness.
- [TextSquare: Scaling up Text-Centric Visual Instruction Tuning](https://arxiv.org/abs/2404.12803): Generates the Square-10M text-centric VQA instruction dataset through self-questioning, answering, reasoning, and evaluation, then trains TextSquare for OCR-heavy multimodal reasoning.
- [Mapping Social Choice Theory to RLHF](https://arxiv.org/abs/2404.13038): Analyzes where RLHF preference aggregation differs from social-choice voting settings, clarifying which impossibility and aggregation results transfer to alignment.
- [Filtered Direct Preference Optimization](https://arxiv.org/abs/2404.13846): Uses a reward model during DPO training to discard low-quality preference samples relative to current model outputs, improving reward-model-free alignment.
- [Optimal Design for Human Preference Elicitation](https://arxiv.org/abs/2404.13895): Adapts optimal experimental design to listwise preference questions, choosing annotation queries that efficiently learn absolute and ranking feedback models.
- [Self-Supervised Alignment with Mutual Information: Learning to Follow Principles without Preference Labels](https://arxiv.org/abs/2404.14313): Introduces SAMI, an iterative fine-tuning algorithm that maximizes mutual information between written constitutions and self-generated responses without preference labels or demonstrations.
- [From Complex to Simple: Enhancing Multi-Constraint Complex Instruction Following Ability of Large Language Models](https://arxiv.org/abs/2404.15846): Studies multi-constraint instruction data, then constructs and uses effective complex-instruction training examples that generalize across in-domain, out-of-domain, and adversarial constraints.
- [Prefix Text as a Yarn: Eliciting Non-English Alignment in Foundation Language Model](https://arxiv.org/abs/2404.16766): Proposes PreTTY, a training-free multilingual alignment method that seeds decoding with one or two task-related prefix tokens to make foundation LLMs approach SFT performance on translation and tagging.
- [HFT: Half Fine-Tuning for Large Language Models](https://arxiv.org/abs/2404.18466): Freezes half of the parameters during SFT, DPO, and continual fine-tuning so models learn new instruction behavior while reducing catastrophic forgetting and training time.
- [Creative Beam Search: LLM-as-a-Judge For Improving Response Generation](https://arxiv.org/abs/2405.00099): Combines diverse beam search with an LLM judge that validates candidate responses, making decoding-time response generation more intentional than standard sampling.
- [Self-Refine Instruction-Tuning for Aligning Reasoning in Language Models](https://arxiv.org/abs/2405.00402): Transfers reasoning demonstrations from large to small models, then uses DPO-style self-refinement with sampled reasoning paths and ground-truth rewards for math and commonsense alignment.
- [MANTIS: Interleaved Multi-Image Instruction Tuning](https://arxiv.org/abs/2405.01483): Builds the 721K-example Mantis-Instruct dataset and trains multi-image LMMs for co-reference, comparison, temporal understanding, and reasoning without massive noisy interleaved pretraining.
- [D2PO: Discriminator-Guided DPO with Response Evaluation Models](https://arxiv.org/abs/2405.01511): Adds a separate response-evaluation discriminator to online DPO so gold preferences can silver-label synthetic pairs and reduce preference-data requirements.
- [LLM Theory of Mind and Alignment: Opportunities and Risks](https://arxiv.org/abs/2405.08154): Analyzes theory-of-mind behavior as an alignment-relevant model property, covering goal inference, conversational adaptation, empathy, group cooperation, and moral judgment risks.
- [Intuitive Fine-Tuning: Towards Simplifying Alignment into a Single Process](https://arxiv.org/abs/2405.11870): Unifies SFT and preference optimization through token-level preference estimation and transition optimization, using a temporal residual connection on ordinary SFT-style data.
- [SPO: Multi-Dimensional Preference Sequential Alignment With Implicit Reward Modeling](https://arxiv.org/abs/2405.12739): Sequentially optimizes helpfulness, harmlessness, and other preference dimensions without explicit reward models, deriving a closed-form policy and loss for multi-objective alignment.
- [The Echoes of Multilinguality: Tracing Cultural Value Shifts during LM Fine-tuning](https://arxiv.org/abs/2405.12744): Traces how multilingual fine-tuning data shifts culturally dependent values across languages, using training-data attribution to identify examples that trigger value drift.
- [Mosaic-IT: Cost-Free Compositional Data Synthesis for Instruction Tuning](https://arxiv.org/abs/2405.13326): Synthesizes compositional instruction examples by concatenating existing instruction-response pairs under higher-level meta-instructions, improving multi-step and format following while cutting training cost.
- [Disperse-Then-Merge: Pushing the Limits of Instruction Tuning via Alignment Tax Reduction](https://arxiv.org/abs/2405.13432): Splits instruction data into portions, fine-tunes separate submodels, and merges them to reduce late-stage SFT alignment tax on knowledge and reasoning benchmarks.
- [AlignGPT: Multi-modal Large Language Models with Adaptive Alignment Capability](https://arxiv.org/abs/2405.14129): Groups image-text pairs by alignment degree during pretraining and adaptively recombines alignment-level representations during instruction tuning for task-specific multimodal alignment.
- [Maintaining Structural Integrity in Parameter Spaces for Parameter Efficient Fine-tuning](https://arxiv.org/abs/2405.14739): Generalizes PEFT beyond 2D LoRA by modeling low-rank updates in N-dimensional tensor parameter spaces while preserving their topology across NLP, vision, and multimodal tasks.
- [MallowsPO: Fine-Tune Your LLM with Preference Dispersions](https://arxiv.org/abs/2405.14953): Extends DPO with a Mallows-inspired dispersion index that captures diversity in human rankings and can plug into offline preference optimization.
- [Reinforcing Language Agents via Policy Optimization with Action Decomposition](https://arxiv.org/abs/2405.15821): Decomposes language-agent actions to token-level Bellman backups, giving PPO finer credit assignment for unrestricted action spaces in interactive environments.
- [Mechanism Design for LLM Fine-tuning with Multiple Reward Models](https://arxiv.org/abs/2405.16276): Frames multi-reward LLM fine-tuning as mechanism design, adding VCG-style payments so agents with different preferences have incentives to report reward objectives truthfully.
- [Multi-Reference Preference Optimization for Large Language Models](https://arxiv.org/abs/2405.16388): Replaces single-reference DPO with a closed-form multi-reference objective that leverages several pretrained models as priors for more robust preference learning.
- [Implicit Multimodal Alignment: On the Generalization of Frozen LLMs to Multimodal Inputs](https://arxiv.org/abs/2405.16700): Shows frozen LLMs internally align perceptual and textual tokens, using that implicit alignment as a proxy for multimodal performance, hallucination risk, and inference compression.
- [Getting More Juice Out of the SFT Data: Reward Learning from Human Demonstration Improves SFT for LLM Alignment](https://arxiv.org/abs/2405.17888): Improves supervised fine-tuning for LLM alignment by learning rewards from human demonstrations.
- [Online Merging Optimizers for Boosting Rewards and Mitigating Tax in Alignment](https://arxiv.org/abs/2405.17931): Interpolates RLHF policy updates with SFT and pretrained parameter directions at each step, improving alignment reward while mitigating capability loss across DPO and KTO variants.
- [Unified Preference Optimization: Language Model Alignment Beyond the Preference Frontier](https://arxiv.org/abs/2405.17956): Decomposes preference and auxiliary objectives so DPO-style training can optimize human preferences plus designer goals such as style or harm reduction without extra preference data.
- [Outlier-weighed Layerwise Sampling for LLM Fine-tuning](https://arxiv.org/abs/2405.18380): Samples and fine-tunes layers according to outlier distributions, then adds low-rank gradient projection for memory-efficient LLM adaptation that can outperform LoRA.
- [Efficient Model-agnostic Alignment via Bayesian Persuasion](https://arxiv.org/abs/2405.18718): Trains a small advisor model to send Bayesian-persuasion signals that steer black-box receiver LLMs toward better math and code responses without updating receiver weights.
- [Weak-to-Strong Search: Align Large Language Models via Searching over Small Language Models](https://arxiv.org/abs/2405.19262): Guides a frozen large model at test time by maximizing the log-probability gap between tuned and untuned small models, avoiding direct large-model fine-tuning.
- [Group Robust Preference Optimization in Reward-free RLHF](https://arxiv.org/abs/2405.20304): Optimizes reward-free preferences for worst-group performance, targeting subgroup failures that ordinary average-case preference optimization can hide.
- [Joint Embeddings for Graph Instruction Tuning](https://arxiv.org/abs/2405.20684): Aligns graph and language representations through joint embeddings so LLMs can follow graph-structured instructions for graph understanding tasks.
- [The AI Alignment Paradox](https://arxiv.org/abs/2405.20806): Explains the tension between steering AI systems toward human values and preserving pluralistic or contested goals, making it an off-axis conceptual alignment entry rather than a training recipe.
- [Scalable Ensembling For Mitigating Reward Overoptimisation](https://arxiv.org/abs/2406.01013): Uses ensembles of reward models to reduce RLHF reward overoptimization, making proxy-reward selection more robust during aligned generation.
- [LoFiT: Localized Fine-tuning on LLM Representations](https://arxiv.org/abs/2406.01563): Localizes fine-tuning to representation subspaces associated with target behavior, adapting LLMs while limiting unnecessary parameter updates.
- [Self-Improving Robust Preference Optimization](https://arxiv.org/abs/2406.01660): Iteratively generates preference data with the current policy and optimizes against it, improving robustness over static offline DPO-style alignment.
- [Dishonesty in Helpful and Harmless Alignment](https://arxiv.org/abs/2406.01931): Studies how helpfulness and harmlessness alignment incentives can produce dishonest model behavior, exposing an evaluation failure mode for preference-trained assistants.
- [Computational Limits of Low-Rank Adaptation (LoRA) Fine-Tuning for Transformer Models](https://arxiv.org/abs/2406.03136): Analyzes when LoRA can or cannot express fine-tuning updates in transformers, clarifying limits of parameter-efficient instruction adaptation.
- [Is Free Self-Alignment Possible?](https://arxiv.org/abs/2406.03642): Tests whether pretrained LMs can self-align with little or no preference data, probing the boundary between intrinsic model feedback and supervised alignment.
- [Self-Play with Adversarial Critic: Provable and Scalable Offline Alignment for Language Models](https://arxiv.org/abs/2406.04274): Uses self-play against an adversarial critic on offline preference data, giving a scalable alignment objective with theoretical guarantees.
- [Phased Instruction Fine-Tuning for Large Language Models](https://arxiv.org/abs/2406.04371): Adds a model entry for Instruction Following, because it uses phased instruction fine-tuning for large language models.
- [Spread Preference Annotation: Direct Preference Judgment for Efficient LLM Alignment](https://arxiv.org/abs/2406.04412): Designs preference questions that directly judge response spread, aiming to collect more efficient human feedback for LLM alignment.
- [Distributional Preference Alignment of LLMs via Optimal Transport](https://arxiv.org/abs/2406.05882): Aligns the full distribution of model responses to preference distributions with optimal transport, moving beyond sample-level pairwise labels.
- [Aligning Large Language Models with Representation Editing: A Control Perspective](https://arxiv.org/abs/2406.05954): Treats alignment as controllable representation editing, steering model activations instead of relying only on full preference fine-tuning.
- [Inverse Constitutional AI: Compressing Preferences into Principles](https://arxiv.org/abs/2406.06560): Infers concise constitutional principles from pairwise preference data, compressing examples into reusable rules for alignment and evaluation.
- [Prototypical Reward Network for Data-Efficient RLHF](https://arxiv.org/abs/2406.06606): Builds a prototype-based reward model that needs fewer human preference labels by comparing responses to learned preference prototypes.
