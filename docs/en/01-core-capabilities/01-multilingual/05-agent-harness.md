# 1.1.5 Agent Harness

- [ReAct](https://arxiv.org/abs/2210.03629) ([open-source code](https://github.com/ysymyth/ReAct)): a general `think -> act -> observe` framework. In multilingual settings, it is more like a controllable cross-lingual workflow skeleton that can make `language detection -> translation/back-translation -> retrieval/verification -> output` explicit instead of hiding cross-lingual processing in one answer.
- [Reflexion](https://arxiv.org/abs/2303.11366) ([open-source code](https://github.com/noahshinn/reflexion)): iteratively improves answers through failure reflection and memory writing. In multilingual tasks, it can be used to repair errors across turns, such as mistranslated terms, missed constraints, and entity mismatches.
- [DSPy](https://arxiv.org/abs/2310.03714) ([open-source code](https://github.com/stanfordnlp/dspy)): organizes `translation -> retrieval -> answer -> verification` as a programmable program. In multilingual tasks, it is suitable for solidifying cross-lingual retrieval and evidence-consistency constraints.
- [Enhancing Multilingual Information Retrieval in Mixed Human Resources Environments: A RAG Model Implementation for Multicultural Enterprise](https://arxiv.org/abs/2401.01511): Implements an enterprise HR RAG pipeline that retrieves across multilingual employee-policy material so multicultural users can query internal information in their own languages.
- [Improving LLM-based Machine Translation with Systematic Self-Correction](https://arxiv.org/abs/2402.16379): Wraps LLM translation in a systematic self-correction loop that detects translation errors, revises candidates, and iterates without retraining the base model.
- [Decomposed Prompting: Unveiling Multilingual Linguistic Structure Knowledge in English-Centric Large Language Models](https://arxiv.org/abs/2402.18397): Decomposes multilingual linguistic-structure probes into prompted subtasks to expose what English-centric LLMs know about non-English syntax and morphology.
- [Retrieving Examples from Memory for Retrieval Augmented Neural Machine Translation: A Systematic Comparison](https://arxiv.org/abs/2404.02835): Compares example-memory retrieval strategies for retrieval-augmented NMT, testing how translation memory selection affects sentence-level MT quality.
- [LLM-Assisted Rule Based Machine Translation for Low/No-Resource Languages](https://arxiv.org/abs/2405.08997): Uses LLMs to help author and refine rule-based MT resources for low-resource languages, keeping explicit linguistic rules in the translation workflow.
- [Context-aware and Style-related Incremental Decoding framework for Discourse-Level Literary Translation](https://arxiv.org/abs/2409.16539): Adds incremental decoding with discourse context and style constraints so literary translation can preserve cross-sentence coherence and authorial tone.
- [Multilingual Retrieval Augmented Generation for Culturally-Sensitive Tasks: A Benchmark for Cross-lingual Robustness](https://arxiv.org/abs/2410.01171): Defines a culturally sensitive multilingual RAG evaluation that stresses cross-lingual retrieval robustness and culturally grounded answer generation.
- [DelTA: An Online Document-Level Translation Agent Based on Multi-Level Memory](https://arxiv.org/abs/2410.08143): Implements an online document-level translation agent with multi-level memory.
- [Kahani: Culturally-Nuanced Visual Storytelling Tool for Non-Western Cultures](https://arxiv.org/abs/2410.19419): Provides an interactive visual-storytelling tool that guides users through culturally grounded narrative creation for non-Western contexts.
- [CRAT: A Multi-Agent Framework for Causality-Enhanced Reflective and Retrieval-Augmented Translation with Large Language Models](https://arxiv.org/abs/2410.21067): Coordinates causal analysis, retrieval augmentation, reflection, and translation agents to revise LLM machine-translation outputs with explicit error reasoning.
- [GlotCC: An Open Broad-Coverage CommonCrawl Corpus and Pipeline for Minority Languages](https://arxiv.org/abs/2410.23825): Releases a CommonCrawl-based corpus and filtering pipeline for minority languages, making it stronger as data infrastructure than as an agent harness.
- [M-MAD: Multidimensional Multi-Agent Debate for Advanced Machine Translation Evaluation](https://arxiv.org/abs/2412.20127): Uses multiple debate agents to evaluate translations across adequacy, fluency, terminology, and other MT quality dimensions before forming a judgment.
- [TransAgents: Build Your Translation Company with Language Agents](https://doi.org/10.18653/v1/2024.emnlp-demo.14): Simulates a translation company with specialized language-agent roles for translation, editing, review, and project coordination.
- [Doc-Guided Sent2Sent++: A Sent2Sent++ Agent with Doc-Guided memory for Document-level Machine Translation](https://arxiv.org/abs/2501.08523): Adds document-guided memory to a sentence-to-sentence translation agent, making document-level machine translation an explicit memory-augmented multilingual workflow.
- [Edit Once, Update Everywhere: A Simple Framework for Cross-Lingual Knowledge Synchronization in LLMs](https://arxiv.org/abs/2502.14645): Synchronizes factual edits across languages by applying one knowledge update and propagating it to multilingual model behavior.
- [LegalRAG: A Hybrid RAG System for Multilingual Legal Information Retrieval](https://arxiv.org/abs/2504.16121): Combines lexical and dense retrieval with generation for multilingual legal search, grounding legal answers in retrieved multilingual statutes or case material.
- [MAATS](https://arxiv.org/abs/2505.14848): A multi-agent automated translation harness based on MQM evaluation. Core idea: split translation, quality analysis, and revision into coordinated agent roles so multilingual generation can be improved and audited through explicit criteria.
- [HiMATE: A Hierarchical Multi-Agent Framework for Machine Translation Evaluation](https://arxiv.org/abs/2505.16281): Uses a hierarchical multi-agent framework for machine-translation evaluation.
- [TACTIC: Translation Agents with Cognitive-Theoretic Interactive Collaboration](https://arxiv.org/abs/2506.08403): A multi-agent machine-translation harness. Core idea: decompose translation into cognitively motivated collaborative subtasks so agents can revise and validate translations through interaction.
- [EfficientXLang](https://arxiv.org/abs/2507.00246) ([open-source code](https://github.com/microsoft/EfficientXLang)): a cross-lingual test-time reasoning harness. The core idea is to route the same reasoning task to a more token-efficient language, then check whether accuracy and language consistency are preserved; it is suitable for multilingual reasoning cost/quality tradeoff experiments.
- [Pun Intended: Multi-Agent Translation of Wordplay with Contrastive Learning and Phonetic-Semantic Embeddings](https://arxiv.org/abs/2507.06506): Contributes reusable orchestration, planning, memory, verification, tool use, or runtime logic for multilingual capability. Core signal: agentic translation, multi-agent translation, or explicit multilingual workflow orchestration.
- [Checklist Engineering Empowers Multilingual LLM Judges](https://arxiv.org/abs/2507.06774): Uses checklist engineering as a training-free multilingual LLM-as-a-judge workflow, improving pointwise and pairwise evaluation without target-language fine-tuning.
- [ViDove: A Translation Agent System with Multimodal Context and Memory-Augmented Reasoning](https://arxiv.org/abs/2507.07306): LLM-based translation agents have achieved highly human-like translation results and are capable of handling longer and more complex contexts with greater efficiency.
- [Robust Native Language Identification through Agentic Decomposition](https://arxiv.org/abs/2509.16666): Decomposes native-language identification into agentic linguistic evidence checks instead of making a single-pass authorship prediction.
- [Selective Translation for multilingual reasoning](https://arxiv.org/abs/2510.27269): A test-time mitigation for multilingual reasoning gaps. Core idea: detect understanding failures and insert an English translation only when needed, approaching full-translation accuracy while translating a small fraction of inputs.
- [RACQC: Advanced Retrieval-Augmented Generation for Chinese Query Correction](https://doi.org/10.18653/v1/2025.findings-emnlp.36): Uses retrieval-augmented generation to correct Chinese queries by grounding rewrites in retrieved evidence and query-correction context.
- [AgriGPT-Omni: A Unified Speech–Vision–Text Framework for Multilingual Agricultural Intelligence](https://arxiv.org/abs/2512.10624): Unifies speech, vision, and text interfaces for multilingual agricultural assistance, closer to a multimodal domain system than a generic agent harness.
- [LITMUS++](https://doi.org/10.18653/v1/2025.ijcnlp-demo.6): Uses agents to synthesize evidence across tasks and models when direct benchmark results are sparse for low-resource languages.
- [Agent-SiMT: Agent-Assisted Simultaneous Translation With Large Language Models](https://doi.org/10.1109/taslpro.2025.3566220): Frames simultaneous translation as an agent-assisted process that manages partial context, anticipation, and incremental output under latency constraints.
- [Building from Scratch: A Multi-Agent Framework with Human-in-the-Loop for Multilingual Legal Terminology Mapping](https://arxiv.org/abs/2512.12950): Coordinates agents and human reviewers to build multilingual legal terminology mappings from scratch, combining candidate extraction, validation, and expert correction.
- [Agent for Anti-Discriminatory Language (AAL) A Human-Centered AI Approach to Discriminatory Speech in Italian](https://doi.org/10.1109/ieee-ch65308.2025.11279699): Presents a human-centered Italian-language agent for detecting and responding to discriminatory speech, with multilingual-page fit limited to language-specific safety tooling.
- [Impact of Large Language Models on Conversational Translation: Towards Translation Agents](https://doi.org/10.1109/aciis66255.2025.11402976): Discusses conversational translation agents that maintain dialogue context, speaker intent, and turn-level translation decisions rather than isolated sentence translation.
- [Revisiting Round-Trip Translation with LLMs and Agentic Translation](https://doi.org/10.1109/seai65851.2025.11108752): Contributes reusable orchestration, planning, memory, verification, tool use, or runtime logic for multilingual capability. Core signal: agentic translation, multi-agent translation, or explicit multilingual workflow orchestration.
- [Multi-agentMT: Deploying AI Agent in the WMT25 Shared Task](https://doi.org/10.18653/v1/2025.wmt-1.53): Deploys an AI-agent approach in the WMT25 machine-translation shared task.
- [NeoAMT: Neologism-Aware Agentic Machine Translation with Reinforcement Learning](https://arxiv.org/abs/2601.03790): Builds a neologism-aware translation agent with a Wiktionary-based search toolkit, dedicated multilingual data, and reinforcement learning, making lexical lookup part of the MT workflow.
- [AWED-FiNER: Agents, Web applications, and Expert Detectors for Fine-grained Named Entity Recognition across 36 Languages for 6.6 Billion Speakers](https://arxiv.org/abs/2601.10161): Candidate external workflow, orchestration, memory, or execution contribution for multilingual capability; it directly targets this page's capability scope and belongs in the `Agent Harness` track.
- [Mitigating Cultural Bias in LLMs via Multi-Agent Cultural Debate](https://arxiv.org/abs/2601.12091): Uses agents representing different cultural viewpoints to debate model responses and reduce culturally biased assumptions before final generation.
- [Gained in Translation: Privileged Pairwise Judges Enhance Multilingual Reasoning](https://arxiv.org/abs/2601.18722): Provides a multilingual reasoning harness; core idea: use translated evidence, judges, or verification loops to improve cross-lingual reasoning.
- [CHORUS](https://arxiv.org/abs/2602.19016): An effort-aware multi-agent workflow for professional translation. Core idea: coordinate AI suggestions, revision roles, and translator effort so high-stakes translation can be optimized for quality and human workload.
- [Toward Agentic RAG for Ukrainian](https://arxiv.org/abs/2604.14896): Adapts agentic RAG to Ukrainian.
- [FairQE: Multi-Agent Framework for Mitigating Gender Bias in Translation Quality Estimation](https://arxiv.org/abs/2604.21420): Uses a multi-agent framework to mitigate gender bias in translation-quality estimation.
- [CORAL](https://arxiv.org/abs/2604.25676): An adaptive retrieval loop for culturally aligned multilingual RAG. Core idea: change the retrieval space and evidence path according to cultural context instead of using one fixed multilingual embedding or translation strategy.
- [MAFIA-NeT: Multi-Agent Framework for Interactive Agricultural Negotiation and Trading Systems](https://doi.org/10.5220/0014484100004052): Builds a multi-agent negotiation and trading workflow for agriculture; its multilingual relevance is secondary unless the system explicitly supports cross-lingual negotiation.
- [CogSQL: A Cognitive Framework for Enhancing Large Language Models in Text-to-SQL Translation](https://doi.org/10.1609/aaai.v39i24.34770): Adds cognitive decomposition and verification steps for text-to-SQL generation, so the current multilingual placement is likely a translation-word false positive.
