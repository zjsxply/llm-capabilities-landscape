- [Formal Mathematics Statement Curriculum Learning](https://arxiv.org/abs/2202.01344): Expert iteration interleaves formal proof search with model updates, allowing the prover to discover an increasingly difficult curriculum without ground-truth proofs; on a curated statement set it reaches state-of-the-art miniF2F performance.
