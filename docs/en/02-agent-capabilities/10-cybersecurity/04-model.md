# 2.10.4 Model

- [PRIMUS](https://arxiv.org/abs/2502.11191): Provides cybersecurity datasets for continued pretraining, instruction tuning, and reasoning distillation, with evaluation on public cyber benchmarks.
- [Synthetic Security Graphs](https://arxiv.org/abs/2506.06226): Synthesizes security graphs to train intrusion-detection models when labeled cyber data are scarce.
- [Less Data, More Security](https://arxiv.org/abs/2507.02964): Specializes cybersecurity LLMs through resource-efficient domain-adaptive continuous pretraining with minimal tokens.
- [Cyber-Zero](https://arxiv.org/abs/2508.00910): Trains cybersecurity agents without relying on runtime environments, addressing domains where executable feedback loops are scarce or unsafe.
- [CTF-Dojo](https://arxiv.org/abs/2508.18370): Trains language-model agents to find vulnerabilities using CTF-Dojo, focusing on execution-grounded vulnerability-discovery learning.
- [Policy-Value Guided MDP-MCTS](https://arxiv.org/abs/2512.15150): Infers ATT&CK-consistent cyber kill chains by combining Transformer semantic priors, symbolic MDP structure, and policy-value guided MCTS, making CTI reconstruction a model-side cyber-reasoning technique.
- [AWDP](https://doi.org/10.1109/TDSC.2025.3575064): Applies deep reinforcement learning to automate Windows-domain penetration decisions, making it a model-side cyber-operation technique rather than an agent harness.
- [LOSVER](https://doi.org/10.1109/ASE63991.2025.00092): Uses line-level modifiability signals to focus pretrained code models on vulnerable regions for vulnerability detection and classification.
- [LLM Assistance for Memory Safety](https://doi.org/10.1109/ICSE55347.2025.00023): Combines LLM code transformation with lightweight static analysis to migrate C code toward Checked C annotations and memory-safety verification.
- [GVI](https://doi.org/10.1109/ICSE55347.2025.00214): Prompts LLMs to synthesize vulnerability samples from seed flaws, augmenting training data for deep vulnerability detectors.
- [ZeroByX](https://doi.org/10.1109/ICITEICS64870.2025.11341519): Specializes a large language model for cybersecurity tasks, providing a model-side entry for domain-adapted cyber reasoning and assistance.
- [GAPPO](https://doi.org/10.1109/Trustcom66490.2025.00376): Uses graph-attention-enhanced reinforcement learning for efficient cyber attack-path planning, extending the model-side line of RL-based attack-path optimization.
- [Minerva](https://arxiv.org/abs/2602.00513): Introduces Reinforcement Learning with Verifiable Rewards for Cyber Threat Intelligence LLMs, a model-side contribution for Cybersecurity.
- [SecureForge](https://arxiv.org/abs/2605.08382): Audits generated-code vulnerabilities and optimizes secure system prompts to reduce security flaws while preserving test success.
- [VectraYX-Nano](https://arxiv.org/abs/2605.13989): Trains a compact Spanish cybersecurity language model with curriculum learning and native tool-use behavior.
- [Prior-Knowledge PPO for Attack-Path Optimization](https://doi.org/10.1186/s42400-024-00288-8): Uses prior-knowledge-guided PPO to optimize network attack paths, fitting the cybersecurity model section as an RL-based cyber-operations technique.
- [PenQA](https://doi.org/10.3390/app15042117): Provides instructional data for improving penetration-testing behavior in language models, making it a model-side data recipe for cyber capability.
