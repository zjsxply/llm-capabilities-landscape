# 2.6.3 Bench

- [Autonomous Evaluation and Refinement of Digital Agents](https://arxiv.org/abs/2404.06474): Adds an evaluation target or dataset for long running capability coverage.
- [Evaluating Uncertainty-based Failure Detection for Closed-Loop LLM Planners](https://arxiv.org/abs/2406.00430): Adds a bench entry for Long-Running, because it evaluates uncertainty-based failure detection for closed-loop LLM planners.
- [GameBench: Evaluating Strategic Reasoning Abilities of LLM Agents](https://arxiv.org/abs/2406.06613): Adds an evaluation target or dataset for long running capability coverage.
- [DialSim: A Real-Time Simulator for Evaluating Long-Term Dialogue Understanding of Conversational Agents](https://arxiv.org/abs/2406.13144): Adds a bench reference for long-running agents, with a reusable contribution signaled by the title rather than a narrow application-only result.
- [AssistantBench](https://arxiv.org/abs/2407.15711) ([project page](https://assistantbench.github.io/); [leaderboard](https://huggingface.co/spaces/AssistantBench/leaderboard)): Evaluates realistic, time-consuming open-web assistant tasks. Core idea: make agents work on tasks such as property monitoring and merchant search that require sustained browsing and multi-step filtering, then use automatic evaluation to check final results, exposing early instability of web agents on long real-world tasks.
- [Disentangling Exploration of Large Language Models by Optimal Exploitation](https://arxiv.org/abs/2501.08925): Adds a benchmark or evaluation suite for long running, centered on Disentangling Exploration of Large Language Models by Optimal Exploitation.
- [Can LLM Agents Maintain a Persona in Discourse?](https://arxiv.org/abs/2502.11843): Adds a bench entry for Long-Running, because it tests whether LLM agents maintain a persona across discourse.
- [Vending-Bench](https://arxiv.org/abs/2502.15840) ([leaderboard](https://andonlabs.com/evals/vending-bench)): Evaluates consistency and stability of long-running autonomous agents over very long horizons, using "automated vending-machine operation" as a simplified business scenario, with a single run reaching over 20M tokens. Core idea: stretch decision chains where each step is simple but long-range coupled, explicitly exposing long-horizon failure modes such as high variance, meltdown loops, and difficulty recovering from bad states.
- [METR Time Horizon](https://arxiv.org/abs/2503.14499) ([open analysis code](https://github.com/METR/eval-analysis-public)): Evaluates how long a human-duration task AI agents can reliably complete. Core idea: calibrate task difficulty by qualified human completion time, then estimate p50/p80 time horizons from success-rate curves, forming a long-term autonomy scale that can update with models and agent systems.
- [HCAST: Human-Calibrated Autonomy Software Tasks](https://arxiv.org/abs/2503.17354): Evaluates human-calibrated autonomy tasks tied to real-world effects. Core idea: make this capability comparable through a defined task set, protocol, or scoring interface.
- [RealWebAssist](https://arxiv.org/abs/2504.10445) ([open-source code](https://github.com/SCAI-JHU/RealWebAssist)): Evaluates long-horizon web assistance for real users. Core idea: split user needs that may be supplemented, corrected, or ambiguously expressed into sequential instructions, testing whether agents can maintain goals, identify clarification needs, and keep making progress during long interactions.
- [TALES: Text Adventure Learning Environment Suite](https://arxiv.org/abs/2504.14128): Adds a bench entry for Long-Running, focusing on the capability signal stated in the title.
- [4Hammer](https://arxiv.org/abs/2505.13638): Evaluates hour-scale long-horizon reasoning in a complex board-game environment. Core idea: use a Warhammer 40,000 digital-twin subset where agents must parse long natural-language rules, maintain evolving game state, reason about opposing pieces, and complete a zero-sum task over a much longer horizon than ordinary puzzle benchmarks.
- [Wide-Horizon Thinking and Simulation-Based Evaluation for Real-World LLM Planning with Multifaceted Constraints](https://arxiv.org/abs/2506.12421): A simulation-based evaluation for wide-horizon real-world LLM planning under multifaceted constraints. Core idea: stress agents on plans that must balance long-range goals, constraints, and simulated outcomes.
- [LIFELONG SOTOPIA: Evaluating Social Intelligence of Language Agents Over Lifelong Social Interactions](https://arxiv.org/abs/2506.12666): Evaluates long-running agents. Core idea: use the paper's task, dataset, or protocol around evaluating social intelligence of language agents over lifelong social interactions to make this capability more comparable.
- [OSWorld-Human](https://arxiv.org/abs/2506.16042) ([OSWorld-Human Efficiency Leaderboard](https://github.com/WukLab/osworld-human); [open-source code](https://github.com/WukLab/osworld-human)): Evaluates computer-use agent efficiency against human reference trajectories. Core idea: add human traces and metrics such as weighted excess steps beyond OSWorld success rate, identifying long-horizon GUI agents that can complete tasks but execute them very inefficiently.
- [AgentGym](https://doi.org/10.18653/v1/2025.acl-long.1355): Evaluates and trains LLM agents across diverse interactive environments, serving as a broad multi-environment agent benchmark.
- [Agent Identity Evals](https://arxiv.org/abs/2507.17257): Measures whether language-model agents preserve identity-relevant capabilities and properties over time, including continuity, persistence, consistency, and recovery from state perturbations.
- [TextQuests](https://arxiv.org/abs/2507.23701): What it evaluates: long-horizon self-contained problem solving in text-based adventure games. Core idea: use Infocom-style interactive fiction to test state tracking, trial-and-error learning, and sustained reasoning without external tools.
- [OdysseyBench](https://arxiv.org/abs/2508.09124) ([open-source code](https://github.com/microsoft/OdysseyBench)): Evaluates memory and context reuse in long-horizon office productivity workflows. Core idea: build cross-stage state dependencies around documents, email, calendars, and spreadsheets, specifically checking whether agents can correctly refer to early results after multi-step execution.
- [Hell or High Water: Evaluating Agentic Recovery from External Failures](https://arxiv.org/abs/2508.11027): As language model agents are applied to real world problems of increasing complexity, they will be expected to formulate plans across large search spaces.
- [Stated Preference for Interaction and Continued Engagement (SPICE): Evaluating an LLM's Willingness to Re-engage in Conversation](https://arxiv.org/abs/2509.09043): Adds a reusable evaluation signal for long-running assistance, centered on Stated Preference for Interaction and Continued Engagement (SPICE): Evaluating an LLM's Willingness to Re-engage in Conversation.
- [The Illusion of Diminishing Returns: Measuring Long Horizon Execution in LLMs](https://arxiv.org/abs/2509.09677): Long-horizon evaluation: measurement of compounded execution failures as task length grows. Core idea: show why short-task scores can hide large differences in long-horizon reliability.
- [Gaia2](https://arxiv.org/abs/2509.17158) ([open-source code](https://github.com/facebookresearch/meta-agents-research-environments)): Evaluates realistic agent environments that are dynamic, asynchronous, and time-varying. Core idea: move tasks beyond one-shot QA into changing environmental states, notifications, and external-system interactions, requiring agents to maintain goals, update plans, and adapt to new information in long-horizon context.
- [UltraHorizon](https://arxiv.org/abs/2509.21766) ([code](https://github.com/StarDewXXX/UltraHorizon)): Evaluates ultra-long-horizon agents in partially observable simulated environments. Core idea: stretch goal decomposition, exploration, and state tracking over very long action sequences so task success depends on persistent planning rather than local tool-use competence alone.
- [HAL / Holistic Agent Leaderboard](https://arxiv.org/abs/2510.11977) ([HAL Long-Horizon Tracks](https://hal.cs.princeton.edu/); [open-source code](https://github.com/princeton-pli/hal-harness)): Evaluates unified long-horizon agent comparison across AssistantBench, GAIA, Online Mind2Web, and other tasks. Core idea: put accuracy, cost, runtime, and traces into the same leaderboard/harness to compare the generality of different long-horizon agent scaffolds.
- [Crucible: Quantifying the Potential of Control Algorithms through LLM Agents](https://arxiv.org/abs/2510.18491): Contributes a benchmark, dataset, metric, or evaluation protocol for long-running agents.
- [Agent Drift](https://arxiv.org/abs/2601.04170): Quantifies behavioral degradation in multi-agent systems over extended interactions, making long-run stability measurable.
- [Long-term Task-oriented Agent: Proactive Long-term Intent Maintenance in Dynamic Environments](https://arxiv.org/abs/2601.09382): Provides a dataset, benchmark, metric, or evaluation protocol for measuring Long-Running Agents capabilities.
- [Task2Quiz](https://arxiv.org/abs/2601.09503): Evaluates whether agents understand their task environment by converting completed tasks into quizzes about world state and dynamics.
- [DeepPlanning](https://arxiv.org/abs/2601.18137) ([project page](https://qwenlm.github.io/Qwen-Agent/en/benchmarks/deepplanning/)): Evaluates long-horizon agentic planning and multi-step execution. Core idea: use tasks requiring deep decomposition, constraint tracking, and staged backfilling to test whether agents can reliably map high-level goals into long action sequences.
- [OS-Marathon](https://arxiv.org/abs/2601.20650) ([project page](https://os-marathon.github.io/)): Evaluates computer-use agent stability in long-running, repetitive GUI tasks. Core idea: lengthen desktop tasks that are not hard step by step but are long in duration and accumulate state, observing pace maintenance, memory contamination, early stopping, and error-recovery failures.
- [AgentLongBench](https://arxiv.org/abs/2601.20730): Evaluates dynamic-environment episodes for long-context agents. Core idea: turn static retrieval questions into environment rollouts, specifically testing decay in multi-round feedback, nonlinear reasoning, and information integration over long chains.
- [Why Reasoning Fails to Plan: A Planning-Centric Analysis of Long-Horizon Decision Making in LLM Agents](https://arxiv.org/abs/2601.22311): Evaluates planning-centric analysis of long-horizon agent failures. Core idea: make long-running agent workflows measurable with task-specific data, protocols, metrics, or diagnostic environments rather than generic aggregate scores.
- [TRIP-Bench](https://arxiv.org/abs/2602.01675): Evaluates long-horizon multi-turn agents in realistic travel planning. Core idea: use 18 tools, 40+ travel constraints, up to 15 rounds of user interaction, and 150+ tool calls to test global constraint maintenance, adaptation to changing requirements, and version revision under long context.
- [SE-Bench](https://arxiv.org/abs/2602.04811): Benchmarks self-evolution with knowledge internalization, targeting whether agents can absorb experience across extended interaction.
- [OdysseyArena: Benchmarking Large Language Models For Long-Horizon, Active and Inductive Interactions](https://arxiv.org/abs/2602.05843): Evaluates long-horizon active and inductive interactions. Core idea: make this capability comparable through a defined task set, protocol, or scoring interface.
- [EcoGym](https://arxiv.org/abs/2602.09514) ([open-source code](https://github.com/OPPO-PersonalAI/EcoGym)): Evaluates long-horizon `plan-and-execute` ability in interactive economic systems. Core idea: provide `Vending / Freelance / Operation` environments under a unified interface, using 1000+ step action budgets to assess long-term strategy consistency, robustness, and returns.
- [LongCLI-Bench](https://arxiv.org/abs/2602.14337) ([open-source code](https://github.com/finyorko/longcli-bench)): Evaluates long-horizon agentic programming in command-line environments. Core idea: use CLI workflows with longer task spans, fine-grained intermediate metrics, and lower contamination risk to evaluate whether coding agents can keep planning, executing, debugging, and recovering.
- [Capable but Unreliable: Canonical Path Deviation as a Causal Mechanism of Agent Failure in Long-Horizon Tasks](https://arxiv.org/abs/2602.19008): Adds a benchmark or evaluation suite for long running, centered on Capable but Unreliable: Canonical Path Deviation as a Causal Mechanism of Agent Failure in Long-Horizon Tasks.
- [Silo-Bench](https://arxiv.org/abs/2603.01045): Evaluates distributed coordination in multi-agent LLM systems, a long-horizon coordination capability not covered by single-agent task benchmarks.
- [MMR-Life](https://arxiv.org/abs/2603.06746) ([open-source code](https://github.com/BugMakerzzz/MMR-Life)): Evaluates multimodal, multi-perspective reasoning for long-context daily-life agents. Core idea: use real-world long-duration, multi-view, multimodal records to test whether agents can preserve, retrieve, and combine life-scenario evidence across time.
- [LifeSim / LifeSim-Eval](https://arxiv.org/abs/2603.12152): Evaluates long-horizon personalized assistants through simulated user lives. Core idea: model cognition with a Belief-Desire-Intention structure and physical environments, then test whether agents preserve goals, preferences, and context across realistic life trajectories.
- [RetailBench](https://arxiv.org/abs/2603.16453): Evaluates long-horizon autonomous decision-making and strategy stability in realistic retail environments. Core idea: test whether agents can separately maintain high-level strategy and low-level execution under stochastic demand and evolving external conditions, preserving long-term operational consistency as complexity rises.
- [When Users Change Their Mind: Evaluating Interruptible Agents in Long-Horizon Web Navigation](https://arxiv.org/abs/2604.00892): Evaluates interruptible long-horizon web navigation. Core idea: make long-running agent workflows measurable with task-specific data, protocols, metrics, or diagnostic environments rather than generic aggregate scores.
- [AgentCE-Bench](https://arxiv.org/abs/2604.06111): A configurable lightweight agent benchmark with scalable horizons and controllable difficulty. Core idea: use hidden-slot scheduling tasks, static JSON-backed tool calls, and decoy budgets to separate long-horizon reasoning from environment overhead.
- [SEA-Eval: A Benchmark for Evaluating Self-Evolving Agents Beyond Episodic Assessment](https://arxiv.org/abs/2604.08988): Adds a benchmark or evaluation suite for long running, centered on SEA-Eval: A Benchmark for Evaluating Self-Evolving Agents Beyond Episodic Assessment.
- [LLMs for Text-Based Exploration and Navigation Under Partial Observability](https://arxiv.org/abs/2604.09604): A bench candidate for long-running agents, with the title/abstract indicating a benchmark-style task, dataset, diagnostic protocol, or evaluation suite.
- [HORIZON](https://arxiv.org/abs/2604.11978) ([leaderboard](https://xwang2775.github.io/horizon-leaderboard/)): Diagnoses long-horizon agent failure across domains. Core idea: construct cross-domain tasks and use trajectory-grounded failure attribution so degradation can be localized by planning, memory, tool use, or recovery behavior rather than reported only as final failure.
- [Agents Explore but Agents Ignore: LLMs Lack Environmental Curiosity](https://arxiv.org/abs/2604.17609): A bench candidate for long-running agents, with the title/abstract indicating a benchmark-style task, dataset, diagnostic protocol, or evaluation suite.
- [ClawMark](https://arxiv.org/abs/2604.23781) ([project page](https://claw-mark.com/); [leaderboard](https://claw-mark.com/leaderboard); [open-source code](https://github.com/evolvent-ai/ClawMark)): Evaluates multimodal coworker-style agents over multi-day calendar time. Core idea: use realistic schedules, messages, files, and external-event constraints over 1 to 3 days to assess whether agents can wait, remind, resume across days, and handle delayed feedback.
- [Odysseys](https://arxiv.org/abs/2604.24964) ([project page](https://odysseys-website.pages.dev/)): Evaluates long-horizon agent tasks on real websites. Core idea: put real websites, multi-stage goals, state dependencies, and error recovery into the same execution trajectory, testing whether web agents can maintain task consistency over longer spans.
- [EnvSimBench: A Benchmark for Evaluating and Improving LLM-Based Environment Simulation](https://arxiv.org/abs/2605.07247): What it evaluates: LLM-based environment simulation for agents. Core idea: test whether simulated environments are reliable enough to support planning, training, or evaluation of long-horizon agents.
- [π-Bench](https://arxiv.org/abs/2605.14678) ([results](https://simplified-reasoning.github.io/Pi-Bench/)): Evaluates long-term preferences, implicit intent, and cross-session action for proactive personal-assistant agents. Core idea: make agents decide when to act proactively, when to wait for confirmation, and how to maintain user preferences and task boundaries across multi-turn personal-affairs scenarios that continuously evolve.
- [Vending-Bench 2](https://andonlabs.com/evals/vending-bench-2) ([arena results](https://andonlabs.com/evals/vending-bench-arena)): Evaluates long-horizon business-operation agents in a newer public version of Andon Labs' vending-machine evaluation. Core idea: keep the one-year simulated business setting from Vending-Bench while adding more realistic messiness such as adversarial suppliers, negotiation, delivery delays, supplier failures, refunds, and clearer money-balance scoring.
