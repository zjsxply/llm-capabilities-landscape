# 1.11.5 Skill

- [mcp-builder](https://skills.sh/anthropics/skills/mcp-builder) is suitable for quickly building MCP servers.
- [mcp-cli](https://skills.sh/github/awesome-copilot/mcp-cli) is suitable for MCP runtime and command-line management.
- [mcp-deploy-manage-agents](https://skills.sh/github/awesome-copilot/mcp-deploy-manage-agents) is suitable for MCP service deployment and agent lifecycle management.
- [mcporter](https://github.com/openclaw/openclaw/tree/main/skills/mcporter) is suitable for listing, configuring, authenticating, calling, and inspecting MCP servers and tools from an agent-readable command-line workflow.
- [langchain4j-tool-function-calling-patterns](https://skills.sh/giuseppe-trisciuoglio/developer-kit/langchain4j-tool-function-calling-patterns) is suitable for integrating function calling into engineering frameworks.
- [skill-validator](https://skills.sh/daffy0208/ai-dev-standards/skill-validator) can serve as an additional validation layer in tool-call chains.
