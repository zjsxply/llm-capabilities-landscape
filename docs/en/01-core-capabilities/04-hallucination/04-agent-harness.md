# 1.4.4 Agent Harness

- [RARR](https://arxiv.org/abs/2210.08726) ([open-source code](https://github.com/anthonywchen/RARR)): retrieval-backed hallucination repair. A typical loop is `claim decomposition -> evidence retrieval -> evidence filtering/alignment -> revision`.
- [SelfCheckGPT](https://arxiv.org/abs/2303.08896) ([open-source code](https://github.com/potsawee/selfcheckgpt)): detects suspicious claims through self-consistency and variant sampling. The core idea is to treat "inconsistency" as a hallucination-risk signal.
- [FacTool](https://arxiv.org/abs/2307.13528) ([open-source code](https://github.com/GAIR-NLP/factool)): a tool-augmented factuality detection framework. The core idea is to decompose generated content in tasks such as QA, code, math, and scientific literature review into verifiable units, then call external tools and evidence to judge factual errors.
- [Chain-of-Verification](https://arxiv.org/abs/2309.11495): decomposes complex answers into subclaims to verify one by one. The core idea is to make the verification control flow explicit, reducing the pattern where an answer looks plausible overall but fabricates details.
- [SAFE](https://arxiv.org/abs/2403.18802) ([open-source code](https://github.com/google-deepmind/long-form-factuality)): a search-augmented factuality evaluation harness. The core idea is to split long answers into atomic claims and then judge whether each is supported by retrieved evidence.
- [MiniCheck](https://arxiv.org/abs/2404.10774) ([open-source code](https://github.com/Liyan06/MiniCheck)): a lightweight grounded factuality verifier. The core idea is to train/evaluate small detectors on LLM-AggreFact and judge answer-reference consistency at lower cost.
- [RefChecker](https://arxiv.org/abs/2405.14486) ([open-source code](https://github.com/amazon-science/RefChecker)): a reference-based fine-grained hallucination checker. The core idea is to split answers into verifiable fragments and align them with reference evidence, producing span/claim-level hallucination judgments.
- [RAGChecker](https://arxiv.org/abs/2408.08067) ([open-source code](https://github.com/amazon-science/RAGChecker)): a diagnostic evaluation framework for RAG systems. The core idea is to locate factuality errors in retrieval and generation through claim-level support, omissions, and noise.
- [SelfCheckAgent](https://arxiv.org/abs/2502.01812): a multi-agent, zero-resource hallucination detection framework. The core idea is to combine symbolic, specialized-detection, and contextual-consistency agents and use multidimensional consistency signals to judge whether generated content is reliable.
- [REFIND](https://arxiv.org/abs/2502.13622) ([open-source code](https://github.com/oneonlee/REFIND)): retrieval-augmented factuality hallucination detection. The core idea is to use retrieved documents and a context sensitivity ratio to locate hallucinated spans and validate robustness in multilingual settings.
- [FactSelfCheck](https://arxiv.org/abs/2503.17229): black-box hallucination detection based on fact triples. The core idea is to decompose answers into fine-grained facts and perform multi-round consistency checks.
- [Premise Verification](https://arxiv.org/abs/2504.06438): a retrieval-augmented logical verification framework for false-premise queries. The core idea is to convert a user question into logical premises before generation and verify them one by one, blocking the hallucination chain that follows a false premise.
- [FaithJudge](https://arxiv.org/abs/2505.04847) ([open-source code](https://github.com/vectara/FaithJudge)): an automatic judge for factual faithfulness. The core idea is to use a reusable evaluator to judge whether generated content is faithful to given evidence, supporting later versions of the Vectara hallucination leaderboard.
