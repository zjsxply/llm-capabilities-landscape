- [COLLIE](https://arxiv.org/abs/2307.08689): evaluates constrained text generation and complex instruction following. The core idea is to make constraints such as format, inclusion/exclusion, length, and set constraints into composable, decidable diagnostic task families.
- [FollowBench](https://arxiv.org/abs/2310.20410) ([open-source code and leaderboard](https://github.com/YJiangcm/FollowBench)): evaluates multi-level, fine-grained constraint following. The core idea is to split complex user instructions into constraints of different difficulties and types, locating whether models fail at the overall task, local constraints, or detailed execution.
- [IFEval](https://arxiv.org/abs/2311.07911) (dataset: [google/IFEval](https://huggingface.co/datasets/google/IFEval); core instruction-following task in [Open LLM Leaderboard](https://huggingface.co/spaces/open-llm-leaderboard/open_llm_leaderboard)): evaluates instruction following for format, constraints, prohibited items, and related rules.
