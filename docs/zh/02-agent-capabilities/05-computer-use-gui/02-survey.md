# 2.5.2 Survey

- [Survey of User Interface Design and Interaction Techniques in Generative AI Applications](https://arxiv.org/abs/2410.22370)：面向计算机与图形界面使用能力，梳理近期工作、分类边界与开放问题。
- [Foundations and Recent Trends in Multimodal Mobile Agents: A Survey](https://arxiv.org/abs/2411.02006)：梳理计算机与图形界面使用相关方法、风险与开放问题。
- [GUI Agents with Foundation Models: A Comprehensive Survey](https://arxiv.org/abs/2411.04890)：《GUI Agents with Foundation Models: A Comprehensive Survey》梳理Computer Use GUI的方法、分类、证据或实践边界。
- [Fine-tuning Large Language Models with Limited Data: A Survey and Practical Guide](https://arxiv.org/abs/2411.09539)：综述GUI、移动端、屏幕或网页导航智能体能力，补充近期方法、基准、风险或开放问题脉络。
- [GUI Agents: A Survey](https://arxiv.org/abs/2412.13501)：回顾跨界面的感知、定位、规划、动作空间、基准与失败。
- [Vision-Based Multimodal Interfaces: A Survey and Taxonomy for Enhanced Context-Aware System Design](https://arxiv.org/abs/2501.13443)：以分类法梳理面向上下文感知系统设计的多模态界面。
- [A Comprehensive Survey of Agents for Computer Use: Foundations, Challenges, and Future Directions](https://arxiv.org/abs/2501.16150)：综述 computer-use agent 的环境、交互闭环、记忆、安全与评测。
- [Towards Computer-Using Personal Agents](https://arxiv.org/abs/2503.15515)：梳理计算机使用 GUI 智能体的方法、风险、数据集或评测实践。
- [Towards Trustworthy GUI Agents](https://arxiv.org/abs/2503.23434)：以可信性为 GUI agent 的组织视角，覆盖感知、定位、规划、动作安全与评测。
- [A Survey on (M)LLM-Based GUI Agents](https://arxiv.org/abs/2504.13865)：梳理 UI grounding、动作预测、模型能力与系统挑战。
- [A Survey on GUI Agents with Foundation Models Enhanced by Reinforcement Learning](https://arxiv.org/abs/2504.20464)：综述强化学习如何增强基础模型驱动的 GUI 智能体。
- [A Survey on the Safety and Security Threats of Computer-Using Agents: JARVIS or Ultron?](https://arxiv.org/abs/2505.10924)：回顾 GUI 动作、跨应用执行、隐私暴露与工具误用带来的风险。
- [OS Agents: A Survey on MLLM-based Agents for General Computing Devices Use](https://arxiv.org/abs/2508.04482)：聚焦通用计算设备的操作、观察、行动与评测。
- [Next Generation XR Systems—Large Language Models Meet Augmented and Virtual Reality](https://doi.org/10.1109/mcg.2025.3548554)：系统梳理该方向的方法、评测缺口或部署问题。
- [LLM Integration in Extended Reality: A Comprehensive Review of Current Trends, Challenges, and Future Perspectives](https://doi.org/10.1145/3706598.3714224)：系统梳理该方向的方法、评测缺口或部署问题。
