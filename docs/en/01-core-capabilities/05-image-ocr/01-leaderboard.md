# 1.5.1 Leaderboard

- [DocVQA Challenge](https://www.docvqa.org/challenges): continuous leaderboard and classic public challenge for document visual question answering. It is suitable for tracking long-term progress in OCR, layout understanding, and answer extraction on real document QA.
- [Vision Arena](https://huggingface.co/spaces/WildVision/vision-arena): continuous leaderboard for pairwise battles between open-ended image-dialogue models. It is suitable for supplementing traditional accuracy leaderboards with human-preference/open-QA comparisons.
- [MMMU Leaderboard](https://mmmu-benchmark.github.io/#leaderboard): official leaderboard for multidisciplinary multimodal understanding and MMMU-Pro. It is suitable for tracking STEM, humanities, and expert-level image-question reasoning across closed and open models.
- [MMStar Leaderboard](https://mmstar-benchmark.github.io/): official leaderboard for vision-indispensable multimodal tasks. It is useful for comparing models on perception, reasoning, and leakage-aware sub-capabilities.
- [MTVQA Leaderboard](https://bytedance.github.io/MTVQA/): official leaderboard for multilingual text-centric visual QA. It is useful for tracking OCR-grounded VQA across languages and low-resource scripts.
- [CharXiv Leaderboard](https://charxiv.github.io/#leaderboard): official leaderboard for chart, figure, and image-text alignment understanding in scientific-paper contexts. It is useful for comparing models on evidence alignment beyond ordinary OCR.
- [OCRBench v2 Leaderboard](https://www.codesota.com/ocr/benchmark/ocrbench-v2): continuous leaderboard aggregating results around OCRBench v2 for text-rich images, documents, charts, and OCR-to-reasoning. It is useful for quickly tracking where new VLMs stand on the "read text and reason" pipeline.
- [EMMA Leaderboard](https://emma-benchmark.github.io/#leaderboard): official leaderboard for organic multimodal reasoning across math, physics, chemistry, and coding. It is suitable for tracking whether models can chain evidence across modalities rather than answer from isolated text.
- [PhyX Leaderboard](https://phyx-bench.github.io/): official leaderboard for visual physics reasoning in high-fidelity scene questions. It is useful for comparing models under text-deduplicated and visually grounded physics protocols.
- [PointArena](https://pointarena.github.io/): official arena and ranking page for pointing and localization models. It is useful for comparing visual grounding systems with direct spatial-output metrics.
- [OmniDocBench Leaderboard](https://github.com/opendatalab/OmniDocBench#leaderboard): continuous leaderboard for layout, table, paragraph, and structured metrics in document-parsing pipelines. It is suitable for comparing OCR-free/OCR-based parsers and end-to-end document models.
- [IDP Leaderboard](https://idp-leaderboard.org/): continuous leaderboard for enterprise document AI models, covering OCR, table extraction, KIE, VQA, classification, and long-document processing. It is suitable as an engineering-side comprehensive leaderboard for "document intelligence."
- [OCR Arena](https://www.ocrarena.ai/): continuous arena-style comparison for OCR/document models. It is useful for finding reusable document-parsing, table-extraction, and visual-QA model configurations.
- [OpenCompass Open VLM Leaderboard](https://huggingface.co/spaces/opencompass/open_vlm_leaderboard): widely used Hugging Face aggregate leaderboard for open VLMs across MMMU, MMStar, OCRBench, and related multimodal benchmarks. It is useful as a cross-benchmark entry point when readers need a broad model ranking.
