# 2.5.1 Leaderboard

- [OSWorld / OSWorld-Verified Leaderboard](https://os-world.github.io/): The official, continuously maintained results table and verified trajectories for desktop computer use; useful for tracking comparable results for UI-TARS, Agent S, Claude, Gemini, OpenAI models, and different maximum-step settings.
- [AndroidWorld Official Leaderboard](https://docs.google.com/spreadsheets/d/1cchzP9dlTZ3WXQTfYNhh3avxoLipqHN75v1Tb86uhHo/edit?gid=0#gid=0): A public submission table for mobile GUI agents; it helps track reusable mobile agent harnesses such as Mobile-Agent, Minitap/mobile-use, DroidRun, and FinalRun.
- [WindowsAgentArena Results](https://microsoft.github.io/WindowsAgentArena/): Public project results for Windows OS agents, the Navi baseline, and the BYOA reproduction interface; currently closer to an official results page than a rolling submission leaderboard, but still the main public comparison point for Windows GUI agents.
- [OSWorld-Human Efficiency Leaderboard](https://github.com/WukLab/osworld-human): Adds human reference trajectories and efficiency metrics beyond OSWorld scores, avoiding an exclusive focus on final success rate while ignoring overly long, inefficient, or trial-and-error completion paths.
- [MMBench-GUI Leaderboard](https://github.com/open-compass/MMBench-GUI): The repository has released evaluation data and cross-platform protocols, while the README still marks the leaderboard as coming soon; it should currently be treated as a tracking entry, not as an already launched ranking.
- [OSWorld-MCP Leaderboard](https://osworld-mcp.github.io/): A computer-use leaderboard for GUI plus MCP tool invocation, reporting accuracy, tool invocation rate, and average completion steps; useful for comparing pure GUI, tool-augmented, and hybrid agent configurations.
