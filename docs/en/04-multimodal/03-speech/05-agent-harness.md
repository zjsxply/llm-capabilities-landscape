# 4.3.5 Agent Harness

- [AudioGPT](https://arxiv.org/abs/2304.12995) ([open-source code](https://github.com/AIGC-Audio/AudioGPT)): An early audio agent harness that uses ChatGPT/LangChain-style planning to call speech, singing, audio, and talking-head foundation models as tools.
- [WavJourney](https://arxiv.org/abs/2307.14335) ([open-source code](https://github.com/Audio-AGI/WavJourney); [demo](https://audio-agi.github.io/WavJourney_demopage/)): A compositional audio-creation harness that decomposes text intent into story, speech, music, and sound-effect generation workflows.
- [A Near-Real-Time Processing Ego Speech Filtering Pipeline Designed for Speech Interruption During Human-Robot Interaction](https://arxiv.org/abs/2405.13477): A real-time HRI pipeline that filters a robot's own speech so interruption detection can keep listening while the robot is speaking.
- [Towards Achieving Human Parity on End-to-end Simultaneous Speech Translation via LLM Agent](https://arxiv.org/abs/2407.21646): Uses an LLM agent to coordinate listening, translation, and output timing for low-latency end-to-end simultaneous speech translation.
- [Audio-Agent: Leveraging LLMs For Audio Generation, Editing and Composition](https://arxiv.org/abs/2410.03335): Wraps audio generation, editing, and composition tools behind an LLM planner so complex audio requests can be decomposed into executable steps.
- [Aligning Audio-Visual Joint Representations with an Agentic Workflow](https://arxiv.org/abs/2410.23230): Uses an agentic workflow to align audio-visual representations through iterative multimodal reasoning rather than a single fixed encoder pass.
- [Grasp What You Want: Embodied Dexterous Grasping System Driven by Your Voice](https://arxiv.org/abs/2412.10694): Connects spoken user intent to an embodied dexterous grasping pipeline that grounds voice commands in object selection and robotic hand control.
- [LLM-Enhanced Dialogue Management for Full-Duplex Spoken Dialogue Systems](https://arxiv.org/abs/2502.14145): Adds an LLM dialogue manager for full-duplex spoken systems, targeting interruption handling and response control during overlapping speech.
- [ReelWave](https://arxiv.org/abs/2503.07217): A multi-agent harness for movie sound generation. Core idea: use a Sound Director agent to coordinate on-screen and off-screen sound agents through multimodal conversation, aligning speech, effects, ambience, and music across multi-scene video narratives.
- [Dopamine Audiobook](https://arxiv.org/abs/2504.11002): A training-free multi-agent harness for emotional audiobook generation. Core idea: split speech and audio design roles around multimodal inputs, align speech, sound effects, and music temporally and semantically, and include automated preference-aligned evaluation for immersive audio outputs.
- [DialogueAgents: A Hybrid Agent-Based Speech Synthesis Framework for Multi-Party Dialogue](https://arxiv.org/abs/2504.14482): Decomposes multi-party dialogue synthesis into agent roles so speaker turns, interaction context, and expressive speech generation can be coordinated.
- [LLAMAPIE: Proactive In-Ear Conversation Assistants](https://arxiv.org/abs/2505.04066): Proposes an in-ear assistant that monitors live conversations and proactively supplies context-aware support without waiting for explicit user prompts.
- [AudioGenie](https://arxiv.org/abs/2505.22053): A training-free multi-agent harness for multimodality-to-multiaudio generation. Core idea: coordinate specialized agents for fine-grained multimodal understanding, audio-type planning, and generation so speech, music, songs, and sound effects can be synthesized from mixed inputs.
- [Interactive Real-Time Speaker Diarization Correction with Human Feedback](https://arxiv.org/abs/2509.18377): Puts a human feedback loop around streaming diarization so user corrections can update speaker labels during an ongoing session.
- [AudioToolAgent](https://arxiv.org/abs/2510.02995) ([open-source code](https://github.com/GLJS/AudioToolAgent)): An agentic harness for audio-language models. Core idea: route audio understanding and generation tasks through external tools so auditory agents can decompose workflows instead of relying only on one end-to-end model call.
- [Audio-Maestro: Enhancing Large Audio-Language Models with Tool-Augmented Reasoning](https://arxiv.org/abs/2510.11454): Adds tool-augmented reasoning to large audio-language models. Core idea: let the model call external audio-analysis tools and integrate timestamped tool outputs, improving structured audio reasoning beyond end-to-end inference.
- [From Generation to Attribution: Music AI Agent Architectures for the Post-Streaming Era](https://arxiv.org/abs/2510.20276): Frames music agents as end-to-end systems that connect generation with attribution, rights tracking, and post-streaming value distribution.
- [LVAS-Agent / LVAS-Bench](https://aclanthology.org/2025.emnlp-main.1133/): A multi-agent harness for long-video audio synthesis. Core idea: decompose long-form video-to-audio work into scene segmentation, script generation, audio design, and audio synthesis, with LVAS-Bench providing professionally curated long videos for systematic evaluation.
- [Open Full-duplex Voice Agent](https://doi.org/10.1109/ASRU65441.2025.11434669): An open-source framework for full-duplex speech-to-speech voice agents. Core idea: convert standard text LLMs into spoken agents that can listen and speak with interruption-aware full-duplex interaction rather than turn-isolated text exchange.
- [Orchestrating Audio: Multi-Agent Framework for Long-Video Audio Synthesis](https://doi.org/10.18653/v1/2025.emnlp-main.1133): A multi-agent harness for long-video audio synthesis. Core idea: decompose long-form video-to-audio work into scene segmentation, script generation, audio design, and audio synthesis, with LVAS-Bench providing professionally curated long videos for systematic evaluation.
- [AudioFab](https://arxiv.org/abs/2512.24645): An open-source audio-agent framework for tool learning. Core idea: package fragmented audio-processing tools behind a natural-language interface, simplify dependency management, and improve tool selection and collaboration for complex audio tasks.
- [Towards Robust Dysarthric Speech Recognition: LLM-Agent Post-ASR Correction Beyond WER](https://arxiv.org/abs/2601.21347): Uses an LLM agent as a post-ASR corrector for dysarthric speech, emphasizing semantic recovery beyond word-error-rate optimization.
- [Building Enterprise Realtime Voice Agents from Scratch: A Technical Tutorial](https://arxiv.org/abs/2603.05413): A candidate agent harness, workflow, protocol, runtime, or orchestration method for speech and audio models. Its value is making agent-side control, tool use, coordination, or verification reusable beyond one prompt.
- Pipecat ([open-source code](https://github.com/pipecat-ai/pipecat); [docs](https://docs.pipecat.ai/)): An open-source Python framework for real-time voice and multimodal conversational agents, covering STT, LLM, TTS, WebRTC/WebSocket transports, pipeline composition, and subagents.
- LiveKit Agents ([open-source code](https://github.com/livekit/agents); [docs](https://docs.livekit.io/agents/)): A real-time programmable-participant framework for conversational multimodal voice agents, including tool calls, telephony, MCP integrations, job scheduling, and testing support.
- TEN Framework ([open-source code](https://github.com/TEN-framework/ten-framework)): A real-time multimodal conversational-AI framework with voice assistant examples, VAD, turn detection, memory, RTC/WebSocket integrations, and agent orchestration components.
- [MIST](https://arxiv.org/abs/2605.06897): A multimodal speech-based tool-calling assistant framework for smart homes. Core idea: connect spoken interaction, multimodal context, and executable device tools so tool-use agents can be evaluated and engineered beyond text-only API calls.
- [SoundStager: Interactive Design of Story-Driven GenAI Soundscapes for Video](https://doi.org/10.1145/3772318.3790870): Provides an interactive generative-AI workflow for story-driven soundscape design for video.
