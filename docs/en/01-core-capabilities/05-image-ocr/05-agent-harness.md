# 1.5.5 Agent Harness

- [VisProg](https://arxiv.org/abs/2211.11559) ([open-source code](https://github.com/allenai/visprog)): converts visual tasks into a reusable harness of "generate executable program + execute and fill results", reducing the risk of end-to-end hallucination by a single model.
- [Visual ChatGPT](https://arxiv.org/abs/2303.04671) ([open-source code](https://github.com/microsoft/visual-chatgpt)): a general visual-agent harness for collaboration among multiple vision tools. A typical loop is `plan -> call tools -> verify -> refine`.
- [ViperGPT](https://arxiv.org/abs/2303.08128) ([open-source code](https://github.com/cvlab-columbia/viper)): a visual-reasoning harness that uses Python execution as an intermediate layer, constraining model outputs to executable API compositions.
- [MM-REACT](https://arxiv.org/abs/2303.11381) ([open-source code](https://github.com/microsoft/MM-REACT)): a multimodal ReAct workflow that organizes visual perception, reasoning, and actions (tool calls) into reusable prompt control flow.
- [HuggingGPT](https://arxiv.org/abs/2303.17580) ([open-source code](https://github.com/microsoft/JARVIS)): a general agent framework that routes multimodal tasks to tools/models and orchestrates execution, including visual task routing and composition.
- [VisionGPT: Vision-Language Understanding Agent Using Generalized Multimodal Framework](https://arxiv.org/abs/2403.09027): Introduces an agent workflow or orchestration pattern for Images/OCR.
- [Meta-Prompting for Automating Zero-shot Visual Recognition with LLMs](https://arxiv.org/abs/2403.11755): Contributes an external workflow, tool, memory, retrieval, orchestration, or agent loop for image/ocr capabilities.
- [Swarm Intelligence in Geo-Localization: A Multi-Agent Large Vision-Language Model Collaborative Framework](https://arxiv.org/abs/2408.11312): Presents a workflow, retrieval/tool loop, verification method, prompting strategy, or orchestration harness for image, OCR, or vision-language capability.
- [ViDoRAG: Visual Document Retrieval-Augmented Generation via Dynamic Iterative Reasoning Agents](https://arxiv.org/abs/2502.18017): Adds a agent harness for image ocr, centered on ViDoRAG: Visual Document Retrieval-Augmented Generation via Dynamic Iterative Reasoning Agents.
- [MDocAgent](https://arxiv.org/abs/2503.13964) ([open-source code](https://github.com/aiming-lab/MDocAgent)): a multimodal multi-agent RAG framework for document QA. It combines roles such as text agent, image agent, critical agent, and summary agent for cross-modal evidence integration.
- [DWIM: Towards Tool-Aware Visual Reasoning via Discrepancy-Aware Workflow Generation & Instruct-Masking Tuning](https://arxiv.org/abs/2503.19263): A harness for tool-aware visual reasoning workflow generation. Core idea: expose workflow logic outside the base model so planning, tool use, memory, verification, recovery, or orchestration can be studied and reused.
- [OmniNova:A General Multimodal Agent Framework](https://arxiv.org/abs/2503.20028): A general multimodal agent framework for multimodal task execution.
- [An agentic system with reinforcement-learned subsystem improvements for parsing form-like documents](https://arxiv.org/abs/2505.13504): An agentic system for extracting data from form-like documents. Core idea: improve document parsing through agent-managed subsystem selection and reinforcement-learned improvements.
- [Agentic Visualization: Extracting Agent-Based Design Patterns From Visualization Systems](https://arxiv.org/abs/2505.19101): Introduces an agent workflow or orchestration pattern for Images/OCR.
- [Multimodal Reasoning Agent for Zero-Shot Composed Image Retrieval](https://arxiv.org/abs/2505.19952): Uses a multimodal reasoning agent for zero-shot composed image retrieval.
- [VReST: Enhancing Reasoning in Large Vision-Language Models through Tree Search and Self-Reward Mechanism](https://arxiv.org/abs/2506.08691): A harness for tree search and self-reward for visual reasoning. Core idea: expose workflow logic outside the base model so planning, tool use, memory, verification, recovery, or orchestration can be studied and reused.
- [Socratic-MCTS: Test-Time Visual Reasoning by Asking the Right Questions](https://arxiv.org/abs/2506.08927): A harness for Socratic MCTS for test-time visual reasoning. Core idea: expose workflow logic outside the base model so planning, tool use, memory, verification, recovery, or orchestration can be studied and reused.
- [ChartAgent](https://arxiv.org/abs/2507.06157) (open-source code: no stable public official repository currently known): an agentic workflow for chart QA. A common staged orchestration is `read chart/OCR -> tabularize/structure -> compute/verify -> answer`.
- [PyVision](https://arxiv.org/abs/2507.07998) ([project page](https://agent-x.space/pyvision/); [open-source code](https://github.com/agents-x-project/PyVision)): a dynamic tool harness for visual reasoning. It lets models generate, execute, and revise Python image-processing tools according to the task instead of relying on a fixed toolset.
- [DatasetAgent: A Novel Multi-Agent System for Auto-Constructing Datasets from Real-World Images](https://arxiv.org/abs/2507.08648): An agent harness or runtime for visual document, chart, table, or OCR reasoning. Core idea: externalize a novel multi-agent system for auto-constructing datasets from real-world images into reusable orchestration, tool-use, memory, or protocol logic.
- [Agentic AI With Orchestrator-Agent Trust: A Modular Visual Classification Framework With Trust-Aware Orchestration and RAG-Based Reasoning](https://arxiv.org/abs/2507.10571): Adds an agent workflow, orchestration pattern, tool loop, or runtime harness for orchestrated visual-classification framework with trust-aware RAG reasoning.
- [VProChart](https://arxiv.org/abs/2507.17209) (open-source code: no stable public official repository currently known): a procedural method for chart reasoning, emphasizing modularizing chart understanding with computation/verification to reduce chart hallucination.
- [Analyze-Prompt-Reason: A Collaborative Agent-Based Framework for Multi-Image Vision-Language Reasoning](https://arxiv.org/abs/2508.00356): A collaborative agent-based framework for multi-image vision-language reasoning. Core idea: use a PromptEngineer agent to generate task-specific prompts and a VisionReasoner to perform final inference across diverse multi-image tasks.
- [Visual Document Understanding and Reasoning: A Multi-Agent Collaboration Framework with Agent-Wise Adaptive Test-Time Scaling](https://arxiv.org/abs/2508.03404): A multi-agent collaboration framework for visual document understanding and reasoning. Core idea: assign document reasoning subtasks to agents and scale computation adaptively per agent.
- [ContextualLVLM-Agent: A Holistic Framework for Multi-Turn Visually-Grounded Dialogue and Complex Instruction Following](https://arxiv.org/abs/2508.15164): A candidate agent harness, workflow, protocol, runtime, or orchestration method for image, OCR, and visual document understanding. Its value is making agent-side control, tool use, coordination, or verification reusable beyond one prompt.
- [See it. Say it. Sorted.](https://arxiv.org/abs/2508.15222) ([code](https://github.com/hantaoZhangrichard/see_it_say_it_sorted)): A training-free agentic harness for sketch-to-diagram generation. Core idea: use a Critic VLM to propose relational edits, multiple LLM candidates to synthesize SVG updates, and a Judge VLM to select stable improvements, yielding editable programmatic diagrams instead of raster-only outputs.
- [Mini-o3: Scaling Up Reasoning Patterns and Interaction Turns for Visual Search](https://arxiv.org/abs/2509.07969): Adds a agent harness for image ocr, centered on Mini-o3: Scaling Up Reasoning Patterns and Interaction Turns for Visual Search.
- [ChartAgent: A Multimodal Agent for Visually Grounded Reasoning in Complex Chart Question Answering](https://arxiv.org/abs/2510.04514): A multimodal agent for visually grounded reasoning in complex chart QA. Core idea: combine chart perception, grounded evidence, and reasoning steps instead of answering chart questions directly.
- [ContextNav: Towards Agentic Multimodal In-Context Learning](https://arxiv.org/abs/2510.04560): Agent Harness candidate for image, document, chart, and general multimodal understanding. Core idea: Towards Agentic Multimodal In-Context Learning.
- [PoSh: Using Scene Graphs To Guide LLMs-as-a-Judge For Detailed Image Descriptions](https://arxiv.org/abs/2510.19060): Uses scene graphs to guide LLM-as-a-judge evaluation for detailed image descriptions. Core idea: score long visual descriptions with localized attribute and relation checks rather than short-caption metrics.
- [Doc-Researcher](https://arxiv.org/abs/2510.21603) (open-source code: no stable public official repository currently known): a multi-agent system for multimodal document deep research. It connects parsing, hierarchical retrieval, question decomposition, evidence accumulation, and cross-document synthesis into an iterative workflow.
- [SlideAgent: Hierarchical Agentic Framework for Multi-Page Visual Document Understanding](https://arxiv.org/abs/2510.26615): A hierarchical agentic framework for multi-page visual document understanding.
- [DocAssistant: Integrating Key-region Reading and Step-wise Reasoning for Robust Document Visual Question Answering](https://doi.org/10.18653/v1/2025.findings-emnlp.187): A document-VQA assistant that combines key-region reading with stepwise reasoning; core idea: localize useful document regions before composing an answer.
- [DocAgent](https://aclanthology.org/2025.emnlp-main.893/) ([open-source code](https://github.com/lisun-ai/DocAgent)): an agentic framework for multimodal long-context document understanding. It emphasizes memory and reviewer mechanisms, unifying text, layout, charts, tables, and image evidence into a long-document reasoning chain.
- [TabRAG: Improving Tabular Document Question Answering for Retrieval Augmented Generation via Structured Representations](https://arxiv.org/abs/2511.06582): Uses structured representations to make tabular-document question answering work with RAG.
- [Orion: A Unified Visual Agent for Multimodal Perception, Advanced Visual Reasoning and Execution](https://arxiv.org/abs/2511.14210): A unified visual agent that orchestrates specialized tools for perception, reasoning, and execution across images, videos, and documents.
- [Octopus: Agentic Multimodal Reasoning with Six-Capability Orchestration](https://arxiv.org/abs/2511.15351): A harness for six-capability orchestration for agentic multimodal reasoning. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [ARIAL](https://arxiv.org/abs/2511.18192) (open-source code: no stable public official repository currently known): an agentic framework for Document VQA and answer localization. A planner orchestrates OCR, semantic retrieval, answer generation, and text-to-region alignment, outputting both answers and bounding-box evidence.
- [Be My Eyes: Extending Large Language Models to New Modalities Through Multi-Agent Collaboration](https://arxiv.org/abs/2511.19417): Multi-agent multimodal harness: extending LLMs to new modalities through collaboration. Core idea: pair language and modality-specialist agents instead of retraining a full VLM.
- [Thinking with Programming Vision: Towards a Unified View for Thinking with Images](https://arxiv.org/abs/2512.03746): A harness for programming-vision tools for image-grounded reasoning. Core idea: expose workflow logic outside the base model so planning, tool use, memory, verification, recovery, or orchestration can be studied and reused.
- [Collaborative Document Simplification Using Multi-Agent Systems](https://aclanthology.org/2025.coling-main.60/): Adds a agent harness entry for Image OCR, focusing on the capability signal stated in the title.
- [TabAgent: A Multi-Agent Table Extraction Framework for Unstructured Documents](https://doi.org/10.1109/aibdf67964.2025.11440749): A multi-agent framework for extracting tables from unstructured documents. Core idea: decompose table extraction into coordinated agent roles for parsing, checking, and structuring document evidence.
- [CodeDance: A Dynamic Tool-integrated MLLM for Executable Visual Reasoning](https://arxiv.org/abs/2512.17312): A harness for executable visual reasoning with dynamic tool integration. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [DocDancer](https://arxiv.org/abs/2601.05163) (open-source code: the paper says it is open source, but no stable public repository has been confirmed): models DocQA as a tool-driven information-seeking process, explicitly separating document exploration from answer synthesis, and trains open-ended document agents with synthetic trajectories.
- [AVIR: Adaptive Visual In-Document Retrieval for Efficient Multi-Page Document Question Answering](https://arxiv.org/abs/2601.11976): Adds adaptive visual in-document retrieval before multi-page document question answering.
- [Clarify or Answer: Reinforcement Learning for Agentic VQA with Context Under-specification](https://arxiv.org/abs/2601.16400): A harness for clarify-or-answer agentic VQA under context underspecification. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [Pixel-Grounded Retrieval](https://arxiv.org/abs/2601.19060): A multimodal retrieval harness for knowledgeable VQA. Core idea: ground retrieval decisions in image regions so external knowledge is invoked when visual evidence and question context require it.
- [TikArt: Stabilizing Aperture-Guided Fine-Grained Visual Reasoning with Reinforcement Learning](https://arxiv.org/abs/2602.14482): Uses aperture-guided sequential evidence acquisition for visual reasoning. Core idea: let an agent focus on fine-grained regions over multiple steps instead of relying on one global image pass.
- [OCR-Agent](https://arxiv.org/abs/2602.21053) ([open-source code](https://github.com/AIGeeksGroup/OCR-Agent)): a specialized agent for OCR/document understanding. It emphasizes an iterative `OCR -> structured parsing -> verification -> fill-back` workflow.
- [PhotoAgent: Agentic Photo Editing with Exploratory Visual Aesthetic Planning](https://arxiv.org/abs/2602.22809): An agentic photo-editing framework with exploratory visual-aesthetic planning. Core idea: plan and revise edits through visual feedback so the burden is not only on a perfectly specified user instruction.
- [AgenticOCR: Parsing Only What You Need for Efficient Retrieval-Augmented Generation](https://arxiv.org/abs/2602.24134): A harness for agentic OCR that parses only task-relevant visual documents. Core idea: expose workflow logic outside the base model so planning, tool use, memory, verification, recovery, or orchestration can be studied and reused.
- [ORCA: Orchestrated Reasoning with Collaborative Agents for Document Visual Question Answering](https://arxiv.org/abs/2603.02438): Adds a agent harness for image ocr, centered on ORCA: Orchestrated Reasoning with Collaborative Agents for Document Visual Question Answering.
- [KFRA](https://arxiv.org/abs/2603.03762): A knowledge-augmented agent for open-set fine-grained visual understanding. Core idea: use open-vocabulary detection and web-scale retrieval to form hypotheses, localize discriminative regions, and integrate multimodal evidence into an interpretable reasoning loop.
- [DeepScan: A Training-Free Framework for Visually Grounded Reasoning in Large Vision-Language Models](https://arxiv.org/abs/2603.03857): A training-free framework for visually grounded reasoning in LVLMs. Core idea: localize critical visual cues first and then reason over the full context to improve grounded answers.
- [Scaling Test-Time Robustness of Vision-Language Models via Self-Critical Inference Framework](https://arxiv.org/abs/2603.07659): A harness for self-critical inference for test-time robustness of vision-language models. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [Explicit Logic Channel for Validation and Enhancement of MLLMs on Zero-Shot Tasks](https://arxiv.org/abs/2603.11689): A harness for explicit logic channels that validate and enhance MLLMs on zero-shot visual-language tasks. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [Feynman: Knowledge-Infused Diagramming Agent for Scalable Visual Designs](https://arxiv.org/abs/2603.12597): Diagramming agent: knowledge-infused diagram generation for scalable visual designs. Core idea: use agentic knowledge and layout reasoning to construct visual artifacts.
- [AwaRes](https://arxiv.org/abs/2603.16932): A spatial-on-demand visual tool-calling harness for efficient VLMs. Core idea: start from a low-resolution global view, call a high-resolution crop retrieval tool only when the query needs fine evidence, and train multi-turn crop-use trajectories from automatically labeled examples.
- [Evidence Units](https://arxiv.org/abs/2604.00500): a parser-independent document organization layer for multimodal RAG. The core idea is to group tables, figures, equations, captions, and explanatory paragraphs into ontology-grounded evidence units, then use graph rules to validate completeness before retrieval.
- [CharTool: Tool-Integrated Visual Reasoning for Chart Understanding](https://arxiv.org/abs/2604.02794): A tool-integrated visual reasoning harness for chart understanding. Core idea: combine chart-specific data pipelines and external computation so MLLMs can ground visual elements and perform precise numerical reasoning over charts.
- [V-Reflection: Transforming MLLMs from Passive Observers to Active Interrogators](https://arxiv.org/abs/2604.03307): A harness for active visual interrogation and reflection for fine-grained MLLM perception. Core idea: externalize planning, tool use, memory, verification, environment interaction, or orchestration beyond the base model.
- [HIVE: Query, Hypothesize, Verify An LLM Framework for Multimodal Reasoning-Intensive Retrieval](https://arxiv.org/abs/2604.07220): Adds an LLM query-hypothesize-verify loop to multimodal retrieval so charts, diagrams, and screenshots are reasoned over before evidence is accepted.
- [Entropy-Gradient Grounding](https://arxiv.org/abs/2604.08456): a training-free evidence-retrieval workflow for VLMs. The core idea is to use entropy gradients over visual tokens to rank relevant regions, then iteratively zoom and reground with a spatial-entropy stopping rule for detail-critical questions.
- [VISOR: Agentic Visual Retrieval-Augmented Generation via Iterative Search and Over-horizon Reasoning](https://arxiv.org/abs/2604.09508): An agentic visual RAG harness for visually rich documents. Core idea: interleave iterative retrieval, visual actions, and long-horizon reasoning to reduce cross-page evidence sparsity and search drift.
- [MM-Doc-R1](https://arxiv.org/abs/2604.13579): An agentic long-document visual-QA harness. Core idea: use iterative, vision-aware information discovery and synthesis over long documents, with reinforcement learning encouraging effective multi-turn evidence seeking.
- [Doc-V*](https://arxiv.org/abs/2604.13731) (open-source code: no stable public official repository currently known): a coarse-to-fine interactive visual-reasoning harness for multi-page Document VQA. The core idea is to replace one-shot full-page reading with a loop of page-level retrieval, region-level zoom-in, evidence verification, and answer generation.
- [Foveated Reasoning](https://arxiv.org/abs/2604.21079): a stateful visual-focusing harness for VLMs. The core idea is to start from a coarse image view, trigger high-resolution foveation only when needed, and feed selected evidence back into the same reasoning trajectory under a visual-token budget.

Core idea: manage joint image-text context when solving advanced chart tasks.
- [From Sketch to Structure](https://doi.org/10.1109/ACCESS.2026.3678494): An agentic prompting workflow for business-process diagram understanding. Core idea: turn sketch-like diagrams into structured process representations through staged vision-language reasoning.
- [VTQA: visual tabular data question answering framework based on multi-agent](https://doi.org/10.1007/s12650-025-01103-3): VTQA: visual tabular data question answering framework based on multi-agent contributes an agent workflow, orchestration pattern, tool loop, or runtime harness for image ocr.
