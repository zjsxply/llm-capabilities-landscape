# 2.11 Embodied and VLA Agents

## Sections

- [Unfettered Forceful Skill Acquisition with Physical Reasoning and Coordinate Frame Labeling](https://arxiv.org/abs/2505.09731): A VLM-based robot-manipulation harness that prompts for force and wrench reasoning using explicit coordinate-frame labels. Core idea: wrap visual prompting, force control, interaction feedback, and recovery into a reusable embodied-control loop rather than predicting trajectories directly.
- [HomeSafeBench: A Benchmark for Embodied Vision-Language Models in Free-Exploration Home Safety Inspection](https://arxiv.org/abs/2509.23690): Evaluates embodied VLMs in free-exploration home safety inspection. Core idea: require agents to navigate, observe, and identify household hazards rather than only answer static safety questions.
