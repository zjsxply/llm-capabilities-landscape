# 1.7.3 Bench

- `CountBench` (see [Teaching CLIP to Count to Ten](https://arxiv.org/abs/2302.12066)): What it evaluates: reliability of visual counting and quantity concepts; core idea: counting is often a foundational diagnostic for spatial and compositional reasoning, so it can serve as an auxiliary characterization dimension for spatial reasoning evaluation.
- [CatTrack: Single-Stage Category-Level 6D Object Pose Tracking via Convolution and Vision Transformer](https://doi.org/10.1109/tmm.2023.3284598): Adds a bench reference for spatial and 3D capability, with a reusable contribution signaled by the title rather than a narrow application-only result.
- [PEGASUS: Physically Enhanced Gaussian Splatting Simulation System for 6DoF Object Pose Dataset Generation](https://arxiv.org/abs/2401.02281): Generates 6DoF object-pose datasets with physics-enhanced Gaussian Splatting simulation, making synthetic pose data more useful for spatial pose-estimation evaluation.
- [CloSe: A 3D Clothing Segmentation Dataset and Model](https://arxiv.org/abs/2401.12051): Releases a 3D clothing segmentation dataset and baseline model, evaluating whether methods can separate garment regions and shapes in deformable clothed-human geometry.
- [GauU-Scene: A Scene Reconstruction Benchmark on Large Scale 3D Reconstruction Dataset Using Gaussian Splatting](https://arxiv.org/abs/2401.14032): Provides a large-scale 3D reconstruction benchmark for Gaussian Splatting scene modeling, evaluating reconstruction and rendering quality on broad scene data.
- [GeoEval: Benchmark for Evaluating LLMs and Multi-Modal Models on Geometry Problem-Solving](https://arxiv.org/abs/2402.10104): Evaluates LLMs and multimodal models on geometry problem solving with main, backward-reasoning, augmented, and hard subsets, stressing diagram-text integration and out-of-distribution geometric reasoning.
- [MultiCorrupt: A Multi-Modal Robustness Dataset and Benchmark of LiDAR-Camera Fusion for 3D Object Detection*](https://arxiv.org/abs/2402.11677): Tests LiDAR-camera 3D object detection under coordinated sensor corruptions, measuring whether fusion models remain robust when point clouds, images, or calibration signals degrade.
- [VisionGPT-3D: A Generalized Multimodal Agent for Enhanced 3D Vision Understanding](https://arxiv.org/abs/2403.09530): Evaluates a multimodal routing framework that selects depth, mesh, and 3D reconstruction tools from text or image inputs, making the spatial target the end-to-end quality of generated 3D representations.
- [Learning coherent matrixized representation in latent space for volumetric 4D generation](https://arxiv.org/abs/2403.13238): Benchmarks volumetric 4D generation on ShapeNet, 3DBiCar, DeformingThings4D, and Objaverse, measuring whether animated 3D shapes preserve color, geometry, and motion coherence across time.
- [Find n' Propagate: Open-Vocabulary 3D Object Detection in Urban Environments](https://arxiv.org/abs/2403.13556): Benchmarks top-down and bottom-up baselines for open-vocabulary LiDAR-based 3D object detection in urban scenes, focusing on novel-category localization from multi-sensor evidence.
- [CausalChaos! Dataset for Comprehensive Causal Action Question Answering Over Longer Causal Chains Grounded in Dynamic Visual Scenes](https://arxiv.org/abs/2404.01299): Evaluates causal action question answering over dynamic visual scenes, stressing longer causal chains where spatial interactions and temporal changes must be tracked jointly.
- [GeoReF: Geometric Alignment Across Shape Variation for Category-level Object Pose Refinement](https://arxiv.org/abs/2404.11139): Evaluates category-level object pose refinement under shape variation, using geometric alignment, cross-cloud transformation, and pose metrics to test robustness beyond instance-specific refinement.
- [BLINK](https://arxiv.org/abs/2404.12390) ([leaderboard](https://zeyofu.github.io/blink/); [code](https://github.com/zeyofu/BLINK_Benchmark)): What it evaluates: core visual perception and spatially related capabilities of multimodal models, such as relative depth, correspondence, and multi-view consistency; core idea: rewrite classic CV perception tasks as multiple-choice VQA, emphasizing the gap between "visible" and "actually perceived."
- [TableVQA-Bench: A Visual Question Answering Benchmark on Multiple Table Domains](https://arxiv.org/abs/2404.19205): Builds 1,500 visual table QA pairs from rendered tables and generated questions, testing whether MLLMs can read table layout, visual encodings, and cell relationships from images.
- [Multimodal LLMs Struggle with Basic Visual Network Analysis: a VNA Benchmark](https://arxiv.org/abs/2405.06634): Evaluates VLMs on rendered graph-analysis tasks such as maximum-degree nodes, signed-triad balance, and component counting, exposing failures in spatial layout parsing over networks.
- [Reframing Spatial Reasoning Evaluation in Language Models: A Real-World Simulation Benchmark for Qualitative Reasoning](https://arxiv.org/abs/2405.15064): Uses real-world simulation scenarios to test qualitative spatial reasoning in language models, requiring models to reason over relations and physical layouts rather than answer template word problems.
- [LLMGeo: Benchmarking Large Language Models on Image Geolocation In-the-wild](https://arxiv.org/abs/2405.20363): Benchmarks large models on in-the-wild image geolocation, testing whether visual landmarks, scene context, and world knowledge can be converted into location predictions.
- [Are Large Vision Language Models up to the Challenge of Chart Comprehension and Reasoning? An Extensive Investigation into the Capabilities and Limitations of LVLMs](https://arxiv.org/abs/2406.00257): Evaluates LVLMs across chart reasoning tasks, probing whether models can connect visual encodings, table values, and natural-language questions without hallucinating data.
- [Collaborative Novel Object Discovery and Box-Guided Cross-Modal Alignment for Open-Vocabulary 3D Object Detection](https://arxiv.org/abs/2406.00830): Evaluates open-vocabulary 3D detection on ScanNetv2 and SUN-RGBD, measuring novel-object localization and classification from 3D point clouds aligned with 2D and text priors.
- [The 3D-PC: a benchmark for visual perspective taking in humans and machines](https://arxiv.org/abs/2406.04138): Compares humans and machines on visual perspective taking, using 3D scenes to test whether an observer can infer how the world appears from another viewpoint.
- [Omni6DPose: A Benchmark and Model for Universal 6D Object Pose Estimation and Tracking](https://arxiv.org/abs/2406.04316): Provides a benchmark and model for universal 6D object pose estimation and tracking across object categories.
- [3D-GRAND: A Million-Scale Dataset for 3D-LLMs with Better Grounding and Less Hallucination](https://arxiv.org/abs/2406.05132): Provides 40,087 household 3D scenes and 6.2M grounded instructions, plus 3D-POPE for measuring hallucination and grounding reliability in 3D-LLMs.
- [Situational Awareness Matters in 3D Vision Language Reasoning](https://arxiv.org/abs/2406.07544): Evaluates situation-grounded 3D question answering on SQA3D and ScanQA, separating self-location estimation from answering questions from the inferred viewpoint.
- [MMScan: A Multi-Modal 3D Scene Dataset with Hierarchical Grounded Language Annotations](https://arxiv.org/abs/2406.09401): Provides 3D scene data with hierarchical grounded language annotations, supporting tasks that link objects, regions, attributes, and instructions to explicit 3D scene structure.
- `DA-2K` ([Depth Anything V2](https://arxiv.org/abs/2406.09414)): What it evaluates: single-image depth, relative depth, and other visual capabilities strongly tied to 3D geometry; core idea: use relative depth and geometric consistency as foundational observation signals for spatial understanding, though the task is closer to traditional vision evaluation than conversational reasoning.
- [Revisiting Referring Expression Comprehension Evaluation in the Era of Large Multimodal Models](https://arxiv.org/abs/2406.16866): Reassesses referring-expression comprehension for large multimodal models, exposing whether benchmark protocols still measure fine-grained grounding rather than generic object recognition.
- [NerfBaselines: Consistent and Reproducible Evaluation of Novel View Synthesis Methods](https://arxiv.org/abs/2406.17345): Standardizes novel-view-synthesis evaluation with reproducible NeRF and related baselines, making rendering quality and scene reconstruction comparisons less implementation-dependent.
- [CORE4D: A 4D Human-Object-Human Interaction Dataset for Collaborative Object REarrangement](https://arxiv.org/abs/2406.19353): Releases a 4D dataset for collaborative human-object-human rearrangement, evaluating dynamic spatial interaction, object motion, and coordination over time.
- [VSP: Assessing the dual challenges of perception and reasoning in spatial planning tasks for VLMs](https://arxiv.org/abs/2407.01863): Breaks visual spatial planning into perception and reasoning subtasks, testing whether VLMs can understand object layouts and produce action plans for simple visual scenes.
- [TAPVid-3D: A Benchmark for Tracking Any Point in 3D](https://arxiv.org/abs/2407.05921): Extends point tracking into 3D by evaluating whether methods can maintain arbitrary point identities through motion, occlusion, and viewpoint change.
- [GLBench: A Comprehensive Benchmark for Graph with Large Language Models](https://arxiv.org/abs/2407.07457): Standardizes supervised and zero-shot GraphLLM evaluation across real graph datasets, measuring how structure and semantics affect graph reasoning rather than ordinary scene geometry.
- [OmniNOCS: A unified NOCS dataset and model for 3D lifting of 2D objects](https://arxiv.org/abs/2407.08711): Unifies NOCS-style 3D object lifting from 2D observations, evaluating category-level canonical coordinates, pose, and shape recovery across object types.
- [Evaluating Modern Approaches in 3D Scene Reconstruction: NeRF vs Gaussian-Based Methods](https://arxiv.org/abs/2408.04268): Compares NeRF-style and Gaussian-based 3D scene reconstruction methods under a shared empirical protocol, focusing on rendering quality, reconstruction fidelity, and practical tradeoffs.
- [Can Large Language Models Understand Symbolic Graphics Programs?](https://arxiv.org/abs/2408.08313): Tests LLM understanding of symbolic graphics programs, requiring models to reason from code-like drawing instructions to visual layout and geometric relationships.
- [OpenScan: A Benchmark for Generalized Open-Vocabulary 3D Scene Understanding](https://arxiv.org/abs/2408.11030): Tests open-vocabulary 3D scene understanding under generalized category settings, requiring models to recognize and ground objects beyond a fixed closed-label set.
- [Evaluating Large Language Models on Spatial Tasks: A Multi-Task Benchmarking Study](https://arxiv.org/abs/2408.14438): Benchmarks LLMs across multiple spatial task families, separating failures in relation understanding, navigation-style reasoning, and symbolic or geometric spatial inference.
- [Space3D-Bench: Spatial 3D Question Answering Benchmark](https://arxiv.org/abs/2408.16662): Evaluates spatial 3D question answering over scene geometry, requiring models to answer relation, distance, layout, and object-grounding questions from 3D evidence.
- [BOP-Distrib: Revisiting 6D Pose Estimation Benchmarks for Better Evaluation under Visual Ambiguities](https://arxiv.org/abs/2408.17297): Revises 6D pose evaluation under visual ambiguities by treating pose hypotheses as distributions, making symmetric and visually indistinguishable object poses less unfairly penalized.
- [EgoPressure: A Dataset for Hand Pressure and Pose Estimation in Egocentric Vision](https://arxiv.org/abs/2409.02224): Captures egocentric RGB-D, hand meshes, and pressure annotations, benchmarking hand pose and contact-pressure estimation for hand-object spatial interaction.
- [Multi-modal Situated Reasoning in 3D Scenes](https://arxiv.org/abs/2409.02389): Evaluates situated reasoning in 3D scenes, combining multimodal scene evidence with questions that depend on local viewpoint, object relations, and task context.
- [UniDet3D: Multi-dataset Indoor 3D Object Detection](https://arxiv.org/abs/2409.04234): Evaluates spatial capabilities with a benchmark, dataset, or assessment protocol.
- [LayeredFlow: A Real-World Benchmark for Non-Lambertian Multi-Layer Optical Flow](https://arxiv.org/abs/2409.05688): Benchmarks optical flow in non-Lambertian multi-layer scenes, stressing transparent, reflective, or layered motion where standard single-surface flow assumptions fail.
- [3DGCQA: A Quality Assessment Database for 3D AI-Generated Contents](https://arxiv.org/abs/2409.07236): Provides a quality-assessment database for AI-generated 3D content, enabling evaluation of geometry, texture, realism, and perceptual quality in generated spatial assets.
- [AutoGeo: Automating Geometric Image Dataset Creation for Enhanced Geometry Understanding](https://arxiv.org/abs/2409.09039): Generates AutoGeo-100k image-text geometry pairs from formal geometric clauses, evaluating MLLM gains on geometric captioning and mathematical reasoning over diagrams.
