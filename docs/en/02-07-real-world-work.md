# 2.7 Real-World Work

> Parent section: 2. Foundation Agents


## 2.7.1 Leaderboard

- [GAIA Leaderboard](https://huggingface.co/spaces/gaia-benchmark/leaderboard): A long-running public leaderboard for general real-world assistant tasks, covering reasoning, web browsing, multimodality, and tool use; it remains an important entry point for comparing whether agents can solve real problems rather than isolated tool skills.
- [TheAgentCompany Leaderboard](https://the-agent-company.com/#/leaderboard): A public leaderboard for digital-employee tasks in a simulated software company; useful for observing end-to-end completion rates on mixed real-work tasks involving web, code, files, and coworker communication.
- [HAL / Holistic Agent Leaderboard](https://hal.cs.princeton.edu/) ([open-source harness](https://github.com/princeton-pli/hal-harness)): Reports accuracy, cost, runtime, and traces across GAIA, AssistantBench, tau-bench, Online Mind2Web, SWE-bench Verified, and other tasks; its value is that models, agent scaffolds, and evaluation cost are compared together in public.
- [GDPval Leaderboard](https://evals.openai.com/gdpval/leaderboard): A public leaderboard for economically valuable task deliverables; it focuses on rubric-driven professional output quality and puts model capability, context, and scaffolding benefits for real work into one entry point.
- [Remote Labor Index Leaderboard](https://labs.scale.com/leaderboard/rli): Continuously compares agents on automation rate and delivery quality for real remote-labor projects; it complements GDPval by emphasizing outsourced projects, economic signals, and end-to-end delivery.
- [APEX-Agents Leaderboard](https://www.mercor.com/apex/apex-agents-leaderboard/): A public leaderboard covering professional-service tasks such as investment banking, consulting, and corporate law; it treats files, tools, rubrics, and gold outputs as deliverables for real white-collar work.
- [ClawBench Leaderboard](https://claw-bench.com/): A leaderboard for write-operation tasks on real live websites, recording model, harness, trace, HTTP interception, and reward; its main value is making agent behavior auditable in real web workflows.
- [ClawMark Leaderboard](https://claw-mark.com/leaderboard): A multi-calendar-time coworker-agent workflow leaderboard, useful for tracking real-work agents that can wait, remember, and collaborate across days rather than only complete single-session tasks.

## 2.7.2 Bench

- [GAIA](https://arxiv.org/abs/2311.12983) ([dataset](https://huggingface.co/datasets/gaia-benchmark/GAIA)): Evaluates reasoning, multimodality, web browsing, and tool use by general AI assistants on real-world questions. Core idea: combine "can search, calculate, use tools, and integrate evidence" into an early anchor for general agent evaluation using problems easy for humans but hard for models.
- [WorkArena](https://arxiv.org/abs/2403.07718) ([open-source code](https://github.com/ServiceNow/WorkArena)): Evaluates common knowledge-work web tasks in ServiceNow enterprise software. Core idea: use a realistic enterprise-software-style platform and BrowserGym environment to evaluate web operation, form handling, retrieval, and process execution.
- [WorkBench](https://arxiv.org/abs/2405.00823) ([open-source code](https://github.com/olly-styles/WorkBench)): Evaluates tool use and state-changing tasks in realistic office/business activities. Core idea: provide a sandbox with 5 databases, 26 tools, and 690 tasks, using outcome-centric evaluation to check whether the final database state is uniquely correct, emphasizing executable common workflows such as email, meetings, and record updates as well as the risk of misoperation.
- [tau-bench](https://arxiv.org/abs/2406.12045) ([open-source code](https://github.com/sierra-research/tau-bench)): Evaluates multi-turn tool-agent-user interaction in realistic domains such as retail and airlines. Core idea: constrain agents jointly with simulated users, domain APIs, and policy guidelines, then evaluate true user-goal completion through final database state.
- [WorkArena++](https://arxiv.org/abs/2407.05291) ([open-source code](https://github.com/ServiceNow/WorkArena)): Evaluates more compositional enterprise knowledge workflows. Core idea: extend WorkArena to 682 tasks requiring compositional planning, logical/arithmetic reasoning, retrieval, and context understanding, specifically amplifying planning failures in multi-step enterprise processes.
- [AssistantBench](https://arxiv.org/abs/2407.15711) ([project page](https://assistantbench.github.io/)): Evaluates realistic and time-consuming web assistant tasks. Core idea: turn web work such as monitoring, filtering, locating, and information integration into automatically evaluated tasks, linking GAIA-style general assistant ability with WebArena-style executable web environments.
- [OfficeBench](https://arxiv.org/abs/2407.19056) ([open-source code](https://github.com/zlwang-cs/OfficeBench)): Evaluates office automation across Word, Excel, PDF, calendars, email, and other applications. Core idea: use 300 multi-application tasks to test long-horizon planning, application switching, and large-action-space grounding, highlighting redundant operations, hallucination, and cross-application failures in daily office workflows.
- [CRMArena](https://arxiv.org/abs/2411.02305): Evaluates professional customer service, analysis, and management tasks in CRM systems. Core idea: introduce industrial objects, hidden variables, and business rules to test function calling, rule following, and business-process reliability in realistic CRM work environments.
- [TheAgentCompany](https://arxiv.org/abs/2412.14161) ([open-source code](https://github.com/TheAgentCompany/TheAgentCompany)): Evaluates real digital-employee tasks in a simulated software company. Core idea: build a self-contained company environment, internal websites, and coworker communication, requiring agents to complete work through web browsing, coding, program execution, and collaboration rather than operating in a single tool.
- [ML-Dev-Bench](https://arxiv.org/abs/2502.00964): Evaluates agentic ability in applied machine-learning development workflows. Core idea: assess whether agents can complete the full ML development chain, from data processing, training, and improving existing code to generating experiment reports, rather than solving isolated coding problems or single-point Kaggle tasks.
- [RealWebAssist](https://arxiv.org/abs/2504.10445) ([open-source code](https://github.com/SCAI-JHU/RealWebAssist)): Evaluates long-horizon web assistance for real users. Core idea: use sequential, changing human instructions with clarification needs to evaluate agents' sustained assistance ability, close to real users delegating web tasks to AI.
- [CRMArena-Pro](https://arxiv.org/abs/2505.18878): Evaluates CRM agents across sales, service, quote configuration, and other business scenarios. Core idea: extend CRMArena with B2B/B2C, multi-persona multi-turn interaction, and confidentiality-awareness evaluation, closer to the compound "conversation + data + rules + permissions" needs of enterprise deployment.
- [FieldWorkArena](https://arxiv.org/abs/2505.19662): Evaluates multimodal tasks in field work such as manufacturing, warehousing, and retail. Core idea: construct tasks from real-site images/videos and frontline-worker interviews, testing safety hazards, process violations, and critical-event recognition to cover real work beyond the digital office.
- [WebChoreArena](https://arxiv.org/abs/2506.01952) ([open-source code](https://github.com/WebChoreArena/WebChoreArena)): Evaluates tedious and complex chores on real websites. Core idea: benchmark common work tasks that humans dislike but often encounter, such as heavy filtering, repeated confirmation, and cross-page state maintenance, testing stable execution and error recovery.
- [SpreadsheetBench Verified](https://arxiv.org/abs/2506.03768): Evaluates verifiable spreadsheet tasks involving formulas, computation, operations, and result consistency. Core idea: bring spreadsheets, a common productivity tool, into the programming-agent capability spectrum through an automatically verifiable protocol.
- [AssetOpsBench](https://arxiv.org/abs/2506.03828) ([open-source code](https://github.com/IBM/AssetOpsBench)): Evaluates multi-step decisions and operations in industrial asset operations. Core idea: organize equipment states, maintenance strategies, and operational constraints from Industry 4.0 scenarios into executable tasks, complementing enterprise operational workflows beyond office software.
- [xbench](https://arxiv.org/abs/2506.13651): Evaluates dynamic real-work tasks directly aligned with occupational productivity, initially covering recruiting and marketing. Core idea: have industry experts define commercially important tasks and use an evalset that can update over time to track agent Technology-Market Fit rather than static academic questions.
- [OpenAgentSafety](https://arxiv.org/abs/2507.06134): Evaluates agent safety in real tool environments. Core idea: connect browsers, code execution, file systems, shells, and messaging platforms, covering eight risk categories in multi-turn, multi-user tasks and exposing safety-alignment gaps in real workflows.
- [WearVox](https://arxiv.org/abs/2507.11824) ([open-source code](https://github.com/facebookresearch/wearvox)): Evaluates context awareness in wearable voice assistants. Core idea: combine speech, vision, and user context to evaluate assistant ability in mobile life scenarios, complementing real-assistant forms beyond desktop/web workflows.
- [Finance Agent Benchmark](https://arxiv.org/abs/2508.00828): Evaluates LLM agents on real-world financial research tasks such as analyzing SEC filings. Core idea: measure whether an agent can retrieve financial evidence, reason over company documents, and produce decision-relevant answers in a domain where factual grounding and calculation both matter.
- [OdysseyBench](https://arxiv.org/abs/2508.09124) ([open-source code](https://github.com/microsoft/OdysseyBench)): Evaluates agent memory in long-horizon office productivity workflows. Core idea: construct cross-stage state dependencies around documents, email, calendars, and spreadsheets to test whether agents retain key context and correctly reuse previous operation results over long chains.
- [MCP-Bench](https://arxiv.org/abs/2508.20453) ([open-source code](https://github.com/Accenture/mcp-bench)): Evaluates tool-use ability for complex real tasks through MCP servers. Core idea: each MCP server provides complementary tools, and tasks require cross-tool planning, schema understanding, trajectory-level decisions, and final task completion, close to enterprise MCP-based tool ecosystems.
- [AgentArch](https://arxiv.org/abs/2509.10769) ([open-source code](https://github.com/ServiceNow/AgentArch)): Evaluates end-to-end effects of different agent architectures in enterprise scenarios. Core idea: compare architecture choices such as ReAct, planner-executor, multi-agent, memory, and tool routing on a unified enterprise task set, helping distinguish model capability from harness-design contributions.
- [Gaia2](https://arxiv.org/abs/2509.17158) ([open-source code](https://github.com/facebookresearch/meta-agents-research-environments)): Evaluates asynchronous tasks, notifications, and external-system interactions in dynamic real environments. Core idea: approximate "wait, update, replan" in real work through changing environment states and continuous event streams, serving as a dynamic complement to static one-shot workplace benchmarks.
- [SCUBA](https://arxiv.org/abs/2509.26506) ([open-source code](https://github.com/SalesforceAIResearch/SCUBA)): Evaluates enterprise computer-use tasks in the Salesforce GUI. Core idea: use CRM business objects and real SaaS interfaces to test reliability in record query/editing, form navigation, rule following, and state consistency.
- [DRBench](https://arxiv.org/abs/2510.00172) ([open-source code](https://github.com/ServiceNow/drbench), [dataset](https://huggingface.co/datasets/ServiceNow/drbench)): Evaluates enterprise deep research work. Core idea: require agents to retrieve evidence across public web pages, private files, email, chat, and productivity tools, then produce cited reports, filling the gap for research work where information is scattered and permission-bounded.
- [GDPval](https://arxiv.org/abs/2510.04374) (public benchmark; [Leaderboard](https://evals.openai.com/gdpval/leaderboard)): Evaluates real economically valuable tasks, covering deliverable-style work across professions and industries. Core idea: ground "real work" in a comparable evaluation protocol through explicit deliverables and rubric-driven scoring, and discuss the effects of `reasoning effort / context / scaffolding` on performance.
- [GDPval-AA](https://artificialanalysis.ai/evaluations/gdpval-aa): Evaluates agentic performance on OpenAI's GDPval gold public task set through Artificial Analysis' independent framework. Core idea: give models shell and web access through the Stirrup agent harness, derive Elo ratings from blind pairwise comparisons, and expose a vendor-facing real-work leaderboard over professional documents, slides, diagrams, spreadsheets, and other deliverables.
- [HAL / Holistic Agent Leaderboard](https://arxiv.org/abs/2510.11977) ([open-source code](https://github.com/princeton-pli/hal-harness)): Evaluates agents uniformly across GAIA, AssistantBench, tau-bench, Online Mind2Web, SWE-bench Verified, and other tasks. Core idea: publish accuracy, cost, runtime, and traces together as a cross-benchmark comparison framework for real-work agents.
- [LaborMarketplaceBenchmark](https://openreview.net/forum?id=be76fus1ou) (NeurIPS 2025 LLM Evaluation Workshop): Evaluates knowledge-work tasks from real freelance marketplaces. Core idea: build a refreshable evaluation set from fixed-price, single-milestone marketplace tasks accepted by clients, preserving economic signals such as payout, task category, and human feedback iteration; a direction adjacent to RLI.
- [ProfBench](https://arxiv.org/abs/2510.18941) (dataset: [nvidia/ProfBench](https://huggingface.co/datasets/nvidia/ProfBench), [open-source code](https://github.com/NVlabs/ProfBench)): Evaluates document processing, information synthesis, and report generation/judging requiring professional knowledge. Core idea: use human rubrics from physics, chemistry, finance, and consulting experts to evaluate open-ended professional outputs, serving as a "professional rubric" complement to GDPVal/RLI.
- [Tool Decathlon (Toolathlon)](https://arxiv.org/abs/2510.25726): Evaluates multi-application, multi-tool, long-horizon task execution. Core idea: provide more realistic environment setups and execution-based evaluation to assess stability over long tasks across cross-domain toolchains, as a general tool-execution neighbor to OfficeBench/MCP-Bench.
- [Remote Labor Index (RLI)](https://arxiv.org/abs/2510.26787) ([open evaluation platform](https://github.com/centerforaisafety/rli_evaluation_platform); see the repository README for the public data entry): Evaluates end-to-end automation of real remote freelance/outsourced projects. Core idea: ground "can it replace remote labor" in economically valuable project deliverables, emphasizing multiple industries, long work hours, ambiguous requirements, and final delivery quality rather than isolated skills.
- [EnterpriseBench](https://arxiv.org/abs/2510.27287): Evaluates enterprise tasks in software engineering, HR, finance, and administration. Core idea: construct 500 enterprise tasks with fragmented data sources, access-control hierarchies, and cross-functional workflows, testing whether agents can complete work in a sandbox close to real organizational constraints.
- [NL2Repo-Bench](https://arxiv.org/abs/2512.12730) (public benchmark): Evaluates end-to-end construction of complete software repositories from natural-language requirement documents, starting from an empty workspace and requiring architecture design, dependency management, multi-file implementation, installable packages, and tests. Core idea: explicitly benchmark long-horizon repo construction plus tests to expose cross-file consistency and long-chain execution failures in vibe coding.
- [Finch (FinWorkBench)](https://arxiv.org/abs/2512.13168) ([open-source code](https://github.com/FinWorkBench/Finch), [dataset](https://huggingface.co/datasets/FinWorkBench/Finch)): Evaluates spreadsheet-centric workflows in enterprise finance and accounting. Core idea: construct long-horizon composite tasks from real enterprise workspaces, email threads, and spreadsheet version histories, covering data entry, modeling, validation, retrieval, visualization, and report delivery.
- [SafePro](https://arxiv.org/abs/2601.06663) ([project page](https://safeprobench.github.io/safepro/)): Evaluates safety for professional-grade AI agents. Core idea: assess both task completion and unsafe actions in complex professional tasks, covering safety failures that real-work evaluations such as GDPval, RLI, and APEX-Agents do not fully capture.
- [TraineeBench](https://arxiv.org/abs/2601.08173) ([open-source code](https://github.com/KnowledgeXLab/EvoEnv)): Evaluates dynamic learning, exploration, and task scheduling in new-employee-like work scenarios. Core idea: have agents continuously receive streaming tasks in unfamiliar workplace environments, proactively explore information, summarize rules, and schedule work over time, evaluating a more common production "first day on the job" capability rather than static one-shot task completion.
- [AgencyBench](https://arxiv.org/abs/2601.11044) ([open-source code](https://github.com/GAIR-NLP/AgencyBench)): Evaluates long-horizon real tasks from daily AI use. Core idea: cover 32 real scenarios and 138 tasks, emphasizing deliverables and rubric-based automatic evaluation under 1M tokens, about 90 tool calls, and hours of execution time.
- [APEX-Agents](https://arxiv.org/abs/2601.14242) ([evaluation infrastructure Archipelago](https://github.com/Mercor-Intelligence/archipelago)): Evaluates long-horizon cross-application tasks in professional services such as investment banking, management consulting, and corporate law. Core idea: measure Pass@1 in realistic work environments with files and tools, while opening questions, rubrics, gold outputs, files, and metadata, emphasizing deliverable quality in white-collar professional services.
- [EntWorld](https://arxiv.org/abs/2601.17722): Evaluates long-horizon enterprise GUI-agent workflows in high-density business systems such as CRM, ITIL, and ERP. Core idea: infer business logic from database schemas and synthesize 1,756 tasks, using SQL state transitions for deterministic verification and emphasizing the combined difficulty of rule constraints, information consistency, and multi-step UI operation in enterprise systems.
- [World of Workflows](https://arxiv.org/abs/2601.22130): Evaluates end-to-end workflow execution in enterprise systems. Core idea: build tasks around multi-step business processes, cross-system state, and rule constraints, making "can complete a full workflow" rather than a single API/page action the core evaluation target.
- [AIRS-Bench](https://arxiv.org/abs/2602.06855) ([open-source code](https://github.com/facebookresearch/airs-bench)): Evaluates end-to-end research tasks in AI research science. Core idea: extract full research-lifecycle tasks from frontier ML papers, including idea generation, experiment analysis, code implementation, and literature understanding, assessing whether agents can produce verifiable research-work outcomes.
- [WorldTravel](https://arxiv.org/abs/2602.08367) (public benchmark): Evaluates realistic travel planning with strongly coupled constraints, multiple objectives, and multi-step plans, including text-only and multimodal web environments (WorldTravel-Webscape). Core idea: explicitly amplify the fragility of planning and the perception-action loop through strongly coupled constraints plus real-web parameter reading from visual layouts, with plan feasibility and constraint satisfaction as core metrics.
- [EcoGym](https://arxiv.org/abs/2602.09514): Evaluates continuous planning and execution in long-horizon economic environments, covering Vending, Freelance, and Operation scenarios. Core idea: use 1000+ steps, partial observability, stochastic perturbations, and business metrics such as net worth, revenue, and DAU to test whether agents can maintain long-term strategy consistency in economic systems rather than optimizing only short-term actions.
- [LongCLI-Bench](https://arxiv.org/abs/2602.14337) ([open-source code](https://github.com/finyorko/longcli-bench)): Evaluates long-horizon agentic programming workflows in the command line. Core idea: lengthen planning, execution, debugging, and staged checks from real software engineering through CLI tasks, and record intermediate failure modes with fine-grained metrics.
- [LiveAgentBench](https://arxiv.org/abs/2603.02586): Evaluates comprehensive agent tasks from real user needs, covering social media and real product issues. Core idea: use Social Perception-Driven Data Generation to construct 104 realistic scenarios and 374 tasks, continuously updating from real interactions to reduce the gap between static benchmarks and real needs.
- [OneMillion-Bench](https://arxiv.org/abs/2603.07980): Evaluates expert-level occupational tasks in high-economic-consequence scenarios, covering law, finance, industry, healthcare, and natural sciences. Core idea: require retrieval from authoritative sources, conflict-evidence handling, domain-rule application, and constrained decisions, using rubrics to evaluate factual correctness, logical consistency, practical feasibility, and professional compliance.
- [OfficeQA / OfficeQA Pro](https://arxiv.org/abs/2603.08655): Evaluates grounded office-style question answering over documents, spreadsheets, and presentations. Core idea: focus on precise extraction, synthesis across heterogeneous professional files, and numerical or tabular reasoning, complementing OfficeBench's operation-heavy automation setting.
- [EnterpriseOps-Gym](https://arxiv.org/abs/2603.13594) ([project page](https://enterpriseops-gym.github.io/); [open-source code](https://github.com/ServiceNow/EnterpriseOps-Gym); [dataset](https://huggingface.co/datasets/ServiceNow-AI/EnterpriseOps-Gym)): Evaluates stateful planning, tool use, and policy compliance in enterprise environments. Core idea: provide a containerized enterprise sandbox with 164 database tables, 512 functional tools, and 1150 expert tasks, covering customer service, HR, IT, email, calendar, Teams, Drive, and hybrid scenarios, and use SQL checks of final state rather than trajectory text alone.
- [MM-ClawBench / MM Claw end-to-end benchmark](https://www.minimax.io/news/minimax-m27-en) (model-card-only; no standalone public release confirmed): Evaluates OpenClaw-style real-world needs across work and life, including personal learning planning, office-document delivery, scheduled professional research and investment advice, and code development and maintenance. Core idea: use a broad end-to-end task set to measure whether skill- and tool-rich agents can deliver realistic artifacts, while keeping public-status limitations explicit.
- [Data Agent Benchmark (DAB)](https://arxiv.org/abs/2603.20576) ([open-source code](https://github.com/ucbepic/DataAgentBench)): Evaluates enterprise data agents answering natural-language data questions. Core idea: use 12 datasets, 9 domains, 4 database-management systems, and 54 queries to test cross-database integration, dirty-key joins, unstructured text conversion, and domain knowledge, rather than only single-database Text-to-SQL.
- [EnterpriseArena (CFO)](https://arxiv.org/abs/2603.23638): Evaluates CFO-style long-horizon resource allocation in dynamic enterprise environments. Core idea: unfold decisions over a 132-month enterprise simulation where agents must keep cash nonnegative and maximize terminal value under budgeted tool calls, partially observed financial state, macro signals, and capital constraints, specifically exposing "analysis without action" and long-term risk-control failures.
- [Claw-Eval](https://arxiv.org/abs/2604.06132) ([open-source code](https://github.com/claw-eval/claw-eval)): Evaluates multi-step agent workflows in real software environments. Core idea: use 300 human-verified tasks, 9 scenario classes, and 2,159 fine-grained rubrics, unifying Completion, Safety, Robustness, and consistent pass rate across three runs, with trajectory-aware grading through execution traces, audit logs, and environment snapshots.
- [ClawBench](https://arxiv.org/abs/2604.08523) ([project page](https://claw-bench.com/); [open-source code](https://github.com/reacher-z/ClawBench); [dataset](https://huggingface.co/datasets/TIGER-Lab/ClawBench)): Evaluates everyday online tasks and state-changing operations on real live websites. Core idea: start from 153 write-operation web tasks across 144 real platforms and maintain 130 updated tasks in the newer leaderboard; final HTTP request interception, payload judges, and multilayer trajectory recording reduce destructiveness and irreproducibility in real-site evaluation.
- [OccuBench](https://arxiv.org/abs/2604.10866) ([open-source code](https://github.com/GregxmHu/OccuBench), [dataset](https://huggingface.co/datasets/gregH/OccuBench)): Evaluates real professional task scenarios across industries and occupations. Core idea: use Language World Models / Language Environment Simulators to simulate domain tool responses, covering 100 professional task scenarios, 10 industry categories, 65 professional fields, and 382 solvable instances; also evaluate the occupational profile of "task completion + environmental robustness" through explicit errors, implicit data degradation, and hybrid fault injection.
- [AlphaEval](https://arxiv.org/abs/2604.12162) ([open-source code](https://github.com/GAIR-NLP/AlphaEval)): Evaluates full agent-product performance in production environments. Core idea: extract 94 production tasks from 7 companies with deployed agents, covering 6 O*NET occupational domains, and combine LLM-as-a-Judge, reference-driven metrics, formal verification, rubrics, UI tests, and other paradigms to evaluate complete agent systems such as Claude Code and Codex rather than only model APIs.
- [CI-Work](https://arxiv.org/abs/2604.21308): Evaluates contextual integrity and privacy-leakage risks for enterprise LLM agents. Core idea: distinguish essential content from sensitive context in dense-retrieval enterprise workflows, cover 5 information-flow directions, and evaluate whether agents can complete tasks while suppressing sensitive-context leakage, adding the "useful but must not leak" safety dimension of real work.
- [ClawMark](https://arxiv.org/abs/2604.23781) ([project page](https://claw-mark.com/); [open-source code](https://github.com/evolvent-ai/ClawMark)): Evaluates multimodal coworker-style real-work tasks over multi-calendar-day spans. Core idea: use real files, calendars, messages, and delayed events to construct 1- to 3-day coworker-agent workflows, testing whether agents can maintain task state across days, wait for external feedback, and deliver on time.
- [Odysseys](https://arxiv.org/abs/2604.24964) ([project page](https://odysseys-website.pages.dev/)): Evaluates long-horizon real tasks on real websites. Core idea: construct realistic long-horizon web tasks from real websites, multi-stage goals, and state dependencies, sitting between web GUI, real online work, and long-running evaluation.
- [Claw-Eval-Live](https://arxiv.org/abs/2604.28139) ([project page](https://claw-eval-live.github.io/); [open-source code](https://github.com/Claw-Eval-Live/Claw-Eval-Live)): Evaluates enterprise workflow agents that change with real demand. Core idea: refresh task distribution from ClawHub marketplace signals; the current version contains 105 tasks and 17 task families, with planned quarterly resampling; scoring reads execution traces, audit logs, service states, and workspace artifacts, so the benchmark is not only a static question bank.
- [Workspace-Bench](https://arxiv.org/abs/2605.03596): Evaluates workspace-learning tasks with large-scale file dependencies. Core idea: construct realistic workspaces with 5 worker profiles, 74 file types, and 20,476 files, using file dependency graphs and multidimensional rubrics to check whether agents can retrieve, reason, update, and deliver across files.
- [EntCollabBench](https://arxiv.org/abs/2605.08761): Evaluates role-specialized multi-agent collaboration in enterprise workflows. Core idea: simulate a permission-isolated organization with 11 role-specialized agents, workflow-state checks, and policy-based approvals, testing delegation, context transfer, access control, parameter grounding, and workflow closure beyond all-in-one single-agent setups.
- [WildClawBench](https://arxiv.org/abs/2605.10912) ([open-source code](https://github.com/internlm/WildClawBench)): Evaluates long-horizon, multimodal, bilingual work tasks in real CLI agent harnesses. Core idea: run real harnesses such as OpenClaw, Claude Code, Codex, or Hermes Agent in reproducible Docker containers; provide 60 human-authored tasks averaging 8 minutes and 20+ tool calls, and score them with a mix of rule checks, environment-state audits, and LLM/VLM judges, explicitly exposing the impact of harness choice on results.
- [Seed2.0 in-house XPert Bench and ToB benchmarks](https://github.com/ByteDance-Seed/Seed2.0): Closed/internal evaluations reported in the Seed2.0 model card, including XPert Bench and ToB-Complex Workflows, ToB-Reference Q&A, ToB-K12 Education, ToB-Compositional Tasks, ToB-Text Classification, and ToB-Information Extraction. These are not publicly released, but they are worth tracking because they show vendor emphasis on enterprise, education, classification, extraction, and workflow completion tasks.

## 2.7.3 Agent Harness

- [BrowserGym Ecosystem](https://arxiv.org/abs/2412.05467) ([open-source code](https://github.com/ServiceNow/BrowserGym)): Unifies web/enterprise work environments such as WebArena, VisualWebArena, and WorkArena, with the AgentLab experiment framework; suitable for reproducible comparison of real web and workplace agents.
- [Alita](https://arxiv.org/abs/2505.20286) ([open-source code](https://github.com/CharlesQ9/Alita)): A production-oriented general solver agent emphasizing cross-tool orchestration and complex workflow execution, transferable to multi-step execution in real business tasks.
- [WorkForceAgent-R1](https://arxiv.org/abs/2505.22942) (open-source code: no stable public repository found): A workplace web agent for WorkArena, using regularized R1-style reinforcement learning to improve single-step reasoning, format following, and action correctness; closer to a specialized executor for enterprise web navigation than a general chat agent.
- [HomerAgent](https://arxiv.org/abs/2508.09124) ([open-source code](https://github.com/microsoft/OdysseyBench)): The office-productivity agent/harness paired with OdysseyBench, using explicit memory to organize stage results in long-horizon workflows; useful for analyzing context forgetting and erroneous reuse in office workflows.
- [AgentArch Reference Harness](https://arxiv.org/abs/2509.10769) ([open-source code](https://github.com/ServiceNow/AgentArch)): Compares multiple agent architectures in a unified enterprise task environment, suitable for ablating harness design variables such as planner-executor, multi-agent, memory, and tool routing.
- [ARE](https://arxiv.org/abs/2509.17158) ([open-source code](https://github.com/facebookresearch/meta-agents-research-environments)): Turns real task environments into asynchronous runtimes supporting notifications, external systems, state evolution, and execution logs, suitable for evaluating sustained plan updates in dynamic workflows.
- [BrowserAgent](https://arxiv.org/abs/2510.10666) ([open-source code](https://github.com/TIGER-AI-Lab/BrowserAgent)): A solver agent that executes multi-step tasks in real browser action spaces, suitable for realistic constraint-driven web tasks such as WorldTravel.
- [HAL Harness](https://openreview.net/pdf?id=vUaY1t64ZZ) ([open-source code](https://github.com/princeton-pli/hal-harness)): A standardized and cost-visible agent evaluation harness providing a unified CLI, parallel runs, log/cost tracking, and leaderboard submission workflow; useful for moving reproducible real-work agent experiments from single-paper scripts to continuous evaluation.
- [Enterprise Deep Research](https://arxiv.org/abs/2510.17797) ([open-source code](https://github.com/SalesforceAIResearch/enterprise-deep-research)): A multi-agent deep-research system implementation for enterprise research scenarios. Core idea: connect enterprise private knowledge, public web, messages, and file retrieval to a planner/retriever/writer/checker process, suitable for research and reporting workflows inside real organizations.
- [EvoEnv](https://arxiv.org/abs/2601.08173) ([open-source code](https://github.com/KnowledgeXLab/EvoEnv)): The unified environment/harness framework behind TraineeBench, providing a workspace manager, virtual clock, tool gateway, trajectory/evaluation pipeline, and visual trace viewer; suitable for studying dynamic task scheduling and continuously learning workplace agents.
- [DAB DataAgent](https://arxiv.org/abs/2603.20576) ([open-source code](https://github.com/ucbepic/DataAgentBench)): The execution framework bundled with Data Agent Benchmark, organized around multi-database connections, Python execution, query logs, tool-call traces, and Pass@1 aggregation; useful as a harness reference for enterprise data QA/analytics tasks.
- [EnterpriseLab](https://arxiv.org/abs/2603.21630) (open-source code: no stable public repository found): A full-stack development and deployment platform for enterprise agents; it connects MCP-style enterprise application environments, automatic trajectory synthesis, training pipelines, and continuous evaluation, validated on an EnterpriseArena instance with 15 applications and 140+ tools. It belongs to the "private enterprise agent harness + data generation + training/evaluation loop" line.
- [Claw-Eval Harness](https://arxiv.org/abs/2604.06132) ([open-source code](https://github.com/claw-eval/claw-eval)): Runs multiple classes of real tasks around OpenClaw-style agents, emphasizing three-channel evidence recording, fine-grained rubrics, Pass^k stability, and safety/robustness checks; suitable as a regression evaluation framework for deployable agents.
- [ClawBench Browser Harness](https://arxiv.org/abs/2604.08523) ([open-source code](https://github.com/reacher-z/ClawBench)): Builds a pipeline for task recording, HTTP interception, trajectory replay, and payload judgment around real browser sessions; suitable for evaluating browser agents that modify remote state while minimizing actual destructive submissions.
- [OccuBench LWM Harness](https://arxiv.org/abs/2604.10866) ([open-source code](https://github.com/GregxmHu/OccuBench)): Outsources professional-scenario tool responses to a Language World Model and provides a reference agent loop, fault injection, 3-vote rubric verifier, and OpenAI-compatible API interface; its value is enabling interactive agent evaluation for professional tasks without real backend systems.
- [Agentic Harness Engineering](https://arxiv.org/abs/2604.25850): Treats the harness as an observable and iterative object. Core idea: use component visibility, experience visibility, and decision visibility to make automatic evolution of coding-agent harnesses a verifiable loop.
- [Claw-Eval-Live Harness](https://arxiv.org/abs/2604.28139) ([open-source code](https://github.com/Claw-Eval-Live/Claw-Eval-Live)): Connects marketplace signals to task snapshots, mock services, workspace fixtures, graders, and leaderboard aggregation; suitable for building workflow benchmarks that refresh periodically while preserving reproducible snapshots.
- [WildClawBench Native Runtime Harness](https://arxiv.org/abs/2605.10912) ([open-source code](https://github.com/internlm/WildClawBench)): Hosts long-horizon tasks with Docker and real CLI agent harnesses, emphasizing joint evaluation of the agent system, tool runtime, and model; a realistic complement to evaluating only raw models or lightweight wrappers.
