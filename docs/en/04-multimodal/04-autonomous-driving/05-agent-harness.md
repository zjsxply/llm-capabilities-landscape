# 4.4.5 Agent Harness

- [Drive Like A Human](https://arxiv.org/abs/2307.07162) ([open-source code](https://github.com/PJLab-ADG/DriveLikeAHuman)): TLDR: uses an LLM in a HighwayEnv closed loop to expose human-like reasoning, interpretation, and memory as the missing interface between scene understanding and driving decisions.
- [DiLu](https://arxiv.org/abs/2309.16292) ([open-source code](https://github.com/PJLab-ADG/DiLu)): TLDR: turns autonomous driving into a self-evolving agent loop with environment observation, reasoning, reflection, and memory, targeting dataset bias and poor interpretability in data-driven policies.
- [Agent-Driver](https://arxiv.org/abs/2311.10813) ([open-source code](https://github.com/physical-superintelligence-lab/Agent-Driver); [project page](https://usc-gvl.github.io/Agent-Driver/)): TLDR: frames driving as an LLM cognitive-agent problem with function-call tools, cognitive memory, task planning, motion planning, and self-reflection instead of a fixed perception-prediction-planning stack.
- [DriveLLM: Charting the Path Toward Full Autonomous Driving With Large Language Models](https://doi.org/10.1109/tiv.2023.3327715): TLDR: inserts an LLM into the decision layer of an autonomous-driving stack, adding commonsense hazard reasoning, cyber-physical feedback from mistakes, human instruction handling, and adversarial-input defenses.
- [VLP: Vision Language Planning for Autonomous Driving](https://arxiv.org/abs/2401.05577): TLDR: connects visual scene understanding to language-level reasoning for planning, addressing the weak generalization and limited reasoning of vision-only driving planners.
- [Editable Scene Simulation for Autonomous Driving via Collaborative LLM-Agents](https://arxiv.org/abs/2402.05746): TLDR: uses collaborative LLM agents to turn user editing requests into multi-camera, asset-aware driving-scene simulations, improving interactive control over synthetic data generation.
- [PlanAgent: A Multi-modal Large Language Agent for Closed-loop Vehicle Motion Planning](https://arxiv.org/abs/2406.01587): TLDR: uses an MLLM as a cognitive planner that converts BEV maps and lane graphs into hierarchical reasoning, planner code, and reflection-based simulation checks for nuPlan closed-loop motion planning.
- [DriVLMe: Enhancing LLM-based Autonomous Driving Agents with Embodied and Social Experiences](https://arxiv.org/abs/2406.03008): TLDR: evaluates a video-language driving agent built from embodied simulator experience and human-dialogue experience, surfacing practical limits in inference latency, multi-turn interaction, and unexpected events.
- [AD-H: Autonomous Driving with Hierarchical Agents](https://arxiv.org/abs/2406.03474): TLDR: inserts mid-level language commands between high-level instructions and low-level control, letting an MLLM planner reason while a lightweight controller executes and self-corrects in closed-loop driving.
- [DriveArena: A Closed-Loop Generative Simulation Platform for Autonomous Driving](https://arxiv.org/abs/2408.00415): TLDR: combines a Traffic Manager with a generative World Dreamer so image-based driving agents can act in a closed loop where trajectories reshape traffic and the rendered scene updates.
- [Edge-Cloud Collaborative Motion Planning for Autonomous Driving with Large Language Models](https://arxiv.org/abs/2408.09972): TLDR: splits LLM-enabled motion planning across edge and cloud components to preserve personalization and open-world reasoning while reducing latency and local compute pressure.
- [DualAD: Dual-Layer Planning for Reasoning in Autonomous Driving](https://arxiv.org/abs/2409.18053): TLDR: pairs a routine rule-based planner with an LLM reasoning layer that intervenes only in dangerous cases, mimicking human escalation from automatic driving to deliberative reasoning.
- [LASER: Script Execution by Autonomous Agents for On-demand Traffic Simulation](https://arxiv.org/abs/2410.16197): TLDR: converts natural-language traffic-simulation requests into executable scripts through LLM agents, making safety-critical traffic scenario generation more flexible and scalable.
- [Autoware.Flex: Human-Instructed Dynamically Reconfigurable Autonomous Driving Systems](https://arxiv.org/abs/2412.16265): TLDR: lets users steer an Autoware-based ADS with natural-language preferences, using an LLM plus ADS knowledge base for instruction translation and a validation layer for safe execution.
- [LLM-Attacker: Enhancing Closed-Loop Adversarial Scenario Generation for Autonomous Driving With Large Language Models](https://arxiv.org/abs/2501.15850): Uses llm or agentic orchestration for autonomous-driving scenario generation or planning.
- [Parallel Actor-Reasoner Framework](https://arxiv.org/abs/2503.00502): TLDR: separates a slow LLM Reasoner from an interaction-memory Actor, enabling AVs to communicate intentions and retrieve feasible actions without invoking the LLM for every real-time decision.
- [V2X-ReaLO: An Open Online Framework and Dataset for Cooperative Perception in Reality](https://arxiv.org/abs/2503.10034): Provides an open online real-vehicle V2X cooperative perception framework and dataset.
- [CoLLMLight: Cooperative Large Language Model Agents for Network-Wide Traffic Signal Control](https://arxiv.org/abs/2503.11739): Uses cooperative LLM agents for network-wide traffic signal control.
- [Driving-RAG: Driving Scenarios Embedding, Search, and RAG Applications](https://arxiv.org/abs/2504.04419): TLDR: builds embeddings and retrieval over driving scenarios so online decision making, planning, and offline simulation can reuse similar past scenes rather than treating each case independently.
- [LangCoop](https://arxiv.org/abs/2504.13406): TLDR: compresses V2X cooperation into concise natural-language messages and uses structured vision-language reasoning to coordinate connected driving agents with much lower communication bandwidth.
- [Sky-Drive: A Distributed Multi-Agent Simulation Platform for Socially-Aware and Human-AI Collaborative Future Transportation](https://arxiv.org/abs/2504.18010): Agent-harness candidate for autonomous driving: Provides a distributed multi-agent simulation platform for future transportation.
- [Seeking to Collide: Online Safety-Critical Scenario Generation for Autonomous Driving with Retrieval Augmented Large Language Models](https://arxiv.org/abs/2505.00972): Uses llm or agentic orchestration for autonomous-driving scenario generation or planning.
- [AI-CDA4All: Democratizing Cooperative Autonomous Driving for All Drivers via Affordable Dash-cam Hardware and Open-source AI Software](https://arxiv.org/abs/2505.06749): TLDR: proposes an affordable cooperative-driving stack around dash-cam hardware and open-source software, targeting interoperability for vehicles without expensive CDA sensors.
- [Case-based Reasoning Augmented Large Language Model Framework for Decision Making in Realistic Safety-Critical Driving Scenarios](https://arxiv.org/abs/2506.20531): TLDR: augments an LLM driving decision maker with case-based retrieval so safety-critical decisions are grounded in analogous prior scenarios instead of only generic language priors.
- [AGENTS-LLM](https://arxiv.org/abs/2507.13729): TLDR: uses an agentic LLM framework to augment rare and challenging traffic scenarios, giving driving planners harder stress cases than fixed real-world scene libraries provide.
- [VLM-UDMC: VLM-Enhanced Unified Decision-Making and Motion Control for Urban Autonomous Driving](https://arxiv.org/abs/2507.15266): Combines VLM-enhanced decision making and motion control for urban autonomous driving.
- [SafeDriveRAG: Towards Safe Autonomous Driving with Knowledge Graph-based Retrieval-Augmented Generation](https://arxiv.org/abs/2507.21585): Combines knowledge-graph RAG with autonomous-driving safety reasoning.
- [Risk Map as Middleware: Toward Interpretable Cooperative End-to-End Autonomous Driving for Risk-Aware Planning](https://arxiv.org/abs/2508.07686): An agent harness or runtime for autonomous driving. Core idea: externalize toward interpretable cooperative end-to-end autonomous driving for risk-aware planning into reusable orchestration, tool-use, memory, or protocol logic.
- [Multi-Agent Visual-Language Reasoning for Comprehensive Highway Scene Understanding](https://arxiv.org/abs/2508.17205): TLDR: decomposes highway-scene understanding across specialized VLM agents with domain-specific chain-of-thought prompts, improving traffic risk interpretation beyond a single generic VLM.
- [MTRDrive](https://arxiv.org/abs/2509.20843): TLDR: combines procedural driving-experience retrieval with dynamic toolkits, forming a memory-tool reasoning loop for hallucination-prone corner cases and zero-shot roadwork scenarios.
- [SafeCoop](https://arxiv.org/abs/2510.18123): TLDR: protects natural-language collaborative driving with a semantic firewall, language-perception consistency checks, multi-source consensus, and spatial-frame transformation against V2X language attacks.
- [Multi-Agent AI Framework for Road Situation Detection and C-ITS Message Generation](https://arxiv.org/abs/2511.06892): Contributes an agent workflow, runtime, protocol, tool-use pattern, or multi-agent orchestration approach for autonomous driving.
- [Argus: Resilience-Oriented Safety Assurance Framework for End-to-End ADSs](https://arxiv.org/abs/2511.09032): Builds a resilience-oriented safety-assurance framework for end-to-end autonomous-driving systems.
- [A Multi-Agent LLM Framework for Design Space Exploration in Autonomous Driving Systems](https://arxiv.org/abs/2512.08476): TLDR: applies multiple LLM agents to autonomous-driving hardware and software design-space exploration, interpreting complex execution outputs across traffic, weather, road, and configuration variables.
- [Dream2Drive](https://doi.org/10.1109/IJCNN64981.2025.11228910): TLDR: builds an LLM vehicle motion-planning agent with observation, short-term memory, long-term experience, planning, and rethinking modules for multi-task real-world driving.
- [LLM-Based Safety Case Generation for Baidu Apollo](https://doi.org/10.1109/CAIN66642.2025.00033): TLDR: tests whether LLMs can draft safety cases for Baidu Apollo, extending driving-agent coverage to assurance artifacts rather than control performance.
- [DAPlanner: Dual-agent framework with multi-modal large language model for autonomous driving motion planning](https://doi.org/10.1016/j.asoc.2025.113625): TLDR: separates multimodal scene reasoning and motion-planning decisions into a dual-agent MLLM workflow, aiming to make driving plans both interpretable and responsive.
- [Retrieval-Augmented Autonomous Driving Agent Framework for Complex Traffic Scenarios](https://doi.org/10.1109/icftic68075.2025.11325053): TLDR: augments a VLM driving agent with retrieval over long-tail and corrupted traffic scenarios, improving robustness under open-set visual conditions.
- [TrajAgents: A Multi-Agent Framework for Interpretable and Semantically Consistent V2I Trajectory Prediction](https://doi.org/10.1109/mesa68091.2025.11278858): Provides a multi-agent framework for interpretable and semantically consistent V2I trajectory prediction.
- [SafeSim: An Open-Source Platform for Safety-Critical Driving Scenario Simulation and Curriculum-based Adversarial Training](https://doi.org/10.1109/smc58881.2025.11343679): Provides an open-source platform for safety-critical driving scenario simulation and curriculum-based adversarial training.
- [Virtual Traffic Police: Large Language Model-Augmented Traffic Signal Control for Unforeseen Incidents](https://arxiv.org/abs/2601.15816): A reusable agent harness, runtime, protocol, or workflow scaffold for autonomous-driving and driving VLA systems. Core idea: Adaptive traffic signal control (TSC) has demonstrated strong effectiveness in managing dynamic traffic flows.
- [PRAM-R: A Perception-Reasoning-Action-Memory Framework with LLM-Guided Modality Routing for Adaptive Autonomous Driving](https://arxiv.org/abs/2603.04222): Combines perception, reasoning, action, and memory with LLM-guided modality routing for adaptive autonomous driving.
- [CRASH: Cognitive Reasoning Agent for Safety Hazards in Autonomous Driving](https://arxiv.org/abs/2603.15364): TLDR: analyzes NHTSA AV incident reports with an LLM reasoning agent that summarizes crashes, attributes primary causes, and estimates whether the AV materially contributed.
- [Agentic Fast-Slow Planning](https://arxiv.org/abs/2604.01681): TLDR: decouples slow large-model reasoning from fast control by mapping scene topology to symbolic directives, refining planner parameters with feedback and memory, and tracking with MPC.
- [Causal Scene Narration with Runtime Safety Supervision for Vision-Language-Action Driving](https://arxiv.org/abs/2604.01723): Adds causal scene narration and runtime safety supervision for vision-language-action driving.
- [Automotive Engineering-Centric Agentic AI Workflow Framework](https://arxiv.org/abs/2604.07784): A candidate agent harness, workflow, protocol, runtime, or orchestration method for autonomous-driving agents and models. Its value is making agent-side control, tool use, coordination, or verification reusable beyond one prompt.
- [Ozone: A Unified Platform for Transportation Research](https://arxiv.org/abs/2604.10959): A reusable execution or planning harness for autonomous driving; core idea: A Unified Platform for Transportation Research.
- [Agentic traffic intelligence: Augmented human-in-the-loop scenario generation for microscopic traffic simulation](https://doi.org/10.1016/j.ait.2026.100057): Uses augmented human-in-the-loop scenario generation for microscopic traffic simulation.
- [SafeTraffic Copilot: adapting large language models for trustworthy traffic safety assessments and decision interventions](https://doi.org/10.1038/s41467-025-64574-w): TLDR: adapts LLMs to forecast expected crashes and recommend trustworthy interventions, emphasizing transparent traffic-safety assessment rather than perception-only prediction.
- [Decision-Making Framework for Autonomous Vehicles in Complex Scenarios Using Large Language Models](https://doi.org/10.1007/s42154-025-00408-1): TLDR: applies LLM reasoning to autonomous-vehicle decision making in complex scenarios, making commonsense interpretation part of the planning workflow.
