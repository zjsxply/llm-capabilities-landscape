# 1.13.2 Survey

- [Augmented Language Models: a Survey](https://arxiv.org/abs/2302.07842)：关于工具、检索、记忆与外部推理增强模型的基础综述。
- [What Are Tools Anyway? A Survey from the Language Model Perspective](https://arxiv.org/abs/2403.15452)：建立 tools 与可复用 skills 之间的概念边界。
- [LLM App Store Analysis: A Vision and Roadmap](https://arxiv.org/abs/2404.12737)：综述或系统梳理技能使用，为该能力页补充分类、趋势或风险边界。
- [Agent Skills](https://arxiv.org/abs/2602.08004)：把公开 Claude-style skills 作为可复用 agent 能力模块进行实证分析。核心思想：分析 marketplace 类别、采用情况、prompt budget 适配和安全风险，把 skill 生态作为可研究对象。
- [Agent Skills for Large Language Models: Architecture, Acquisition, Security, and the Path Forward](https://arxiv.org/abs/2602.12430)：回顾 skill 架构、获取流程、安全与未来方向。
- [SoK: Agentic Skills - Beyond Tool Use in LLM Agents](https://arxiv.org/abs/2602.20867)：系统化梳理超越一次性计划和原子工具调用的可复用 agentic skills。
- [Towards Secure Agent Skills: Architecture, Threat Taxonomy, and Security Analysis](https://arxiv.org/abs/2604.02837)：给出恶意 skill、供应链与沙箱的威胁分类。
- [A Comprehensive Survey on Agent Skills: Taxonomy, Techniques, and Applications](https://arxiv.org/abs/2605.07358)：直接综述 agent skill 的定义、获取、组合、评测与应用。
- [When Skills Don't Help](https://arxiv.org/abs/2605.20023)：为 tool-grounded offensive-cybersecurity agent 中的程序性 skills 提供负结果证据。核心思想：重新分析 MCP-grounded CTF agent 的 skills ablation，并用 environment-feedback bandwidth 解释何时可复用程序知识不再带来收益。
- [Agent Skill Evaluation and Evolution: Frameworks and Benchmarks](https://arxiv.org/abs/2606.11435)：综述 agent skill 的评测与演化，把执行反馈、轨迹蒸馏、压缩和强化学习等机制同效用、质量和安全评估连接起来。
