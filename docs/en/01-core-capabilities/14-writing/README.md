# 1.14 Writing and Long-Form Generation

> Parent section: 1. Foundational Capabilities

Note: Writing overlaps with DeepResearch, but the evaluation target is different.
Writing tasks mainly ask whether a model can produce high-quality text under constraints on topic, materials, style, structure, length, and audience.
The main failure modes are drifting off topic, losing structural control, inconsistent style, redundancy, incoherent narration or argumentation, and failure to satisfy format or length constraints.
DeepResearch mainly evaluates open-ended information acquisition, source filtering, evidence support, citation consistency, and multi-source synthesis; writing is only its final expression stage.
This section therefore remains an independent foundational capability.
Work that "first searches for evidence and then writes a report" should primarily be placed under [2.4 Deep Research](../../02-agent-capabilities/04-deep-research/README.md); this section only cross-lists representative work that directly contributes to writing quality, long-form structure, or drafting workflows.
