# 1.4.1 Leaderboard

- [The FACTS Leaderboard: A Comprehensive Benchmark for Large Language Model Factuality](https://arxiv.org/abs/2512.10791): 系统化 FACTS Leaderboard suite，覆盖多模态、参数知识、搜索和 grounding factuality，并用公开/私有 split 支持持续提交。
- [Hallucinations Leaderboard](https://huggingface.co/spaces/hallucinations-leaderboard/leaderboard)：早期开放幻觉榜单尝试；价值在于把 TruthfulQA、HaluEval、FEVER 等信号聚合到统一比较入口。
- [LLM-AggreFact Leaderboard](https://llm-aggrefact.github.io/)：grounded factuality verifier 榜单；价值在于把多源 factual consistency 数据统一成可比较评测集，并连接 MiniCheck 等可运行检测器。
- [Vectara Hallucination Evaluation Leaderboard](https://huggingface.co/spaces/vectara/Hallucination-evaluation-leaderboard)：面向摘要/RAG 场景的公开幻觉榜单；价值在于持续比较回答是否由输入事实支撑，并提供 HHEM/FaithJudge 等自动评测器线索。
- [FACTS Grounding Leaderboard](https://www.kaggle.com/facts-leaderboard)：Google FACTS Grounding 的 Kaggle 榜单；价值在于为长文本 grounded factuality 提供早于广义 FACTS suite 的具体公开排名入口。
- [Kaggle Benchmarks 上的 FACTS Leaderboard](https://www.kaggle.com/benchmarks/google/facts)：扩展版 FACTS factuality suite 的公开 Kaggle 入口；价值在于把多模态、参数知识、搜索和 grounding factuality 轨道放在统一提交界面下。
- [SimpleQA Verified Leaderboard](https://www.kaggle.com/benchmarks/deepmind/simpleqa-verified)：DeepMind verified short factuality evaluation 的 Kaggle benchmark 页面；价值在于跟踪低歧义、客观核验 factoid QA 上的幻觉率与正确率。
- [AVeriTeC Leaderboard](https://huggingface.co/spaces/fever/AVeriTeC)：FEVER 维护的自动文本声明验证公开榜单；价值在于比较需要检索证据并验证复杂真实世界声明的系统。
- [SciHal25 Kaggle Leaderboard](https://www.kaggle.com/competitions/hallucination-detection-scientific-content-2025/leaderboard)：科学内容幻觉检测公开竞赛榜单；价值在于按 shared-task 协议跟踪多语言科学幻觉检测器。
- [Google DeepMind Eval Suite 中的 FACTS 入口](https://deepmind.google/research/evals/)：FACTS 事实性评测的公开入口；价值在于把 grounded、search、parametric 和 multimodal factuality 等设置组织为可比较、可提交、可复核的评测轨道。
