- [ResearchStudio-Reel](https://arxiv.org/abs/2607.04438): Packages five Codex/Claude-executable skills that extract a shared asset bundle, generate editable PowerPoint poster/video and bilingual Word blog artifacts, and bind them in an interactive Paper2Reel viewer. Its measured-fill and artifact-specific release checks make paper promotion a testable research-delivery workflow.
- [Rehearse: Stepping Back from the Confidence Cliff in Self-Improving Autoresearch](https://arxiv.org/abs/2607.27687): Improves autoresearch loops by selecting among proposed changes before execution and using focused memory of comparable prior outcomes.
- [SciVisAgentSkills](https://arxiv.org/abs/2606.05525): Packages reusable skills for scientific data analysis and visualization. Core idea: expose ParaView, napari, VMD, and TTK operations as agent skills and evaluate them on 108 multi-step visualization tasks.
- [F(AI)2R: Who Did What, and Who Checked? Verifiable AI Provenance as an Executable Skill](https://arxiv.org/abs/2607.25637): Packages AI-in-the-loop research provenance as an executable skill over the aiprov PROV-O extension: setup resolves an operator ORCID, scaffolds CI that gates pushes on graph conformance, and records activities, claims, and sources under no-parentless-claim and human-only verification-rung invariants, with the paper's build as its case study.
- [Scientific Data Skills: Enabling Agent-Ready Scientific Data Services at Scale](https://arxiv.org/abs/2608.19625): Defines SciDSK as a reusable agent skill that packages dataset context, file organization, operating procedures, quality checks, and provenance while leaving data in its authoritative repository; a six-discipline Skill Bank and discovery and interpretation evaluations show that the structured packages make scientific data more actionable for agents.
- [Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents](https://arxiv.org/abs/2609.00065): The library packages 163 versioned procedures across 16 practice areas as on-demand directories containing instructions, references, and runnable scripts, covering choices such as accepted statistical tests, authoritative identifier namespaces, and required caveats; it reports no task-level evaluation.
