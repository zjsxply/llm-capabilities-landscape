# 2.9.1 Leaderboard

- [CAIS AI Dashboard](https://dashboard.safe.ai/)：包含 Risk Index、capability index 与 automation 视图，是当前最适合跨模型观察能力-风险共同演化的公开安全总览。
- [MLCommons AILuminate official results](https://ailuminate.mlcommons.org/benchmarks/security/0.5-en_us-official-ensemble)：发布 MLCommons AI 安全与可靠性基准的官方结果，协议标准化程度较高，是当前较可信的公开安全结果页面之一。
- [Libra-Leaderboard](https://leaderboard.librai.tech/)：在公开榜单中同时平衡 helpfulness 与 safety 分数，适合观察只看安全分数时容易被隐藏的能力退化。
- [TrustLLM benchmark site](https://trustllmbenchmark.github.io/TrustLLM-Website/)：提供 truthfulness、safety、fairness、robustness、privacy、machine ethics 等多维 trustworthiness 的公开模型结果表。
- [HarmBench](https://www.harmbench.org/)：自动红队与鲁棒拒答基准的官方页面，公开展示 attack、classifier 与 target model 的结果线索。
- [JailbreakBench](https://jailbreakbench.github.io/)：越狱攻防开放鲁棒性基准的官方站点，提供面向模型拒答鲁棒性的 challenge-style 公开结果表。
- [AgentDojo results](https://agentdojo.spylab.ai/results)：工具型 agent 提示注入鲁棒性的官方结果页，区分 task utility、attack success 与 defense behavior。
- [SafeArena leaderboard](https://huggingface.co/spaces/McGill-NLP/safearena-leaderboard)：自主 Web Agent 安全的 Hugging Face 榜单，与 SafeArena 官方项目页配套。
- [SafePro](https://safeprobench.github.io/safepro/)：专业级 agent 安全项目页，提供 benchmark 说明和 unsafe-rate 等结果线索；适合追踪现实专业工作中“能完成但不安全”的失败模式。
- [SORRY-Bench](https://sorry-bench.github.io/)：安全拒答基准的官方站点，公开呈现 refusal 与 over-refusal 行为的模型结果。
- [Agent Security Bench / ASB](https://luckfort.github.io/ASBench/)：Agent 安全攻防的官方结果页，覆盖提示注入、记忆投毒、后门与工具阶段漏洞。
- [SafeBench for MLLMs](https://safebench-mm.github.io/)：多模态大模型安全评测的官方项目页与结果表。
- [SafeAgentBench](https://safeagentbench.github.io/)：具身 agent 安全规划的官方项目页，提供 benchmark 示例与结果线索。
- [AgentHarm evaluation](https://ukgovernmentbeis.github.io/inspect_evals/evals/safeguards/agentharm/)：UK AISI Inspect Evals 中的 AgentHarm 页面，说明该公开评测实现与结果解读方式。
- [ML Safety SafeBench winners](https://www.mlsafety.org/safebench/winners)：SafeBench challenge 的竞赛结果页，可用于定位 AgentDojo、BackdoorLLM 等安全 benchmark 优胜提交。
- [Gray Swan Agent Red-Teaming Challenge results](https://www.grayswan.ai/news/uk-aisi-x-gray-swan-agent-red-teaming-challenge-results-snapshot)：Agent 间接提示注入红队竞赛的公开结果快照，与 ART-style agent red-team evaluation 相关。

说明：Agent 安全方向还没有像 SWE-bench 或 Terminal-Bench 那样成熟统一的持续提交榜，当前更常见的是项目页、dashboard 和论文内结果表。
