# 1.4.6 Skill

- [fact-checker](https://skills.sh/shubhamsaboo/awesome-llm-apps/fact-checker) is suitable for fact checking and evidence tracing.
- [fact-checker](https://skills.sh/daymade/claude-code-skills/fact-checker) leans more toward "report-style verification results."
- [fact-check](https://clawhub.ai/webguhui/fact-check) can turn arbitrary claims into a cross-checking workflow.
- [clarity-gate](https://clawhub.ai/frmoretto/clarity-gate) explicitly flags risks such as "missing uncertainty markers" and "verifiable claims not verified."
- [citation-validator](https://skills.sh/liangdabiao/claude-code-stock-deep-research-agent/citation-validator) is suitable for intercepting cases where a cited source appears to exist but does not support the conclusion.
