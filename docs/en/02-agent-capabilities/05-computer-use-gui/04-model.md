# 2.5.4 Model

- [CogAgent](https://arxiv.org/abs/2312.08914) ([code](https://github.com/THUDM/CogAgent)): Specializes a visual language model for GUI understanding and navigation, with a refreshed CogAgent-9B release noted in the paper metadata.
- [ScreenAI: A Vision-Language Model for UI and Infographics Understanding](https://arxiv.org/abs/2402.04615): Specializes a 5B PaLI-style vision-language model with pix2struct flexible patching, screen-element type and location annotation, and LLM-generated QA, navigation, and summarization data.
- [Improving Language Understanding from Screenshots](https://arxiv.org/abs/2402.14073): Pretrains screenshot language models with Patch-and-Text Prediction, recovering masked image patches and rendered text so visual-only inputs approach BERT-level GLUE performance.
- [AutoWebGLM](https://arxiv.org/abs/2404.03648) ([code](https://github.com/THUDM/AutoWebGLM)): Trains a ChatGLM-based web-navigation model with HTML simplification, curriculum data, reinforcement learning, and rejection sampling.
- [Ferret-UI](https://arxiv.org/abs/2404.05719): Trains a multimodal LLM for mobile UI referring, grounding, reasoning, and open-ended UI instruction following.
- [VisualWebBench: How Far Have Multimodal LLMs Evolved in Web Page Understanding and Grounding?](https://arxiv.org/abs/2404.05955): Provides a web-page understanding and grounding benchmark with 1.5K human-curated examples from 139 sites, exposing MLLM failures on text-rich grounding and low-resolution inputs.
- [Large Language Models Meet User Interfaces: The Case of Provisioning Feedback](https://arxiv.org/abs/2404.11072): Replaces free-form conversational LLM use in education with Feedback Copilot, an API-backed application framework for personalized assignment feedback and safer UI-mediated GenAI deployment.
- [OmniActions: Predicting Digital Actions in Response to Real-World Multimodal Sensory Inputs with LLMs](https://arxiv.org/abs/2405.03901): Derives a design space of digital follow-up actions from a diary study, then evaluates LLM intent classification, in-context learning, and finetuning for action prediction over multimodal inputs.
- [V-Zen: Efficient GUI Understanding and Precise Grounding With A Novel Multimodal LLM](https://arxiv.org/abs/2405.15341): Combines dual-resolution image encoders with the GUIDE dataset of real GUI elements and task sequences to improve efficient grounding and next-action prediction.
- [GUI Action Narrator: Where and When Did That Action Take Place?](https://arxiv.org/abs/2406.13719): Introduces Act2Cap and GUI Narrator, using cursor detection, keyframe selection, and key-region prompting or finetuning to caption subtle GUI actions in videos.
- [Flowy: Supporting UX Design Decisions Through AI-Driven Pattern Annotation in Multi-Screen User Flows](https://arxiv.org/abs/2406.16177): Uses large multimodal AI models and a high-quality user-flow dataset to annotate abstract design patterns across multi-screen UX flows for designer ideation.
- [Automatically Generating UI Code from Screenshot: A Divide-and-Conquer-Based Approach](https://arxiv.org/abs/2406.16386): Proposes DCGen, which segments webpage screenshots, generates code for each visual segment, and reassembles the result to reduce omission, distortion, and layout errors in MLLM UI-code generation.
- [MobileFlow](https://arxiv.org/abs/2407.04346): Transforms Qwen-VL-Chat into a 21B mobile-GUI MLLM with hybrid visual encoders, MoE expansion, and GUI alignment for Chinese mobile interfaces.
- [OmniParser](https://arxiv.org/abs/2408.00203): Trains screenshot parsing components for interactable-region detection and UI-element semantics, enabling pure-vision GUI agents to ground actions more reliably.
- [UI-JEPA](https://arxiv.org/abs/2409.04081): Learns lightweight active perception of user intent from onscreen UI activity, making user-state inference a model-side component for GUI agents.
- [Bridging Design and Development with Automated Declarative UI Code Generation](https://arxiv.org/abs/2409.11667): Presents DeclarUI, combining component segmentation, Page Transition Graphs, and compiler-driven iterative optimization to generate React Native, Flutter, and ArkUI code from UI designs.
- [MobileVLM: A Vision-Language Model for Better Intra- and Inter-UI Understanding](https://arxiv.org/abs/2409.14818): Adds UI-specific pretraining stages and four mobile tasks over the Mobile3M Chinese UI graph to teach fine-grained elements and page-transition actions.
- [Ferret-UI 2](https://arxiv.org/abs/2410.18967): Extends Ferret-UI into a cross-platform UI-understanding model across iPhone, Android, iPad, web pages, and Apple TV.
- [OS-ATLAS](https://arxiv.org/abs/2410.23218): A foundation action model for generalist GUI agents trained to map screen observations and instructions into GUI actions.
- [AutoGLM](https://arxiv.org/abs/2411.00820): Trains autonomous foundation agents for browser and phone GUIs with progressive self-evolving online curriculum reinforcement learning.
- [Falcon-UI: Understanding GUI Before Following User Instructions](https://arxiv.org/abs/2412.09362): Pretrains a 7B GUI agent on the instruction-free Insight-UI dataset from Common Crawl before Android and web instruction tuning, separating GUI context understanding from task following.
- [Attention-driven GUI Grounding: Leveraging Pretrained Multimodal Large Language Models without Fine-Tuning](https://arxiv.org/abs/2412.10840): Proposes TAG, a tuning-free grounding method that aggregates pretrained MLLM attention maps from query prompts to localize GUI text and icons.
- [AutoDroid-V2: Boosting SLM-based GUI Agents via Code Generation](https://arxiv.org/abs/2412.18116): Converts mobile task automation into on-device SLM code generation, using app-specific API documentation and synthetic task samples to produce executable UI scripts with lower latency and token cost.
- [OS-Genesis](https://arxiv.org/abs/2412.19723): Automates GUI-agent trajectory construction through reverse task synthesis and reward-model filtering, creating training data for GUI policies.

- [How Mobile World Model Guides GUI Agents?](https://arxiv.org/abs/2605.10347): This work studies how mobile world models can guide GUI agents.
- [ToolCUA](https://arxiv.org/abs/2605.12481) ([project page](https://x-plug.github.io/ToolCUA/)): Trains a CUA model for hybrid GUI-tool path selection through interleaved trajectory synthesis, RFT, online agentic RL, and tool-efficient path rewards.
- H Company Holo/Holotron family ([Holo2](https://hcompany.ai/holo2); [Holotron-12B](https://hcompany.ai/holotron-12b); [Holotron 3 Nano](https://hcompany.ai/holotron3)): Multimodal CUA models for navigation and localization across web, desktop, and mobile interfaces.
- Microsoft Fara1.5 ([official report](https://www.microsoft.com/en-us/research/articles/fara1-5-computer-use-agent/)): A small browser CUA model family continuing Fara-style synthetic browser-action training at 4B, 9B, and 27B scales.
- [DRS-GUI: Dynamic Region Search for Training-Free GUI Grounding](https://arxiv.org/abs/2605.15542): Uses dynamic region search for training-free GUI grounding, improving precise screen-element localization without additional training.
- [DroidCoder: Enhanced Android Code Completion with Context-Enriched Retrieval-Augmented Generation](https://doi.org/10.1145/3691620.3695063): Enriches RAG for Android code completion with Android-specific context and a tailored fine-tuning loss, improving line-level and multi-line completion for lifecycle callbacks and UI widgets.
- [GUI-Narrator: Detecting and Captioning Computer GUI Actions](https://doi.org/10.1145/3746027.3755150): Detects and captions computer GUI actions, adding an action-understanding component for training or auditing computer-use agents.
