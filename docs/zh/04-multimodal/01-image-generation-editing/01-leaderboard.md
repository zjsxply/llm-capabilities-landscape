# 4.1.1 Leaderboard

- [Artificial Analysis Text to Image Leaderboard](https://artificialanalysis.ai/text-to-image)：基于盲测人类偏好的公开文本到图像竞技场式对比榜单。
- [Arena Image Edit Leaderboard](https://arena.ai/en/leaderboard/image-edit)：面向指令式图像编辑系统的公开竞技场榜单。
- [GenAI-Bench Leaderboard](https://huggingface.co/datasets/TIGER-Lab/GenAI-Bench)：GenAI-Bench 官方榜单，用于比较文本到视觉生成评估器与模型输出。
- [DreamBench++ Leaderboard](https://dreambenchplus.github.io/#leaderboard)：DreamBench++ 官方个性化图像生成榜单，比较概念保持与提示遵循能力。
- [MJ-Bench Leaderboard](https://mj-bench.github.io/#leaderboard)：MJ-Bench 官方榜单，用于在对齐、安全、图像质量和偏见维度评测文本到图像偏好判断器。
- [AI-GenBench Leaderboard](https://mi-biolab.github.io/aigenbench-website/)：AI-GenBench 官方持续更新榜单，面向 AI 生成图像检测。
- [ForensicHub FIDL Leaderboard](https://scu-zjz.github.io/ForensicHub-doc/rank/fidl_rank.html)：ForensicHub 官方伪造图像检测与定位榜单，覆盖 deepfake、篡改图像、AIGC 和文档篡改等域。
- [UniGenBench++ Leaderboards](https://github.com/CodeGoat24/UniGenBench)：UniGenBench++ 官方仓库，链接维护中的英文、中文与长提示 Hugging Face 榜单。
- [GIR-Bench Leaderboard](https://hkust-longgroup.github.io/GIR-Bench/)：GIR-Bench 官方推理式图像生成榜单，面向统一多模态模型。
- [GIE-Bench Leaderboard](https://sueqian6.github.io/GIE-Bench-web/#leaderboard)：GIE-Bench 官方 grounded 图像编辑榜单，比较功能正确性与内容保持能力。
- [BizGenEval Leaderboard](https://microsoft.github.io/BizGenEval/)：BizGenEval 官方商业视觉内容生成榜单，比较版式、品牌、指令遵循与内容质量。
