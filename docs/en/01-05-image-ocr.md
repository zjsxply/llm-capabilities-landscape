# 1.5 Images (Including OCR)

> Parent chapter: 1. Basic Capabilities

## 1.5.1 Leaderboard

- [DocVQA Challenge](https://www.docvqa.org/challenges): continuous leaderboard and classic public challenge for document visual question answering. It is suitable for tracking long-term progress in OCR, layout understanding, and answer extraction on real document QA.
- [Vision Arena](https://huggingface.co/spaces/WildVision/vision-arena): continuous leaderboard for pairwise battles between open-ended image-dialogue models. It is suitable for supplementing traditional accuracy leaderboards with human-preference/open-QA comparisons.
- [OCRBench v2 Leaderboard](https://www.codesota.com/ocr/benchmark/ocrbench-v2): continuous leaderboard aggregating results around OCRBench v2 for text-rich images, documents, charts, and OCR-to-reasoning. It is useful for quickly tracking where new VLMs stand on the "read text and reason" pipeline.
- [OmniDocBench Leaderboard](https://github.com/opendatalab/OmniDocBench#leaderboard): continuous leaderboard for layout, table, paragraph, and structured metrics in document-parsing pipelines. It is suitable for comparing OCR-free/OCR-based parsers and end-to-end document models.
- [IDP Leaderboard](https://idp-leaderboard.org/): continuous leaderboard for enterprise document AI models, covering OCR, table extraction, KIE, VQA, classification, and long-document processing. It is suitable as an engineering-side comprehensive leaderboard for "document intelligence."
- [OCR Arena](https://www.ocrarena.ai/): continuous arena-style comparison for OCR/document models. It is useful for finding reusable document-parsing, table-extraction, and visual-QA model configurations.

## 1.5.2 Survey

- [From Pixels to Insights: A Survey on Automatic Chart Understanding in the Era of Large Foundation Models](https://arxiv.org/abs/2403.12027): Covers chart-understanding tasks, datasets, methods, and evaluation under foundation models.
- [Survey on Question Answering over Visually Rich Documents: Methods, Challenges, and Trends](https://arxiv.org/abs/2501.02235): Surveys document QA over layout, OCR, structure, and reasoning challenges.
- [A Survey on MLLM-based Visually Rich Document Understanding: Methods, Challenges, and Emerging Trends](https://arxiv.org/abs/2507.09861): Updates document understanding for end-to-end multimodal large language models.
- [Scaling Beyond Context: A Survey of Multimodal Retrieval-Augmented Generation for Document Understanding](https://arxiv.org/abs/2510.15253): Reviews multimodal retrieval for long and multi-page document understanding.
- [A Survey of OCR Evaluation Methods and Metrics and the Invisibility of Historical Documents](https://arxiv.org/abs/2603.25761): Anchors OCR-specific metrics and historical-document blind spots.

## 1.5.3 Bench

(The following are sorted by release time and cover OCR, document understanding, chart understanding, general VQA and diagnostics, STEM/science figure reasoning, visual agent/tool-use evaluation, and related subtasks.)

- [DocVQA](https://arxiv.org/abs/2007.00398) ([challenge page](https://www.docvqa.org/challenges)): evaluates visual question answering, table understanding, and information extraction on document images. The core idea is to put OCR, layout structure, and answer localization in real scanned/photographed documents into one challenge protocol; it is the core benchmark behind the DocVQA Challenge leaderboard.
- [FSC-147](https://arxiv.org/abs/2105.08386): evaluates few-shot counting, where the model counts in a new image after receiving a few annotated examples. The core idea is to test counting generalization in a few-shot setting, and it is often used as a classic reference for the "counting" sub-capability.
- `CountBench` (see [Teaching CLIP to Count to Ten](https://arxiv.org/abs/2302.12066); [dataset](https://huggingface.co/datasets/vikhyatk/CountBenchQA)): evaluates visual counting and the reliability of quantity concepts. The core idea is to diagnose basic visual capability and bias through "whether the count is correct", often combined with VQA/bias diagnostics.
- [HallusionBench](https://arxiv.org/abs/2310.14566) ([open-source code](https://github.com/tianyi-lab/HallusionBench); [dataset](https://huggingface.co/datasets/lmms-lab/HallusionBench)): evaluates visual hallucination and errors driven by visual illusions. The core idea is to use controlled visual illusions and image-context reasoning questions to diagnose specific types of "making things up from images."
- [MMMU](https://arxiv.org/abs/2311.16502) ([homepage/leaderboard](https://mmmu-benchmark.github.io/#leaderboard); [dataset](https://huggingface.co/datasets/MMMU/MMMU); [evaluation code](https://github.com/MMMU-Benchmark/MMMU)): evaluates multidisciplinary multimodal understanding and reasoning. The core idea is to use cross-disciplinary question types and a unified scoring protocol to measure integrated "see image + read question + reason" capability.
- [MMStar](https://arxiv.org/abs/2403.20330) ([project page](https://mmstar-benchmark.github.io/); [open-source code](https://github.com/MMStar-Benchmark/MMStar); [dataset](https://huggingface.co/datasets/Lin-Chen/MMStar)): evaluates comprehensive multimodal tasks where vision is indispensable. The core idea is to use multidimensional sub-capability axes and analysis metrics such as "multimodal gain/leakage" to measure whether models truly use visual input.
- [Vibe-Eval](https://arxiv.org/abs/2405.02287) ([open-source code](https://github.com/reka-ai/reka-vibe-eval)): evaluates multimodal models across multidimensional tasks. The core idea is to provide a broad comprehensive evaluation suite with annotations and scoring protocols closer to human subjective preferences.
- [MTVQA](https://arxiv.org/abs/2405.11985) ([project page](https://mtvqa.github.io/); [open-source code](https://github.com/bytedance/MTVQA)): evaluates multilingual text-centric visual QA, where models read and understand text in images. The core idea is to cover multilingual and low-resource languages and emphasize integrated text perception and cross-lingual understanding.
- [MuirBench](https://arxiv.org/abs/2406.09411) ([project page](https://muirbench.github.io/); [open-source code](https://github.com/muirbench/MuirBench); [dataset](https://huggingface.co/datasets/muirbench/MuirBench)): evaluates robust multi-image understanding under multi-image input. The core idea is to decompose multi-image tasks into robustness/consistency subtasks that specifically test cross-image alignment and resistance to interference.
- [CharXiv](https://arxiv.org/abs/2406.18521) ([project page](https://princeton-nlp.github.io/CharXiv/); [dataset](https://huggingface.co/datasets/princeton-nlp/CharXiv)): evaluates chart/figure and image-text alignment understanding in scientific-paper settings. The core idea is to make "figure-text evidence alignment" into quantifiable QA.
- [Vision Arena](https://huggingface.co/spaces/WildVision/vision-arena): evaluates human preference/arena-style comparisons for open-ended image-dialogue models. The core idea is to use pairwise battles to supplement fixed VQA/OCR question sets, making it suitable for observing model preference rankings in real open image QA.
- [VLMs are Blind](https://arxiv.org/abs/2407.06581) ([project page](https://vlmsareblind.github.io/)): evaluates VLM reliability on extremely simple visual-primitive tasks. The core idea is to use geometry/spatial/counting mini-tests that are nearly effortless for humans to diagnose whether models really "see" the key evidence.
- [MMMU-Pro](https://arxiv.org/abs/2409.02813) ([homepage/leaderboard](https://mmmu-benchmark.github.io/#leaderboard); [dataset](https://huggingface.co/datasets/MMMU/MMMU_Pro); [evaluation code](https://github.com/MMMU-Benchmark/MMMU)): evaluates harder multimodal STEM where the model "must look at the image." The core idea is to embed question text into images, filter out text-only-answerable questions, and strengthen distractor options so evaluation depends more on visual input and reasoning chains.
- [OmniDocBench 1.5](https://arxiv.org/abs/2412.07626) ([open-source code](https://github.com/opendatalab/OmniDocBench); [dataset](https://huggingface.co/datasets/opendatalab/OmniDocBench)): evaluates modular document-parsing capabilities such as layout, paragraphs, tables, and structure. The core idea is to decompose "document parsing capability" into measurable parts with modular metrics and engineering runtimes such as hybrid matching, CDM, and Dockerization.
- [OCRBench v2](https://arxiv.org/abs/2501.00321) ([evaluation implementation collection](https://github.com/Yuliang-Liu/MultimodalOCR)): evaluates multimodal OCR, where models read text in images and then perform understanding/reasoning. The core idea is to couple OCR with downstream reasoning and distinguish "cannot read it" from "read it but cannot use it."
- [EMMA](https://arxiv.org/abs/2501.05444) ([homepage/leaderboard](https://emma-benchmark.github.io/); [dataset](https://huggingface.co/datasets/luckychao/EMMA-mini); [open-source code](https://github.com/EMMA-Bench/EMMA)): evaluates "organic multimodal reasoning" across math, physics, chemistry, and coding. The core idea is to construct tasks that require chaining evidence across modalities and provide generation/evaluation scripts for reproducible comparison.
- [SimpleVQA](https://arxiv.org/abs/2502.13059) ([open-source code](https://github.com/SimpleVQA/SimpleVQA)): evaluates multimodal factuality and "whether the image is truly used." The core idea is to use a simple but strict VQA protocol to identify whether models rely on language priors instead of visual evidence.
- [RealWorldQA](https://huggingface.co/datasets/xai-org/RealworldQA): evaluates QA correctness on real-world scene images. The core idea is to use real environment images and directly verifiable short QA, reducing overestimation from synthetic data distributions and templated question types.
- [VisFactor](https://arxiv.org/abs/2502.16435) ([open-source code](https://github.com/CUHK-ARISE/VisFactor)): evaluates basic visual cognition in multimodal models, leaning toward "visual primitives." The core idea is to systematically split basic visual sub-capabilities into controlled subtests and reduce room for language gaming.
- [IDP Leaderboard](https://idp-leaderboard.org/): evaluates OCR, table extraction, KIE, VQA, classification, and long-document processing in enterprise intelligent document processing. The core idea is to organize common engineering-side document AI tasks into a public leaderboard entry point, filling gaps where academic DocVQA/OCRBench under-cover real business documents.
- [XLRS-Bench](https://arxiv.org/abs/2503.23771) ([project page](https://xlrs-bench.github.io/home_page.html); [open-source code](https://github.com/AI9Stars/XLRS-Bench)): evaluates perception and reasoning on ultra-high-resolution remote-sensing images. The core idea is to challenge general VLMs with ultra-high resolution, remote-sensing domain semantics, and cross-scale fine-grained tasks.
- [ChartQAPro](https://arxiv.org/abs/2504.05506) ([open-source code](https://github.com/vis-nlp/ChartQAPro); [dataset](https://huggingface.co/datasets/ahmed-masry/ChartQAPro)): evaluates chart understanding and chart QA. The core idea is to cover diverse chart types, increase the reasoning share, and provide reproducible evaluation scripts.
- [Omni-Chart-600K](https://doi.org/10.18653/v1/2025.findings-naacl.226): evaluates chart understanding over a large variety of chart types. Core idea: scale chart-type coverage so document and visual-language models are tested beyond common bar, line, and pie charts.
- [PointArena (PointBench)](https://arxiv.org/abs/2505.09990) ([open-source code](https://github.com/pointarena/pointarena)): evaluates pointing/localization capability, such as clicking or locating targets/regions in an image. The core idea is to turn grounding from text into measurable spatial output, where localization error can be directly evaluated.
- [WildDoc](https://arxiv.org/abs/2505.11015): evaluates comprehensiveness and robustness in real in-the-wild document understanding. The core idea is to supplement the OCRBench v2 citation chain with a stress test closer to real capture noise, complex layouts, and multitask document understanding.
- [ViC-Bench](https://arxiv.org/abs/2505.14404): Evaluates visual-interleaved chain-of-thought in MLLMs. Core idea: let models produce free-style intermediate visual states and measure whether those states support faithful stepwise multimodal reasoning.
- [PhyX](https://arxiv.org/abs/2505.15929) ([project page](https://phyx-bench.github.io/); [dataset](https://huggingface.co/datasets/Cloudriver/PhyX); [open-source code](https://github.com/killthefullmoon/PhyX)): evaluates physics reasoning in visual scenes. The core idea is to use realistic high-fidelity visual situations for college-level physics questions and provide multiple input versions, such as Text-DeRedundancy, plus evaluation scripts to reduce bias from redundant question text.
- [OCR Arena](https://www.ocrarena.ai/): evaluates arena-style comparisons of OCR/document models. The core idea is to put OCR, document parsing, table extraction, and visual-QA models into a continuously public comparison entry point as a practical supplement to OCRBench, OmniDocBench, and IDP Leaderboard.
- [MMDocRAG](https://arxiv.org/abs/2505.16470) ([project page](https://mmdocrag.github.io/MMDocRAG/); [open-source code](https://github.com/MMDocRAG/MMDocRAG)): evaluates multi-page, multi-evidence-chain document QA and multimodal RAG. The core idea is to jointly evaluate retrieval, evidence selection, and integration of "text + image evidence", avoiding text-only DocQA.
- [OCR-Reasoning Benchmark](https://arxiv.org/abs/2505.17163): evaluates complex text-rich image reasoning. The core idea is to explicitly separate OCR reading scores from post-reading reasoning and test whether models can perform compositional reasoning over dense text, tables, and image evidence.
- [InfoChartQA](https://arxiv.org/abs/2505.19028): evaluates multimodal QA for infographic-style charts. The core idea is to supplement the ChartQAPro citation chain with infographic chart scenarios, covering stronger layout variation, textual descriptions, and chart-semantics fusion.
- [VLMs are Biased](https://arxiv.org/abs/2505.23941) ([project page](https://vlmsarebiased.github.io/); [open-source code](https://github.com/anvo25/vlms-are-biased)): evaluates visual bias in VLMs and failure modes where "memory replaces looking." The core idea is to use objective counting/control constructions to reveal models being pulled by familiar object priors and ignoring real pixel evidence.
- [Agent-X](https://arxiv.org/abs/2505.24876) ([open-source code](https://github.com/mbzuai-oryx/Agent-X); [dataset](https://huggingface.co/datasets/Tajamul21/Agent-X)): evaluates vision-centric multi-step agentic tasks. The core idea is to place image, multi-image, video, and web visual contexts into real tool-use environments and evaluate reasoning chains and tool-call quality with step-level metrics.
- [SFE](https://arxiv.org/abs/2506.10521) ([competition page](https://internscience.github.io/sfe-competition-2025/); [dataset](https://huggingface.co/datasets/PrismaX/SFE)): evaluates science-exam-style understanding, reasoning, and expression. The core idea is to test scientific reasoning capability with questions and scoring protocols closer to research/science-exam expression.
- [Table Recognition with Vision LLMs](https://www.ijcai.org/proceedings/2025/279): evaluates table recognition and reasoning with vision LLMs. The core idea is to pair a benchmark with a neighbor-guided toolchain reasoner so structural table parsing and downstream reasoning are assessed together.
- [M4Bench](https://www.ijcai.org/proceedings/2025/762): evaluates multi-domain, multi-granularity, multi-image understanding for MLLMs. The core idea is to test whether models can coordinate evidence across several images and granularities, rather than solving each image independently.
- [DashboardQA](https://arxiv.org/abs/2508.17398): evaluates multimodal agent QA on interactive dashboards. The core idea is to put chart understanding, control state, and page-level information retrieval into one task, diagnosing whether agents can actively gather evidence around visualization interfaces.
- [HiPhO](https://arxiv.org/abs/2509.07894) ([dataset](https://huggingface.co/datasets/SciYu/HiPhO); [open-source code](https://github.com/SciYu/HiPhO)): evaluates physics reasoning on recent high-school physics/Olympiad problems, including multimodal input. The core idea is to use difficult Olympiad problems to reduce "commonsense guessing" and emphasize rigorous derivation and physics modeling.
- [Seeing Culture](https://arxiv.org/abs/2509.16517): Evaluates visual reasoning and grounding over culturally rich images. Core idea: require VLMs to select relevant visual evidence and reason about underrepresented cultural contexts, extending image understanding beyond object recognition or generic VQA.
- [GroundingSuite](https://openaccess.thecvf.com/content/ICCV2025/html/Hu_GroundingSuite_Measuring_Complex_Multi-Granular_Pixel_Grounding_ICCV_2025_paper.html) ([code](https://github.com/hustvl/GroundingSuite)): evaluates complex multi-granular pixel grounding. The core idea is to test localization at multiple levels of granularity, supporting visual QA, GUI grounding, and embodied perception pipelines.
- [MC-Bench](https://openaccess.thecvf.com/content/ICCV2025/html/Xu_MC-Bench_A_Benchmark_for_Multi-Context_Visual_Grounding_in_the_Era_ICCV_2025_paper.html) ([project page](https://xuyunqiu.github.io/MC-Bench)): evaluates multi-context visual grounding in the MLLM era. The core idea is to require models to localize and align evidence across multiple contexts, which is central for document, GUI, and embodied visual agents.
- [MMReason](https://openaccess.thecvf.com/content/ICCV2025/html/Yao_MMReason_An_Open-Ended_Multi-Modal_Multi-Step_Reasoning_Benchmark_for_MLLMs_Toward_ICCV_2025_paper.html): evaluates open-ended multi-modal multi-step reasoning. The core idea is to move beyond multiple-choice VQA by requiring longer free-form reasoning over visual evidence.
- [OCR Hinders RAG / OHR-Bench](https://openaccess.thecvf.com/content/ICCV2025/html/Zhang_OCR_Hinders_RAG_Evaluating_the_Cascading_Impact_of_OCR_on_ICCV_2025_paper.html) ([code](https://github.com/opendatalab/OHR-Bench)): evaluates how OCR errors cascade into retrieval-augmented generation. The core idea is to score downstream RAG reliability under imperfect document extraction rather than treating OCR quality as an isolated metric.
- [UNIDOC-BENCH](https://arxiv.org/abs/2510.03663) ([open-source code](https://github.com/SalesforceAIResearch/UniDoc-Bench)): evaluates document-centered multimodal RAG. The core idea is to compare text-only, image-only, fused, and joint-retrieval MM-RAG on text, table, and image evidence from real PDF pages.
- [M4DocBench](https://arxiv.org/abs/2510.21603): evaluates multimodal, multi-hop, multi-document, multi-turn deep research. The core idea is to introduce full evidence-chain annotations through Doc-Researcher and specifically test cross-document visual-semantic preservation, dynamic retrieval granularity, and iterative evidence accumulation.
- [DiagramEval](https://arxiv.org/abs/2510.25761): Evaluates LLM-generated diagrams through graph structure. Core idea: parse generated SVG-style diagrams into nodes and relations so diagram quality can be judged by structural faithfulness rather than only by generic image similarity.
- [ChartAB](https://arxiv.org/abs/2510.26781): evaluates chart grounding and dense alignment. The core idea is to require models to extract tabular data, locate visualization elements, identify chart attributes, and use structured JSON plus dual-chart alignment tasks to evaluate fine-grained chart perception.
- [TIR-Bench](https://arxiv.org/abs/2511.01833): evaluates agentic thinking-with-images. The core idea is to require models to create or call image-processing tools in the reasoning chain, covering 13 categories of dynamic visual tasks such as rotated OCR, gauge reading, mazes, spot-the-difference, and visual search.
- [MME-CC](https://arxiv.org/abs/2511.03146): evaluates multimodal cognitive capacity diagnostics. The core idea is to measure the boundary of comprehensive capability with more challenging multidimensional subitems; no stable official code repository is currently known.
- [DOCR-Inspector](https://arxiv.org/abs/2512.10619) ([open-source code](https://github.com/ZZZZZQT/DOCR-Inspector)): evaluates fine-grained error detection and quality assessment for real document-parsing results. The core idea is to use VLM-as-a-Judge to inspect document images and parsed outputs item by item, diagnose parsing failures with 28 error types and Chain-of-Checklist, and provide DOCRcaseBench.
- [BabyVision](https://arxiv.org/abs/2601.06521) ([open-source code](https://github.com/UniPat-AI/BabyVision)): evaluates core visual reasoning beyond language prompts. The core idea is to diagnose weaknesses in model vision with more "early vision/compositional concept" task types.
- [WorldVQA](https://arxiv.org/abs/2602.02537): evaluates atomic world knowledge in multimodal large language models. The core idea is to ask visually grounded questions whose answers depend on recognizing real-world entities, attributes, and relations, complementing OCR-heavy and chart-heavy image benchmarks.
- [AgentVista](https://arxiv.org/abs/2602.23166) ([open-source code](https://github.com/hkust-nlp/AgentVista)): evaluates extremely difficult multimodal agent tasks in real visual scenes. The core idea is to extend from the Agent-X citation chain to more open, more realistic visual tasks, emphasizing scene understanding, action selection, and multi-step feedback.
- [FinDocBench](https://arxiv.org/abs/2603.11044): evaluates table-of-contents structure, cross-page table stitching, and cell-level localization in financial PDFs. The core idea is to use expert-verified financial document categories and metrics such as TocEDS, cross-page TEDS, and C-IoU for audit-level document parsing.
- [MADQA](https://arxiv.org/abs/2603.12180): evaluates agentic document QA over multidocument collections. The core idea is to bind accuracy with retrieval/reading effort, diagnosing whether an agent navigates strategically or brute-forces traversal.
- [VTC-Bench](https://arxiv.org/abs/2603.15030): evaluates compositional visual-toolchain calls for agentic multimodal models. The core idea is to decompose visual tasks into composable tool-call sequences and evaluate whether models can select, order, and verify multiple visual tools instead of answering once.
- [VAREX](https://arxiv.org/abs/2603.15118) ([project page](https://udibarzi.github.io/varex-bench/); [dataset](https://huggingface.co/datasets/ibm-research/VAREX); [open-source code](https://github.com/udibarzi/varex-bench)): evaluates multimodal structured extraction from government forms. The core idea is to provide a unique schema and four input modalities for each document, distinguishing whether models can "read fields" from whether they can "output stably according to a schema."
- [MDPBench](https://arxiv.org/abs/2603.28130) ([open-source code](https://github.com/Yuliang-Liu/MultimodalOCR/tree/main/MDPBench)): evaluates multilingual document parsing in real scenarios. The core idea is to cover 17 languages, digital documents, and photographed documents, with emphasis on parsing degradation for non-Latin scripts and low-resource languages.
- [ParseBench](https://arxiv.org/abs/2604.08538) ([open-source code](https://github.com/run-llama/ParseBench)): evaluates semantic correctness, table/chart fidelity, and visual grounding in document parsing. The core idea is to decompose the parsing failures that most affect automated decisions in enterprise documents into evaluable dimensions.
- [HLE-VL](https://github.com/ByteDance-Seed/Seed2.0): A vision-language HLE-style evaluation reported in the Seed2.0 model card; no standalone public release has been confirmed. Core idea: track frontier vendors' use of high-difficulty visual knowledge and reasoning tasks even when the exact evaluation subset is model-card-only.
- [CC-OCR V2](https://arxiv.org/abs/2605.03903) ([open-source code](https://github.com/eioss/CC-OCR-V2)): evaluates OCR literacy in real enterprise document processing. The core idea is to cover five OCR-centric tracks: text recognition, document parsing, document grounding, key-information extraction, and document QA, with emphasis on hard and corner cases.

## 1.5.4 Agent Harness

- [VisProg](https://arxiv.org/abs/2211.11559) ([open-source code](https://github.com/allenai/visprog)): converts visual tasks into a reusable harness of "generate executable program + execute and fill results", reducing the risk of end-to-end hallucination by a single model.
- [Visual ChatGPT](https://arxiv.org/abs/2303.04671) ([open-source code](https://github.com/microsoft/visual-chatgpt)): a general visual-agent harness for collaboration among multiple vision tools. A typical loop is `plan -> call tools -> verify -> refine`.
- [ViperGPT](https://arxiv.org/abs/2303.08128) ([open-source code](https://github.com/cvlab-columbia/viper)): a visual-reasoning harness that uses Python execution as an intermediate layer, constraining model outputs to executable API compositions.
- [MM-REACT](https://arxiv.org/abs/2303.11381) ([open-source code](https://github.com/microsoft/MM-REACT)): a multimodal ReAct workflow that organizes visual perception, reasoning, and actions (tool calls) into reusable prompt control flow.
- [HuggingGPT](https://arxiv.org/abs/2303.17580) ([open-source code](https://github.com/microsoft/JARVIS)): a general agent framework that routes multimodal tasks to tools/models and orchestrates execution, including visual task routing and composition.
- [MDocAgent](https://arxiv.org/abs/2503.13964) ([open-source code](https://github.com/aiming-lab/MDocAgent)): a multimodal multi-agent RAG framework for document QA. It combines roles such as text agent, image agent, critical agent, and summary agent for cross-modal evidence integration.
- [ChartAgent](https://arxiv.org/abs/2507.06157) (open-source code: no stable public official repository currently known): an agentic workflow for chart QA. A common staged orchestration is `read chart/OCR -> tabularize/structure -> compute/verify -> answer`.
- [PyVision](https://arxiv.org/abs/2507.07998) ([project page](https://agent-x.space/pyvision/); [open-source code](https://github.com/agents-x-project/PyVision)): a dynamic tool harness for visual reasoning. It lets models generate, execute, and revise Python image-processing tools according to the task instead of relying on a fixed toolset.
- [VProChart](https://arxiv.org/abs/2507.17209) (open-source code: no stable public official repository currently known): a procedural method for chart reasoning, emphasizing modularizing chart understanding with computation/verification to reduce chart hallucination.
- [Doc-Researcher](https://arxiv.org/abs/2510.21603) (open-source code: no stable public official repository currently known): a multi-agent system for multimodal document deep research. It connects parsing, hierarchical retrieval, question decomposition, evidence accumulation, and cross-document synthesis into an iterative workflow.
- [DocAgent](https://aclanthology.org/2025.emnlp-main.893/) ([open-source code](https://github.com/lisun-ai/DocAgent)): an agentic framework for multimodal long-context document understanding. It emphasizes memory and reviewer mechanisms, unifying text, layout, charts, tables, and image evidence into a long-document reasoning chain.
- [ARIAL](https://arxiv.org/abs/2511.18192) (open-source code: no stable public official repository currently known): an agentic framework for Document VQA and answer localization. A planner orchestrates OCR, semantic retrieval, answer generation, and text-to-region alignment, outputting both answers and bounding-box evidence.
- [DocDancer](https://arxiv.org/abs/2601.05163) (open-source code: the paper says it is open source, but no stable public repository has been confirmed): models DocQA as a tool-driven information-seeking process, explicitly separating document exploration from answer synthesis, and trains open-ended document agents with synthetic trajectories.
- [OCR-Agent](https://arxiv.org/abs/2602.21053) ([open-source code](https://github.com/AIGeeksGroup/OCR-Agent)): a specialized agent for OCR/document understanding. It emphasizes an iterative `OCR -> structured parsing -> verification -> fill-back` workflow.
- [Doc-V*](https://arxiv.org/abs/2604.13731) (open-source code: no stable public official repository currently known): a coarse-to-fine interactive visual-reasoning harness for multi-page Document VQA. The core idea is to replace one-shot full-page reading with a loop of page-level retrieval, region-level zoom-in, evidence verification, and answer generation.
