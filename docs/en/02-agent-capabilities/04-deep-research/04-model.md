# 2.4.4 Model

- [Automating Research Synthesis with Domain-Specific Large Language Model Fine-Tuning](https://arxiv.org/abs/2404.08680): Fine-tunes an open LLM to automate systematic-review synthesis after screening, targeting evidence integration and narrative composition rather than prompt-only summarization.
- [OpenReviewer: A Specialized Large Language Model for Generating Critical Scientific Paper Reviews](https://arxiv.org/abs/2412.11948): Fine-tunes Llama-OpenReviewer-8B on 79,000 expert reviews and combines full-paper extraction with a structured pipeline for critical review generation.
- [Improving Scientific Document Retrieval with Concept Coverage-based Query Set Generation](https://arxiv.org/abs/2502.11181): Introduces CCQGen, which tracks uncovered academic concepts in earlier synthetic queries and conditions later query generation on those gaps, improving scientific-document retrieval fine-tuning.
- OpenAI Deep Research / `o3-deep-research` ([official report](https://openai.com/index/introducing-deep-research/); [model docs](https://platform.openai.com/docs/models/o3-deep-research)): A closed model line optimized with end-to-end reinforcement learning for web browsing, data analysis, and hard long-horizon research tasks.
- Perplexity Sonar Deep Research ([model docs](https://docs.perplexity.ai/docs/sonar/models/sonar-deep-research)): A deep-research API model endpoint for exhaustive source search, reasoning, and long-form cited report generation.
- [DeepResearcher](https://arxiv.org/abs/2504.03160) ([code](https://github.com/GAIR-NLP/DeepResearcher)): Trains deep-research agents end-to-end with reinforcement learning in real web-search environments.
- [HiPerRAG: High-Performance Retrieval Augmented Generation for Scientific Insights](https://arxiv.org/abs/2505.04846): Builds a high-throughput RAG stack for scientific insight discovery, emphasizing retrieval performance and evidence grounding when research questions require traversing large paper or data collections.
- [REMOR](https://arxiv.org/abs/2505.11718): Combines a reasoning LLM with multi-objective reinforcement learning for peer-review generation, balancing several review-quality dimensions instead of optimizing only verdict agreement.
- Kimi-Researcher ([official report](https://moonshotai.github.io/Kimi-Researcher/)): Reports a Kimi k-series internal model trained through end-to-end agentic reinforcement learning for multi-turn search, browsing, code tools, and deep-search benchmarks.
- [Scientific Paper Retrieval with LLM-Guided Semantic-Based Ranking](https://arxiv.org/abs/2505.21815): Uses LLM-guided semantic ranking and concept indexing for scientific paper retrieval.
- [Beyond path selection: Better LLMs for Scientific Information Extraction with MimicSFT and Relevance and Rule-induced(R2)GRPO](https://arxiv.org/abs/2505.22068): Improves scientific information extraction with MimicSFT and rule-induced GRPO.
- [WebDancer](https://arxiv.org/abs/2505.22648) ([code](https://github.com/Alibaba-NLP/DeepResearch/tree/main/WebAgent/WebDancer)): Trains autonomous information-seeking agency for multi-step search and reasoning.
- [TDCSA: LLM-Guided Top-Down Approach for Robust Citation Sentiment Analysis](https://doi.org/10.18653/v1/2025.findings-acl.335): Introduces TDCSA's top-down citation-sentiment architecture: dual LLMs generate citation-related quadruples, multi-view representations handle neutral citations, and a quad-feature-enhanced PLM performs classification; experiments report state-of-the-art performance and robustness when quadruple quality varies.
- [WebSailor](https://arxiv.org/abs/2507.02592): Trains an agent for difficult reasoning navigation with uncertainty-aware task synthesis and reinforcement tuning of challenging search trajectories.
- [WebWatcher](https://arxiv.org/abs/2508.05748) ([code](https://github.com/Alibaba-NLP/DeepResearch/tree/main/WebAgent/WebWatcher)): Trains multimodal deep-research agents with synthetic multimodal trajectories and reinforcement learning.
- [Beyond Ten Turns / Long-Horizon Agentic Search](https://arxiv.org/abs/2508.07976) ([OpenReview](https://openreview.net/forum?id=MfPDdPUGKi)): Extends end-to-end reinforcement learning for long-horizon agentic search, bridging web-search training and deep-research model optimization beyond a fixed ten-turn budget.
- [Atom-Searcher](https://arxiv.org/abs/2508.12800): Uses atomic-thought rewards and reasoning reward models to reinforce fine-grained deep-research search behavior.
- xAI Grok 4 Fast Search ([model card PDF](https://data.x.ai/2025-09-19-grok-4-fast-model-card.pdf)): Reports end-to-end tool-use reinforcement learning for web and X browsing, code execution, and deep-search evaluations.
- [CASPER: Concept-integrated Sparse Representation for Scientific Retrieval](https://arxiv.org/abs/2508.13394): Injects explicit scientific concepts into sparse retrieval representations so search can match papers by domain facets rather than surface terms alone.
- [Scalable scientific interest profiling using large language models](https://arxiv.org/abs/2508.15834): Uses LLMs to infer researcher-interest profiles from publications, turning paper histories into scalable expert and topic representations.
- [Open Data Synthesis For Deep Research](https://arxiv.org/abs/2509.00375): Introduces Open Data Synthesis For Deep Research, a model-side contribution for Deep Research.
- [SFR-DeepResearch](https://arxiv.org/abs/2509.06283): Continually reinforces a reasoning-optimized model for autonomous single-agent deep research with web and Python tools.
- [FLeW: Facet-Level and Adaptive Weighted Representation Learning of Scientific Documents](https://arxiv.org/abs/2509.07531): Learns scientific-document representations with facet-level weighting and citation-intent signals. Core idea: use citation intent and frequency to produce task-adaptive scientific embeddings rather than a single undifferentiated paper vector.
- [SciGPT](https://arxiv.org/abs/2509.08032): Adapts Qwen3 for scientific literature understanding through domain distillation, sparse MoE attention for long documents, and ontology-aware knowledge adaptation.
- [DeepDive](https://arxiv.org/abs/2509.10446): Trains deep-search agents with knowledge-graph question synthesis and end-to-end multi-turn reinforcement learning.
- [WebSailor / WebSailor-V2](https://arxiv.org/abs/2509.13305): Bridges open and proprietary deep-research agents with uncertainty-focused task synthesis, cold-start reinforcement fine-tuning, and scalable agentic RL.
- [Scaling Agents via Continual Pre-training](https://arxiv.org/abs/2509.13310): Introduces Agentic CPT and AgentFounder as a foundation-model training stage for deep-research agents.
- [Meow](https://arxiv.org/abs/2509.19370): Separate the outline writing of automatic academic surveys into the task of generating hierarchical outlines from paper metadata, and use two-stage SFT and RL to train the 8B model.
- [MARS: Co-evolving Dual-System Deep Research](https://arxiv.org/abs/2510.04935): Uses multi-agent reinforcement learning to co-optimize dual-system deep-research behavior.
- [Beyond Turn Limits](https://arxiv.org/abs/2510.08276): Trains deep-search agents with dynamic context windows to address failures caused by truncating long-horizon information-seeking trajectories at a fixed turn budget.
- [DeepPlanner](https://arxiv.org/abs/2510.12979): Uses advantage shaping to optimize planning capability for deep-research agents.
- [Tongyi DeepResearch](https://arxiv.org/abs/2510.24701) ([code](https://github.com/Alibaba-NLP/DeepResearch)): Reports an agentic LLM trained for long-horizon deep information seeking and end-to-end deep-research capability.
- [Thinker: Training LLMs in Hierarchical Thinking for Deep Search via Multi-Turn Interaction](https://arxiv.org/abs/2511.07943): Turns query decomposition, hierarchical reasoning, and evidence correction into multi-turn training targets, making search planning a learned behavior rather than only a prompt scaffold.
- [DR Tulu](https://arxiv.org/abs/2511.19399): Trains and releases an open deep-research model with rubric-evolving reinforcement learning for long-form open-ended research.
- [Step-DeepResearch Technical Report](https://arxiv.org/abs/2512.20491) ([code](https://github.com/stepfun-ai/StepDeepResearch)): Provides an end-to-end training route for open-ended deep research, including data, policy optimization, and checklist-style judging.
- [Improving Scientific Document Retrieval with Academic Concept Index](https://arxiv.org/abs/2601.00567): Improves scientific document retrieval with concept-indexed representations for research literature search.
- [O-Researcher](https://arxiv.org/abs/2601.03743): Builds an open-ended deep-research model through multi-agent distillation and agentic reinforcement learning.
- [Chaining the Evidence](https://arxiv.org/abs/2601.06021): Densifies reinforcement-learning supervision for deep-search agents with citation-aware rubric rewards.
- [OpenScholar](https://www.nature.com/articles/s41586-025-10072-4): Use large-scale open paper indexing and retrieval enhanced models to generate citation-backed responses; it differs from PaperQA2 in that it places more emphasis on open models, open corpora, and citation accuracy on cross-domain expert questions.
- [Turning Citation Networks Inside Out: Studying Science Using Content-Based Knowledge Graphs from LLM-Derived Taxonomies](https://arxiv.org/abs/2601.15062): Rather than mapping science through citations alone, this method uses an LLM-induced taxonomy to encode each paper as measure-data-question triplets and builds a content-based graph that surfaces a field's methodological backbone and rare bridging combinations.
- [OffSeeker: Online Reinforcement Learning Is Not All You Need for Deep Research Agents](https://arxiv.org/abs/2601.18467): Studies how search, report generation, trajectory data, and reinforcement-learning choices interact when training deep-research agents, questioning whether online RL alone is sufficient.
- [EchoReview](https://arxiv.org/abs/2602.00733): Uses citation echoes from later papers as weak supervision for automatic peer review, reducing reliance on scarce expert review labels.
- [IntentRL](https://arxiv.org/abs/2602.03468): Trains proactive intent-clarification behavior before expensive long-horizon deep research.
- [How to Train Your Deep Research Agent?](https://arxiv.org/abs/2602.19526): Studies prompt, reward, and policy-optimization choices for Search-R1-style deep-research training and introduces Search-R1++.
- [Ensembling approaches to citation function classification and important citation screening](https://doi.org/10.1007/s11192-025-05265-7): Systematically ensembles citation-context classifiers using three sources of base-model diversity, five diversity measures, two diversity re-ranking methods, voting and stacking, performance-aware weighting, and deeper hierarchical combinations. The best systems improve state of the art by more than 5 and 4 percentage points on 11-class and 6-class citation-function schemes and by 3 points on important-citation screening.
- [DeepResearch-9K / DeepResearch-R1](https://arxiv.org/abs/2603.01152): Releases a dataset and open RL training framework for deep-research agents.
- [KARL](https://arxiv.org/abs/2603.05218): Trains enterprise knowledge agents through synthetic data and iterative large-batch off-policy RL across search and report-generation regimes.
- [SciBERT-Based Interpretable Framework for Citation Influence Classification Using Sparse Rationale Extraction](https://doi.org/10.1109/access.2026.3688794): Combines SciBERT with a HardKuma-L0 selector to classify citation importance while exposing minimal token rationales; it reaches F1 0.95 on ACL-ARC and 0.92 on imbalanced SciCite, beats strong baselines significantly, and improves ERASER sufficiency and comprehensiveness over attention, LIME, and SHAP.
- [SynPlanResearch-R1](https://arxiv.org/abs/2603.07853) ([code](https://github.com/HansiZeng/syn-plan-research)): Trains tool exploration for deep research with synthetic executable plans.
- [OpenSeeker: Democratizing Frontier Search Agents by Fully Open-Sourcing Training Data](https://arxiv.org/abs/2603.15594): Fully opens training data for frontier-style search agents, supporting reproducible research on trajectory construction and reinforcement learning for deep research.
- [MiroThinker-1.7 & H1](https://arxiv.org/abs/2603.15726) ([code](https://github.com/MiroMindAI/MiroThinker)): Advances open-source research agents through verification, interaction scaling, and heavy-duty reasoning training.
- [Citation Intent Classification via Exponential Borda Fusion and SciBERT](https://doi.org/10.3390/a19080612): Exponentially weighted Borda fusion combines Gemma, LLaMA, and Mistral rankings to label UnarXive citation contexts, then supervises a five-way SciBERT classifier that reaches 0.83 macro-F1 across background, methodology, comparison, extension, and critique intents.
- [OpenResearcher](https://arxiv.org/abs/2603.20278) ([code](https://github.com/TIGER-AI-Lab/OpenResearcher)): Builds a fully open pipeline for long-horizon deep-research trajectory synthesis over an offline corpus and search/open/find primitives.
- [Integrating Table Representations into Large Language Models for Improved Scholarly Document Comprehension](https://doi.org/10.18653/v1/2024.sdp-1.28):The method performs intermediate task pretraining on table question answering, then adapts the model to tables in computer-science papers. The resulting table-aware models substantially improve scientific-literature understanding, including peer-review score prediction, and the code and models are public.
- [HGNet: Scalable Foundation Model for Automated Knowledge Graph Generation from Scientific Literature](https://arxiv.org/abs/2603.23136): HGNet combines orthogonal semantic decomposition and n-gram-aware attention for entity recognition with hierarchy-aware message passing, differentiable anti-cycle loss, and a continuous abstraction-field loss; it improves out-of-distribution NER by 8.08% and relation extraction by 5.99%, with larger zero-shot gains on SPHERE.
- [Research topic detection in scientific articles using a hybrid BERT integrated telescopic vector tree model with emperor penguin enhanced NSGA II optimization](https://doi.org/10.1038/s41598-025-21145-9): Adds a hybrid BERT-based model for detecting research topics in scientific articles.
- [ScilinkBERT](https://doi.org/10.1007/s11227-025-07838-y): Adapts a BERT-style language model to scientific texts with citation context for literature understanding.
- [Soft-Prompted Semantic Normalization for Unsupervised Analysis of the Scientific Literature](https://doi.org/10.3390/make8030063): Uses soft prompts to normalize scientific terminology without labeled supervision, supporting unsupervised analysis of heterogeneous literature.
- [Scientific Claim Recognition via Staged Fine-Tuning with LoRA](https://doi.org/10.3724/2096-7004.di.2025.0009): Scientific-claim recognition with staged LoRA fine-tuning is a broad scholarly document understanding model.
- [Mind DeepResearch / MindDR](https://arxiv.org/abs/2604.14518): Combines SFT cold start, Search-RL, Report-RL, and preference alignment for planning, deep search, and report-generation agents.
- [LiteResearcher](https://arxiv.org/abs/2604.17931): Builds a lite virtual world to scale agentic reinforcement learning for deep-research agents without unstable live-search dependence.
- [GAN-CITE: leveraging semi-supervised generative adversarial networks for citation function classification with limited data](https://doi.org/10.1007/s11192-025-05233-1): Combines a language model with a semi-supervised GAN so unlabeled citation contexts improve citation-function classification; experiments at 10%, 20%, and 30% labeled-data budgets, plus insufficient and imbalanced-label settings, show gains over supervised and semi-supervised baselines for digital-library citation categorization.
- [Tool-Augmented Multi-Turn Academic Paper Recommendation via Reinforcement Learning](https://doi.org/10.1109/bigcomp68355.2026.00031): Treats paper recommendation as a multi-turn tool-augmented agent task and uses reinforcement learning to improve how the recommender queries tools and adapts to user feedback.
- [DR-Venus](https://arxiv.org/abs/2604.19859): Trains an edge-scale 4B deep-research agent from open data and agentic training recipes.
- [Data Gatherer](https://doi.org/10.18653/v1/2025.sdp-1.10): Uses LLMs to extract dataset references from scientific literature, adding a research-information-extraction model case.
- [Learning study similarity to investigate heterogeneity in meta-analysis using LLMs and triplet loss](https://arxiv.org/abs/2605.29603): Uses LLM embeddings and triplet loss to learn study similarity for meta-analysis heterogeneity, linking semantic comparison with statistical synthesis.
- [HyBIRD: Hyperbolic Bridge Retrieval and Diagnosis for Methodology Inspiration Retrieval](https://arxiv.org/abs/2606.28336): HyBIRD keeps a dense methodology retriever fixed, adds lightweight hyperbolic bridge representations, and diagnoses which retrieved method blocks cover a proposal's needs, exposing evidence gaps instead of returning only a ranked paper list.
- [From citation intent to knowledge contribution: Classifying what cited papers actually contribute](https://arxiv.org/abs/2608.20697): Introduces the Knowledge Contribution Taxonomy, which labels cited work as Method, Resource Tool, Empirical Finding, or Background and distinguishes core from non-core contributions. A Dual-Path Fusion classifier reaches 85.5% accuracy; across 802,202 ACL citations, core contributions comprise 39.09%. Core-contribution counts identify award-winning papers better than traditional citation counts at every cutoff, while KCT labels predict dissemination better than citation-intent labels.
