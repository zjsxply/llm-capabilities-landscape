# 2.3.3 Bench

- [WebArena](https://arxiv.org/abs/2307.13854): Evaluates end-to-end web-task completion in a browser-native action space; core idea: self-hosted multi-site web environment, native browser actions, and automatic evaluation scripts. ([code](https://github.com/web-arena-x/webarena))
- [VisualWebArena](https://arxiv.org/abs/2401.13649): Evaluates a WebArena extension with visual web understanding; core idea: incorporate visual perception and interaction into the same browser-native runtime loop. ([code](https://github.com/web-arena-x/visualwebarena))
- [ST-WebAgentBench](https://arxiv.org/abs/2410.06703): Evaluates behavior and constraint following of safe and trustworthy web agents; core idea: provide a reproducible safety-evaluation template using the BrowserGym/WebArena paradigm. ([code](https://github.com/segev-shlomov/ST-WebAgentBench))
- [Unsafe LLM-Based Search](https://arxiv.org/abs/2502.04951): Evaluates safety risks in AI-powered search engines. Core idea: define threat models and risk types, then test production search systems on malicious or unsafe query conditions where retrieval and generation can quote harmful content or cite malicious sites.
- [BrowseComp](https://arxiv.org/abs/2504.12516): Evaluates information acquisition through "retrieval, reading, and synthesis" in the real internet environment; core idea: constrain information acquisition as an executable browsing and evidence-chain process rather than offline knowledge QA.
- [BrowseComp-ZH](https://arxiv.org/abs/2504.19314) ([code](https://github.com/PALIN2018/BrowseComp-ZH); [Leaderboard](https://huggingface.co/spaces/PALIN2018/BrowseComp-ZH); [Wizwand BrowseComp-ZH SOTA](https://www.wizwand.com/sota/deep-research-on-browsecomp-zh-score)): Evaluates difficult web browsing and multi-hop retrieval reasoning in the Chinese internet environment; core idea: explicitly benchmark platform fragmentation, cross-page retrieval, and information synthesis in the Chinese web ecosystem.
- [Seal-0 / SealQA](https://arxiv.org/abs/2506.01062): Evaluates search-augmented reasoning under harder answer-completion requirements. Core idea: raise the bar for retrieval plus reasoning by checking whether agents can gather sufficient evidence before producing the final answer.
- [WebChoreArena](https://arxiv.org/abs/2506.01952): Evaluates longer, more tedious web operations closer to "web labor"; core idea: systematize repetitive work and multi-step operational tasks on the web. ([code](https://github.com/WebChoreArena/WebChoreArena))
- [Search Arena](https://arxiv.org/abs/2506.05334) ([code](https://github.com/lmarena/search-arena)): Evaluates search-augmented LLM performance under real user preferences. Core idea: collect multi-turn search-augmented answers and human preference votes, then analyze relationships among citation quality, source credibility, search calls, and final-answer preference.
- [Mind2Web 2](https://arxiv.org/abs/2506.21506) ([code](https://github.com/OSU-NLP-Group/Mind2Web-2)): Evaluates agentic search with agent-as-a-judge. Core idea: use long-horizon real-time web search and information-synthesis tasks to test agents on dynamic webpages, evidence citation, and complex answer construction, with an agent judge assisting evaluation.
- [WebWalker](https://aclanthology.org/2025.acl-long.508/): Evaluates website traversal for LLMs. Core idea: require models or agents to move through a site's subpages and systematically extract useful information, filling the gap between shallow search-result reading and deep site navigation.
- [MMInA](https://aclanthology.org/2025.findings-acl.703/): Evaluates multihop multimodal internet agents. Core idea: use evolving real-world multimodal websites so agents must compose navigation and evidence gathering across pages rather than solve static multimodal QA.
- [WebDS](https://arxiv.org/abs/2508.01222) (dataset: [yamhm/WebDS](https://huggingface.co/datasets/yamhm/WebDS)): Evaluates web data-science tasks. Core idea: have agents navigate containerized websites, obtain data, process structured and unstructured information, and produce analysis reports, connecting web search, data extraction, and data-science workflows.
- [BrowseComp-Plus](https://arxiv.org/abs/2508.06600) ([code](https://github.com/texttron/BrowseComp-Plus)): Evaluates deep web retrieval and browsing reasoning over a fixed corpus; core idea: turn BrowseComp from black-box live search into a reproducible environment of about 100K human-verified documents, decoupling the effects of retrievers, LLM agents, and context engineering.
- [WideSearch](https://arxiv.org/abs/2508.07999): Evaluates search-heavy tasks of `broad retrieval -> structured table output`; core idea: constrain outputs to structured entries and use protocols such as `SR / Row-F1 / Item-F1` for comparable evaluation. ([code](https://github.com/ByteDance-Seed/WideSearch))
- [MM-BrowseComp](https://arxiv.org/abs/2508.13186) ([code](https://github.com/MMBrowseComp/MM-BrowseComp)): Evaluates retrieval and reasoning capability of multimodal web-browsing agents; core idea: include images and video content from question clues and web evidence in BrowseComp-style multi-hop browsing tasks, with checklists for fine-grained diagnosis.
- [FinSearchComp](https://arxiv.org/abs/2509.13160): Evaluates expert-level financial search and reasoning. Core idea: require agents to retrieve, compare, and synthesize financial information rather than answer from parametric knowledge, making it a domain-specific stress test for search-heavy professional work.
- [BrowserArena](https://arxiv.org/abs/2510.02418): Evaluates LLM agent navigation tasks on the real open web; core idea: use a live open-web arena to collect user-submitted tasks, run agent battles, and use step-level human feedback to diagnose failure modes such as captchas, popups, and direct navigation.
- [Needle in the Web](https://arxiv.org/abs/2512.16553) ([code](https://github.com/Tango-Whiskyman/Needle_in_the_Web)): Evaluates target-page retrieval on real webpages; core idea: convert vague exploratory queries into tasks that require finding a unique target page, testing retrieval capability under semantic ambiguity, multi-domain webpages, and source verification.
- [UIS-Digger](https://arxiv.org/abs/2603.08117): What it evaluates: addressing real-world unindexed information. Core idea: organize tasks around webpages, files, and deep entry points that search engines cannot easily retrieve directly, evaluating whether agents discover entry points, adjust queries, and track evidence sources.
- [LiveWeb-IE](https://arxiv.org/abs/2603.13773): What it evaluates: online web information extraction. Core idea: place webpage changes, real-time sources, and structured extraction targets into a live benchmark, complementing BrowseComp-style QA with tabular extraction and data freshness.
- [VisBrowse-Bench](https://arxiv.org/abs/2603.16289): What it evaluates: visual-native multimodal web search. Core idea: require agents to handle screenshots, image clues, and text pages simultaneously on real webpages, filling the need after MM-BrowseComp for dedicated evaluation of visual-native search trajectories.
- [WebForge](https://arxiv.org/abs/2604.10988): What it evaluates: realistic, reproducible, and scalable browser-agent benchmarks. Core idea: automatically generate controllable task environments with real webpage noise, mitigating the trilemma among live-website drift, manual construction cost, and static-sandbox distortion.
- [MERRIN](https://arxiv.org/abs/2604.13418): What it evaluates: multimodal evidence retrieval and multi-hop reasoning in noisy web environments. Core idea: include text, images, video, and audio together in search tasks.
- [StressWeb](https://arxiv.org/abs/2604.16385): What it evaluates: robustness of web agents under real interaction perturbations. Core idea: systematically inject dynamic DOM changes, loading delays, prompt variants, and UI noise into WebArena/VisualWebArena-style tasks to diagnose weak points in search and browsing agents.
