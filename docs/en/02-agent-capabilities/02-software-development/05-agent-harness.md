# 2.2.5 Agent Harness

- [XUAT-Copilot: Multi-Agent Collaborative System for Automated User Acceptance Testing with Large Language Model](https://arxiv.org/abs/2401.02705): Coordinates requirement analysis, test-case design, script generation, and result assessment agents so user-acceptance testing can be automated as a multi-role QA workflow.
- [LLM4PlC: Harnessing large Language Models for Verifiable Programming of PlCs in Industrial Control Systems](https://arxiv.org/abs/2401.05443): Couples PLC code generation with formal-verification feedback, turning industrial-control programming into a generate-check-repair loop rather than one-shot code synthesis.
- [PyTy: Repairing Static Type Errors in Python](https://arxiv.org/abs/2401.06619): Repairs Python static type errors with a program-analysis-guided workflow.
- [CodeAgent: Enhancing Code Generation with Tool-Integrated Agent Systems for Real-World Repo-level Coding Challenges](https://arxiv.org/abs/2401.07339): Gives repository-level coding agents explicit tools for code search, editing, execution, and feedback so fixes can be planned and validated inside real codebases.
- [FinSQL: Model-Agnostic LLMs-based Text-to-SQL Framework for Financial Analysis](https://arxiv.org/abs/2401.10506): Uses schema linking, SQL generation, and execution-oriented refinement for financial-analysis Text-to-SQL, making query synthesis a tool-mediated data-analysis workflow.
- [AssertLLM: Generating and Evaluating Hardware Verification Assertions from Design Specifications via Multi-LLMs](https://arxiv.org/abs/2402.00386): Orchestrates multiple LLM roles to derive hardware assertions from design specifications and evaluate them, adding a verification-centered harness for HDL development.
- [Executable Code Actions Elicit Better LLM Agents](https://arxiv.org/abs/2402.01030): Treats executable code snippets as agent actions, letting the model compute, inspect state, and call tools through generated code rather than plain natural-language actions.
- [CodePori: Large-Scale System for Autonomous Software Development Using Multi-Agent Technology](https://arxiv.org/abs/2402.01411): Describes a large-scale autonomous development system where multiple agents divide software tasks across planning, implementation, review, and integration.
- [CodeAgent: Autonomous Communicative Agents for Code Review](https://arxiv.org/abs/2402.02172): Models code review as a communicative agent workflow in which reviewer and author roles exchange critiques and revisions around candidate code changes.
- [You Can REST Now: Automated Specification Inference and Black-Box Testing of RESTful APIs with Large Language Models](https://arxiv.org/abs/2402.05102): Infers REST API specifications and drives black-box API tests, linking endpoint discovery, request generation, and response validation into an LLM-assisted testing loop.
- [CigaR: Cost-efficient Program Repair with LLMs](https://arxiv.org/abs/2402.06598): Reduces repair cost by controlling when LLM calls are made in the program-repair pipeline, combining patch generation with cheaper filtering and validation steps.

- [RepoAgent: An LLM-Powered Open-Source Framework for Repository-level Code Documentation Generation](https://arxiv.org/abs/2402.16667): Walks a repository to recover file, module, and dependency context, then generates documentation through a repository-level analysis and writing pipeline.
- [Debug like a Human: A Large Language Model Debugger via Verifying Runtime Execution Step by Step](https://arxiv.org/abs/2402.16906): Builds a debugging loop that inspects runtime execution step by step, compares expected and observed states, and uses that evidence to localize and repair faults.
- [Metasql: A Generate-Then-Rank Framework for Natural Language to SQL Translation](https://arxiv.org/abs/2402.17144): Generates multiple SQL candidates and ranks them with consistency and execution signals, adding a selection harness for Text-to-SQL rather than a single-pass generator.
- [SceneCraft: An LLM Agent for Synthesizing 3D Scene as Blender Code](https://arxiv.org/abs/2403.01248): Uses an LLM agent to translate scene intent into Blender code, making code execution the interface for creating and revising 3D scenes.
- [Prompting Large Language Models to Tackle the Full Software Development Lifecycle: A Case Study](https://arxiv.org/abs/2403.08604): Runs a case-study workflow across requirements, design, coding, testing, and maintenance prompts to examine how LLM assistance can cover the software lifecycle.
- [PET-SQL: A Prompt-enhanced Two-stage Text-to-SQL Framework with Cross-consistency](https://arxiv.org/abs/2403.09732): Splits Text-to-SQL into prompt-enhanced generation and cross-consistency checking, using agreement among candidate queries as a validation mechanism.
