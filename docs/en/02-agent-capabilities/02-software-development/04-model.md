# 2.2.4 Model

- [Qwen2.5-Coder Technical Report](https://arxiv.org/abs/2409.12186): Documents a code-specialized Qwen model family and large-scale code instruction tuning, providing an important open foundation for later agentic coding models.
- [RLEF](https://arxiv.org/abs/2410.02089): Grounds code LLMs in multi-step execution feedback with reinforcement learning, showing that models can learn to use compiler and test feedback rather than only resample independently.
- [Training Language Models on Synthetic Edit Sequences](https://arxiv.org/abs/2410.02749): Uses synthetic edit trajectories to train code LMs to write and revise programs edit-by-edit, filling a data gap between single-pass generation and software-agent patching.
- [Process Supervision-Guided Policy Optimization for Code Generation](https://arxiv.org/abs/2410.17621): Trains line-level process reward models and uses them in policy optimization so code RL receives denser feedback than final unit-test outcomes.
- [SFS: Smarter Code Space Search improves LLM Inference Scaling](https://openreview.net/forum?id=MCHuGOkExF): Uses smarter search over code candidates as an inference-scaling route for programming tasks, complementing training-time RL with test-time code-space exploration.
- [SWE-Gym](https://arxiv.org/abs/2412.21139): Provides executable training environments for real-world software-engineering agents and trains both agents and verifiers on SWE-style tasks.
- [SWE-Fixer](https://arxiv.org/abs/2501.05040): Trains open retrieval and code-editing models on 110K GitHub issues and patches for efficient repository-level issue resolution.
- [PRLCoder](https://arxiv.org/abs/2502.01715): Builds process-supervised code RL by automatically labeling statement-level mutations and refactorings with compilation and execution checks.
- [CTRL](https://arxiv.org/abs/2502.03492): Trains critic models through reinforcement learning so iterative critique-revision and generative reward modeling improve code generation.
- [SWE-RL](https://arxiv.org/abs/2502.18449): Applies reinforcement learning to open software-evolution tasks so coding agents learn from verifiable repository changes.
- [muCode](https://arxiv.org/abs/2502.20380): Trains generators and verifiers for multi-turn code generation from execution feedback using single-step rewards.
- [R2E-Gym](https://arxiv.org/abs/2504.07164): Uses SYNGEN to synthesize issue-like executable environments and hybrid verifiers for training and test-time scaling of open-weight SWE agents.
- [SWE-smith](https://arxiv.org/abs/2504.21798) ([open-source code](https://github.com/SWE-bench/SWE-smith)): Scales synthetic SWE training data and trains SWE-agent-LM-32B, complementing its environment-setup role with a direct model-training contribution.
- [AlphaVerus](https://proceedings.mlr.press/v267/aggarwal25a.html): Bootstraps formally verified code generation through self-improving translation and tree refinement, making proof-oriented feedback part of code-model improvement.
- [NextCoder](https://proceedings.mlr.press/v267/aggarwal25b.html): Adapts code language models to diverse code edits, strengthening the edit-distribution coverage needed by patching and coding-assistant agents.
- [Reasoning Through Execution](https://proceedings.mlr.press/v267/yu25f.html): Unifies process and outcome rewards for code generation by grounding intermediate reasoning and final success in execution feedback.
- [Synthesizing Software Engineering Data in a Test-Driven Manner](https://proceedings.mlr.press/v267/zhang25cn.html): Generates SWE training data around tests so synthetic examples carry executable validation signals rather than only natural-language issue descriptions.
- OpenAI Codex / `codex-1` ([official release](https://openai.com/index/introducing-codex/); [system-card addendum](https://openai.com/index/o3-o4-mini-codex-system-card-addendum/)): Reports an o3-derived software-engineering model optimized with reinforcement learning on real coding tasks, while the Codex CLI and cloud workflow remain harness-side artifacts.
- Claude 4 and Claude Sonnet 4.5 coding model cards ([Claude 4](https://www.anthropic.com/news/claude-4); [Sonnet 4.5](https://www.anthropic.com/news/claude-sonnet-4-5)): Provide closed-model evidence for long-running coding, repository repair, terminal work, and SWE-bench-style software-agent capability.
- [Training Language Models to Generate Quality Code with Program Analysis Feedback](https://arxiv.org/abs/2505.22704): Uses program-analysis findings and unit tests as scalable reinforcement signals for production-quality code generation.
- [Satori-SWE](https://arxiv.org/abs/2505.23604) ([code](https://github.com/satori-reasoning/Satori-SWE)): Combines evolutionary test-time scaling and RL-based self-evolution so smaller SWE models can improve repairs with fewer samples.
- [Co-Evolving LLM Coder and Unit Tester via Reinforcement Learning](https://arxiv.org/abs/2506.03136) ([code](https://github.com/Gen-Verse/CURE)): Co-trains coder and unit-tester capabilities from interaction outcomes, making the tester a supervision source for agentic coding.
- [Seed-Coder](https://arxiv.org/abs/2506.03524) ([code](https://github.com/ByteDance-Seed/Seed-Coder)): Builds an 8B code-model family with model-centric code-data filtering, SFT, preference optimization, and Long-CoT RL for code reasoning and software tasks.
- [SWE-Dev](https://arxiv.org/abs/2506.07636): Builds SWE agents through supervised data construction, reinforcement learning, and inference scaling.
- [CUDA-L1](https://arxiv.org/abs/2507.14111): Applies contrastive reinforcement learning to CUDA optimization, representing a specialized execution-feedback training line for performance-oriented coding agents.
- [D3: A Dataset for Training Code LMs to Act Diff-by-Diff](https://openreview.net/forum?id=sy71y74U80): Trains code models on diff-by-diff source evolution, matching the incremental edit actions used by repository agents.
- [Kimi K2](https://arxiv.org/abs/2507.20534): Reports an open MoE model with large-scale agentic data synthesis and joint reinforcement learning, including strong SWE-bench and agentic task results.
- Qwen3-Coder ([official report](https://qwenlm.github.io/blog/qwen3-coder/)): Trains a 480B-A35B MoE coding-agent model with code-heavy pretraining, execution-driven Code RL, and long-horizon Agent RL across large parallel coding environments.
- [Training Long-Context, Multi-Turn Software Engineering Agents with Reinforcement Learning](https://arxiv.org/abs/2508.03501): Applies rejection fine-tuning and DAPO-style RL to Qwen2.5-72B for long-context, stateful SWE environments.
- [ReCode](https://arxiv.org/abs/2508.05170): Trains reasoning-process reward models from synthesized reasoning variants and gates RL rewards with execution correctness to reduce reward hacking in code generation.
- [GLM-4.5](https://arxiv.org/abs/2508.06471): Presents open agentic, reasoning, and coding foundation models trained with multi-stage post-training and reinforcement learning for software-engineering and agent tasks.
- [Dream-Coder 7B](https://arxiv.org/abs/2509.01142): Introduces an open diffusion language model for code, adding a non-autoregressive code-model branch to the software-generation landscape.
- Grok Code Fast 1 ([model docs](https://docs.x.ai/docs/models/grok-code-fast-1)): A purpose-built agentic coding model with programming-rich pretraining, post-training on real PR and coding-task data, and terminal/file-editing tool behavior.
- GPT-5-Codex family ([GPT-5-Codex](https://openai.com/index/introducing-upgrades-to-codex/); [GPT-5.2-Codex](https://openai.com/index/introducing-gpt-5-2-codex/); [GPT-5.3-Codex](https://openai.com/index/introducing-gpt-5-3-codex/)): Tracks OpenAI's closed coding-agent model line across real engineering tasks, native compaction, long-running work, SWE-Bench Pro, Terminal-Bench, and vulnerability-oriented coding.
- [Maximum-Entropy Long-CoT Code Review Tuning](https://arxiv.org/abs/2509.21170): Fine-tunes LLMs with regulated long chain-of-thought to analyze multiple dimensions of code review.
- [Kimi-Dev](https://arxiv.org/abs/2509.23045): Turns Agentless-style localization, editing, and self-reflection training into transferable skill priors for SWE-Agent adaptation.
- [Devstral](https://arxiv.org/abs/2509.25193): Fine-tunes lightweight open models specifically for coding-agent applications with OpenHands-style software-engineering evaluation.
- [Afterburner](https://openreview.net/forum?id=At8OUlyTOu): Uses reinforcement learning to support self-improving code-efficiency optimization, extending code-agent training from correctness toward performance.
- [More Than Just Functional](https://openreview.net/forum?id=0Zri6HSYaK): Uses LLM critique to optimize generated code for efficiency as well as functional correctness, adding a model-side route for quality-aware coding agents.
- [KAT-Coder](https://arxiv.org/abs/2510.18779): Reports an agentic coding model trained with mid-training, SFT, reinforcement fine-tuning, and deployment adaptation for IDE-style software workflows.
- MiniMax M2 ([official report](https://www.minimax.io/news/minimax-m2); [interleaved-thinking note](https://www.minimax.io/news/why-is-interleaved-thinking-important-for-m2)): Frames a vendor model around agentic coding, tool use, and deep search, with interleaved thinking emphasized for reliable tool-mediated code work.
- [DeepSeek-V3.2](https://arxiv.org/abs/2512.02556): Adds large-scale agentic task synthesis and scalable reinforcement learning to a frontier open model, with coding and tool-use implications for software agents.
- [Training Versatile Coding Agents in Synthetic Environments](https://arxiv.org/abs/2512.12216): Synthesizes diverse coding-agent environments to train agents beyond fixed GitHub issue distributions.
- [Self-Play SWE-RL](https://arxiv.org/abs/2512.18552): Trains software agents through self-play with generated software-evolution challenges rather than only human GitHub issues.
- [SWE-RM](https://arxiv.org/abs/2512.21919): Trains execution-free reward models for SWE agents, targeting both test-time scaling and reinforcement-learning feedback.
- [daVinci-Dev](https://arxiv.org/abs/2601.18418): Studies agent-native mid-training with contextual and executable trajectories for software-engineering agents before post-training.
- [SERA](https://arxiv.org/abs/2601.20789): Generates soft-verified repository trajectories for low-cost SFT of open, repository-specialized coding agents.
- [SWE-Replay](https://arxiv.org/abs/2601.22129): Reuses and branches prior trajectories for low-cost test-time scaling of modern SWE agents.
- [Kimi K2.5](https://arxiv.org/abs/2602.02276): Extends the Kimi agentic line with visual-text joint training, reinforcement learning, and Agent Swarm for multimodal coding and agentic tasks.
- [SWE-Universe](https://arxiv.org/abs/2602.02361): Scales verifiable SWE environments to hundreds of thousands of tasks and demonstrates their use for agentic mid-training and reinforcement learning.
- [SWE-World](https://arxiv.org/abs/2602.03419) ([code](https://github.com/RUCAIBox/SWE-World)): Replaces Docker execution with learned surrogate feedback models, enabling Docker-free SFT, RL, and test-time scaling for SWE agents.
- [Hybrid-Gym](https://arxiv.org/abs/2602.16819): Trains coding agents to generalize across codebase exploration, localization, dependency search, testing, and repair skills.
- [CUDA Agent](https://arxiv.org/abs/2602.24286): Scales agentic reinforcement learning for high-performance CUDA kernel generation, extending coding-agent training to GPU optimization.
- [Qwen3-Coder-Next](https://arxiv.org/abs/2603.00729): Trains an efficient open coding-agent model with verifiable coding tasks, executable environments, mid-training, and reinforcement learning.
- [CodeScout](https://arxiv.org/abs/2603.17829): Trains code-search agents with reinforcement learning over standard Unix terminal actions, focusing on repository localization as a core SWE-agent skill.
- [KAT-Coder-V2](https://arxiv.org/abs/2603.27703): Uses a specialize-then-unify recipe across SWE, web coding, terminal, web search, and general coding domains, with on-policy distillation and large-scale sandboxed RL.
- Cursor Composer 2 ([technical report](https://cursor.com/blog/composer-2-technical-report); [PDF](https://cursor.com/resources/Composer2.pdf)): Reports an IDE-native agentic coding model trained with continued pretraining and large-scale RL in realistic Cursor sessions.
- Kimi K2.6 ([official report](https://www.kimi.com/blog/kimi-k2-6); [model card](https://huggingface.co/moonshotai/Kimi-K2.6)): Focuses the open Kimi line on long-horizon coding execution, Kimi Code Bench, Terminal-Bench, SWE-Bench Pro, and agent-swarm coding tasks.
- [From SWE-ZERO to SWE-HERO](https://arxiv.org/abs/2604.01496): Distills execution-free and execution-backed trajectories from frontier coding models to train open SWE agents for repository repair and multilingual transfer.
- [SWE-Shepherd](https://arxiv.org/abs/2604.10493): Trains process reward models over SWE-Bench trajectories to guide repository-level code agents with dense action-level feedback.
- [Step Rejection Fine-Tuning](https://arxiv.org/abs/2605.10674): Uses critic-scored trajectory steps to retain unresolved SWE trajectories as context while masking erroneous steps during distillation.
