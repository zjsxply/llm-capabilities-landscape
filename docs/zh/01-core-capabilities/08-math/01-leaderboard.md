# 1.8.1 Leaderboard

- [LiveBench Mathematics](https://livebench.ai/)（[开源代码](https://github.com/LiveBench/LiveBench)）：LiveBench 的数学分项榜会随时间更新题目，适合把数学能力放在通用模型综合榜中横向比较。
- [FrontierMath / Epoch Benchmarking Hub](https://epoch.ai/benchmarks/frontiermath)：Epoch AI 维护的专家级数学榜，含私有集、公开样题和 log viewer，尤其适合观察“可运行 Python + 形式化答案函数”式高难数学求解设置。
- [MathArena](https://matharena.ai/?view=problem)（[模型页](https://matharena.ai/models?page=1&q=)；[输出数据](https://huggingface.co/MathArena)）：当前最实用的持续竞赛数学榜之一，按 AIME、HMMT、USAMO、IMO、Project Euler、Apex 等任务发布问题级得分、原始输出和模型级聚合结果。
