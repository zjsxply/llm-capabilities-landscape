# 1.8.1 Leaderboard

- [MATH / Papers with Code Leaderboard](https://paperswithcode.com/sota/problem-solving-on-math)（[论文](https://arxiv.org/abs/2103.03874)，[开源代码](https://github.com/hendrycks/math)）：经典竞赛数学解题公开排名入口，适合与 MATH、MATH-500 风格的非形式化数学推理结果做历史对齐。
- [MathVista Leaderboard](https://mathvista.github.io/#leaderboard)（[开源代码](https://github.com/lupantech/MathVista)）：MathVista 官方视觉数学榜，覆盖 testmini 与私有 test 评测，适合追踪图表、几何、文字题和科学图示中的多模态数学推理。
- [OlympiadBench Leaderboard](https://github.com/OpenBMB/OlympiadBench#leaderboard)（[数据集](https://huggingface.co/datasets/Hothan/OlympiadBench)）：官方仓库中的双语多模态奥赛数学与物理榜，分别给出全量 benchmark 与 text-only 设置的结果。
- [MATH-Vision Leaderboards](https://mathllm.github.io/mathvision/)（[开源代码](https://github.com/mathllm/MATH-V)）：MATH-Vision 官方页面提供 main、open-source 和 wild 三类榜单，用真实竞赛来源的视觉数学题比较模型。
- [MathVerse Leaderboard](https://mathverse-cuhk.github.io/#leaderboard)（[开源代码](https://github.com/ZrrSkywalker/MathVerse)）：MathVerse 官方榜按 text-dominant、vision-dominant 和 vision-only 等变体比较多模态模型，用于区分图形理解与题干文本捷径。
- [Omni-MATH Results](https://omni-math.github.io/)（[开源代码](https://github.com/KbsdJames/Omni-MATH)）：Omni-MATH 官方页面按数学子领域和难度发布模型得分，并补充奥赛级数学的 rule-based evaluation 结果。
- [LiveBench Mathematics](https://livebench.ai/)（[开源代码](https://github.com/LiveBench/LiveBench)）：LiveBench 的数学分项榜会随时间更新题目，适合把数学能力放在通用模型综合榜中横向比较。
- [FrontierMath / Epoch Benchmarking Hub](https://epoch.ai/benchmarks/frontiermath)：Epoch AI 维护的专家级数学榜，含私有集、公开样题和 log viewer，尤其适合观察“可运行 Python + 形式化答案函数”式高难数学求解设置。
- [U-MATH Leaderboard](https://huggingface.co/spaces/toloka/u-math-leaderboard)：Toloka 公开的 U-MATH 与 mu-MATH 榜，比较大学水平文本和视觉数学求解能力，以及数学解答判分能力。
- [MathArena](https://matharena.ai/?view=problem)（[模型页](https://matharena.ai/models?page=1&q=)；[输出数据](https://huggingface.co/MathArena)）：当前最实用的持续竞赛数学榜之一，按 AIME、HMMT、USAMO、IMO、Project Euler、Apex 等任务发布问题级得分、原始输出和模型级聚合结果。
- [G-Pass@k / LiveMathBench Leaderboard](https://open-compass.github.io/GPassK/)（[数据集](https://huggingface.co/datasets/opencompass/LiveMathBench)）：OpenCompass 官方 G-Pass@k 榜，面向 LiveMathBench-Hard、MATH500、AIME 2024 和 AIME 2025 发布近时效、抗污染的数学评测结果。
- [MathCanvas-Bench Leaderboard](https://mathcanvas.github.io/#leaderboard)（[开源代码](https://github.com/wangjy020524/MathCanvas)）：MathCanvas 官方榜追踪多模态模型在“视觉与文本交错生成数学解法”任务上的表现。
- [IMO-Bench Leaderboard](https://imobench.github.io/#leaderboard)（[开源代码](https://github.com/google-deepmind/superhuman/tree/main/imobench)）：Google DeepMind 官方 IMO-ProofBench 榜，用于比较 IMO 任务族中的证明生成表现。
- [AMO-Bench Leaderboard](https://amo-bench.github.io/#Leaderboard)（[数据集](https://huggingface.co/datasets/GAIR/AMO-Bench)）：AMO-Bench 官方榜，面向至少 IMO 难度的原创高中数学竞赛题。
- [PolyMATH Leaderboard](https://polymathbenchmark.github.io/#leaderboard)：PolyMATH 官方多模态数学推理榜，覆盖图像重和文本重的数学题变体。
- [LiveMathematicianBench Leaderboard](https://livemathematicianbench.github.io/)（[数据集](https://huggingface.co/LiveMathematicianBench)）：一个持续更新的研究级数学榜，从近期 arXiv 论文定理中构造 theorem-comprehension 问题。
- [MathNet Results](https://mathnet.mit.edu/#results)（[数据集](https://huggingface.co/datasets/shaden/MathNet)，[开源代码](https://github.com/shadenx/MathNet)）：MathNet 官方页面发布 3 万题多语种奥赛语料上的解题、数学检索和检索增强解题结果。
