- [desktop-control](https://clawhub.ai/matagul/desktop-control)（通用桌面自动化：键鼠、截图、窗口管理与图像识别）
- [turix-cua](https://clawhub.ai/Tongyu-Yan/turix-cua)（桌面 GUI 自动化与工作流编排；调用其自有 CUA 模型）
