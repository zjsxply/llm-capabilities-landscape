# 3.1.4 Model

- [PIPer](https://arxiv.org/abs/2509.25455): Tunes a specialized environment-setup model with Bash-script supervised fine-tuning and reinforcement learning with verifiable rewards for repository setup tasks.
- [DockSmith](https://arxiv.org/abs/2602.00592) (open-source code: not released) trains a 30B-A3B Docker-building model on execution-grounded trajectories from a SWE-Factory-style pipeline, adding loop detection and cross-task success memory so environment-construction training improves Multi-Docker-Eval and transfers to SWE and terminal benchmarks.
