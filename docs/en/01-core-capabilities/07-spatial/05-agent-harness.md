# 1.7.5 Agent Harness

- [VLM-Grounder](https://arxiv.org/abs/2410.13860) ([code](https://github.com/InternRobotics/VLM-Grounder)) targets zero-shot 3D visual grounding; the core idea is to let a VLM agent call 3D scene tools and geometric verification to ground open-vocabulary targets to concrete 3D regions.
- [RoboRefer](https://arxiv.org/abs/2506.04308) ([code](https://github.com/Zhoues/RoboRefer)) targets robot spatial referring tasks, using explicit spatial grounding and an execution-feedback loop to improve the stability of solving complex spatial relations.
- [MapAgent](https://arxiv.org/abs/2509.05933) ([code](https://github.com/Hasebul/MapAgent)) is a hierarchical multi-agent harness for geospatial reasoning; the core idea is to decompose complex map questions into planning, map-tool calls, evidence extraction, and answer generation modules, reducing tool-selection confusion from similar geospatial APIs.
- [SpaceTools](https://arxiv.org/abs/2512.04069) ([code](https://github.com/spacetools/SpaceTools)): A tool-augmented harness for spatial reasoning; the core idea is to bring visual/robotics tools such as segmentation, pointing, depth, 3D boxes, and grasping into an interactive execution chain, using tool feedback to improve verifiability on complex spatial tasks.
- [VULCAN](https://arxiv.org/abs/2512.22351) (code: no stable public official repository found yet): A tool-augmented multi-agent framework for 3D object placement; the core idea is to translate language instructions into verifiable 3D operations through MCP-style APIs, 3D scene tools, Planner/Executor/Evaluator collaboration, and feedback loops.
- [Think3D](https://arxiv.org/abs/2601.13029) ([code](https://github.com/zhangzaibin/spagent)) is an active-exploration harness for 3D spatial reasoning; the core idea is to let a VLM agent call 3D operation tools to form an interactive spatial chain-of-thought and use tool feedback to improve multi-view and video spatial reasoning.
- [Spatial-Agent](https://arxiv.org/abs/2601.16965) (code: no stable public official repository found yet) targets the GeoFlow workflow for geospatial QA; the core idea is to parse natural language into executable spatial transformation graphs, then suppress spatial hallucinations through computation and verification loops.
- [Think, Act, Build](https://arxiv.org/abs/2604.00528) (code: no stable public official repository found yet): An agentic framework for zero-shot 3D visual grounding; the core idea is to alternate thinking, 3D actions, and scene building, using tool feedback to gradually converge on target localization.
- [MAG-3D](https://arxiv.org/abs/2604.09167) (code: no stable public official repository found yet): Multi-agent grounded reasoning for 3D understanding; the core idea is to split scene understanding, spatial-relation judgment, and result verification into collaborative roles to improve verifiability in complex 3D reasoning.
- [ViSRA](https://arxiv.org/abs/2605.10106) (code: not confirmed public): A training-free video-based spatial reasoning agent; the core idea is to route MLLM reasoning through explicit spatial expert outputs, making video spatial inference modular and transferable without post-training on a specific spatial benchmark.
