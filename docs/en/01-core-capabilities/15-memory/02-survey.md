# 1.15.2 Survey

- [Federated Unlearning: A Survey on Methods, Design Guidelines, and Evaluation Metrics](https://arxiv.org/abs/2401.05146): Organizes federated unlearning methods, deletion guarantees, evaluation metrics, and client-level privacy constraints for removing remembered data from distributed models.
- [Attractor Memory for Long-Term Time Series Forecasting: A Chaos Perspective](https://arxiv.org/abs/2402.11463): Frames long-term forecasting memory through attractor dynamics, connecting chaotic temporal structure with mechanisms that preserve recurrent state over long horizons.
- [Machine Unlearning: Taxonomy, Metrics, Applications, Challenges, and Prospects](https://arxiv.org/abs/2403.08254): Maps machine-unlearning settings, metrics, and applications for erasing learned data influence, clarifying the removal side of model memory.
- [A Survey on the Memory Mechanism of Large Language Model based Agents](https://arxiv.org/abs/2404.13501): Reviews memory types, storage, retrieval, updating, and evaluation for LLM agents.
- [Recent Advances of Foundation Language Models-based Continual Learning: A Survey](https://arxiv.org/abs/2405.18653): Reviews continual-learning techniques for foundation language models, including rehearsal, parameter isolation, regularization, and evaluation of retention versus forgetting.
- [Memorization in Deep Learning: A Survey](https://arxiv.org/abs/2406.03880): Reviews how deep networks memorize data, how memorization is measured, and how it affects generalization, privacy leakage, and mitigation strategies.
- [Undesirable Memorization in Large Language Models: A Survey](https://arxiv.org/abs/2410.02650): Surveys harmful LLM memorization, covering training-data extraction, privacy leakage, detection protocols, and mitigation during training and deployment.
- [SoK: On Finding Common Ground in Loss Landscapes Using Deep Model Merging Techniques](https://arxiv.org/abs/2410.12927): Systematizes model merging through loss-landscape common ground, giving the memory page a boundary case for knowledge retention and fusion across models.
- [Human-inspired Perspectives: A Survey on AI Long-term Memory](https://arxiv.org/abs/2411.00489): Uses human-memory concepts to classify AI long-term memory around encoding, consolidation, retrieval, forgetting, and personalization.
- [Unleashing the Power of Continual Learning on Non-Centralized Devices: A Survey](https://arxiv.org/abs/2412.13840): Surveys continual learning on non-centralized devices, emphasizing privacy-preserving updates, communication constraints, and retention under distributed data drift.
- [A Comprehensive Analysis of Memorization in Large Language Models](https://doi.org/10.18653/v1/2024.inlg-main.45): Analyzes LLM memorization sources, measurement protocols, data-leakage risks, and mitigation strategies across training and generation.
- [A survey on memory-efficient transformer-based model training in AI for science](https://arxiv.org/abs/2501.11847): Surveys activation, parameter, and optimizer-memory reduction techniques for Transformer training in AI-for-science workloads, marking a systems-memory boundary rather than agent recall.
- [A Survey of Personalization: From RAG to Agent](https://arxiv.org/abs/2504.10147): Surveys personalization methods from retrieval augmentation toward agent memory and adaptive behavior.
- [From Human Memory to AI Memory: A Survey on Memory Mechanisms in the Era of LLMs](https://arxiv.org/abs/2504.15965): Connects episodic, semantic, procedural, and personalized AI memory with human-memory concepts.
- [PersonalAI: A Systematic Comparison of Knowledge Graph Storage and Retrieval Approaches for Personalized LLM Agents](https://arxiv.org/abs/2506.17001): Compares knowledge-graph storage and retrieval designs for personalized LLM agents, covering schemas, update operations, and personalized QA trade-offs.
- [Modern Methods in Associative Memory](https://arxiv.org/abs/2507.06211): Surveys modern associative-memory methods, giving model-side background for key-value recall, Hopfield-style retrieval, and dense memory mechanisms.
- [Memory-Augmented Transformers](https://arxiv.org/abs/2508.10824): Reviews model-side memory mechanisms for Transformers, connecting neuroscience principles with context retention, reasoning, knowledge integration, and continual adaptation.
- [On Memory: A comparison of memory mechanisms in world models](https://arxiv.org/abs/2512.06983): Compares memory mechanisms in world models, giving the memory page a model-side map beyond conversational memory stores.
- [Towards large language models with human-like episodic memory.](https://doi.org/10.1016/j.tics.2025.06.016): Connects LLM memory design with human episodic-memory concepts, giving the memory page a cognitive reference point.
- [Analysis of the Content of ChatGPT's Memory: Types of Information, Security Implications, and User Perception](https://doi.org/10.1109/mipro65660.2025.11131839): Empirically analyzes ChatGPT memory content, information types, security implications, and user perception.
- [Graph-based Agent Memory: Taxonomy, Techniques, and Applications](https://arxiv.org/abs/2602.05665): Surveys graph construction, retrieval, temporal updates, and reasoning over agent memory.
- [Anatomy of Agentic Memory: Taxonomy and Empirical Analysis of Evaluation and System Limitations](https://arxiv.org/abs/2602.19320): Analyzes memory evaluation gaps and system limitations through an agentic taxonomy.
- [Toward a Theory of Hierarchical Memory for Language Agents](https://arxiv.org/abs/2603.21564): Formalizes hierarchical agent memory as extraction, grouping, compression, and traversal under token budgets. Core idea: provide shared abstractions for comparing memory designs beyond ad hoc implementations.
- [From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms](https://arxiv.org/abs/2605.06716): Tracks memory from static storage toward reusable experience and adaptation.
- [Unsupervised Continual Learning: A Review of Challenges, Techniques, and Evaluation Metrics](https://doi.org/10.1109/access.2026.3679348): Reviews unsupervised continual-learning challenges, representation forgetting, replay or regularization techniques, and metrics for streaming unlabeled adaptation.
- [Users' Expectations and Practices with Agent Memory](https://doi.org/10.1145/3706599.3720158): Studies user expectations and practices around agent memory, grounding memory-system design in real use.
- [From Storage to Interpretation: User Perceptions, Practices, and Challenges with Long-term Memory in Agents](https://doi.org/10.1145/3765766.3765843): Analyzes user perceptions and challenges for long-term agent memory, from storage to interpretation.
- [Conversational Agents: From RAG to LTM](https://doi.org/10.1145/3767695.3769671): Reviews conversational agents from retrieval-augmented generation toward long-term memory.
