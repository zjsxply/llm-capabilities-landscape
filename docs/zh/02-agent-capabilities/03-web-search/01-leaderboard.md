# 2.3.1 Leaderboard

- [BrowseComp Benchmark Leaderboard](https://llm-stats.com/benchmarks/browsecomp)：第三方持续汇总 BrowseComp 分数，适合追踪 live web search 能力的公开报告结果；不是 OpenAI 官方提交榜，引用时应把它视作聚合榜单。
- [BrowseComp-ZH Leaderboard](https://huggingface.co/spaces/PALIN2018/BrowseComp-ZH)：BrowseComp-ZH 官方 Hugging Face Space；适合比较中文网页搜索、多跳检索和信息整合 agent。
- [BrowseComp-Plus Leaderboard](https://huggingface.co/spaces/Tevatron/BrowseComp-Plus)：BrowseComp-Plus 官方 Hugging Face Space；适合在固定文档语料上比较检索器、浏览 agent 和上下文工程，而不受 live web 漂移影响。
- [Search Arena](https://github.com/lmarena/search-arena)：搜索增强 LLM 偏好数据与分析入口；适合观察 search augmentation、引用、来源可信度和用户偏好之间的关系。
- [Wizwand BrowseComp-ZH SOTA](https://www.wizwand.com/sota/deep-research-on-browsecomp-zh-score)：第三方 BrowseComp-ZH SOTA 聚合页；适合补充查找 BrowseMaster、InfoSeeker、ReSum 等网页搜索 agent 的公开成绩线索。
- [X-WebArena Leaderboard](https://docs.google.com/spreadsheets/d/1M801lEpBbKSNwP-vDBkC_pF7LdyGU1f_ufZb_NWNBZQ/edit?usp=sharing)：WebArena 与 VisualWebArena 项目页共同链接的官方 WebArena 系列榜单；适合比较自托管网页环境和视觉网页环境中的 browser agent。
- [STaRK Leaderboard](https://huggingface.co/spaces/snap-stanford/stark-leaderboard)：STaRK 官方 Hugging Face 榜单；适合比较文本与关系知识库上的检索模型和 LLM 检索器。
- [BRIGHT Leaderboard](https://brightbenchmark.github.io/)：BRIGHT 官方项目页包含 reasoning-intensive retrieval 榜单；适合追踪真实高难查询任务上的检索器表现。
- [Meta CRAG KDD Cup Leaderboards](https://www.aicrowd.com/challenges/meta-comprehensive-rag-benchmark-kdd-cup-2024/leaderboards)：CRAG KDD Cup 挑战赛的官方 AIcrowd 榜单入口；适合查找 retrieval-augmented generation 的分任务比赛结果。
- [MIRAGE Leaderboard](https://mirage-bench.github.io/)：MIRAGE 官方项目页包含 arena 风格榜单；适合按检索池和上下文鲁棒性指标比较 metric-intensive RAG 系统。
- [T2-RAGBench Leaderboard](https://t2ragbench.demo.hcds.uni-hamburg.de/)：T2-RAGBench 官方 demo 与榜单；适合比较系统在文本与表格证据上的 RAG 表现。
- [Mind2Web 2 Leaderboard](https://osu-nlp-group.github.io/Mind2Web-2/)：Mind2Web 2 官方项目页和榜单；适合追踪长程实时网页搜索与信息综合 agent。
- [WideSearch Leaderboard](https://widesearch-seed.github.io/)：WideSearch 官方项目页包含榜单式结果；适合比较宽域检索与结构化表格输出任务。
