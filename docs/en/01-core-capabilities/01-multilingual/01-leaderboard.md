# 1.1.1 Leaderboard

- [Evalita-LLM Leaderboard](https://huggingface.co/spaces/evalitahf/evalita_llm_leaderboard) ([paper](https://aclanthology.org/2025.clicit-1.61/)): A public benchmark and leaderboard for Italian LLM evaluation. Core idea: use ten native Italian tasks, multiple prompts, and zero-shot/few-shot settings so Italian capability is not inferred from translated English tests alone.
- [compar:IA](https://arxiv.org/abs/2602.06669): A French-government LLM arena for blind pairwise comparison on French-language prompts. Core idea: collect real user prompts and preference judgments through an open public-service platform so French alignment and evaluation data are not inferred from English-only arenas.
- [CLARIN-PT-LDB](https://arxiv.org/abs/2603.12872): A public leaderboard and benchmark suite for European Portuguese. Core idea: evaluate language, culture, and civility in PT-PT rather than inferring performance from English-translated tests.
- [MTEB Leaderboard](https://huggingface.co/spaces/mteb/leaderboard): a public leaderboard for multilingual text embedding and retrieval capability. Its value is providing a reusable evaluation entry point for embedding/RAG prerequisites, which can connect to multilingual RAG and retrieval tasks such as MIRAGE-Bench and AfriMTEB.
- [TyDi QA Leaderboard](https://github.com/google-research-datasets/tydiqa/blob/master/leaderboard.md): the official public result list for TyDi QA. Its value is tracking multilingual open-domain QA systems on typologically diverse, non-translation question-answer data.
- [Open Ko-LLM Leaderboard Results](https://huggingface.co/datasets/open-ko-llm-leaderboard/results): public Korean LLM benchmark results for Ko-H5 tasks. Its value is comparing Korean-language model behavior with private and public Korean evaluation sets rather than translated English-only tasks.
- [Open Arabic LLM Leaderboard](https://huggingface.co/spaces/OALL/Open-Arabic-LLM-Leaderboard): a public Arabic LLM leaderboard. Its value is collecting Arabic-centered model results around regional language understanding benchmarks such as ArabicMMLU.
- [QIMMA Leaderboard](https://huggingface.co/spaces/qimma/leaderboard): the public leaderboard for the QIMMA Arabic evaluation suite. Its value is combining quality-first Arabic benchmark curation with reproducible ranking infrastructure.
- [WMT24 General MT Shared Task](https://www2.statmt.org/wmt24/translation-task.html): the official WMT24 challenge page for general machine translation. Its value is providing ranked shared-task submissions and reproducible task details for multilingual machine translation.
