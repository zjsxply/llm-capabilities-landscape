# 1.7.4 Model

- [3D-LLM](https://arxiv.org/abs/2307.12981): An early 3D-language architecture that connects 3D scene representations with LLMs for object, relation, and spatial-context reasoning.
- [SpatialVLM](https://arxiv.org/abs/2401.12168): A VLM training method that injects spatial reasoning through spatial data, supervision, and model adaptation.
- [SpatialRGPT](https://arxiv.org/abs/2406.01584): A grounded spatial-reasoning method that ties language answers to region-level visual grounding and explicit spatial relations.
- [3UR-LLM: An End-to-End Multimodal Large Language Model for 3D Scene Understanding](https://arxiv.org/abs/2501.07819): Connects 3D scene representations to a multimodal LLM for end-to-end 3D scene understanding.
- [3D-MoE: A Mixture-of-Experts Multi-modal LLM for 3D Vision and Pose Diffusion via Rectified Flow](https://arxiv.org/abs/2501.16698): Uses a mixture-of-experts multimodal LLM for 3D vision and pose diffusion.
- [ReasonGrounder: LVLM-Guided Hierarchical Feature Splatting for Open-Vocabulary 3D Visual Grounding and Reasoning](https://arxiv.org/abs/2503.23297): Grounds open-vocabulary 3D visual reasoning through LVLM-guided hierarchical feature splatting.
- [SpatialReasoner](https://arxiv.org/abs/2504.20024): A 3D spatial-reasoning method that trains or structures models to reason explicitly over 3D spatial relations.
- [CAD-Llama: Leveraging Large Language Models for Computer-Aided Design Parametric 3D Model Generation](https://arxiv.org/abs/2505.04481): Uses LLMs to generate parametric CAD models, connecting natural language with structured 3D design.
- [Video World Models with Long-term Spatial Memory](https://arxiv.org/abs/2506.05284): Introduces Video World Models with Long-term Spatial Memory, a model-side contribution for Spatial.
- [Fine-Grained Preference Optimization for Spatial Reasoning](https://arxiv.org/abs/2506.21656): Uses fine-grained spatial preferences to improve VLM judgments of relations, positions, and 3D layouts.
- [Point3R: Streaming 3D Reconstruction with Explicit Spatial Pointer Memory](https://arxiv.org/abs/2507.02863): Adds explicit spatial pointer memory for streaming 3D reconstruction, relevant to persistent spatial representation.
- [Scene-LLM](https://doi.org/10.1109/WACV61041.2025.00220): Introduces Extending Language Model for 3D Visual Reasoning, a model-side contribution for Spatial.
- [3ViewSense](https://arxiv.org/abs/2603.07751): Uses orthographic-view grounding and a simulate-and-reason mechanism to improve VLM mental rotation, reconstruction, and view-consistent spatial reasoning.
- [SpatialStack](https://arxiv.org/abs/2603.27437): Introduces Layered Geometry-Language Fusion for 3D VLM Spatial Reasoning, a model-side contribution for Spatial.
- [MolmoPoint](https://arxiv.org/abs/2603.28069): Adds pointing and grounding tokens so VLMs can output visual locations more accurately as a model-native behavior.
- [Token Warping](https://arxiv.org/abs/2604.02870): Warps visual tokens to support viewpoint-shift spatial reasoning without observing every nearby view.
- [SpatialEvo](https://arxiv.org/abs/2604.14144): Introduces Self-Evolving Spatial Intelligence via Deterministic Geometric Environments, a model-side contribution for Spatial.
- [A dual‐dimension collaborative enhancement framework to boost language model spatial semantic understanding](https://doi.org/10.1111/nyas.15388): Improves language-model spatial semantic understanding with a dual-dimension collaborative enhancement framework.
