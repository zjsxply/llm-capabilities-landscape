- [RAG-Driver: Generalisable Driving Explanations with Retrieval-Augmented In-Context Learning in Multi-Modal Large Language Model](https://arxiv.org/abs/2402.10828): Grounds multimodal driving explanations with retrieved examples and in-context evidence for more transferable scene reasoning.
