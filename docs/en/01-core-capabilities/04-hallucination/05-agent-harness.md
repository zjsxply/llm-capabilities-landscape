# 1.4.5 Agent Harness

- [RARR](https://arxiv.org/abs/2210.08726) ([open-source code](https://github.com/anthonywchen/RARR)): retrieval-backed hallucination repair. A typical loop is `claim decomposition -> evidence retrieval -> evidence filtering/alignment -> revision`.
- [SelfCheckGPT](https://arxiv.org/abs/2303.08896) ([open-source code](https://github.com/potsawee/selfcheckgpt)): detects suspicious claims through self-consistency and variant sampling. The core idea is to treat "inconsistency" as a hallucination-risk signal.
- [FacTool](https://arxiv.org/abs/2307.13528) ([open-source code](https://github.com/GAIR-NLP/factool)): a tool-augmented factuality detection framework. The core idea is to decompose generated content in tasks such as QA, code, math, and scientific literature review into verifiable units, then call external tools and evidence to judge factual errors.
- [Chain-of-Verification](https://arxiv.org/abs/2309.11495): decomposes complex answers into subclaims to verify one by one. The core idea is to make the verification control flow explicit, reducing the pattern where an answer looks plausible overall but fabricates details.
- [DRAGIN: Dynamic Retrieval Augmented Generation based on the Real-time Information Needs of Large Language Models](https://arxiv.org/abs/2403.10081): a dynamic RAG controller that decides both when to retrieve and how to form retrieval queries from the model's real-time information needs across the whole generation context.
- [SAFE](https://arxiv.org/abs/2403.18802) ([open-source code](https://github.com/google-deepmind/long-form-factuality)): a search-augmented factuality evaluation harness. The core idea is to split long answers into atomic claims and then judge whether each is supported by retrieved evidence.
- [Visual Fact Checker: Enabling High-Fidelity Detailed Caption Generation](https://arxiv.org/abs/2404.19752): a training-free captioning pipeline that generates candidate captions, uses LLM-driven object-detection and VQA checks to verify them, then synthesizes a final detailed caption with fewer visual hallucinations.
- [Argumentative Large Language Models for Explainable and Contestable Claim Verification](https://arxiv.org/abs/2405.02079): augments LLM claim verification with argumentation frameworks and formal reasoning so decisions can be explained, challenged, and corrected instead of returned as opaque labels.
- [FlashRAG: A Modular Toolkit for Efficient Retrieval-Augmented Generation Research](https://arxiv.org/abs/2405.13576): a lightweight, modular RAG research toolkit for reproducing and comparing retrievers, generators, and evaluation components without committing to heavy application frameworks.
- [RefChecker](https://arxiv.org/abs/2405.14486) ([open-source code](https://github.com/amazon-science/RefChecker)): a reference-based fine-grained hallucination checker. The core idea is to split answers into verifiable fragments and align them with reference evidence, producing span/claim-level hallucination judgments.
- [GNN-RAG: Graph Neural Retrieval for Large Language Model Reasoning](https://arxiv.org/abs/2405.20139): combines a GNN retriever over dense knowledge-graph subgraphs with LLM generation, retrieving candidate answer nodes and shortest-path evidence before answering KGQA questions.
- [CheckEmbed: Effective Verification of LLM Solutions to Open-Ended Tasks](https://arxiv.org/abs/2406.02524): verifies open-ended LLM answers by reducing each answer to a single modern embedding vector and comparing whole-answer semantic equivalence more cheaply than token- or sentence-level scorers.
- [Ragnarök: A Reusable RAG Framework and Baselines for TREC 2024 Retrieval-Augmented Generation Track](https://arxiv.org/abs/2406.16828): provides the TREC RAG Track framework for building, testing, visualizing, and evaluating attributed RAG search systems rather than only submitting ranked document lists.
- [Speculative RAG: Enhancing Retrieval Augmented Generation through Drafting](https://arxiv.org/abs/2407.08223): has a smaller specialist LM draft multiple answers from different retrieved-document subsets while a larger generalist LM verifies them, reducing long-context position bias and improving RAG efficiency.
- [Interpreting and Mitigating Hallucination in MLLMs through Multi-agent Debate](https://arxiv.org/abs/2407.20505): uses self-reflection and multi-agent debate to diagnose and reduce multimodal hallucination. Core idea: make agents challenge visual claims, localize hallucinated regions, and explain the source of errors instead of only returning a final factuality score.
- [RAGChecker](https://arxiv.org/abs/2408.08067) ([open-source code](https://github.com/amazon-science/RAGChecker)): a diagnostic evaluation framework for RAG systems. The core idea is to locate factuality errors in retrieval and generation through claim-level support, omissions, and noise.
- [HyPA-RAG: A Hybrid Parameter Adaptive Retrieval-Augmented Generation System for AI Legal and Policy Applications](https://arxiv.org/abs/2409.09046): adapts RAG parameters for legal-policy questions with a query-complexity classifier, hybrid dense/sparse/KG retrieval, and task-specific fidelity metrics on NYC Local Law 144.
- [Astute RAG: Overcoming Imperfect Retrieval Augmentation and Knowledge Conflicts for Large Language Models](https://arxiv.org/abs/2410.07176): makes RAG robust to irrelevant or conflicting retrieval by eliciting internal model knowledge, consolidating it with external evidence under source awareness, and choosing answers by reliability.
- [LEGO-GraphRAG: Modularizing Graph-based Retrieval-Augmented Generation for Design Space Exploration](https://arxiv.org/abs/2411.05844): decomposes GraphRAG into reusable workflow modules, classifies existing design choices, and supports constructing new GraphRAG instances for cost-quality exploration.
- [GeAR: Graph-enhanced Agent for Retrieval-augmented Generation](https://arxiv.org/abs/2412.18431): augments conventional retrievers with graph expansion and inserts the graph retrieval into a multi-step agent framework for multi-hop RAG question answering.
- [A Self-Reflective Retrieval Augmented Generation System to Eliminate Hallucination in LLM Generation](https://doi.org/10.5121/csit.2024.141402): uses LangChain workflow nodes around ChatGPT generation to add self-reflective checks inside a RAG pipeline before returning the final answer.
- [Think More, Hallucinate Less: Mitigating Hallucinations via Dual Process of Fast and Slow Thinking](https://arxiv.org/abs/2501.01306): A tree-search harness for reducing hallucination. Core idea: route generation through explicit slow-thinking search such as MCTS so candidate answers can be explored and checked before finalizing factual responses.
- [SelfCheckAgent](https://arxiv.org/abs/2502.01812): a multi-agent, zero-resource hallucination detection framework. The core idea is to combine symbolic, specialized-detection, and contextual-consistency agents and use multidimensional consistency signals to judge whether generated content is reliable.
- [Faithful, Unfaithful or Ambiguous? Multi-Agent Debate with Initial Stance for Summary Evaluation](https://arxiv.org/abs/2502.08514): A multi-agent debate workflow for summary faithfulness evaluation. Core idea: force agents with different initial stances to surface evidence for faithful, unfaithful, or ambiguous labels.
- [REFIND](https://arxiv.org/abs/2502.13622) ([open-source code](https://github.com/oneonlee/REFIND)): retrieval-augmented factuality hallucination detection.
