# 1.18.5 Agent Harness

- [Exploring Large Language Model based Intelligent Agents: Definitions, Methods, and Prospects](https://arxiv.org/abs/2401.03428): Surveys LLM-agent architectures across single-agent and multi-agent settings, organizing composition, planning, memory, tool use, and agent-society applications as reusable harness components.
- [AutoAct: Automatic Agent Learning from Scratch for QA via Self-Planning](https://arxiv.org/abs/2401.05268): Synthesizes tool-use planning trajectories from limited QA data, then splits the learned system into specialized sub-agents instead of relying on GPT-4-generated demonstrations.
- [Small LLMs Are Weak Tool Learners: A Multi-LLM Agent](https://arxiv.org/abs/2401.07324): Decomposes tool use into planner, caller, and summarizer LLMs so small models can specialize on query planning, API invocation, and result synthesis.
- [Visibility into AI Agents](https://arxiv.org/abs/2401.13138): Treats agent governance as an observability problem, comparing identifiers, real-time monitoring, and activity logs by intrusiveness, informativeness, and accountability value.
- [Green Runner: A tool for efficient deep learning component selection](https://arxiv.org/abs/2401.15810): Turns a natural-language application description into model candidates, metrics, training strategies, and resource-aware experiments for selecting deep-learning components.
- [AMOR: A Recipe for Building Adaptable Modular Knowledge Agents Through Process Feedback](https://arxiv.org/abs/2402.01469): Uses a finite-state-machine reasoning loop with disentangled knowledge modules so human process feedback can target individual steps during domain adaptation.
- [Assistive Large Language Model Agents for Socially-Aware Negotiation Dialogues](https://arxiv.org/abs/2402.01737): Adds a third remediator agent to business-negotiation simulations, rewriting norm-violating utterances with label-free in-context exemplars selected by value impact.
- [LLM Agents in Interaction: Measuring Personality Consistency and Linguistic Alignment in Interacting Populations of Large Language Models](https://arxiv.org/abs/2402.02896): Constructs persona-conditioned agent populations and measures how collaborative dialogue shifts personality-test consistency and linguistic alignment.
- [A Framework for Effective Invocation Methods of Various LLM Services](https://arxiv.org/abs/2402.03408): Formalizes LLM-service invocation choices such as context selection and caching as cost, latency, and quality tradeoffs for routing among providers.
- [In-context learning agents are asymmetric belief updaters](https://arxiv.org/abs/2402.03969): Uses instrumental-learning tasks to show that prompted LLM agents learn more from better-than-expected outcomes, with the effect changing under counterfactual feedback and agency framing.
- [Tell Me More! Towards Implicit User Intention Understanding of Language Model Driven Agents](https://arxiv.org/abs/2402.09205): Introduces IN3 for testing clarification behavior and trains an upstream interaction model that detects vague tasks, asks intent questions, and rewrites goals before execution.
- [MuLan: Multimodal-LLM Agent for Progressive Multi-Object Diffusion](https://arxiv.org/abs/2402.12741): Uses an LLM painter loop to decompose multi-object image prompts into sequential object-generation subtasks, with attention guidance and VLM feedback correcting location, size, and bindings.
- [Exploring LLM-Based Agents for Root Cause Analysis](https://arxiv.org/abs/2403.04123): Extends incident root-cause analysis with agents that dynamically collect diagnostic logs, metrics, and database evidence rather than diagnosing only from a fixed prompt.
- [StateFlow: Enhancing LLM Task-Solving through State-Driven Workflows](https://arxiv.org/abs/2403.11322): Represents complex tool-using tasks as state machines, separating process grounding through states and transitions from prompt or tool actions inside each state.
- [Envisioning the Next-Generation AI Coding Assistants: Insights & Proposals](https://arxiv.org/abs/2403.14592): Distills in-IDE assistant design lessons around expectation setting, deep IDE and extension integration, extensible backends, and responsible app-data collection.
- [AIOS](https://arxiv.org/abs/2403.16971) ([code](https://github.com/agiresearch/AIOS)): An LLM agent operating-system harness that exposes scheduling, context and memory management, storage, access control, and SDK interfaces as reusable runtime services.
- [MIMIR: A Streamlined Platform for Personalized Agent Tuning in Domain Expertise](https://arxiv.org/abs/2404.04285): Provides a data pipeline for personalized agent tuning that combines private knowledge with legally compliant public data and can also emit general instruction-tuning data.
- [AgentCoord: Visually Exploring Coordination Strategy for LLM-based Multi-Agent Collaboration](https://arxiv.org/abs/2404.11943): Visualizes agent relationships, task dependencies, and result correspondences so users can design multi-agent coordination strategies without parsing long text traces.
- [BIRD: A Trustworthy Bayesian Inference Framework for Large Language Models](https://arxiv.org/abs/2404.12494): Aligns LLM-generated factors and coarse probabilities with a Bayesian network, then performs deduction for calibrated probability estimates under incomplete information.
- [Aligning LLM Agents by Learning Latent Preference from User Edits](https://arxiv.org/abs/2404.15269): Infers user preference descriptions from historical edits and injects them into future prompts, aligning writing-agent outputs without fine-tuning.
- [Large Language Model Agent as a Mechanical Designer](https://arxiv.org/abs/2404.17525): Couples an LLM designer with finite-element analysis feedback so truss designs can be generated, numerically evaluated, and revised without domain-specific fine-tuning.
- [STRIDE: A Tool-Assisted LLM Agent Framework for Strategic and Interactive Decision-Making](https://arxiv.org/abs/2405.16376): Gives strategic-game agents memory and specialized tools for rule tracking, long-term planning, exploration, and opponent reasoning in interactive economic environments.
- [AgentGym: Evolving Large Language Model-based Agents across Diverse Environments](https://arxiv.org/abs/2406.04151): Packages diverse environments, trajectories, and self-evolution routines so agents can explore beyond imitation data and improve across tasks.
- [Dissecting Adversarial Robustness of Multimodal LM Agents](https://arxiv.org/abs/2406.12814): Defines ARE on VisualWebArena, modeling an agent as an intermediate-output graph and injecting 200 targeted adversarial tasks to trace how attacks flow through components.
