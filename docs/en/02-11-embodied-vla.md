# 2.11 Embodied and VLA Agents

> Parent section: 2. Foundation Agents

Note: This category covers embodied agents and vision-language-action settings where the model must connect perception, language, planning, and actions in an interactive physical, simulated, game, or robot environment. GUI-only computer use stays in [2.5 Computer Use](02-05-computer-use-gui.md), while passive spatial or video understanding stays in the corresponding core-capability pages.

## 2.11.1 Leaderboard

- [VideoGameBench Leaderboard](https://vgbench.com/#leaderboard): A continuous leaderboard for embodied agent perception, navigation, manipulation, and planning in video-game environments; useful for tracking models and scaffolds that operate in executable visual worlds rather than static screenshots.

## 2.11.2 Bench


- [CALVIN](https://arxiv.org/abs/2112.03227): Evaluates language-conditioned long-horizon robot manipulation. Core idea: use a simulated tabletop environment and language instructions to test whether agents can compose manipulation skills over extended horizons.
- [MineDojo](https://arxiv.org/abs/2206.08853): Evaluates open-ended embodied agents in Minecraft with internet-scale knowledge resources. Core idea: use a rich, long-horizon sandbox environment to test exploration, tool use, crafting, navigation, and task completion under language goals.
- [VIMA-Bench](https://arxiv.org/abs/2210.03094): Evaluates general robot manipulation with multimodal prompts. Core idea: specify manipulation tasks through combinations of text, images, and object references, making the benchmark closer to vision-language-action grounding than pure language-conditioned control.
- [LIBERO](https://arxiv.org/abs/2306.03310): Evaluates knowledge transfer for lifelong robot learning. Core idea: organize robot-manipulation tasks into suites that test whether agents reuse skills and adapt across objects, layouts, and task families.
- [VLABench](https://arxiv.org/abs/2412.18194): Evaluates language-conditioned robotic manipulation with long-horizon reasoning tasks. Core idea: provide many manipulation categories and compositional instructions so VLA models are tested on task reasoning, grounding, and action sequence execution together.
- [ECBench](https://arxiv.org/abs/2501.05031) ([open-source code](https://github.com/Rh-Dang/ECBench)): Evaluates egocentric embodied cognition in multimodal foundation models. Core idea: test self-cognition, dynamic scene perception, and hallucination from an agent-centered view, which is closer to embodied operation than static image QA.
- [Text2World](https://arxiv.org/abs/2502.13092): Benchmarks LLMs on symbolic world-model generation. Core idea: convert natural-language environment descriptions into executable symbolic models so evaluation can test whether models represent states, actions, and dynamics needed for planning.
- [Openfly](https://arxiv.org/abs/2502.18041): Evaluates aerial vision-language navigation agents in embodied environments. Core idea: provide a comprehensive aerial navigation platform so models must connect visual observation, language goals, spatial reasoning, and flight actions rather than only answer static navigation questions.
- [EXPRESS-Bench](https://arxiv.org/abs/2503.11117): Evaluates exploration-aware embodied question answering. Core idea: pair 3D exploration trajectories with question-answer tasks and exploration-aware metrics so agents are judged on both evidence gathering and downstream reasoning.
- [HA-VLN](https://arxiv.org/abs/2503.14229): Evaluates human-aware vision-language navigation in discrete-continuous environments with dynamic multi-human interactions. Core idea: include real-world validation and an open leaderboard so navigation agents are scored on social awareness as well as route completion.
- [OvercookedV2](https://arxiv.org/abs/2503.17821): Evaluates zero-shot coordination in an Overcooked-style embodied multi-agent environment. Core idea: stress-test whether agents can infer partner behavior, divide labor, and recover from coordination failures in executable collaborative tasks.
- [SHREC](https://arxiv.org/abs/2504.13898): Evaluates social reasoning in real human-robot embodied conversations. Core idea: use real interaction videos, social-error annotations, rationales, and correction tasks so embodied agents are tested on subtle conversational and social failures rather than only navigation or manipulation success.
- [Robotouille](https://openreview.net/forum?id=OhUoTMxFIH): Evaluates asynchronous planning for LLM agents in an embodied task setting. Core idea: require agents to plan and coordinate under delayed or asynchronous execution rather than assuming a single immediate action loop.
- [ManiSkill-HAB](https://openreview.net/forum?id=6bKEWevgSd): Evaluates low-level manipulation for home rearrangement tasks. Core idea: connect household rearrangement goals with manipulation primitives, testing whether embodied agents can perform grounded object handling rather than only high-level navigation.
- [HASARD](https://openreview.net/forum?id=5BRFddsAai): Evaluates vision-based safe reinforcement learning for embodied agents. Core idea: make safety constraints visible in the embodied environment so models must avoid hazards while completing tasks.
- [TPT-Bench](https://arxiv.org/abs/2505.07446): Evaluates target-person tracking from robot-egocentric views. Core idea: use long-term crowded and unstructured scenes to test whether embodied agents can keep tracking a designated person under occlusion, distractors, and changing viewpoints.
- [UAV-Flow Colosseo](https://arxiv.org/abs/2505.15725): Evaluates language-conditioned UAV imitation learning in real-world flight settings. Core idea: connect natural-language commands with aerial trajectories so embodied aerial agents are tested on grounded flight behavior rather than passive scene understanding.
- [TrackVLA / EVT-Bench](https://arxiv.org/abs/2505.23189) ([project page](https://pku-epic.github.io/TrackVLA-web)): Evaluates embodied visual tracking in synthetic and real-world environments. Core idea: require an egocentric agent to recognize a target and plan trajectories under occlusion and high scene dynamics, making visual tracking an embodied VLA capability rather than only passive perception.
- [CheckManual](https://openaccess.thecvf.com/content/CVPR2025/html/Long_CheckManual_A_New_Challenge_and_Benchmark_for_Manual-based_Appliance_Manipulation_CVPR_2025_paper.html): Evaluates appliance manipulation from manuals. Core idea: bind document/manual understanding to physical-action planning so agents must extract procedural knowledge and apply it to manipulation.
- [RoboTwin](https://openaccess.thecvf.com/content/CVPR2025/html/Mu_RoboTwin_Dual-Arm_Robot_Benchmark_with_Generative_Digital_Twins_CVPR_2025_paper.html): Evaluates dual-arm robot manipulation with generative digital twins. Core idea: use generated interactive simulation scenes and expert demonstrations to test coordinated manipulation under more diverse object and layout conditions.
- [Orak](https://arxiv.org/abs/2506.03610): Benchmarks training and evaluation of LLM agents across 12 video-game genres. Core idea: use an MCP-based interface, gameplay trajectories, leaderboards, battle arenas, and agent-module ablations to study executable game agents.
- [WorldPrediction](https://arxiv.org/abs/2506.04363): Evaluates high-level world modeling and long-horizon procedural planning. Core idea: test whether agents can predict abstract future states and plan procedures over extended horizons, complementing video-world-model benchmarks that focus more on generated dynamics.
- [HEAL](https://arxiv.org/abs/2506.15065): Evaluates hallucinations in LLM-driven embodied agents under scene-task inconsistencies. Core idea: build probing cases where requested objects or conditions conflict with the observed environment, exposing whether agents ground instructions before acting.
- [EmbodiedBench](https://proceedings.mlr.press/v267/yang25f.html) ([open-source code](https://github.com/EmbodiedBench/EmbodiedBench)): Evaluates multimodal large language models as vision-driven embodied agents. Core idea: combine embodied perception, planning, and action tasks into a unified benchmark for VLM/LLM agents operating from visual observations.
- [VLN-PE](https://arxiv.org/abs/2507.13019): evaluates vision-language navigation under physically realistic robot embodiments. Core idea: compare navigation pipelines across humanoid, quadruped, and wheeled robots so embodied navigation is tested against physical and visual disparities rather than idealized motion assumptions.
- [UAV-ON](https://arxiv.org/abs/2508.00288): Benchmarks open-world object-goal navigation for aerial agents. Core idea: evaluate whether UAV agents can use visual perception and spatial exploration to find target objects in open environments, extending embodied navigation beyond ground-level settings.
- [Follow-Bench](https://arxiv.org/abs/2509.10796): Evaluates socially aware robot person-following motion planning. Core idea: test whether embodied agents can follow people while respecting social navigation constraints rather than optimizing only geometric path efficiency.
- [ConEQsA](https://arxiv.org/abs/2509.11663): Benchmarks concurrent and asynchronous embodied question scheduling and answering. Core idea: move beyond one-question EQA by giving agents multiple questions with different arrival times and urgencies, requiring shared memory, prioritization, exploration, and answer timing.
- [MoMa-Kitchen](https://openaccess.thecvf.com/content/ICCV2025/html/Zhang_MoMa-Kitchen_A_100K_Benchmark_for_Affordance-Grounded_Last-Mile_Navigation_in_Mobile_ICCV_2025_paper.html): Evaluates affordance-grounded last-mile navigation in mobile manipulation. Core idea: score whether navigation stops in positions that make subsequent manipulation feasible, not merely whether the robot gets near the object.
- [VideoGameBench](https://vgbench.com/#leaderboard): Evaluates embodied perception, navigation, manipulation, and planning in video-game environments. Core idea: place spatial understanding in actionable game worlds and use task completion plus trajectory quality to evaluate whether agents can translate visual-spatial relations into actions.
- [SAGE-Bench](https://arxiv.org/abs/2510.21307): Evaluates vision-language navigation in semantically and physically executable 3D Gaussian environments. Core idea: upgrade 3DGS scenes with object semantics and collision-aware execution so navigation agents are tested in photorealistic but action-grounded spaces.
- [CityEQA](https://aclanthology.org/2025.emnlp-main.630/): Evaluates embodied question answering in city-scale spaces. Core idea: place language agents in hierarchical urban environments where answering requires navigation, spatial reasoning, and evidence gathering rather than static scene recognition.
- [UAVBench](https://arxiv.org/abs/2511.11252): Evaluates autonomous and agentic UAV systems with LLM-generated flight scenarios. Core idea: use scenario generation to expand aerial-agent tasks and test perception, planning, and control under varied flight goals.
- [RoboAfford](https://doi.org/10.1145/3746027.3758209): Evaluates object and spatial affordance learning for robot manipulation. Core idea: make actionable affordances the target, testing whether embodied models infer how objects can be used and manipulated from visual-spatial context.
- [RoboAfford++](https://arxiv.org/abs/2511.12436): Evaluates multimodal affordance learning for robotic manipulation and navigation. Core idea: expand affordance supervision with generative-AI-enhanced data so agents can connect objects, spatial context, possible actions, and navigation/manipulation decisions.
- [Embodied4C](https://arxiv.org/abs/2512.18028): Evaluates embodied vision-language navigation with a focus on the capabilities that matter for navigation success. Core idea: diagnose navigation agents beyond final success by measuring perceptual grounding, context use, commonsense, and control-relevant reasoning in embodied environments.
- [VLNVerse](https://arxiv.org/abs/2512.19021): Evaluates vision-language navigation in versatile embodied simulation settings. Core idea: combine realistic scenes, embodied navigation tasks, and standardized evaluation so agents are tested on grounded perception, spatial reasoning, and action execution rather than static navigation QA.
- [α3-Bench](https://arxiv.org/abs/2601.03281): Evaluates LLM-based UAV agents over 6G network settings. Core idea: jointly measure safety, robustness, and efficiency so aerial-agent evaluation covers communication constraints and operational reliability, not only navigation success.
- [AirNav](https://arxiv.org/abs/2601.03707): Evaluates UAV vision-language navigation with a large-scale dataset of natural and diverse instructions. Core idea: test whether aerial agents can ground language goals in visual observations and navigate under realistic instruction variation.
- [P2Maze](https://doi.org/10.1109/SoutheastCon63549.2026.11476499): Evaluates sim-to-real robot maze navigation under paired simulation and real-world protocols. Core idea: use matched maze tasks to measure zero-shot transfer and few-shot adaptation of embodied navigation policies.
- [Autonomous UAV Visual Object Search in City Space](https://doi.org/10.1609/aaai.v40i22.38898): Evaluates UAV visual object search in city-scale environments. Core idea: combine a benchmark with an agentic search methodology so aerial agents are measured on open visual target finding, exploration, and navigation decisions.
- [LMEE-Bench](https://arxiv.org/abs/2601.10744): Evaluates embodied exploration with long-term episodic memory. Core idea: combine multi-goal navigation and memory-based question answering so agents are scored on both exploration process and later use of accumulated experience.
- [VisGym](https://arxiv.org/abs/2601.16973): Evaluates multimodal agents in 17 multi-step visual interaction environments. Core idea: vary difficulty, horizon, feedback, and observation format to test perception, memory, planning, and action across puzzles, real-image tasks, navigation, and manipulation.
- [EmboCoach-Bench](https://arxiv.org/abs/2601.21570): Benchmarks AI agents on developing embodied robots. Core idea: turn robot-development workflows into comparable tasks with explicit protocols and scoring.
- [Beyond Binary Success](https://arxiv.org/abs/2603.13616): Evaluates sample-efficient, statistically rigorous robot-policy comparison under limited hardware rollouts. Core idea: replace fragile binary success-rate averages with sequential, anytime-valid tests over binary, partial-credit, and continuous robot metrics.
- [PokeAgent Challenge](https://arxiv.org/abs/2603.15563): Benchmarks embodied decision making in Pokemon battles and RPG speedrunning. Core idea: combine partial observability, competitive multi-agent reasoning, long-horizon planning, and standardized baselines in executable game environments.
- [HUGE-Bench](https://arxiv.org/abs/2603.19822): evaluates high-level UAV vision-language-action tasks. Core idea: use concise operational commands, digital-twin scenes, process-oriented trajectories, and safety-aware scoring to test whether aerial agents can execute complex multi-stage behaviors rather than only follow route descriptions.
- [IndoorR2X](https://arxiv.org/abs/2603.20182): Benchmarks LLM-driven indoor multi-robot planning with robot-to-everything perception. Core idea: combine mobile-robot observations with static IoT sensors to test whether agents can coordinate under partial observability and shared semantic state.
- [CaP-X](https://arxiv.org/abs/2603.22435): Evaluates and improves coding agents for robot manipulation. Core idea: connect generated code, embodied manipulation tasks, and execution feedback so robot-control agents can be compared beyond static program synthesis.
- [Urban Airspace Spatial Action Benchmark](https://arxiv.org/abs/2604.07973): Evaluates goal-oriented embodied navigation in urban airspace. Core idea: test whether large multimodal models can translate spatial perception and language goals into aerial navigation actions rather than only answer passive spatial questions.
- [SCOPE](https://doi.org/10.1145/3757279.3785641): Evaluates natural-language PTZ camera agents with a sim-to-real benchmark. Core idea: test whether vision-language agents can map language goals to pan-tilt-zoom actions under edge-runtime constraints.
- [Spatial-Gym](https://arxiv.org/abs/2604.09338): Evaluates whether agents can turn spatial reasoning into sequential action. Core idea: use a Gymnasium-style interactive benchmark with pathfinding, backtracking, and action-level scoring rather than passive spatial QA.
- [E3VS-Bench](https://arxiv.org/abs/2604.17969): Evaluates viewpoint-dependent active perception in 3D Gaussian Splatting scenes. Core idea: require embodied agents to move through 5-DoF viewpoints to reveal occluded, container-internal, or attribute-dependent evidence rather than answering from static observations.
- [Capability-Oriented Failure Attribution for VLN Agents](https://arxiv.org/abs/2604.25161): Evaluates where vision-language navigation agents fail across capabilities. Core idea: combine adaptive test-case generation, capability-specific oracles, and feedback-based attribution so navigation failures can be mapped to perception, memory, planning, or decision weaknesses rather than only final success rates.
- [Minedojo-Verified](https://github.com/ByteDance-Seed/Seed2.0): A verified embodied-agent visual task subset reported in the Seed2.0 model card; no standalone public release of this verified subset has been confirmed. Core idea: track whether frontier multimodal agents can ground perception, planning, and action in an interactive environment beyond static screenshots.
- [ESARBench](https://arxiv.org/abs/2605.01371): evaluates agentic UAV embodied search and rescue. Core idea: place aerial agents in search-and-rescue scenarios where perception, navigation, task planning, and action execution must work together rather than being scored as static visual understanding.
- [OmniNavBench](https://arxiv.org/abs/2605.09441): Evaluates general-purpose embodied navigation across skills and embodiments. Core idea: use composite instructions spanning PointNav, VLN, ObjectNav, SocialNav, human following, and EQA so agents must coordinate subskills and generalize across robot morphologies rather than solve isolated navigation tasks.
## 2.11.3 Agent Harness


- MineDojo, CALVIN, VIMA, and LIBERO are benchmark-side harnesses as much as datasets: they define environments, observations, action spaces, task resets, and success checks. The reusable design pattern is `observe multimodal state -> parse language goal -> plan/subgoal -> act -> verify environment state -> recover`.
- [UAV-VLA](https://arxiv.org/abs/2501.05014): A vision-language-action system for large-scale aerial mission generation. Core idea: translate mission-level language and visual context into UAV action plans, making aerial task decomposition and execution part of the agent runtime.
- [Generalized Mission Planning for Heterogeneous Multi-Robot Teams](https://arxiv.org/abs/2501.16539): An LLM-based multi-robot mission-planning harness. Core idea: construct hierarchical task trees from language goals so heterogeneous robots can receive coordinated subtasks and execute team missions.
- [VL-Nav](https://arxiv.org/abs/2502.00931): A neuro-symbolic vision-language navigation harness. Core idea: combine VLM reasoning with symbolic 3D scene graphs, image memory, task decomposition, exploration heuristics, and replanning so robots can follow complex instructions in unseen indoor and outdoor environments.
- [MuJoCo Playground](https://arxiv.org/abs/2502.08844): A reusable environment suite for robot learning on MuJoCo. Core idea: package simulation, tasks, and evaluation scaffolding so embodied policies can be developed and compared across standardized control settings.
- [MapNav](https://arxiv.org/abs/2502.13451): Provides a semantic-map memory representation for VLM-based vision-language navigation. Core idea: annotate navigational memory on maps so an embodied agent can ground route choices in persistent spatial context.
- [Mem2Ego](https://arxiv.org/abs/2502.14254): A global-to-egocentric memory harness for long-horizon embodied navigation. Core idea: maintain allocentric scene memory and translate it back into egocentric action context so a VLM navigation agent can reason over past observations during extended exploration.
- [ATLAS Navigator](https://arxiv.org/abs/2502.20386): An active navigation harness built on language-embedded Gaussian Splatting. Core idea: connect 3D scene representation, language goals, and task-driven exploration so embodied agents can navigate through richer spatial memory than raw egocentric observations alone.
- [General-Purpose Aerial Intelligent Agents](https://arxiv.org/abs/2503.08302): an LLM-powered UAV agent harness for open-world aerial task execution. Core idea: combine onboard language reasoning, robotic autonomy, and hardware-software coordination so aerial agents can interpret high-level goals and execute them in the physical world.
- [SmartWay](https://arxiv.org/abs/2503.10069): a zero-shot vision-language navigation harness with enhanced waypoint prediction and backtracking. Core idea: combine spatial waypoint generation, multimodal reasoning, history use, and recovery behavior so agents can adapt in continuous 3D navigation environments.
- [PORTAL](https://arxiv.org/abs/2503.13356): Provides a language-guided policy-generation harness for agents playing large sets of 3D games. Core idea: generate behavior-tree policies and improve them with game metrics and vision-language feedback for reusable execution in executable game environments.
- [AirVista-II](https://arxiv.org/abs/2504.09583): An agentic system for embodied UAV dynamic-scene semantic understanding. Core idea: structure aerial perception and reasoning as an embodied agent workflow rather than a passive image or video understanding task.
- [ApexNav](https://arxiv.org/abs/2504.14478): A zero-shot object-navigation harness with adaptive exploration and target-centric semantic fusion. Core idea: switch between semantic and geometric exploration cues and maintain long-term memory of target and similar objects to improve navigation reliability under noisy detections.
- [UAV-CodeAgents](https://arxiv.org/abs/2505.07236): A multi-agent ReAct harness for UAV mission planning from language and satellite imagery. Core idea: combine vision-grounded pixel pointing, collaborative trajectory generation, and reactive goal revision so aerial agents can turn high-level instructions into executable missions.
- [Air-Ground Collaboration for Language-Specified Missions](https://arxiv.org/abs/2505.09108): An embodied air-ground collaboration harness for language-specified missions in unknown environments. Core idea: coordinate aerial and ground agents so natural-language goals can be decomposed, explored, and executed across complementary embodiments.
- [FlightGPT](https://arxiv.org/abs/2505.12835): A UAV vision-language navigation framework built around vision-language models. Core idea: make aerial navigation decisions more generalizable and interpretable by connecting visual observations, language goals, and explicit route reasoning.
- [VLM-RRT](https://arxiv.org/abs/2505.23267): A UAV navigation harness that guides RRT search with a vision-language model. Core idea: combine language and visual grounding with sampling-based planning so aerial agents can turn observations and goals into navigation trajectories.
- [Language-Grounded Hierarchical Planning and Execution with Multi-Robot 3D Scene Graphs](https://arxiv.org/abs/2506.07454): an embodied multi-robot planning harness. Core idea: use language grounding and 3D scene-graph state to coordinate hierarchical task planning and execution across robots.
- [GRaD-Nav++](https://arxiv.org/abs/2506.14009): an onboard vision-language-action framework for visual drone navigation. Core idea: combine language-command grounding, Gaussian-radiance-field simulation, differentiable dynamics, and real-time onboard execution so aerial agents can follow high-level instructions in unstructured environments.
- [DyNaVLM](https://arxiv.org/abs/2506.15096): A zero-shot vision-language navigation harness with dynamic viewpoints and self-refining graph memory. Core idea: maintain and revise a navigation graph during exploration so route decisions can use accumulated spatial evidence instead of one-step observations.
- [RALLY](https://arxiv.org/abs/2507.01378): an LLM-driven harness for agentic UAV swarms. Core idea: use role-adaptive coordination for yoked navigation so multiple aerial agents can share planning and execution responsibilities.
- [SkyVLN](https://arxiv.org/abs/2507.06564): A UAV vision-and-language navigation framework paired with NMPC control in urban environments. Core idea: connect language-goal grounding with model-predictive flight control so aerial agents can execute route decisions in constrained city scenes.
- [Enter the Mind Palace](https://arxiv.org/abs/2507.12846): A reasoning-and-planning harness for long-term active embodied question answering. Core idea: externalize long-horizon spatial and evidence memory so an embodied agent can navigate, collect observations, and answer questions over time.
- [DISCOVERSE](https://arxiv.org/abs/2507.21981): A robot-simulation infrastructure layer for complex high-fidelity environments. Core idea: provide efficient simulated worlds and interfaces so embodied agents can be developed and evaluated beyond small fixed scenes.
- [Mixture of Skill-Based Vision-and-Language Navigation Agents](https://arxiv.org/abs/2508.07642): An embodied navigation agent harness built around decomposed skills. Core idea: split VLN behavior into skill-like components and compose them for navigation decisions, making skill organization part of the embodied-agent runtime.
- [SpatialGPT](https://doi.org/10.1145/3748636.3762753): A zero-shot vision-language navigation harness built around spatial chain-of-thought and structured spatial memory. Core idea: externalize spatial state so route decisions can be grounded in persistent scene structure rather than one-step visual-language matching.
- [DEXTER-LLM](https://arxiv.org/abs/2508.14387): A dynamic, explainable LLM harness for multi-robot coordination in unknown environments. Core idea: make robot-team task allocation and coordination explicit enough for replanning and human inspection.
- [Agentic UAVs](https://arxiv.org/abs/2509.13352): An LLM-driven UAV autonomy harness with integrated tool calling. Core idea: organize perception, reasoning, action, integration, and learning layers so aerial agents can query databases, use external systems, and produce mission decisions in simulated search-and-rescue settings.
- [VLN-Zero](https://arxiv.org/abs/2509.18592): an embodied navigation harness for zero-shot transfer. Core idea: combine rapid exploration, cached experience, and neurosymbolic vision-language planning so robot navigation can adapt without task-specific training.
- [JanusVLN](https://arxiv.org/abs/2509.22548): An embodied navigation harness with dual implicit memory. Core idea: separate semantic and spatial memory so vision-language agents can maintain route-relevant context across navigation decisions.
- [See, Point, Fly](https://arxiv.org/abs/2509.22653): A learning-free VLM framework for unmanned aerial navigation; the core idea is to convert open-vocabulary goals into visual pointing and flight-control steps so UAV agents can navigate without task-specific training.
- [Advancing Audio-Visual Navigation Through Multi-Agent Collaboration in 3D Environments](https://arxiv.org/abs/2509.22698): A multi-agent harness for audio-visual navigation in 3D environments; the core idea is to split navigation reasoning across collaborating agents so visual cues, acoustic cues, and route decisions can be coordinated during embodied exploration.
- [Leave No Observation Behind](https://arxiv.org/abs/2509.23224): A real-time correction harness for VLA action chunks. Core idea: use incoming observations to detect stale or failing action chunks and revise execution online so embodied agents can recover during continuous control.
- [RAVEN](https://arxiv.org/abs/2509.23563): An aerial navigation harness using open-set semantic memory and behavior adaptation. Core idea: maintain environment memory and adapt navigation behavior under changing or unseen aerial scenes rather than treating VLN as a fixed-policy prediction task.
- [Prompting Robot Teams with Natural Language](https://arxiv.org/abs/2509.24575): A natural-language orchestration harness for robot teams. Core idea: translate human language instructions into coordinated multi-robot behavior, making team assignment and embodied execution part of the agent runtime.
- [Cogito, Ergo Ludo](https://arxiv.org/abs/2509.25052): A reasoning-and-planning agent for learning to play games. Core idea: wrap game interaction with explicit reasoning, planning, and feedback so agents can acquire strategies in executable environments rather than only answer static game questions.
- [GaussGym](https://arxiv.org/abs/2510.15352): An open-source real-to-sim framework for learning locomotion from pixels. Core idea: connect Gaussian-splatting reconstruction with simulation and policy evaluation so visually grounded locomotion agents can be tested in photorealistic real-to-sim environments.
- [Next-Generation LLM for UAV](https://arxiv.org/abs/2510.21739): An LLM-based UAV framework for translating natural language into autonomous flight behavior. Core idea: make language understanding, mission planning, and flight execution part of one aerial-agent loop.
- [Running VLAs at Real-time Speed](https://arxiv.org/abs/2510.26742) ([code](https://github.com/Dexmal/realtime-vla)): A streaming inference harness for real-time VLA robot control. Core idea: remove inference overhead around multi-view VLA policies so action generation can run at real-time control rates on consumer hardware.
- [SPINE-HT](https://arxiv.org/abs/2510.26915): A grounded generative-intelligence harness for heterogeneous robot collaboration in unstructured environments. Core idea: decompose natural-language missions into feasible subtasks, assign them by robot capability, and refine plans with online perception feedback.
- [Isaac Lab](https://arxiv.org/abs/2511.04831): A GPU-accelerated simulation framework for robot learning. Core idea: provide reusable multimodal robot environments, sensors, and policy-evaluation workflows that embodied-agent harnesses can build on instead of one-off simulators.
- [MindPower](https://arxiv.org/abs/2511.23055): Adds theory-of-mind reasoning to VLM-based embodied agents. Core idea: make other-agent beliefs and intentions explicit in the embodied decision loop so agents can plan under social or collaborative uncertainty.
- [LEO-RobotAgent](https://arxiv.org/abs/2512.10605): A general-purpose robotic agent for language-driven embodied operation. Core idea: wrap language goals, perception, planning, and robot actions into a reusable embodied-agent execution loop.
- [VLA-AN](https://arxiv.org/abs/2512.15258): An onboard vision-language-action framework for aerial navigation. Core idea: run perception, language-goal grounding, and action selection in an efficient UAV navigation loop for complex environments.
- [ImagineNav++](https://arxiv.org/abs/2512.17435): An embodied navigation harness that prompts vision-language models to imagine scene structure before action selection. Core idea: use generated spatial hypotheses as external reasoning context so navigators can plan beyond the immediately observed view.
- [Genie Sim 3.0](https://arxiv.org/abs/2601.02078): A high-fidelity humanoid-robot simulation platform for scalable data collection and policy evaluation. Core idea: use LLM-assisted scene generation and unified manipulation environments so embodied agents can be tested across diverse, realistic scenarios.
- [Current Agents Fail to Leverage World Model as Tool for Foresight](https://arxiv.org/abs/2601.03905): Evaluates agent use of world models as foresight tools. Core idea: expose the planning loop around a world model to test whether agents can simulate future outcomes before acting.
- [SpatialNav](https://arxiv.org/abs/2601.06806): A zero-shot vision-language navigation harness built around spatial scene graphs. Core idea: let agents explore first, construct global spatial and semantic structure, and use an agent-centric map for grounded navigation decisions.
- [VLingNav](https://arxiv.org/abs/2601.08665): An embodied navigation harness with adaptive reasoning and visual-assisted linguistic memory. Core idea: maintain language-grounded memory from visual observations so navigation decisions can use persistent route context across steps.
- [VLAgents](https://arxiv.org/abs/2601.11250): Provides a policy-server runtime for efficient VLA inference. Core idea: expose VLA policies through a serving layer that can be reused by embodied-agent execution loops and environment harnesses.
- [IROS](https://arxiv.org/abs/2601.21506): A dual-process harness for real-time VLM-based indoor navigation. Core idea: separate fast reactive control from slower deliberative vision-language reasoning so indoor agents can keep moving while revising plans from observations.
- [From Knowing to Doing Precisely](https://arxiv.org/abs/2602.01811): Provides a self-correction and termination framework for VLA models. Core idea: wrap action execution with correction and stopping checks so long-horizon manipulation does not continue after accumulated errors.
- [MerNav](https://arxiv.org/abs/2602.05467): A Memory-Execute-Review framework for zero-shot object-goal navigation. Core idea: wrap navigation with persistent memory, action execution, and review so embodied agents can recover and generalize during object search.
- [Grounding Generative Planners in Verifiable Logic](https://arxiv.org/abs/2602.08373): A hybrid embodied-AI planning harness. Core idea: combine generative planning with verifiable logic so embodied agents can check plan constraints and trustworthiness before or during action.
- [One Agent to Guide Them All](https://arxiv.org/abs/2602.15400): A vision-language navigation agent built around explicit world representation. Core idea: expose world state as an external navigation structure so MLLMs can ground route decisions beyond one-shot visual-language inference.
- [VLA-Perf](https://arxiv.org/abs/2602.18397): A performance-analysis framework for real-time VLA inference. Core idea: model the latency tradeoffs among VLA architecture, long-context visual inputs, hardware placement, edge or cloud execution, and network conditions so embodied-agent runtimes can be designed against control-loop constraints.
- [RoboCritics](https://arxiv.org/abs/2603.06842): A robot-programming harness that augments LLM-generated robot code with expert-informed motion critics. Core idea: inspect execution traces for collisions, joint-speed violations, and unsafe poses, then feed structured corrections back into the programming loop.
- [OnFly](https://arxiv.org/abs/2603.10682): A zero-shot aerial vision-language navigation harness for onboard UAV agents. Core idea: combine a dual-agent decision architecture, hybrid trajectory memory, semantic-geometric verification, and receding-horizon planning to stabilize long-horizon navigation.
- [GoalVLM](https://arxiv.org/abs/2603.18210): a cooperative multi-agent object-navigation harness. Core idea: put VLM semantic scoring, open-vocabulary segmentation, spatial reasoning, and frontier selection inside the decision loop so multiple agents can search for free-form language goals.
- [ReMemNav](https://arxiv.org/abs/2603.26788): a memory-augmented framework for zero-shot object navigation. Core idea: add reusable memory mechanisms to embodied navigation so agents can recover object-location and exploration context during task execution.
- [MetaNav](https://arxiv.org/abs/2604.02318): A metacognitive vision-language navigation harness. Core idea: combine persistent 3D semantic memory, history-aware planning, and reflective correction so training-free VLN agents can detect inefficient wandering, revise exploration strategy, and reduce redundant revisits.
- [Speculative Verification for VLA](https://arxiv.org/abs/2604.02965): A VLA control harness that combines open-loop action-chunk planning with lightweight closed-loop verification. Core idea: keep high-throughput action generation while checking observations online so embodied agents can catch stale or unsafe chunks before error accumulation dominates execution.
- [ABot-Claw](https://arxiv.org/abs/2604.10096): an embodied-agent harness for persistent, cooperative, and self-evolving robotic agents. Core idea: extend OpenClaw with unified embodiment interfaces, cross-embodiment multimodal memory, capability scheduling, and critic-based feedback so natural-language goals can be closed over physical robot action and replanning.
- [FineCog-Nav](https://arxiv.org/abs/2604.16298): A zero-shot UAV vision-language navigation harness with fine-grained cognitive modules. Core idea: coordinate language, perception, attention, memory, imagination, reasoning, and decision modules through structured protocols, with AerialVLN-Fine used to diagnose instruction adherence and long-horizon navigation.
- [HELM: Harness-Enhanced Long-horizon Memory](https://arxiv.org/abs/2604.18791): A model-agnostic harness for long-horizon VLA manipulation. Core idea: add external memory, verification, and recovery around a VLA policy so execution failures can be diagnosed and corrected across extended tasks.
- [Explore Like Humans](https://arxiv.org/abs/2604.19034): An autonomous exploration harness for embodied agents with online SG-Memo construction. Core idea: build spatial and semantic memory during exploration so later navigation decisions can use an evolving environment model.
- [AsyncShield](https://arxiv.org/abs/2604.24086): A plug-and-play edge adapter for asynchronous cloud-based VLA navigation. Core idea: compensate for network jitter and stale visual-language intents with latency-aware control and safety filtering, making cloud-hosted VLA policies more usable in continuous mobile navigation loops.
- [GS-Playground](https://arxiv.org/abs/2604.25459): A high-throughput photorealistic simulation infrastructure for vision-informed robot learning. Core idea: use Gaussian-splatting assets and multimodal simulation interfaces so embodied policies can be trained and evaluated in visually rich environments at higher throughput.
- [Embodied EvoAgent](https://doi.org/10.1145/3746027.3754880): A brain-inspired embodied-agent paradigm for connecting multimodal large models with world models. Core idea: use an agent framework around perception, world modeling, and action so embodied systems can reason over environment state instead of relying on a single passive multimodal model.
- [Continual Harness](https://arxiv.org/abs/2605.09998): Provides an online-adaptation harness for self-improving foundation agents in long-horizon embodied tasks. Core idea: keep the adaptation loop outside the base model so task feedback can update behavior during extended interaction.
- [RIO](https://arxiv.org/abs/2605.11564): a flexible robot I/O infrastructure layer for cross-embodiment robot learning and deployment. Core idea: standardize robot control, teleoperation, sensors, data formatting, and policy deployment so embodied-agent runtimes can move across hardware with less setup-specific code.
- [Think Twice, Act Once](https://arxiv.org/abs/2605.12620): Provides a verifier-guided action-selection wrapper for embodied agents. Core idea: sample candidate actions at test time and use a trained verifier to choose the most reliable action without changing the base policy.
