# 1.8.4 Model

- [Minerva](https://arxiv.org/abs/2206.14858): A high-impact quantitative-reasoning recipe that continues training on mathematical and scientific corpora and uses chain-of-thought plus sampling at inference.
- [DeepSeekMath](https://arxiv.org/abs/2402.03300): A math-specialized language-model training recipe using mathematical pretraining data, supervised fine-tuning, and reinforcement learning.
- [DeepSeek-Prover-V1.5](https://arxiv.org/abs/2408.08152) ([code](https://github.com/deepseek-ai/DeepSeek-Prover-V1.5)): A Lean formal-proof model line using proof data, verifier feedback, and inference-time search around theorem proving.
- [Unlocking Multimodal Mathematical Reasoning via Process Reward Model](https://arxiv.org/abs/2501.04686): Introduces Unlocking Multimodal Mathematical Reasoning via Process Reward Model, a model-side contribution for Math.
- [AlphaGeometry 2](https://arxiv.org/abs/2502.03544) ([code](https://github.com/google-deepmind/alphageometry2)): A follow-up geometry-proving system that strengthens the collaboration between learned geometry reasoning and symbolic search.
- [Goedel-Prover](https://arxiv.org/abs/2502.07640) ([code](https://github.com/Goedel-LM/Goedel-Prover)): A formal theorem-proving model built around proof search and verifier-grounded output.
- [AlphaGeometry](https://www.nature.com/articles/s41586-023-06747-5) ([code](https://github.com/google-deepmind/alphageometry)): A neuro-symbolic geometry model system that couples learned premise generation with verifiable symbolic deduction.
- [Kimina-Prover Preview](https://arxiv.org/abs/2504.11354): Introduces Towards Large Formal Reasoning Models with Reinforcement Learning, a model-side contribution for Math.
- [Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?](https://arxiv.org/abs/2504.13837): Introduces Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?, a model-side contribution for Math.
- [DeepSeek-Prover-V2](https://arxiv.org/abs/2504.21801) ([code](https://github.com/deepseek-ai/DeepSeek-Prover-V2)): Uses Lean-verifiable subgoals, cold start, and reinforcement learning to train theorem-proving models for subgoal decomposition.
- [AceReason-Nemotron](https://arxiv.org/abs/2505.16400): Introduces Advancing Math and Code Reasoning through Reinforcement Learning, a model-side contribution for Math.
- [KTAE: A Model-Free Algorithm to Key-Tokens Advantage Estimation in Mathematical Reasoning](https://arxiv.org/abs/2505.16826): Estimates key-token advantages without model training to improve mathematical reasoning supervision signals.
- [Enigmata](https://arxiv.org/abs/2505.19914): Introduces Scaling Logical Reasoning in Large Language Models with Synthetic Verifiable Puzzles, a model-side contribution for Math.
- [Seed-Prover](https://arxiv.org/abs/2507.23726) ([code](https://github.com/ByteDance-Seed/Seed-Prover)): A lemma-style whole-proof system that uses Lean feedback, proven lemmas, self-summarization, and breadth-depth search for IMO-level proofs.
- [Goedel-Prover-V2](https://arxiv.org/abs/2508.03613) ([code](https://github.com/Goedel-LM/Goedel-Prover-V2)): Improves proof models through difficulty-progressive synthetic data, Lean compiler-feedback self-correction, and checkpoint averaging.
- [DeepSeekMath-V2](https://arxiv.org/abs/2511.22570): A self-verifiable mathematical reasoning model that trains generation and verification of mathematical reasoning together.
- [OProver](https://arxiv.org/abs/2605.17283): A Lean 4 proving framework that feeds failed attempts, compiler feedback, and verified proofs back into training and repair loops.
- [Olympiad-level formal mathematical reasoning with reinforcement learning](https://doi.org/10.1038/s41586-025-09833-y): Introduces Olympiad-level formal mathematical reasoning with reinforcement learning, a model-side contribution for Math.
