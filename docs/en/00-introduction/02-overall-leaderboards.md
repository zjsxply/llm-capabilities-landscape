# 0.2 Overall Experience-Oriented Leaderboards

> Parent chapter: 0. Introduction


- [LMSYS Chatbot Arena](https://lmarena.ai/leaderboard/text) is closer to an end-user experience leaderboard for text scenarios.
- [Vision Arena](https://lmarena.ai/leaderboard/vision) is closer to an end-user experience leaderboard for vision scenarios.
- [LLM Stats](https://llm-stats.com/) is a continuously aggregated overall model leaderboard that combines public benchmarks, API speed, pricing, and other signals into one comparison entry point. It is useful for quickly viewing overall trends across mainstream tasks.
- [Artificial Analysis Intelligence Index](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index) is a public composite model ranking that aggregates multiple hard evaluations into a broad capability index. It is useful as a vendor-facing overall comparison point, not as a specialized benchmark for one task family.
- [CAIS AI Dashboard](https://dashboard.safe.ai/) is an overview of frontier models across both capability and safety, covering text capability, vision capability, risk indices, and automation progress. It is useful for observing capability leaderboards and safety dashboards in one view.

These leaderboards are not dedicated benchmarks for any single specialized capability, so they are kept separately as overall experience indicators rather than placed in later capability chapters.
