# 1.10.3 Bench

Note: These benchmarks often do not require a specially named solver agent. The more common form is `a benchmark-provided harness (chunking, RAG toggles, no-context controls) + pluggable context compression/retrieval components`. Long-term memory across sessions and tasks is listed separately in [1.15 Memory](../15-memory/README.md); this section only keeps projects directly related to one-time long inputs or context-growth processes.

- [DUDE](https://arxiv.org/abs/2305.08455): Evaluates the effect of image-text long context on document understanding; the core idea is to use mixed image-text long input as the main load and emphasize evidence alignment.
- [L-Eval](https://arxiv.org/abs/2307.11088) ([leaderboard](https://l-eval.github.io/); [code](https://github.com/OpenLMLab/LEval)): What it evaluates: long-context QA, summarization, and closed-book/open-book tasks; core idea: establish a standardized long-context evaluation protocol, with early distinctions among context length, task type, and input dependence.
- [LongBench](https://arxiv.org/abs/2308.14508): Evaluates task completion quality under long context across a multitask set; the core idea is to compare `long input vs. truncation/no context` with unified data and scripts, exposing long-range dependency failure modes. ([leaderboard](https://longbench2.github.io/); [code](https://github.com/THUDM/LongBench))
- [BAMBOO](https://arxiv.org/abs/2309.13345) ([code](https://github.com/RUCAIBox/BAMBOO)): What it evaluates: long-text modeling capability, including cross-segment reasoning, summarization, and information localization; core idea: use a multitask set to diagnose LLM weaknesses in long-text structural understanding.
- [DocFinQA: A Long-Context Financial Reasoning Dataset](https://arxiv.org/abs/2401.06915): Extends FinQA questions from short snippets to full financial filings averaging 123K words, making numerical financial QA depend on document-scale retrieval and reasoning; retrieval pipelines and long-context LMs still struggle, especially on the longest reports.
- [Can Large Language Models Understand Context?](https://arxiv.org/abs/2402.00858): Evaluates whether large language models understand context beyond surface cues.
- [LV-Eval](https://arxiv.org/abs/2402.05136) ([leaderboard](https://github.com/infinigence/LVEval#leaderboard); [code](https://github.com/infinigence/LVEval)): What it evaluates: long-context performance across different length ranges up to 256K; core idea: use length levels for more balanced comparison and avoid evaluating only at a single length point.
- [Benchmarking and Building Long-Context Retrieval Models with LoCo and M2-BERT](https://arxiv.org/abs/2402.07440): Introduces LoCoV1, a 12-task benchmark for long-document retrieval where chunking is ineffective, and pairs it with M2-BERT, an 80M-parameter state-space encoder that retrieves from documents up to 32K tokens.
- [InfinityBench (∞Bench)](https://arxiv.org/abs/2402.13718) ([code](https://github.com/OpenBMB/InfiniteBench)): What it evaluates: capability on ultra-long context tasks exceeding 100K tokens; core idea: push evaluation length limits into larger ranges and explicitly expose degradation curves and the impact of truncation strategies under long input.
- [Same Task, More Tokens: the Impact of Input Length on the Reasoning Performance of Large Language Models](https://arxiv.org/abs/2402.14848): Controls for task content by padding the same QA reasoning samples with different lengths, types, and positions, showing that reasoning degrades well below advertised context limits and that next-token perplexity can correlate negatively with task success.
- [CLongEval: A Chinese Benchmark for Evaluating Long-Context Large Language Models](https://arxiv.org/abs/2403.03514): Builds a Chinese long-context suite with 7 tasks, 7,267 examples, windows from 1K to 100K tokens, and more than 2,000 manually annotated QA pairs, then releases data, scripts, and model outputs for comparing Chinese long-context LLMs.
- [Counting-Stars](https://arxiv.org/abs/2403.11802) ([code](https://github.com/nick7nlp/Counting-Stars)): What it evaluates: multi-evidence retrieval and reasoning in long contexts. Core idea: vary evidence position and count so models must collect distributed clues rather than solve a single-needle lookup.
- [NovelQA](https://arxiv.org/abs/2403.12766) ([project page](https://novelqa.github.io/), [dataset](https://huggingface.co/datasets/NovelQA/NovelQA)): What it evaluates: QA over book-length novels beyond 200K tokens. Core idea: require long-range character, event, and detail understanding so models are tested on narrative evidence spread across an entire work rather than on isolated needles.
- [ConvBench: A Multi-Turn Conversation Evaluation Benchmark with Hierarchical Capability for Large Vision-Language Models](https://arxiv.org/abs/2403.20194): Evaluates LVLMs in 577 curated multi-turn conversations across 215 tasks, using a perception-reasoning-creativity hierarchy so errors can be attributed to the capability level where the dialogue breaks.
- [ELITR-Bench: A Meeting Assistant Benchmark for Long-Context Language Models](https://arxiv.org/abs/2403.20262): Evaluates meeting-assistant QA over ASR transcripts by adding 271 manually written questions to the ELITR corpus and perturbing transcripts to controlled word-error-rate levels, exposing robustness to noisy oral long context.
- [Long-context LLMs Struggle with Long In-context Learning](https://arxiv.org/abs/2404.02060): Stress-tests whether long-context models can use many in-context examples rather than only retrieve nearby facts.
- [XL$^2$Bench: A Benchmark for Extremely Long Context Understanding with Long-range Dependencies](https://arxiv.org/abs/2404.05446): Tests extremely long English and Chinese contexts across fiction, paper, and law reading, with four task levels from memory retrieval to open-ended generation so long-range dependencies are not reduced to simple padding.
- [Ada-LEval: Evaluating long-context LLMs with length-adaptable benchmarks](https://arxiv.org/abs/2404.06480): Adds TSort and BestAnswer subsets whose input lengths can be precisely expanded up to 128K tokens, separating length effects that are entangled in mixed-length suites such as L-Eval and LongBench.
- [RULER](https://arxiv.org/abs/2404.06654) ([results](https://github.com/NVIDIA/RULER); [code](https://github.com/hsiehjackson/RULER)): What it evaluates: the "real usable context length" of long-context models; core idea: systematically diagnose the gap between "claimed window size" and "usable window size" with multiple needle/dependency forms.
- [MileBench](https://arxiv.org/abs/2404.18532) ([leaderboard](https://milebench.github.io/); [code](https://github.com/milebench/MileBench)): What it evaluates: multimodal long-context model performance on long videos, long image-text sequences, and cross-modal retrieval/reasoning; core idea: extend long-context pressure from pure text to multimodal input and provide a public leaderboard for alignment.
- [Can Perplexity Reflect Large Language Model's Ability in Long Text Understanding?](https://arxiv.org/abs/2405.06105): Critiques perplexity as a long-text proxy by showing that PPL mainly tracks local language modeling and has little correlation with downstream long-text understanding, warning against using low PPL as evidence of long-range dependency use.
- [Russian-Language Multimodal Dataset for Automatic Summarization of Scientific Papers](https://arxiv.org/abs/2405.07886): Releases 420 Russian scientific papers with text, tables, and figures for long-document scientific summarization, and reports baseline experiments with GigaChat and YandexGPT.
- [Challenges in Deploying Long-Context Transformers: A Theoretical Peak Performance Analysis](https://arxiv.org/abs/2405.08944): Quantifies serving bottlenecks for 100K-to-10M-token transformers by tracing prefill, concurrency, communication, and throughput limits back to KV-cache growth, making it a system-performance evaluation rather than a task dataset.
- [Long-Span Question-Answering: Automatic Question Generation and QA-System Ranking via Side-by-Side Evaluation](https://arxiv.org/abs/2406.00179): Uses whole books to synthesize questions about character arcs, themes, and delayed consequences, then ranks QA systems with pairwise evaluator judgments and a Bradley-Terry model instead of single-answer absolute scoring.
- [Analyzing Temporal Complex Events with Large Language Models? A Benchmark towards Temporal, Long Context Understanding](https://arxiv.org/abs/2406.02472): Introduces TCELongBench for news-based temporal complex events, with reading comprehension, temporal sequencing, and future forecasting tasks that compare long-window LLMs against RAG over extended event chains.
- [RepoQA: Evaluating Long Context Code Understanding](https://arxiv.org/abs/2406.06025): Creates 500 Searching Needle Function tasks from 50 repositories in 5 programming languages, requiring models to locate functions from natural-language descriptions rather than exact-code needles.
- [BABILong: Testing the Limits of LLMs with Long Context Reasoning-in-a-Haystack](https://arxiv.org/abs/2406.10149): Tests long-context reasoning with synthetic reasoning-in-a-haystack tasks that require using scattered evidence.
- [SEAM: A Stochastic Benchmark for Multi-Document Tasks](https://arxiv.org/abs/2406.16086): Standardizes multi-document summarization, QA, and coreference inputs, then repeatedly randomizes factors such as document order so evaluation captures prompt-variation sensitivity rather than a single static score.
- [One Thousand and One Pairs: A “novel” challenge for long-context language models](https://arxiv.org/abs/2406.16264): Creates a novel-based long-context challenge where models must match paired evidence across a long narrative instead of relying on a single local passage.
- [Losing Visual Needles in Image Haystacks: Vision Language Models are Easily Distracted in Short and Long Contexts](https://arxiv.org/abs/2406.16851): Introduces LoCoVQA, a generator that surrounds math, VQA, and character-recognition questions with in- and out-of-distribution distractor images, revealing rapid performance decay as visual context grows.
- [Leave No Document Behind: Benchmarking Long-Context LLMs with Extended Multi-Doc QA](https://arxiv.org/abs/2406.17419): Builds Loong, an extended multi-document QA benchmark where every document is relevant, using Spotlight Locating, Comparison, Clustering, and Chain of Reasoning tasks to avoid artificial filler noise.
- [Summary of a Haystack: A Challenge to Long-Context LLMs and RAG Systems](https://arxiv.org/abs/2407.01370): Synthesizes document haystacks with repeated target insights and asks systems to produce query-focused summaries with source citations, enabling automatic Coverage and Citation scoring for both long-context LLMs and RAG pipelines.
- [Needle in the Haystack for Memory Based Large Language Models](https://arxiv.org/abs/2407.01437): Uses passkey and needle-in-a-haystack recall to show that Larimar's external associative memory can write long contexts off GPU and retrieve facts at test time without training on longer windows.
- [MMLongBench-Doc](https://arxiv.org/abs/2407.01523): Evaluates long-document multimodal understanding; the core idea is to use document-style multimodal input to test cross-page/cross-segment alignment and summary compression.
- [KV Cache Compression, But What Must We Give in Return? A Comprehensive Benchmark of Long Context Capable Approaches](https://arxiv.org/abs/2407.01527): Benchmarks more than ten KV-cache, token-dropping, prompt-compression, linear-sequence, and hybrid approaches across seven long-context task categories, exposing tradeoffs hidden by evaluating only compression ratio or latency.
- [EVA-Score: Evaluation of Long-form Summarization on Informativeness through Extraction and Validation](https://arxiv.org/abs/2407.04969): Proposes an informativeness metric for abstractive long-form summarization that extracts information units from generated summaries, validates overlap with reference content, and reports a quantitative richness score.
- [NeedleBench: Can LLMs Do Retrieval and Reasoning in 1 Million Context Window?](https://arxiv.org/abs/2407.11963): Generates bilingual long-context tests with adaptive lengths and controlled evidence density, separating sparse needle retrieval from dense Ancestral Trace reasoning where evidence is continuously distributed.
- [Visual Haystacks: A Vision-Centric Needle-In-A-Haystack Benchmark](https://arxiv.org/abs/2407.13766): Evaluates multi-image QA over large sets of unrelated images, measuring cross-image reasoning and key-image position bias, and adds MIRAGE as a lightweight visual-RAG baseline for thousands of images.
- [Fast Training Dataset Attribution via In-Context Learning](https://arxiv.org/abs/2408.11852): Estimates training-data contribution by comparing LLM outputs with and without retrieved context and by fitting a mixture-distribution matrix factorization model; it is a data-attribution evaluation lead rather than a core long-context benchmark.
- [UserSumBench: A Benchmark Framework for Evaluating User Summarization Approaches](https://arxiv.org/abs/2408.16966): Evaluates user-profile summarization without references using MovieLens, Yelp, and Amazon Review data, and supplies a time-hierarchical summarizer plus self-critique verifier as a hallucination-resistant baseline.
- [DetectiveQA: Evaluating Long-Context Reasoning on Detective Novels](https://arxiv.org/abs/2409.02465): Provides 1,200 human-written Chinese and English questions over detective novels averaging more than 100K tokens, with reference reasoning steps and a step-wise metric for narrative evidence retrieval.
- [Retrieval Or Holistic Understanding? Dolce: Differentiate Our Long Context Evaluation Tasks](https://arxiv.org/abs/2409.06338): Classifies benchmark items by retrieval versus holistic understanding using complexity and redundancy parameters, estimating from sampled short spans whether a task can be solved without reading the full context.
- [Michelangelo: Long Context Evaluations Beyond Haystacks via Latent Structure Queries](https://arxiv.org/abs/2409.12640): Uses Latent Structure Queries to build synthetic, automatically scored code and natural-language tasks where models must filter irrelevant context, recover a hidden structure, and answer details about that structure rather than find a single needle.
- [FRAMES](https://arxiv.org/abs/2409.12941) (dataset: [google/frames-benchmark](https://huggingface.co/datasets/google/frames-benchmark)): What it evaluates: factuality, retrieval, and multi-hop reasoning in retrieval-augmented and long-document environments; core idea: use questions that require integrating evidence across multiple documents to jointly measure `factuality + retrieval + reasoning`.
- [Evaluating Multilingual Long-Context Models for Retrieval and Reasoning](https://arxiv.org/abs/2409.18006): Introduces or analyzes a benchmark, dataset, metric, or evaluation protocol for long-context, memory, or sequence modeling.
- [LFQA-E: Carefully Benchmarking Long-form QA Evaluation](https://arxiv.org/abs/2410.01945): Builds a multilingual reference-based meta-evaluation set for long-form QA with 1,618 questions and 7,323 pairwise comparisons across 15 topics, showing that 17 automatic metrics still fall short of human judgments.
- [HELMET](https://arxiv.org/abs/2410.02694) ([leaderboard](https://princeton-nlp.github.io/HELMET/); [code](https://github.com/princeton-nlp/HELMET)): What it evaluates: a multidimensional long-context evaluation set; core idea: combine dimensions such as retrieval, RAG, reranking, reasoning, and learning, avoiding the use of only needle-style tasks as a proxy for long-context capability.
- [MathHay: An Automated Benchmark for Long-Context Mathematical Reasoning in LLMs](https://arxiv.org/abs/2410.04698): Automates long-context math tasks that combine information seeking with multi-step calculation, showing that strong general models still lose accuracy when the relevant mathematical evidence is embedded in long inputs.
- [DAPE V2: Process Attention Score as Feature Map for Length Extrapolation](https://arxiv.org/abs/2410.04798): Treats attention scores as feature maps and applies convolution over neighboring heads to improve length extrapolation, making it a model-side long-context method that should be reviewed for Model placement.
- [Cognitive Overload Attack:Prompt Injection for Long Context](https://arxiv.org/abs/2410.11272): Evaluates long-context prompt-injection risk by crafting cognitive-overload prompts that exploit in-context learning load, reporting jailbreak success across GPT-4, Claude, Llama, and Gemini models.
- [Holistic Reasoning with Long-Context LMs: A Benchmark for Database Operations on Massive Textual Data](https://arxiv.org/abs/2410.11996): Introduces HoloBench, which converts database-style operations over massive textual data into controllable long-context tasks varying information density, distribution, context length, and query complexity.
- [How much do contextualized representations encode long-range context?](https://arxiv.org/abs/2410.12292): Uses perturbations and anisotropy-calibrated cosine similarity to measure how much model representations encode long-range patterns, revealing differences between recurrent, hybrid, and Transformer architectures beyond perplexity.
- [Towards More Effective Table-to-Text Generation: Assessing In-Context Learning and Self-Evaluation with Open-Source Models](https://arxiv.org/abs/2410.12878): Studies open-source table-to-text generation under different in-context example strategies and LLM self-evaluation prompts, finding that examples help generation but self-evaluation remains weakly aligned with human-oriented metrics.
- [LONG²RAG: Evaluating Long-Context & Long-Form Retrieval-Augmented Generation with Key Point Recall](https://arxiv.org/abs/2410.23000): Evaluates long-context and long-form retrieval-augmented generation with key-point recall over extended evidence.
- [What is Wrong with Perplexity for Long-context Language Modeling?](https://arxiv.org/abs/2410.23771): Introduces LongPPL, a long-short context contrastive metric that focuses on key tokens, and pairs it with LongCE re-weighting to show why average PPL hides long-context failures.
- [Long Context RAG Performance of Large Language Models](https://arxiv.org/abs/2411.03538): Studies RAG workflows over three domain datasets while varying total context from 2K to 128K tokens, and up to 2M where models allow it, showing when adding retrieved documents helps and when long-context accuracy collapses beyond 64K.
- [Needle Threading: Can LLMs Follow Threads through Near-Million-Scale Haystacks?](https://arxiv.org/abs/2411.05000): Tests whether LLMs can follow information threads across near-million-scale contexts.
- [On Many-Shot In-Context Learning for Long-Context Evaluation](https://arxiv.org/abs/2411.07130): Introduces MANYICLBENCH, distinguishing similar-sample learning from all-sample learning and showing that some many-shot tasks collapse around 16K tokens even when models handle retrieval-like prompts up to 64K.
- [SummExecEdit: A Factual Consistency Benchmark in Summarization with Executable Edits](https://arxiv.org/abs/2412.13378): Builds factual-consistency tests from executable summary edits, scoring both error detection and explanation quality and showing that more than twenty LLMs still fail on a large fraction of edited cases.
- [DynamicKV: Task-Aware Adaptive KV Cache Compression for Long Context LLMs](https://arxiv.org/abs/2412.14838): Adapts KV-cache budgets per layer and task during inference, retaining about 1.7% of cache size while preserving most LongBench performance, so it belongs primarily with model-side long-context compression.
- [LongBench v2](https://arxiv.org/abs/2412.15204): Evaluates updated long-context task families and stronger control protocols; the core idea is to make toggles such as `--rag N / --no_context / --cot` explicit, strengthening controllable variables in the benchmark-side harness. ([leaderboard](https://longbench2.github.io/); [code](https://github.com/THUDM/LongBench))
- [LongDocURL](https://arxiv.org/abs/2412.18424): Evaluates information localization and citation consistency over long documents plus URLs/citation chains; the core idea is to make alignment between external references (URLs) and long-document evidence central to scoring.
- [Unified Multi-Scenario Summarization Evaluation and Explanation](https://doi.org/10.1109/tkde.2024.3509715): Compares summarization evaluation across multiple scenarios and adds explanation-oriented analysis, but the available DOI metadata is insufficient here to pin down a long-context-specific protocol.
- [RAG-Check: Evaluating Multimodal Retrieval Augmented Generation Performance](https://arxiv.org/abs/2501.03995): Evaluates multimodal RAG reliability with separate retrieval relevancy and generation correctness scores, training RS and CS judges from human labels over a 5,000-sample annotated database.
- [Eliciting In-context Retrieval and Reasoning for Long-context Large Language Models](https://arxiv.org/abs/2501.08248): evaluates in-context retrieval and reasoning for long-context models under realistic confounding passages, making it a useful long-context benchmark beyond simplified whole-context QA.
- [LongReason](https://arxiv.org/abs/2501.15089): Evaluates long-context reasoning through context expansion. Core idea: synthesize long-context versions of short reasoning questions across reading comprehension, logical inference, and math word problems, then measure degradation as context grows.
- [Evaluating Large Language Models in Vulnerability Detection Under Variable Context Windows](https://arxiv.org/abs/2502.00064): Tests ten LLMs on vulnerability detection while varying tokenized Java-code length, finding model-specific links between context window size and both detection accuracy and answer explicitness.
- [Adaptive Distraction: Probing LLM Contextual Robustness with Automated Tree Search](https://arxiv.org/abs/2502.01609): A contextual-robustness benchmark method using automated tree search. Core idea: generate coherent but task-irrelevant distractions that stress whether long-context models preserve the original task signal.
- [NoLiMa](https://arxiv.org/abs/2502.05167): What it evaluates: long-context understanding beyond literal matching; core idea: reduce needle-style retrieval shortcuts through rewriting, indirect reference, and non-literal clues, emphasizing true semantic localization and reasoning.
- [GSM-Infinite: How Do Your LLMs Behave over Infinitely Increasing Context Length and Reasoning Complexity?](https://arxiv.org/abs/2502.05252): Scales GSM-style reasoning across increasing context length and complexity.
- [DebateBench: A Challenging Long Context Reasoning Benchmark For Large Language Models](https://arxiv.org/abs/2502.06279): A long-context reasoning benchmark built around debate-style tasks.
- [LaRA: Benchmarking Retrieval-Augmented Generation and Long-Context LLMs - No Silver Bullet for LC or RAG Routing](https://arxiv.org/abs/2502.09977): A benchmark for routing between retrieval-augmented generation and long-context LLMs; core idea: test when retrieval, long context, or hybrid routing is actually preferable.
- [SCALAR: Scientific Citation-based Live Assessment of Long-context Academic Reasoning](https://arxiv.org/abs/2502.13753): Evaluates long-context academic reasoning through live citation-based tasks, stressing whether models can use scholarly evidence rather than only retrieve isolated passages.
- [Large Language Models Struggle to Describe the Haystack without Human Help: Human-in-the-loop Evaluation of LLMs](https://arxiv.org/abs/2502.14748): Compares unsupervised, supervised, and traditional topic-model workflows for exploring large corpora, showing that LLM-generated topics are readable but often too generic without human supervision.
- [DocPuzzle: A Process-Aware Benchmark for Evaluating Realistic Long-Context Reasoning Capabilities](https://arxiv.org/abs/2502.17807): A process-aware benchmark for realistic long-context reasoning. Core idea: ask expert-level questions over long real-world documents that require multi-step reasoning rather than simple span retrieval.
- [PhantomWiki: On-Demand Datasets for Reasoning and Retrieval Evaluation](https://arxiv.org/abs/2502.20377): Evaluates on-demand reasoning and retrieval datasets. Core idea: make long-context and retrieval reasoning measurable with task-specific data, protocols, metrics, or diagnostic environments rather than generic aggregate scores.
- [U-NIAH: Unified RAG and LLM Evaluation for Long Context Needle-in-a-Haystack](https://arxiv.org/abs/2503.00353): Unifies RAG and long-context needle-in-a-haystack evaluation.
- [One ruler to measure them all: Benchmarking multilingual long-context language models](https://arxiv.org/abs/2503.01996): Introduces ONERULER, a multilingual long-context benchmark extending RULER across 26 languages.
- [Sequential-NIAH: A Needle-In-A-Haystack Benchmark for Extracting Sequential Needles from Long Contexts](https://arxiv.org/abs/2504.04713): A long-context needle-in-a-haystack benchmark for sequential information extraction. Core idea: test completeness and order consistency when multiple needles appear in long contexts.
- [NeedleInATable](https://arxiv.org/abs/2504.06560): Evaluates long-context capability on long structured tables. Core idea: treat table cells as needles and ask models to locate or look up target cells, separating robust table perception from downstream tabular-task shortcuts.
- [Can LLMs reason over extended multilingual contexts? Towards long-context evaluation beyond retrieval and haystacks](https://arxiv.org/abs/2504.12845): Evaluates long-context reasoning. Core idea: use the paper's task, dataset, or protocol around can llms reason over extended multilingual contexts? towards long-context evaluation beyond retrieval and haystacks to make this capability more comparable.
- [ETHIC](https://aclanthology.org/2025.naacl-long.283/) ([code](https://github.com/dmis-lab/ETHIC)): What it evaluates: long-context tasks with high information coverage. Core idea: force models to use many relevant pieces of a long input, reducing the bias toward benchmarks answerable from one retrieved span.
- [LOFT: Scalable and More Realistic Long-Context Evaluation](https://doi.org/10.18653/v1/2025.findings-naacl.374): What it evaluates: a scalable and more realistic long-context evaluation benchmark.
- [REVEAL: Multi-turn Evaluation of Image-Input Harms for Vision LLM](https://arxiv.org/abs/2505.04673): Evaluates image-input harms in multi-turn VLLM conversations, making safety behavior depend on accumulated visual-dialogue context rather than a single-image prompt.
- [MMLongBench](https://arxiv.org/abs/2505.10610): Evaluates a multimodal long-context task family; the core idea is to make robustness under mixed `long visual / long text` input reproducible.
- [SemTrace](https://arxiv.org/abs/2505.13353): Evaluates semantic recall in long-context code reasoning; its counterfactual tasks test whether models understand operational semantics instead of relying on lexical or pattern-matching shortcuts.
- [CUB: Benchmarking Context Utilisation Techniques for Language Models](https://arxiv.org/abs/2505.16518): Benchmarks context-utilisation techniques. Core idea: test whether models use relevant context, ignore distractors, and handle conflicts with parametric memory.
- [100-LongBench: Are de facto Long-Context Benchmarks Literally Evaluating Long-Context Ability?](https://arxiv.org/abs/2505.19293): Provides a length-controllable variant and a metric that separates baseline model ability from true long-context use, making breakdown points comparable instead of fixing every benchmark item at one input length.
- [MiniLongBench](https://arxiv.org/abs/2505.19959): A low-cost long-context understanding benchmark. Core idea: prune redundant samples from larger LCU benchmarks to preserve diagnostic coverage while reducing evaluation time and inference cost.
- [Rethinking Chunk Size For Long-Document Retrieval: A Multi-Dataset Analysis](https://arxiv.org/abs/2505.21700): Analyzes retrieval chunk size across multiple long-document retrieval datasets.
- [ToolHaystack](https://arxiv.org/abs/2505.23662): What it evaluates: information retention and invocation decisions for tool-augmented models in long-term interaction; core idea: extend haystack stress tests to realistic multi-turn tool-use settings and observe alignment among historical evidence, tool results, and the current goal.
- [Evaluating the Sensitivity of LLMs to Prior Context](https://arxiv.org/abs/2506.00069): A benchmark suite for sensitivity to prior context in sustained interactions. Core idea: measure how previous turns alter model behavior, complementing single-turn QA evaluation.
- [LongBioBench](https://arxiv.org/abs/2506.02921) ([code](https://github.com/Thomasyyj/LongBio-Benchmark), [dataset](https://huggingface.co/datasets/thomasyyj/LongBioBench_Sample)): What it evaluates: controllable long-context understanding over biographical narratives. Core idea: construct coherent long-context examinations where target facts are meaningfully embedded, making difficulty and evidence position easier to control than in purely synthetic needle tasks.
- [Generating Q&A Benchmarks for RAG Evaluation in Enterprise Settings](https://doi.org/10.18653/v1/2025.acl-industry.33): Generates question-answer benchmarks for enterprise RAG evaluation.
- [Serial Position Effects of Large Language Models](https://doi.org/10.18653/v1/2025.findings-acl.52): Evaluates serial-position effects in large language models.
- [LOOM-Scope](https://arxiv.org/abs/2507.04723): A standardized and efficient long-context evaluation framework that aligns settings across benchmark suites and supports lower-cost comprehensive assessment.
- [Ref-Long: Benchmarking the Long-context Referencing Capability of Long-context Language Models](https://arxiv.org/abs/2507.09506): Measures long-context referencing by asking models to identify which documents cite or refer to a target key, spanning synthetic-to-realistic subsets and exposing failures even in GPT-4o-class models.
- [Document Haystack](https://arxiv.org/abs/2507.15882): Evaluates long-context multimodal document understanding for VLMs. Core idea: insert text or text-image needles at different depths inside 5-to-200-page visually complex documents and score retrieval with objective automated questions.
- [NeedleChain: Measuring Intact Long-Context Reasoning Capability of Large Language Models](https://arxiv.org/abs/2507.22411): Tests full-context integration with contexts composed entirely of query-relevant evidence, using three comprehension-order variants plus a needle-in-a-haystack comparison and a training-free ROPE contraction intervention.
- [Are We on the Right Way for Assessing Document Retrieval-Augmented Generation?](https://arxiv.org/abs/2508.03644): A benchmark and diagnostic study for multimodal document RAG assessment. Core idea: evaluate retrieval, evidence labels, and generation bottlenecks in real document-RAG systems.
- [PRELUDE](https://arxiv.org/abs/2508.09848): What it evaluates: long-context tasks requiring global understanding and cross-segment reasoning; core idea: make questions depend on the overall document structure and combinations of distant evidence, reducing the evaluation bias that local segment retrieval alone can answer.
- [HAMLET](https://arxiv.org/abs/2508.19578): Evaluates book-length context comprehension with a multi-level key-fact hierarchy. Core idea: use root-, branch-, and leaf-level facts plus query-focused summarization to diagnose coarse versus fine-grained recall and lost-in-the-middle effects.
- [Who Gets Cited Most? Benchmarking Long-Context Numerical Reasoning on Scientific Articles](https://arxiv.org/abs/2509.21028): Evaluates long-context numerical reasoning over scientific articles. Core idea: generate verifiable SQL-backed questions requiring counting, sorting, aggregation, and comparison across full papers.
- [Maximum Effective Context Window](https://arxiv.org/abs/2509.21361): Evaluates how much context models can actually use under different problem types. Core idea: distinguish advertised maximum context length from effective context length through standardized degradation tests.
- [LongLeader](https://arxiv.org/abs/2509.23161) ([ACL Anthology page](https://doi.org/10.18653/v1/2025.naacl-long.439)): What it evaluates: a comprehensive long-context leaderboard and evaluation framework. Core idea: unify ranking criteria across tasks, length ranges, and metrics, avoiding overrepresentation of long-context capability by a single LongBench/needle task.
- [MDSEval: A Meta-Evaluation Benchmark for Multimodal Dialogue Summarization](https://arxiv.org/abs/2510.01659): Creates a meta-evaluation set for image-sharing dialogue summarization with summaries and human judgments over eight quality aspects, using mutually exclusive key information across modalities to filter richer examples.
- [Evaluation Framework for Highlight Explanations of Context Utilisation in Language Models](https://arxiv.org/abs/2510.02629): Evaluates whether highlight explanations correctly show which context pieces language models use, exposing when answers rely on provided context versus parametric memory.
- [Finding Diamonds in Conversation Haystacks: A Benchmark for Conversational Data Retrieval](https://arxiv.org/abs/2510.02938): Evaluates retrieval over conversation corpora for product insights. Core idea: use 1.6K analytical queries over 9.1K conversations to test retrieval under turn dynamics and implicit state.
- [Context Length Alone Hurts LLM Performance Despite Perfect Retrieval](https://arxiv.org/abs/2510.05381): Shows that long inputs can degrade reasoning even when all relevant information is retrieved, separating retrieval failure from long-context computation failure.
- [AudioMarathon: A Comprehensive Benchmark for Long-Context Audio Understanding and Efficiency in Audio LLMs](https://arxiv.org/abs/2510.07293): A benchmark for long-context audio understanding and efficiency. Core idea: test long-range temporal audio reasoning beyond short-clip benchmarks.
- [HaystackCraft](https://arxiv.org/abs/2510.07414): What it evaluates: long-context robustness under heterogeneous retrieval and agentic context growth. Core idea: engineer haystacks from Wikipedia hyperlink structure and simulate retrieval bias, query refinement, reflection, and stopping decisions, moving beyond single-needle tests.
- [LiteraryQA](https://arxiv.org/abs/2510.13494): Evaluates long-document narrative question answering on cleaned literary works. Core idea: repair noisy NarrativeQA-style samples and study automatic metrics so long-context narrative understanding is measured with more reliable evidence.
- [LC-Eval: A Bilingual Multi-Task Evaluation Benchmark for Long-Context Understanding](https://arxiv.org/abs/2510.16783): Evaluates English and Arabic contexts from 4K to more than 128K tokens across multi-document QA, bilingual QA, paragraph claim verification, and long-context multiple choice, where even GPT-4o struggles on some tasks.
- [AcademicEval](https://arxiv.org/abs/2510.17725) ([leaderboard and code](https://github.com/ulab-uiuc/AcademicEval); [dataset](https://huggingface.co/datasets/ulab-ai/AcademicEval)): What it evaluates: long-context generation tasks based on new arXiv papers; core idea: continuously connect sources to new papers and automatically construct tasks such as Title, Abstract, Introduction, and Related Work, reducing label leakage and covering hierarchical abstraction capability.
- [Overruled Precedent Benchmark](https://arxiv.org/abs/2510.20941): Evaluates long-document legal reasoning over U.S. Supreme Court case pairs. Core idea: require models to identify whether a precedent has been overruled from full judicial opinions, testing realistic cross-document legal understanding beyond synthetic long-context retrieval.
- [LooGLE v2](https://arxiv.org/abs/2510.22548) ([code](https://github.com/MuLabPKU/LooGLE-v2), [dataset](https://huggingface.co/datasets/MuLabPKU/LooGLE-v2)): What it evaluates: real long-text understanding from 16K to 2M tokens. Core idea: use long-document tasks in legal, finance, gaming, and code domains to test distant dependencies and global understanding, avoiding the use of only needle retrieval as a proxy for long-context capability.
- [Ko-LongRAG: A Korean Long-Context RAG Benchmark Built with a Retrieval-Free Approach](https://doi.org/10.18653/v1/2025.findings-emnlp.938): A Korean long-context RAG benchmark built with a retrieval-free construction route, useful for testing long-context retrieval and generation outside English.
- [Long Context Benchmark for the Russian Language](https://doi.org/10.18653/v1/2025.codi-1.1): Provides 18 Russian long-context datasets grouped into four complexity levels, covering retrieval, knowledge extraction, machine reading, QA, and reasoning up to 128K tokens, with released datasets, code, and leaderboard.
- [Comparison-Based Automatic Evaluation for Meeting Summarization](https://doi.org/10.21437/interspeech.2025-2771): Evaluates meeting-summarization outputs by comparison rather than isolated absolute scores, making it a long-meeting summary evaluation lead pending fuller protocol details.
- [SYNC](https://doi.org/10.18653/v1/2025.emnlp-main.1707): Evaluates long-context understanding with synthetic, controlled tasks. Core idea: isolate context-length and reasoning variables so model comparisons are less confounded by uncontrolled document content or task construction.
- [Oolong: Evaluating Long Context Reasoning and Aggregation Capabilities](https://arxiv.org/abs/2511.02817): A benchmark for long-context reasoning and aggregation; core idea: test whether models can combine many dispersed pieces of evidence instead of only retrieving a single relevant span.
- [What Matters in Evaluating Book-Length Stories? A Systematic Study of Long Story Evaluation](https://arxiv.org/abs/2512.12839): Introduces LongStoryEval with 600 newly published books averaging 121K tokens, derives an eight-aspect reader-review criterion structure, and compares aggregation-, incremental-, and summary-based evaluation methods.
- [LongBench Pro: A More Realistic and Comprehensive Bilingual Long-Context Evaluation Benchmark](https://arxiv.org/abs/2601.02872): Extends long-context evaluation with naturally occurring English and Chinese samples across broad task families and subtasks.
- [Gavel-Ref](https://arxiv.org/abs/2601.04424): evaluates long-context legal case summarization across multi-document cases of roughly 100K to 500K tokens. Core idea: use multi-value checklist items plus residual factual and writing-style checks to diagnose failures beyond one aggregate summary score.
- [ChronosAudio](https://arxiv.org/abs/2601.04876): Evaluates long-audio understanding in audio large language models. Core idea: use 36,000 instances over more than 200 hours of audio, stratified by duration, to diagnose long-context collapse, temporal-locality failures, and limits of current mitigation strategies in audio reasoning.
- [PosIR](https://arxiv.org/abs/2601.08363): What it evaluates: position bias in heterogeneous information retrieval. Core idea: use length-controlled buckets, reference-span relevance, 10 languages, and 31 domains to test whether retrievers miss evidence because it appears late or in difficult document positions.
- [RIKER](https://arxiv.org/abs/2601.08847): Evaluates knowledge retrieval and extraction systems through a coherent simulated universe. Core idea: generate documents from known ground truth so retrieval, cross-document aggregation, grounding, and hallucination resistance can be scored deterministically and regenerated to reduce contamination.
- [SagaScale: A Realistic, Scalable, and High-Quality Long-Context Benchmark Built from Full-Length Novels](https://arxiv.org/abs/2601.09723): A bilingual long-context benchmark built from full-length novels. Core idea: generate high-quality QA from external resources while withholding those resources during evaluation, reaching very long context lengths.
- [SIN-Bench](https://arxiv.org/abs/2601.10108): Evaluates native evidence-chain tracing in long-context multimodal scientific literature. Core idea: require models to construct cross-modal evidence chains inside full papers rather than match final answers alone.
- [CorpusQA](https://arxiv.org/abs/2601.14952): Evaluates corpus-level reasoning over document repositories up to 10 million tokens. Core idea: synthesize computation-intensive questions with programmatically guaranteed answers so systems must aggregate dispersed evidence across hundreds of documents; the results show long-context LLMs degrade with length and standard retrieval-augmented generation collapses, pointing toward memory-augmented architectures for global synthesis.
- [Is Length Really A Liability? An Evaluation of Multi-turn LLM Conversations using BoolQ](https://arxiv.org/abs/2601.16508): Converts BoolQ into multi-turn conversations with varying length and scaffolding, revealing model-specific veracity failures that are invisible in single-prompt evaluation.
- [Mil-SCORE](https://arxiv.org/abs/2601.21826): Benchmarks long-context geospatial reasoning and planning. Core idea: require selective reading across maps, reports, and heterogeneous sources so planning depends on integrated long-context evidence.
- [CL-Bench](https://arxiv.org/abs/2602.03587): Evaluates long-context learning and memory-organization capability; the core idea is to use a more systematic context-learning task family to make "what to remember, when to use it, and how to cite it" comparable.
- [Long-Context Long-Form Question Answering for Legal Domain](https://arxiv.org/abs/2602.07190): Targets legal QA whose answers span multiple pages, combining domain-vocabulary deconstruction, layout and footnote parsing, and a coverage metric that classifies recall of long-form answer content.
- [LOCA-bench](https://arxiv.org/abs/2602.07962) ([code](https://github.com/hkust-nlp/LOCA-bench)): What it evaluates: robustness of language agents under continuously growing context; core idea: turn long context from "single-shot input" into a "controlled growth process," specifically testing failure boundaries of memory/compression/retrieval strategies.
- [TS-Haystack: A Multi-Scale Retrieval Benchmark for Time Series Language Models](https://arxiv.org/abs/2602.14200): Tests time-series language models on ten event-grounded retrieval and reasoning tasks over 100-second to 24-hour contexts, including temporal reasoning, multi-step reasoning, and contextual anomaly detection.
- [MTRAG-UN: A Benchmark for Open Challenges in Multi-Turn RAG Conversations](https://arxiv.org/abs/2602.23184): Releases 666 multi-turn RAG tasks with more than 2,800 turns across 6 domains, focusing on unanswerable, underspecified, non-standalone, and unclear-response conversation failures.
- [BRIDGE](https://arxiv.org/abs/2603.07931): Evaluates multi-hop reasoning over long multimodal documents with grounded evidence. Core idea: require evidence integration across text, tables, and figures instead of scoring only final-answer correctness.
- [MedMT-Bench](https://arxiv.org/abs/2603.23519): Evaluates memory and understanding over long multi-turn medical conversations. Core idea: simulate diagnosis and treatment interactions so models must maintain medical context, resist interference, and preserve safety across turns.
- [Reasoning Shift: How Context Silently Shortens LLM Reasoning](https://arxiv.org/abs/2604.01161): Diagnoses how long context and multi-turn settings shorten reasoning traces and reduce self-verification.
- [YC-Bench](https://arxiv.org/abs/2604.01212): What it evaluates: long-term planning and consistent execution; core idea: make agents repeatedly use historical goals, resource states, and intermediate decisions in ongoing management-style tasks, observing the real benefits of context truncation, scratchpads, and memory strategies.
- [Prompt Compression in the Wild: Measuring Latency, Rate Adherence, and Quality for Faster LLM Inference](https://arxiv.org/abs/2604.02985): Measures prompt-compression latency, rate adherence, and output quality in realistic use.
- [CL-bench Life](https://arxiv.org/abs/2604.27043): Evaluates whether models can learn from real-life context. Core idea: use messy personal and social histories such as multi-party conversations, archives, and behavioral traces to test context learning beyond clean long documents.
- [ASTRA-QA: A Benchmark for Abstract Question Answering over Documents](https://arxiv.org/abs/2605.10168): A benchmark for abstract question answering over documents. Core idea: evaluate whether models can synthesize document-level abstractions rather than only extract local spans.
- [Needle In A Haystack](https://github.com/gkamradt/LLMTest_NeedleInAHaystack): What it evaluates: single-needle retrieval in long context; core idea: bury the target segment at different depths and lengths to quickly expose the gap between the "claimed window" and the "usable window."
- [MRCR](https://huggingface.co/datasets/openai/mrcr): What it evaluates: multi-needle coreference retrieval and localization in long context; core idea: place same-distribution requests with `2 / 4 / 8 needles` into long conversations and require the model to return the target segment in the specified order, testing real long-range distinction and indexing capability.
- [GraphWalks](https://huggingface.co/datasets/openai/graphwalks): What it evaluates: graph-traversal-style multi-hop reasoning in long context; core idea: encode graph operations such as BFS and parents as structured tasks in long prompts, testing whether models can maintain structural state and execute multi-step reasoning correctly in long input.
- [Long Document Summarization with Transformer Models: A Comparative Evaluation on the Gutenberg Dataset](https://doi.org/10.1145/3746709.3746746): Compares Transformer summarizers on long Gutenberg documents, making the entry a long-document summarization evaluation lead pending more detailed accessible metadata.
